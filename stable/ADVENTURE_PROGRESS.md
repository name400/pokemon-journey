- 우두머리 포획 난도를 구현할 때 개체 데이터의 종 기본 포획률까지 낮게 저장하던 문제를 수정했다. 이제 기본값은 그대로 보존하고 `isAlpha`가 있는 대상의 포획 계산에서만 0.4배 보정한다. 일반·우두머리 확률 비교와 실제 포획 후 저장된 기본값을 검사했다. 이 수정 전에 이미 생성된 격리 미리보기 개체를 일괄 변경하지는 않았다.
- 행동 없이 화면을 보고 있어도 낮밤과 게임 시각이 경계에서 갱신되도록 했다. 서버가 현재 시각을 응답하고 클라이언트는 같은 시계 계산으로 다음 게임 시간 경계에만 화면을 갱신한다. 숨겨진 탭에서는 타이머를 멈추고 돌아오면 갱신하며, 낮밤·해질녘·보름달 조건이 바뀌면 가벼운 재조회로 진화 조건도 다시 받는다. 서버 시계와 표시 계산의 시간·날짜 경계를 단위 검사했고, 별도 로컬 탭에서 입력 없이 게임 시각이 7시→8시로 바뀌는 것을 확인했다. 이 변경은 기존 진화 규칙이나 저장 스키마를 바꾸지 않으며 배틀존의 야간 입장 제한을 구현한 것은 아니다.
- 시간 표시와 서버 응답을 포함한 전체 테스트 73개, 타입 검사 및 빌드가 통과했다.
- 야생 정원에 `조용히 걷기`와 우두머리 감지를 추가했다. 은신하지 않은 플레이어가 우두머리 시야 2칸 안으로 들어오면 먼저 경고하고 현재 이동 묶음과 대기 중인 추가 이동을 멈춘다. 경고 후에도 가까이 움직이면 배틀이 시작되며, 멀어지거나 조용히 걷기를 켜면 경고가 해제된다. 포획·격파한 우두머리는 감지하지 않고, 경고 중 포획에 성공하면 경고가 남지 않는다. 고정 위치에서 거리·장애물로 판정하는 단순 반응이며 실제 추격 애니메이션이나 시야각은 미구현이다. 사용자에게 보여 주기 위해 로컬 미리보기에서 조용히 걷기를 켰고, 현재 토글은 다시 끌 수 있다. 경고→이탈, 경고→은신, 계속 접근 시 배틀, 자동 이동 중단, 포획 후 경고 해제를 격리 API와 단위 시험으로 확인했다. 전체 테스트 75개, 타입 검사 및 빌드 통과.
- 추가로 잘못된 은신 입력 거절과 재조회 후 은신·경고 상태 보존을 격리 API에서 확인했다.
- 일반 캐터피·뚜벅쵸는 조용히 걷지 않고 가까이 접근하면 놀라 30초 뒤 돌아오는 반응을 추가했다. 임시 부재는 영구 포획 상태와 별도로 저장되며 만료 시 정리되고, 열린 정원 화면은 돌아올 시점에 가벼운 재조회로 갱신한다. 은신 시에는 달아나지 않고, 놀란 순간 묶음 이동과 버퍼 이동을 멈춘다. 격리 API 및 단위 검사로 일시 부재·만료·은신을 확인했다. 단순 거리·시야 판정이며 실제 이동·도주 애니메이션은 아니다. 이후 사용자의 UI 통일 요청으로 전환했다.
- 위 기력의조각과 리그 확장 이후 전체 테스트 68개, 타입 검사 및 프로덕션 빌드가 통과했다. 배틀 중 기력의조각 거절도 API로 확인했다. UI 화면은 로컬 소켓 접근 거부 때문에 이번 변경 후 직접 확인하지 못했다.
- R까지 확장한 회귀 시험을 포함해 전체 테스트 68개, 타입 검사, 프로덕션 빌드가 통과했다. 화면 미리보기는 앞서 기록한 로컬 소켓 제한으로 재검증하지 못했다.
- 위 재연습 1.5배, 호텔 교습과 S 랭크 시험을 반영한 후 전체 테스트 68개, TypeScript 검사, 프로덕션 빌드가 다시 통과했다. 로컬 브라우저 서버의 연결 거부로 이번 UI 변경은 실제 화면에서 재검증하지 못했다.

## 재개 순서
1. 최신 기록과 사용자 지시를 확인하고 탐험 사본에서 계속 구현한다. 포켓로그는 참고하지 않는다. 기존 저장·레벨 100 상한·수동 진화와 다른 채팅의 공통 코드 소유권을 유지한다.
2. 공식 Z-A 자료를 기준으로 도시 지구·등장인물·사건·보상을 단계별로 대조한다. 현재 단순화한 MZ단 도입, 세 사건, 최종 조사는 원작 전체가 아니므로 빈 단계는 실제로 플레이·저장되는 기능으로 확장한다.
3. 야간 배틀존은 현재 상시 입장 가능한 턴제 공간이다. 낮·밤 순환, 원작에 가까운 배틀존 규칙 및 실시간 배틀은 아직 별도 설계와 구현이 필요하다. 공통 전투 엔진 소유 채팅과 경계를 조율하고 저장·연결 지연에서 일관성을 검증한다.
4. 자연 레벨·실제 파티로 도입부터 A 랭크, 메가 사건과 마지막 조사까지 난이도·경험치·자원 흐름을 검증한다. 기존 테스트의 Lv.100 보충 파티 결과를 자연 진행 검증으로 표시하지 않는다.
5. PC와 실제 모바일 기기의 입력·화면 회전·긴 연결 지연·응답 유실을 확인한다. 렌더러는 테스트상 유휴 프레임 예약을 중단하지만 실제 CPU·배터리 측정은 아직 없다.
6. 통합 전 사본·기준본·원본과 별도 클라우드의 미푸시 6커밋을 보존·대조하고 새 `pc*` 상태와 내부 구역의 저장 호환성을 확인한다. 원본/클라우드 덮어쓰기·배포는 하지 않는다.
