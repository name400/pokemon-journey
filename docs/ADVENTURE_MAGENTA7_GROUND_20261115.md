# 마젠타 7번지 지상 초안

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/magenta-sector-7.html)는 북동쪽 콰자르티코, 서쪽 마젠타 8번지, 동쪽 4번지, 남쪽 마젠타 스트리트와 남쪽 건물 안뜰을 기록한다. 독립 지상 화면과 네 구역의 왕복 접근을 추가했다. 건물 윤곽·안뜰의 입구와 크기·출입 좌표는 잠정 2D 배치다.

북쪽 안뜰의 불꽃 장애물·옥상 고도와 아이템의 위치는 확인되지 않아 새로 추가하지 않았다. 기존 화면의 통행 칸·저장 형식과 야생 구역 7·18의 해금 조건을 유지한다. 원작 실기와 실제 Sites 병합본은 확인하지 않았다. 모바일 이동 오류 기록은 운영 재검증 전까지 유지한다.
