# 베르 광장 주변 거리와 건물 표현

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-plaza.html)는 야생 구역 2가 광장의 잔디 부분에 있고 주변 번지·거리와 연결된다고 설명한다. [Bulbapedia](https://bulbapedia.bulbagarden.net/wiki/Vert_Plaza)는 광장이 원형이고 Z-A의 야생 구역 2가 대부분을 차지한다고 설명한다. 기존 광장 화면의 보행면 경계와 건물 외곽을 구분해 표시했다.

현재 화면은 야생 구역 2를 별도 화면으로 연결한 압축 2D 초안이다. 건물 형태·좌표와 도로 선형은 원작에서 측량한 값이 아니며, 원작과의 정확한 위치·외형은 미확인이다. 타일, 충돌, 출입 및 저장은 변경하지 않았다.

광장과 주변 구역 연결 및 기존 저장 복원 등을 포함하는 66개 개발 단위 검사가 통과했고 모의 API의 PC·모바일 Chromium 화면을 확인했다. 전체 타입 검사는 프로세스가 종료되어 통과 여부를 확인하지 못했다. 원작 기기와 실제 Sites 병합본은 확인하지 않았다.
