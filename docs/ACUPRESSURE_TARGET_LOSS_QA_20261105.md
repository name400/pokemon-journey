# 경혈찌르기의 대상 소실

원본 `MovePhase.getActiveTargetPokemon`과 `USER_OR_NEAR_ALLY` 대상을 대조했다. 신규 도전의 `acupressureFaintedTargetRule: source-v1`은 선택한 아군이 행동 전에 기절하거나 자리가 비면 능력치 상승을 사용자에게 재지정하지 않는다. 같은 자리에 다른 아군이 교체되면 해당 아군을 대상으로 한다. 이전 도전은 이전 동작을 유지한다.

격리 전투에서 선공 기절 시 실패·PP 소비, 교체된 아군, 사용자 직접 선택, 다이맥스 맥스가드, 변신으로 기술을 복사한 뒤 저장 복원 및 다른 저장 데이터 보존을 검사했다. 호출·동시 기절·Z기술·특성·도구의 모든 조합과 실제 브라우저·모바일 조작은 별도 검증이 필요하다. 운영 데이터와 Sites는 변경하지 않았다.
