# 에스파스 비드의 지상과 수변 표시

[지역 설명](https://www.pokepedia.fr/All%C3%A9e_Ranavoir)은 건물 사이 좁은 길과 양끝의 계단을, [야생 구역 10 설명](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_10)은 에스파스 비드 쪽 출입과 수로를 설명한다. 기존 2D 지상 건물·포장로·계단을 구별하고, 별도 하층의 석재 보행면과 물가를 지상과 다르게 표시했다. 기존 계단과 양 층의 출입 연결을 그대로 사용한다.

건물 윤곽·높이, 계단 위치와 수로 폭은 원작에서 추출한 값이 아닌 2D 초안이다. 지도 타일·충돌·층 연결·조우 및 저장 위치는 바꾸지 않았다.

기존 구역 10·블루 4·6번지 왕복, 지상·하층 연결 및 저장 복원 단위 검사 3건과 타입 검사가 통과했다. PC·모바일 Chromium에서는 모의 API로 양 층 화면과 계단 대화를 확인했다. 원작 기기·운영 D1·Sites 병합본은 확인하지 않았다.
