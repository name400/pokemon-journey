# 블루 5번지와 에이믈리스 공원 접근

- [에이믈리스 공원 자료](https://bulbapedia.bulbagarden.net/wiki/Aymlis_Park)는 공원이 블루 5번지 동쪽에 있으며 이후 야생 구역 12가 공원 대부분을 차지한다고 설명한다. [구역 12 안내](https://pokemongohub.net/post/guide/all-wild-zones-pokemon-legends-z-a/)는 서쪽 입구를 확인한다.
- 기존 2D 지도에서 서쪽 건물과 안뜰, 남북 도로, 동쪽 공원 접근로 두 곳, 물가와 계단을 각각 그려 구분했다. 기존 보행 타일·계단·진행 조건·두 출입 연결은 변경하지 않았다. 원작에서 공원이 동쪽이라는 관계와 서쪽 입구는 확인했으나 두 입구의 정확한 개수·간격, 건물 입면과 도로 폭·물가 위치는 이 게임의 초안이다.
- 이전 안뜰 저장 위치의 재접속과 두 기존 공원 출입구 왕복, 파티·재화·진행 보존을 격리 API에서 확인했다. PC·모바일 Chromium 검사는 시험 상태와 외부 이미지 대체물을 사용했다. 실제 운영 기기와 원작 전체 도시의 정확한 배치는 확인하지 않았다.
