# v52 파티 및 타입 표시 배치

승인 원본의 파티 점은 논리 화면에서 4×4px, 세로 간격 3px이다. 포켓로그 280px 화면에서는 기존 점이 논리 약 9.26px이고 마지막 점이 장면 밖(y 약 225)이었다. 점 크기·간격·시작점과 타입 아이콘 간격·정렬을 원본의 장면 비율에 맞췄다. 실제 파티의 정상·기절·빈 칸 상태와 접근성 라벨은 보존했다. 공통 스타일이므로 탐험 단일에도 적용된다.

격리 포켓로그 Chromium의 280×568, 390×844, 844×390, 960×540에서 원본 HTML과 점 여섯 개 및 상대 타입 두 개의 좌표·크기를 각각 0.2 논리 픽셀 이내로 비교했다. 1마리·6마리 격리 파티에서 정상·빈 칸·기절 표시와 라벨을 확인했다. 이전 이름·HP 좌표와 실제 단일·더블 기술·PP·상성 회귀도 통과했다. 원본 타입 PNG 대신 임시 이미지를 사용한 좌표 검사이므로 이미지의 픽셀 일치가 아니다. 탐험 브라우저, 실제 기기 및 원본 포켓몬 PNG를 포함한 전체 화면 일치는 미검증이다. 사용자 저장과 Sites는 변경하지 않았다.
