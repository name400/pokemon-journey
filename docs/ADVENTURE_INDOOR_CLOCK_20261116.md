# 건물 내부 시계 정지

[시간 자료](https://bulbapedia.bulbagarden.net/wiki/Time#Pok%C3%A9mon_Legends:_Z-A)는 건물 내부와 일시정지 메뉴·지도에서 시간이 멈추며 일반 야생 전투에서는 흐른다고 설명한다. 현재 구현은 모든 전투를 정지하며, 전투 밖 건물 안에서는 시간이 흘렀다. 이 자료는 2차 출처이며 원작 기기와는 직접 비교하지 않았다.

기존 서버 보정 기록을 이용해 명시적으로 식별되는 미르시티 건물 내부에서 시계를 멈추고 퇴실 후 재개한다. 호텔 옥상과 알 수 없는 향후 실내 식별자는 정지시키지 않는다. 건물 내 전투와 실내 이동 사이에 보정이 중복되지 않으며 기존 정수 휴식 시간·개체·재화를 초기화하지 않는다. 서버가 저장하는 다음 성공 행동부터 정지하므로 이미 실내에 있던 이전 저장의 과거 시간은 추정해 보정하지 않는다. 연결이 끊겨도 저장된 실내 정지는 계속 유지되는 웹게임 방식이며 원작의 게임 종료 동작을 확인한 것은 아니다.

단위 검사에서 자정·출현 주기·실내 이동·전투 겹침·재접속·퇴실·미확인 값 및 기존 휴식 오프셋을 확인했다. 격리 SQLite API에서 호텔 진입·재조회·퇴실과 19시에서 20시 경계, 파티·개체·재화와 기존 로열 전투 시계를 확인했다. 일시정지 메뉴와 지도는 서버에 열림·닫힘 및 다중 탭 상태가 전달되지 않아 정지하지 않는다. 하수도 등 `interior` 이외의 별도 맵과 일반 야생 전투 시계는 이번에 변경하지 않았다. 실제 운영 D1·모바일 기기·Sites 병합본 및 원작 기기 검증은 하지 않았다.
