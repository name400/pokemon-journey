# 구역 17 옥상 시간 전환과 플레이어 위치

[구역 17 안내](https://www.videogameschronicle.com/guide/pokemon-legends-z-a-wild-zone-17/)는 옥상의 클레피와 램프라가 낮과 밤에 같은 장소에서 나타난다고 설명한다. 현재 2D 맵도 같은 타일을 사용한다. 낮에 클레피를 처리한 뒤 그 칸에 선 상태에서 밤으로 바뀌면 램프라 표식이 플레이어 발밑에 나타나는 문제가 격리 API에서 재현됐다. 기존 갱신 안전 확인에는 구역 17의 현재 시간대가 빠져 있었고, 서로 다른 종의 소진 기록도 별개였다.

현재 플레이어가 점유한 구역 17의 출현 칸에는 필드 개체를 그리지 않고, 다음 시간대의 출현 후보가 같은 칸이면 주기 갱신도 이동 후까지 미룬다. 이동 후에는 기존 출현 주기와 이로치 보존 규칙으로 처리한다. 좌표·포획·소지품이나 저장 형식을 변경하지 않으며 보행에 DB 조회를 추가하지 않는다. 이 대기는 2D 충돌 안전을 위한 처리이며 원작의 정확한 재출현 거리나 시간이라고 단정하지 않는다.

격리 SQLite API에서 낮→밤과 밤→낮, 같은 칸 재접속·이동 후 출현·기존 이로치 보존·파티와 지갑을 확인했다. 구역 17 옥상 기존 조우·보상, 다른 구역 재출현 대기 및 이동 예측도 대표 회귀 검사했다. 원작 기기·운영 D1·Sites 병합본과 실제 브라우저는 검사하지 않았다.
