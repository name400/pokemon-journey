# 존느 3번지와 존느 광장 외곽길

[존느 3번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-3.html)는 동쪽에 존느 광장이 있다고 설명한다. 광장 바깥 거리와 기존 지상 화면 사이에 왕복 경로를 추가했다. 출입 좌표와 길의 선형은 잠정 2D 배치다.

기존 존느 5번지 출입과 야생 구역 8 해금 조건, 저장 형식을 유지하며 폭주 메가전의 다른 층이나 알 수 없는 층 기록을 덮어쓰지 않는다. 원작 실기와 실제 Sites 병합본은 확인하지 않았다. 모바일 이동 오류 기록은 운영 재검증 전까지 유지한다.
