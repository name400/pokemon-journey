# 베르 8번지와 9번지 지상 접근

[베르 8번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-8.html)는 서쪽의 베르 9번지 접근을, [베르 9번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-9.html)는 동쪽의 베르 8번지 접근을 설명한다. 이전 지도에는 두 번지를 직접 오가는 지상 경로가 없었다.

두 화면 사이의 왕복 접근을 추가했다. 출입 좌표와 길의 폭·선형은 원작에서 측정되지 않은 2D 추정이다. 기존 수로와 다리, 야생 구역 1과 호텔 방면 경로는 유지하며 이전 통행 칸을 막지 않는다. 저장 형식·미션 진행과 보유함은 변경하지 않는다.

대표 단위 검사에서 새 접근 양방향, 기존 위치 복원과 진행값, 수로·다리·구역 1 및 호텔 경로를 확인했다. 원작 실기·운영 D1·실제 Sites 병합본은 확인하지 않았고 모바일 이동 오류 및 배포 검사 실패 기록을 유지한다.
