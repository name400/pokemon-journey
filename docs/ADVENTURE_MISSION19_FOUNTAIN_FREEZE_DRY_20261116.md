# Mission 19 fountain: Freeze-Dry alternative

[Bulbapedia's walkthrough](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Part_14) describes opening the sewer using Ice Beam. A [player's account](https://www.reddit.com/r/LegendsZA/comments/1q8u6hb/mission_19_fountain_freeze_alternative/) specifically reports that Freeze-Dry also works. The second source is an individual report; this change does not assert that every Ice-type move works or independently verify the original on hardware.

The existing fountain action now accepts a healthy lead that knows either Ice Beam or Freeze-Dry, including the saved Korean names and English move aliases. Glalie's existing adventure growth data includes Freeze-Dry as its evolution move. The existing action, saved mission stages, sewer route, Pokémon, PP and rewards are retained; no existing save is migrated. The interaction's text reflects the accepted moves without changing the screen layout.

The isolated API fixture checks the Korean and English Freeze-Dry names, a non-confirmed Ice move and a fainted lead, stale request rejection, reconnect, unchanged Pokémon and wallet, and entry into the sewers. The existing Ice Beam and TM path is checked separately. This is not a natural playthrough, an original-device comparison, a production D1 test or a Sites merged-source test.
