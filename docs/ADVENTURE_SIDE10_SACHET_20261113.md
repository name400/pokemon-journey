# 사이드 미션 10과 향기주머니

[의뢰 원작 자료](https://www.serebii.net/legendsz-a/sidemissions/skiddo%27sfragrantleaves.shtml)와 [보상 안내](https://www.shacknews.com/article/146420/where-to-catch-a-skiddo-fragrant-leaves-pokemon-legends-za)에 따라 미션 7 시작 이후 베르날 대로의 Odette에게 파티의 메이클을 보여주면 향기주머니 2개·시몬열매 5개·800코인을 한 번 받는다. 요청자는 기존에 막혀 있던 경계에 배치했으며 2D 좌표는 초안이다. 기존 진행 데이터와 이미 보유한 도구·포켓몬은 그대로 둔다. 보상을 전부 받을 공간이 없으면 진행·재화를 바꾸지 않으며 기존 리비전 검사로 중복 요청을 거부한다.

향기주머니를 든 슈쁘의 통신교환 진화 조건은 기존 진화 로직을 사용한다. 슈쁘 자체의 야생 획득 경로와 사이드 미션 14의 휘핑팝 확정 획득 경로는 아직 구현하지 않았으므로 이것만으로 두 진화의 전체 정상 진행이나 연구 레벨 50 도달을 보장하지 않는다. 실제 원작 기기·운영 데이터는 검사하지 않았다.
