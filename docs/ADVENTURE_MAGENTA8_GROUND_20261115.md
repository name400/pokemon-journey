# 마젠타 8번지 지상 잔디 구간

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/magenta-sector-8.html)는 건물 사이 잔디의 슈퍼볼, 동쪽 건물 곁 퀵볼, 북쪽 움푹한 곳의 만병통치약을 기록한다. 자료는 2차 출처다. 기존 압축 2D 지도에 잔디 구간과 세 도구를 추가했다. 건물과 잔디의 크기, 움푹한 곳의 표현과 구체적 도구 좌표는 추정이며 원작 장면과의 정밀 일치는 미확인이다.

기존 통행 칸과 출입구를 보존하고 이전 저장 좌표를 유지한다. 지도·센터 접근·구역 18 제한 및 저장 복원 검사와 실제 라우터의 볼 한도·중복 요청·도구 수집 검사를 통과했다. 원작 기기와 운영 Sites는 확인하지 않았다. 모바일 이동 오류 기록은 운영 재검증 전까지 유지한다. 옥상과 비계의 세부 지형 및 다른 도구는 아직 미완성이다.
