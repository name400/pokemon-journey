# 미션 40 이상 우두머리 필드 포획

[미션 진행 공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Part_28)은 구역 3·5·9의 이상 우두머리를 포획하거나 쓰러뜨려 조사한다고 설명한다. [공식 모험 안내](https://legends.pokemon.com/en-us/news/adventure)는 야생 포켓몬에게 필드에서 볼을 던지는 방식을 설명한다. 이를 바탕으로 강철톤·엘레이드·부란다의 기존 현장에서 직접 볼을 선택해 던지는 경로를 추가했다. 개별 사건의 실제 원작 조준 조건은 확인하지 못했으며 인접 칸 조준은 이 게임의 2D 근사다.

직접 포획하면 해당 조사 기록·볼 소비·도감·보유함을 함께 저장하고, 볼에서 나오면 같은 우두머리와 기존 전투를 시작한다. 포획한 포켓몬은 기존 이벤트 기술과 우두머리 속성을 유지한다. 전투 중이거나 범위 밖, 이미 조사했거나 알 수 없는 조사·볼 기록은 거절한다. 이전 임시 조사 현장도 같은 진행 기록을 사용한다. 이로치 제한은 기존 이벤트 규칙을 유지한다.

구역 3·5·9에서 볼 탈출·전투·도주와 직접 포획, 기존 조사 기록·미확인 형식·중복 요청·파티 보존을 격리 API로 확인했다. 원작 실기와 실제 운영 D1·Sites 병합본 및 브라우저 화면은 검증하지 않았다.
