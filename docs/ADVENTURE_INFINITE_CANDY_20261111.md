# 무한 로열 경험사탕 보상

[무한 로열 보상 자료](https://bulbapedia.bulbagarden.net/wiki/Infinite_Z-A_Royale)의 보상전 연승별 사탕 수량을 첫 번째 보상전부터 적용한다. 보상전 패배 시 별도 연승 기록을 초기화하며, 누적 보상전 승수는 상대 순서와 플라엣테 진행에 계속 사용한다. 기존 저장에는 과거 패배 기록이 없으므로 첫 기록 생성 시 기존 누적 승수를 연승의 근사치로 사용한다. 이전에 지급하지 않았던 첫 두 배틀의 보상을 소급하지 않는다.

도구별 999개 제한에 걸리는 사탕은 승리 저장을 막지 않고 접수처에 보관한다. 공간을 만든 뒤 여러 차례에 나누어 받을 수 있다. 추첨 보상은 원작 목록과 가중치로 보상전 승리 때 한 번 결정한다. 마스터볼은 기존 볼 보관함에, 나머지는 도구 가방에 넣고 넘치는 수량은 가방에서 나누어 수령한다. 희귀 볼 7종은 기존 도구 수량을 그대로 사용한다. 영양제는 가방에서 선두 파티원에게 사용할 수 있다. 병뚜껑은 보유 기록과 표시만 지원하며 사용 효과는 아직 구현하지 않았다. 원작은 실시간 배틀이지만 이 프로젝트의 기존 턴제 배틀을 유지한다.

[Z-A 포획 설명](https://rotomlabs.net/guide/legends-z-a-capture-mechanics)과 [볼별 특성](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9_Ball)을 기준으로 일곱 희귀 볼의 조건을 반영한다. 2D 턴제 전투에서는 필드 수역 위치가 기록된 대상만 루어볼 보너스를 받으며, 위치가 없는 구 저장이나 불명확한 조우는 보너스를 주지 않는다. 레벨·러브볼은 현재 싸우는 생존 포켓몬을 기준으로 한다. 턴제 포획 기회에서 포켓몬이 필드에 나와 있는지는 원작의 실시간 상황과 완전히 동일하지 않다.

[Z-A 육성 자료](https://poketrainervault.com/legends-za/guides/competitive-building-guide/)에 따라 영양제는 노력치를 10씩, 한 능력치 252 및 총합 510 한도까지 올린다. [친밀도 자료](https://bulbapedia.bulbagarden.net/wiki/Friendship)에 따른 +4/+2 증가와 160 상한을 적용한다. 체력 변화는 기존 손상량을 유지하며 기절 상태는 회복하지 않는다.
