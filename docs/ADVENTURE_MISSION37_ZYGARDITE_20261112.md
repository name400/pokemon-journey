# 미션 37 지가르데나이트

[미션 37 공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Part_26)은 최종전에서 돌을 쥐면 지가르데나이트가 되어 메가진화한다고 설명한다. 새 진행에서 돌을 쥐면 기존 가방에 지가르데나이트를 지급하고 메가도감에 기록한다. 이미 보유하거나 기록된 돌은 중복 지급하지 않는다.

이전 버전에서 미션 37을 완료한 저장은 여행 기록에서 보상을 확인할 수 있다. 가방, 파티 밖 보관함의 지닌 도구, 과거 메가도감 기록을 확인한다. 과거에 이력 없이 돌을 처분한 경우는 구별할 수 없어 미수령으로 취급한다. 확인 및 지급 여부는 저장되어 재접속이나 재요청으로 중복 지급하지 않는다. 기존 포켓몬, 진행과 재화는 변경하지 않는다.

미션 42에서 얻는 스웜체인지 지가르데가 지가르데나이트를 지니고 체력이 절반 아래가 되어 퍼펙트폼으로 변한 뒤 기존 턴제 엔진에서 메가진화를 선택하는 대표 사례를 검사했다. 원작의 실시간 연출과 운영 환경은 검증하지 않았다.
