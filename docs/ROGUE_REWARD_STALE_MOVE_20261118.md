# 보상 화면의 오래된 기술 선택

- 전용 격리 브라우저에서 두 탭으로 재현했다. 한 탭에서 PP업 또는 기술머신의 기술을 선택한 뒤, 다른 탭에서 기억버섯으로 같은 자리를 바꾸고 첫 탭에서 요청하면 리비전 충돌로 갱신된다. 기존 화면은 자리 번호만 기억해 새 기술을 이전 선택처럼 표시하고 재확인할 수 있었다.
- 선택한 자리와 기술 이름을 함께 확인해 기술이 달라지면 선택을 해제하고 재선택하도록 했다. 다른 자리만 바뀐 경우 기존 선택은 유지한다. 선택 당시 가능한 PP 대상이 하나인 경우의 자동 선택은 유지하되, 갱신으로 기술이 바뀐 뒤에는 새 기술을 자동 선택하지 않는다. 기존 서버 저장 형식은 변경하지 않았다.
- 격리된 시험 데이터로 실제 보상·구매 명령과 409 충돌을 사용해 PP업과 기술머신 각각 선택 자리 변경·다른 자리 변경을 390px 및 1280px Chromium에서 검사했다. 새 선택, 저장 복원, 다른 저장 슬롯과 탐험 데이터 보존도 확인했다. 가능한 PP 대상 하나의 자동 선택도 확인했다. 실제 모바일 기기, 모든 보상 조합 및 운영 데이터는 검사하지 않았다.
- 기억버섯, 융합 기술머신, 보상 대상 별명 브라우저 회귀도 같은 격리 시험 환경에서 각각 두 화면 크기로 통과했다. 관련 보상 컴포넌트의 ESLint 검사는 통과했다. 전체 린트와 전체 타입 검사의 통과를 뜻하지 않는다.
- 이후 전체 TypeScript 검사를 `tsc --noEmit --incremental false`로 실행해 통과했다. 알기술 기억버섯·융합 기술머신·기억버섯 보상 관련 격리 엔진 검사 7건도 통과했다. 전체 ESLint는 실행하지 않았다.
