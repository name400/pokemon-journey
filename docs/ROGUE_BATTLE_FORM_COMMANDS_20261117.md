# 포켓로그 전투 폼 선택 기록

- 그란돈·가이오가는 각각 붉은구슬·쪽빛구슬과 메가팔찌가 있을 때 원시회귀 명령을 제공한다. 팔찌 요건은 [PokéRogue Wiki](https://wiki.pokerogue.net/gameplay:differences)의 Forms and Evolution 항목을 참고했다.
- 네크로즈마는 도감 포획·진화 기록과 해당 합체 도구를 기준으로 황혼의갈기 또는 새벽의날개 명령을 제공한다. [PokéRogue 도감](https://wiki.pokerogue.net/pokedex:800)은 상대를 과거에 포획하거나 진화시킨 기록을 요구한다. 현재 구현은 파티에 상대가 없어도 되며 파티에서 상대를 소모하지 않는다. 파티에 보유한 상대의 데이터는 폼 변경·저장·해제 후에도 보존되는 것을 대표 검사했다. 울트라버스트는 이 명령과 별개다.
- 새 도구는 획득만으로 폼을 바꾸지 않고 기술과 함께 명령을 확정할 때 바뀐다. 이는 사용자가 요청한 전투 방식이며, 위 위키가 설명하는 전투 밖 폼 전환과 다르다. 기존 활성 폼 저장은 그대로 보존한다. 같은 턴의 여러 폼 변화 제한도 현재 엔진의 근사다.
- 현재 특수 변화 메뉴는 기존 텍스트 버튼을 사용한다. 승인된 원시회귀·합체 투명 아이콘, 메가 버튼 자산과 승인 연출은 전달 및 실제 연결 전이다. 해당 시안과의 시각 일치와 모바일 실기기 확인은 미완료다. 거다이맥스가 승인된 다이맥스 영상과 일치하는지도 미검증이다.
- 2026-11-17: 승인된 두 아이콘이 들어 있는 Library 원본을 확인했지만 다운로드 단계에서 `download failed`가 발생해 실제 이미지 확인과 분리를 하지 못했다. 사용자는 이후 두 아이콘의 밝은 활성화 모습도 승인했다. 기본 이미지를 유지하는 밝기 효과 및 소리는 원본 자산을 확보한 후 실제 토글에 연결하고 검사해야 한다.
- 같은 날 별도로 전달된 `v62-icons.zip`(4,107,671바이트)도 공식 전송 단계에서 `download failed`가 발생했다. 파일의 내용과 이미지 형태를 확인하지 못했으므로 기본·활성 이미지 비교나 연결은 하지 않았다. 누락·불일치 아이템을 사용한 전투 명령은 대표 격리 API 검사에서 거절됐고 저장 바이트와 리비전이 보존됐다.
- 다이맥스 실제 전투의 폼 이벤트와 이미 거다이맥스인 개체의 등장 이벤트에 기존 다이맥스 효과를 연결했다. 등장 이벤트에서 해당 개체에만 효과가 표시되는 것을 격리 Chromium PC 1280×800 및 모바일 크기 390×844에서 확인했다. 거다이맥스는 전투 밖에서 유지되는 폼이므로 이 효과는 변신 상태 변경 없이 등장할 때 재생된다. 외부 이미지는 대체했고 승인 영상 원본 및 모바일 실기기와의 시각적 일치는 미검증이다.
- Z파워 이벤트에는 `zpower` 표식을 추가해 같은 종류의 일반 폼 변신이나 현재 폼 상태와 구분된 임시 효과를 재생한다. 실제 Z기술·테라스탈 전투 이벤트와 직렬화 복원 후 표시 대상을 대표 검사했다. 거다이맥스 폼 이벤트는 다이맥스와 같은 임시 효과 경로를 사용한다. 이는 기존 CSS 효과 연결이며 승인된 원본 영상의 재현이나 브라우저·모바일 시각 검증을 의미하지 않는다.
- 횟수 확인: 현재 포켓로그 개발본은 메가진화를 전투당 한 번 허용하며 교체·기절·재접속으로 초기화하지 않는다. 원시회귀와 네크로즈마 합체는 해당 메가진화 횟수를 공유하지 않으며, 다른 적격 개체는 다른 턴에 각각 사용할 수 있다. 세 종류를 같은 턴에 두 개 이상 선택하는 것은 더블 전투에서도 막는다. 이미 변신한 개체에는 동일 명령이 다시 제공되지 않는다. 이는 현재 구현에 대한 기록이며 원작 규칙이라고 확정하지 않는다.
- 격리 검사에서 변신한 턴의 HP·상태·PP가 이전 개체 값으로 덮이는 결함을 재현해 폼 필드만 반영하도록 수정했다. 메가진화 후 기절·강제 교체·재접속, 세 종류의 같은 턴 피해·마비·PP, 다른 턴의 횟수를 확인했다. 저장된 기존 값의 소급 복구는 하지 않았다.
- 추가 격리 검증: 메가진화·원시회귀·네크로즈마 합체 직후 상대의 강제 교체가 일어난 경우, 전투 기록의 폼 이벤트가 교체보다 먼저 나오고 폼·도구 상태와 교체 위치가 저장 인코딩 및 복원 후에도 유지됐다. 원시회귀·합체 직후 기절하는 경우에도 폼 이벤트 뒤 기절이 나오고 HP 0이 유지됐다. 이번 검증에서 해당 경로의 추가 결함은 재현되지 않았으며 운영·모바일 실기기는 검사하지 않았다.
- 탐험모험 엔진과 저장은 변경하지 않았다. 기존 진행 전투, 폼 도구 소유권 및 구형 활성 저장을 대표 API 검사로 확인했다. 전체 검사와 Sites 병합본·운영 배포는 이번 변경에 대해 검사하지 않았다.

## 2026-11-17 원시회귀·울트라 폼 재점검

현재 개발본에서 가이오가·그란돈의 원시회귀는 각 포켓몬의 쪽빛구슬·주홍구슬 소유와 메가팔찌가 필요하다. 네크로즈마 합체는 각각 네크로플러스솔·루나와 대응하는 포켓몬의 도감 획득 기록을 사용한다. 선택만으로는 변하지 않고 기술 명령 확정 시 바뀐다. 울트라네크로즈마는 이 합체 명령과 별개로, 합체 폼에서 울트라네크로Z를 사용하는 **전투 밖 폼 도구** 경로다. 전투 중 울트라버스트 토글을 제공한다고 판단하지 않는다. 이 경로와 현행 도감 조건은 구현 현황이며 새로운 원작 규칙 검증이 아니다.

원시회귀·네크로즈마 합체의 승인 기본/활성 아이콘은 현재 게임 자산과 `/workspace/scratch`에서 확인하지 못했다. 필요한 전달물은 승인된 원시회귀 및 네크로즈마 합체의 **기본 투명 이미지 두 개**와 선택 시 소리 원본이다. 기존에 안내받은 결합 이미지 Library ID는 `libfile_fde3_f-bae1f6759e348191ba86557201ca32e1_a75c51ffcb48819196b067662e6c8fbf`, 분리 패키지는 `libfile_fde3_f-59d6c87c615881919cffb6761b51e5ac_a75c51ffcb48819196b067662e6c8fbf`이나 실제 바이트는 확인하지 못했다. 별도로 승인된 밝은 상태와 직접 비교하려면 해당 원본도 필요하다. 현재는 특수 변화의 텍스트 선택이며, 앞의 오래된 메가 자산 미전달 기록과 달리 v60 메가 마크는 이미 적용되어 있다. 울트라네크로즈마 전용으로 승인된 별도 아이콘의 존재는 확인하지 못했다.

기존 `rogue-primal-ultra-boundary` 및 `rogue-classic-api` 격리 검사 104건이 통과했다. 두 구슬의 자격·전투·승리·저장 복원·해제, 양쪽 네크로즈마 합체와 울트라 폼의 직렬화·다음 전투·역순 해제, HP·PP 및 다른 저장 보존을 포함한다. 별도 Chromium 390×844의 실제 게임 함수에 연결된 격리 fixture에서 원시회귀와 솔 합체의 선택/해제 시 저장 불변, 명령 확정, 새로고침 복원을 확인했다. 이 화면 검사는 움직임 줄이기와 대체 외부 이미지를 사용했다.

현행 화면은 변신 이벤트에 일반 `primal`/`ultra` 공통 폭발 효과와 폼별 색 효과를 적용한다. 승인 아이콘 및 두 폼의 전용 승인 영상과 실제 렌더의 비교, 정상 속도 전체 연출·소리, 울트라 폼 도구 조작의 실제 브라우저, 모바일 실기기 및 운영 저장은 이번에 검증하지 않았다. 원본과 동일하다고 판단하지 않으며 새로운 폼 규칙이나 임의 아이콘은 추가하지 않았다.

## 2026-11-17 사용자 요청과 제한 재대조

사용자는 조건이 충족되면 메가 버튼 **대신 해당 원시회귀 또는 네크로즈마 합체 아이콘**을 보이고, 조건 미충족 때는 표시하지 않도록 요청했다. 현재 화면은 서버의 적격 선택지가 있을 때 메가 마크를 숨기지만, 대체 아이콘 대신 `특수 변화` 안의 텍스트 버튼을 보여 준다. 따라서 조건부 선택·기술 확정은 있으나 승인 아이콘의 위치·밝기·소리까지 포함한 버튼 요구는 미완료다. 아이콘 원본을 확보할 때까지 임의 디자인으로 대체하지 않는다.

실제 선택지는 살아 있는 현재 행동 대상, 대응하는 폼 전이와 도구, 원시회귀의 메가팔찌 또는 합체 상대의 도감 기록을 사용한다. 전투 중 테라스탈 또는 다이맥스 상태에서는 이 선택지를 제공하지 않는다. 울트라네크로즈마는 합체 자체가 아니므로 합체 아이콘 승인만으로 울트라버스트 버튼의 모양·사용 조건·횟수를 확정할 수 없다. 현재는 울트라네크로Z를 소유한 합체 폼의 전투 밖 폼 변경이며, **전투 중 조건 충족 시 울트라버스트 버튼을 제공하지 않는 차이**가 남아 있다. 사용자 의도의 적용 범위와 적절한 전투 조건을 확인하지 않은 채 새 규칙을 추가하지 않았다.

배틀별 횟수는 이전 기록과 일치한다. 메가만 배틀당 1회 기록하며, 원시회귀·합체는 그 카운터를 공유하지 않는다. 같은 턴에는 세 종류를 합쳐 하나만 선택하도록 서버와 UI가 제한한다. 이미 변한 개체는 적격 폼 전이가 더 이상 없어 같은 명령을 다시 제공하지 않는다. 이것은 현재 코드의 동작이지 사용자가 여러 번 허용했다고 승인한 규칙이나 원작과의 완전한 일치라는 뜻은 아니다. 교체 후 서로 다른 개체의 다른 턴 사용 및 재접속, 메가 사용자의 기절 후 재접속은 격리 API로 다시 통과했다. 더블 조합의 동일 턴 제한은 UI 명령 생성 검사와 서버 분기 코드로 확인했으며, 이번에는 더블 실제 API 전송을 별도로 재현하지 않았다.

검증: `rogue-classic-api`의 대상 명령·저장 보호·횟수 테스트와 `rogue-primal-ultra-boundary`를 대상으로 실행했고, 별도로 `rogue-dynamax-ui-logic`과 양쪽 원시회귀·울트라 폼 복원 경계 검사를 통과했다. 운영 데이터·실기기·Sites 배포는 건드리지 않았다.

## 승인 v61 아이콘 적용 및 더블 기믹 검사

전달된 비공개 Drive 명세의 여섯 조각을 실제로 받아 각각 바이트 수·SHA-256을 확인했고, 합본 PNG 1,068,964바이트의 SHA-256 `2103eb8bfcd00a406ef4a0bbad0a06a2ea635276bfac8bbf7e1888d5f8133068`이 일치했다. 합본의 좌우 빈 투명 영역을 경계로 각 아이콘의 알파 경계만 잘라 `public/game/v61/primal.png`, `necrozma.png`에 저장했다. 잘라낸 이미지와 원본 해당 영역의 RGBA 픽셀 일치를 확인했다. 재생성된 v62 이미지는 쓰지 않았다.

기존 서버가 제공하는 원시회귀·합체 적격 선택지가 있을 때 단일·다중 전투의 메가 버튼 위치에 해당 아이콘을 보여 준다. 토글은 기술 확정 전의 선택만 변경하며, 선택 중에는 기본 이미지에 밝기와 글로우를 적용한다. 둘 이상의 선택지가 있으면 기존 상세 메뉴에서 선택한다. 승인된 활성화 이미지 원본과 밝기의 직접 비교는 아직 못 했다. 함께 전달된 WAV는 메가 전용이므로 원시회귀·합체에 사용하지 않았으며, 이 두 버튼의 승인 전용 소리는 확인되지 않았다. 배틀 횟수·기존 폼 규칙과 저장 형식은 변경하지 않았다.

격리 Chromium의 390×844, 844×390, 1280×800에서 두 아이콘 각각 단일·더블 화면의 버튼 경계, 44px 터치 영역, 기술 버튼·정보 버튼·특수 메뉴와의 충돌, 토글을 검사했다. 각각의 단일·더블에서 실제 게임 함수에 연결된 모의 API로 예약 시 저장 불변, 명령 확정, 선택 개체의 폼 및 새로고침을 확인했으며 해당 도구가 없으면 아이콘이 없는 것도 확인했다. 외부 포켓몬 이미지는 대체했고 실제 모바일 기기는 미검증이다. 순차 실행 시 이 검사는 통과했으며 공유 fixture 서버에서 두 검사 동시 실행 시 한 차례 실패해 순차 재실행했다.
