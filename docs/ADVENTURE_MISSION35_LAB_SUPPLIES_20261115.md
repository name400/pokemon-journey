# 미션 35 연구소의 추가 도구

[연구소 물품 목록](https://www.serebii.net/pokearth/lumiosecity/lysandrelabs.shtml)은 녹색 구역 리보플라빈과 보라색 구역의 천둥의돌·금구슬·키토산을 기록한다. 이미 구현된 연구소의 해당 구역에 수집 지점을 추가했다. 개별 방의 평면과 정확한 좌표는 확인되지 않은 2D 추정이다.

기존 도구 기록을 그대로 사용해 한 번만 획득하며, 가방에 공간이 없거나 알 수 없는 기록 형식이면 소모하지 않는다. 기존 저장의 미확인 기록과 소지품도 유지한다. 원작 실기와 운영 환경은 검증하지 않았다.

## 입구·녹색 구역과 보라색 서버실

[연구소 물품표](https://www.serebii.net/pokearth/lumiosecity/lysandrelabs.shtml)는 입구와 녹색 구역에 하이퍼볼 한 개씩, 보라색 서버실에 불꽃의돌과 회복약을 기록한다. 해당 구역에 네 수집 지점을 연결했다. 원작 방 구조와 정확한 위치를 확인하지 못했으므로 현재 2D 타일 좌표와 구역 대응은 근사다. 자료는 2차 출처이며 실기 대조는 하지 않았다.

볼·도구·회복약은 기존 각 저장소와 상한을 따르며, 자리가 없거나 알 수 없는 볼·수령 기록 형식에서는 수령하지 않는다. 기존 수령 내역과 다른 볼, 파티는 보존한다. 지도 통행과 격리 API 수령·재접속·상한·중복 요청을 대표 검사했다. 운영 D1·Sites 병합본은 확인하지 않았다.
