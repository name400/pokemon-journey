# 미션 35 연구소의 추가 도구

[연구소 물품 목록](https://www.serebii.net/pokearth/lumiosecity/lysandrelabs.shtml)은 녹색 구역 리보플라빈과 보라색 구역의 천둥의돌·금구슬·키토산을 기록한다. 이미 구현된 연구소의 해당 구역에 수집 지점을 추가했다. 개별 방의 평면과 정확한 좌표는 확인되지 않은 2D 추정이다.

기존 도구 기록을 그대로 사용해 한 번만 획득하며, 가방에 공간이 없거나 알 수 없는 기록 형식이면 소모하지 않는다. 기존 저장의 미확인 기록과 소지품도 유지한다. 원작 실기와 운영 환경은 검증하지 않았다.
