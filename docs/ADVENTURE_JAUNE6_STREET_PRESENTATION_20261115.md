# 존느 6번지 거리와 홀로베이터 표현

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-6.html)는 존느 6번지의 건물 사이 거리, 남동쪽 트리미앙 미용실과 홀로베이터 의뢰를 설명한다. 기존 건물 외곽과 도로를 구분하고 기존 진행 조건으로 나타나는 홀로베이터에 표식을 표시했다.

건물 형태·거리 선형·미용실과 홀로베이터의 격자 좌표는 측량하지 않은 기존 2D 추정이다. 원작의 옥상 높이·정확한 비계 경로는 이번 작업에서 추가하지 않았다. 타일·충돌·등장 조건·상호작용·진행 및 저장은 변경하지 않았다.

미용실 의뢰와 홀로베이터의 기존 경로·조건 검사 3건과 타입 검사가 통과했다. 모의 API를 사용한 PC·모바일 Chromium 화면과 홀로베이터 대화를 확인했다. 원작 기기와 실제 Sites 병합본은 확인하지 않았다.
