# 포켓로그 더블 기술 격자의 비활성 항목 — 2026-11-18

더블 전투에서 두 번째 기술의 PP를 0으로 만든 격리 전투를 사용했다. 기술은 화면에 2×2로 남아 있었으나 방향키가 비활성 버튼을 제거한 목록에서 두 칸을 이동해, 첫 기술에서 아래를 누르면 같은 열의 셋째가 아닌 넷째 기술로 이동했다. 실제 Chromium 390×844에서 재현했다.

포켓로그 더블 기술의 위·아래 이동은 비활성 슬롯도 포함한 2열 위치를 기준으로 한다. 같은 열의 목적지가 비활성이거나 없는 경우 초점을 그대로 둔다. 다른 화면과 좌우 이동은 기존 동작을 유지한다. 기술을 실행하거나 PP를 변경하는 코드는 바꾸지 않았다.

전용 포트와 소유 토큰을 확인한 격리 fixture의 실제 PP 0 더블 전투에서 280×568·390×844·1280×800의 초점·비활성 목적지, 방향키만 누를 때 저장 불변, 파도타기 명령 및 PP 차감, PP 0 유지, 새로고침과 다른 슬롯/탐험 보존을 확인했다. 기존 싱글·더블 기술 방향키 브라우저 검사 여섯 경로도 재실행했다. 실제 기기·스크린리더, 기술 수가 다른 모든 조합, 탐험 모드는 미검증이다.
