# 누보 카페 본점과 호텔 분리

[원작 카페 설명](https://bulbapedia.bulbagarden.net/wiki/Nouveau_Caf%C3%A9)은 누보 카페가 센트리코 광장에 인접한 베르 거리에 있으며 음료를 주문하면 파티를 회복하고 선두의 친밀도를 올린다고 설명한다. 기존에는 여러 메인 미션에서 찾는 누보 카페와 호텔 리시심이 같은 표식에 겹쳐 있고 본점 음료·지도 이동이 없었다. 기존 광장 접근 화면에 별도의 카페 트럭을 추가하고 미션 5·10·19·35·41의 기존 카페 상호작용을 연결했다. 위치는 2D 초안이다. 호텔 표식의 기존 미션 상호작용도 구형 저장 호환을 위해 그대로 남기며, 새 카페에서는 호텔로 들어갈 수 없다. 이전 통행 가능한 칸을 계속 통행 가능하게 유지한다.

미션 5에서 카페를 만난 뒤 본점의 커피 네 가지와 차 세 가지를 원작 목록의 250·300·350원 가격으로 주문할 수 있다. 각 주문은 기존 카페와 같은 파티 전체 HP·상태·PP 회복, 선두 친밀도 1 증가와 연구 활동을 사용한다. 친밀도 증가량은 프로젝트의 근사치이며 음료 한국어 이름은 임시 번역이다. 구형 저장은 미션 5 이후 단계·랭크에서도 기능이 열린다. 기존 보유 재화·개체는 이행하지 않는다.

카페 방문 후 지도 이동 지점에 등록하고 같은 해금 조건에서 710원 택시 목적지로 제공한다. 원작 자료는 해금 후 빠른 이동을 설명하지만, 이 프로젝트의 방문 판정과 도착 좌표는 2D 근사다. 격리 API에서 신규·구형 미션 위치, 해금·잔액·중복 요청, 기절·상태이상 파티 회복과 보관함 보존, 지도·택시와 호텔 입장을 확인했다. PC·모바일 Chromium 모의 API 화면에서 7개 메뉴와 첫·마지막 주문 버튼을 확인했다. 원작 실기와 운영 데이터는 검증하지 않았다.
