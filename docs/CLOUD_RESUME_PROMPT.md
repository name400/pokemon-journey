## DNA 스플라이서 내부 미리보기 (진행 중)

`lib/rogue-dna-fusion.mjs`는 기본 폼 두 마리의 종족값 평균, 타입, 두 번째 특성, 상태 및 분리 계산을 격리된 미리보기로만 제공한다. 미리보기는 입력을 변경하지 않고 두 번째 개체의 복사본과 기술 목록을 보존한다. 전투 엔진은 미리보기 데이터의 능력치와 타입을 적용할 수 있으며 직렬화·복원 테스트가 있다. 일반 보상, API, 파티 화면에서는 사용할 수 없다. 아직 임의 파티원 융합 완성이 아니다.

고정 원본의 `PlayerPokemon.fuse`는 두 번째 파티원을 실제로 제거하고 도구 이전을 시도한 뒤 기술 습득 단계를 대기열에 넣으며, `unfuse`는 두 번째 포켓몬을 복원하지 않는다. 따라서 실제 공개 전에 기술 습득 선택과 저장 중단·복구, 도구별 이전 한도와 형상 도구, 중복 보상, 챌린지 판정, 진화·특수 폼, 소멸에 대한 사용자 확인을 원본 및 기존 저장 구조와 대조해 원자적으로 구현해야 한다. 미리보기의 HP는 새 최대 HP로 안전하게 제한하므로 원본 구현의 이전 최대 HP 제한과 차이가 있다. 특수 폼 및 기존 융합은 현재 명시적으로 거부한다. 실기기 플레이와 운영 배포는 진행하지 않았다.

검증: 전체 `npm test` 484개 통과, 타입 검사 통과, 관련 집중 검사 10개 통과. 전체 린트는 저장소의 기존 672개 오류와 127개 경고로 실패했으며 이번 수정 파일에는 린트 항목이 없다. 브라우저 실플레이는 검증하지 않았다.
