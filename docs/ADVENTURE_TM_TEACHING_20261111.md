# 탐험모험 기술머신 학습

[원작 기술머신 목록](https://www.serebii.net/legendsz-a/tm.shtml)은 기술머신을 반복 사용할 수 있다고 설명한다. 기존 기술 관리 화면과 서버의 학습·슬롯 교체 기능에 루주 6번지에서 얻는 089번 독압정을 추가했다. [Z-A 전용 학습 목록](https://www.serebii.net/attackdex-sv/toxicspikes.shtml)을 기준으로 확인된 기본 폼을 허용하며 지역 폼과 형태가 불명확한 항목은 제외한다. 포켓몬마다 보유 기술과 나머지 PP를 보존하고 기술머신은 소모하지 않는다.

기존 필드·스토리에서 지급하는 16종은 해당 학습 기능에 등록돼 있다. 연구 보상 기술머신은 기존의 별도 수령 플래그와 일부 확인된 기본 폼 목록을 사용한다. 미확인 종·지역 폼·그 밖의 기술머신은 임의로 학습할 수 없으며, 학습 가능하지만 아직 확인되지 않은 폼의 추가 대조가 남아 있다. 연구 보상도 파티 안의 대상만 학습할 수 있다.

후속 구현: 필드·스토리 기술머신 19종의 기본 폼 호환성을 [Z-A 2.0 학습 데이터](https://github.com/Fortelle/pokemon-learnsets/tree/79351bcf414276f82efda89c474f9de6e837af06/raw/legendsza%402.0.0)와 대조하고, 알로라 라이츄·페르시온, 가라르 야돈·야도란·야도킹, 히스이 침바루·미끄네일·미끄래곤·크레베이스에는 해당 폼의 학습표를 적용한다. 기존 표에서 지역 폼 정보가 섞인 기본 폼의 일부 허용도 정정했다. 이 자료는 제3자 자료이고, 원본 저장소에 라이선스가 명시되지 않아 원본 소스나 파일이 아닌 종·기술머신 번호 관계만 생성했다. 다른 폼과 Z-A 2.0 등장 목록 밖의 종은 계속 제한한다. 이미 배운 기술과 기술머신, 저장된 파티는 유지한다. 격리 서버에서 가라르 야돈의 보유·학습·재사용·복원과 기존 독압정 경로를 확인했으며 실제 운영 기기는 미검증이다.
