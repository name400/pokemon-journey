# 구역 16 높은 정원

[구역 안내](https://allthings.how/every-pokemon-in-wild-zone-16-in-pokemon-legends-z-a-and-how-to-catch-them/)는 블루 광장과 사무소가 가까우며 전룡과 보송송이 있는 높은 정원을 설명한다. 기존 지상↔정원 계단과 공유 조우를 유지하고, 정원 층의 계단 접근로·정원 바닥·경계가 서로 구분되도록 표현했다. 길은 기존 이동 가능한 칸을 포장한 것으로 충돌이나 저장 좌표를 막지 않는다.

정원 위치 관계와 높은 층이라는 점을 제외한 정원 윤곽, 화단, 보도 및 축척은 압축된 2D 초안이다. 원작 정밀 지형과 실제 기기 화면은 확인하지 않았다. 기술머신 076은 높은 정원의 추정 좌표에서 한 번 획득하며 기존 기술머신 학습 기능으로 반복 사용한다. [Serebii 기술 자료](https://www.serebii.net/attackdex-sv/liquidation.shtml)의 Z-A 학습 목록을 적용했다. 기본 폼 및 확인된 가라르 야돈·야도란·야도킹과 히스이 침바루 외의 별도 폼은 확인 전 제한한다. 기존에 배운 기술은 변경하지 않는다. 가방 한도, 재접속, 중복 수령 및 기술 교체는 격리 검사했다.
