# 구역 16 높은 정원

[구역 안내](https://allthings.how/every-pokemon-in-wild-zone-16-in-pokemon-legends-z-a-and-how-to-catch-them/)는 블루 광장과 사무소가 가까우며 전룡과 보송송이 있는 높은 정원을 설명한다. 기존 지상↔정원 계단과 공유 조우를 유지하고, 정원 층의 계단 접근로·정원 바닥·경계가 서로 구분되도록 표현했다. 길은 기존 이동 가능한 칸을 포장한 것으로 충돌이나 저장 좌표를 막지 않는다.

정원 위치 관계와 높은 층이라는 점을 제외한 정원 윤곽, 화단, 보도 및 축척은 압축된 2D 초안이다. 원작 정밀 지형과 실제 기기 화면은 확인하지 않았다. 기술머신 076의 원작 위치는 확인되지만 이 변경에 획득이나 학습 기능을 추가하지 않았다.
