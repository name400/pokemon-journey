# 미션 34 옥상과 융합 도구 조사

## 미션 34 옥상

[PokeQuery의 미션 34 공략](https://pokequery.com/games/legends-za/walkthrough)은 야생 구역 10에서 블루 6·8번지 쪽 옥상을 거쳐 Philippe와의 배틀 후 아쿠스타의 위치로 내려가는 경로를 설명한다. 이는 2차 자료이며 타일 좌표나 건물의 정확한 윤곽을 제공하지 않는다. [GameWith의 장면 자료](https://gamewith.jp/pokemon-za/524375)에서 비계·옥상 후보 이미지를 찾았지만, 이미지 파일을 이 환경에서 직접 요청했을 때 HTTP 403으로 차단되어 시각적 대응을 확인하지 못했다. 검색 이미지의 자동 설명은 제목을 다른 게임으로 잘못 표시하므로 좌표 근거로 사용하지 않았다.

현재 게임은 `lumiose-bleu6-approach`의 사다리에서 `lumiose-mission34-roof`로 진입해 Philippe 승리 뒤 아쿠스타 지점에 접근하고, 별도의 남쪽 큰길 홀로베이터는 사이드 92 승리 뒤 열린다. 현재 2D 타일·연결이 원작의 실제 위치와 일치하는지는 미확정이며, 원작에 있는 미끄러져 내려가는 동선도 현재 검사만으로 확인되지 않는다. 대표 지도 검사 2건은 현재 게임의 진입·해금·기존 저장 복원을 확인하지만 원작 배치의 증거는 아니다. 대응할 수 있는 지형 근거가 부족해 지도와 저장 좌표를 변경하지 않았다.

## 융합 도구

현재 `stageClassicDnaFusion`은 원본 저장의 복사본에 도구 이전을 시도한다. 검토된 회복·타입·일부 전투 도구는 modifier로 보존하지만, 그 외 두 native 도구는 포켓몬당 `item` 한 슬롯만 있어 충돌한다. 주체의 광각렌즈와 기증자의 선제공격손톱을 넣은 격리 재현에서 융합은 빈 슬롯 필요 오류로 거절됐고 원래 파티와 두 도구는 변하지 않았다. 이는 **지원되지 않는 조합**의 재현이며, 현재 이 경로에서 데이터 손실이 발생했다는 뜻은 아니다. 도구 관련 기존 대표 검사 20건이 통과했다.

기증자 원본 스냅샷은 융합 정보에 보관되지만 분리 경로는 주체만 남기고 기증자를 복원하지 않으므로, 스냅샷을 독립 소지품으로 간주해 재생성하면 중복·소모 복구 위험이 있다. 두 효과를 실제로 허용하려면 별도 도구 표현과 전투 이벤트·소모·빼앗기·이동·분리·저장 복구의 일관된 소유권 및 기존 불명 저장 보존이 필요하다. 광각렌즈와 선제공격손톱을 임의로 modifier로 변환하거나 기존 저장을 소급하지 않았다. 실제 운영 저장과 모든 도구 조합은 확인하지 않았다.
