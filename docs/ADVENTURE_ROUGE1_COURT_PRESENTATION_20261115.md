# 루주 1번지 전투장 표현

- 참고: [Lumiose Locations – Rouge Sector 1](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/rouge-sector-1.html)은 전투장, 북쪽 건물 안뜰의 노점과 사이드 미션 004 이후 홀로베이터를 통한 옥상 접근을 설명한다.
- 기존 2D 맵의 건물 타일 윤곽과 전투장 경계·중앙선, 보행로 가장자리를 시각적으로 구분한다. 위치와 치수, 선의 모양은 기존 타일에 맞춘 추정이며 원작의 정확한 배치나 충돌 판정을 뜻하지 않는다. 북쪽 안뜰 전체와 정확한 고도는 이번에 새로 구현하지 않았다.
- 타일, 출입, 상점, 의뢰, 홀로베이터와 저장 형식은 변경하지 않았다.
- 검증: 루주 1번지 기존 Node 테스트 6건, 타입 검사, 모의 API를 이용한 모바일·PC 화면과 홀로베이터 대화 검사. 실제 운영 데이터나 Sites 병합본은 확인하지 않았다.
- 모바일 이동의 D1 오류는 운영 재검증 전이므로 `testfailed.md` 기록을 유지한다.
