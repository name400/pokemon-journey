# 찌릿찌릿액셀 원본 전투 효과

고정 원본 `7c0881255af5cd51992e513ff93c2f71adbe40e0`의 `ZIPPY_ZAP`은 위력 50, 우선도 +2, 확정 급소이며 회피율을 올리지 않는다. 기존 simulator 데이터는 위력 80에 회피율 +1 효과를 가졌다.
