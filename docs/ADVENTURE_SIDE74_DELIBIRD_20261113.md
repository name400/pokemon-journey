# 사이드 미션 74: 딜리버드 구출

[Serebii](https://www.serebii.net/legendsz-a/sidemissions/delibirdgetsinaflap.shtml)는 미션 26 시작 후 베르 9번지의 딜리버드를 쫓는 더스트나를 물리치는 의뢰를 설명한다. [공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_61-80)은 더스트나 레벨 50과 배리열매 1개·500원·숙달의씨 5개 보상을 기록한다. 기존 베르 9번지의 통행 가능한 칸에 딜리버드와 대화·전투·보상 흐름을 추가해 기술플러스 숙달 재료의 정상 획득 경로를 제공한다.

더스트나는 기존 턴제 야생 전투에서 승리하거나 포획할 수 있다. 도망·패배 후 재도전하며 승리·포획과 보상 대기 단계는 저장된다. 가방 공간과 재화 범위를 확인한 뒤 보상을 한 번 지급하고 리비전으로 중복 요청을 막는다. 기존 이동 충돌·파티 및 진행은 바꾸지 않는다. 오래된 저장은 미션 26 이후의 확인 가능한 진행 플래그도 사용한다.

딜리버드의 정확한 타일과 추격 방향은 확인하지 못해 위치와 정지 상호작용으로 근사했다. 포켓몬이 실시간으로 추격하는 연출은 미구현이다. 격리 SQLite API에서 접근 제한·승리·포획·도망 후 재도전·재접속·가방과 재화 한도·중복 보상을 확인했고, PC·모바일 Chromium에서 모의 API와 대체 이미지로 상호작용을 확인했다. 실제 원작 기기·운영 데이터 및 전체 자연 진행은 검증하지 않았다.
