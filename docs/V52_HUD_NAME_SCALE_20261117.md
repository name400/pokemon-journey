# v52 이름과 HP 위치 대조

승인 원본은 폭 360 논리 좌표에서 포켓몬 이름 10px, 이름행 뒤 HP 위치 y27(상대), y184(아군)이다. 포켓로그 960×540에서는 이름이 실제 18px로 제한되어 정규화 약 6.85px, 상대 HP는 y22.76이었다. 이름 글꼴과 HP 간격을 장면 폭 비율로 바꿔 이름 10px, 상대 HP y26.99로 맞췄다. 280px에서는 HP 최소 높이가 원본보다 컸으므로 비율을 따르도록 했다. 같은 스타일은 탐험 단일에도 적용된다.

포켓로그 격리 Chromium 280×568, 390×844, 844×390, 960×540에서 원본 HTML과 동일한 리자몽·이상해꽃 이름, 두 HP 막대의 좌표·크기 및 이름 글꼴 크기를 장면 기준 허용 오차 0.2 논리 픽셀로 비교했다. 포켓몬 이미지는 대체 파일이며 해당 비교 대상이 아니다. 긴 HP 수치·명령, 실제 기술·PP·상성의 단일·더블 회귀도 통과했다. 탐험 브라우저, 실제 기기 및 원본 PNG를 포함한 화면 전체 일치는 미검증이다. 사용자 데이터와 Sites는 변경하지 않았다.
