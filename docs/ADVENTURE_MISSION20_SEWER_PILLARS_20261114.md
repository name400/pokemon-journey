# 미션 20 결정 하수도의 기둥

[원작 미션 안내](https://www.thonky.com/pokemon-legends-z-a/main-mission-20-a-request-from-the-rust-syndicate)는 기둥과 벽 주변의 결정 27개를 찾아 정리한다고 설명한다. 새로 정리를 시작하는 진행에서는 기존 2D 하수도의 여덟 기둥 위치를 실제로 통행할 수 없는 석조 기둥으로 표현한다. 기존 결정의 ID·위치·보상은 바꾸지 않으며 기둥 사이를 돌아 모든 결정에 접근할 수 있다. 기둥의 개수와 정확한 2D 좌표·방의 형태는 원작에서 확인되지 않은 초안이다.

기둥은 외부에서 새 정리 의뢰를 시작할 때만 켜진다. 이미 정리 중이거나 하수도에 저장된 기존 진행은 이전 통행 구조를 유지한다. 동작 중 새 DB 조회는 없고 야생 이동은 기존 충돌 판정을 사용한다. 시작·재진입은 공유 보유함을 쓰지 않으며 결정·파티·재화 기록을 유지한다.

지도 검사에서 새 통행 경계, 27개 결정의 접근, 기존 기둥 위치의 구형 저장 복원과 기존 야생 개체 이동을 확인했다. 격리 API에서 실제 시작·기둥 차단·재접속·귀환, 공유 구형 개체 보존 및 결정·조각 처리를 대표 검사했다. 원작 실기와 운영 저장, 실제 PC·모바일 게임 화면은 검사하지 않았다.
