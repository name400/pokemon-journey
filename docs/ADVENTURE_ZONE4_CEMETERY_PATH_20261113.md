# 야생 구역 4 묘지 동선

[구역 안내](https://www.pokemon-france.com/en/guides/pokemon-legends-z-a/wild-zones/)에는 묘비 사이 좌우 길과 원형 구역, 건물 뒤 가시덤불 속 TM072가 나온다. 기존 묘지 건물과 출입구를 유지하면서 묘비 사이 접근로와 원형 지점, 건물 뒤 덤불 및 회오리불꽃 기술머신을 연결했다. [기술머신 목록](https://www.serebii.net/legendsz-a/tm.shtml)과 [학습 목록](https://www.serebii.net/attackdex-sv/firespin.shtml)을 대조했다. 일반 텅구리는 학습 대상이 아니며, 알로라 텅구리는 별도 폼으로 처리한다.

건물·묘비의 정확한 위치와 원형 지점의 크기, 보상 타일은 기존 축약 지도에 맞춘 추정이다. 원작의 높낮이는 확인하지 못해 추가하지 않았다. 새로운 덤불 칸에 있던 구형 저장은 같은 리비전일 때만 통행 가능한 인접 칸으로 복원한다. 기술머신 특수 폼 중 확인되지 않은 항목은 학습시키지 않는다.
