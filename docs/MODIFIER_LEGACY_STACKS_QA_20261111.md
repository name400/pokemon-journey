# 구형 저장의 도구 중첩 한도

기존 지급 함수는 저장된 도구의 `typeBoost`가 없는 경우 명시적인 null과 다른 기록으로 취급했다. 그래서 이미 소지한 도구를 같은 행에 쌓지 못했다. 서로 나뉜 행도 한 행만 한도에 포함해 최대 중첩을 넘어 지급할 수 있었다.

지급 시 생략된 소유자·타입을 null과 동일하게 판정하고 같은 소유자·타입의 모든 행을 합산해 한도를 검증한다. native 소지 도구도 기존 규칙대로 합산하며, 다른 소유자·타입은 분리한다. 새 수량은 첫 일치 행에 더하며 구형 행을 병합·삭제하거나 한도 초과 기록을 임의 교정하지 않는다. 손상된 수량은 수정 전에 거부한다. 교정깁스의 계산 기록은 합산한 수량으로 유지한다.

검증: 생략 필드·복수 행·한도 거부 시 저장 불변, 소유자·타입 구분, native 소지 도구 합산 및 저장 직렬화 대표 사례. 일반 경로 23개, Worker 경로 14개, 딜리버드·폼 도구·배틀 도구 경로 10개와 타입 검사 통과. 전체 테스트나 운영 계정·실기기 검증은 아니다.
