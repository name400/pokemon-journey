# 동료 단독 전투 이어가기

플레이어 파티 전멸 후 동료가 싸우는 구간에서 128회 한도에 도달하면 이전 코드는 오류로 해당 요청 전체를 버렸다. 엔진이 받는 비공격 기술을 조합한 격리 팀으로 재현했으며, 해당 종이 원작에서 그 기술을 모두 배울 수 있다는 의미는 아니다.

한도에서 실행을 마치지 못한 경우 시뮬레이터·포켓몬·노력치·전투 로그를 원자적으로 저장한다. 화면의 `동료 배틀 이어가기`로 다음 구간을 실행한다. 플레이어가 조작 가능한 전투나 체크포인트가 없는 저장에 이어가기 명령을 허용하지 않고, 기존 리비전 검사를 통해 중복 요청이 같은 구간을 다시 적용하지 않는다. 새로고침 후에도 버튼이 남으며 플레이어의 이전 기술을 다시 사용하지 않는다. 실제로 처리할 수 없는 다른 대기 상태는 기존처럼 오류로 남긴다.

격리 엔진에서 원래의 128회 오류 구성으로 저장·JSON 복원·완료를 검사했다. 로컬 SQLite를 D1 인터페이스에 연결한 실제 API 검사에서 체크포인트 저장, 재접속, 오래된 리비전의 재요청 거절, 결과·파티·보상 보존을 확인했다. 모바일 크기 Chromium과 모의 API에서는 새로고침 후 이어가기 버튼과 한 번의 이어가기 요청을 확인했다. 운영 D1·실제 계정과 실기기는 검사하지 않았다.
