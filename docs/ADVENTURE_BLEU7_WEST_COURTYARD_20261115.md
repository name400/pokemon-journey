# 블루 7번지 서쪽 안뜰

[블루 7번지 지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-7.html)는 서쪽 안뜰과 그 안의 계단·높은 공간을 언급하고, 의뢰 28의 상대가 안뜰에 있다고 설명한다. 2차 자료이며 의뢰 상대가 어느 안뜰에 있는지와 안뜰의 정확한 윤곽은 여기서 확인되지 않는다.

기존 의뢰 지점에 인접한 서쪽 건물 블록에 지상 안뜰을 열었다. 위치·입구·크기는 2D 압축 지도의 잠정 배치이며 계단과 높이 차는 구현하지 않았다. 기존 센터·벤치·의뢰·옥상과 저장 필드는 유지한다. 원작 아이템은 이번에 추가하지 않았다.

모바일 이동 오류와 Sites 병합본 실패 기록은 운영 재검증 전이므로 유지한다.
