# AI의 같은 점수 대상 추첨

고정 원본 `7c0881255af5cd51992e513ff93c2f71adbe40e0`의 `EnemyPokemon.getNextTargets`는 대상별 이점 점수를 정렬·보정하고 가중 추첨한다. 같은 이점의 두 대상은 같은 가중치를 받는다. 기존 구현은 선택된 기술의 같은 점수 대상 중 첫 대상을 고정했다.

새 도전의 `enemyAiTargetRule: source-tie-v1`은 선택된 기술에서 같은 진영·동일 로컬 점수·동일 KO 판정인 복수 대상만 균등 추첨한다. 단일 대상이나 다른 점수·기술·진영은 추첨에 섞지 않는다. 전투 스냅샷에 규칙을 보존하고 이전 도전은 기존 선택을 유지한다.

동일한 두 포켓몬을 둔 실제 더블 전투에서 여러 시드로 양쪽이 선택되는 것, 저장된 동일 전투에서 같은 결과와 PRNG 상태가 재현되는 것, 단일 후보에서 불필요한 추첨이 없는 것을 검사했다. 현재 이점 점수는 로컬 휴리스틱이며 원본의 전체 대상 점수·가중치·후보별 추첨 순서와 원본 난수 스트림은 **미구현**이다. 이 변경은 원본 대상 선택의 전체 동등성을 의미하지 않는다.

관련 트레이너·AI·챌린지·융합 회귀는 일반 환경과 Worker 각각 250/250 통과했다. 타입 검사와 프로덕션 빌드도 통과했다. 전체 테스트와 실계정 플레이는 실행하지 않았다.
