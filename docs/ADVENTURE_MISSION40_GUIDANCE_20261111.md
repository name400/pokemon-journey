# 미션 40 조사 안내

[원작 미션 안내](https://www.serebii.net/legendsz-a/mainmissions/theonethatgives.shtml)와 [현장 공략](https://www.nintendolife.com/guides/pokemon-legends-z-a-how-to-catch-xerneas-and-yveltal)은 구역 3·5·9의 세 우두머리를 조사한 뒤 연구소에 보고하고 구역 11의 제르네아스를 찾는 흐름을 설명한다. 이미 구현된 각 조사 기록을 일지에 표시하고 미조사 구역, 연구소 보고, 제르네아스 포획을 실제 저장 상태에 따라 현재 목표로 안내한다. 동시 진행 중인 미션 41의 Vinnie·시뮬레이터·이벨타르 안내는 유지한다.

조사 여부는 기존 플래그만 읽으며 저장이나 진행 규칙을 변경하지 않는다. 구역 9 옥상의 정확한 좌표와 도시 지형은 기존 초안이다.
