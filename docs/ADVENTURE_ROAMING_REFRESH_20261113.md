# 구역 2·3 이동 야생 개체의 재출현

[낮밤 자료](https://www.serebii.net/legendsz-a/daynightcycle.shtml)는 시간대가 바뀌면 야생 포켓몬이 갱신된다고 설명한다. 이 게임에서는 기존 게임 시계의 시간 구간을 기준으로 구역 2·3에서 사라진 이동 개체가 다시 나타나게 했다. 꼬몽울과 딱충이도 구역 2에서 다시 나타날 수 있다.

기존 저장의 첫 조회는 기준 시각만 기록한다. 이후 시간 구간이 바뀌면 사라진 개체만 초기 위치에서 다시 만든다. 살아 있는 개체의 위치와 이로치 상태, 이미 얻은 포켓몬과 도구, 스토리 우두머리와 진행은 유지한다. 전투·포획 중이거나 출현 위치가 플레이어 또는 다른 개체와 겹칠 경우 갱신을 미룬다. 구역 3 스토리로 야생 개체가 감춰진 경우에도 미룬다.

살아 있는 개체를 그대로 유지하는 방식, 초기 위치와 정확한 갱신 시각은 안전한 게임 내 근사이며 원작의 세부 재출현 규칙을 확인한 것은 아니다. 현재 게임의 낮밤 경계는 원작과 다르며 변경하지 않았다. 운영 환경과 원작 기기 검증은 하지 않았다.
