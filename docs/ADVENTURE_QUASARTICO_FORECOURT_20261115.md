# 콰자르티코 건물과 앞마당

[시설 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/quasartico-inc.html)는 콰자르티코 본관 앞의 데덴네 전투, 건물과 주변 배틀 코트를 설명한다. 기존 2D 본관 타일을 유리 외벽처럼 구분하고, 이미 통행 가능한 앞마당을 포장된 배틀 공간으로 표시했다. 데덴네·Vinnie 및 사무실 진입은 기존 단계와 상호작용을 그대로 사용한다.

건물 윤곽·높이·재질과 앞마당 크기·격자 좌표는 원작에서 추출하지 않은 2D 초안이다. 지도 타일·충돌·주변 출입구·진행 및 저장 위치는 바꾸지 않았다.

미션 10 동료 전투 단위 검사 24건, 콰자르티코·마젠타 4번지 연결과 저장 복원 등을 포함한 단위 검사 5건 및 타입 검사가 통과했다. PC·모바일 Chromium에서는 모의 API로 전투 전·사무실 진입 단계의 화면과 대화를 확인했다. 원작 기기·운영 D1·Sites 병합본은 확인하지 않았다.
