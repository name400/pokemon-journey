# 야생 이로치 생성 진행

풀숲 조우와 구역 5·6·8~20 및 연구소의 개별 야생 조우에 색 추첨을 연결했다. 기본 확률은 1/4096이며 부적 수령 기록이 있을 때는 네 번 추첨하는 것과 같은 확률이다. 근거: https://rotomlabs.net/legends-z-a/shiny-rates

구역별 고정 슬롯은 처음 대면할 때 결과를 월드에 저장한다. 도주·재접속 시 결과를 유지하고, 포획하거나 승리해 해당 슬롯을 소진하면 기록을 지운다. 풀숲에서는 전투 개체 생성 시 정하고 전투·포획 저장에 보존한다. 현재 필드에 나타나는 순간이 아니라 처음 대면할 때 추첨하므로 원작의 이로치 선표시와 최대 열 개의 유지 동작은 미구현이다.

구역 2·3 및 하수도의 접촉·직접 볼 투척 경로와 일부 별도 우두머리에도 추첨을 연결했다. 포획이나 배틀로 넘겨진 개체의 색을 유지한다. 그 외 특수 조우 경로는 계속 검토해야 한다. 고정 이벤트, 선물, 기존 저장의 개체 및 화석 복원 규칙은 바꾸지 않았다. 모든 경로와 레벨 50 도달을 검증하기 전에는 부적 보상 지급을 열지 않는다.
