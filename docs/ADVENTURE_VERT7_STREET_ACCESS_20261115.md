# 베르 7번지와 베르 스트리트 연결

[베르 7번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-7.html)는 서쪽 베르 스트리트 접근을, [베르 스트리트 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-street.html)는 동쪽 베르 7번지 접근을 설명한다. 기존 2D 지도에 두 구역 사이 왕복 지상 출입을 추가했다. 출입 타일과 도로 배치는 잠정이며 정확한 원작 좌표와 높이는 확인하지 못했다.

기존 출입구와 저장 형식을 유지하며 미션 3의 도로 우회 조건을 양방향에 적용한다. 원작 실기와 실제 Sites 병합본은 검증하지 않았다. 모바일 이동 오류의 운영 재검증 전 실패 기록은 유지한다.
