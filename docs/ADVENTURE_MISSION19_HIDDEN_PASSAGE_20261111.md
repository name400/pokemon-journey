# 미션 19 하수도 환상의 벽

[미션 공략](https://www.neoseeker.com/pokemon-legends-z-a/Main_Mission_19)은 네 조사 지점을 확인한 다음 환상의 벽을 지나 통로 끝의 Gwynn을 만나는 순서를 설명한다. 새로 벽을 통과하면 분리된 하수도 안쪽 통로로 들어가며, 통로를 걸어 Gwynn과 배틀할 수 있다. 출구로 돌아갔다가 다시 들어갈 수 있고, 패배 후에는 바깥 하수도에서 재도전한다.

이전에 Gwynn 단계로 저장된 플레이어는 기존 지도에서 그대로 대결할 수 있다. 하수도 출입구의 복귀 정보와 다른 미션은 유지한다. 안쪽 통로의 정확한 길이·방향·벽과 인물 좌표는 2D 초안이며, 원작의 환상 연출과 촛불 안내는 미구현이다.
