# 디아루가·펄기아·기라티나 오리진폼

고정 원본의 크리스털·글로브·코어 도구와 각각의 오리진폼을 기존 보상·폼 도구 상태 및 융합 경로에 연결했다. 세 폼의 native 종과 원본 능력치 6항목이 일치할 때만 허용한다. 별도의 native 소지 도구를 지급하거나 기존 도구·저장을 지우지 않는다. 일반·기존 저장의 수동 활성화와 새 저장의 독립 활성 상태를 보존한다.

세 도구별 실제 보상 선택, 활성·해제, 두 융합 역할, 실제 전투 시작과 한 턴 뒤 native 폼, codec·분리·도구 상태, 기존 저장과 다른 슬롯 보존을 검사했다. 관련 일반/Worker 각각 32/32, 타입·production 빌드 통과. 생성기 두 종류도 검증한다. 브라우저 실기기·운영 검증과 모든 특성·도구 조합의 동등성은 별도다. `/tmp/origin-final.log`, `/tmp/origin-worker.log`, `/tmp/origin-type.log`, `/tmp/origin-build.log`.
