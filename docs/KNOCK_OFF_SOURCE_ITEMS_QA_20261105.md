# 탁쳐서떨구기 소지 효과

원본은 이전 가능한 포켓몬 소지 효과가 있을 때 위력을 1.5배로 하고, 명중 후 그 효과 중 무작위로 하나를 제거한다. 최신 신규 도전은 포켓로그식 효과와 검토된 네이티브 도구를 함께 고려한다. 원본의 현재 코드에 따라 대상이 플레이어 포켓몬이면 상대 트레이너·야생 여부와 관계없이 도구를 제거하지 않는다. 기존 도전은 이전 처리를 유지한다.

이전 불가 폼 도구와 고정 효과는 보호하고 점착은 제거를 막되 위력 보너스는 유지한다. 마음의물방울 제거 시 성격 능력치를 다시 계산한다. 여러 효과의 선택에는 현재 엔진 난수를 사용하므로 원본 난수 스트림과 같지는 않다. 복합 폼·특성, 기절 시 점착 및 공격자 반사 피해 관련 원본의 TODO 경계, 모든 네이티브 도구의 분류와 후속 아이템 회수는 전수 검증하지 않았다.

격리 전투에서 단일·더블 대상, 스택 하나 제거, 네이티브·혼합 효과, 대타·방어·다이맥스, 플레이어 도구 보존, 자시안 폼 도구, 마음의물방울, 손상된 수량, 포획 시 남은 도구 인계, 저장 복구와 다른 슬롯 보존을 확인했다. 실계정·실기기 검증은 하지 않았다.

수량 보호 추가 전 관련 도구·열매·미스터리·첫 턴·변신·호출·AI·날씨·지형·트레이너·상태·챌린지·융합·학습·스케치 회귀는 일반 실행과 Worker 로더에서 각각 482건 통과했다. 최종 코드의 탁쳐서떨구기·폴터가이스트 집중 검사 30건도 양쪽에서 통과했고, 최종 타입 검사와 빌드가 통과했다. 전체 프로젝트 검사는 아니다.
