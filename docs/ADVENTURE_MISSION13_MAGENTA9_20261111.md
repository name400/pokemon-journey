# 미션 13: 로즈 9번지 우츠보트

[로즈 9번지 원작 자료](https://bulbapedia.bulbagarden.net/wiki/Magenta_Sector_9)는 이 지역의 미션 13 메가우츠보트를 Lv.34, 씨기관총·덩굴채찍으로 기재한다. 기존 임시 북쪽 큰길 표식에 더해 로즈 9번지 지상에서도 같은 전투와 우츠보트나이트를 받을 수 있도록 연결하고, 새 전투의 기술을 확인된 두 기술로 설정했다. 이미 시작된 전투 저장은 수정하지 않는다.

정확한 도로 칸과 전투 공간은 초안이다. 원작 특수 독탄·독 웅덩이와 동료의 실시간 참전은 턴제 전투에 구현되지 않았다. 기존 큰길 표식과 보상 대기 상태는 유지한다.
