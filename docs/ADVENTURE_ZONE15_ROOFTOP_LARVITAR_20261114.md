# Zone 15 rooftop Larvitar

[VGC's Zone 15 guide](https://www.videogameschronicle.com/guide/pokemon-legends-z-a-wild-zone-15/) describes reaching the roof via a repaired holovator, a fire-opened web and the rooftop gate, with three Larvitar on the roof. The existing route was already available, but only one rooftop Larvitar was represented.

Two additional visible slots use the existing encounter, shiny and per-slot spent handling. The original `larvitar` ID is unchanged; previously captured or defeated encounters stay consumed. Each new slot has its own ID, and the existing occupied-tile protection keeps a player restored on a newly occupied tile safe. The individual positions, level 41 and 2D roof geometry use the current provisional model; the source does not confirm exact positions or respawn behavior. The existing legacy lift and interior web remain for save compatibility, so the route is not claimed to be an exact original reconstruction.

Representative unit and isolated SQLite API tests cover access, old saves, independent spent slots, shiny capture, a repeated request and party preservation. Original hardware, production D1 and Sites are not verified.
