# 이상한 꿈 백금옥 보존

고정 네이티브 데이터의 백금옥(`griseousorb`)은 기라티나의 고스트·드래곤 기술 위력에만 적용되며 폼 변경 훅이 없다. 신규 도전의 `reviewed-native-v3`에 이 도구를 추가해 이상한 꿈의 파티 변환·대체 전투·거절에서 보존한다. 기존 `reviewed-native-v2`와 이전 저장은 기존 제한을 유지한다. 원본 폼 도구인 백금코어(`griseouscore`)와 미검토 도구는 새로 허용하지 않는다.

실제 선택·확인·codec 경로에서 세 선택과 융합 파티, 다른 슬롯 보존을 검사했다. 변환 후 기라티나의 섀도볼 피해 증가, 다른 종에는 증가하지 않는 점 및 도구가 폼을 바꾸지 않는 점을 격리 전투로 확인했다. 기존 검토 도구 모두의 신규 정책 허용도 확인했다. 이는 네이티브 도구 보존 확장이며 원본의 모든 소지 효과·특수 폼/융합 조합이나 실사용·실기기의 동등성을 뜻하지 않는다.

추가 검사로 대체 전투의 기라티나도 codec 복원 후 백금옥 위력 효과를 유지하는지 확인했다. 두 피해 값을 비교할 때는 대상이 두 경우 모두 한 방에 쓰러지지 않도록 격리된 전투 대상 HP를 늘렸다.

도구 정책 생성 검사는 기존 기준 커밋에서도 녹슨 검·녹슨 방패의 분류 사유가 최신 폼 도구 분류와 달라 실패했다. 생성 결과와 대조해 두 사유만 `form-or-special-item`으로 갱신했으며 두 항목은 전후 모두 거부 상태다. 정책의 기존 143개 허용 목록은 변하지 않는다.

기존 생성 정책 JSON은 v2 기준을 보존하므로 백금옥은 그 표에서 계속 미승인으로 남는다. v3 코드의 명시적 1개 예외가 별도로 허용하며, v2 저장이 자동으로 허용 상태로 바뀌지 않도록 했다.
