# 사이드 미션 99 — 가보리의 먹이

[의뢰 공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-099-pleasing-arons-palate)에 따라 미션 35의 Mable 대화 뒤 연구소 서쪽 Appée에게 의뢰를 받고, 선두 포켓몬의 오물폭탄으로 철 조각을 양념한 뒤 3,500원·키토산 5개·파워밴드를 받을 수 있다. 연구 레벨 32의 기술머신 053으로 해당 기술을 배우는 기존 경로도 사용할 수 있다. 연구소 주변 인물·가보리·철 조각의 정확한 좌표는 2D 초안이다.

기존 저장에 단계가 없으면 미수락으로 두고, 이미 시작한 저장은 해금 조건이 바뀌어도 진행한다. 가방 한도가 부족하면 보상 전체를 보류하며 오래된 리비전과 완료된 의뢰의 중복 지급을 거절한다. 여행 수첩과 현재 장소 표식은 저장된 단계만 사용한다. 알 수 없는 미래 단계는 보상이나 목표로 추측하지 않는다.

실시간 조준·던지기와 가보리의 원작 행동은 구현하지 않았으며 필드 상호작용은 기존 턴제 근사다. 실제 기기와 운영 D1·Sites 병합본은 검증하지 않았다.
