# 잠꼬대의 적 AI 판단

원본 잠꼬기의 수면·절대안깸 조건과 `RandomMovesetMoveAttr`의 호출 가능 기술 조건을 대조했다. 신규 도전의 `enemyAiSleepTalkRule: source-v1`에서 적 AI는 깨어 있거나 절대안깸이 아닌 경우, 또는 원본 호출 규칙을 사용하는 도전에서 호출할 수 있는 기술이 없으면 잠꼬기의 점수를 낮춘다. 다이맥스 기술은 기본 기술 조건을 적용하지 않는다. 기존 도전의 판단은 유지한다.

격리 전투 및 저장 복원에서 깨어 있음, 실제 수면, 절대안깸, 호출 가능한 기술 없음, PP가 0인 호출 대상 기술, 다이맥스 맥스가드와 다른 저장 데이터 보존을 검사했다. 호출 가능 기술 판단은 현재 구현된 원본 호출 정책의 범위를 따르며, 모든 챌린지·특성·대상 조합과 원본 난수열 및 실제 브라우저 플레이까지 검증한 것은 아니다. 운영 데이터와 Sites는 변경하지 않았다.
