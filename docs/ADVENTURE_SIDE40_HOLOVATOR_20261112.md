# 사이드 미션 40: 전력이 부족한 홀로베이터

[원작 의뢰 자료](https://www.serebii.net/legendsz-a/sidemissions/aholovatorwithoutpower.shtml)와 [공략](https://gmtreks.com/pokemon-z-a/side-missions/40)은 Canari 퀴즈 이후 전기 기술로 홀로베이터를 작동시키고 1,700원·하이퍼볼 3개·메가조각 10개를 받는다고 설명한다. 기존 수리와 옥상 이동을 유지하고 지상 승강기의 별도 보상 수령을 추가했다. 이전 버전에서 이미 수리했으나 보상을 받지 못한 저장도 한 번 받을 수 있다.

하이퍼볼 보관 한도에 도달하면 지급을 보류하고 빈 공간을 만든 뒤 다시 받을 수 있다. 보상과 수령 플래그는 같은 저장 처리로 적용되며 다른 파티·진행 상태는 바꾸지 않는다. 정확한 승강기 좌표와 옥상 지형은 기존 2D 초안이며, 원작의 현장 포켓몬 소환·기술 연출 및 실제 운영 기기 동작은 확인하지 않았다.
