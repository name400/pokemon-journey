# 가시덤불 필드 기술

- [원작 장애물 자료](https://bulbapedia.bulbagarden.net/wiki/Obstruction)에 열거된 기술과 불꽃 공격을 공통 판정에 연결한다. 저장된 한글 기술명과 영문 이름·ID는 기존 전투 기술 데이터로 확인한다.
- 구역 3·4·7·13·19와 카페 옥상의 기존 덤불 상호작용을 사용한다. 제거 여부 저장 형식, 위치, 기존 진행 및 기술 PP 처리 방식은 바꾸지 않는다.
- 종전 구역에서 허용하던 모든 공격형 비행 기술은 호환을 위해 계속 허용한다. 구역 19는 기존의 불꽃 공격에 더해 자료에 열거된 기술만 허용한다. 이는 원작의 완전한 재현이 아닌 기존 게임 규칙과의 절충이다.
- 구역 19 덤불의 원작 재생 시간과 게임 내 영구 제거 사이의 차이는 이 변경에서 해결하지 않았다.
- 격리 SQLite API에서 세 구역의 기술 사용, 저장 복원, 오래된 요청과 중복 제거 거부를 확인했다. 운영 데이터와 Sites 배포본은 검증하지 않았다.
