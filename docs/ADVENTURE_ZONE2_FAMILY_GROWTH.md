# 구역 2 두 계열의 성장 기술

신규 일반 꼬몽울과 보르쥐는 조우 생성 시 Z-A 기술표 표식을 받고 포획 후 각 진화 단계의 레벨·진화·다시 배우기 기술을 사용한다. 구역 2의 풀숲, 필드 접촉, 직접 볼 투척에 연결했다. 초기 야생 기술은 현재 레벨까지의 마지막 네 기술을 사용하는 기존 2D 게임의 근사다. [꼬몽울](https://pokemondb.net/pokedex/budew/moves/9), [로젤리아](https://pokemondb.net/pokedex/roselia/moves/9), [로즈레이드](https://pokemondb.net/pokedex/roserade/moves/9), [보르쥐](https://pokemondb.net/pokedex/patrat/moves/9), [보르그](https://pokemondb.net/pokedex/watchog/moves/9)의 Z-A 기술을 참고했다.

기존 개체와 이미 생성된 전투·포획 기회, 알 수 없는 표식은 소급하지 않는다. 우두머리와 새로 출현하는 진화형의 초기 기술은 이 변경에서 다루지 않는다. 대표 단위 검사와 격리 API에서 필드 접촉·직접 포획·재접속·진화·PP 보존을 확인했으며 실제 운영·원작 기기 검증은 아니다.
