# 루주 광장 남동쪽 조각상과 접근로

[야생 구역 3 안내](https://www.pokemon-france.com/en/guides/pokemon-legends-z-a/wild-zones/)는 루주 광장 남동쪽의 로즈레이드 조각상 아래에서 해독제를 얻을 수 있다고 설명한다. 기존 정원 남동쪽에 조각상과 일회성 해독제를 연결하고, 남쪽 출입구와 동쪽 길에서 접근하는 포장 동선을 표시했다. 기존 정원, 탑, 출입구, 풀숲 조우와 미션 40 조사 대상은 유지한다.

조각상의 형상·정확한 좌표와 포장된 도로의 너비는 공개 자료로 측정하지 못한 2D 초안이다. 새로 막힌 조각상 칸에 있던 구형 지상 저장은 같은 리비전에서 가까운 통행 가능 칸으로 복원한다. 해독제는 지갑의 기존 99개 한도와 원자적 저장을 사용하며, 공간이 없으면 수령 상태가 바뀌지 않는다. 구형 저장의 미확인 수령 이력은 추정하지 않는다.

격리 검사에서 세 방향 접근, 이전 저장 복원, 지갑 한도·재요청·재접속 및 기존 조사 진행을 확인했다. PC·모바일 화면은 시험 상태와 외부 이미지 대체물을 사용했다. 원작 기기와 운영 환경의 정밀 배치는 검증하지 않았다.
