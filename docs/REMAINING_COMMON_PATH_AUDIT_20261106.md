# 남은 공통 경로 대조 — 2026-11-06

## 저장 복구

동일 기술의 표시 별칭은 `classicMoveAliasPreview` 및 확인 액션을 공통으로 사용한다. 별도의 사용자 선택, 원본 기술·PP 백업과 revision 비교를 유지한다. 정상적인 스케치 중복과 식별할 수 없는 경우는 자동 변경하지 않는다. 검증된 DNA 융합과 스케치가 함께 있는 경우도 같은 경로로 처리한다.

종료된 전투 스냅샷은 파티·전투 파티·기술 ID/PP/PP업이 정확히 일치하고 진행 중 요청·변신·슬롯 순서 충돌이 없는 경우에만 사용자가 확인해 정리할 수 있다. 스냅샷 기술 사용 여부를 보존하고 원본 슬롯을 별도 백업한다. 자연 전투에서 날씨·능력치 변화와 다른 포켓몬, PRNG가 유지되는지와 다음 야생 전투 및 API 저장 충돌을 격리 검사했다. 일반 기술에서 서로 다른 슬롯 PP와 구조가 불확실한 저장은 제외한다. 진행 중인 일반 야생전·트레이너전·라이벌전의 대기 포켓몬은 명령 대기·빈 실행 큐 등 엄격한 조건에서 사용자 확인 후 처리한다. 출전 포켓몬과 검증되지 않은 이벤트·기타 전투 중 상태는 제외한다. 이미 시작된 트레이너의 시험·이상한 꿈 이벤트 전투는 이벤트·단계·트레이너가 일치하고 챌린지가 없을 때 대기 포켓몬을 지원한다. 챌린지 ID 0, 1, 4–10, 12는 진행 기록·전투 제한이 일치하고 출전 판정이 가능한 경우에 한해 지원한다. 특성 무작위화는 파티 전원의 시드·특성·패시브가 일치해야 하며 융합체의 주체와 기증자도 각각 검증한다. 기술 무작위화와 불명확한 챌린지는 제외한다. 스케치 대기 포켓몬은 슬롯별 PP와 두 네이티브 기술 배열이 일치할 때 사용자가 직접 선택한다. 스케치는 슬롯별 PP가 파티·전투·스냅샷에서 일치하면 사용자가 해당 PP를 보고 선택할 수 있다. 사용자 저장·브라우저 실검증은 남는다.

## 전체 공격 및 멀티렌즈

`PrepareHit`, 공통 `getSpreadDamage` 순차 처리, `spreadDamage`와 후속 효과가 공통 지점이다. 현재는 최초 타격의 대상 순서를 검토된 기술 집합에 한정하며, 단순히 모든 기술로 확장하면 자해·드레인·대상별 추가 효과·기술 실패·난수 순서를 바꿀 수 있다. 스케일노이즈처럼 자기 효과가 대상 사이에 들어가는 처리는 여전히 별도 검증이 필요하다.

`scripts/audit-classic-spread-candidates.mjs`는 현재 게임의 기술표와 네이티브 메타데이터에서 일반 전체 공격 후보를 재현 가능하게 열거한다. 기존 15개 후보의 원본 기술 정의는 15개 모두 확인했다. 그중 `brutalswing`, `searingshot`, `breakingswipe`, `relicsong`, `sparklingaria`, `thousandarrows`, `thousandwaves`, `matchagotcha`, `paraboliccharge`, `shelltrap`, `synchronoise`, `mortalspin`, `nihillight`, `magnitude`, `mindblown` 15개는 신규 도전에서 공통 첫 타격 피해 순서에 연결했다. 기존 15개 후보 중 첫 피해 순서 연결 15개, 이 집합 밖 후보 0개다. 전체 후보 63개가 첫 피해 검토 집합에 포함된다. 이 완료 수치는 첫 피해 순서 연결만 의미한다. `magnitude`의 원본 웨이브·턴 기반 위력 추첨과 네이티브 난수 차이는 남는다. `mindblown`은 신규 도전에서 명중 또는 전체 대상의 방어 시 원본처럼 최대 HP의 절반을 내림해 감소시킨다. 멀티렌즈 유무, 기존 규칙 보존, 방습·매직가드 및 HP 1 기절을 검사했다. 모든 대상이 불꽃 흡수 면역이거나 빗나간 경우에도 사용자 HP가 한 번 감소하고 매직가드가 유지됨을 격리 검사했다. 다른 실패 원인과 특성 조합 전체의 동등성은 추가 대조가 필요하다.

이 숫자는 메타데이터 기반 **후보**이며 원본 출현·멀티렌즈 적격성 또는 실제 미구현 확정 수가 아니다. 첫 피해 순서 연결은 전체 원본 동등성을 뜻하지 않는다. 특히 부가 효과가 각 대상 피해 사이에 발생하는 순서와 난수는 추가 대조가 필요하다. 고정 피해, 차지·다단·Z/다이맥스와 다른 대상 표기는 이 목록 밖이다. 원본 효과를 비교해 대상 부가 효과·자기 피해/회복·조건부 피해 등을 묶어 공통 처리하고 경계 사례부터 검사한다.

## AI와 꿈 이벤트

AI의 현재 같은 점수 대상 추첨은 원본 전체 가중 추첨이 아니라 제한된 동점 사례다. 전체 대상 점수, 실패 판정, 교체 판단, 난수 스트림은 공통 AI 선택 경로에서 원본과 대조해야 한다. 이상한 꿈은 검증된 폼·도구·융합 외 native 도구, 특수 효과·패시브 및 특성 변경 조합을 분류해 공통 변환·저장·복원 경로별로 검증한다. 원본이 비활성화한 콘텐츠는 임의로 활성화하지 않는다.
