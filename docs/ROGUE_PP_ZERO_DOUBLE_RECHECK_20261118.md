# PP 0 기술 표시 재검사 — 2026-11-18

기존 신고는 Lv9 염버니의 신속이 PP 0에서 화면에 보이지 않던 사례다. 당시 원인은 저장에서 기술이 삭제된 것이 아니라 실행 가능 기술 목록을 표시에도 사용한 것이었으며, 현재 코드는 화면용 `displayMoves`를 별도로 제공한다. 과거 운영 저장과 배포본은 이번 검사 대상이 아니다.

현재 개발본의 격리 엔진 검사에서 신속 5회 사용과 매 턴 저장 복원 후 네 번째 카드가 PP 0·비활성 상태로 남고, 불가능한 명령이 저장을 바꾸지 않는 것을 확인했다. 전체 기술 PP 소진 시 발버둥, 사슬묶기 및 연속 야생 전투의 PP 회복 검사도 통과했다. 격리 SQLite API의 동일 신속 사용·재조회 및 거절 검사도 통과했다.

추가한 더블 전투 검사에서는 염버니가 신속을 5회 쓰고 매 턴 저장을 복원한 뒤에도 기술이 원래 개체의 네 번째 카드에 PP 0으로 남으며, 다른 출전자의 카드에는 나타나지 않고 재사용 명령이 거절되는 것을 확인했다. 합성 파티를 사용했다. 엔진 5건과 API 1건이 통과했으며 이 표본에서 게임 결함은 재현되지 않아 게임 코드를 바꾸지 않았다. 모든 기술 소실 경로·다른 폼과 전투 조합, 이번 코드의 브라우저·실기기·운영 저장은 검증하지 않았다. Sites에는 배포하지 않았다.
