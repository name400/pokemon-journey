# 블루 7번지 동쪽 안뜰

[블루 7번지 지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-7.html)는 동쪽 안뜰에 북쪽과 남쪽 입구가 있다고 설명한다. 이는 2차 자료다.

기존 동쪽 건물 블록 안에 두 방향으로 통하는 안뜰을 추가했다. 실제 안뜰의 정확한 크기, 건물 윤곽과 입구 위치는 확인되지 않아 압축된 2D 지도에 맞춘 잠정 배치다. 기존 센터, 승강기 의뢰와 옥상 동선 및 저장 필드는 유지한다. 안뜰의 원작 아이템과 기술머신 전달자는 이번에 추가하지 않았다.

모바일 이동 오류 및 Sites 병합본 실패 기록은 운영 재검증 전이므로 유지한다.
