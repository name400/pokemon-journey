# 멀티렌즈 불사르기 첫 타격

신규 도전에서 불사르기의 멀티렌즈 첫 타격 중 앞 상대가 실제로 기절하면 뒤 대상 피해에 남은 대상 수를 반영한다. 기존 도전은 이전 규칙을 유지한다.

아군·상대 사용, 방어·기합의머리띠 생존, 타오르는불꽃 면역과 반복 타격의 열매 제거를 격리 검사했다. 상대가 사용할 때 파티 소지 열매와 전투 기록을 함께 갱신하고 다른 도구·슬롯을 보존하는지 저장 복구로 확인했다. 첫 대상의 열매 제거를 다음 대상 피해 이전에 반영하는 원본 세부 순서와 모든 특성·원본 난수 조합, 운영·실기기 플레이는 별도 검증이 필요하다.
