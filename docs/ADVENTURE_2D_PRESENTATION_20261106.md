# 탐험·모험 2D 연출 현황

## NPC 대화창 — 부분 구현

[포켓몬 블랙·화이트의 대화창 화면 소개](https://www.siliconera.com/proper-pokemon-black-white-screens/)를 참고해 NPC 대화에 화면 아래의 테두리형 대화 상자를 적용했다. 기존 필드를 뒤에 남기고 화자·대사·선택지를 보여 주며, 긴 선택지는 상자 안에서 스크롤한다. 선택·닫기·Escape는 기존 대화 경로를 사용하고 다른 메뉴와 강제 선택 창의 배치는 바꾸지 않는다. 이는 고전 2D 대화창을 참고한 독자적 표현이며 특정 게임의 화면이나 Z-A 대사를 완전 재현한 것은 아니다.

남은 범위: Z-A의 장면별 대사·초상화·대화 진행 순서와 이벤트 연출, 전투 진입 및 실시간 전투의 2D 표현. 특정 좌표·구조의 원작 일치 여부는 별도 맵 대조 문서를 따른다.
