# 베르 8번지와 남쪽 큰길 연결

[베르 8번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-8.html)는 남쪽 큰길을 남쪽 접근로로, [남쪽 큰길 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/south-boulevard.html)는 베르 8번지를 인접 구역으로 명시한다. 두 구역의 지상 왕복 출입을 추가했다. 출입 좌표와 도로의 세부 형태는 잠정 2D 배치다.

기존 구역 1 출입과 저장 형식을 유지하고, 남쪽 큰길 옥상 층의 미래 형식 상태는 덮어쓰지 않는다. 원작 실기 및 실제 Sites 병합본은 확인하지 않았다. 모바일 이동 오류 기록은 운영 재검증 전까지 유지한다.
