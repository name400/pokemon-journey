# 자기 대상 호출 기술의 프레셔 PP

고정 원본 `7c0881255af5cd51992e513ff93c2f71adbe40e0`에서 손가락흔들기·따라하기·조수는 사용자 자신을 대상으로 사용하며 `CallMoveAttr`는 실제 호출 기술을 PP를 사용하지 않는 `FOLLOW_UP`으로 실행한다. 기존 시뮬레이터는 호출된 공격의 대상이 프레셔일 때 원래 호출 기술의 PP를 추가로 차감했다.

신규 도전의 `calledSelfPressureRule: source-v1`에서 위 세 호출 기술의 후속 공격에 대한 추가 차감만 건너뛴다. 잠꼬대는 기존 별도 규칙으로 처리하고, 흉내내기·자연의힘처럼 상대를 직접 지정하는 기술과 지시하기는 이번 변경에 포함하지 않는다. 구형 저장은 기존 동작을 유지한다.

실제 격리 단일·더블 전투에서 각 호출 기술, 프레셔, 직접 선택한 기술의 프레셔 비용, 구형 규칙과 저장 직렬화 복원을 확인했다. 관련 검사 57건 통과. 원본은 코드를 대조했으며 원본 게임 런타임, 브라우저, 실제 기기, 모든 호출 기술 및 특수 변화 조합은 검증하지 않았다. 실제 운영 데이터와 Sites 배포는 사용하지 않았다.
