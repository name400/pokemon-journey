# 야생 구역 17 옥상 탐색

[구역 안내](https://www.nintendolife.com/guides/pokemon-legends-z-a-wild-zone-17-guide-all-pokemon-and-alphas)는 입치트가 있는 옥상과 낮의 클레피·밤의 램프라를 설명한다. [원작 진행 안내](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Part_18)는 입치트 뒤의 기술머신 062를, [구역 물품 안내](https://www.pokemon-france.com/en/guides/pokemon-legends-z-a/wild-zones/)는 그 옆의 큰금구슬을 확인한다. 기존 산책로 사다리로 도달하는 두 옥상에 연결 발판과 이 탐색 대상을 추가했다. 기존 지상 클레피와 사용 이력은 보존하고, 같은 클레피의 사용 상태를 공유한다.

발판 모양, 옥상 방향, 포켓몬과 아이템의 개별 좌표는 축약된 2D 초안으로 원작의 정밀 배치를 재현하지 않는다. 옥상 진입과 저장 좌표는 유지하며 새 아이템 칸도 통행 가능하다. [학습 목록](https://www.serebii.net/attackdex-sv/flamethrower.shtml)에서 확인된 종과 일부 검증된 폼만 TM062를 배울 수 있다. 전체 특수 폼은 확인하지 않았다.
