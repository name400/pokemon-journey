# 구역 6 하층 수로와 남서 출입

별도 조사에서 전달된 [원작 지도](https://images.nintendolife.com/778300c10d077/wild-zone-6-pokemon-legends-z-a.large.jpg)와 [3D 화면](https://www.videogameschronicle.com/files/2025/10/Pokemon-Legends-Z-A-Wild-Zone-6-Binacle.jpg) 분석은 긴 석축 수로, 양옆 보행면, 위쪽 다리와 남서 하층 입구 둘을 설명한다. 원본 이미지는 이번 작업 환경에서 직접 보지 못했다. 기존 상층 다리의 통행과 수로층의 얕은 통로를 유지하면서 하층 보행면과 다리 밑의 가장자리를 석재로 구분해 그린다. 그림은 충돌이나 깊은 물의 판정을 바꾸지 않는다.

기존 남서 하층 출입을 보존하고 두 번째 출입과 그에 이르는 통행면을 추가했다. 두 출입 모두 기존 쉐종 운하변의 서로 인접한 지점으로 연결하는 게임 내 초안이다. 각 출입구의 정확한 좌표, 서로 다른 바깥 도로와의 대응, 석축 모양과 북쪽 수로 끝은 원작에서 확인하지 못했다. 옥상·상층 대로와 하층을 독립적으로 유지하고 새 계단을 만들지 않았다. 새 통행면은 원래 막힌 칸에만 들어가므로 기존 저장 위치를 덮지 않는다.

지도·이동 예측 91개와 격리 API 대표 3개에서 두 하층 출입 왕복, 상층·하층 분리, 다리 아래 이동·깊은 물 차단, 재접속 및 파티·가방 이력 보존을 확인했다. PC·모바일 Chromium 화면은 시험 상태와 대체 이미지이며 원작 기기와 운영 데이터는 검사하지 않았다.
