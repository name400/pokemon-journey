# 포켓로그 부화의 새 이로치 변형 표시

이미 일반 이로치를 등록한 뒤 아직 등록되지 않은 다른 이로치 변형이 알에서 나오면, 변형 마스크에는 새 모습이 추가되지만 기존 결과가 `중복`으로 표시되는 것을 격리 재현했다. 변형 마스크가 명확히 존재하고 해당 비트가 없을 때만 새 모습으로 표시한다. 과거 저장에 마스크가 없으면 획득 이력을 추측하지 않고 이전 중복 판단을 유지한다. 기존 지급액 보호를 위해 코인 환급은 종전 중복 판단을 그대로 사용하며, 새 모습과 환급이 함께 발생하면 양쪽을 결과 화면에 표시한다. 기존 저장이나 이미 생성된 부화 결과를 일괄 변경하지 않는다.

동일 웨이브의 신규 변형·동일 변형·기존 변형에 대한 표시, 코인 환급, 변형 등록 및 직렬화 복원을 검사했다. 실제 격리 SQLite API에서 승리→부화→조회→오래된 중복 요청 거절→결과 확인까지 검증하고 다른 모드 및 저장 슬롯이 보존됨을 확인했다. 390×844와 1280×800 격리 Chromium에서 새 모습과 환급 표시, 결과 모아보기, 확인과 새로고침을 검사했고 기존 부화 연출·건너뛰기·움직임 줄이기도 회귀 확인했다. API·알 관련 대표 검사 115건과 타입 검사가 통과했다.

첫 API 검사에서 승리 자체의 코인까지 부화 환급과 같다고 가정해 실패했으며, 환급 표시와 결과 확인 이후 총액 불변을 별도로 확인하도록 수정했다. 첫 브라우저 검사는 앱 최초 조회가 격리 fixture의 도감 기본 항목을 준비하기 전 상태와 비교해 실패했고, 화면 로드 후 기준으로 바꿔 통과했다. 이는 과거 운영 실패의 원인을 확정하는 결과가 아니다. 실제 운영 데이터와 실기기는 사용하지 않았고 Sites에는 배포하지 않았다.
