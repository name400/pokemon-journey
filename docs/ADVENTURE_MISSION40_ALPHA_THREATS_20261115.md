# 미션 40 이상 우두머리의 필드 경계

[미션 공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Part_28)은 구역 3·5·9의 이상 우두머리 세 마리를 조사한다고 설명한다. [공식 안내](https://legends.pokemon.com/en-us/news/adventure)는 우두머리가 플레이어를 발견하면 추격·공격한다고 설명한다. 이 일반 설명을 근거로 세 조사 대상에도 기존 우두머리의 필드 경계·포효와 정지 중 공격을 연결했다. 해당 세 이벤트 개체의 실제 원작 행동을 직접 확인한 것은 아니다.

현재 2D 표시 위치에서 기존 두 칸 감지, 포효 피해 10, 공격 피해 30, 2.5초 간격을 적용한다. 실제 추격 이동, 공격 기술·거리·속도와 지도 좌표는 원작 확인값이 아닌 기존 게임의 잠정 규칙이다. 다른 우두머리가 동시에 가까우면 기존 구역별 위협을 우선한다. 기존 정지 공격 요청을 재사용하며 위협이 없는 경우 별도 요청은 추가하지 않는다.

해당 층·진행 단계에서만 판정하고 조사한 개체는 더 이상 위협하지 않는다. 구형 임시 조사 현장도 인식하며 알 수 없는 조사 기록은 덮어쓰지 않는다. 격리 API에서 구역 3·5·9의 경계·정지 공격·완료 후 중단, 오래된 요청·파티·이로치 기록 보존과 기존 고정·무작위 우두머리 경로를 대표 확인했다. 실제 원작 기기·운영 D1·Sites 병합본과 이동 지연은 측정하지 않았다.
