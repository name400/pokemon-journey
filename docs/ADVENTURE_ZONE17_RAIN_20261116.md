# 구역 17의 비와 무장조 조우

[Serebii 날씨 자료](https://www.serebii.net/legendsz-a/weather.shtml)와 [구역 공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Part_18)은 구역 17에서 비가 올 때 무장조가 나타나지 않는다고 설명한다. 기존 일반 풀 조우가 날씨와 관계없이 무장조를 선택하던 것을 비일 때 후보에서 제외하도록 바꿨다. 비가 아니면 기존 후보와 선택 순서를 유지한다. 진행 중인 조우와 이미 포획한 개체, 연구·의뢰 보상은 변경하지 않는다.

구역 17의 수로·거리 출입은 이미 연결돼 있어 새 출구를 추가하지 않았다. [지역 관계 자료](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_17)는 북쪽 수로와 동서 거리를 확인하지만 세부 진입 좌표·높이와 전체 형상은 여전히 2D 초안이다.

이 게임은 현재 비와 비가 아닌 날씨만 나타내므로 원작의 맑음·흐림·안개 및 실제 비행 출현을 재현하지 않는다. 출처들은 안개 조건에 서로 차이가 있어 여기서는 비에 대해서만 적용한다. 풀 조우 방식과 동일 가중치는 기존 게임의 근사이며 원작 출현 확률은 확인하지 못했다.

격리 API에서 비·비가 아닌 시각의 조우, 진행 중 날씨 변경 후 재접속과 저장 포켓몬 보존을 확인했다. 별도 구역 동선·기존 저장·낮밤 조우 검사도 수행했다. 실제 기기·운영 D1·Sites 병합본은 검사하지 않았다.
