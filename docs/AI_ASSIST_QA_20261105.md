# 조수의 적 AI 판단

원본 `RandomMovesetMoveAttr`의 다른 파티원 기술 후보 조건과 현재 Classic 호출 정책을 대조했다. 신규 도전의 `enemyAiAssistRule: source-v1`은 원본 호출 정책을 사용하는 경우 다른 파티원 중 호출 가능한 기술이 없으면 적 AI가 조수의 점수를 낮추도록 한다. 기절한 파티원의 호출 가능 기술은 후보로 인정하며 해당 기술의 남은 PP를 요구하지 않는다. 다이맥스 맥스가드와 이전 도전은 기존 동작을 유지한다.

격리 전투 및 저장 복원에서 파티원 없음, 기절한 파티원, 금지 기술, PP 0, 현재 엔진에서 제외하는 놓아준·포획된 개체, 다이맥스와 다른 저장 데이터 보존을 검사했다. 놓아준·포획된 개체의 처리와 호출 허용 여부는 현재 Classic 호출 정책에 맞춘 것이며 원본의 전체 후보·챌린지·난수열 동등성을 주장하지 않는다. 실제 브라우저 플레이와 다른 특성·도구 조합은 별도 검증이 필요하다. 운영 데이터와 Sites는 변경하지 않았다.
