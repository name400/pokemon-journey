# 야생 구역 14 변전소 작업장

전달받은 [원작 지도](https://images.nintendolife.com/8c1edbebc70ca/pokemon-legends-z-a-wild-zone-14.large.jpg)와 [현장 화면](https://www.serebii.net/pokearth/maps/lumiosecity/15.jpg)의 별도 분석은 북쪽의 단일 출입, 북서쪽 작은 관리동과 북동쪽 큰 건물, 설비 사이 넓은 포장면과 바깥쪽 흙을 설명한다. 이 작업 환경에서는 두 원본 이미지의 내용을 직접 열어 확인하지 못했으므로 전달된 분석과 기존 [변전소 안내](https://allthings.how/pokemon-legends-z-a-100-wild-zone-14-power-station-guide/)를 참고했다.

기존 건물·전기 설비·바위 좌표는 유지하며 북쪽의 넓은 포장 야드와 남쪽에서 좁아지는 작업 통로, 안전선·금속 프레임·외곽 흙·경계 가로등을 구분했다. 통행 가능한 기존 바닥 중 일부만 포장 바닥으로 바꾸고, 옛 서쪽·남쪽 출입구는 저장과 이동 호환을 위해 유지한다. 정확한 설비 배치와 쐐기 외곽, 충돌 좌표는 2D 추정이며 원작과 동일하다고 주장하지 않는다. 이 작업은 임의 옥상·수로나 출입을 만들지 않는다.

변경 전 지도와 현재 지도의 전체 타일을 비교해 포장된 기존 바닥 외에 장애물·야생 개체·출입구 변화가 없음을 확인했다. 기존 구역 단위 검사 10건과 격리 API의 북쪽 출입·구형 저장·바위·도구·날씨 검사 4건 및 타입 검사가 통과했다. PC·모바일 Chromium 캔버스는 모의 API와 대체 스프라이트로 확인했다. 로컬 지도 생성 반복 측정은 편차가 커 실질적인 지연 차이를 결론내릴 수 없었고, 실제 요청·운영 기기는 측정하지 않았다.
