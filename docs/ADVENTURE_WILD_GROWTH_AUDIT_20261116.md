# 야생 조우 성장표 연결 점검

개발 커밋 `490415fd`를 기준으로 `route.ts`의 야생 개체 생성과 포획 경로를 확인했다. 일반 풀숲의 구역 1~20, 구역별 고정 개체, 물·직접 볼 투척, 도시 조사 및 하수도 경로에서 기존 `prepareVerifiedWildMoves` 연결과 진화형 옵션을 대조했다. 우두머리·기존 전투·원작 표가 없는 폼을 일반 개체처럼 추정해 변경하지 않았다. 모든 종·이벤트와 모든 세부 폼을 전수 입증한 검사는 아니다.

별도 의뢰 조우 중 이미 검토된 기술표가 있는데 생성 경로에서 연결되지 않은 네 가지를 격리 API에서 재현했다. 미션 17의 색이 다른 메리프, 미션 19의 클레피, 사이드 77 입치트, 사이드 74 더스트나가 대상이다. 새로 만든 일반 조우에만 해당하는 기존 표와 표식을 연결한다. 클레피는 원래 이벤트용 고정 기술 네 개를 그대로 사용하고 성장표 표식만 추가한다. 다른 세 포켓몬의 새 야생 초기 기술은 기존의 레벨 이하 마지막 네 기술 선택 방식으로 설정하며 이는 원작 배치의 확정이 아닌 근사다. 이미 포획된 포켓몬, 진행 중이던 전투, 미확인 우두머리 및 폼은 수정하지 않는다.

격리 API 8건에서 클레피 직접 포획·볼 실패 후 전투·구형 전투의 기존 기술, 입치트 직접 전투·기절 후 포획, 더스트나 포획·보상, 이로치 메리프 포획·재조회, 구구와 의뢰 진행·중복 방지를 확인했다. 성장·진화·PP와 옥상·구역 20 기존 단위 검사 6건이 통과했다. `490415fd`의 타입 검사와 구구 관련 API 3건도 통과했다. 변경 후 전체 검사, 운영 데이터와 Sites 병합본은 검사하지 않았다. 보유한 ZA 표가 없는 도시 원숭이 등과 이벤트의 개별 정확성은 별도 자료 확인이 필요하다.
