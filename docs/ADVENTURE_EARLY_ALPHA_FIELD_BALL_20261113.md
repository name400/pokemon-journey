# 초기 구역 우두머리 필드 포획

야생 구역 1 옥상 구구, 4 묘지 페이검, 7 광장 불화살빈에게 기존에 보유한 볼을 선택해 직접 던질 수 있다. [공식 모험 안내](https://legends.pokemon.com/en-us/news/adventure)는 필드에서 볼을 던져 포획하고 우두머리를 만날 수 있다고 설명한다. 기존의 각 등장 조건과 2D 위치, 우두머리 포획률·볼 효과를 그대로 사용한다. 이 세 고정 개체에는 실시간 감지가 없으므로 미발견·뒤치기 보너스를 주지 않는다.

서버는 위치·상호작용·진행·재고와 리비전을 검증한다. 포획 성공 시 기존 구역별 재등장 이력, 도감·연구, 이로치 색과 볼을 함께 기록한다. 실패하면 같은 이로치 우두머리와 기존 전투가 시작되며 도주 후에도 색이 보존된다. 구형 저장과 기존 개체·맵·이동을 변환하지 않는다.

격리 SQLite API에서 세 구역의 포획 실패·도주·재접속·마스터볼 포획·소진 기록, 다른 위치·재고 부족·오래된 요청 거절을 확인했다. 기존 우두머리 재등장·고정 개체 포획 검사와 PC·모바일 Chromium의 모의 API 볼 선택을 확인했다. 원작 기기와 운영 D1, 세 구역의 전체 자연 진행은 검증하지 않았다.
