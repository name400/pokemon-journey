# 사이드 미션 34: 방어 기술 배틀

[Serebii](https://www.serebii.net/legendsz-a/sidemissions/movesthatputupawall.shtml)와 [공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-034-moves-that-put-up-a-wall)에 따라 메인 미션 14 시작 후 존느 8번지에서 Muro의 레벨 30 윤겔라·비비용과 배틀한다. 각각 리플렉터와 빛의장막을 포함한 확인된 기술을 사용한다. 승리 상금은 1,440원, 별도 의뢰 보상은 1,100원·기술머신 031·미네랄사이다다. 다른 공략은 상대 레벨을 34로 기재하므로 레벨 30은 잠정 채택이다. 배틀은 기존 턴제 순차 전투이며 원작의 실시간 배치와 NPC 좌표는 확인하지 못한 2D 초안이다.

보상은 별도 수령하며 가방에 자리가 부족하면 나머지를 맡긴다. 기존 리비전과 소유·재고 검증을 따르고 구형 저장의 보상을 추정하지 않는다. 기술머신은 [Z-A 학습 목록](https://www.serebii.net/attackdex-sv/reflect.shtml)에서 확인한 기본 종 일부에 재사용할 수 있다. 나머지 종·폼은 아직 미확인이므로 임의로 학습시키지 않는다. 기술 칸 교체와 전투 효과는 기존 공통 처리를 사용한다.

격리 SQLite API에서 해금·실제 전투·패배 재도전·승리·부분 수령·중복 요청·재접속, 호환과 비호환 종의 기술 학습 및 기존 파티 보존을 확인했다. 원작 실기·운영 D1·Sites 병합본은 확인하지 않았다.
