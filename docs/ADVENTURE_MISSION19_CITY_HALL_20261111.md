# 미션 19 시청 단서

[미션 공략](https://strategywiki.org/wiki/Pok%C3%A9mon_Legends%3A_Z-A/Reaching_Rank_D)은 시청 주변 분수의 주민에게서 Gwynn과 누보 카페에 관한 단서를 얻는다고 설명한다. [상세 경로](https://pokemon.fandom.com/wiki/Pok%C3%A9mon_Legends%3A_Z-A/Walkthrough/Main_Mission_19_%E2%80%94_23)는 시청을 존느 구역 9에 둔다.

존느 구역 9의 시청 입구와 분수, 미션 19 단서 주민을 기존 지도에 연결했다. 이전 저장의 진행을 위해 루주 북쪽 임시 단서도 유지한다. 지도 좌표, 건물의 모습과 분수의 크기·주민 위치는 확인되지 않은 2D 초안이며, 시청 실내와 원작 대화 장면은 구현하지 않았다. 새 표식은 통행 가능한 칸이므로 기존 좌표와 출입구를 막지 않는다.

신규 진행에서는 탐정 사무소를 방문한 후 시청 밖의 Ivor를 만나고 분수 근처 주민에게 단서를 묻는다. 위 상세 경로는 시청 밖에서 Ivor를 만난 뒤 분수 주변의 여인에게 묻는 순서를 설명한다. 원작의 정확한 이벤트 연출과 NPC 좌표는 확인되지 않아 대화 조작과 타일은 이 게임의 초안이다. 접근 가능한 시청 실내를 확인할 충분한 근거는 확보하지 못했다.

기존에 시청 단계를 시작한 저장에는 새로운 대기 플래그가 없으므로 Ivor를 다시 만나지 않아도 된다. 기존 루주 북쪽 단서 경로도 보존한다. 신규 진행의 플래그는 탐정 사무소에서 설정하고 대화 또는 기존 단서 진행 시 정리한다.
