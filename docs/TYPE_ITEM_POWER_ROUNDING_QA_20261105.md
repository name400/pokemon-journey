# 타입 강화 도구의 위력 계산

고정 원본 `7c0881255af5cd51992e513ff93c2f71adbe40e0`의 `AttackTypeBoosterModifier`는 적용 시 기술 위력에 배율을 곱해 내림한다. `calculateBattlePower`는 타입 없는 발버둥에 이 도구를 적용하지 않는다. 기존 시뮬레이터 연결은 배율을 다른 보정과 함께 반올림했고 발버둥도 강화할 수 있었다.

새 도전의 `typeItemRule: source-v2`는 타입 강화 도구 적용 단계에서 내림하고 발버둥을 제외한다. 기존 진행은 이전 계산을 유지하며, 전투 스냅샷에 선택한 규칙을 보존한다. 여러 도구 수량과 위력, 다른 타입, 안개와 솔라빔, 실제 발버둥 전투, 저장 인코딩과 다른 슬롯을 검사했다. 다른 모든 특성·기술·도구의 보정 순서가 원본과 완전히 같다는 의미는 아니다.

관련 전투·도구·융합·챌린지 회귀는 일반 환경과 Worker 로더에서 각각 202/202 통과했다. 타입 검사와 프로덕션 빌드도 통과했다. 전체 테스트와 실계정 플레이는 이번에 실행하지 않았다.
