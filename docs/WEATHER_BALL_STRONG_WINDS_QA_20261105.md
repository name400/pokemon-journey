# 강풍과 날씨볼

원본에서 날씨볼은 유효한 날씨가 있으면 기본 위력이 두 배이며 강풍에서는 노말 타입을 유지한다. 신규 도전의 `weatherBallStrongWindsRule: source-v1`은 강풍에서 빠져 있던 위력 보정을 전투에 적용하며 날씨볼의 AI 피해 추정에도 반영한다. 기존 도전은 이전 위력을 유지한다.

격리 전투에서 아군·상대의 피해, 강풍·안개·무날씨 비교, AI의 기절 후보 선택, 저장 복원 및 다른 저장 데이터 보존을 확인했다. 메가솔과 패시브 메가솔, 특성 억제, 날씨부정, 날씨볼에서 파생된 다이맥스 기술이 보정을 잘못 중첩하지 않는지도 검사했다.

남은 범위: 다른 날씨와 모든 타입 변경 특성·특수 기술 조합, 원본 AI의 전체 대상·교체·난수 동등성 및 실제 브라우저 플레이는 별도 구현·검증이 필요하다. 운영 데이터와 Sites는 변경하지 않았다.
