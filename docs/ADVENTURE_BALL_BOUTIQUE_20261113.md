# 볼 부티크

[볼 위치·가격 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Legends-Z-A/poke-balls.html)는 오토널 애비뉴의 볼 부티크와 특수 볼 가격을 설명한다. 기존 루주 3번지 초안의 부티크 표식에서 현재 포획 엔진이 지원하는 힐볼 300원, 네트볼·다크볼·타이머볼·퀵볼 각 1,000원, 럭셔리볼 3,000원을 구입할 수 있다. 메뉴는 수량별 합계를 표시한다. 건물 좌표·외형과 접근은 기존 지도 초안이며 원작의 정확한 좌표나 실내를 재현한 것은 아니다.

원작 부티크의 네스트볼·다이브볼·리피트볼·프레미어볼과 10개 구입 시 프레미어볼 지급은 현재 포획·재고 체계에 연결되지 않아 구현하지 않았다. 이 목록 전체가 완성된 것은 아니다. 기존 포켓몬센터의 구형 판매 경로는 유지한다.

서버는 정확한 표식과 전투·포획·통신 상태, 상품·수량, 종류별 99개 한도, 지갑 잔액과 리비전을 확인하고 볼 재고·대금을 함께 저장한다. 기존 저장이나 보유 볼을 변환하지 않는다. 격리 SQLite API에서 수량·가격, 잔액 부족, 한도, 엉뚱한 위치, 재접속과 중복 요청을 확인했다. 지도·빠른 이동·예측 회귀 32개, 상점 지도 4개와 타입 검사가 통과했다. PC·모바일 Chromium은 모의 API를 사용했다. 운영 D1·원작 기기 및 Sites 병합본은 검사하지 않았다.
