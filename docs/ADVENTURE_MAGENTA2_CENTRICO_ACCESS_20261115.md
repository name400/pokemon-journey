# 마젠타 2번지와 센트리코 광장 지상 접근

[마젠타 2번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/magenta-sector-2.html)는 남동쪽 센트리코 광장 접근을, [센트리코 광장 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/centrico-plaza.html)는 북서쪽 마젠타 2번지 접근을 설명한다. 기존 지도에는 두 화면 사이의 직접 지상 경로가 없었다.

기존 지상 화면에 왕복 접근을 추가했다. 출입 좌표와 길의 폭·선형은 원작에서 측정되지 않은 2D 추정이다. 기존 오토널 대로·마젠타 거리와 구역 7 진입 제한, 카페·연구소 미션을 유지한다. 기존 통행 칸을 막지 않으며 저장 형식과 미션 진행 상태를 바꾸지 않는다.

대표 단위 검사에서 양방향 이동·구형 저장 복원, 카페 진입 상호작용, 기존 도로와 구역 7 제한을 확인했다. 원작 실기·운영 D1·실제 Sites 병합본은 확인하지 않아 모바일 이동 오류와 배포 검사 실패 기록을 유지한다.
