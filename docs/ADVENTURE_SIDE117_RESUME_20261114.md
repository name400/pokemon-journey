# Josée 수련 복원과 의뢰 안내

사이드 미션 117의 대련을 이미 마쳤거나 우두머리와의 전투를 끝낸 저장에서 상위 미션 39 시작 기록이 없으면 서버는 다음 전투·보상을 허용하지만 도장 대화에서 선택할 수 없었다. 명시적인 117 단계 1·2가 있으면 도장 대화를 복원한다. 새 대련은 여전히 미션 39 시작이 필요하며, 우선순위가 높은 진행 중인 미션 19·118 대화와 보상 지급·중복 방지는 유지한다. 저장을 소급 수정하거나 누락된 완료를 추정하지 않는다.

이미 시작한 117·118은 저장된 단계에 맞춰 여행 수첩에 다음 목표를 표시하고 추적할 수 있다. 완료 후에는 메인 목표로 돌아간다. 안내는 현재 게임의 2D 경로에 맞춘 텍스트이며 원작의 지도 좌표가 아니다. 격리 SQLite API에서 구형 단계의 전투·기권·재접속·보상·오래된 요청 거절과 목표 추적을 확인했다. 단계별 안내와 기존 이동 예측도 대표 검사했다. 실제 운영 저장·Sites 병합본·원작 실기는 확인하지 않았다.
