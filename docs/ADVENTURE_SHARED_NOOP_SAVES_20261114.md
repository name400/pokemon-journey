# 탐험의 월드 전용 요청과 공유 보유함

기존 탐험 API는 일부 요청에서 응답 패치를 제공하려고 변경되지 않은 선두 포켓몬도 공유 보유함에 다시 저장했다. 요청을 읽은 뒤 다른 모드가 같은 개체를 갱신하면 이동 지점 선택이나 방향 전환만으로 그 갱신을 덮어쓸 수 있었다.

기존 응답에 선두 개체를 포함하는 조건은 유지하고, 실제 데이터가 바뀐 경우에만 보유함에 기록한다. 기존에 명시적으로 변경 처리한 걸음 수·회복·진화·전투 등은 원래 기록 경로를 유지한다. 이동·회피·방향 전환의 빠른 경로에 추가 개체 직렬화는 하지 않는다. 기존 저장을 이주하거나 공유 개체를 일괄 수정하지 않는다.

격리 SQLite API에서 방향 전환과 지도 이동 직전 다른 모드의 개체 변경을 모의해 보존과 최신 응답을 확인했고, 실제 걸음 수와 회전 저장, 민트·파티 회복·구형 지도 이동을 대표 검사했다. 실제 쓰기가 필요한 이동·전투와 다른 모드 간의 동시 개체 수정 전체를 해결하거나 검증한 것은 아니다. 운영 D1·실기·Sites 병합본은 미검증이다.

## 실제 개체 변경의 요청 중 경합

걸음·회복·도구·전투 등에서 개체를 실제로 저장할 때도 요청이 읽은 공유 보유함 행의 데이터·소유자·출처가 커밋 순간과 일치해야 한다. 검사와 월드·아이템·지갑·개체 저장은 같은 D1 배치에서 수행해, 다른 모드가 그 사이 개체를 바꾸면 해당 요청 전체를 거절한다. 이동 충돌은 기존 이동 충돌 코드로 보고해 다시 불러온 뒤 재시도할 수 있다. 구형 저장 데이터는 소급 변경하지 않는다. 기존 배치 안에서 기본키 조회 조건을 추가하며 별도 네트워크 왕복은 만들지 않는다. 실제 운영 이동 속도는 측정하지 않았다.

격리 SQLite API에서 이동, 이상한사탕, 두 마리 회복 도중 다른 모드의 수정이 발생하면 위치·재고·다른 개체까지 변경되지 않고 재시도는 성공함을 확인했다. 기존 도입 배틀과 동료 전투·저장 복원도 대표 검사했다. 이 검사는 개별 요청이 읽은 뒤 커밋하기 전의 충돌을 보호하며, 이미 진행 중인 배틀 스냅샷이 만들어진 뒤 다른 모드에서 개체가 바뀐 모든 경우까지 보호한다고 보장하지 않는다. 운영 D1·실기·Sites 병합본은 미검증이다.

## 새 전투의 턴 사이 공유 개체 변경

새 전투는 플레이어 소유 참가 개체의 공유 보유함 데이터와 출처에 대한 SHA-256 지문을 저장한다. 전투 시작을 저장할 때 참가 개체가 바뀌면 시작을 거절하고, 이후 요청마다 직전 커밋의 지문과 현재 개체를 비교한다. 서로 다르면 전투 명령을 거절해 이전 스냅샷으로 새 개체 데이터를 덮지 않는다. 이때 기권하면 전투·연속 식당 진행을 안전하게 중단하고 보유 개체·재화·진행 보상을 건드리지 않아 다시 도전할 수 있다. 플레이어 소유 ID만 지문에 포함하며 동료 포켓몬은 포함하지 않는다.

직전 커밋에 이미 참여한 구형 전투는 지문을 소급해 만들지 않고 기존 규칙을 유지한다. 알 수 없는 미래 지문 형식도 변경하지 않는다. 지문 계산은 전투 요청에만 수행하며 일반 이동에는 추가하지 않는다. 격리 API에서 전투 시작 직전 경합, 턴 사이 변경·재접속·기권·재도전, 동료 소유권, 단일·다수·세 자리 전투와 구형 저장을 대표 검사했다. 실제 운영 D1, 실기 및 운영 속도는 검증하지 않았다.

## 사라진 파티의 복구

다른 모드에서 선두 개체의 소유권이 이동해 탐험에서 찾을 수 없으면, 진행 중인 전투는 안전하게 중단하고 남아 있는 싸울 수 있는 보유 개체로 파티를 재편성할 수 있다. 지문이 없는 구형 전투에서 저장된 플레이어 참가 개체가 사라진 경우에도 전투를 중단할 수 있으며 동료 개체는 소유 참가자로 취급하지 않는다. 새로운 파티 개체는 커밋 시 소유권과 내용이 그대로인지 다시 확인한다. 포획 기회와 미처 선택하지 않은 기술은 유지한다. 보유함에 싸울 수 있는 개체가 없으면 새 개체를 만들지 않는다.

격리 API에서 소유권 이동, 새 전투와 구형 전투의 중단, 보유 개체 선택 중 경합과 재시도, 재고·미처리 선택 보존을 검사했다. PC·모바일 화면은 모의 API로 중단부터 도입 화면 복귀까지 확인했다. 실제 두 사람의 동시 접속과 운영 D1, Sites 병합본은 검증하지 않았다.
