# 사이드 미션 77: 입치트를 잡아라

[의뢰 자료](https://www.serebii.net/legendsz-a/sidemissions/catchmawileifyoucan.shtml)와 [공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_61-80#Side_Mission_077:_Catch_Mawile_If_You_Can)을 참고해 미션 26 시작 후 Réu에게 의뢰를 받고 북서 비계에서 Lv.52 입치트를 포획한다. 직접 포획과 쓰러뜨린 뒤 포획 기회가 모두 가능하며 단순 격파·도주·기권은 완료로 세지 않는다. 포획 후 Réu에게 1,900원과 하이퍼볼 20개를 받는다.

볼 공간 또는 지갑 한도가 부족하면 보상을 보류하고, 기존 월드 리비전으로 중복 수령을 거절한다. 이미 저장된 출현·포켓몬·의뢰는 소급 수정하지 않는다. 수첩에서 진행 단계별 비계 목적지를 표시한다. 입치트와 의뢰인의 정확한 좌표는 기존 2D 맵의 초안이며, 포획 확률·실시간 장면과 기술은 기존 엔진을 사용해 원작의 세부 동작을 재현했다고 확인한 것은 아니다.

격리 SQLite API에서 의뢰 해금, 구역 9 상층에서 북서 비계 이동, 격파 후 미완료, 직접 포획 및 쓰러뜨린 뒤 포획 기회, 재접속·보상 한도·중복 요청과 기존 파트너 보존을 검사했다. 단계별 목적지 표식도 단위 검사했다. 실기·운영 D1·Sites 병합본과 PC·모바일 화면은 확인하지 않았다.
