# 러스트단 사무소 내부 시각 개선

[Poképédia의 사무소 설명](https://www.pokepedia.fr/Agence_D%C3%A9rouillard)은 검은 대리석 통로와 책상, 대나무, 검고 흰 자갈의 배틀 코트 및 붉은 벽을 설명한다. 이를 참고해 기존 `rustOffice`의 책상 타일을 풀 장식 대신 책상으로 그리고, 대나무·인물·흑백 코트와 어두운 통로를 별도의 공간으로 표현했다. 이미지나 원작 로고는 복사하지 않았다.

현재 게임의 한 화면은 원작의 층별 공간을 압축한 초안이다. 코트와 책상의 상대 위치, 인물·가구의 정확한 형태와 방의 크기는 원작 재현이 아니다. 지도 셀, 출입구·상호작용·충돌과 저장 좌표는 바꾸지 않았다.

Chromium의 390×844 모바일 및 1280×850 PC 크기에서 격리 상태를 렌더링해 확인했다. 테스트 포켓몬과 모의 API를 사용했으며 외부 포켓몬 이미지는 대체 응답이다. 사무소 API 진행과 저장, 안뜰·옥상 출입의 대표 검사를 통과했다. 실제 운영 계정과 기기는 검사하지 않았다.
