# 루주 6번지의 파르빗 의뢰

[Serebii 의뢰 자료](https://www.serebii.net/legendsz-a/sidemissions/abigol%27bunnelby.shtml)는 Emma를 도운 뒤 루주 6번지에서 Trevelle의 이야기를 듣고 야생 구역 밖 골목의 레벨 10 우두머리 파르빗을 배틀하거나 잡는다고 설명한다. 기존 루주 6번지 초안에 의뢰인과 골목 상호작용을 연결했다. 두 칸은 원래 막힌 건물 전면이었고 출입문·묘지 접근로·홀로베이터는 바꾸지 않았다. 두 위치를 같은 2D 화면에 표현한 것은 근사이며, 원작의 정확한 타일과 골목 형상은 확인하지 못했다.

이미 시작한 저장을 위해 기존 야생 구역 3의 의뢰인과 배틀 지점도 유지한다. 두 경로는 같은 의뢰 단계·전투와 리비전을 사용해 중복 보상을 만들지 않는다. 기권·도주 후 재도전과 기존 구역 3 보고도 유지한다.

격리 SQLite API에서 루주 6번지의 도보 접근·의뢰 수락·도주 후 재도전·포획·보고·재접속·중복 요청 및 기존 구역 3 진행을 확인했다. 묘지 연결과 미션 23 홀로베이터 회귀도 확인했다. PC·모바일 Chromium은 모의 API로 대화·의뢰 시작·새로고침을 확인했다. 원작 기기·운영 D1과 Sites 병합본은 검증하지 않았다.
