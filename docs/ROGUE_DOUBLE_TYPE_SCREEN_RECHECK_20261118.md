# 더블 전투 복수 타입 표시 재검사 — 2026-11-18

전용 포트의 소유권을 확인한 격리 Vite 서버와 Chromium에서 포켓로그 더블 전투의 아군·상대 각 두 HUD를 검사했다. 실제 BattlePanel과 컨트롤러 생성 시험 상태를 사용하며 외부 포켓몬 이미지는 대역이다. 1280×800, 390×844, 320×568 세 크기에서 리자몽의 불꽃·비행과 누리레느의 물·페어리 배지가 각각 양쪽에 두 개씩 표시되고 화면 안·각 HUD 안에서 서로 겹치지 않는지 확인했다. 실제 포켓로그 화면 경로의 새로고침 뒤에도 네 HUD와 시험 저장이 유지됐으며 세 화면이 통과했다.

별도의 BattlePanel 배치 검사에서는 1280×800, 375×667, 320×568 각각에서 단일·더블 기본 타입, 일반 테라, 스텔라 및 현재 타입 변경의 15가지 배치를 검사했다. 네 HUD의 타입 배열·표시·양수 크기·화면 및 HUD 안 위치·배지 간 비중첩과 이름 폭을 확인했다. 이 중 테라·스텔라·현재 타입 변경은 표시용 시험 데이터를 직접 수정한 사례로, 실제 더블 전투 변신 명령·저장 복원 검사가 아니다.

이번 표본에서 복수 타입 누락이나 가림은 재현되지 않아 게임 코드는 수정하지 않았다. 실제 기기·다른 종과 크기·스프라이트 자산·운영 저장은 확인하지 않았다. 운영 및 다른 시험 서버를 건드리지 않았고 Sites에도 배포하지 않았다.
