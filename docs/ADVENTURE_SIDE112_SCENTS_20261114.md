# 사이드 미션 112 — 슈쁘의 향기

[의뢰 공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-112-exploring-the-scents-of-spritzee)에 따라 메인 미션 37 이후 마젠타 거리의 Sente에게 의뢰를 받고 버치열매 20개, 토망열매와 오카열매 각 5개를 건네면 4,000원·조심민트 3개·경험사탕 L을 받는다. 제출과 보상 대기는 별도로 저장하므로 가방이 가득 차도 이미 건넨 열매의 보상이 사라지지 않는다.

기존 구역 8의 가판대에서 토망열매와 오카열매를 살 수 있지만 버치열매 20개를 정상적으로 모으는 반복 구매 경로가 빠져 있었다. [원작 가판대 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Legends-Z-A/berry-stalls.html)에 기록된 마젠타 거리 기본 열매 판매를 추가해 버치열매를 개당 80원에 구매할 수 있다. 같은 가판대의 기본 열매 여섯 종류도 같은 가격으로 판매한다. 마젠타 거리의 가판대와 Sente의 정확한 칸은 기존 2D 지도에 맞춘 초안이다.

서버에서 재고·자금·가방 한도와 리비전을 원자적으로 검사한다. 격리 API에서 세 열매를 실제 가판대에서 구매하고, 제출 직전 재고 변경에 따른 부분 차감 방지, 재접속·중복 요청·보상 한도와 파티 속성 보존을 확인했다. 기존 저장과 상점 구매 형식은 유지한다. 원작 기기·운영 D1·Sites 병합본과 세부 상인 좌표는 미검증이다.
