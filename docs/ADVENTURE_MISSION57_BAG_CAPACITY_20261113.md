# 미션 57 보상 보관

[원작 의뢰 목록](https://bulbapedia.bulbagarden.net/wiki/Task_(Legends:_Z-A))은 Hérup과의 전투 뒤 4,500원과 불꽃의돌·목탄 각 하나를 보상으로 기재한다. 기존 구현은 두 도구 중 하나라도 999개면 전투를 시작하지 못했다.

전투 자체는 가방 한도와 관계없이 시작한다. 승리하면 기존 전투 상금과 의뢰금, 승리 기록은 같은 저장에 반영하고, 공간이 있는 도구부터 지급하며 나머지만 Hérup에게 보관한다. 가방 공간을 확보해 같은 인물에게 말하면 남은 도구를 나누어 받을 수 있다. 중복 요청은 기존 리비전 조건으로 거부한다. 패배·기권은 완료와 보상 대기를 만들지 않으며, 기존 완료 저장에는 지급 여부를 추측해 새 보상을 만들지 않는다. 별도 보관은 이 게임의 999개 제한을 처리하기 위한 근사이며 원작의 UI 규칙이 아니다.

격리 SQLite API에서 가방이 가득 찬 상태의 전투·기권·재도전·승리, 도구별 분할 수령, 기존 재화와 파티, 재접속·중복 요청을 확인했다. 미션 22의 같은 장소 선택지 및 이미 끝낸 구형 저장도 검사했다. 원작 실기, 운영 D1과 전체 자연 진행은 확인하지 않았다.
