# 마젠타 7번지 안뜰 랄토스

[포획 안내](https://www.powerpyx.com/pokemon-legends-z-a-ralts-location/)는 마젠타 7번지 건물 사이 정원에서 낮과 밤에 랄토스가 나온다고 설명한다. [별도 공략](https://www.destructoid.com/how-to-find-ralts-and-evolve-it-to-gardevoir-in-pokemon-legends-z-a/)은 해당 구역 입구의 덤불을 불꽃 기술로 치우는 경로를 설명한다. [종별 자료](https://rotomlabs.net/dex/legends-z-a/ralts)는 이 구역의 레벨 범위를 12~24로 기재한다. 모두 2차 자료이며 원작 실기는 확인하지 않았다.

기존 북쪽 안뜰이 열린 뒤 랄토스와 조우할 수 있도록 기존 도시 야생 조우·전투·이로치·재출현 처리에 연결했다. 좌표와 고정 레벨 12, 항상 보이는 단일 개체 및 기존 시간·구역 이탈에 따른 재출현은 턴제 초안이며 원작 출현 확률·정확한 위치·레벨 분포를 재현한 것은 아니다. 우두머리 출현과 실제 이동·도주 동작은 구현하지 않았다. 기존 안뜰에 저장된 좌표를 막지 않는 통행 가능 표식을 사용하며 베르 4번지 랄토스의 기록과 독립적으로 저장한다.

닫힌 입구 차단, 저장 좌표·이로치 기록, 조우 소비와 재출현, 전투 재접속 및 기존 구역 출입을 대표 검사했다. 운영 Sites·모바일 D1 오류는 재검증하지 않았고 실패 기록을 유지한다. 북쪽·남쪽 옥상의 상세 지형과 나머지 도구는 미완성이다.
