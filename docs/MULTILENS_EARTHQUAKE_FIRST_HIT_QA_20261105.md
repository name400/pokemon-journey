# 멀티렌즈 지진 첫 타격

고정 원본의 지진은 모든 인접 상대와 아군을 대상으로 하며 대상별 추가 상태 이상이 없다. 신규 도전의 멀티렌즈 지진 첫 타격은 상대를 먼저, 아군을 나중에 처리하고 각 대상에게 실제 피해를 적용한 뒤 다음 대상의 전체 공격 보정을 계산한다. 기존 `swift-source-v1`·`simple-spread-v1`·`surf-source-v1` 저장의 대상 범위는 유지한다.

격리 테스트에서 상대 둘의 기절 뒤 아군 피해, 방어·부유·기합의머리띠로 상대가 생존하는 경계, 그래스필드, 적 측 사용, 실제 턴과 codec 복원·다른 데이터를 확인했다. 이는 첫 타격 피해 적용 순서의 부분 지원이며 땅속 상태·모든 특성/도구 후속 효과와 원본 난수열, 다른 전체 공격·실사용·실기기는 별도다.
