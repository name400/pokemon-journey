# AI 환영 자속 판정

원본 `Pokemon.getMatchupScore`는 자신의 기술 자속 여부를 실제 타입으로 판정한다. 교체 점수 계산에서 환영으로 위장한 포켓몬의 표시 타입을 자신의 자속으로 사용하던 차이를 수정했다. 신규 도전에 `enemyAiIllusionStabRule: source-v1`을 설정하며, 기존 저장은 이전 판정을 유지한다.

순수 점수의 자속 양쪽 경계와 환영을 가진 트레이너의 실제 자발 교체, 전투 직렬화 복구, 새 도전 생성과 다른 저장 슬롯 보존을 격리 검사했다. 이 변경은 자신의 자속 계산만 다룬다. 상대 환영·테라스탈의 방어 상성 및 AI의 나머지 대상·교체·난수 동등성은 별도 확인이 필요하다. 운영 저장과 Sites는 변경하지 않았다.
