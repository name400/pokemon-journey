# 미르미술관 히스이 전시

[원작 미술관 자료](https://bulbapedia.bulbagarden.net/wiki/Lumiose_Museum)는 북쪽 큰길의 미술관 2층에 히스이 특별전이 있으며 지역 지도, 수제 몬스터볼과 공작대가 전시된다고 설명한다. 기존 미술관의 계단과 양쪽 관람 경로를 유지하면서 2층에 이 세 전시를 서로 다른 그림과 설명으로 배치했다. 전시를 바라보면 내용을 읽을 수 있다.

전시 타일은 통행을 막지 않으며, 기존 층별 출입과 사이드 미션 21의 열두 분떠도리 위치 및 기록을 유지한다. 세 전시의 화면 좌표·실물 형태와 세부 실내 구조는 2D 추정이다. 원작 건물의 정확한 전시 동선과 실제 운영 기기는 확인하지 않았다.
