# 사이드 미션 92 보상 보관

[원작 의뢰 목록](https://pokemongohub.net/post/guide/legends-z-a-all-side-missions/)에는 홀로베이터 주변의 메탕 네 마리를 쫓아낸 뒤 3,000원과 울퉁불퉁멧, 풀회복약을 받는다고 나온다. 기존 게임에서 도구 보유량이 상한이면 보상 전체를 받을 수 없었고, 특히 풀회복약이 99개일 때는 저장 충돌로 표시됐다.

승리 후 첫 보상 요청에서 코인은 한 번 지급하고 각 도구는 공간이 있는 것만 지급한다. 남은 도구는 같은 홀로베이터에서 나중에 받을 수 있다. 기존 리비전·재고 검사로 중복 수령과 경합을 거절하며, 이미 보상 수령을 마친 구형 저장에 새 보상을 만들지 않는다. 나누어 보관하는 방식은 이 게임의 보유량 제한을 위한 처리이며 원작 UI와 같다고 확인한 것은 아니다.

격리 SQLite API에서 두 도구가 가득 찬 상태, 재접속, 재화 한 번 지급, 도구별 수령, 오래된 요청 거부와 완료된 구형 저장을 검사했다. 원작 기기·운영 D1·Sites 병합본은 검사하지 않았다.
