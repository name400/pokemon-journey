# 사이드 미션 48: 거미줄 구조

[의뢰 자료](https://www.serebii.net/legendsz-a/sidemissions/alltiedup.shtml)에 따라 미션 19 시작 뒤 루주 5번지에서 거미줄에 묶인 사람을 만난다. 선두 포켓몬이 아는 위력 100 이상의 기술로 구조하고 1,500원과 네트볼 10개를 받는다. 원작은 기술의 기본 위력을 사용하며, 이 구현은 현재 게임의 필드 기술 데이터에 등록된 위력을 사용한다. 게임 데이터와 원작 수치가 다른 기술은 별도 대조가 필요하다.

기존에 막혀 있던 칸에 구조 지점을 두어 보행과 저장 위치를 보존한다. 정확한 나무 좌표와 정지 상호작용은 2D 초안이다. 볼을 모두 받을 공간이 없으면 보상을 보류하고 리비전으로 중복 수령을 막는다. 포켓몬의 기술·PP와 보유 데이터는 변경하지 않는다. 원작 실기·운영 D1·Sites 병합본은 검증하지 않았다.
