# 야생 구역 9 북쪽·서쪽 비계

- [Nintendo Life](https://www.nintendolife.com/guides/pokemon-legends-z-a-wild-zone-9-guide-all-pokemon-and-alphas)는 북서쪽 사다리와 우두머리 썬더볼트가 있는 옥상을 설명한다.
- [Pokémon France](https://www.pokemon-france.com/en/guides/pokemon-legends-z-a/wild-zones/)는 북쪽 비계의 하이퍼볼·힐볼, 서쪽 비계의 금구슬·큰진주·리보플라빈·타이머볼·이상한사탕을 열거한다.
- 북쪽과 서쪽을 잇는 연속 발판, 옥상 연결 지점, 정확한 타일과 높이는 자료로 확인하지 못한 2D 초안이다. 기존 북쪽 힐볼은 중복 배치하지 않았다. 이상한사탕은 탐험 모험에서 사용 기능이 준비되지 않아 추가하지 않았다.
- 새 비계는 별도 저장 구역이며 기존 옥상 좌표, 남쪽 비계, 구역 9 포켓몬과 아이템 수령 기록을 유지한다. 기존 옥상에서 막혀 있던 두 칸을 출입구로 사용한다.
