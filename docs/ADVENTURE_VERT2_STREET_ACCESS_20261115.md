# 베르 2번지와 베르 거리 연결

[베르 2번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-2.html)는 북동쪽 베르 거리 접근을, [베르 거리 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-street.html)는 서쪽 베르 2번지 접근을 설명한다. 모두 2차 자료다.

기존 지상 화면에 왕복 접근을 추가했다. 정확한 접점과 방향은 압축된 2D 지도의 잠정 배치이며, 별도 옥상에서는 이 출구를 사용하지 않는다. 미션 3 바위 우회 중 새 연결을 양방향 차단해 기존 진행을 보호한다. 이 차단은 현 게임 구조를 위한 처리로 원작의 정확한 도로 차단 위치는 확인되지 않았다. 구역 2 출입, 구역 11·17 제한, 기존 위치와 저장 형식은 유지한다.

모바일 이동 오류와 Sites 병합본 실패 기록은 운영 재검증 전이므로 유지한다.
