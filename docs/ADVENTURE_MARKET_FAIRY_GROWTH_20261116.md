# 블루 5 시장의 슈쁘·나룸퍼프 성장 기술

실제 구현의 블루 5 노점에는 일반 슈쁘와 나룸퍼프가 출현하지만 ZA 전용 성장표가 없어 기존 공용 표를 사용했다. [슈쁘](https://rotomlabs.net/dex/legends-z-a/spritzee), [프레프티르](https://rotomlabs.net/dex/legends-z-a/aromatisse), [나룸퍼프](https://rotomlabs.net/dex/legends-z-a/swirlix), [나루림](https://rotomlabs.net/dex/legends-z-a/slurpuff)의 ZA 레벨 기술을 확인하고, [슈쁘](https://bulbapedia.bulbagarden.net/wiki/Spritzee_%28Pok%C3%A9mon%29)와 [나룸퍼프](https://bulbapedia.bulbagarden.net/wiki/Swirlix_%28Pok%C3%A9mon%29) 자료와 대조했다. 현재 접근 가능한 두 자료는 2차 출처이며 원작 실기는 검증하지 않았다.

신규 일반 조우에만 성장 표식을 넣어 레벨 상승·다시 배우기와 두 진화형까지 같은 계열의 기술표를 사용한다. 진화 시 별도 기술은 확인되지 않아 임의로 추가하지 않는다. 기존 포획 개체·전투, 우두머리, 알 수 없는 표식은 소급하지 않는다. 초기 기술은 이전 구현과 마찬가지로 레벨 이하 마지막 네 개를 쓰고, 같은 레벨 기술의 순서는 근사다. 시장의 고정 위치와 종은 기존 2D 초안이다.

시장 두 종의 실제 격리 API 조우·포획·재접속과 기존 의뢰 검사가 통과했다. 성장·진화형·PP·알 수 없는 표식 및 우두머리 보존 단위 검사와 기존 성장 단위 총 52건이 통과했다. 전체 검사·운영 D1·Sites 병합본은 확인하지 않았다.
