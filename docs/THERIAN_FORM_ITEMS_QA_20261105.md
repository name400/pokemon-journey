# 비추는거울 영물폼

고정 원본의 비추는거울을 토네로스·볼트로스·랜드로스·러브로스 영물폼에 연결했다. native 종과 원본 능력치 6항목이 일치하는 경우만 허용하고, 폼별 주특성과 러브로스 패시브를 갱신한다. 기존 저장의 수동 활성화와 새 저장의 도구별 활성 기록을 유지한다.

각 종별 보상 선택·활성/해제, 융합 양쪽 역할, 실제 전투 시작과 한 턴 뒤 폼, codec·분리·도구, 기존 저장과 다른 슬롯 보존을 검사했다. 러브로스 패시브의 Cloud Nine/Fairy Aura 변경 및 역변경도 검사한다. 관련 일반·Worker 각각 37/37, 타입·production 빌드 통과. 생성기 검증 및 원본 이미지 목록은 별도 생성한다. 실기기·운영과 모든 특성 조합은 검증하지 않았다. 로그 `/tmp/therian-final.log`, `/tmp/therian-worker.log`, `/tmp/therian-type.log`, `/tmp/therian-build.log`.
