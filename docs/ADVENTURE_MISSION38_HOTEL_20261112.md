# 미션 38 호텔 귀환

[원작 진행 안내](https://www.thonky.com/pokemon-legends-z-a/main-mission-38-the-future-of-lumiose-city)는 객실에서 나와 엘리베이터를 타고 동료를 만난 뒤 센트리코 광장으로 가는 순서를 설명한다. 새 타워 접근 경로를 거쳐 최종전을 끝내면 기존 Hotel Z 202호에서 시작해 로비의 동료에게 갈 수 있다. 이전 버전의 최종전 저장과 이미 시작된 미션 38 저장은 기존 로비 경로를 유지한다.

기존 202호·복도 지도와 엘리베이터를 사용하며 건물 형태와 좌표는 초안이다. 원작 엔딩 크레딧과 장면 연출은 구현하지 않았다.
