# 리테이크 카페 (Café Action!)

존느 8번지의 기존 카페 표식을 실내 출입과 음료 주문으로 연결한다. 출입구와 실내의 2D 타일 배치는 게임 내 초안이며 원작의 정확한 충돌·실내 구조를 뜻하지 않는다. 기존 거리와 야생 구역 19 출입은 변경하지 않는다.

원작의 카페 위치, 메뉴 및 가격은 [Serebii 카페 목록](https://www.serebii.net/legendsz-a/cafes.shtml), 파티 회복·선두 친밀도와 이동 지점은 [Bulbapedia Café Action!](https://bulbapedia.bulbagarden.net/wiki/Caf%C3%A9_Action%21) 및 [Lumi Cab](https://bulbapedia.bulbagarden.net/wiki/Lumi_Cab)을 참고했다. 정확한 친밀도 증가량은 확인되지 않아 기존 카페의 +1을 재사용하며, PP 회복과 택시 요금도 기존 게임 체계를 따른다. DLC 사이드 미션 175는 이 변경에 포함되지 않는다.

주문은 기존 지갑과 파티 저장을 사용하고 리비전 검증으로 중복 요청을 차단한다. 기존 저장을 선제적으로 변경하지 않으며, 방문 시 기존에 알 수 없는 이동 지점도 그대로 보존한다.
