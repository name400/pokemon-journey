# 마젠타 9번지와 18번 구역 접근

[18번 구역 자료](https://bulbapedia.bulbagarden.net/wiki/Wild_Zone_18)는 마젠타 9번지 및 북쪽 큰길에 걸친 구역과 고층 건물 사이의 골목·비계를 설명한다. [현장 안내](https://www.nintendolife.com/guides/pokemon-legends-z-a-wild-zone-18-guide-all-pokemon-and-alphas)는 지상과 옥상 접근, 풀밭과 비계 골목을 구분한다.

기존 마젠타 9번지의 동서 거리와 남쪽 비계 접근을 기존 통행 가능한 칸에 포장으로 표시하고, 기존에 막혀 있던 두 건물의 지붕·창문과 사다리 외형을 구분했다. 기존 출입구, 충돌, 해금 및 저장 위치는 바꾸지 않는다. 원작에서 확인된 것은 지역과 골목·비계의 관계이며, 두 건물의 외형과 압축된 2D 도로·건물 좌표는 재구성한 초안이다. 실제 건물 외관이나 지도 축척이 원작과 같다는 의미는 아니다.

격리된 시험 데이터로 PC·모바일 브라우저 화면을 확인했다. 원작의 정확한 높낮이와 건물 배치, 실제 운영 기기 확인은 남아 있다.
