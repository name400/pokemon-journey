# 사이드 미션 16: 꼬몽울 쇼

[원작 공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-016-the-budew-show)에 따라 미션 7부터 베르날 포켓몬센터 부근의 Jardin에게 초대받고, 블루 8번지에서 파티에 꼬몽울을 넣고 5,800원을 내면 쇼에 참가한다. 이후 질문에 어떤 답을 고르든 10,000원과 기적의씨를 한 번 받는다. 기적의씨 가방이 가득 차면 코인은 지급하고 도구는 접수처에 보관한다.

참가비 지불과 쇼 진행·보상은 각각 리비전 조건으로 저장하므로 재접속이나 중복 요청으로 참가비와 보상이 반복되지 않는다. 참가한 꼬몽울은 파티에 남고 상태를 변경하지 않는다. 기존 통행 불가 벽에 인물을 배치해 저장 위치와 이동 경로를 보존한다. 두 장소의 타일과 쇼의 단일 질문은 이 게임의 2D 표현이며, 원작의 정확한 무대·모든 질문과 연출을 재현한 것은 아니다.

격리 API에서 참가 조건·자금 부족·실제 접수 접근·참가비·재접속·가방 한도·중복 보상과 파티 보존을 확인했다. 원작 실기·운영 D1·Sites 병합본은 확인하지 않았다.
