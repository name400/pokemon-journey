# 메리프·후반 의뢰 추적

진행 중인 사이드 미션 17의 메리프 관찰과 명시적인 보상 대기를 여행 수첩에서 추적할 수 있다. 현재 구역이 맞으면 높은 옥상의 메리프 또는 베르 9번지의 Duve를 가리키며, 보상 수령 후에는 메인 목표로 돌아간다. 완료한 의뢰에서 선택적으로 가능한 메리프 포획은 별도의 야생 조우로 남는다.

이미 수첩에 연결된 117·118도 도장 출입구·대화 상대, 호텔 앞, 수로, 갤러리의 현재 단계 상호작용에 표식을 표시한다. 도장에서 다른 진행이 같은 대화 상대를 우선 점유하면 117 표식을 숨긴다. 표시할 때만 저장된 단계와 기존 맵 타일을 읽으며 위치·보상·이동 판정을 변경하지 않는다. 위치는 기존 2D 맵의 좌표로 원작 지형 좌표가 아니다.

격리 SQLite API에서 메리프 관찰·의뢰 추적·재접속·수령·중복 거절과 118의 수로·갤러리 진행을 검사했다. 단위 검사에서 각 단계, 다른 층·대화 우선순위·완료 및 이동 예측을 확인하고 PC·모바일 Chromium의 모의 API로 메리프 표식과 완료 후 복귀를 확인했다. 실제 운영 저장·Sites 병합본·원작 기기는 검사하지 않았다.
