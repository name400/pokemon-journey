# 야생 구역 8 원형 광장의 외곽

[존느 광장 자료](https://bulbapedia.bulbagarden.net/wiki/Jaune_Plaza)는 광장이 둥글고 중앙 대부분에 야생 구역 8이 있다고 설명한다. 별도로 전달된 원작 지도·3D 화면 분석에는 대체로 평탄한 원형 외곽과 중앙 모래 원, 서남서·동북동의 두 입구가 보인다. 원본 이미지는 이번 환경에서 직접 확인하지 못했다.

기존 사각형 바깥쪽의 빈 바닥 36칸에 통행 불가 경계와 녹지 표현을 넣어 원형 광장의 모서리를 좁혔다. 주 출입구 두 곳과 종전 호환 출입구들, 노점·흙더미·아이템·기존 조우 지형은 유지한다. 새 경계와 녹지의 정확한 모양·재질·충돌선은 원작에서 확인하지 못한 2D 추정이다. 원작에 해당 경계가 같은 위치에 있다고 주장하지 않으며 원작의 평탄한 지형에 임의의 층이나 수역을 넣지 않았다.

신규 경계에 있던 구형 위치는 저장 리비전이 일치할 때 가까운 보행 칸으로 옮기며 포켓몬·재화·아이템·흙더미와 소진 기록은 유지한다. 새 저장에는 별도 레이아웃 표식을 기록한다. 일치하지 않는 리비전의 복구는 기존처럼 거부한다.

변경 전후를 비교해 바뀐 36칸이 모두 일반 바닥인 것을 확인했다. 구역 검사에서 모든 변경 칸의 구형 저장 복원과 중앙·일곱 기존 출입 접근을 확인했고, 격리 SQLite API에서 구형 저장·재접속·출입 왕복, 중앙 노점과 흙더미 조우를 대표 검사했다. PC·모바일 Chromium은 모의 API와 대체 이미지를 사용했다. 원작 실기·운영 환경과 실제 Sites 병합본은 검사하지 않았다.
