# 물거품아리아 대상별 화상 해제 순서

고정 원본 `7c0881255af5cd51992e513ff93c2f71adbe40e0`의 [기술 정의와 화상 해제 속성](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/data/moves/move.ts#L3218) 및 [대상별 공격 처리](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/phases/move-effect-phase.ts#L269)를 대조했다. 원본은 각 명중 대상에 마지막 타격의 효과를 적용한 뒤 다음 대상을 처리한다.

기존 엔진은 모든 대상에게 피해를 준 뒤 화상을 해제했다. 새 도전의 `sparklingAriaOrderRule: source-v1`에서는 대상별 마지막 타격 직후 기존 부가 효과 판정을 수행하고 화상을 해제한다. 규칙이 없는 기존 저장은 기존 순서를 유지하며 저장 데이터를 일괄 수정하지 않는다. 배틀 스냅샷에도 규칙을 보존한다.

격리 엔진 검사에서 일반 공격 및 멀티렌즈의 마지막 타격 순서, 저수 면역, 방어, 인분의 단일·다중 대상, 소리 기술의 대타 관통, 우격다짐, 실제 턴 명령·저장 복원 및 다른 슬롯 보존을 확인했다. 새 검사와 기존 대상별 부가 효과 검사 35건, 별도의 기존 물거품아리아 멀티렌즈 검사 4건이 통과했다. 사용자에게 보이는 원본 전체 이벤트 순서·모든 패시브·특성 조합·실기기는 확인하지 않았다. Sites에는 배포하지 않았다.
