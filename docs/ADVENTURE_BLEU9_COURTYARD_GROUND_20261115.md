# 블루 9번지 안뜰과 지상 도구

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-9.html)는 건물 단지 안뜰의 타우린과 인접한 블루 8번지 건물 서쪽의 좋은상처약·잠깨는약을 기록한다. 자료는 2차 출처이며 원작 기기에서 확인하지 않았다. 기존 압축 지도에서 안뜰 바닥을 주변 거리와 구별하고 세 도구를 연결했다. 안뜰의 정확한 윤곽·높이, 건물 관계 및 도구 좌표는 2D 추정이다.

기존 메인 미션 20 상가 건물 표식과 출입·진행을 유지한다. 지상 저장 좌표, 도구 수령 기록, 가방 한도와 중복 요청도 보존한다. 지도와 실제 라우터 대표 검사를 통과했으며 원작 실기와 운영 Sites는 검사하지 않았다. 옥상 접근·도구의 정확한 구조는 미완성이고, 모바일 D1 이동 오류는 운영 재검증 전까지 실패 기록을 유지한다.

후속으로 [같은 지역 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-9.html)의 건물 단지 옥상 동쪽·서쪽·북쪽 도구를 별도 2D 옥상에 연결했다. 옥상에서 안뜰로 왕복할 수 있으며 동·서 구역을 구분해 표시한다. 자료는 정확한 접근 경로와 옥상 평면을 제시하지 않으므로 안뜰 계단, 좌표·형태와 구역 경계는 플레이 가능한 추정이다. 카페 솔레유 옥상은 이번 경로와의 관계가 확인되지 않아 별도로 남긴다.

구형 지상 저장·미션 20 입구·기존 수집 이력과 별도의 옥상 수집 기록을 유지한다. 격리 API에서 옥상 왕복·재접속, 아이템 수령, 가방·볼 한도, 중복 요청, 알 수 없는 미래 수집 형식과 파티 보존을 확인했다. 실제 원작 기기와 운영 Sites·모바일 이동 오류는 검증하지 않았다.
