# 뒀다쓰기의 직접 사용 이력과 변신 저장 복구

원본은 출전 중 비가상 기술 사용 이력을 기술 ID로 유지한다. 원본에 재학습 시 초기화해야 한다는 TODO가 있지만, 현재 원본 동작은 이력을 유지한다. 최신 신규 도전 `source-v2`는 직접 사용된 기술을 전투 스냅샷에 보존해 같은 출전 중 잊었다가 다시 배우거나 변신해 복사할 때에도 참조하고, 교체 후 다시 출전하면 초기화한다. 잠꼬대·따라하기의 호출 기술 자체는 직접 이력으로 기록하지 않는다. 이미 시작된 `source-v1` 도전의 재학습 초기화는 이전대로 유지해 규칙을 소급하지 않는다.

변신 후 복사한 기술 개수가 원래 기술보다 적은 전투 저장이 엔진 역직렬화에서 실패하는 별도 문제를 수정했다. 원본 저장은 변경하지 않고 복사본을 불러오는 과정에서만 임시 슬롯을 채운 뒤 즉시 제거한다. 아군의 복사 기술 1~4개, 상대의 복사 기술, 저장 데이터 불변과 전투 재개를 격리 검사했다. 기존 저장에도 복구 처리가 적용된다.

직접 이력의 재학습·변신·교체·저장 복구, 이전 규칙과 호출 기술 일부를 확인했다. 스케치·변신·호출 기술의 모든 복합 조합과 첫 턴 미행동 경계, 실제 계정 및 실기기 플레이는 아직 확인하지 않았다.

변신·호출·AI·날씨·지형·트레이너·상태·챌린지·융합·학습·스케치 관련 회귀는 일반 실행과 Worker 로더에서 각각 307건 통과했다. 타입 검사와 빌드도 통과했다. 전체 프로젝트 검사는 아니다.
