# 사이드 미션 54: 기합에너지 배틀

미션 19의 Canari 대결 후 콰자르티코의 Foco에게 의뢰를 받아 레벨 44 독침붕·샤크니아·스라크와 싸운다. 각 포켓몬의 기합에너지와 공격 기술을 반영한다. 새 전투 승리 시 2,112원, 이후 의뢰 보상으로 3,000원·초점렌즈·하이퍼볼 3개를 지급한다. 가방이나 볼 보관량이 가득 차면 보상을 보류하며 리비전으로 중복 지급을 막는다. 이미 저장된 다른 전투와 진행은 변경하지 않는다.

상대·기술은 [Serebii](https://www.serebii.net/legendsz-a/sidemissions/getenergized.shtml), 별도 전투 상금은 [트레이너 자료](https://bulbapedia.bulbagarden.net/wiki/Mission_(Legends:_Z-A)/Trainers), 의뢰 보상은 [공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_41-60)을 대조했다. 해금 시점은 자료마다 Canari 또는 Gwynn 대결 후로 달라 정확한 실기 기준이 미확인이다. 인물 좌표와 상대의 턴제 행동은 현재 2D 게임의 초안이다.

격리 API에서 해금·전투 편성·기권·재도전·재접속·상금·볼 한도·중복 수령과 초점렌즈 착용, 기존 파티 보존을 검사했다. 원작 기기·운영 D1·Sites 병합본은 확인하지 않았다.
