# 미르시티 포켓몬센터 공통 상점

[원작 센트리코 센터의 판매 목록](https://www.serebii.net/pokearth/lumiosecity/centricoplaza.shtml)과 [센터 이용 안내](https://sportsrant.indiatimes.com/gaming/pokemon-legends-za-every-pokemon-center-location-in-lumiose-city/articleshow/126645919.html)를 참고해, 현재 게임에서 실제 포켓몬센터로 식별되는 지점의 회복 대화에 기존 상점 선택지를 추가했다. 별도 상점이 없던 센트리코·프랭탕·마젠타 광장·베르·루주 광장에서도 기존 재고와 구매·판매 규칙을 이용한다. 기존 별도 상점은 유지하고, 기존 센터 타일·출입·좌표·등록 기록은 변경하지 않는다.

게임의 공통 상점 구성은 원작의 모든 센터 품목·해금 시점을 완전히 재현한 것이 아니다. 하이퍼볼 랭크 E 조건은 별도 기록의 잠정 조건이며, 자료가 충돌하는 몬스터볼 가격은 변경하지 않았다. 정확한 원작 점원 위치는 확인하지 않았다.

격리 SQLite API로 다섯 센터의 상점·회복·등록된 빠른 이동 대화, 구매·재접속·오래된 요청 거절, 대표 약 구매와 도구 판매를 검사했다. 기존 블르·마젠타 상점 및 가격·재고 검사와 각 지역·빠른 이동 대표 단위 검사도 통과했다. 실제 원작 기기, 운영 D1과 Sites 병합본은 검사하지 않았다.
