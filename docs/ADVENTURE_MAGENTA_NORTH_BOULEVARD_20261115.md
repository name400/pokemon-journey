# 마젠타 스트리트와 북쪽 큰길 연결

[마젠타 스트리트 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/magenta-street.html)는 북서쪽 끝에 북쪽 큰길이 있다고 설명하고, [북쪽 큰길 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/north-boulevard.html)도 서쪽 끝의 마젠타 스트리트를 기록한다. 두 지상 화면 사이 왕복 보행 연결을 추가했다. 출입 좌표와 길의 선형은 잠정 2D 배치다.

기존 운하의 물·다리와 운하변 접근, 야생 구역 18 해금 조건 및 저장 형식을 유지한다. 원작 실기와 실제 Sites 병합본은 확인하지 않았다. 모바일 이동 오류 기록은 운영 재검증 전까지 유지한다.
