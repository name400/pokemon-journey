# 사이드 미션 24: 캐이시의 놀이 친구

[Serebii](https://www.serebii.net/legendsz-a/sidemissions/anabraplaymate.shtml)와 [Bulbapedia](https://bulbapedia.bulbagarden.net/wiki/Task_(Legends:_Z-A))를 대조해 미션 10 동료전 이후 학교의 Bond에게 캐이시를 리오르와 교환하고 300코인과 경험사탕XS 5개를 받도록 했다. 리오르는 25레벨, Riolouie라는 교환 별명과 네 기술을 가진다. 학교의 2D 위치, 원작 대사와 연출은 초안이다. 원작의 무작위 성격과 색이 다른 모습 여부는 재현하지 않아 현재 기본 성격과 일반 색상이다.

교환은 명시적 확인을 요구한다. 지닌 도구, 소유권, 온라인 교환·대전, 가방과 지갑, 원본 변경 및 월드 리비전을 검사하고 하나의 트랜잭션으로 교환과 보상을 처리한다. 선택한 개체는 탐험에서만 제외하며 공유 보유함 원본은 보존한다. 구형 클라이언트가 이전 선두를 저장한 경우 교환받은 리오르로 복구한다. 보상 공간이 없으면 교환하지 않는다.

격리 SQLite API에서 해금, 지닌 도구·가방 한도·온라인 교환·원본 경합 거절, 선두 교체, 공유 원본 보존, 중복 요청과 재접속을 검사했다. 실기, 운영 D1, 실제 Sites 병합본은 확인하지 않았다.
