# 적 AI 타입 변경 기술의 교체 점수

고정 원본의 `Pokemon.getMatchupScore`는 `VariableMoveTypeAttr`가 붙은 공격 기술을 평균할 때 자속 보너스를 붙이지 않는다. 기존 엔진은 네이티브 `onModifyType` 유무로 추정해 맹세 3종의 원본 속성을 놓쳤다. 신규 도전은 원본의 타입 변경 속성을 가진 현재 기술 목록을 사용하며, 잠재파워 변종도 한 계열로 판정한다. 기존 도전은 이전 네이티브 판정을 유지한다.

격리 검사에서 타입 변경 기술·일반 기술 분류, 맹세가 과대평가되던 실제 싱글 자발 교체, 기절 후 싱글·더블 교체, codec 복원과 다른 슬롯 보존을 확인했다. 적 AI 전체 점수·대상·교체와 원본 난수 스트림의 완전 일치는 별도다. 목록은 고정 원본 기준이므로 원본 기술 데이터가 바뀌면 재대조가 필요하다.
