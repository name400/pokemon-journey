# 따라하기의 적 AI 판단

원본 `CopyMoveAttr`의 마지막 기술과 호출 금지 조건, 현재 Classic 따라하기 구현을 대조했다. 신규 도전의 `enemyAiCopycatRule: source-v1`은 원본 호출 정책을 사용하는 경우 복사할 마지막 기술이 없거나 호출이 금지되어 있으면 적 AI가 따라하기의 점수를 낮추도록 한다. 이전 맥스 기술의 원래 기술과 다이맥스 맥스가드는 기존 호출 경로에 맞춰 구분하며, 이전 도전은 기존 판단을 유지한다.

격리 전투와 저장 복원에서 이전 기술 없음, 허용 기술, 손가락흔들기·따라하기·발버둥의 금지, 맥스 기술의 원래 기술, 다이맥스 및 다른 저장 데이터 보존을 검사했다. 이 판단은 현재 Classic 호출 정책과 선택 시점의 기록을 따르며, 모든 호출·챌린지·상대 행동 순서와 원본 난수열 동등성은 검증하지 않았다. 실제 브라우저 플레이도 별도다. 운영 데이터와 Sites는 변경하지 않았다.
