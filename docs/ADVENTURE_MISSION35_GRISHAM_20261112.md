# Mission 35: Grisham promotion battle

[The original mission listing](https://www.serebii.net/legendsz-a/mainmissions/reachingranka.shtml) provides Grisham's six Pokémon, their levels and moves, and Charizardite X. New battles use that roster and Mega Stone. The turn-based opponent AI selects when to Mega Evolve; the original's real-time combat and Plus Moves are not represented. The existing promotion and reward rules remain unchanged.

Existing in-progress snapshots are left untouched. Isolated API and engine checks cover ticket boundaries, all six levels and representative moves, Mega Charizard X, reload, forfeiture, old snapshot restoration, victory and one-time reward. Opponents were reduced to 1 HP and put to sleep for the victory progression check, which does not validate ordinary difficulty. Original hardware and production have not been tested.
