# 라이벌 전투와 보상 전환 격리 검사

격리 SQLite와 실제 포켓로그 API·전투 엔진에서 7웨이브의 시험 저장을 만들어 `next`로 8웨이브 라이벌을 생성하고, 등장 대화·전투 명령·승리 대화·보상 건너뛰기·9웨이브 진입을 실행했다. 7웨이브까지 자연 플레이한 것은 아니며 아군은 시험용 고레벨 포켓몬이다. 라이벌과 상대 파티는 실제 웨이브 생성 코드가 만들었다.

승리 후 재조회에서 대화와 종료된 전투가 복원되고, 대화가 남은 상태의 보상 건너뛰기와 이전 리비전의 중복 요청은 저장을 변경하지 않는 것을 확인했다. 정상 대화 종료 뒤 9웨이브 진입, 라이벌 선택값과 다른 저장 슬롯·탐험 데이터 보존도 확인했다. 이전 교환권 검사에서는 시험용으로 구성한 체육관 트레이너의 실제 승리와 보상 건너뛰기 후 교환권 뽑기를 확인했다.

라이벌 API 흐름과 기존 트레이너 대화·라이벌 초상·보상 진행·고정 도구 검사 9건이 통과했다. 이 표본에서 새 결함은 재현되지 않아 게임 로직은 변경하지 않았다. 다른 라이벌 단계의 전투·모든 트레이너와 보상, 실제 운영 저장·브라우저·실기기와 200웨이브 자연 완주는 검증하지 않았다. Sites에는 배포하지 않았다.
