# 고정 최대 PP와 포인트업

고정 원본 `7c0881255af5cd51992e513ff93c2f71adbe40e0`의 `PokemonPpUpModifierType`은 기본 PP가 5 미만이거나 PP업 3단계 또는 `maxPpOverride`가 있는 기술을 포인트업 대상으로 허용하지 않는다. 기존 보상 화면과 서버는 별도의 최대 PP override를 검사하지 않아, 최대치가 변하지 않는데도 포인트업을 소비할 수 있었다.

새 도전의 `ppUpEligibilityRule: source-v1`에서 포인트업·포인트맥스 대상과 각 기술의 선택 가능 여부, 서버의 실제 사용 판정에 같은 조건을 적용한다. 이전 진행은 기존 판정을 유지한다. 명시적 최대 PP와 현재 PP는 변경하거나 삭제하지 않는다.

실제 보상 선택에서 고정 최대 PP가 있는 기술에 대한 요청을 거부하면서 보상과 전체 저장을 보존하고, 같은 포켓몬의 다른 기술에는 정상 적용되는 것을 확인했다. 별도 포켓몬, PP업·포인트맥스 양쪽, 기존 규칙과 저장 복구도 검사했다. 모든 이벤트가 제공하는 특수 PP override의 실계정 플레이는 별도다.

관련 이벤트·보상 회귀는 일반 환경과 Worker에서 각각 160/160 통과했다. 마지막 기존 규칙 보존 조정 뒤 PP 집중 검사는 두 환경 각각 17/17 통과했으며 프로덕션 빌드를 다시 통과했다. 타입 검사는 조정 전 통과했다. 전체 테스트와 실계정 플레이는 실행하지 않았다.
