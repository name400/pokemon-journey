# 베르 스트리트와 센트리코 광장 연결

[베르 스트리트 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-street.html)는 북서쪽 끝이 센트리코 광장이라고 설명하며, [광장 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/centrico-plaza.html)는 남동쪽에 베르 스트리트를 기록한다. 두 지상 화면 사이 왕복 경로를 추가했다. 출입 좌표와 길의 선형은 2D 초안이다.

기존 출입과 저장 형식, 미션 3 우회 제한을 유지한다. 원작 실기와 실제 Sites 병합본은 확인하지 않았다. 모바일 이동 오류 기록은 운영 재검증 전까지 유지한다.
