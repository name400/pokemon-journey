# 구역 6 Café Bataille 주문

[Serebii의 카페 목록](https://www.serebii.net/legendsz-a/cafes.shtml)에 표시된 Café Bataille의 11종 음료와 가격을 구역 6의 기존 카페 지점에 연결했다. 구매하면 파티의 HP·상태·PP를 회복하고 선두의 친밀도를 올린다. 친밀도 증가량 1은 기존 누보 카페 2호의 게임 규칙이며 원작의 정확한 증가량으로 확인한 수치가 아니다. 내부 구조와 필드상의 좌표는 기존 2D 초안이다.

지상 주문대 위치·전투 및 포획 대기·잔액을 확인하며, 기존 revision 및 원자적 커밋을 사용한다. 기존 저장에 필드를 추가하거나 변경하지 않는다. 격리 API에서 300코인·830코인 주문, 파티 회복, 친밀도, 잔액 부족, 구형 진행 보존, 위치 밖 거절과 동일 revision 중복 요청 거절을 확인했다. PC·모바일 Chromium은 모의 API와 대체 이미지를 사용해 주문 목록을 확인했다. 물리 기기와 운영 데이터는 검사하지 않았다.
