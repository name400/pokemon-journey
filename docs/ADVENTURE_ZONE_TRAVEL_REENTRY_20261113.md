# 야생 구역 빠른 이동 지점 복구

방문한 야생 구역의 저장된 이동 지점이 후속 지도 변경으로 벽이나 물에 놓이면 기존 이동 요청은 안전하게 거절되지만, 기존 등록 로직은 재방문해도 해당 좌표를 바꾸지 않아 계속 사용할 수 없었다. 이를 구성된 구형 저장으로 재현했다. 실제 운영 저장에서 발생했는지는 확인하지 않았다.

다른 구역에서 해당 야생 구역의 지상 통행 칸으로 실제 진입할 때에만 현재 지도에서 기존 지점이 벽 또는 물인지 검사한다. 그 경우 현재 진입 지점으로 갱신한다. 기존 지점이 통행 가능하거나 야생 개체·임시 장애물 등 다른 타일이면 유지한다. 다른 구역의 등록, 파티, 재화, 진행과 저장 형식은 유지하고, 이동의 기존 리비전 검사를 사용한다. 옥상·지하 및 같은 화면 내 이동은 복구하지 않는다.

원작의 방문 지점으로 빠른 이동하는 기능은 [닌텐도 안내](https://www.nintendo.com/us/whatsnew/12-tips-and-tricks-for-pokemon-legends-z-a/)에 근거한다. 좌표 복구는 2D 맵 변경에 필요한 이 게임의 호환 처리이며 원작 기능이라고 주장하지 않는다. 격리 단위·API 검사에서 막힌 지점의 거절과 재진입 복구, 재접속과 무료 이동, 리비전 충돌, 임시 개체·다른 구역 및 파티·지갑 보존을 확인했다. 운영 D1 및 실제 플레이어 저장은 확인하지 않았다.
