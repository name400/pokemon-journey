# 존느 9번지 시청 광장 시각 개선

- [미션 19 자료](https://strategywiki.org/wiki/Pok%C3%A9mon_Legends%3A_Z-A/Reaching_Rank_D)는 시청 주변 분수의 주민에게서 단서를 얻는 흐름을 설명한다. [존느 9번지 자료](https://bulbapedia.bulbagarden.net/wiki/Jaune_Sector_9)의 화면에서는 분수, 아치형 건물 외관과 주변 비계를 볼 수 있다.
- 기존 시청 표식을 건물·입구로, 분수 표식을 작은 분수로, 옥상 진입 표식을 승강 장치로 그렸다. 광장 포장과 주변 건물을 구분하고 기존 미션 주민과 연결을 유지한다. 기존 이동 타일과 충돌 판정은 변경하지 않았고, 분수 칸도 기존처럼 통행 가능하다.
- 실제 시청의 정확한 형태·분수 크기·시청과 분수의 거리 및 도로의 좌표는 확인하지 못한 2D 초안이다. 시청 실내와 원작의 전체 광장 동선도 미완성이다. 자료 이미지는 코드에 복사하지 않았다.
- 기존 미션 19 단서와 저장 복원, 이웃 지역 이동·미션 18 및 옥상 연결 대표 검사를 실행했다. PC·모바일 Chromium의 화면은 시험 상태와 외부 이미지 대체물을 사용했으며 운영 기기에서 검증하지 않았다.
