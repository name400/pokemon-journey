# 블루 7번지 안뜰 기술머신 101

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-7.html)는 동쪽 안뜰 남쪽 입구의 주민이 TM101을 준다고 기재한다. [기술머신 안내](https://www.serebii.net/legendsz-a/tm.shtml)는 블루 7번지의 TM101이 일렉트릭네트임을 확인한다. 2차 자료이며 원작 실기는 확인하지 않았다. 기존 2D 안뜰 남쪽에 주민을 두었으며 정확한 격자 좌표와 외형은 추정이다.

주민에게서 한 번 받는 기술머신을 기존 재사용 학습 흐름에 연결했다. 가방이 가득 차면 수령 기록을 남기지 않고, 기존 저장·안뜰 출입과 포켓몬의 기술은 자동 변경하지 않는다. [학습 자료](https://www.serebii.net/attackdex-sv/electroweb.shtml)와 [폼별 대조](https://www.dittobase.com/legends-za/moves/electroweb)를 참고해 대표 기본 종 16종과 알로라 라이츄·로토무 5개 폼만 명시했다. 호환 목록은 불완전하며 나머지 종·폼은 미확인 상태로 보류한다. 시간 감소는 기존 턴제 전투 처리로 근사한다.

주민과 옛 좌표 복원, 가방 한도, 중복 요청, 대표 호환·비호환·폼 및 실제 기술 학습 후 기술머신 보존을 검사했다. 모바일 D1 이동 오류는 운영 재검증 전이며 실패 기록을 유지한다. Sites 병합본과 원작 기기는 확인하지 않았다.
