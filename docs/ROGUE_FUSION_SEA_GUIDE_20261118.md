# 융합 포켓몬의 바다 길 안내

「바다에서 길을 잃었다」 선택지에서 주체가 파도타기·공중날기를 배울 수 없더라도 융합 상대가 기술머신으로 배울 수 있으면 안내할 수 있어야 한다. 수정 전 캐터피·꼬부기와 캐터피·구구의 검증된 융합을 각각 시험했을 때 해당 선택지가 빠졌다. 고정 원본의 [길 안내 요구 조건](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/data/mystery-encounters/requirements/can-learn-move-requirement.ts#L64)과 [융합 기술머신 호환성](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/field/pokemon.ts#L5646)을 대조했다.

검증된 비무작위 융합의 상대 종·폼이 배우는 기술머신과 현재 레벨 기술을 안내 가능성에 포함한다. 알기술은 원본의 `getEggMoves()`처럼 주체 종을 따른다. 기절·확인 불가능한 융합과 무작위 기술 조합은 기존 판정을 유지한다. 기존 저장을 일괄 변경하지 않으며 저장된 안내 대상·보상·경험치 지급 흐름은 그대로 사용한다.

격리 엔진에서 꼬부기 파도타기·구구 공중날기, 레벨 40 골덕의 파도타기와 인접 레벨, 상대의 알기술 제외·기절·유효하지 않은 융합·무작위 기술 경계를 검사했다. 강제 구성된 이벤트에서 실제 선택·확인·저장 복원과 다른 저장 슬롯 보존을 확인했고, 별도 고정 시드 시험에서는 기존 조우 생성기로 바다 이벤트를 생성해 선택·취소했다. 바다 이벤트와 융합 기술머신 관련 대표 회귀를 포함해 26건이 통과했다. 모든 폼·챌린지·오래된 융합과 실기기는 미검증이며 자연 전체 게임을 진행한 검사는 아니다.

별도 격리 SQLite의 실제 게임 API에서 꼬부기 융합의 선택 가능 표시, 선택 후 재조회, 확인·경험치, 다른 저장 영역 보존과 오래된 리비전의 중복 요청 거절을 추가로 확인했다. 사용자 저장이나 기존 서버는 사용하지 않았다. 전체 타입 검사·전체 린트와 브라우저·실기기는 이번 변경에서 실행하지 않았다.
