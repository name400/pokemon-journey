# 베르 2번지와 베르날 애비뉴 연결

[베르 2번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-2.html)와 [Bulbapedia 지역 설명](https://bulbapedia.bulbagarden.net/wiki/Vert_Sector_2)은 서쪽의 베르날 애비뉴를 설명한다. 모두 2차 자료다.

두 지상 화면에 왕복 접근을 추가했다. 정확한 접점과 도로 방향은 압축된 2D 지도의 잠정 배치다. 기존 구역 2 출입과 구역 17 제한, 베르날 수변·옥상 및 베르 2번지 옥상 층은 유지한다. 알 수 없는 대상 층 기록이 있으면 새 경로를 차단해 기록을 덮어쓰지 않는다.

모바일 이동 오류와 Sites 병합본 실패 기록은 운영 재검증 전이므로 유지한다.
