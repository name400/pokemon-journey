# 사이드 미션 39: 야돈 교환

[Serebii](https://www.serebii.net/legendsz-a/sidemissions/slowpokeforslowpoke.shtml)의 퀴즈 완료 조건, 남쪽 큰길, 레벨 30 가라르 야돈 Spicy의 성격과 기술, [Thonky](https://www.thonky.com/pokemon-legends-z-a/side-mission-039-slowpoke-for-slowpoke)의 교환과 보상 1,000원·진주·파워벨트를 반영했다. 인물의 2D 좌표는 추정이다. 퀴즈 완료는 현재 미션 14 단계 9부터로 해석한다.

화면에서 일반 야돈과 영구 교환을 명시적으로 확인해야 하며, 지닌 도구는 교환 전에 빼야 한다. 선택한 본인 개체가 진행 중인 온라인 교환·대전에 묶여 있거나 읽은 후 바뀌면 거절한다. 월드 리비전, 원본 개체 데이터·소유권, 미완료 교환, 온라인 대전, 가방과 지갑 한도를 조건으로 탐험에서의 개체 제외·새 개체·파티 교체·보상을 하나의 D1 배치에서 처리한다. 공유 보유함 원본은 다른 게임과 기존 교환 호환을 위해 보존한다. 기존 피카츄 교환과 구형 저장은 변경하지 않는다. 완료 플래그만으로 과거 보상을 새로 만들지 않는다.

격리 SQLite API에서 파티 외 야돈과 단독 선두, 미확인·폼·소유·지닌 도구·가방·지갑·온라인 대기·기존 교환·낡은 리비전 및 트랜잭션 직전 개체 수정 거절, 재접속과 중복 방지를 검사했다. 교환으로 받은 야돈을 미션 75의 실제 보상으로 진화시키는 흐름도 확인했다. 실제 기기, 운영 D1, Sites 병합본과 브라우저 화면은 확인하지 않았다.

후속 점검에서 공유 보유함 원본을 삭제하던 로컬 초기 구현은 기존 게임 간 보존 정책과 충돌함을 확인해 수정했다. 이전 커밋은 배포되지 않았다. 기존 피카츄 교환처럼 탐험에서만 제외하고, 구형 클라이언트가 이전 선두를 되돌려도 교환받은 야돈으로 복원한다.
