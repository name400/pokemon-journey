# 사이드 미션 46: 피죤투의 공중날기

[Colis의 의뢰 자료](https://www.serebii.net/legendsz-a/sidemissions/pidgeotsoaringhigh.shtml)와 [공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-046-pidgeot-soaring-high)에 따라 미션 19 시작 후 세존 운하변에서 레벨 41 구구·42 피죤·43 피죤투와 배틀한다. 승리 상금은 2,064원이며 의뢰 보상은 2,600원·기술머신 043 공중날기·리피트볼 5개다. 기존 금색 인형의 전투 상금 보정은 유지한다.

[공중날기 학습 자료](https://www.serebii.net/attackdex-sv/fly.shtml)의 Z-A 기술머신 기본 종과 명시된 가라르 파오리를 연결했다. 아직 확인하지 않은 다른 폼은 제한한다. 기술머신은 기존 기술 교체 화면에서 반복 사용하며 기존 포켓몬과 기술을 임의 변경하지 않는다. 리피트볼 공간이 부족하면 의뢰 보상을 보류하고 중복 요청은 리비전으로 방지한다.

운하변의 타일 위치는 기존 지도에 맞춘 2D 초안이며 배틀은 기존 턴제 엔진의 공중날기 처리다. 원작 실기·운영 D1·Sites 병합본은 확인하지 않았다.
