# 블루 7번지 서쪽 안뜰의 높은 공간

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-7.html)는 서쪽 안뜰의 계단 옆 도구와 높은 공간의 기력의조각을 기록한다. 2차 자료이며 원작 기기에서 확인하지 않았다. 두 위치가 같은 계단으로 연결되는지, 계단 방향·높이·정확한 윤곽은 자료에서 확인되지 않아 기존 서쪽 안뜰에서 오가는 별도 2D 높이층으로 근사했다. 기력의조각의 격자 좌표도 추정이다.

기존 통행 가능 칸에 오르내리는 계단 표식을 두어 지상 위치를 보존하고, 높은 공간은 별도 지구로 저장한다. 기존 의뢰·센터·옥상 상태를 재사용하며 수집 성공 전 가방이 가득 찬 경우 보상 기록을 남기지 않는다. 옛 지상 저장, 신규 층 저장, 계단 왕복, 안뜰 의뢰·출입, 도구 수량 한도와 중복 요청을 대표 검사했다. 마비치료제와 이 지역의 다른 옥상 동선·도구는 아직 미완성이다.

실제 Sites 병합본과 모바일 D1 이동 오류는 운영 재검증 전이며 실패 기록을 유지한다.
