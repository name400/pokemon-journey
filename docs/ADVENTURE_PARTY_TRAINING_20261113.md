# 파티 육성 도구 대상 선택

가방에서 민트·영양제·노력치 감소 열매와 대단한 특훈의 대상 파티원을 선택한다. 기존 API의 파티 소유권·재고·상한·리비전 검증을 그대로 사용하며 선두나 파티 순서를 바꾸지 않는다. 특훈 대상의 상세 개체값이 응답에 없을 때는 임의 값을 표시하지 않는다. 이 기능은 이미 서버에서 지원하던 대상 선택을 화면에 연결한 것이다. 원래 성격과 유전 개체값을 보존하는 기존 효과도 유지한다.

[원작 도구 목록](https://www.serebii.net/legendsz-a/items.shtml)과 [특훈 안내](https://www.polygon.com/pokemon-legends-z-a-plza-ivs-bottle-caps-hyper-training/)에서 도구 효과와 특훈 조건을 대조했다. 격리 SQLite API에서 대기 파티원에 대한 네 종류 사용, 파티 외 대상·오래된 요청 거절, 재접속과 선두·다른 개체 보존을 확인했다. PC·모바일 Chromium에서는 모의 API로 선택과 요청·재접속을 확인했다. 실제 운영 D1과 원작 기기는 확인하지 않았다. 이동 처리와 저장 형식은 변경하지 않았다.
