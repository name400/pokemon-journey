# 후일담 구역 20 지도 이동

[미션 42 공략](https://www.neoseeker.com/pokemon-legends-z-a/Main_Mission_42)은 L과 배틀한 뒤 야생 구역 20으로 빠른 이동하는 경로를 설명한다. 기존 구현은 미션 42를 끝낼 때까지 구역 20을 지도 목적지로 등록하거나 지상에서 빠른 이동으로 나갈 수 없었다. 미션 38을 마친 뒤에는 방문을 등록하고, 일반 탐험과 L 배틀 직후의 미션 42 1단계에 지도 이동을 허용한다. 지도 등록은 기존 방문 지점 방식이며 직접 출입 버튼에서도 실제 도착 칸을 기록한다. 기존에 방문 기록이 없는 저장은 다시 방문하면 등록한다.

원작에서 엔딩 직후 입장이 가능하다는 [안내](https://www.nintendolife.com/guides/pokemon-legends-z-a-wild-zone-20-guide-all-pokemon-and-alphas)와 미션 38 이후 해금이라는 [다른 안내](https://allthings.how/pokemon-legends-z-a-wild-zone-20-unlock-spawns-and-tm-draco-meteor/)가 엇갈린다. 따라서 이번 지도 이동은 보수적으로 미션 38 완료부터 적용한다. 목적지의 정확한 원작 좌표와 빠른 이동 제한은 실기 미확인이며 기존 2D 출입 위치를 사용한다.

진행 중인 지가르데 연전 단계 2~4, 지하, 위협 및 전투 등 기존 제한은 유지한다. 기존 구역 이탈과 같은 방식으로 확인된 임시 야생 출현을 초기화하며, 알 수 없는 출현 기록이나 버전이 명시된 지도 기록은 새 경로에서 덮어쓰지 않는다. 보유 포켓몬·도구·보상과 영구 수집 기록은 변경하지 않는다. 미션 42 완료 저장은 이전 규칙을 그대로 유지한다.

지도 이동 단위 검사와 격리 API에서 등록·재접속·왕복, L 배틀 뒤 접근, 연전·지하 제한, 구형·미확인 기록과 파티·보상 보존을 대표 확인했다. 원작 실기, 실제 Sites 병합본과 운영 D1은 검증하지 않았다.
