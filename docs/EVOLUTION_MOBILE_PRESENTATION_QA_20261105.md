# 진화 이미지·교체 이름·모바일 전투

고라파덕 전투 후 남은 `battleAppearance=psyduck`, `battleArtId=54`가 골덕 진화 결과에도 복사돼 그림이 고라파덕으로 남는 문제를 격리 재현했다. 주체와 융합 기증자 진화에서 이전 전투 외형 캐시를 지우고 새 종·폼 이미지 정보를 사용한다. 저장 종 ID와 게임 규칙을 임의 변경하지 않는다.

교체 메뉴 표시만 별도 함수로 처리한다. 기본 영문 `Normal` 등은 숨기고, 네 식구 등 알려진 영문 폼은 한국어로 표시한다. 번역되지 않은 비기본 영문 폼은 폼 번호로 구분하며, 저장된 이름·ID는 변경하지 않는다. 모바일 세로 전투의 상단 정보 및 로그를 줄이고 상대 HUD 폭을 제한해 스프라이트 공간을 확보한다. 설정 등 터치 조작은 유지한다.

격리 Chromium 320×568, 375×667, 390×844, 430×932, 1280×850의 실제 페이지에서 진화 전/후 이미지 요청이 각각 54/55인지, Normal 숨김·네 식구 표시와 실제 교체 요청, 가로 넘침/페이지 오류를 확인했다. 외부 이미지는 이 경로 검사에서 stub이다. 더블 전투는 실제 스프라이트 6개로 배치·가림 27경로를 검사했고, 연출·축소 동작 30경로도 통과했다. 390×844 단일 기준 전투 화면 시작 y좌표는 187px에서 165px로 줄었다. 일반·Worker 진화 관련 각 31/31, 타입·빌드·신규 파일 lint 통과. 다른 모든 종의 외형, 물리 기기 및 운영 저장은 미검증이다. `/tmp/evolution-mobile-final.log`, `/tmp/ui-double-check.log`, `/tmp/ui-types-motion-last.log`, `/tmp/ui-evolution-final.log`, `/tmp/ui-evolution-final-worker.log`, `/tmp/ui-fix-type-final.log`, `/tmp/ui-fix-build-final.log`.
