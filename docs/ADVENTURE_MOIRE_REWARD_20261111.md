# 묘지 의뢰 보상

[Serebii의 의뢰 안내](https://ns5.serebii.net/legendsz-a/sidemissions/sableyeinthecemetery.shtml)는 Moire의 깜까미 의뢰 도구 보상으로 기력의조각 2개를 명시한다. 반지 반환 시 기존 코인과 보상 대기 상태를 유지하고, Moire와 다시 대화해 기력의조각을 한 번 받을 수 있다. 이미 완료하고 대기 상태로 저장한 플레이어도 같은 방법으로 받을 수 있다. 기존 보유량이 정상적인 안전 정수가 아니면 보류 상태를 유지하고 거절한다. 재접속·중복 요청은 대기 플래그와 저장 리비전 검증으로 보호한다.

정확한 의뢰인 위치·도시 지형은 기존 초안이다. 다른 의뢰의 미지급 보상은 이 변경에서 처리하지 않는다.
