# 포켓로그 최고기록·랭킹 격리 검사

현재 최고기록은 저장 슬롯의 승리 보상 웨이브와 완료된 미스터리 웨이브, 동기화된 개인 최고기록 및 200 웨이브 완주 기록을 사용한다. 미확정 미스터리나 패배한 200 웨이브를 승리로 계산하지 않는다. 랭킹 화면은 이 기준을 ‘승리로 돌파한’ 기록이라고만 설명해, 전투 없이 완료한 미스터리 웨이브가 포함되는 실제 집계와 어긋났다. 화면 설명을 ‘완료한 웨이브’로 수정했으며 점수 계산과 저장은 변경하지 않았다.

실제 전투 승리 API에서 기록 5의 저장·랭킹 반영, 중복 리비전 거절, 재조회와 다른 슬롯·탐험 데이터 보존을 격리 SQLite로 확인했다. 랭킹 조회 API의 저장 기록 동기화, 동점 등록 순서, 같은 기록의 재조회·낮거나 같은 기록 재제출에서 시간과 점수 유지, 저장 경쟁 실패 시 랭킹 미반영, 상위 50명 밖 개인 순위와 프로필 없는 계정의 개인 기록을 검사했다. 관련 API·미스터리·랭킹 검사 122건이 통과했다. 격리 Chromium PC·모바일 크기에서는 모의 랭킹 응답으로 기록·동점 순서·기록 없음·닉네임 안내를 확인했다.

동점의 시간과 ID는 SQLite에서 인위적으로 구성했고 200 완주는 저장 기록의 판독만 검사했다. 운영 DB·실제 계정·실기기, D1의 실제 동시 실행 및 모든 레거시 기록은 검사하지 않았다. Sites에는 배포하지 않았다.

수정 컴포넌트의 ESLint는 `no-explicit-any`와 `react-hooks/set-state-in-effect` 두 오류로 실패했다. 변경 전 HEAD의 동일 파일도 같은 두 규칙에서 실패하는 것을 별도로 확인했으며, 이 문구 수정에서 로딩 코드는 변경하지 않았다.
