# 미션 42 지가르데 포획 볼

[원작 구역 20 설명](https://bulbapedia.bulbagarden.net/wiki/Wild_Zone_20)은 지가르데 포획을 시도할 때 볼을 하나도 가지고 있지 않으면 몬스터볼을 보충한다고 명시한다. 세 폼을 쓰러뜨린 후 포획 화면을 열 때 몬스터볼과 다른 사용 가능한 볼이 모두 없으면 몬스터볼 1개를 같은 저장 트랜잭션에서 지급한다. 이미 포획 화면에 저장되어 볼이 없는 플레이어는 화면의 보충 버튼으로 복구할 수 있다. 볼이 있을 때는 보충을 거절하며, 화면의 저장 리비전을 갱신해 재접속 및 중복 요청을 보호한다.

기존의 턴제 3연전, 보유 볼 소모와 확정 포획, 지가르데큐브 진행은 유지한다. 프리즘타워 아래 대결 공간의 정확한 지형과 원작의 실시간 전투 연출은 여전히 미완성이다.

가방에 보관된 희귀 볼 7종도 사용 가능한 볼로 계산하도록 보충 조건을 수정했다. 이전 조건은 필드 볼 저장만 확인해 가방에 희귀 볼이 있어도 불필요하게 몬스터볼을 지급했다. 희귀 볼을 사용한 확정 포획·큐브 수령, 볼 재고를 다시 0으로 설정한 반복 보충, 각 폼 포기 및 최종 폼 실제 패배 후 처음부터 재도전 상태를 격리 검사했다. 볼 재고를 다시 비우는 것은 반복 보충을 검증하기 위한 테스트 설정이다.
