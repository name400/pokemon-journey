# Rintaro 승급전 보상

[원작 승급전 목록](https://bulbapedia.bulbagarden.net/wiki/Promotion_match)은 랭크 W Rintaro를 이겼을 때 1,140원을 명시한다. 새 승리는 다른 승급전과 같이 같은 저장 트랜잭션에서 1,140코인을 지급한다. 과거에 승급했으나 금액 미확인으로 남은 `zaRintaroRewardPending` 저장은 일지의 수령 버튼으로 보상받는다. 플래그가 있는 경우에만 지급하며 저장 리비전으로 중복 요청을 막는다. 패배는 지급하지 않는다. 기존 랭크·진행과 다른 승급전 보상은 유지한다.
