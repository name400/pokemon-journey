# 멀티렌즈 방전 첫 타격

신규 도전의 멀티렌즈 방전은 첫 타격에서 상대 슬롯을 먼저, 아군을 나중에 처리한다. 각 대상의 실제 피해를 적용한 뒤 다음 대상의 전체 공격 보정을 계산하고, 마비 추가 효과의 대상 순서도 상대 다음 아군으로 정한다. 기절한 대상은 마비되지 않는다. 기존 `earthquake-source-v1` 이하 저장의 규칙은 보존한다.

격리 전투에서 양측 사용자, 상대 기절·방어·축전·기합의머리띠, 유연과 우격다짐, 마비 대상 순서, 실제 턴과 codec 복원·다른 데이터를 검사했다. 원본은 각 대상의 피해·효과를 더 세밀하게 처리하므로 여기서는 첫 타격 피해와 추가 효과의 대상 순서만 지원한다. 피해와 마비 사이의 모든 특성/도구 효과 및 원본 난수열, 다른 전체 공격·실사용·실기기는 별도다.
