# 사이드 미션 110·111 — 멸망의노래와 어린 포켓몬

[Chante 의뢰](https://www.serebii.net/legendsz-a/sidemissions/atunethatbeckonsdoom.shtml)와 [공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-110-a-tune-that-beckons-doom)을 따라 미션 37 이후 루주 8번지의 Chante에게 앱솔·파비코리·팬텀으로 도전한다. 각각 멸망의노래와 확인된 기술을 사용하며 승리 상금 4,896원과 별도 의뢰 보상 3,400원·수불열매 5개·경험사탕 M 5개를 받는다. 첫 행동에 멸망의노래를 선택하도록 이 전투에만 지정한다. 원작 자료의 실시간 30초는 기존 턴제 엔진의 카운트로 근사한 것이며 같은 시간 규칙은 아니다.

[Aimée 의뢰](https://www.serebii.net/legendsz-a/sidemissions/myadorable%2Cadorablebabies.shtml)와 [공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-111-my-adorable-adorable-babies)에 따라 베르 4번지 코트에서 삐·꼬몽울·피츄·리오르와 배틀하고 승리 상금 4,352원과 의뢰 보상 20,000원·튼튼밀크 12개를 별도로 받는다. 두 인물의 정확한 위치는 기존 2D 맵에 맞춘 초안이다. 상대 기술·레벨은 위 자료를 따르지만 실제 원작의 실시간 전투와 AI를 재현한 것은 아니다.

구형 저장에서 의뢰 완료를 추정하지 않는다. 기권 뒤 재도전할 수 있으며 가방 또는 지갑이 가득 차면 보상을 보류하고 기존 리비전 조건으로 중복 수령을 막는다. 격리 API에서 해금·실제 멸망의노래 사용·두 상대 편성·기권·승리·재접속·가방과 지갑 한도·중복 요청 및 기존 파티 보존을 확인했다. 멸망의노래 턴 카운트의 저장 복원과 교체 시 해제, 기존 판별 선공도 별도 엔진 검사했다. 승리 검사는 상대 HP를 시험용으로 조정했으며 원작 기기·정상 난이도·운영 D1·Sites 병합본은 미검증이다.
