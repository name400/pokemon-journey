# 세존 운하변과 북쪽 큰길 연결

[세존 운하변 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/saison-canalside.html)는 남동쪽 끝에서 북쪽 큰길에 접근한다고 설명하고, [북쪽 큰길 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/north-boulevard.html)도 동쪽 끝의 운하변을 기록한다. 기존 보행 화면 사이 왕복 접근을 추가했다. 출입 좌표와 길의 선형은 잠정 2D 배치다.

기존 운하의 물·다리와 존느 10번지 접근, 야생 구역 11 해금 조건 및 저장 형식을 유지한다. 원작 실기와 실제 Sites 병합본은 확인하지 않았다. 모바일 이동 오류 기록은 운영 재검증 전까지 유지한다.
