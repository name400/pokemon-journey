# 미션 34: Lida의 진화와 전투 준비

- [Lida의 미션 대사](https://bulbapedia.bulbagarden.net/wiki/Lida/Quotes)와 [Serebii 미션 정리](https://www.serebii.net/legendsz-a/mainmissions/aroguemegastarmie.shtml)에 따르면 Philippe가 Lida에게 물의돌을 주고 Lida의 별가사리가 진화한다. 보스전 직전 Lida가 플레이어 파티 회복을 제안하며 거절 대사에서도 회복한다. 플레이어에게 물의돌을 지급하는 사건은 아니다.
- 새로 시작한 Philippe 전투에서 승리하면 기존 옥상 사건 지점에 Lida의 진화·회복 확인을 추가한다. 확인하면 파티 HP·상태·PP를 한 번 회복하고 기존 동료 아쿠스타와 보스전을 진행한다. 원작의 두 긍정 답변은 하나의 확인으로 요약했고 대사는 재구성했다. 원작의 정확한 3D 연출과 지점에 대한 재현은 아니며 현재 2D 옥상 위치는 초안이다.
- 이미 진행 중이던 Philippe 전투 및 이전에 승리한 저장은 새 단계를 소급 적용하지 않는다. 미션 보상과 가방은 변경하지 않는다. 확인 상태는 저장되며 중복 회복을 막는다. 사용자 운영 환경 검증은 아직 하지 않았다.
