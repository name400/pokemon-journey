# 세존 운하변과 남쪽 큰길 연결

[세존 운하변 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/saison-canalside.html)는 남동쪽 끝의 남쪽 큰길 접근과 운하를 건너는 남동쪽 다리를 기록한다. [남쪽 큰길 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/south-boulevard.html)도 동쪽 끝의 운하변을 기록한다. 기존 두 화면에 왕복 접근을 추가하고 다리 구간은 화면 전환으로 압축했다. 정확한 다리 연결점·높이와 출입 좌표는 미확인된 2D 추정이다.

기존 운하의 물·다리와 북쪽 큰길 접근, 야생 구역 11 해금 조건 및 저장 형식을 유지하고 남쪽 큰길의 다른 층 상태를 덮어쓰지 않는다. 원작 실기와 실제 Sites 병합본은 확인하지 않았다. 모바일 이동 오류 기록은 운영 재검증 전까지 유지한다.
