# 블루 9번지와 남쪽 큰길 지상 접근

[블루 9번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-9.html)는 남쪽 큰길로의 접근과 상가 건물을 설명하며, [남쪽 큰길 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/south-boulevard.html)도 블루 9번지를 연결 구역으로 열거한다. 기존 지도에서는 두 곳 사이에 직접 이동 경로가 없었다.

두 지상 지도에 왕복 접근을 추가했다. 출입 타일과 길의 폭·선형은 압축된 2D 추정이다. 상가 건물의 미션 상호작용과 블루 6·8번지 출입, 큰길의 기존 연결과 옥상 층은 유지한다. 이전 통행 칸을 막지 않으며 저장 형식과 미션 진행을 바꾸지 않는다.

대표 단위 검사에서 새 경로 양방향, 저장 복원, 기존 상가 입구의 미션 상호작용과 인접 경로·옥상을 확인했다. 운영 D1·실제 Sites 병합본과 원작 실기는 검증하지 않았고 모바일 이동 오류 및 배포 검사 실패 기록을 유지한다.
