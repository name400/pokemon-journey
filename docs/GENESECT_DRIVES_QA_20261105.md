# 게노세크트 카세트와 테크노버스터

원본의 번개·불꽃·얼음·물 카세트를 폼 도구 및 융합의 양쪽 역할에 연결했다. 네 폼은 native 종과 원본 능력치 6항목이 일치할 때만 허용한다. 도구 획득·활성/해제, 전투·저장·분리에서 다른 포켓몬과 도구를 보존한다.

원본 테크노버스터는 게노세크트가 주체이면 주체 폼, 기증자이면 기증자 폼의 타입을 사용하며, 둘 다 게노세크트이면 주체가 우선한다. 원본 규칙을 사용하는 전투의 로컬 기술 객체에서만 이 처리를 적용한다. 게노세크트가 아닌 포켓몬의 native 카세트는 원본과 같이 기술 타입에 영향을 주지 않으며, 구형 규칙과 공유 Dex는 변경하지 않는다. 타입 변환 특성 등 확정할 수 없는 기술 미리보기는 기존 불확정 처리로 둔다.

실제 보상 선택, 양쪽 융합, 카세트별 8가지 실제 공격 타입과 기술 화면 타입, 두 게노세크트의 주체 우선, 비게노세크트·구형 규칙, 전투·codec·분리를 검사했다. 관련 일반·Worker 각 44/44, 추가 주체 우선 경계 포함 게노세크트 일반·Worker 각 7/7, 타입·production 빌드 통과. 겹치는 검사 수를 더해 전체 검사로 주장하지 않는다. 실제 브라우저/실기기·운영, 모든 특성 및 특수기 조합은 별도다. 로그 `/tmp/genesect-final.log`, `/tmp/genesect-worker.log`, `/tmp/genesect-precedence.log`, `/tmp/genesect-precedence-worker.log`, `/tmp/genesect-type.log`, `/tmp/genesect-build.log`.
