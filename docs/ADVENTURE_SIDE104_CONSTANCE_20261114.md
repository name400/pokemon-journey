# 사이드 미션 104: 벌레 타입 배틀

[Serebii](https://www.serebii.net/legendsz-a/sidemissions/abuzzaboutbugtypes.shtml)와 [Thonky](https://www.thonky.com/pokemon-legends-z-a/side-mission-104-abuzz-about-bug-types)에 따라 미션 35에서 AZ를 만난 뒤 루주 7번지 배틀코트의 Constance에게 의뢰를 받고 독침붕·아리아도스·스라크·헤라크로스·쁘사이저와 배틀한다. Serebii의 레벨과 기술, 쁘사이저나이트를 사용하고 기존 상대 메가진화 엔진을 연결했다. 상대 출전 순서는 Serebii와 Thonky의 기재가 다르므로 Serebii 순서를 사용한 잠정 처리다.

승리 상금 4,872원과 별도 의뢰 보상 2,500원·경험사탕 M 5개·파워렌즈를 지급한다. 보상 가방이 가득 차면 공간 확보 전까지 대기하고 저장 리비전으로 중복 수령을 막는다. 구형 저장의 완료나 보상을 추정하지 않는다. 기존 파워렌즈 장착·노력치 효과를 사용하며 의뢰를 수첩에서 추적할 수 있다.

Constance의 코트 내 정확한 칸과 외형은 기존 2D 지도에 놓은 초안이며 실시간 원작 배틀은 턴제 근사다. 격리 API에서 해금 경계·수락·상대 편성·기권과 재도전·승리·보상 한도·재접속·중복 요청을 검사했다. 실제 상대 쁘사이저나이트와 분리된 전투 엔진에서 메가진화를 확인했다. 승리 검사는 상대 HP를 시험용으로 낮췄으며 자연 난이도·원작 기기·운영 D1·Sites 병합본은 확인하지 않았다.
