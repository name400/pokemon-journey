# 호텔 Z 옥상 메가결정

[수급 안내](https://gamingbolt.com/pokemon-legends-z-a-guide-how-to-farm-mega-shards)는 호텔 Z 주변 옥상에 재생되는 메가결정이 있다고 설명한다. 튜토리얼 결정을 처리한 뒤 기존 옥상 초안에 작은 결정과 큰 결정을 추가했다. 정확한 좌표·개수·크기는 원작에서 확인하지 못한 2D 근사다. 결정은 걸어갈 수 있는 타일에 표시되어 기존 길과 저장 좌표를 막지 않는다.

기존 구역 9와 같은 조각·분홍 인형·경험치·연구 및 10분 재생 규칙을 사용한다. 자료에는 약 30초가 기재되지만 개별 위치의 조건은 확인하지 못해 이 게임의 잠정 규칙을 유지한다. 재생 시각과 보상은 저장 리비전과 함께 기록하고 기존 튜토리얼·파티와 알 수 없는 저장 형식을 보존한다. 운영과 원작 실기는 검증하지 않았다.
