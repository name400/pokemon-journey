# 구역 18 공사 구역 서쪽 출구

[구역 자료](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_18)는 이어롭이 있는 비계 마당의 서쪽 출구 뒤에서 옥상 비계에 접근할 수 있다고 설명한다. [현장 안내](https://www.videogameschronicle.com/guide/pokemon-legends-z-a-wild-zone-18/)도 이어롭 골목과 사다리, 옥상 출입구를 설명한다. 기존 공사 구역 서쪽에서 마젠타 9번지 바깥 비계까지 왕복 연결을 추가하고 기존 옥상 사다리와 문으로 갈 수 있게 했다. 마젠타 쪽에서 구역으로 들어갈 때 기존 랭크 B 조건을 확인한다.

두 화면의 접점, 통로 폭과 위치는 압축된 2D 초안이다. 이전 공사 구역 출구와 기존 사다리 및 옥상 출입구는 유지한다. 바깥길은 기존 통행 바닥만 포장하고 새 출구는 기존 경계에 놓아 저장 위치를 막지 않는다. 실제 서버 경로에서 공사 구역→비계→옥상→공사 구역 왕복과 각 단계 재접속, 기존 파티·소지금 유지를 확인했다. 원작의 정밀한 건물·비계 배치 및 운영 기기는 미검증이다.
