# 화산 진정 선택의 챌린지 조건

저장된 진정 대상이 없는 경로에서 불꽃 타입이 전혀 없고, 챌린지 출전 금지인 잠만보의 두꺼운지방만 조건에 해당해도 진정 선택과 확정이 허용되는 결함을 격리 재현했다. 물 챌린지에서 출전 가능한 별도의 물 타입 융합 포켓몬도 있는 구성이다.

[고정 원본의 화산 이벤트](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/data/mystery-encounters/encounters/fiery-fallout-encounter.ts#L246)는 생존 불꽃 타입 조건과 출전 가능한 불꽃 저항 특성 조건을 별도로 사용한다. 저장된 대상이 없는 챌린지 경로에서 생존 불꽃 타입이 없을 때만 저항 특성 후보의 출전 가능성을 확인한다. 불꽃 타입 기준, 저장된 대상 경로, 일반 게임 및 다른 이벤트 규칙은 변경하지 않는다. 불꽃 타입이 있는 기존 폴백의 전체 후보 우선순위·기절 후보는 이번 범위가 아니다.

수정 전 위 차단과 올바른 후보 선택 검사가 실패했다. 수정 후 출전 금지 후보 차단, 허용 후보 선택·확정·저장 복원, 불꽃 타입 별도 조건, 확정 전 기절, 일반 게임 유지와 기존 바다·화산 이벤트를 포함한 격리 엔진 검사 25건이 통과했다. 격리 SQLite의 실제 API에서 차단·저장 행 불변과 기존 바다 이벤트를 포함해 3건이 통과했다. 최초 유효 후보 경험치 시험은 시험 레벨이 웨이브 상한에 도달해 경험치를 얻지 못했으므로 레벨을 낮춰 재검사했다. 시험 데이터 주입이며 자연 전체 게임·실기기·모든 챌린지와 폼은 미검증이다.
