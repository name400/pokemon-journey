# 구역 6 카페 바타유 접근

[Nintendo Life의 구역 6 안내](https://www.nintendolife.com/guides/pokemon-legends-z-a-wild-zone-6-guide-all-pokemon-and-alphas)는 북쪽의 존느 11번지와 남쪽 다리 위·아래 진입, 카페 바타유 빠른 이동을 설명한다. [Lumi Cab 목적지 목록](https://bulbapedia.bulbagarden.net/wiki/Lumi_Cab)에도 이 카페가 포함된다.

기존 구역 6의 북쪽 진입로에서 카페 입구 옆까지 보행 바닥에 포장을 이어 시각적인 접근로를 추가했다. 기존 다리·운하·높이층과 이동 가능 여부는 그대로다. 건물·입구와 포장 위치 및 폭은 이 게임의 2D 초안이며 원작 지도의 정밀 좌표가 아니다.

카페 지상에 접근하면 지도 목적지가 등록되고 무료로 되돌아갈 수 있다. 미방문 목적지로 택시를 이용하는 기존 방식에도 추가했다. 카페는 기존 미션 6 시작 또는 이후 랭크에서만 목적지로 제공한다. 옥상·운하에서는 등록하지 않으며 도착 시 지상층을 명시한다. 기존 저장, 조우, 보상 및 카페 메뉴는 수정하지 않는다.

격리 API에서 북쪽 입구부터 실제 이동·등록, 재조회·무료 복귀, 지닌 재화와 파티 및 획득 이력 보존, 택시 요금·오래된 중복 요청 거절, 구형 저장의 카페 부지 복원을 검사했다. 단위 검사에서 초기 진행 제한과 층별 등록, 이동 예측을 확인했다. PC·모바일 Chromium 화면은 시험 API 데이터와 외부 이미지 대체물을 사용했으며, 원작 기기 및 운영 D1은 검사하지 않았다.
