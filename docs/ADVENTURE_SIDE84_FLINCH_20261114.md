# 사이드 미션 84: 먼저 공격해 풀죽게 하자

미션 26의 폭주 메가 출현 이후 콰자르티코 코트에서 Flynn에게 의뢰를 받고, 샤크니아·아보크·갸라도스와 배틀한다. 상대의 레벨과 풀죽음 기술, 갸라도스의 왕의징표석은 [Serebii](https://ns5.serebii.net/legendsz-a/sidemissions/strikefirsttomake%27emflinch.shtml)의 상대 데이터를 따랐다. 기존 턴제 시뮬레이터의 풀죽음과 도구 효과를 사용하며 실시간 원작과 동작 타이밍은 다르다.

승리 상금은 [Thonky](https://www.thonky.com/pokemon-legends-z-a/side-mission-084-strike-first-to-make-em-flinch)의 4,452원을 잠정 적용했다. [Bulbapedia](https://bulbapedia.bulbagarden.net/wiki/Mission_(Legends:_Z-A)/Trainers)는 2,968원으로 기재하므로 실기 대조가 필요하다. 의뢰 보상은 2,800원과 왕의징표석이다. 재고가 가득 차면 지급을 보류하고 중복 요청을 거부한다. 위치는 현재 2D 코트의 초안이다.

구형 저장은 진행 단계가 없으면 의뢰를 새로 시작하며 기존 파티·공유 보유함을 바꾸지 않는다. 실제 기기와 Sites 병합본은 검증하지 않았다.
