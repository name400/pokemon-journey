포켓로그는 사용자의 변경된 기준에 따라 확인된 진행 차단·저장 손상과 명시 요청 기능을 우선했다. 최근 상인·사파리·마자용·챌린지·융합 보상·저장 복구 대표 검사 173건이 통과했다. 과거 운영 409와 PC 끊김은 사용자가 당시 해결됐다고 했지만 근본 원인은 확인되지 않아 재발 시 조사한다. 전체 원본 동등성이나 전종·200웨이브 실플레이가 끝났다는 뜻이 아니다.

`NEXT_STEPS.md`와 기존 클라우드 탐험 경로를 읽고 옥상의 미구현 AZ 임무를 이어받았다. 랭크 V에서 광장 포켓몬을 따라 옥상에서 AZ를 만나면 대여 배틀을 시작할 수 있다. 임시 루카리오와 메가링으로 메가앱솔을 상대하며, 승리하면 이야기 단계가 4로 진행된다. 패배·포기하면 같은 위치에서 재도전한다. 대여 포켓몬은 게임 저장의 전투 스냅샷에만 존재하며 실제 보유함·파티·아이템·지갑·연구 승리 기록을 변경하지 않는다. 소지 도구·포획을 제한하고 기존 전투 UI의 메가진화 조작을 사용한다.

레벨 50과 임시 기술 구성은 현재 프로젝트의 시범 밸런스이며 원작 수치로 검증된 내용이 아니다. 다음 스토리·보상·실시간 배틀은 추가 구현이 필요하다. Sites 배포는 사용자가 담당한다.
