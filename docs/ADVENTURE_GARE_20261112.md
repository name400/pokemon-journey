# 미르역 외관과 출발 선택

[역 자료](https://bulbapedia.bulbagarden.net/wiki/Gare_de_Lumiose)에 따르면 Gare de Lumiose는 남쪽 큰길 역전의 베르 구역에 있으며, 도입 때 나온 후 역 안에는 다시 들어갈 수 없다. 기존 역 외관의 막힌 벽에 입구 상호작용을 추가하되 그 칸으로 걸어 들어가는 것은 막았다. 기존 베르 포켓몬센터와 길, 저장 가능 좌표를 유지한다.

[출발 안내](https://allthings.how/leaving-lumiose-city-in-pokemon-legends-z-a/)에 따르면 열차로 떠나겠다는 선택을 세 번 확인하면 실제로 도시를 떠나지 않고 베르 포켓몬센터 앞에서 깨어난다. 세 차례 선택·중단·재접속과 센터 앞 복귀를 구현했다. 다른 위치로 이동하면 대기 중인 확인은 취소하며 파티와 진행은 변경하지 않는다. 역은 기존 지도 방문 등록 및 710코인 택시 목적지에도 포함한다.

기존 2D 역의 외관과 입구·센터 좌표는 초안이다. 역 내부의 도입 장면, 원작의 실제 컷신과 벤치 수면 애니메이션은 구현하지 않았으며 실제 기기와 운영 환경에서는 검증하지 않았다.
