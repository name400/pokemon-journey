# 가라르 야돈 진화 선택

기존 공용 진화 자료에서 기본 폼 조건이 없는 야돈의 레벨·교환 진화 행이 가라르 야돈에도 적용되어, 레벨 37 이상 또는 교환 이력과 왕의징표석을 갖추면 일반 야도란·야도킹을 선택할 수 있었다. [원작 진화 경로 안내](https://allthings.how/how-to-get-and-evolve-galarian-slowpoke-in-pokemon-legends-z-a/)와 [진화 방식 자료](https://bulbapedia.bulbagarden.net/wiki/Evolution_method)를 대조해 탐험 모험의 후보 표시와 진화 요청에서 가라두구팔찌·머리장식에 해당하는 가라르 폼 두 가지만 허용한다.

일반 야돈과 다른 게임의 공용 진화 함수는 변경하지 않는다. 이미 진화한 개체나 기존 저장은 소급 수정하지 않는다. 과거 저장에 종·폼 필드가 없어도 가라르 야돈의 고유 개체 ID가 있으면 진화 선택 계산 시에만 필드를 보충한다.

격리 SQLite API에서 레벨 40·교환 이력·왕의징표석을 가진 가라르 야돈의 일반 진화 거절과 데이터 보존, 올바른 도구 소비·중복 요청, 필드 누락 구형 저장의 진화를 확인했다. 단위 검사로 일반 폼과 다른 게임의 기존 후보, 이동 사전 조회를 대표 확인했다. 원작 실기·실제 운영 데이터·Sites 병합본·브라우저 화면은 확인하지 않았다.
