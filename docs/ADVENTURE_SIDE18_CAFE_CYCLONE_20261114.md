# 사이드 미션 18과 Café Cyclone

[원작 의뢰 안내](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_1-20)에 따라 베르 3번지의 Servando에게 의뢰를 받고 야나프·바오프·앗차프를 모두 파티에 넣어 보여주면 1,000코인·맥스업 3개·하양허브 1개와 팬트리오 차 메뉴를 얻는다. 포켓몬은 소비하거나 교환하지 않는다. 가방 한도에 걸린 도구는 같은 장소에 맡기고, 저장된 잔여 수량만 수령한다. 완료 플래그와 리비전 검사로 보상 중복을 막으며 기존 완료·미래 버전 데이터를 추정해 보상을 만들지 않는다.

[카페 메뉴 자료](https://www.serebii.net/legendsz-a/cafes.shtml)의 음료와 가격을 기존 카페의 파티 회복·선두 친밀도 처리에 연결했다. 팬트리오 차는 의뢰 완료 후에만 주문할 수 있다. 기존 2D 지도의 막힌 건물 벽을 재사용하므로 이동 충돌과 구형 저장 위치는 유지한다. 카페 외관·정확한 NPC 좌표와 실내는 초안이며, 원작의 사진 촬영은 구현하지 않았다. 격리 API에서 파티 조건·보상 공간·재접속·중복 요청·차 해금과 주문·파티 및 미래 데이터 보존을, PC·모바일 모의 브라우저에서 메뉴 주문을 검사했다. 원작 실기·운영 D1·Sites 병합본은 확인하지 않았다.
