# 적 AI 지시 대상 판정

신규 도전에서 적 AI는 지시의 각 대상에 대해 마지막 직접 사용 기술이 현재 기술 목록에 있고 PP가 남아 있으며 원본의 지시 호출 정책상 허용되는지 평가한다. 마지막 호출 결과가 아니라 직접 사용 기술을 사용한다. 기존 도전의 판정은 변경하지 않는다. 다이맥스 중에는 원 기술 대신 다이월이 되므로 이 판정을 건너뛴다.

격리 전투에서 대상 이력 없음, 사용 가능한 아군, 잊은 기술, PP 0, 금지 기술, 다이맥스와 싱글 전투를 확인했다. 저장 인코딩·복원과 다른 저장 슬롯 보존도 검사했다. 이는 원본의 전체 AI 점수·대상 선택·난수열과의 일치를 뜻하지 않으며, 평가와 실제 행동 사이 다른 행동으로 대상 상태가 바뀔 수 있다. 실제 플레이와 모바일은 별도다.
