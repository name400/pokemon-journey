# 부화 결과의 폼 이미지 식별 정보

흰 꽃 플라베베 시험 알의 원본 포켓몬은 `rogueFormKey: white`이며 검토된 이미지 선택기는 `669-white`를 고른다. 그러나 기존 부화 결과 객체는 폼 번호만 보존하고 폼 키·성별·전투 종 정보를 생략해 같은 선택기가 해당 폼 자산을 고르지 못하는 것을 재현했다. 이는 부화 결과 화면의 이미지 선택 문제이며 도감의 폼 등록이나 실제 포켓몬 생성이 잘못됐다는 뜻은 아니다.

새로 부화하는 결과와 이력에 원본 알의 폼 키·성별·전투 종 정보를 함께 보존한다. 데이터의 기존 보상·도감·PP나 지급 로직은 변경하지 않는다. 이미 생성된 과거 결과는 소급 수정하지 않으므로 해당 결과의 누락 정보와 이미지 표시는 여전히 미해결이다.

격리 엔진에서 시험용 흰 꽃 이로치 알의 부화·폼 이미지 선택·저장 복원·결과 확인과 다른 저장 보존을 검사했다. 격리 SQLite API에서는 시험용 알이 실제 승리로 부화한 뒤 응답·재조회·결과 확인에서 같은 폼 자산을 선택하는지 확인했다. 기존 알 폼·상점·이로치 중복 환급 테스트 5건과 교환권 획득·부화 API를 포함한 대표 API 검사 3건이 통과했다. 실제 이미지 렌더·전체 폼·실기기·운영 저장 및 전체 타입 검사는 이번에 검증하지 않았다. Sites에는 배포하지 않았다.

## 실제 렌더와 과거 결과 조사

격리 부화 fixture에서 실제 부화 함수로 만든 일반 흰 꽃 결과를 사용했다. Chromium 390×844와 1280×800에서 표시된 이미지의 데이터 PNG를 로컬 `669-white` 아틀라스의 첫 프레임을 같은 캔버스 크기로 추출한 데이터 PNG와 각각 비교해 일치했고, 재진입 후에도 일치하며 시험 저장이 바뀌지 않았다. 외부 이미지는 대체했지만 비교한 폼 아틀라스는 로컬 실제 파일이다. 이 검사는 브라우저 에뮬레이션이며 이로치·다른 폼·실기기와 화면 전체 비교는 아니다.

기존 포켓로그 데이터의 흰 꽃 결과에서 `rogueSourceId=669`, `rogueFormIndex=4`, `id=30106`이 모두 일치하면 현재 폼 목록에서 흰 꽃 키가 하나로 확인되고 해당 기록은 성별별 이미지가 없다. 읽기 전용으로 키를 더한 사본의 선택기가 `669-white`를 고르는 경량 검사도 통과했다. 다만 일부 다른 아틀라스는 성별에 따라 달라 과거 결과의 빠진 성별을 폼 번호만으로 복원할 수 없다. 실제 사용자 저장에 적용하거나 원본 기록을 수정하지 않았고, 과거 결과의 일반적인 복구는 식별자 충돌·누락과 성별 조건을 검증하는 별도 구현이 필요하다. 운영 데이터와 Sites는 변경하지 않았다.

## 이로치·성별·다른 폼 대표 렌더 검사

실제 부화 함수로 만든 시험 결과의 흰 꽃 플라베베 일반 이로치(변형 0), 암컷 에써르, 삐죽귀 피츄를 격리 Chromium 390×844와 1280×800에서 각각 표시했다. 해당 로컬 `shiny/669-white`, `876-female`, `172-spiky` 아틀라스의 첫 프레임과 화면 이미지의 픽셀이 모두 일치하고 재진입 후에도 유지됐다. 기본 흰 꽃 검사도 재실행해 통과했다. 외부 이미지는 대체했으며 비교 대상은 로컬 실제 아틀라스다.

별도의 경량 엔진 검사는 암컷·수컷 에써르의 폼 식별, 삐죽귀 피츄와 흰 꽃 이로치의 부화 결과·저장 복원 후 이미지 선택을 확인했고 기존 알 폼 검사와 합쳐 4건이 통과했다. 수컷 에써르 기본 폼은 해당 검토 아틀라스가 없어 기본 이미지 경로를 유지하며, 이번 브라우저 픽셀 비교 대상은 아니다. 이로치의 다른 색 변형, 다른 폼·성별·실제 단말 및 운영 저장은 검증하지 않았다. 새 결함은 재현되지 않아 게임 로직과 과거 결과는 변경하지 않았다.

## 검증된 과거 흰 꽃 결과 표시 보정

위에서 확인된 과거 결과의 `rogueSourceId=669`, `rogueFormIndex=4`, `id=30106`, `artId=669`가 모두 일치하고 폼 키가 없으며 변신·융합·상충하는 모습 정보가 없는 경우에만 응답의 사본에 `rogueFormKey=white`를 제공한다. 대기 결과와 부화 이력의 화면 응답에 적용하며 저장 기록을 고치거나 누락된 성별을 추정하지 않는다. 다른 값이나 명시적인 폼 키가 있는 결과는 그대로 둔다. 따라서 다른 과거 폼의 누락 이미지 문제는 해결 범위가 아니다.

격리 API에서 보정된 대기 결과·이력의 이미지 선택, 조회 시 원본 저장 행 불변, 결과 확인 뒤 기존 이력·코인·다른 슬롯 보존을 확인했다. 잘못된 종·폼·ID·아트 ID와 충돌하는 정보는 건너뛰는 단위 검사와 부화·환급 및 교환권 관련 검사도 통과했다. Chromium 390×844·1280×800에서 키 없는 시험 결과가 실제 로컬 흰 꽃 아틀라스 픽셀로 표시되고 재진입 뒤에도 저장이 바뀌지 않음을 확인했다. 실제 기기·운영 기록과 다른 과거 폼은 검증하지 않았다. Sites에는 배포하지 않았다.
