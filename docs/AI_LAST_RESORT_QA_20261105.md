# AI 뒀다쓰기 조건

원본 `lastResortCondition`과 현재 엔진의 기술 실행 조건을 대조했다. 신규 도전의 AI는 뒀다쓰기 이외의 기술을 모두 사용하기 전, 또는 뒀다쓰기 이외의 기술이 없는 경우 이 기술을 기절 후보에서 제외하고 점수를 낮춘다. 다이맥스 기술에는 조건을 적용하지 않는다. 기존 도전은 이전 AI 판정을 보존한다.
