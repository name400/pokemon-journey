# 사이드 미션 106 — 클레피의 잃어버린 열쇠

[의뢰 목록](https://bulbapedia.bulbagarden.net/wiki/Mission_%28Legends%3A_Z-A%29)과 [현장 안내](https://www.videogameschronicle.com/guide/pokemon-legends-z-a-klefkis-lost-key-walkthrough/)에 따라 미션 35의 연구소 이후 Cadena에게 의뢰를 받고, 미용실과 카페 인근 배틀코트의 열쇠를 찾으면 5,000원과 금구슬을 받는다. 현재 게임에서는 이베르날 대로와 베르 9번지의 기존 이동 가능한 칸에 의뢰인과 반짝이는 목표를 표시한다. 기존 2D 맵에는 원작 코트의 정확한 형태와 위치가 구현돼 있지 않으므로 두 칸은 임시 배치이며, 현장 도착 장면은 단계별 상호작용으로 근사했다. 열쇠를 찾기 전에는 원작 단서처럼 정확한 위치를 지도 표식으로 알려주지 않는다.

기존 저장에 없는 단계는 미수락으로 취급하고, 찾은 열쇠와 수령 대기를 따로 저장한다. 가방이 가득 차거나 지갑 안전 한도를 넘으면 보상은 그대로 대기한다. 기존 리비전으로 중복 지급을 막고 포켓몬과 공유 데이터를 수정하지 않는다. 격리 API에서 해금·수락·발견·재접속·가방 한도·중복 수령과 파티 및 공유 속성 보존을 확인했다. 두 지점의 기존 맵 접근도 확인했다. 실제 원작 기기·운영 D1·Sites 병합본과 정확한 위치는 확인하지 않았다.
