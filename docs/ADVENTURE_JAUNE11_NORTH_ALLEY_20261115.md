# 존느 11번지 북쪽 골목

[존느 11번지 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-11.html)는 북쪽의 두 건물 사이 골목을 설명한다. 기존 북쪽 건물 덩어리에서 막혀 있던 네 칸을 열어 양끝에서 걸을 수 있는 골목으로 만들었다. 기존 통행 가능 칸과 주변 도로·구역 6 출입은 유지한다.

두 건물과 골목의 폭·좌표·정확한 외형은 기존 2D 화면에 맞춘 추정이다. 자료의 골목 아이템과 원작 옥상·단차의 정밀 배치는 이번에 추가하지 않았다. 골목 횡단·주변 출입·저장 복원 및 모의 API PC·모바일 화면을 검사했다. 실제 운영과 Sites 병합본은 확인하지 않았다. `testfailed.md`의 배포 검사 16건과 모바일 D1 이동 오류는 운영 재검증 전까지 유지한다.
