# Rust Syndicate 사무소

[원작 미션 20 안내](https://www.thonky.com/pokemon-legends-z-a/main-mission-20-a-request-from-the-rust-syndicate)는 안뜰을 지나 사무소 문으로 들어가는 흐름을 설명한다. [사무소 자료](https://bulbapedia.bulbagarden.net/wiki/Rust_Syndicate_Office)와 [실내 장면](https://note.com/ciovlog/n/nff70f17c4d8e)을 바탕으로 기존 안뜰과 별도 사무실을 연결하고 책상·상담 공간·장식을 초안으로 표현했다.

미션 20의 Corbeau 면담·의뢰·완료 보고와 미션 24 승급전·보상을 실내에서 진행할 수 있다. 단원과 Philippe 배틀은 기존 안뜰에서 진행한다. 기존 저장과 플레이 경로를 위해 안뜰의 기존 직접 상호작용도 유지한다. 건물 출입구와 실내 치수, 가구 및 인물 좌표는 원작과 정밀 대조되지 않은 초안이다.
