# 식당 연속 배틀의 회복 도구

[르 와우 의뢰](https://www.serebii.net/legendsz-a/sidemissions/fullcourseofbattles%3Athreestars.shtml)는 10연전 사이 회복을 금지하며, [공략](https://game8.co/games/Pokemon-Legends-Z-A/archives/559530)은 전투 중 도구도 사용할 수 없다고 설명한다. [스시 하이 롤러 의뢰](https://gmtreks.com/pokemon-z-a/side-missions/73)도 회복 없이 다섯 번 연속 대전한다.

기존 구현은 전투 사이 회복을 막았지만, 실제 두 식당의 배틀 중에는 상처약을 사용해 재고를 소모하고 턴을 진행할 수 있었다. 서버에서 두 코스가 진행 중인 전투의 회복 도구와 부활 요청을 거부하고 화면의 도구 명령도 숨긴다. 기존 진행 중 배틀이나 저장을 변환하지 않으며, 기술에 의한 회복과 일반 전투의 도구 사용은 그대로 둔다.

격리 SQLite API에서 각 식당의 실제 코스 시작·재접속 뒤 상처약, 파티 대상 상처약, 맛있는물, 부활 및 임의 도구 명령을 거부하고 재고·HP·리비전이 보존됨을 확인했다. 기존 스시 연전과 르 와우 10연전, 일반 전투 회복·부활을 대표 회귀 검사했다. 실제 원작 기기·운영 D1·Sites 병합본은 검증하지 않았다.
