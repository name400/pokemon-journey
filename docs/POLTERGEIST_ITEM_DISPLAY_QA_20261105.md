# 폴터가이스트 도구 표시와 폼 도구

원본은 이전 가능한 첫 소지 효과 이름을 기술 사용 직후 표시하며 빗나가더라도 해당 안내가 나온다. 신규 규칙 전투에서 보상·가방과 같은 한국어 이름을 사용하고 명중 판정 전에 안내하도록 연결했다. 네이티브 소지 도구 및 예전 전투 로그의 영문 도구명도 한국어로 표시하며, 확인할 수 없는 이름은 일반 이름으로 표시한다. 소지 도구는 사용하거나 변경하지 않는다.

원본의 폼 변화 도구는 이전 불가이므로, 기존 검토 목록에 네이티브 녹슨검·녹슨방패를 추가했다. 다른 모든 네이티브 도구의 이전 가능 여부와 복합 폼·도구는 전수 분류하지 않았다. 원본 난수·특수 상황과 실제 계정·실기기 검증은 남아 있다.

격리 전투에서 소지 효과·열매·타입 강화 도구·네이티브 도구 이름, 이전 불가 도구 뒤 첫 유효 효과 선택, 빗나감 시 안내 순서와 혼란 로그 회귀를 확인했다.

관련 도구·열매·미스터리·첫 턴·변신·호출·AI·날씨·지형·트레이너·상태·챌린지·융합·학습·스케치 회귀는 일반 실행과 Worker 로더에서 각각 466건 통과했다. 타입 검사와 빌드도 통과했으며 전체 프로젝트 검사는 아니다.
