# 미션 41 돔 조사

[원작 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-41-the-one-that-takes)은 시뮬레이터를 마친 뒤 갤러리 돔에 올라 목표 지점을 조사하고 이벨타르와 만나는 흐름을 설명한다. 새 진행은 기존 비계·사다리·로토글라이드 경로로 돔에 오른 후 흔적을 조사해야 이벨타르가 나타난다. 도망 후에는 기존과 같이 재도전할 수 있다. 미션 41이 이미 조우 단계인 과거 저장은 조사 플래그가 없어도 기존 조우를 유지한다.

정확한 돔 좌표·비계 형상과 연출은 초안이다. 원작 공략의 두 번째 돔 활공은 강제하지 않으며 조사한 돔 위에서 바로 조우할 수 있도록 단순화했다. 기존 저장 형식과 전투·포획 규칙은 유지한다.
