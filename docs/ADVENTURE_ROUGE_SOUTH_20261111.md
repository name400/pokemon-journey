# 루주대로 남쪽 연결

- [Avenue Rouge](https://www.pokepedia.fr/Avenue_Rouge)는 루주 광장이 대로를 남북으로 나누며 남쪽에 루주 1번지가 연결된다고 설명한다.
- [Zone sauvage n° 20](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_20)은 구역 20의 북쪽 출입구를 루주대로에 위치시킨다.

이 관계를 바탕으로 루주 광장, 루주 1번지, 구역 20을 잇는 별도 거리 화면을 추가했다. 거리의 정확한 타일 좌표, 건물 윤곽과 각 출입구의 화면상 위치는 자료에서 확인하지 못한 2D 초안이다. 기존 직접 출구는 이전 저장과 경로를 위해 유지하므로 원작 지도를 축소 없이 재현한 것은 아니다.

구역 20 입장에는 기존 진행 제한을 적용한다. 기존 저장의 위치와 파티를 보존하며, 지도 버전 불일치로 위치를 복구할 때 거리 화면 플래그도 함께 정리한다. 구역 20 단위 검사 13건과 기존 출구·신규 거리의 서버 API 대표 검사 4건이 통과했다. 실제 운영 기기에서는 확인하지 않았다.
