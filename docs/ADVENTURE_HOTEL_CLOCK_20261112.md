# Hotel Z 휴식과 로열 시간

[Hotel Z 자료](https://bulbapedia.bulbagarden.net/wiki/Hotel_Z)는 202호 침대에서 아침이나 밤까지 쉴 수 있다고 설명한다. 202호 침대의 선택지를 연결해 개인 모험 시간을 앞으로 보내고 파티의 HP·상태·PP를 회복한다. 신규 도입의 첫 취침도 아침으로 이어진다. 기존 저장은 휴식을 선택하기 전까지 종전 시간과 같다.

저장된 시간 차이는 기존 20분 주기의 1시간 단위이며 실제 시각에 따라 계속 흐른다. 서버 응답, 낮밤 출현·로열 제한·볼 보정과 클라우드 모험의 시간 조건 진화가 같은 시계를 사용한다. 포켓로그와 다른 플레이어의 시계는 바꾸지 않는다. 원작의 정확한 낮밤 길이와 연출은 재현하지 않으며, 운영 기기에서는 미검증이다.

격리 검사에서 두 계정의 시간 분리, 아침·밤 전환과 재접속, 회복, 밤 로열 입장 및 배틀을 확인했다. 시간·보름달 경계와 진화 조건 및 기존 로열·진화 검사도 확인했다.

도입 전투 회귀 검사 중 양쪽이 동시에 기절하고 승리한 경우 파티가 전멸한 채 다음 단계로 넘어갈 수 있음을 발견했다. 이 경우에만 동료가 파티를 회복하며, 해당 실제 전투와 탈출 이동을 격리 검사했다. 기절한 개체에 경험치를 추가하지 않는 기존 지급 조건은 유지한다.
