# 홀로베이터 아래의 포켓몬

[원작 의뢰 자료](https://www.serebii.net/legendsz-a/sidemissions/underneaththeholovator.shtml)와 [공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-023-underneath-the-holovator)을 참고해 베르날 대로에서 Terra의 의뢰를 받고 레벨 28 파르토를 포획하거나 격파할 수 있다. 파르토가 물러나면 홀로베이터가 작동하고, 의뢰 보상 1,500코인·부드러운모래·기력의조각을 받을 수 있다. 도망·기권과 실패한 포획은 완료로 처리하지 않는다. 도구함이 가득 차도 수리된 홀로베이터를 먼저 사용할 수 있고 보상은 남겨 둔다.

기존 지상 경계의 통행 불가 칸에 새 상호작용을 배치해 기존 저장 좌표와 이동 통로를 보존했다. 수리된 홀로베이터는 기존 베르날 동쪽 옥상과 연결하며 기존 사다리와 복귀도 유지한다. 정확한 의뢰·승강장 타일과 이 2D 옥상 연결은 추정이며 원작의 정확한 경로나 고도로 확정하지 않는다. 원작 실기와 운영 D1은 확인하지 않았다.

격리 API에서 해금 전 거절, 의뢰 수락·도망·기권·재접속·격파·포획, 가방 한도와 중복 보상 거절, 보상 전후 홀로베이터 왕복을 확인했다. 격파 검사는 상대 HP를 조정했다. 포획 테스트의 최초 실패는 기존 게임의 자동 파티 편입, 두 번째 실패는 새로 배울 기술 확인이 필요한 조건을 테스트가 처리하지 않은 것이었다. 해당 기존 동작을 검증하도록 검사 조건을 수정했다. 기존 베르날 옥상·카페·이동 예측·수첩 대표 검사가 통과했다. Sites 병합본과 실제 브라우저 화면은 확인하지 않았다.
