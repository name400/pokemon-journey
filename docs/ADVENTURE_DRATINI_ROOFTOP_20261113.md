# 미뇽 도시 옥상 획득

기존 클라우드 탐험의 야생 출현에서 미뇽의 획득 경로를 찾지 못했다. [현장 안내](https://www.powerpyx.com/pokemon-legends-z-a-dratini-location/)는 베르 6번지 레스토랑 르 나 주변 옥상에서 낮에 미뇽이 나타나며 레벨 30·55에 각각 진화한다고 설명한다. [출현 데이터](https://www.serebii.net/pokearth/lumiosecity/vertdistrict.shtml)는 베르 지구에서 미뇽이 레벨 28~29에 등장한다고 기록한다.

기존 베르 6번지 사다리·활공 옥상에 레벨 28 조우 지점을 추가했다. 현재 옥상은 동북쪽 경로의 초안이므로 르 나의 정확한 지붕 위치로 확정하지 않는다. 2D 좌표·출현 빈도는 추정이며 원작의 드문 출현과 접근 시 도주는 미구현이다. 기존 벽에 상호작용을 배치해 통행 가능한 저장 좌표를 바꾸지 않고 밤에는 나타나지 않는다. 포획한 개체와 연구·도감 이력은 기존 로직을 사용한다.

격리 API에서 사다리·활공 접근, 낮·밤 전환, 포획·재접속, 진화와 중복 요청 및 원래 파티 보존을 확인했다. 진화 단계 검사는 포획 개체의 레벨을 시험 데이터로 설정했으므로 레벨 육성 전체를 검증하지는 않았다. 연구 레벨 50의 정상 완주는 별도 검증이 필요하다.
