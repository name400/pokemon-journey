# 사이드 미션 45: 홀로베이터 유지 보수

[원작 의뢰 자료](https://www.serebii.net/legendsz-a/sidemissions/onmaintenanceduty.shtml)에 따라 미션 19 시작 뒤 블루 7번지의 Durstin에게 맛있는물·미네랄사이다·후르츠밀크·튼튼밀크 중 보유한 음료 하나를 건네면 홀로베이터를 수리한다. 맛있는물은 기존 월드 재고에서, 다른 음료는 가방에서 차감한다. 수리 즉시 승강기를 사용할 수 있고 800원·성실민트·카리열매 10개는 가방 공간을 확보한 뒤 한 번 받는다.

기존에 막혀 있던 건물 칸을 승강장으로 사용하고 기존 옥상과 사다리·저장 복귀를 유지한다. 승강장 좌표와 연결되는 2D 옥상은 추정이며 원작의 정확한 옥상 구조를 확인하지 못했다. 의뢰 진행과 수령은 리비전으로 중복 처리하며 알 수 없는 저장 단계는 덮어쓰지 않는다. 원작 기기·운영 D1·실제 Sites 병합본은 검증하지 않았다.
