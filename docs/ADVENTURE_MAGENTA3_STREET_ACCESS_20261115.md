# 마젠타 3번지와 마젠타 거리 지상 접근

[마젠타 3번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/magenta-sector-3.html)는 북쪽 마젠타 거리 접근을, [거리 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/magenta-street.html)는 남쪽 마젠타 3번지 접근을 설명한다. 기존 지도에는 두 화면 사이의 직접 지상 경로가 없었다.

기존 지상 화면에 왕복 접근을 추가했다. 출입 좌표와 길의 선형·폭은 원작에서 측정되지 않은 2D 추정이다. 기존 운하·다리, 에스티발 대로, 구역 7 입장 제한과 홀로베이터·옥상을 유지한다. 이전 통행 칸을 막거나 저장 형식·미션 진행을 바꾸지 않는다.

대표 단위 검사에서 양방향 이동·저장 복원, 기존 수로·다리, 구역 7 제한과 홀로베이터·옥상을 확인했다. 원작 실기·운영 D1·실제 Sites 병합본은 확인하지 않아 모바일 이동 오류와 배포 검사 실패 기록을 유지한다.
