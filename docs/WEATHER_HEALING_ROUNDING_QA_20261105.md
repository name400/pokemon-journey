# 날씨 회복 기술의 비율과 반올림

원본 `sunnyHealRatioFunc`와 `HealAttr.addHealPhase`를 대조했다. 신규 도전의 `sunnyHealSourceRule: source-v1`은 광합성·달의불빛·아침햇살에 햇살 2/3, 비·모래바람·눈·싸라기눈·안개 1/4, 강풍·무날씨 1/2를 적용하고 원본처럼 반올림한다. 메가솔은 사용자의 유효 날씨를 햇살로 처리한다. 기존 도전은 기존 규칙을 유지한다.

격리 전투와 저장 복원에서 세 기술의 무날씨·안개 반올림, 비·강풍, 높은 HP에서의 햇살 비율, 메가솔과 억제, 날씨부정, 치유 부적, 상대 사용 및 다른 저장 데이터 보존을 검사했다. 모래바람·눈·싸라기눈·원시 날씨와 기타 특성·도구의 모든 조합 및 실제 브라우저 플레이는 별도 검증이 필요하다. 운영 데이터와 Sites는 변경하지 않았다.
