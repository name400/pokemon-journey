# 무장조 알기술 거수참 재검사 — 2026-11-18

고정 참조 데이터에서 무장조의 두 번째 알기술 슬롯이 거수참에 대응한다. 새 격리 엔진 검사에서는 무장조가 등록돼 있어도 해당 알기술을 해금하기 전 스타터 편성에 거수참을 넣을 수 없고, 저장 복원 뒤에도 같은 요청이 거절되는 것을 확인했다. 다른 슬롯과 탐험 데이터도 유지됐다.

별도 시험에서는 부화 직전인 무장조 알과 두 번째 알기술 슬롯을 주입한 뒤 실제 부화 처리로 거수참 해금을 확인했다. 복원 후 스타터에 장착하고 실제 전투에서 사용했을 때 PP가 5에서 4로 감소했으며, 다시 저장·복원한 파티와 전투에 기술과 PP가 유지됐다. 해금 후 잊은 거수참을 실제 보상 후보로 생성된 기억버섯으로 다시 배우는 경로도 확인했다. 관련 엔진 검사 5건이 통과했으며 해당 표본에서 결함은 재현되지 않았다.

전용 격리 Vite 서버와 Chromium 390×844·1280×800에서는 이미 해금된 시험 무장조가 생성된 기억버섯 보상에서 거수참을 선택하고, 새로고침 후 기술과 해금 정보가 유지되는 것을 확인했다. 이 브라우저 검사는 부화나 전투를 실행하지 않았다. 알의 자연 획득·모든 확률, 운영 저장·실기기는 확인하지 않았고 Sites에는 배포하지 않았다.
