# 만병통치약과 미르갈레트

[Serebii 도구 목록](https://www.serebii.net/legendsz-a/items.shtml)은 두 도구를 상태 회복 도구로 설명한다. 기존 탐험에서 획득한 만병통치약과 미르갈레트를 필드와 턴제 전투에서 자기 파티원에게 사용할 수 있게 연결했다. 전투에서는 한 턴을 소비하며 보유 도구 하나를 사용하고 혼란도 해제한다. 필드에서는 저장된 상태이상을 치료한다. 원작의 실시간 메뉴·대기시간을 재현한 것은 아니다.

소유하지 않은 개체, 기절했거나 회복할 상태가 없는 개체, 도구 부족과 오래된 리비전은 거절한다. 대여·식당·통신 전투와 포획 대기 중 사용은 제한하며 기존 아이템과 저장을 일괄 변환하지 않는다.

격리 SQLite API에서 두 도구의 필드·단일·1대2·동료 전투, 재접속·소유권·중복 요청을 확인했다. 세 아군 엔진에서 소유권·혼란·복원을 확인했고, 모의 API와 대체 이미지를 사용한 PC·모바일 Chromium에서 전투 중 사용을 확인했다. 운영 D1·기기, 실제 3인 API 및 필드 화면 조작은 검사하지 않았다.
