# 구역 3 루주 광장 보강

별도 조사에서 전달된 [원작 지도](https://images.nintendolife.com/a8501536a999a/wild-zone-3-pokemon-legends-z-a.large.jpg)와 [원작 장면](https://www.serebii.net/pokearth/maps/lumiosecity/4.jpg)의 남북 접근, 중앙 원형 공간, 네 정원과 서쪽 기둥 건물에 관한 분석을 기존 지도와 대조했다. 이 작업 환경에서 두 이미지를 직접 확인하지는 못했다. 기존 네 정원에 서쪽·동쪽의 다른 문양과 회색 곡선 테두리를 그렸고, 중앙 보행면에 원형 포장선을 추가했다. 서쪽 건물 주변에서는 기존에 막혀 있던 울타리 칸을 석조 기둥으로 표현하고 이미 구현된 건물 진입과 내부 동선을 유지했다. 건물 형태와 기둥·포장선의 정확한 위치는 2D 추정이다.

별도 분석의 구역 출입은 남북 두 곳이다. 기존 화면에는 도시 연결과 이전 저장을 위한 다른 가장자리 출구도 섞여 있어 이를 삭제하거나 원작 야생 구역 게이트라고 확정하지 않았다. 현재 풀숲·조우·충돌 타일과 동선은 그대로다. 옥상 기술머신에 대한 접근·높이가 확인되지 않아 사다리나 신규 옥상 연결은 만들지 않았다. 정원 문양을 타일별로 캐시해 반복 렌더링에서 재계산하지 않는다.

정원 문양·경로 단위 검사, 동남쪽 연결·가시덤불·남쪽 옥상 진입 및 구형 저장 관련 격리 API 검사를 통과했다. PC 1280×850과 모바일 390×844의 Chromium 모의 API 화면에서 캔버스와 오류 없음을 확인했다. 외부 이미지는 대체 표시이며 원작 기기·실제 운영 데이터·정확한 원작 충돌은 확인하지 않았다.
