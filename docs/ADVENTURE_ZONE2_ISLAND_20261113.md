# 구역 2 중앙 섬과 제방

별도 조사에서 전달된 원작 확대 지도 분석은 북서·남쪽 출입구, 수면 가운데 불규칙한 섬과 세 연결물, 둥근 바깥 제방을 설명한다. [구역 설명](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_2)은 얕은 강과 중앙 섬, 목교 두 개와 높은 전망부를 확인한다. 세 번째 연결물의 종류와 높이는 확정되지 않았다. 이 작업 환경은 원본 이미지 파일을 직접 열 수 없어 별도 조사에서 전달된 분석을 근거로 삼았으며 이미지와의 직접 대조를 주장하지 않는다.

기존 중앙 수면 중 여섯 칸을 섬의 풀로 바꿔 섬 윤곽을 넓히고, 일반 바닥에는 둥근 제방을 색으로 표현했다. 수변 일부에는 바위 가장자리를 그렸다. 기존 세 연결과 출입·전망층은 유지한다. 바깥 제방은 시각적 표현이며 실제 충돌 경계는 기존 직사각형 맵을 유지한다. 섬과 물의 정확한 윤곽, 난간·연결물의 형태와 높이는 여전히 추정이다. 기존 통행 가능 칸을 막지 않았고, 별가사리 이동 범위의 수면도 변경하지 않았다.

기존 이동 가능 칸의 전수 비교, 세 연결·동쪽 바위 경로, 기존 저장 좌표·파티·현장 개체 기록을 검사했다. 격리 API에서 남서 연결→새 섬→북동 연결 왕복과 재접속을 확인했다. PC·모바일 Chromium 화면은 시험 데이터와 외부 이미지 대체물을 사용했다. 원작 기기 및 운영 환경은 검증하지 않았다.

## 북동 연결의 방향 보완

별도 조사에서 전달된 확대 지도 분석에는 중앙 섬 북동쪽에서 북동 육지 쪽으로 이어지는 연결물이 보인다. 이전 2D 맵은 이 연결의 북쪽 부분이 물로 막혀 동쪽으로만 나가게 되어 있었다. 기존 연결 (15,6)을 유지하며 북쪽 물 세 칸 (15,3~5)을 다리로 바꿔 북쪽 제방으로도 왕복할 수 있게 했다. 다른 두 연결과 중앙 섬, 북서·남쪽 입구 및 기존 동쪽 출입은 유지한다. 기존 동쪽 경로 차단 검사는 이제 연결 전체를 막고 우회가 없는지 확인한다.

추가된 칸은 이전에 수면이어서 기존 정상 지상 저장 좌표를 막지 않는다. 구형 위치의 복원과 야생 별가사리 기록, 세 연결과 두 입구의 접근을 단위 검사했고, 격리 API에서 새 연결의 남북 왕복·재접속·파티와 도구 보존을 확인했다. PC·모바일 Chromium 화면은 시험 데이터와 외부 이미지 대체물을 사용했다. 이 환경에서는 원본 지도를 직접 열지 못했으며 연결의 정확한 좌표·기울기·재질·높이, 둥근 외곽의 충돌 경계 및 나머지 2D 지형은 확인되지 않은 초안이다.

## 북서·남서 연결과 섬 윤곽 보완

별도 조사에서 전달된 지도 분석의 상대 위치는 중앙 섬에서 북서 소지형 및 남서 제방으로 연결되는 구조를 보여 준다. 기존의 북서·남서 연결은 모두 서쪽에서 남북 방향으로만 그려져 있어, 기존 두 통로를 남긴 채 각 통로에서 섬 방향으로 연결을 두 칸씩 연장했다. 섬의 북쪽에도 기존 수면 두 칸을 풀로 바꾸어 비대칭 윤곽을 보완했다. 게임의 나무 발판 타일은 이해를 돕는 2D 표현이며, 특히 북서 연결물이 실제 목교인지 전망로인지는 확인되지 않았다.

이전에 걸을 수 있던 모든 칸은 계속 통행할 수 있고, 추가된 여섯 칸은 모두 이전 수면이다. 별가사리의 저장 가능한 수면 반경과 이전 물고기·육지 개체의 기존 타일은 바꾸지 않았다. 구형 저장과 별가사리 위치, 각 연결의 실제 왕복 및 재접속·파티·재화 보존을 대표 검사했다. PC·모바일 Chromium은 시험 상태와 외부 이미지 대체물을 사용해 확인했다. 북서·남쪽 출입구, 중앙 섬, 북동 연결은 유지한다.

전달된 원작 이미지 **분석**을 기준으로 한 상대 구조 개선이다. 이 환경에서 원본 이미지는 직접 열지 못했으며 정확한 3D 높이, 발판 재질, 세부 좌표와 원형 외곽의 실제 충돌 경계는 미확인이다. 둥근 제방은 기존 시각적 표현이고 충돌 경계는 직사각형 초안이다.

## 외곽 이동·구형 저장 점검

둥근 제방 색은 보행 불가 경계가 아니라 일반 바닥 위의 색상이며, 그 바깥의 베이지색도 보행 바닥으로 표시된다. 따라서 이를 근거로 기존 외곽을 일괄 차단하면 기존 저장과 입구를 손상할 수 있어 적용하지 않았다. 다만 남동쪽 베이지색 바닥 여섯 칸(19~21, 14~15)이 물과 직사각형 외벽 사이에 완전히 고립된 문제가 있었다. 바위 해제 전후 모두 입구에서 닿지 못했고, 해당 바닥의 구형 저장은 정상 복원되지만 남쪽 출구로 나갈 수 없었다.

남쪽 가장자리의 물 한 칸 (18,15)을 일반 제방 바닥으로 바꿔 여섯 칸을 기존 남쪽 출입 동선에 연결했다. 이는 저장을 옮기지 않는 안전한 2D 접근 보정이며 원작의 실제 충돌이나 지형을 확인한 좌표는 아니다. 별가사리의 이동·저장 가능한 수면 반경 밖이고 원래 통행 가능한 칸을 막지 않는다. 바위로 제한되는 동쪽 얕은 물, 북서·남쪽 출입구 및 기존 세 섬 연결은 유지한다.

변경 전 격리 상태에서 (19,15)의 서쪽 이동이 물에 막히는 것을 확인했고, 변경 후 기존 위치를 복원해 남쪽 출구까지 이동했다. 구역 안 재접속 시 야생 위치·소진 기록과 파티·재화를 확인했으며 구역을 떠날 때의 기존 야생 슬롯 갱신 동작은 그대로다. 양쪽 바위 상태·여섯 바닥·두 출입구 및 물과 외벽의 차단을 단위 검사했고 PC·모바일 Chromium의 전후 화면은 시험 데이터와 대체 이미지로 확인했다. 실제 원작 지도 이미지 및 충돌 판정은 이 환경에서 직접 확인하지 못했으며 원형 외곽의 정확한 경계는 여전히 미구현이다.
