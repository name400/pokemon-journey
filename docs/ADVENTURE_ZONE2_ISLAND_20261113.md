# 구역 2 중앙 섬과 제방

별도 조사에서 전달된 원작 확대 지도 분석은 북서·남쪽 출입구, 수면 가운데 불규칙한 섬과 세 연결물, 둥근 바깥 제방을 설명한다. [구역 설명](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_2)은 얕은 강과 중앙 섬, 목교 두 개와 높은 전망부를 확인한다. 세 번째 연결물의 종류와 높이는 확정되지 않았다. 이 작업 환경은 원본 이미지 파일을 직접 열 수 없어 별도 조사에서 전달된 분석을 근거로 삼았으며 이미지와의 직접 대조를 주장하지 않는다.

기존 중앙 수면 중 여섯 칸을 섬의 풀로 바꿔 섬 윤곽을 넓히고, 일반 바닥에는 둥근 제방을 색으로 표현했다. 수변 일부에는 바위 가장자리를 그렸다. 기존 세 연결과 출입·전망층은 유지한다. 바깥 제방은 시각적 표현이며 실제 충돌 경계는 기존 직사각형 맵을 유지한다. 섬과 물의 정확한 윤곽, 난간·연결물의 형태와 높이는 여전히 추정이다. 기존 통행 가능 칸을 막지 않았고, 별가사리 이동 범위의 수면도 변경하지 않았다.

기존 이동 가능 칸의 전수 비교, 세 연결·동쪽 바위 경로, 기존 저장 좌표·파티·현장 개체 기록을 검사했다. 격리 API에서 남서 연결→새 섬→북동 연결 왕복과 재접속을 확인했다. PC·모바일 Chromium 화면은 시험 데이터와 외부 이미지 대체물을 사용했다. 원작 기기 및 운영 환경은 검증하지 않았다.

## 북동 연결의 방향 보완

별도 조사에서 전달된 확대 지도 분석에는 중앙 섬 북동쪽에서 북동 육지 쪽으로 이어지는 연결물이 보인다. 이전 2D 맵은 이 연결의 북쪽 부분이 물로 막혀 동쪽으로만 나가게 되어 있었다. 기존 연결 (15,6)을 유지하며 북쪽 물 세 칸 (15,3~5)을 다리로 바꿔 북쪽 제방으로도 왕복할 수 있게 했다. 다른 두 연결과 중앙 섬, 북서·남쪽 입구 및 기존 동쪽 출입은 유지한다. 기존 동쪽 경로 차단 검사는 이제 연결 전체를 막고 우회가 없는지 확인한다.

추가된 칸은 이전에 수면이어서 기존 정상 지상 저장 좌표를 막지 않는다. 구형 위치의 복원과 야생 별가사리 기록, 세 연결과 두 입구의 접근을 단위 검사했고, 격리 API에서 새 연결의 남북 왕복·재접속·파티와 도구 보존을 확인했다. PC·모바일 Chromium 화면은 시험 데이터와 외부 이미지 대체물을 사용했다. 이 환경에서는 원본 지도를 직접 열지 못했으며 연결의 정확한 좌표·기울기·재질·높이, 둥근 외곽의 충돌 경계 및 나머지 2D 지형은 확인되지 않은 초안이다.
