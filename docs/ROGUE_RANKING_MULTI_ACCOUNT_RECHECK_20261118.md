# 개인 최고기록·글로벌 랭킹 재검사 — 2026-11-18

독립된 격리 SQLite 계정 두 개에 동점과 같은 달성 시각을 설정해 계정 식별자 순서의 안정적인 순위, 재조회 시 기존 기록 유지와 서로의 개인 순위를 확인했다. 한 계정의 저장에서 완료 웨이브를 올리고 해당 계정으로 조회했을 때 그 계정의 최고기록만 갱신됐으며 다른 계정 기록·탐험 데이터는 유지됐다. 랭킹 응답에는 두 시험 계정의 내부 식별자가 노출되지 않았다. 동점 시각과 저장은 시험용으로 주입했다.

기존 랭킹 API 검사를 함께 실행해 낮거나 같은 점수에서 달성 시각을 보존하고, 상위 50명 밖 개인 순위와 프로필 없는 계정의 노출 제한, 저장 충돌 시 랭킹 미반영을 확인했다. 별도 실제 전투 승리 API에서 최고기록의 1회 갱신·재조회·중복 리비전 거절도 확인했다. 랭킹 검사 4건과 전투·충돌 API 검사 2건이 통과했다. 이 표본에서 새 결함이 재현되지 않아 게임 코드는 수정하지 않았다.

실제 계정·운영 D1, 분산 동시성, 모든 구형 저장과 실기기 화면은 이번에 확인하지 않았다. Sites에는 배포하지 않았다.
