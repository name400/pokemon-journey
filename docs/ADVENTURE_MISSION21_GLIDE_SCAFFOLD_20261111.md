# 미션 21: 로즈 6번지 비계 활공 접근

[원작 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-21-a-rogue-mega-mawile)은 구역 14 남쪽 건물의 사다리에서 활공한 뒤 다른 사다리와 경사로를 이용해 메가입치트가 있는 옥상에 오른다고 설명한다. 기존 로즈 6번지 비계와 사건 옥상 사이에 별도의 높은 비계층, 활공 간격과 두 번째 상승 지점을 연결했다. 활공은 기존 해금 조건을 사용한다.

좌표·높이·활공 거리와 경사로의 세부 형상은 확인되지 않은 2D 초안이다. 기존 옥상과 직접 연결된 비계 길 및 기존 저장은 그대로 유지하므로 새 경로가 유일한 경로는 아니다. 원작의 실시간 공격과 동료 동시 전투는 미구현이다.
