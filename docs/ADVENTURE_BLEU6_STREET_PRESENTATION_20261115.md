# 블루 6번지 접근로 시각 구분

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-6.html)는 블루 6번지에서 블루 거리와 에스파스 비드로 갈 수 있고 파사주 드 라 펠리시테 및 주변 건물·비계가 있음을 설명한다. 기존 2D 화면의 건물 외곽과 보도, 기존 비계와 상점 통로 방향을 색과 형태로 구분했다. 기존 비계와 통로의 실제 상호작용 및 이동 조건은 그대로다.

건물 형태·높이, 보도 폭, 비계와 두 통로 출입구의 격자 좌표는 원작에서 추출한 것이 아닌 초안이다. 지도 타일과 충돌, 출입 동선, 조우·아이템 및 저장 위치는 바꾸지 않았다.

기존 블루 거리·에스파스 비드 왕복, 상층·하층 구분 및 저장 복원 단위 검사 5건과 타입 검사가 통과했다. PC·모바일 Chromium에서 모의 API로 화면과 비계 안내를 확인했다. 원작 기기·운영 D1·Sites 병합본은 확인하지 않았다.
