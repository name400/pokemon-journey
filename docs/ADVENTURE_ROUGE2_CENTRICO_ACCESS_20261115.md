# 루주 2번지와 센트리코 광장 지상 접근

[루주 2번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/rouge-sector-2.html)는 남쪽 센트리코 광장 접근을, [광장 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/centrico-plaza.html)는 북쪽 루주 2번지 접근을 설명한다. 기존 지도에서는 갤러리 또는 인접 거리를 경유해야 했다.

기존 지상 화면에 왕복 접근을 추가했다. 출입 좌표와 길의 선형·폭은 원작에서 측정되지 않은 2D 추정이다. 기존 갤러리·학교·레스토랑과 구역 20 접근을 유지하며 이전 통행 칸을 막거나 저장 형식·미션 진행을 바꾸지 않는다.

대표 단위 검사에서 양방향 이동·저장 복원, 기존 갤러리·학교·레스토랑과 구역 20 접근을 확인했다. 원작 실기·운영 D1·실제 Sites 병합본은 확인하지 않아 모바일 이동 오류와 배포 검사 실패 기록을 유지한다.
