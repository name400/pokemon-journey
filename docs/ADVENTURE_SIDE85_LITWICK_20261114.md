# 사이드 미션 85: 불켜미를 따라가자

[Bulbapedia의 미션 목록](https://bulbapedia.bulbagarden.net/wiki/Mission_(Legends:_Z-A))과 [공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_81-100)을 참고해 미션 26 이후 마젠타 9번지의 Consei에게 의뢰를 받고 불켜미를 따라 하수도에서 여동생을 찾는다. 보상은 1,300원과 생명의구슬이다.

이 게임의 세 도시 경유지와 하수도 목표 타일은 원작의 정확한 동선을 확인하지 못해 현재 2D 지도에 맞춘 초안이다. 이동하는 포켓몬을 실시간으로 추적하지 않고 단계별 상호작용으로 근사하며, 기존 베르날 하수도 진입과 복귀 처리를 재사용한다. 원작 자료의 더 많은 추적 지점과 하수도 종점의 실제 위치·연출은 추후 대조가 필요하다.

구형 저장은 단계가 없으면 새로 시작한다. 하수도 복귀 위치, 기존 파티와 개체, 진행을 유지하고 생명의구슬 가방 공간이 부족하면 보상을 보류한다. 리비전 조건으로 중복 요청을 거부한다. 격리 API에서 도시 경유지 이동·재접속·기존 입구 진입·하수도 접근·가방 한도·중복 요청과 파티 보존을 대표 검증했다. 원작 기기, 운영 D1과 Sites 병합본은 미검증이다.
