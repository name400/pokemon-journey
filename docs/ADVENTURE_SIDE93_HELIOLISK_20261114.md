# 사이드 미션 93: 일레도리자의 집

[의뢰 공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-093-finding-a-place-for-heliolisk)과 [옥상 위치 안내](https://www.siliconera.com/where-to-go-in-pokemon-legends-z-a-for-finding-a-place-for-heliolisk/)를 참고해, 미션 31 시작 이후 남쪽 대로의 Trale에게 의뢰를 받고 마젠타 1번지 카페 근처 옥상에 오르면 태양의돌·경험사탕 M 2개·4000원을 받을 수 있게 했다. 기존 마젠타 옥상 사다리와 복귀 경로를 사용하며 정확한 인물·사다리 좌표와 옥상 형태는 2D 초안이다. 원작의 자동 장면 대신 옥상 사다리에서 보상을 확인한다.

수락된 의뢰와 보상 대기는 수첩에 표시한다. 보상 가방 공간이 부족하면 옥상 출입은 유지하고 수령만 보류하며, 재접속과 오래된 리비전의 중복 수령을 보호한다. 진행하지 않은 구형 저장과 다른 의뢰·나사 수집은 변경하지 않는다. 이미 옥상에 있는 구형 저장에서 의뢰 진행을 추정하지 않는다. 단계가 확인되지 않는 미래 저장도 자동으로 진행하지 않는다.

격리 SQLite API에서 해금 전 거부, 실제 옥상 접근·하강, 재접속, 가방 한도, 보상과 중복 요청, 구형 저장 및 파티 보존을 대표 검사했다. 원작 기기·운영 D1·Sites 병합본과 실제 PC·모바일 화면은 검사하지 않았다. 미션의 NPC와 일레도리자가 옥상으로 이동하는 실시간 연출은 미구현이다.
