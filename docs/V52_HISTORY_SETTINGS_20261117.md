# 포켓로그 단일 전투 기록 진입

v52 원본 주명령 화면에 없는 상시 전투 기록 보기 버튼을 포켓로그 단일 화면에서 제거하고 기존 전투 설정 메뉴에 기록 열기를 배치했다. 기록 데이터와 재생 중 메시지는 변경하지 않으며 더블 화면은 기존 버튼을 유지한다.

격리 Chromium 280×568, 390×844, 960×540에서 설정 메뉴의 키보드 열기, 기록 열기·터치로 닫기, 저장 불변을 확인했다. 단일·더블 320×568, 390×844, 844×390, 1280×800의 기록 스크롤·닫기, 연출 중단 시 미확인 처리와 기록 보존, 단일 도망 확인·취소·실제 요청 회귀가 통과했다. 이전 중단 이벤트 재접속 중복 재생 문제를 해결했다는 뜻은 아니다. 실제 기기와 전체 원본 픽셀 일치는 미검증이며 사용자 데이터와 Sites는 변경하지 않았다.

원본 포켓몬 PNG 묶음은 새로운 정식 전송 준비 후 다운로드가 다시 실패하여 수신·해시 확인을 하지 못했다. 원본 배우의 크기와 위치를 정확히 비교할 수 없다.
