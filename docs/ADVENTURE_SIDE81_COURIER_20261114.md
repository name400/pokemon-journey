# 사이드 미션 81: 판짱의 배달

- 남쪽 대로에서 Andi의 의뢰를 받은 뒤 동료와 Doléan의 포켓몬에 맞서고, 승리 후 보상을 받는다. 미션 26 진행 및 이후 저장에서 접근 가능하며 기존 저장에 필수 필드는 추가하지 않는다.
- [Serebii](https://www.serebii.net/legendsz-a/sidemissions/panchamthecourier.shtml), [Thonky](https://www.thonky.com/pokemon-legends-z-a/side-mission-081-pancham-the-courier): 상대와 레벨, 보상 및 진행 시점을 대조했다. [Lumiose Locations](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/south-boulevard.html)의 Andi 파티를 참고했다.
- 원작의 실시간 다수 대전은 기존 턴제 다수 엔진으로 근사해 상대 두 마리와 후보 한 마리를 배치했다. 동료 개체는 별도 전투 진영에만 두고 보유함에 저장하지 않는다. Andi의 정확한 2D 타일과 기술 세부는 확인되지 않은 초안이다.
- 재접속 시 진행 중 배틀을 복원하고, 패배 시 재도전 가능하다. 배틀 상금과 별도 의뢰 보상은 진행 단계 및 원자적 저장으로 중복 지급을 막는다. 가방 공간이 부족하면 의뢰 보상을 보류한다.
- 실제 Sites 병합본, 원작 실기 및 독립된 두 사용자의 서버 접속은 이번에 검증하지 않았다.
