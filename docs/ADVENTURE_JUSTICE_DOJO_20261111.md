# 정의단 도장

[정의단 도장 자료](https://bulbapedia.bulbagarden.net/wiki/Justice_Dojo)는 도장을 존느 구역 2에 두며 Josée와 대단한 특훈을 설명한다. [원작 현장 화면](https://poketrainervault.com/legends-za/guides/competitive-building-guide/)에는 난간으로 둘러싸인 야외 특훈 장소가 보인다. 기존 존느 구역 2와 도장 훈련 마당을 연결하고, Josée의 미션 19 배틀·보상과 Ivor 승급전·보상, 미션 37 이후 대단한 특훈을 연결했다.

입구와 인물 좌표, 마당 크기·배치 및 개방 시점의 상세 조건은 확인되지 않은 2D 초안이다. 예전 저장과 진행을 위해 기존 공사 현장의 임시 상호작용도 유지한다. 새 도장 입구는 기존 통행 가능 바닥을 통행 가능한 표식으로 변경하므로 저장 좌표를 이전하지 않는다.
