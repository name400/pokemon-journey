# 승인 v52 단일 전투 배경 대조

수신한 v52 코드의 `#bg`와 매니페스트에서 확인한 원본 배경을 격리 Chromium에서 같은 무대 크기로 비교했다. 게임의 기본 초원은 다른 픽셀 SVG를 사용하고 있었다. 원본은 1536×1024 이미지에 가운데 `cover`를 적용한다. 이미지와 크롭을 승인 단일 전투의 초원에 적용했으며 해안·화산은 기존 배경을 유지했다. 이 변경은 저장, 서버 전투 판정이나 2D 배우를 바꾸지 않는다.

390×844에서 배경을 제외한 화면 요소를 숨겨 비교했을 때 변경 전 40보다 큰 채널 차이를 보인 픽셀은 93.95%였다. 변경 후 320×568, 390×844, 844×390, 1280×800에서 각각 0.84%, 4.14%, 4.22%, 7.38%였다. 서로 다른 크기의 CSS 렌더링 경로에서 이미지 보간 차이가 있어 픽셀 완전 일치로 판단하지 않는다. 대조 이미지는 각각 `/tmp/v52-field-reference-390.png`와 `/tmp/v52-field-game-390.png`에 생성됐다. 원본과 게임의 전체 화면은 서로 다른 시험 포켓몬을 사용하고 원본 스프라이트 파일이 없어 전체 화면 일치 증거가 아니다.

같은 네 크기에서 명령·HP·레벨·네 기술의 좌표와 겹치지 않는 버튼 중심 입력, 기술 설명 열기·닫기, 각각의 기술 요청을 검사했다. 포켓로그 단일 명령·기록과 단일/더블 기술·상성 표시, 탐험 포획 선택과 강제 교체도 격리 브라우저에서 확인했다. 샘플은 격리 API/모의 외부 이미지이며 실기기, 운영 저장, 모든 전장·날씨와 전체 영상의 픽셀 일치는 미검증이다. Sites 배포는 하지 않았다.

## 명령 대기 중 메시지 가림

원본 명령 화면에는 메시지 상자가 없지만, 탐험 단일 전투는 이전 전투 문구를 경기장 왼쪽에 계속 표시했다. 명령 대기 중에는 상자만 투명하게 처리하고 스크린리더용 상태 노드와 설정의 전투 기록을 유지한다. 전송 대기 및 재생 중은 숨기지 않는다. 원본과 네 크기의 무대·HP·명령·기술 좌표, 동일 데이터의 기술명·PP·상성, 버튼 입력과 기록 열기를 검사했다. 390px에서는 네 주명령과 상태 확인의 내부 영역이 원본과 픽셀 단위로 같았다(볼 선택은 이 검사에 포함하지 않았다). 실제 엔진 교체·공격·상성 이벤트는 네 크기에서 메시지 위치를 비교했고, 390px에서는 재생 중 불투명도도 확인했다. 강제 교체도 네 크기에서 확인했다.

원본 포켓몬 PNG는 Drive에 존재하고 파일 참조는 받았지만 로컬 파일로 내려받지 못해 실루엣의 동일 이미지 직접 비교는 하지 못했다. 로컬 스프라이트로 촬영한 게임 화면과 원본 코드의 좌표 검사는 원본 그림 전체의 픽셀 일치를 보장하지 않는다. 저장·보상, 다른 모드와 사용자 데이터를 변경하거나 Sites에 배포하지 않았다.

## 상태 확인 뒤로 가기 위치

승인 v52의 상태 확인 화면은 오른쪽 아래에 `B 뒤로`가 있으나 탐험 단일 화면은 왼쪽 위에 명령과 기록 버튼을 표시했다. 상태 화면에 한해 뒤로 가기의 시각 표시를 원본 위치로 옮기고 44px 이상의 실제 터치 영역을 유지했다. 스크린리더용 버튼 이름 `명령으로`와 설정 메뉴를 통한 전투 기록 접근도 유지했다. 다른 화면의 버튼과 포켓로그 배치는 바꾸지 않았다.

격리 Chromium의 320×568, 390×844, 844×390, 1280×800에서 같은 상태 데이터의 원본 대비 상태 상자와 뒤로 가기 표시 위치·크기, 긴 이름, 실제 스프라이트, 터치 영역 및 설정과의 비중첩, 전투 기록과 닫기 동작을 검사했다. 별도로 탐험 기술·볼 선택, 포켓로그 단일·더블 상태·포획·새로고침을 확인했다. 실제 모바일 기기와 원본 포켓몬 이미지의 시각 일치는 미검증이다.

## PNG ZIP 수신 진단

직전 Library 전송은 `library_file_transfer.py materialize`를 사용했고 `workspace_path` 없이 `sdmntprcentralus.oaiusercontent.com` 호스트의 서명 URL 방식이 반환됐다. 도우미는 `download failed`만 반환하여 DNS, 네트워크 정책, HTTP 상태, 파일 권한 또는 만료 여부를 구분할 수 없었다. 안전 심사 거부 또는 권한 거부 결과는 반환되지 않았다. 요청에 따라 이번에는 재시도하거나 인증·네트워크 제한을 변경하지 않았다.
