# 야외 트레이너 배틀의 날씨

현재 날씨가 비인데 야생 조우와 일반 트레이너 일부를 제외한 여러 야외 배틀은 맑은 날씨로 시작하는 문제가 있었다. 블루 4·5번지, 마젠타 1번지와 3번지 옥상, 콰자르티코·센트리코 접근로, 야생 구역 1~20의 확인된 야외 위치에서 새 단일 배틀을 만들 때 비를 시뮬레이터에 전달한다. 지하 구역 20, 실내·하수도와 위치가 불명확한 경기장에는 적용하지 않으며, 배틀이 날씨를 명시한 경우 해당 설정이 우선한다. 이미 시작된 전투의 스냅샷이나 기존 저장은 수정하지 않는다.

[원작 날씨 자료](https://www.serebii.net/legendsz-a/weather.shtml)는 비가 물 기술을 강화하고 불꽃 기술을 약화한다고 설명한다. 현재 도시의 강우 시간표는 기존 잠정 게임 시계에 따르며, 현재 확인된 야외 위치의 새 다수 상대·동료 전투에도 같은 규칙을 적용하며, 블루 8번지의 미용실 앞 플라엣테 전투를 포함한다. 이 범위 밖의 야외 지역에는 적용되지 않는다. 원작 실기와 운영 D1·Sites 병합본은 확인하지 않았다.

격리 API에서 비·맑음 시작과 배틀 중 재접속·시간 변화·구형 요청을 확인했고, 단위 검사에서 야외·실내·지하·명시적 날씨의 구분과 같은 난수 조건의 물·불꽃 피해 방향을 확인했다. 기존 파티와 재화는 보존했다.

다수 전투는 생성 시 날씨를 스냅샷에 기록한다. 실내·지하와 구형 진행 중 전투는 기존 상태를 유지하며, 외부 시간 변경이나 재접속이 전투 날씨를 다시 설정하지 않는다. 격리 API의 플라엣테 전투에서 비·맑음과 재접속 및 중복 요청을 확인했고, 두 다수 전투 엔진의 저장 복원과 턴 진행을 확인했다.
