# 야외 트레이너 배틀의 날씨

현재 날씨가 비인데 야생 조우와 일반 트레이너 일부를 제외한 여러 야외 배틀은 맑은 날씨로 시작하는 문제가 있었다. 블루 4·5번지, 마젠타 1번지와 3번지 옥상, 콰자르티코·센트리코 접근로, 야생 구역 1~20의 확인된 야외 위치에서 새 단일 배틀을 만들 때 비를 시뮬레이터에 전달한다. 지하 구역 20, 실내·하수도와 위치가 불명확한 경기장에는 적용하지 않으며, 배틀이 날씨를 명시한 경우 해당 설정이 우선한다. 이미 시작된 전투의 스냅샷이나 기존 저장은 수정하지 않는다.

[원작 날씨 자료](https://www.serebii.net/legendsz-a/weather.shtml)는 비가 물 기술을 강화하고 불꽃 기술을 약화한다고 설명한다. 현재 도시의 강우 시간표는 기존 잠정 게임 시계에 따르며, 현재 확인된 야외 위치의 새 다수 상대·동료 전투에도 같은 규칙을 적용하며, 블루 8번지의 미용실 앞 플라엣테 전투를 포함한다. 이 범위 밖의 야외 지역에는 적용되지 않는다. 원작 실기와 운영 D1·Sites 병합본은 확인하지 않았다.

격리 API에서 비·맑음 시작과 배틀 중 재접속·시간 변화·구형 요청을 확인했고, 단위 검사에서 야외·실내·지하·명시적 날씨의 구분과 같은 난수 조건의 물·불꽃 피해 방향을 확인했다. 기존 파티와 재화는 보존했다.

다수 전투는 생성 시 날씨를 스냅샷에 기록한다. 실내·지하와 구형 진행 중 전투는 기존 상태를 유지하며, 외부 시간 변경이나 재접속이 전투 날씨를 다시 설정하지 않는다. 격리 API의 플라엣테 전투에서 비·맑음과 재접속 및 중복 요청을 확인했고, 두 다수 전투 엔진의 저장 복원과 턴 진행을 확인했다.

## 거리·코트·옥상 추가

야외 전투 장소가 확인된 블루 7번지·블루 6번지 접근로, 존느 8번지와 6번지 옥상, 마젠타 8번지 옥상, 루주 북쪽·1·7번지, 베르 3·6번지, Rust 사무소 앞과 남쪽 대로에도 같은 날씨 전달을 적용한다. 비의 물·불꽃 기술 효과는 [날씨 자료](https://www.serebii.net/legendsz-a/weather.shtml)를 따르며 도시의 강우 시각과 현재 시뮬레이터의 특성·턴 동작은 기존 잠정 구현이다. 장소가 확인되지 않은 지도, 실내와 구역 20 지하는 기존처럼 제외한다. 명시적 전투 날씨가 우선하며 이미 시작된 저장은 바꾸지 않는다.

격리 API에서 베르 6번지 단일 배틀의 비·맑음·재접속과 구형 요청 거부, 남쪽 대로 동료 전투의 시작·복원과 동료 보유함 비저장을 확인했다. 동료 전투의 상대 특성이 기존 턴제 엔진에서 모래바람을 만들므로 이 경우 전투 화면은 모래바람이다. 단위 검사에서는 추가 장소의 비, 실내·맑음·명시적 날씨와 기존 다수 엔진 복원을 확인했다. 실제 기기·운영 D1·Sites 병합본은 확인하지 않았다.

## 폭주 메가 사건 현장

베르날 대로·아이믈리스 공원 물가의 메가야도란, 존느 3번지 옥상의 메가폭타, 북쪽 대로와 마젠타 9번지 지상의 메가우츠보트 사건도 현재 야외 날씨를 새 전투에 전달한다. 비가 오는 화면에서 전투만 맑아지는 기존 누락을 수정한다. 실내는 제외하고, 전투에서 별도로 지정한 날씨가 있으면 그대로 우선한다. 기존 배틀 스냅샷과 저장을 소급 수정하지 않는다.

비의 효과는 [날씨 자료](https://www.serebii.net/legendsz-a/weather.shtml)를 참고한다. 원작의 폭주 사건별 날씨 전환과 강우 시간표는 실기 확인 전이며 이 게임의 기존 잠정 시계와 턴제 시뮬레이터를 유지한다. 격리 API에서 세 사건의 비, 맑음, 재접속·시간 변경과 오래된 요청 및 파티·재화 보존을 대표 검사했다. 실내·명시적 날씨와 피해 방향은 단위 검사했다. 운영 D1과 실제 원작 기기·Sites 병합본은 검증하지 않았다.

## 후반 옥상과 골목의 폭주 사건

미션 27·28·32·33·34에 쓰이는 기존 옥상·안뜰·골목 및 마젠타 4번지에서도 야외의 새 전투가 현재 비를 상속한다. 예전 공용 옥상 경로도 포함하며 실내와 위치가 불명확한 공용 사건 지도는 여전히 제외한다. 진행 중인 배틀은 수정하지 않는다. 원작의 옥상 이동은 [미션 28](https://www.thonky.com/pokemon-legends-z-a/main-mission-28-a-rogue-mega-altaria)·[미션 32](https://www.thonky.com/pokemon-legends-z-a/main-mission-32-a-rogue-mega-dragonite), 골목은 [미션 33](https://www.thonky.com/pokemon-legends-z-a/main-mission-33-a-rogue-mega-tyranitar) 공략을 참고했다. 실제 사건마다 날씨가 강제로 정해지는지는 원작 기기에서 확인하지 못했다.

단위 검사에서 야외·실내·맑음·명시적 날씨를 확인했고, 격리 API에서 파비코리와 망나뇽의 비·맑음, 재접속·중복 요청 및 파티·재화 보존을 대표 검사했다. 다른 후반 현장과 운영 D1·Sites 병합본은 실제로 검증하지 않았다.
