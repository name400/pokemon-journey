# 사이드 미션 6: 장거리 기술 배틀

[Serebii](https://advent.serebii.net/legendsz-a/sidemissions/long-rangemoveshavestyle.shtml)의 블루 4번지 Distan과 레벨 16 거북손손·화살꼬빈·메이클의 기술을 기존 턴제 전투에 연결했다. 미션 6부터 의뢰를 받을 수 있고 패배·기권 후 다시 도전할 수 있다. 원작의 거리 기반 실시간 기술 운용은 현재 턴제 전투로 근사하며 인물의 2D 좌표는 초안이다.

[Thonky](https://www.thonky.com/pokemon-legends-z-a/side-mission-006-long-range-moves-have-style)에 따른 배틀 상금 1,088원과 의뢰 보상 1,000원·금구슬을 별도로 지급한다. 가방이 차면 금구슬은 맡겨 두었다가 받을 수 있고 월드 리비전으로 중복 지급을 막는다. 알 수 없는 미래 보상 형식과 기존 저장은 임의 수정하지 않는다.

격리 SQLite API에서 해금 전 거절, 상대 편성, 기권·재도전, 승리·재접속, 보상 한도와 중복 방지, 기존 파티 및 미지의 보상 상태 보존을 확인했다. 맵의 코트 접근 경로를 검사했으며 실기·운영 D1·실제 Sites 병합본은 확인하지 않았다.
