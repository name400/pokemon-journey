# 그룹 조회와 이동 예측 경합

그룹 상태의 가벼운 조회가 시작된 뒤 이동하면, 같은 리비전의 이전 위치 조회가 이동 응답보다 먼저 도착해 표시된 예측을 지울 수 있었다. 모의 API와 브라우저에서 `(3,8)`에서 오른쪽 입력 후 `(4,8)` 예측이 조회 응답으로 `(3,8)`로 되돌아가는 것을 수정 전 재현했다.

이동 요청이 진행 중인 동안에만, 조회 결과가 현재 리비전과 위치·방향·선두가 같고 전투·포획·기술 선택이 없으면 그 조회를 적용하지 않는다. 다음 그룹 조회는 평소처럼 이뤄진다. 더 높은 리비전, 같은 리비전이라도 위치가 다른 결과, 전투나 선택 상태는 보류하지 않는다. 이동 요청, 충돌·조우 판정, 복구 펜스와 서버 저장은 바꾸지 않았다. 같은 리비전의 다른 그룹 표시 변경은 다음 조회까지 늦어질 수 있다.

모의 API를 지연시킨 브라우저에서 같은 리비전의 예측 유지, 새 리비전 및 변경된 위치 반영, 같은 리비전 전투 반영을 확인했다. 이동 중 대화 8가지와 조우 중 방향 전환도 재검사했다. 검사는 위치 접근성 표시를 기준으로 하며 캔버스 픽셀·실제 운영 네트워크나 기기에서의 체감 지연은 측정하지 않았다. `testfailed.md`의 독립 새로고침·두 탭 펜스 경합은 별개의 미해결 검증으로 유지한다.
