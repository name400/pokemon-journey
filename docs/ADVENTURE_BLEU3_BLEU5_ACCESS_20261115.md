# 블루 3번지와 5번지 지상 연결

- 원작 지역 안내의 [블루 3번지](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-3.html)는 남서쪽에 블루 5번지, 남쪽에 에이믈리스 파크를 표시한다. [블루 5번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-5.html)도 북동쪽 블루 3번지와 동쪽 공원을 표시한다. 두 안내는 2차 자료다.
- 두 번지 사이를 공원 밖 지상 통로로 연결했다. 실제 거리의 정확한 형태와 위치는 이 자료로 확인되지 않아 입구 좌표와 2D 길은 게임 지도에 맞춘 잠정 배치다. 공원 출입구나 해금 조건을 추가하지 않는다.
- 기존 저장 좌표와 진행값은 변경하지 않는다. 두 번지 간 왕복과 위치 복원, 공원 잠금 및 기존 경로를 관련 테스트에서 확인했다.
- 실제 Sites 병합본 및 모바일 운영 환경은 재검증하지 않았다. 해당 실패 기록은 유지한다.
