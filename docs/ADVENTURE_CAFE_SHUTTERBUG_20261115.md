# Shutterbug Café 서비스

Serebii <https://www.serebii.net/legendsz-a/cafes.shtml> 및 Bulbapedia <https://bulbapedia.bulbagarden.net/wiki/Shutterbug_Caf%C3%A9>의 메뉴와 가격을 반영한다. 파티 회복과 선두 포켓몬의 친밀도 증가를 기존 카페 공통 규칙으로 연결한다. 친밀도 +30은 기존 게임의 근사값이며 원작 수치로 검증하지 않았다.

기존 저장·빠른 이동·사이드 미션 14를 보호하기 위해 기존 남쪽 큰길의 임시 표식과 의뢰 진행을 유지한다. 두 자료의 거리 명칭이 엇갈리고 현재 표식의 정확한 원작 위치는 검증되지 않았다. 의뢰인과 주문대를 같은 표식에서 제공하는 것도 근사 구현이다. 원작 실기에서 독립적으로 검증하지 않았다.
