# 마젠타 7번지와 9번지 지상 연결

[7번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/magenta-sector-7.html)는 북서쪽 9번지 접근을, [9번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/magenta-sector-9.html)는 남동쪽 7번지 접근을 설명한다. 모두 2차 자료다. 두 지상 화면을 왕복 연결했다. 압축 지도에서 출구 좌표와 통로의 정확한 형태는 추정이며 원작과 동일하다고 확인되지 않았다.

기존 저장 형식과 구역 18의 해금 조건을 유지한다. 양방향 이동, 저장 복원, 해금 전 차단과 관련 구역 회귀 검사 20개가 통과했다. 실제 원작 기기와 운영 Sites는 검증하지 않았다. 모바일 D1 이동 오류 기록은 운영 재검증 전까지 유지한다. 7번지 북쪽 안뜰의 불꽃 장애물·옥상과 세부 보상은 미완성이다.
