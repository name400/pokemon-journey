# 야생 구역 고정 개체 직접 포획

[공식 안내](https://legends.pokemon.com/en-us/news/adventure)는 야생 구역의 포켓몬에게 볼을 던져 배틀 전에 포획할 수 있다고 설명한다. 기존에는 도시의 여덟 조우와 일부 움직이는 포켓몬만 직접 포획할 수 있었다. 구역 5·6·8~20에서 기존 지도에 표시되는 일반 고정 개체의 상호작용에 기본 볼 투척을 추가했다. 서버는 실제 현재 위치에서 기존 상호작용과 구역·층·시간·소진 상태를 재확인한다. 땅속 흙더미와 우두머리, 스토리 전용 개체는 기존 경로를 유지한다.

성공하면 볼 소비와 개체 소진·도감·연구 기록을 같은 리비전으로 저장한다. 기존 개체의 이로치 색을 사용하며 실패하면 그 개체와 턴제 전투가 시작된다. 도주·재접속 후 색이 유지되고 포획 또는 쓰러뜨리면 기존 구역 규칙으로 소진된다. 볼 부족과 오래된 요청은 저장하지 않으며, 기존 구형 저장·보유 포켓몬과 배틀 버튼을 유지한다. 자유 조준·투척 궤적·개체별 감지와 도주, 다른 볼의 필드 선택 및 우두머리 직접 포획은 이번 범위에 포함하지 않는다. 위치와 개체 수는 기존 2D 지도 초안이다.

지도 검사에서 15개 구역의 접근 가능한 일반 개체와 선택지를 확인했다. 격리 SQLite API에서 구역 14의 이로치 실패·도주·성공, 우두머리·흙더미 거절, 낡은 요청과 구역 12 물가 개체의 포획·재접속을 검사했다. PC·모바일 Chromium은 모의 API와 대체 이미지로 선택과 새로고침을 확인했다. 이동·충돌 계산 및 DB 조회는 추가하지 않았으나 실제 요청 지연과 운영 D1·원작 기기는 측정하지 않았다.
