# 폴터가이스트의 소지 도구 조건

원본은 대상이 가진 이전 가능한 포켓몬 소지 효과가 있어야 폴터가이스트가 성공한다. 신규 도전에서는 전투의 소지 효과 목록과 네이티브 소지 도구를 확인하며, 이전 불가로 표시된 효과·훈련 이벤트 등의 이전 불가 네이티브 도구와 검토된 폼 변경 도구는 제외한다. 적 AI의 기술 점수와 기절 후보도 같은 조건을 사용한다. 네이티브 다이맥스 기술에는 원 기술의 조건을 적용하지 않고 기존 도전은 이전 판정을 유지한다.

격리 전투에서 이전 가능·불가 효과, 도구 없음, 네이티브 도구·폼 도구, 적 AI, 더블 대상, 다이맥스, 저장 복구와 다른 슬롯 및 소지 효과 보존을 확인했다. 네이티브 도구 전체의 원본 이전 가능 여부와 특수 폼·도구 조합을 전수 분류한 것은 아니므로 이 기능은 부분 지원이다. 실계정·실기기 검증은 하지 않았다.

현재 전투 표시기는 폴터가이스트의 도구명을 원본 문구 그대로 보여 주지 않는다. 도구명 표시와 원본 난수·전체 효과 대조는 남아 있다.

관련 도구·열매·미스터리·첫 턴·변신·호출·AI·날씨·지형·트레이너·상태·챌린지·융합·학습·스케치 회귀는 일반 실행과 Worker 로더에서 각각 463건 통과했다. 타입 검사와 빌드도 통과했으며 전체 프로젝트 검사는 아니다.
