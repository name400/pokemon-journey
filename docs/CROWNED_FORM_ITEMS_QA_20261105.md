# 자시안·자마젠타 왕 폼

고정 원본의 녹슨 검과 방패를 기존 폼 도구·융합 경로에 연결했다. 원본과 native 왕 폼의 능력치 6항목이 일치하는 경우에만 허용하며, 별도 native 소지 도구를 지급·삭제하지 않는다. 구형 저장의 수동 활성화와 새 저장의 활성 기록을 유지한다.

원본은 해당 폼의 아이언헤드 자동 교체를 아직 구현하지 않아 기존 기술과 PP를 유지한다. 실제 보상 선택, 활성·해제, 융합 양쪽, 전투 턴·codec·분리, 다른 슬롯, 같은 이름의 native 소지 도구와 별개 도구를 검사했다. 관련 일반·Worker 각 36/36, 추가 소지 도구 경계 일반·Worker 각 4/4, 타입·production 빌드 통과. 물리 기기·운영 및 모든 특성/도구 조합은 별도다. `/tmp/crowned-final.log`, `/tmp/crowned-worker.log`, `/tmp/crowned-held.log`, `/tmp/crowned-held-worker.log`, `/tmp/crowned-type.log`, `/tmp/crowned-build.log`.
