# 사우전드웨이브와 틈새포착

고정 원본 `7c0881255af5cd51992e513ff93c2f71adbe40e0`은 [기술의 대타 명중 여부](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/data/moves/move.ts#L459)를 판정하고 [대타를 맞히지 않을 때 대상 추가 효과를 적용](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/phases/move-effect-phase.ts#L535)한다.

사우전드웨이브의 신규 대상별 순서에서, 틈새포착으로 대타를 관통해도 대타가 존재한다는 이유만으로 선행 교체 불가 처리를 건너뛰어 다른 대상의 마지막 피해 뒤에 적용하는 차이를 재현했다. 새 규칙에서 엔진의 실제 대타 관통 표시를 확인해 명중 대상에 마지막 타격 직후 효과를 적용한다. 대타가 관통되지 않으면 대상의 교체 불가는 그대로 차단하고, 기존 저장 규칙은 변경하지 않는다.

격리 엔진에서 일반·패시브 틈새포착, 특성 억제, 인분, 대타, 멀티렌즈와 저장 복원을 확인했다. 기존 사우전드웨이브·물거품아리아 및 전체 공격 회귀와 합쳐 53건이 통과했다. 다른 기술·특성·도구 전체 조합과 브라우저·실기기는 검증하지 않았으며 Sites에는 배포하지 않았다.
