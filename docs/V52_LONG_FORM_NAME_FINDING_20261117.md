# v52 긴 폼 이름 HUD 확인

포켓로그 격리 응답에서 도감에 있는 `마휘핑 (vanilla-cream-clover-sweet)`을 아군·상대 표시 이름으로 넣으면 HUD 이름의 실제 콘텐츠가 표시 폭을 초과하여 생략된다. 280×568에서는 폭 약 59px 대비 콘텐츠 약 129px, 960×540에서는 폭 약 204px 대비 약 450px이었다. 이는 실제 사용자 저장에서 해당 개체를 재현한 검사가 아니라 기존 도감 이름을 격리 응답에 주입한 검사다.

글자를 영역에 축소하는 시험에서는 280px에서 약 3.4px이 되어 가독성이 나빠지므로 적용하지 않았다. 이름을 전체 표시하면서 원본 배치와 실기기 가독성을 보장하는 처리는 미해결이다. 원본 포켓몬 PNG와 타입 PNG 전체를 받지 못해 배우와 전체 화면의 픽셀 일치도 미검증이다. 사용자 저장과 Sites는 변경하지 않았다.

## 메타데이터가 일치하는 폼의 표시 개선

포켓로그 단일 HUD에서 저장된 이름이 `기본 이름 (폼 이름)`과 정확히 일치하는 경우에만 기본 이름을 표시한다. 전체 원문은 기존 상태 확인 화면과 저장에 그대로 남는다. 값이 일치하지 않거나 메타데이터가 없는 별명은 임의로 축약하지 않는다. 긴 폼이 있는 단일 상태 화면은 전체 이름이 잘리지 않게 패널 여백을 조정한다. 이는 HUD에서 전체 폼을 한 번에 표시하는 해결은 아니며, 임의의 긴 별명이나 다중 전투는 별도 미해결이다.

도감 ID 30476의 실제 기본·폼 메타데이터를 격리 응답에 넣어 280×568, 390×844, 844×390, 960×540에서 기본 이름·상태창 전체 이름·뒤로 버튼 비겹침·저장 불변·새로고침을 확인했다. 별명 보존 단위 검사, 일반 이름과 HP 원본 좌표 비교, 포켓로그 단일·더블 상태·포획 회귀 및 타입 검사가 통과했다. 실제 기기와 운영 저장은 검증하지 않았다.
