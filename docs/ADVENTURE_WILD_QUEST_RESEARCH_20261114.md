# 의뢰 포켓몬 전투와 트레이너 연구 과제

사이드 7의 도치마론, 사이드 37의 거북손손 무리, 사이드 86의 두더류는 의뢰 대상 포켓몬과 직접 싸우는 전투다. 새로 시작한 이 전투는 트레이너 승리 횟수에 더하지 않는다. 원작 공략의 의뢰 설명과 트레이너 승리 과제의 구분에 근거한 판정이며, 원작 내부 카운터를 직접 확인한 것은 아니다.

- https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Part_7#Side_Mission_007:_A_Feisty_Chespin
- https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_21-40#Side_Mission_037:_Binnacle_by_the_Boatload
- https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_81-100#Side_Mission_086:_Who_Messed_Up_the_Garden?

저장된 연구 승수는 수정하지 않는다. 저장된 구형 전투에는 새 표식이 없어 기존 승리 처리도 유지된다. 전투 및 보상 자체의 경험치·재고 규칙은 변경하지 않는다. Sites 병합본의 기존 실패 기록은 별도 재검증 전까지 유지한다.
