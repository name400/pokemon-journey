# 사이드 미션 64: 빗속 배틀

미션 20 사무소 방문 후 호텔 회의를 마치면 루주 7번지 코트의 Cielestine에게 의뢰를 받아 수레기 Lv.45, 블로스터 Lv.45, 야도킹 Lv.46과 싸울 수 있다. 비를 기다리는 선택은 전투 시작 시에만 비를 설정하며 필드 시간·날씨나 진화 조건을 변경하지 않는다. 전투를 포기해도 재도전할 수 있다. 승리 상금 2,208원과 의뢰 보상 2,000원·신비의물방울·맛있는물 3개는 별도이며 가방 한도와 리비전으로 중복 지급을 막는다. 이전 저장에 완료나 보상을 추측해 만들지 않는다.

[의뢰 위치·해금과 보상](https://bulbapedia.bulbagarden.net/wiki/Mission_(Legends:_Z-A)), [트레이너 구성·상금](https://bulbapedia.bulbagarden.net/wiki/Backpacker_(Trainer_class))과 [의뢰 흐름](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_61-80)을 대조했다. 맛있는물 수량은 2개로 기재한 공략도 있어 3개를 잠정 채택했다. 의뢰인 타일은 기존 2D 코트의 추정 배치이며 실제 대기 시간과 원작 기술·동시 전투는 재현하지 않았다.

격리 API에서 해금, 맑은 필드의 비 전투·재접속·재도전·승리, 가방 한도·중복 수령과 기존 파티·진행 보존을 검사했다. 원작 실기·운영 D1·실제 Sites 병합본은 확인하지 않았다.

추가 대조: [GameTrek](https://gmtreks.com/pokemon-z-a/side-missions/64)과 [TrainerLab](https://trainerlab.top/lza/items/fresh-water/)도 맛있는물 3개를 기재한다. 2개로 기재한 공략과 상충하고 실제 기기는 확인하지 못해 기존 3개를 유지한다.
