# 변신과 호출 기술의 뒀다쓰기 이력

원본의 변신은 소환 중 기술 사용 이력을 유지하며 새 기술 목록을 복사한다. 신규 도전에서 변신 직전 현재 기술 목록에 직접 사용했다고 기록된 기술이 복사된 목록에도 있으면 해당 이력을 보존한다. 복사한 적 없는 기술은 미사용이며, 기존 도전은 이전 판정을 유지한다. 실제 전투와 저장 복구 후 뒀다쓰기의 성공·실패를 확인했다.

호출 기술은 원본 규칙과 대조했다. 격리 전투에서 절대안깸 사용자의 잠꼬대가 뒀다쓰기를 호출하는 경우와, 따라하기로 호출한 기술이 직접 사용한 기술로 잘못 기록되지 않는 경우를 확인했다. 이는 변신 전에 이미 잊은 기술의 전체 이력, 변신·스케치·재학습의 모든 조합, 호출 기술 전수 검증을 뜻하지 않는다. 실계정·실기기 검증은 하지 않았다.

관련 변신·호출·AI·날씨·지형·트레이너·상태·챌린지·융합·학습·스케치 회귀는 일반 실행과 Worker 로더에서 각각 299건 통과했다. 타입 검사와 빌드도 통과했으며 전체 프로젝트 검사는 아니다.
