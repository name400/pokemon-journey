# 미션 19 하수도 Gwynn 전 회복

[Bulbapedia 공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Part_14)과 [PokeMundo 공략](https://pokemundo.com.br/detonado/pokemon-legends-z-a)은 Gwynn과의 배틀 전에 Emma가 파티를 회복한다고 설명한다. 두 자료는 2차 자료이며 원작 실기 검증은 하지 않았다.

새로 환상의 벽을 통과한 진행은 샹델라를 끝까지 따라가면 Emma가 파티 HP·상태·PP를 한 번 회복한다. 기존 초안에서 안내를 건너뛰고 Gwynn과 바로 대화해도 배틀 개시 직전에 같은 회복을 적용한다. 벽을 다시 통과하거나 재접속해도 중복 회복되지 않는다. 기존에 벽을 통과한 저장 및 진행 중인 전투는 소급하지 않으며, 알 수 없는 회복 표식은 덮어쓰지 않는다. 파티 소유권·금전·미션과 전투 보상은 유지한다.

2D 방과 Emma의 정확한 좌표·대사는 재구성이며 원작 지하 지도 전체 대응은 미확정이다. 벽 통과 시 저장되는 이벤트 표식만 추가했으며 이동·충돌 판정은 변경하지 않는다. 실제 기기와 Sites 병합본은 미검증이다.
