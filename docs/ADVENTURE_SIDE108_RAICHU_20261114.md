# 사이드 미션 108 — 알로라, 라이츄!

[Serebii](https://www.serebii.net/legendsz-a/sidemissions/alola%2Craichu.shtml)와 [공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-108-alola-raichu)에 따라 메인 미션 37 이후 콰자르티코 앞 Griddella에게 의뢰를 받고, 일반 라이츄 한 마리로 Lv.64 알로라 라이츄와 싸운다. 승리 상금 3,072원은 교환 전에 지급한다. 이후 사용자가 일반 라이츄를 직접 선택·확인하면 알로라 라이츄 Floffy를 받고, 별도로 500원·토망열매와 유석열매 각 10개를 받는다. 상대와 Floffy의 기술은 사이코키네시스·번개·파도타기·치근거리기다.

지닌 도구는 먼저 빼야 하며 다른 사용자의 개체와 지역 폼은 교환할 수 없다. 선택한 개체는 탐험의 파티와 보유함에서만 제외하고 공유 원본은 보존한다. 저장 시 소유자·원본 데이터·교환 대기와 배틀 잠금을 원자적으로 확인한다. 파티에 있던 개체를 교환하면 새 개체가 같은 자리를 채운다. 수령이나 이동 후 다시 불러와도 원본을 탐험 보유함에 부활시키지 않고 도감 동기화에도 포함하지 않는다. 배틀 승리, 교환, 보상을 별도 단계로 저장해 가방과 지갑 한도에 걸려도 재시도할 수 있다. 구형 저장에서 교환을 추정하거나 기존 개체를 바꾸지 않는다.

NPC의 정확한 좌표는 기존 2D 맵의 초안이고 원작 실시간 배틀은 턴제 근사다. Lv.64는 위 두 자료에 따르며 다른 공략은 Lv.66을 제시한다. 단일 라이츄 제한과 원작 개체 정보의 실기 확인은 남아 있다. 격리 API에서 해금·상대 편성·기권·승리·선택 확인·지닌 도구 거절·다른 교환 예약·공유 개체 동시 변경·교환 후 복원·도감 동기화·가방과 지갑 한도·중복 수령을 검증했다. 배틀 승리는 상대 HP를 시험용으로 낮춰 확인했으며 실제 기기·운영 D1·Sites 병합본은 확인하지 않았다.
