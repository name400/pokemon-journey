# 사이드 미션 8: 푸호꼬를 도와줘

[Serebii](https://www.serebii.net/legendsz-a/sidemissions/getwell%2Cfennekin.shtml)와 [Thonky](https://www.thonky.com/pokemon-legends-z-a/side-mission-008-get-well-fennekin)에 따라 미션 6부터 마젠타 2번지에서 의뢰를 받고 카페 클라세 앞 약초꾼, 야생 구역 5의 지하 공터와 사다리 위를 거쳐 푸호꼬를 구한다. 기존 두 오염물과 지하·중간 발판·옥상 사다리 연결을 재사용한다. 공터의 네 마른 가지는 필수가 아니고 사다리 위의 싱싱한 가지만 가져오면 된다. 정확한 타일과 대사는 2D 초안이다.

레벨 14 푸호꼬와 경험사탕XS 3개·S 1개, 1,200원을 지급한다. [Thonky](https://www.thonky.com/pokemon-legends-z-a/side-mission-008-get-well-fennekin)와 [RPG Site](https://www.rpgsite.net/guide/18713-pokemon-legends-z-a-side-mission-list-rewards)는 1,200원을, 다른 [공략](https://strategywiki.org/wiki/Pok%C3%A9mon_Legends%3A_Z-A/Get_Well%2C_Fennekin)은 1,000원을 제시하므로 금액은 실기 미확인이다. [Bulbapedia의 선물 목록](https://bulbapedia.bulbagarden.net/wiki/List_of_in-game_event_Pok%C3%A9mon_in_Pok%C3%A9mon_Legends%3A_Z-A)에 따라 신규 선물은 암컷으로 생성한다. 이미 받은 개체는 바꾸지 않는다. Serebii는 무작위 성격을, Bulbapedia는 고정 성격을 제시해 충돌하므로 선물의 기본 성격은 유지하며 실기 확인이 남았다. 일반 색 사용도 기존 규칙을 유지한다.

선물은 기존 보유함에 별도로 추가하며 파티가 가득 차면 보유함에 둔다. 가방에 넣지 못한 사탕은 맡겨 두고 나중에 받는다. 리비전으로 중복 수령을 막고 알 수 없는 미래 보상 형식은 보존한다.

격리 SQLite API에서 해금, 약초꾼, 두 오염물 제거, 마른 가지, 지하에서 사다리 두 개를 거친 진짜 가지, 선물, 가방 한도와 재접속·중복 요청 및 기존 선두 보존을 확인했다. 실기·운영 D1·실제 Sites 병합본은 확인하지 않았다.

후속: 신규 선물의 암컷 생성과 기존에 받은 수컷 개체의 재접속 보존을 격리 API에서 검사했다. 실기 성별·성격과 보상은 확인하지 않았다.
