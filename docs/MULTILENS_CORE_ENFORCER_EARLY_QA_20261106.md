# 멀티렌즈 코어퍼니셔의 첫 대상 특성 억제

신규 도전에서 코어퍼니셔의 첫 타격이 행동을 마친 첫 대상에게 적중하면, 특성을 억제한 뒤 다음 대상의 피해를 계산한다. 대타출동에 맞힌 타격은 억제를 적용하지 않는다. 이전 저장은 이전 순서를 유지한다.

날씨를 억제하는 에어록 계열 특성이 먼저 해제될 때 햇살과 선파워가 두 번째 대상 피해에 미치는 차이를 아군·상대 전투에서 확인했다. 방어, 대타출동 유지·파괴, 특성가드, 미행동, 억제 불가 특성, 저장 복구 및 다른 슬롯 보존을 격리 검사했다. 이 보완은 검토된 멀티렌즈 첫 타격 경로에 한정된다. 다른 타격·패시브 특성·폼·원본 난수 전체 조합과 운영·실기기 플레이는 별도 검증이 필요하다.
