# 베르 광장과 베르 스트리트 연결

[베르 광장 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-plaza.html)와 [베르 스트리트 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-street.html)는 거리가 광장을 관통한다고 설명한다. 기존 2D 화면에 양방향 지상 연결을 추가했다. 화면 압축에 따른 출입 좌표와 길의 선형은 잠정 배치다.

기존 야생 구역 2 입구와 미션 3의 우회 제한을 유지하며 저장 형식은 변경하지 않는다. 원작 실기와 실제 Sites 병합본은 확인하지 않았다. 모바일 이동 오류 기록은 운영 재검증 전까지 유지한다.
