# 존느 9번지와 존느 스트리트 연결

[존느 9번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-9.html)는 북쪽에 존느 스트리트가 있다고 설명한다. 기존 지상 화면 사이 왕복 경로를 추가했다. 출입 좌표와 길의 선형은 잠정 2D 배치다.

기존 광장 접근과 야생 구역 8 해금 조건, 저장 형식과 사건 지점을 유지한다. 원작 실기와 실제 Sites 병합본은 확인하지 않았다. 모바일 이동 오류 기록은 운영 재검증 전까지 유지한다.
