# v52 아군 HP 수치 크기

승인 원본은 폭 360 논리 화면 기준 HP 수치가 Arial 9px이며 `153/153`처럼 표시된다. 포켓로그 기존 화면은 960×540의 장면 폭 약 946px에서도 9px로 고정돼 원본의 약 23.6px보다 작았다. v52 포켓로그 단일의 글씨를 원본처럼 장면 폭의 2.5%로 조정하고 표시 슬래시 양쪽의 공백을 제거했다. 긴 수치는 기존 압축 크기를 장면 비율에 맞춰 유지했다. 공백 제거는 공통 v52 HP 표시에도 적용되며 수치·접근성 progressbar·엔진 값은 바꾸지 않는다.

격리 포켓로그 Chromium의 280×568, 390×844, 960×540에서 원본 HTML과 일반 수치의 정규화된 글꼴 크기·두께를 비교했다. 9999/9999는 응답 복사본에 주입해 잘림을 검사했고, 명령 선택 및 저장 불변도 확인했다. 단일·더블 네 크기의 실제 기술·PP·상성 회귀와 타입 검사가 통과했다. 탐험 브라우저, 실기기, 원본 포켓몬 PNG 및 전체 화면 픽셀 일치는 미검증이다. 사용자 데이터와 Sites는 변경하지 않았다.
