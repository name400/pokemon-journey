# 미션 32: 야생 구역 2 동쪽 옥상

[원작 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-32-a-rogue-mega-dragonite)은 구역 2 동쪽 건물 안뜰의 홀로베이터로 올라 북쪽 옥상·비계와 사다리를 지나고, 로토글라이드로 건너편 망나뇽 옥상에 접근하도록 안내한다. 기존 구역 2에 안뜰 출입구를 추가하고 별도의 지상·옥상·높은 비계 층과 활공 구간을 연결했다. 기존 턴제 전투 및 망나뇽나이트 보상을 사용한다.

건물 윤곽, 출입구·사다리·활공 거리와 방향, 옥상의 세부 배치는 정밀 자료가 없어 2D 초안이다. 원작 실시간 공격과 동료 동시 전투는 미구현이다. 기존 옥상 사건 표식과 저장·미수령 보상을 유지한다.
