# 겁이 많은 이동 개체의 우두머리 반응

[공식 안내](https://legends.pokemon.com/en-us/news/adventure)는 우두머리가 플레이어를 발견하면 추격하고 공격한다고 설명한다. 기존 구역 2 꼬몽울과 구역 3 냐스퍼는 우두머리 판정이 있어도 기존 일반 개체처럼 도망가거나 포획 실패 후 사라졌다.

두 종의 저장된 우두머리는 일반 도주 로직에서 제외하고, 포획 실패 또는 같은 칸 접촉 시 기존 턴제 우두머리 전투를 시작한다. 일반 개체의 도주 및 기존 이로치·우두머리 저장 키는 유지한다. 구역 3의 다른 우두머리 이동 개체도 같은 칸 접촉을 전투로 처리하며, 기존에 평온한 개체였던 우두머리 근처에서는 예측 이동을 제한해 서버 응답을 기다린다. 개체가 정해진 구역에 남아 있다가 접촉할 때 전투로 들어가는 근사이며, 원작의 추격 경로·발견 거리·실시간 공격은 구현하지 않았다.

격리 SQLite API에서 두 종의 포획 실패 및 이동 접촉, 이로치 보존, 재접속, 중복 요청과 볼 소비를 확인했다. 일반 개체의 도주와 이동 예측 회귀는 단위 검사했다. 운영 데이터와 실제 기기 검증은 수행하지 않았다.
