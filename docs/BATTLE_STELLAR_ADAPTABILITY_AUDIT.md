# 스텔라 적응력과 타입별 사용 이력

제공 ZIP의 고정 원본 `7c0881255af5cd51992e513ff93c2f71adbe40e0`에서 `pokemon.ts`의 `calculateStabMultiplier`·`getTeraTypeBoost`, `move-effect-phase.ts`의 `postAnimCallback`, `moves/move.ts`의 `calculateBattlePower`를 대조했다. 기존 비스텔라 수정에 이어 새 도전의 `adaptabilityRule: source-subset-v2`에 연결한다. v1과 규칙 없는 기존 도전은 이전 스텔라 동작을 유지한다.

| 스텔라 공격 | 첫 사용 | 같은 타입 반복 |
| --- | --- | --- |
| 원래 타입, 적응력 있음 | 2.25 | 2 |
| 원래 타입, 적응력 억제/없음 | 2 | 1.5 |
| 원래 타입이 아닌 기술 | 1.2 | 1 |
| 테라파고스 포함 개체의 원래 타입, 적응력 있음 | 2.25 | 2.25 |
| 테라파고스 포함 개체의 원래 타입이 아닌 기술 | 1.2 | 1.2 |

테라파고스 예외는 기본 종과 검증된 DNA 융합의 두 번째 종을 모두 확인한다. 이 확인이 모든 테라파고스 폼 전환·융합을 새로 지원한다는 뜻은 아니다.

원본은 완료된 공격 기술의 타입을 테라스탈 이전에도 기록한다. 같은 타입의 기술을 테라스탈 전에 이미 사용했다면 이후 첫 스텔라 공격에서 일회성 보너스를 다시 주지 않는다. 명중하지 않거나 면역·방어에 막힌 완료된 공격과 고정 피해도 타입 사용으로 기록한다. 상태 기술·잠들어서 행동하지 못한 경우·충전 준비 턴은 소모하지 않는 경로를 검사했다. 원본의 연타 단계에 맞춰 다단히트는 첫 타격 후 타입을 소모하고, 같은 타격 단계의 전체 공격 대상은 보너스를 공유한다.

## 구현과 저장

`lib/rogue-stellar-adaptability.mjs`는 설치된 `@pkmn/sim 0.10.12`의 피해 계산을 감싼다. 난수 계산 직후 STAB 배율이 적용되는 단계에서만 배율을 교정해 날씨·급소·전체 공격·화상·도구 및 타입 계산 순서를 유지한다. 관찰한 네이티브 STAB 배율이 예상과 다르면 다른 단계의 값을 변경하지 않고 기존 값을 사용한다. 라이브러리 버전이나 계산 순서가 바뀌면 이 계약과 회귀를 다시 확인해야 한다.

또한 원본은 기술 타입과 테라 타입이 같을 때만 최소 위력 60을 적용한다. 스텔라가 아닌 저위력 기술을 네이티브가 잘못 올리던 경우는 BasePower 뒤의 최소 위력 확인에 한정한 Dex 조회로 제외한다. 실제 기술·행동 우선도와 공유 Dex는 바꾸지 않는다. 예외가 발생해도 계산 문맥을 복원하는 검사를 포함한다.

타입 사용 기록은 기존 네이티브 `stellarBoostedTypes` 배열에 중복 없이 저장한다. 새 전투별 규칙도 스냅샷에 보존하며 저장 스키마를 초기화하지 않는다. 기존 비스텔라 v1 동작과 원격에 저장한 과거 도전은 보존한다.

## 자동 검증과 한계

`tests/rogue-stellar-adaptability.test.mjs`에서 실제 전투로 다음을 검사했다.

- 일반·패시브의 물리/특수 첫 사용과 반복, 독립적인 타입별 사용 기록.
- 양쪽 포켓몬과 동일 일반·패시브의 중복 방지, 위액·화학변화가스와 억제 해제 후 이미 소모한 타입 유지.
- 테라파고스 종과 검증된 테라파고스 융합 기증자의 반복 보너스.
- 다단히트와 전체 공격, 일반 교체 후 사용 이력 보존.
- 빗나감·타입 면역·방어·고정 피해, 상태 기술·잠듦·충전 턴의 소비 구분.
- 실제 테라스탈 이전 타입 사용, encode/decode 저장 후 원래/새 타입의 소비 유지와 다른 슬롯·재화 보존.
- 날씨·급소·화상·생명의구슬 조합, 저위력 기술과 우선도의 조회 보존.
- 피해 계산 도중 의도한 예외 후 STAB 문맥과 Dex 조회 문맥 복구.
- 이전 v1 스텔라 동작 유지, 새 도전 v2 선택과 기존 도전 보존.

배율 비교는 비테라 전투의 STAB을 원본의 기대 배율로 고정한 별도 대조군을 사용한다. 명중·급소·피해 난수와 일부 연타 수는 검사에서 고정했다. 지연 공격·모든 호출 기술·행동 실패/대상 소실·추가 연타 도구·폼 변화·타입 변환·원본 난수 전체 및 실계정/실기기 자연 플레이는 미검증이다. 전체 스텔라·테라파고스 폼 구현의 완성을 주장하지 않는다. UI와 Sites는 변경하지 않았다.

최종 검사: 마지막 저위력·문맥 복구 변경 후 전체 회귀 678개 통과(실패·취소·건너뜀 0), 타입 검사·빌드·변경 파일 ESLint·diff 공백 검사 통과.
