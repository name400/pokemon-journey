# 루주 3번지와 7번지 지상 접근

[루주 3번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/rouge-sector-3.html)는 북동쪽의 루주 7번지 접근을, [루주 7번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/rouge-sector-7.html)는 북서쪽의 루주 3번지 접근을 설명한다. 기존 지도에는 두 구역의 직접 지상 경로가 없었다.

두 화면에 왕복 접근을 추가했다. 출입 좌표와 보도 폭·선형은 원작에서 측정되지 않은 2D 추정이다. 기존 루주 광장·4번지·루주 거리와 상점, 전투장·옥상 및 야생 구역 13의 랭크 제한을 유지한다. 이전 통행 칸을 막거나 저장 형식·진행 상태를 바꾸지 않는다.

대표 단위 검사에서 왕복·구형 저장 복원, 기존 상점과 광장·4번지 경로, 구역 13 랭크 제한 및 옥상 연결을 확인했다. 원작 실기·운영 D1·실제 Sites 병합본은 확인하지 않아 모바일 이동 오류와 배포 검사 실패 기록을 유지한다.
