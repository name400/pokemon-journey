# 구형 저장의 분리된 도구 이동

같은 포켓몬의 동일 도구가 여러 저장 행으로 나뉜 경우 이동 화면은 같은 항목을 여러 번 표시했지만 실제 이동은 첫 행만 사용했다. 같은 정보를 가진 일반 도구 행은 이동 화면에서 수량을 합산하고, 선택한 수량을 여러 행에 걸쳐 차감하도록 했다. 이미 나뉜 기록은 자동 병합하거나 삭제하지 않으며 실제 이동으로 수량이 0이 된 행만 제거한다.

알 수 없는 추가 메타데이터가 있는 행은 합산하지 않는다. 같은 ID의 여러 종류가 있으면 첫 묶음을 표시하고, 모두 이동하면 다음 묶음을 표시한다. 목적지에 다른 메타데이터가 있으면 별도 행을 보존하며 전체 한도 검사는 모든 행과 native 소지 도구를 합산한다. 서로 다른 종류·소유자·타입과 다른 저장 슬롯은 보존한다.

대표 파티 화면 데이터와 실제 이동 명령, 저장 복원, 한도 거부 시 전체 보존, 메타데이터 분리, 기존 도구 이동·native 도구·융합 보상 경로를 일반 환경과 Worker 로더에서 검사했다. 모든 도구·특수 효과 조합이나 운영 실계정 검증은 아니다.
