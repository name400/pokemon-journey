# 2026-11-05 울트라볼과 모바일 보상·정비 카드

기준 `e549d370fd2905f85e8ba6cd10575a8dcd15c1e1`. 사용자가 울트라볼은 기존 하이퍼볼(영문 Ultra Ball)과 다른 **Beast Ball**이라고 확인했다. 별도로 모바일7층 보상 카드의 설명·등급, 기력의조각 가격이 잘리는 문제를 요청했다. 두 요청을 연결해 긴 울트라볼 설명까지 검사했다. Sites나 운영 저장은 변경하지 않았다.

## 울트라볼 구현

고정 PokéRogue 원본의 사용 가능한 볼은 몬스터/슈퍼/하이퍼/로그/마스터5종이고 Beast Ball은 없다. 이번 추가는 사용자 요청 확장이다. 원본 enum의 비활성 Luxury Ball 등을 활성화하지 않는다.

공유하는 작은 볼 메타데이터에 `beastball / 울트라볼 / beast-ball`을 추가해 보상·가방·전투 메뉴·볼줍기의 이름을 일치시켰다. 보상은 이 앱의 **하이퍼 등급(2),1개,가중치6,최대99개**로 설정했다. 이 획득 설정은 upstream에 존재하지 않는다. 기존5볼의 개별 배율·가중치·수량은 유지하며 전체 풀은 추가 항목만큼 달라진다. 기존 저장에 beastball 필드가 없어도0개로 취급하고 보상으로 획득한다. 이미 저장된 보상 목록을 초기화하지 않는다.

Beast Ball의 보정은 울트라비스트5배/그 외0.1배다. [PokéAPI item887 효과 자료](https://raw.githubusercontent.com/PokeAPI/pokeapi/master/data/v2/csv/item_prose.csv)의 규칙을 기존 PokéRogue Gen6 흔들림·상태·이로치·크리티컬 계산식에 적용한다. 최종 성공확률 자체가 항상5배가 된다는 의미가 아니다. 울트라비스트 판정은 [고정 원본 NON_LEGEND_ULTRA_BEASTS](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/data/balance/special-species-groups.ts)의11종이다. 코스모그 계열·네크로즈마 등 관련 전설과 변신으로 외형만 바뀐 일반 포켓몬은 포함하지 않는다. 판정은 원래 개체의 source species를 사용한다.

한국어 이름·포획 보정 설명·수량, Beast Ball 전용 아이콘 URL과 포획 재생의 볼 식별자를 연결했다. 기존 하이퍼볼 이미지/atlas로 대신 표시하지 않는다. 실제 획득 후 던지기, 실패 시1개 소모, 성공 시 originBall, 파티 가득 찬 교체/놓아주기, 도감과 다른 슬롯·탐험 보존, 저장 복구를 검사했다. 볼줍기는 실패한 울트라볼을 배틀당1회 회수하며 codec 복구 뒤 중복 회수하지 않는다.

트레이너/포획 불가/보스HP 구간/더블 대상/최종 보스의 기존 제한을 따른다. 마스터볼처럼 제한을 우회하지 않는다. 볼이99개로 가득 찬 저장된 보상은 비활성 사유를 표시하고 원자적으로 거부해 무효 보상 소비를 막는다. 기존98개에서 수량 보상을 받아99개로 자르는 정책은 유지한다.

## 모바일 잘림 수정

390×844의 실제 Page에서 긴 문구를 넣으면 기존76px 보상 카드의 설명이 약83–124px 밖으로 나오고 등급은 위로 밀렸다. 정비 가격도 카드 아래 약1px까지 나왔다. 카드와 정비 그리드의 고정 높이가 원인이었다.

680px 이하에서는 무료 보상을2열로 배치하고 각 행 높이를 내용에 맞춘다. 이름·설명·등급은 줄바꿈하고 정비 가격은 별도 행에 둔다. 패널을 문서와 함께 스크롤하며 대상 선택창은 화면과 모바일 하단 메뉴 위에 맞춰 배치한다. tooltip이나 글자를 단순히 잘라 숨기는 처리는 하지 않는다. lazy component CSS와의 우선순위도 명시해 뒤늦게 고정 높이가 다시 적용되지 않게 했다. PC 배치는 유지한다.

320×740,360×740,390×844,430×932,640×390,1280×850의6크기에서 다음을 확인했다.

- 몬스터볼·과사열매·울트라볼의 설명과 등급, 공백 없는 긴 문구의 카드 내부 표시.
- 정비 설명과 가격의 내부 표시, 부활 대상 선택/확인 버튼 hit testing, 실제480원 결제와HP 회복.
- 무료 울트라볼 보상 선택, 다음 전투 진입, 울트라볼 선택/설명/이미지URL, 실제 포획과 재접속.
- pageerror0, 가로 overflow0, 다른 슬롯·탐험 데이터 보존. 포획의 정상 코인 보상은 마스터볼 대조군과 비교했다.

화면 검사의 외부 이미지는 SVG로 대체했다. 실제 아이콘/포켓몬 이미지의 다운로드와 실기기 렌더링은 별도다. 스크립트는 `tests/browser/ui-readability/beast-and-rewards.mjs`다.
