# 이동 확인 중 대화 입력

이동 요청이 진행 중일 때 대화 입력을 누르면 이전에는 입력이 버려졌다. 이제 현재 표시 중인 예측 위치·방향을 기억하고 이동을 멈춘다. 해당 요청이 성공한 뒤 서버가 확인한 위치·방향·구역·선두 개체가 모두 일치하고 전투·포획·기술 선택이나 다른 화면이 없다면, 서버가 반환한 상호작용만 대화창으로 연다. 행동이나 보상은 대화창에서 사용자가 다시 선택해야 한다. 위치가 다르면 대화를 열지 않고 다시 시도하도록 안내한다. 구역 전환 중인 예측이나 다른 종류의 요청에는 대화 입력을 예약하지 않는다.

키보드 E와 모바일 대화 버튼을 함께 지원한다. 실패·복구·전투·다른 화면 열기에서는 예약이 취소된다. 이미 화면에 예측된 여러 걸음이 서버에 모두 확인되지 않았다면 해당 위치에서 자동 대화하지 않는다. 서버 판정과 저장, 충돌·조우·복구 펜스는 변경하지 않았다.

격리 브라우저와 모의 API에서 일치, 보정, 추가 미확정 이동, 대상 없음, 조우, 409 실패, 선두 변경과 터치 버튼을 검사했다. 기존 방향 전환 8개와 조우 중 방향 전환 검사도 통과했다. 실제 운영 기기·네트워크 지연은 측정하지 않았고, 이 변경은 대화 입력 유실을 줄이는 것이며 걷기 지연 전체를 해결한 것은 아니다. `testfailed.md`의 독립 복구 경합은 이 검사와 별개로 유지한다.
