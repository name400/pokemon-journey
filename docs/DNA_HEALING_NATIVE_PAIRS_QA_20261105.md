# 회복 도구 native 충돌 추가 지원

앞선 동일 먹다남은음식 충돌 단위에서 계속 구현했다. 원본
`TurnHealModifier`와 `HitHealModifier`는 각각 최대4개다. 이제 주체와
기증자가 먹다남은음식/조개껍질방울을 가진 네 조합을 실제 DNA 보상에서
지원한다. 주체 native 슬롯은 유지하며 기증자 한 개는 해당 중첩 도구로
이전한다. 각 도구의 합계 한도는 별도로 검증하고 알 수 없는 메타데이터,
명시적 비이전 도구, 한도 초과는 원본 복사본 단계에서 거부한다.

공통 `CLASSIC_NATIVE_STACK_CAPS`를 사용해 두 도구 모두 보상/직접 지급/
수동 이전/쓰레기 자동 배분/집게손톱/미니블랙홀/픽업의 native+modifier
합산을 적용했다. 네이티브 takeItem 경계의 도둑질·탐내기·매지션·
나쁜손버릇·트릭·바꿔치기·선물·공생도 같은 공통 검증을 호출한다.
기존 과다 보유는 임의 삭제하지 않는다.

검증:
- 새 DNA 조합3검사: 네 조합 모두 실제 보상 후보→확인→codec→분리,
  동일 조개껍질방울 두 개의 실제 Seismic Toss 피해50→회복12를 저장
  복구한 두 턴에서 확인, 한도/보상/수동 이전/자동 배분 검사.
- 전투 획득9검사: 먹다남은음식 합계3/4/5 보존, 별도 native 전달,
  조개껍질방울의 Grip/BH/Pickup 두 표현×합계3/4 포함.
- 표준 관련 집중35/35, Worker 신규12/12.
  `/tmp/astra-healing-items-final.log`,
  `/tmp/astra-healing-items-worker-final.log`.

  `/tmp/astra-healing-items-lint.log`.

독립 active 폼 도구 상태와 자동 재활성 순서.
