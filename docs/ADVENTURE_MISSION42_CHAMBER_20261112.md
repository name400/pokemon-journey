# 미션 42 프리즘타워 아래 대결 공간

[원작 구역 20 설명](https://bulbapedia.bulbagarden.net/wiki/Wild_Zone_20)은 지가르데와의 대결이 프리즘타워 잔해 아래에 있으며 세 단계의 배틀로 진행된다고 설명한다. 이 위치 관계를 반영해 새로 L과 배틀을 시작하여 승리한 진행에는 구역 20 지상 유적에서 지하 대결 공간으로 내려가는 경로를 추가했다. 기존 턴제 세 단계·패배 시 초기화·확정 포획과 큐브 수령은 유지한다. 계단을 통해 지상으로 돌아갈 수 있으며 지하에서는 지도 빠른 이동을 제한한다.

유적 지상 입구의 정확한 좌표, 지하 평면·계단·포켓몬의 위치와 시각적 묘사는 기존 2D 좌표에 맞춘 추정이다. 원작의 실시간 전투 공간이나 영상과의 정밀 일치를 뜻하지 않는다. 이미 L과 배틀 중이던 저장이나 이전에 미션 42를 시작한 저장은 새 분기를 강제하지 않는다. 패배로 센터에 돌아갈 때 지하 상태를 해제하고, 재도전 시 다시 내려갈 수 있다.

새 지하 경로의 입구·왕복·재접속·패배·세 전투·포획·큐브·완료 후 출구와 구형 지상 경로를 격리 API에서 검증했다. 모바일 크기 브라우저에서는 모의 API와 대체 스프라이트로 지상 대화와 지하 진입을 확인했다. 실제 원작 기기 및 운영 서버는 검증하지 않았다.

미션 42를 완료하고 지상으로 나온 뒤에도 같은 지하 대결 장소를 다시 방문하고 돌아올 수 있다. 포획과 큐브 보상은 재발생하지 않는다. 이전에 지하 분기가 없는 저장은 변경하지 않는다. 원작에서 완료 후 재방문이 가능한지는 확인하지 못했으므로 이 접근은 게임 내 편의 처리다.
