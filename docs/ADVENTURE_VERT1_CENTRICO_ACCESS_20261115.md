# 베르 1번지와 센트리코 광장 지상 접근

[베르 1번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-1.html)는 북서쪽 센트리코 광장 접근을, [센트리코 광장 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/centrico-plaza.html)는 남동쪽 베르 1번지 접근을 설명한다. 기존 지도에는 두 화면 사이의 직접 지상 경로가 없었다.

기존 지상 화면에 왕복 접근을 추가했다. 출입 좌표와 길의 폭·선형은 원작에서 측정되지 않은 2D 추정이다. 세존 운하변 별도 층에는 새 출입을 두지 않으며 구역 20 연결과 베르 광장·거리의 기존 출입을 유지한다. 이전 통행 칸을 막지 않고 저장 형식·진행 상태를 변경하지 않는다.

대표 단위 검사에서 양방향 이동·구형 저장 복원, 운하변 층과 구역 20의 접근을 확인했다. 원작 실기·운영 D1·실제 Sites 병합본은 확인하지 않아 모바일 이동 오류와 배포 검사 실패 기록을 유지한다.
