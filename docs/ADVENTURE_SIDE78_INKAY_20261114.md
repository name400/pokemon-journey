# 사이드 미션 78: 오케이징의 향기

[의뢰 자료](https://www.serebii.net/legendsz-a/sidemissions/inkay%27sfragrantink.shtml)와 [공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_61-80#Side_Mission_078:_Inkay%E2%80%99s_Fragrant_Ink)을 참고해 Odette의 바닐프티 의뢰를 마치고 미션 26이 시작되면 오케이징 의뢰를 받는다. 파티의 오케이징을 보여 주고 별도로 2,000원과 큰진주 3개를 받는다. 기존 구역 11의 오케이징 출현을 이용할 수 있다.

보여 준 개체는 소비하거나 수정하지 않는다. 서버는 개체의 소유권·원본을 저장 순간 다시 확인하며, 가방과 지갑 한도 및 월드 리비전으로 보상과 중복 요청을 보호한다. 가방이 가득 차면 수령 단계가 남는다. 과거 저장에 완료를 추정하지 않고 알 수 없는 단계는 수정하지 않는다. 수첩에서 추적하면 같은 지역의 기존 Odette 위치를 표시한다.

격리 SQLite API에서 선행 조건·파티 밖 거절·소유권 경합·재접속·가방 한도·중복 요청 및 이로치·지닌 도구·기술 보존을 확인했다. 기존 메이클·바닐프티 의뢰와 단계별 표식도 대표 검사했다. Odette 위치는 기존 2D 초안이며 실제 원작 기기·운영 D1·Sites 병합본과 PC·모바일 화면은 검증하지 않았다.
