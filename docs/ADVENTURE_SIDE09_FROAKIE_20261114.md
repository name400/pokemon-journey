# 사이드 미션 9: 개구마르의 비계 도전

[Serebii](https://www.serebii.net/legendsz-a/sidemissions/achallengefromfroakie.shtml)와 [Thonky](https://www.thonky.com/pokemon-legends-z-a/side-mission-009-a-challenge-from-froakie)에 따라 미션 6부터 존느 8번지에서 30초·40초 코스를, 노스 불르바르에서 로토글라이드가 필요한 50초 코스를 진행한다. 각각 서버 시각으로 시작과 도착을 확인하며 실패하거나 나가면 해당 코스를 다시 할 수 있다. 코스 중 우회 이동과 파티 변경을 제한하고, 재접속 시 시각과 위치를 복원한다. 구형 클라이언트가 별도 코스 좌표를 잃으면 안전한 기존 위치로 복귀해 다시 시작할 수 있다.

현재는 각 코스를 별도의 좁은 2D 비계 통로로 표현하며 마지막 코스에 기존 로토글라이드 이동을 연결했다. 실제 원작의 비계 모양·계단·낙하·활공 횟수 및 인물의 정확한 좌표는 확인하지 못했으며 초안이다. 원작 실시간 달리기와 동등한 조작감이라고 주장하지 않는다.

완주 후 레벨 14 개구마르와 1,800원, 경험사탕XS 3개·S 1개를 한 번 지급한다. 선물의 무작위 성격과 색이 다른 모습 여부는 검증하지 못해 기본 성격과 일반 색을 사용한다. 파티가 가득 차면 보유함으로 보내고, 공간이 부족한 사탕은 보관한다. 기존 보유 개체를 변경하지 않으며 리비전으로 중복 수령을 막는다.

격리 SQLite API에서 세 코스의 실제 이동, 시간 초과·재도전, 로토글라이드 제한과 사용, 코스 중단, 위치 복원과 구형 클라이언트 복구, 선물·가방 한도·중복 수령을 확인했다. PC·모바일 실제 브라우저, 원작 기기, 운영 D1 및 Sites 병합본은 확인하지 않았다.

후속: 원작의 로토무폰 남은 시간 안내를 참고해 코스 화면에 남은 초를 표시한다. 서버가 응답 시점에 남은 시간을 계산하고 브라우저가 다음 응답까지 화면만 갱신하므로 타이머를 위한 추가 이동·조회 요청은 없다. 응답 지연만큼 표시가 실제 판정보다 늦을 수 있으며 성공·실패는 기존 서버 시간이 최종 판정한다. 타이머는 저장하지 않고 유효하지 않은 코스 상태에서는 표시하지 않는다. 격리 API에서 코스 중 시간 범위, 만료 시 0, 저장에 임시 표시값이 남지 않는 것을 검사했다. PC·모바일 실제 브라우저와 운영 Sites는 확인하지 않았다.
