# 블루 4번지와 에스티발 애비뉴 연결

[블루 4번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-4.html)는 북쪽 에스티발 애비뉴를, [에스티발 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/estival-avenue.html)는 남쪽 블루 4번지를 인접 구역으로 기록한다. 기존 지상 화면에 왕복 접근을 추가했다. 출입 좌표와 길의 선형은 잠정 2D 배치다.

기존 야생 구역 5 출입과 구역 9·10의 해금 조건, 저장 형식을 유지한다. 원작 실기와 실제 Sites 병합본은 확인하지 않았다. 모바일 이동 오류 기록은 운영 재검증 전까지 유지한다.
