# 다이맥스 발동·복원 재검사 — 2026-11-18

격리 SQLite API에 추가한 시험에서 다이맥스 밴드가 없으면 버튼과 직접 발동 명령이 차단되고 저장 행이 유지됐다. 밴드가 있으면 실제 명령으로 발동한 뒤 세 턴을 진행하면서 매 턴 재조회·네이티브 복원했다. 첫 두 턴은 다이맥스 상태와 2배 최대 HP가 유지되고 세 번째 턴 이후 기본 HP로 복귀했으며, 기술 PP는 턴마다 1씩 줄고 같은 전투에서 재사용 선택지는 나타나지 않았다. 다른 슬롯·탐험 데이터와 낡은 리비전 거절도 확인했다. 시험 상대는 공격하지 않아 피해를 입지 않는 구성이다.

별도 엔진 검사에서는 종료 전 승리 후 새 전투에서 임시 HP와 폼이 복귀하는 경계와, 연속 야생 전투에서는 기존 규칙대로 남은 다이맥스 턴이 이어지는 경로를 각각 확인했다. 교체 시 해제, 구형 저장, 융합 단일·더블의 지속과 피해 HP 비율·복원, HP 표시 이벤트를 포함한 엔진 검사 14건 및 위 API 검사 1건이 통과했다. 전투 승리 직후에는 연속 야생 전투를 위해 임시 상태가 남을 수 있으므로 모든 전투 종료 즉시 복귀한다고 단정하지 않는다.

시험 포켓몬과 상대를 구성한 격리 검사이며 이 범위에서 새 결함은 재현되지 않아 게임 코드를 변경하지 않았다. 실제 브라우저·실기기, 모든 기술·폼·피해 조합, 운영 저장과 Sites 배포는 검사하거나 변경하지 않았다.
