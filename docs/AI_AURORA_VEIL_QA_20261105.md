# 오로라베일 날씨 조건의 적 AI

신규 도전의 `enemyAiAuroraVeilRule: source-v1`에서 적 AI가 유효한 눈 또는 싸라기눈이 없을 때 오로라베일의 점수를 낮춘다. 기존 도전은 이전 판단을 유지한다. 원본의 오로라베일 날씨 조건과 전투 엔진의 유효 날씨 처리를 대조했다.

저장·복원 후 눈, 맑음, 비, 날씨 없음과 날씨를 무효화하는 에어록·날씨부정, 기존 도전 및 다른 저장 슬롯 보존을 격리 전투에서 검사했다. 싸라기눈의 별도 실제 전투 사례, 오로라베일 이외 기술의 메가솔 날씨 덮어쓰기와 특성 억제·특수 날씨의 다른 조합, 실제 브라우저 플레이는 아직 검증하지 않았다. AI의 다른 상태 기술 점수·대상·교체·난수와 도구·이벤트·폼의 원본 동등성도 남아 있다. 운영 데이터와 Sites는 변경하지 않았다.

후속 구현: 신규 도전의 `auroraVeilWeatherRule: source-v1`은 원본처럼 메가솔이 사용자의 날씨를 햇살로 취급하므로 눈 속에서도 오로라베일을 실패시키고 AI가 이를 피하게 한다. 양측의 기술 사용, 패시브 메가솔, 위액을 통한 특성 억제, 저장 복원과 기존 도전의 이전 동작을 격리 검사했다. 이 수정은 오로라베일에 한정된다.
