# Z기술 조건·저장 재검사 — 2026-11-18

격리 SQLite API에서 Z링과 노말Z를 가진 이브이의 전광석화 Z기술을 실제 명령으로 발동했다. 첫 사용의 연출 이벤트와 원래 기술 PP 1 소모, 크리스탈 유지 및 사용 상태를 저장 복원으로 확인했다. 같은 전투에서 재사용 선택지가 사라지고 최신 리비전으로 강제 재요청해도 409로 거절돼 저장이 바뀌지 않았으며, 일반 전광석화는 계속 사용할 수 있고 PP가 다시 1 줄었다. 다른 슬롯과 탐험 데이터도 유지됐다.

기존 격리 API 검사에서 Z링 없음·크리스탈 없음·타입 불일치 거절과 더블 전투의 대상·PP·사용 상태 복원도 다시 확인했다. 위 API 3건과 일반·전용 크리스탈, 변화 기술·더블 및 보상 경로가 포함된 엔진 검사 1파일이 통과했다. 신규 검사의 첫 실행은 활성 Z 변형의 `disabled` 필드가 `false`가 아닌 생략 형태임을 잘못 가정해 실패했으며, 변형이 존재하고 비활성으로 표시되지 않는다는 실제 계약을 확인하도록 단언을 바로잡았다. 이는 게임 결함이 아니었다.

시험 포켓몬·상대와 장비를 설정한 경로이며 새 결함은 재현되지 않아 게임 코드는 변경하지 않았다. 모든 크리스탈·기술·폼, 실제 브라우저·실기기와 운영 저장은 이번에 확인하지 않았고 Sites에는 배포하지 않았다.
