# 미션 42 L의 배틀

[Serebii 원작 미션 자료](https://www.serebii.net/legendsz-a/mainmissions/tokeeptheworldinbalance.shtml)의 L 포켓몬 여섯 마리의 레벨과 기술을 적용하고 마지막 갸라도스에게 갸라도스나이트를 장착했다. 기존 턴제 전투 엔진의 상대 메가진화 로직을 사용하며, 갸라도스가 출전해 행동할 기회를 얻을 때 메가진화한다. 패배 시 미션을 진행하지 않고 기존 저장·보유 포켓몬은 그대로 유지한다.

원작의 실시간 전투와 기술플러스 효과는 이 턴제 전투에 구현하지 않았다. 타워 아래 대결 공간의 정확한 지형도 미완성이다.
