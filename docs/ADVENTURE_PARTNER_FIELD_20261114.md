# 필드 선두 포켓몬 표시

선두 포켓몬을 캔버스에서 플레이어가 지나온 칸 쪽에 표시한다. 이동 및 상호작용 판정에 참여하지 않는 클라이언트 전용 표현으로, 서버 위치·파티·보유함·저장 형식과 요청 수는 바꾸지 않는다. 위치가 불연속적으로 수정되거나 구역·층이 바뀌면 주변 통행 가능 칸에서 화면상 궤적을 다시 만든다. 인접한 칸이 없으면 표시하지 않는다. 이동 예측이 취소될 때도 플레이어의 실제 그리기 경로를 따른다. 파트너 교체는 기존 선두 데이터에 따른다.

원작에서 선두 포켓몬이 동행한다는 설명은 [Walking Pokémon](https://bulbapedia.bulbagarden.net/wiki/Walking_Pok%C3%A9mon#Pok%C3%A9mon_Legends:_Z-A)을 참고했다. 한 칸 뒤의 2D 이동과 표시 크기는 이 프로젝트의 근사 표현이며, 원작의 동행 상호작용·독립 행동이나 출입 제한을 재현한다고 주장하지 않는다. 미용한 트리미앙과 확인된 일부 폼은 기존 이미지 로더를 사용한다. 그 외 특수 외형은 기존 필드 스프라이트 대체가 있을 수 있다.
