# 필드 선두 포켓몬 표시

선두 포켓몬을 캔버스에서 플레이어가 지나온 칸 쪽에 표시한다. 이동 및 상호작용 판정에 참여하지 않는 클라이언트 전용 표현으로, 서버 위치·파티·보유함·저장 형식과 요청 수는 바꾸지 않는다. 위치가 불연속적으로 수정되거나 구역·층이 바뀌면 주변 통행 가능 칸에서 화면상 궤적을 다시 만든다. 인접한 칸이 없으면 표시하지 않는다. 이동 예측이 취소될 때도 플레이어의 실제 그리기 경로를 따른다. 파트너 교체는 기존 선두 데이터에 따른다.

원작에서 선두 포켓몬이 동행한다는 설명은 [Walking Pokémon](https://bulbapedia.bulbagarden.net/wiki/Walking_Pok%C3%A9mon#Pok%C3%A9mon_Legends:_Z-A)을 참고했다. 한 칸 뒤의 2D 이동과 표시 크기는 이 프로젝트의 근사 표현이며, 원작의 동행 상호작용·독립 행동이나 출입 제한을 재현한다고 주장하지 않는다. 미용한 트리미앙과 확인된 일부 폼은 기존 이미지 로더를 사용한다. 그 외 특수 외형은 기존 필드 스프라이트 대체가 있을 수 있다.

실제 Sites 병합본 및 실기 동작은 검증하지 않았다. 기존 testfailed.md의 Sites 검증 대기 기록을 유지한다.

## 파티 순서를 유지하는 필드 선두 전환

[원작 동행 안내](https://bulbapedia.bulbagarden.net/wiki/Walking_Pokemon#Pok%C3%A9mon_Legends:_Z-A)는 파티 순서와 별개로 선두를 선택한다고 설명한다. 필드의 선택 상자와 파티 바로가기에서 현재 파티의 건강한 다른 포켓몬을 선택하면 `activeId`만 바꾸고 파티 순서는 보존한다. 기존 보유함에서 파티를 편성하는 동작은 유지한다. 전투·포획 선택·기술 선택 및 연전의 기존 제한을 적용하며, 서버는 선택한 개체의 소유권과 원본이 저장 순간에도 일치하는지 확인한다. 기절한 개체를 필드 선두로 선택할 수 있는 원작 세부 규칙은 별도 확인하지 못해 현재 선택은 제한한다.

격리 API에서 정상 선택·재접속·파티 순서, 기절·파티 밖 선택 거절, 오래된 요청·소유권 경합, 연전 제한 및 선택한 선두로 배틀을 시작하는 경로를 확인했다. PC·모바일 Chromium의 모의 API 화면에서 선택과 순서 보존을 확인했다. 실제 원작 기기·운영 D1·Sites 병합본과 실제 이동 지연은 미검증이다.
