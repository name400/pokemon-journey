# 하수도 곤율랭 획득

미르 도감에 필요한 곤율랭은 기존 동료·트레이너 배틀에 등장하지만 조사한 플레이어 포획 경로에서는 확인되지 않았다. 곤율거니는 구역 20에서 포획할 수 있으나 곤율랭의 등록은 별도다. [원작 위치와 레벨 자료](https://rotomlabs.net/dex/legends-z-a/scraggy)는 하수도에서 레벨 34~48 곤율랭이 나타나고 레벨 39에 곤율거니로 진화한다고 설명한다.

하수도 본 통로의 기존 벽 타일에 레벨 35 개체를 배치했다. 정확한 2D 좌표와 재출현 빈도는 초안이다. 얼음 갈림길과 미션 안쪽 방에는 표시하지 않으며 기존 통행 가능 좌표나 보유 개체를 변경하지 않는다. 기존 야생 단일 배틀·포획과 도감·진화 처리를 재사용한다.

격리 API에서 포획·재접속, 하수도 출입 왕복, 진화 및 포획·진화 중복 요청 방지와 기존 파티 보존을 확인했다. 진화 단계는 포획 개체의 레벨을 시험 데이터로 설정했으므로 전체 육성 경로나 연구 레벨 50 정상 완주는 검증하지 않았다.
