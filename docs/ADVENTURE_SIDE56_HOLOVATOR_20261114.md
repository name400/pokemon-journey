# 사이드 미션 56: 홀로베이터 수리

[의뢰 자료](https://advent.serebii.net/legendsz-a/sidemissions/we%27lljustmuscleourwaythrough.shtml)와 [공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_41-60)을 참고해 미션 20 시작 후 존느 6번지에서 의뢰를 받고 격투 물리 기술로 홀로베이터를 수리한다. 이용해 옥상에 오른 뒤 900원과 힘의머리띠를 한 번 받을 수 있다. 가방이 가득 찬 경우 보상을 보류하고 기존 리비전으로 중복을 막는다.

새 홀로베이터는 기존 막힌 칸에서 기존 존느 6 옥상으로 연결하며 구형 사다리·복귀 위치와 저장을 유지한다. 정확한 원작 좌표와 도착 옥상은 확인하지 못한 2D 초안이다. 기존 사다리 이동은 포켓몬을 변경하지 않으므로 공유 보유함을 불필요하게 다시 저장하지 않도록 했다. 격리 API에서 기술 조건·수리·옥상·사다리 복귀·보상 한도·중복과 보유 개체 보존을 검사했다. 원작 기기, 운영 D1, Sites 병합본은 확인하지 않았다.
