# 불태우기의 소지 열매

원본의 불태우기는 대상의 이전 가능한 열매 중 하나를 제거하며 플레이어 포켓몬도 대상이 된다. 최신 신규 도전은 포켓로그식 열매 스택과 검토된 네이티브 열매를 고려하고, 각각의 전투·플레이어 저장 상태를 동기화한다. 포켓로그식 열매는 먹은 것으로 기록하지 않아 수확으로 복원되지 않는다. 원본과 달리 네이티브 엔진이 태우던 비열매 Gem은 보존한다. 기존 도전은 기존 처리를 유지한다.

플레이어 저장과 전투 사본의 수량·메타데이터가 정확히 일치하는 항목만 제거한다. 일치하지 않거나 수량이 잘못된 항목은 건드리지 않는다. 점착·방어·대타·타입 면역, 여러 열매와 열매주머니, 단일·더블 전투, 다이맥스, 저장 복구와 포획 시 남은 수량을 격리 검사했다. 원본의 기절 시 점착 TODO, 모든 특성·폼 조합과 원본 난수 스트림은 전수 검증하지 않았다. 실계정·실기기 검증은 하지 않았다.

마지막 저장 방어 조건 추가 전 관련 도구·열매·미스터리·첫 턴·변신·호출·AI·날씨·지형·트레이너·상태·챌린지·융합·학습·스케치 회귀는 일반 실행과 Worker 로더에서 각각 498건 통과했다. 최종 코드의 불태우기·탁쳐서떨구기·폴터가이스트 집중 검사 44건도 양쪽에서 통과했고, 최종 타입 검사와 빌드가 통과했다. 전체 프로젝트 검사는 아니다.
