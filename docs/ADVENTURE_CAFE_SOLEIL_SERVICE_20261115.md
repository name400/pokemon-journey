# Café Soleil 음료 서비스

[Café Soleil 자료](https://bulbapedia.bulbagarden.net/wiki/Caf%C3%A9_Soleil)는 남쪽 대로에 있는 카페와 사이드 미션 14, 음료 주문 시 파티 회복과 선두 포켓몬 친밀도 증가를 설명한다. [메뉴 자료](https://www.serebii.net/legendsz-a/cafes.shtml)와 대조해 음료 10종과 가격을 기존 카페 표식에 연결했다. 자료는 2차 출처이며 실기에서 확인하지 않았다.

기존 미션이 진행 중이거나 휘핑팝 보상이 맡겨져 있으면 해당 대화를 주문보다 먼저 처리한다. 주문은 돈·파티·연구 활동을 기존 카페와 같은 트랜잭션으로 처리하며, 선두 친밀도는 기존 공통 +30 규칙을 사용한다. 원작의 정확한 친밀도 증가는 확인되지 않아 근사다. 카페 건물·직원 위치도 기존 2D 초안 그대로다.

메뉴와 의뢰 우선순위, 잔액 부족, 회복·연구 기록, 중복 리비전 및 파티·기존 진행 보존을 대표 검사했다. 실제 운영 Sites와 모바일 D1 오류는 재검증하지 않았으므로 실패 기록을 유지한다. 상세 실내와 원작 연출은 아직 미구현이다.
