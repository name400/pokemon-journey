# 존느 광장과 8번 구역 접근

[원작 지역 자료](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_8)는 존느 광장의 중심과 가장자리가 모래로 바뀌고 존느 거리 양쪽에서 접근할 수 있다고 설명한다. [존느 광장 자료](https://bulbapedia.bulbagarden.net/wiki/Jaune_Plaza)는 원형 광장과 노점, 8번 구역의 관계를 확인한다. 안내 자료의 해금 시점은 서로 달라 기존 게임의 진행 조건을 유지한다.

기존 출입점에서 광장으로 이어지는 바깥 바닥을 포장해 동선을 구분하고 화면 경계에 구역 표식을 그렸다. 기존 모래 지형, 굴과 노점, 출입 좌표 및 저장 위치는 유지한다. 포장 폭·구역 경계 모양과 추가로 유지한 기존 출입구는 압축된 2D 초안이며 원작의 정확한 지형·장벽 배치나 높낮이를 재현한 것은 아니다. 원작 정밀 지도, 실제 운영 기기는 확인하지 않았다.
