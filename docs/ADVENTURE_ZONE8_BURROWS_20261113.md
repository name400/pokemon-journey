# 구역 8 흙더미 조우

[구역 8 안내](https://www.nintendolife.com/guides/pokemon-legends-z-a-wild-zone-8-guide-all-pokemon-and-alphas)와 [진행 안내](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Part_10)는 중앙 흙더미에 두더류와 희귀한 딥상어동이 숨어 있다고 설명한다. 기존 구역 8에서 두 종을 일반 풀숲 난수 풀에서 제외하고, 중앙의 흙더미 두 곳을 살펴보면 각각 턴제 야생 전투를 시작하도록 했다. 두더류를 새 지점에 추가하고 기존 딥상어동의 좌표와 소진 기록을 유지한다. 필드에는 포켓몬 그림 대신 흙더미를 그린다.

기존 출입구와 경로·저장 좌표를 보존하며, 옛 저장에서 두더류 지점에 서 있어도 자리를 옮기지 않는다. 두 개의 고정 위치·레벨과 항상 같은 종이 나오는 방식은 2D 초안이며 원작의 정확한 출현 빈도나 희귀도를 재현하지 않는다. 원작의 실시간 접근·돌출 행동도 상호작용으로 단순화했다. 자연 재출현은 기존 구역 출현 주기 규칙을 따른다.

격리 API에서 두 조우, 재접속, 포획·파티 및 재화 보존을 확인했다. 모바일 렌더링 검사는 모의 API와 대체 이미지를 사용했으며 원작 기기나 운영 사이트에서 검증하지 않았다.

후속 구현: 두 흙더미가 각각 두더류 또는 딥상어동을 공유하도록 변경했다. [원작 현장 안내](https://www.nintendolife.com/guides/pokemon-legends-z-a-where-to-catch-gible)는 흙더미에서 드러난 푸른 지느러미로 딥상어동을 알아볼 수 있다고 설명한다. 필드에는 푸른 지느러미 또는 분홍색 코를 표시한다. 딥상어동은 임시 확률 3%이며 정확한 원작 확률은 확인하지 못했다. 이 종 선택은 서버에 저장하고 재접속과 도주 때 유지한다. 시간 구간 갱신·구역을 떠날 때 일반 개체는 재추첨하며 미소진 이로치는 유지한다. 이전 버전에서 이미 표시된 개체나 이로치, 포획 소진 상태와 진행 중 전투는 보존한다. 구형 저장은 기존 개체 정보가 없는 흙더미만 새로 추첨한다. 모바일 화면은 격리 API·대체 이미지로 확인했다.
