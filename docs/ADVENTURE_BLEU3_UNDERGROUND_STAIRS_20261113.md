# 블루 3번지 지하 접근

[GamesRadar의 지도 안내](https://www.gamesradar.com/games/pokemon/full-pokemon-legends-z-a-map-and-all-locations/)는 뚜뚜 카페 뒤편에서 지하 계단을 내려가 하수도와 야생 구역 5 쪽으로 나뉘는 경로를 설명한다. [PowerPyx 안내](https://www.powerpyx.com/pokemon-legends-z-a-how-to-return-to-lumiose-sewers/)는 블루 3번지 접근의 오염물과 구역 5에서 지하를 거치는 다른 접근을 설명한다.

기존 블루 3번지의 계단 그림에 지하 통로로 내려가는 상호작용을 연결했다. 기존 화면 경계 출입도 구형 저장과 동선을 위해 유지한다. 지하 분기에서 하수도와 구역 5로 각각 이동하며 기존 오염물 제거와 하수도 해금 조건을 그대로 적용한다. 지하 통로를 벽돌과 배수로로 구별했다.

정확한 타일·계단과 배수로의 위치, 통로 폭은 2D 초안이다. 두 안내의 오염물과 계단 순서는 세부 표현이 달라 원작의 정확한 순서로 확정하지 않았다. 기존 저장 좌표는 변경하지 않았고 기존 지하 통로의 막힌 벽 일부만 배수로로 바꿨다. 원작 지도 이미지는 재사용하지 않았다.

대표 이동·차단·해금·재접속과 기존 지하/빠른 이동 회귀를 격리 검사했다. PC·모바일 화면은 시험 상태와 대체 외부 이미지를 사용했으며 원작 실기 및 운영 환경은 검증하지 않았다.
