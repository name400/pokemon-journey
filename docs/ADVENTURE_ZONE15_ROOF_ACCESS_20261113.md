# 구역 15 옥상 접근

[VGC 구역 15 안내](https://www.videogameschronicle.com/guide/pokemon-legends-z-a-wild-zone-15/)는 인접 건물의 홀로베이터와 불꽃 기술로 펼치는 거미줄 다리를 거쳐 옥상에 들어간다고 설명한다. 기존에 구현된 인접 옥상·거미줄 경로를 기본 접근으로 사용하고 이베르날 거리 및 구역 내부에서 옥상으로 바로 가던 지름길을 막았다. 정확한 좌표·도로·건물·다리 형태는 2D 초안이며 원작과 동일하다고 확인한 것은 아니다.

구형 저장의 `zaZone15Upper` 옥상 출구는 홀로베이터 수리 플래그가 없더라도 지상으로 나갈 수 있다. `zaZone15LiftReturn`이 hibernal이면 기존 이베르날 도착점을, 그 외에는 기존 구역 15 지상 도착점을 사용한다. 저장 구조나 포켓몬·재화는 변환하지 않는다. 지상 타일은 보존하되 상행 동작을 제공하지 않는다.

대표 API 검사에서 수리·랭크 조건, 거미줄 차단과 불꽃 기술 요구, 개방 후 저장 복원, 직접 상행 거부 및 구형 저장의 두 하행 목적지와 파티·재화를 확인했다. 지도 단위 검사 10개와 타입 검사가 통과했다. 모의 API 및 대체 이미지를 사용한 로컬 Chromium 390×844와 1280×900에서 인접 옥상 버튼을 확인했다. 운영 저장 및 물리 기기는 검사하지 않았다. 기존 통합 캠페인의 옥상 관련 시험 상태는 지름길 대신 구형 옥상 저장으로 설정했으며, 전체 캠페인 재실행은 이번 범위에 포함되지 않는다.

## 이베르날 홀로베이터 수리 의뢰

[Serebii의 사이드 미션 80](https://www.serebii.net/legendsz-a/sidemissions/ashockingterritorialdispute.shtml)은 르바네 전투 이후 이베르날 대로 홀로베이터 앞에서 전룡과 썬더볼트의 다툼이 일어난다고 설명한다. 기존에는 구역 15 지상에서만 수리 의뢰를 시작할 수 있어, 이베르날 홀로베이터에서도 의뢰를 시작하도록 연결했다. 기존 구역 15의 시작점과 기존 진행 조건은 구형 진행 호환을 위해 유지한다. 옛 저장에서 미션 30이 이미 시작된 경우도 대로에서 의뢰를 제공한다. 수리 후 기존 옥상 홀로베이터·불꽃 거미줄·구역 15 진입 경로를 사용한다.

대로의 건물 외관과 길, 옥상의 거미줄은 기존 이동 타일을 바꾸지 않은 2D 시각 초안이다. 정확한 원작 건물 외곽, 고도와 좌표는 확인하지 못했다. 원작의 두 포켓몬 동시 전투와 달리 현재 의뢰는 기존 턴제의 두 상대 연전이다.

대표 API 검사에서 미션 조건 전 차단, 패배 후 재도전, 승리 후 보상 중복 방지, 홀로베이터·거미줄·옥상 이동과 저장을 확인했다. 구형 구역 시작점 및 복원은 지도 검사로 확인했다. 로컬 Chromium PC·모바일 화면은 모의 API와 대체 이미지를 사용했으며 실제 운영 저장이나 기기에서는 검증하지 않았다.
