# 흉내내기의 적 AI 대상 판단

원본 `CopyMoveAttr`와 현재 Classic 흉내내기의 대상별 마지막 기술 조회·호출 제한을 대조했다. 신규 도전의 `enemyAiMirrorMoveRule: source-v1`은 원본 호출 정책을 사용하는 경우 적 AI가 각 대상의 직접 사용·호출 기술 이력으로 흉내내기 가능 여부를 판단하고 불가능한 대상의 점수를 낮춘다. 기존 도전은 이전 판단을 유지하며, 다이맥스 맥스가드는 기본 기술의 조건을 적용하지 않는다.

격리 싱글·더블 전투와 저장 복원에서 이력 없음, 한 상대만 복사 가능한 경우, 직접 사용과 호출 이력의 차이, 금지된 이력, 아군 대상, 다이맥스 및 다른 저장 데이터 보존을 검사했다. 조회는 기존 Classic 호출 정책과 이력 모델을 공유하며, 복사된 기술의 전체 유불리 점수·상대의 이후 행동·모든 챌린지·원본 난수열 동등성은 구현 또는 검증이 남는다. 실제 브라우저 플레이는 별도다. 운영 데이터와 Sites는 변경하지 않았다.
