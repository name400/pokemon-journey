# 멀티렌즈 에어컷터 첫 타격

고정 원본의 에어컷터는 급소 확률이 높은 상대 전체 바람·베기 기술이다. 신규 도전에서 멀티렌즈 첫 타격 중 앞 상대가 실제로 기절하면 뒤 상대의 피해에 남은 대상 수를 반영한다. 방어, 바람타기 면역 또는 기합의머리띠로 생존하면 피해 감소가 유지된다. 기존 도전은 기존 규칙을 유지한다.

아군·상대 사용, 후속 타격, 저장 복구와 다른 슬롯 보존 및 기존 잎날가르기 피해를 격리 검사했다. 대상별 추가 효과의 전체 순서, 바람 특성의 모든 조합과 원본 난수 동등성, 운영·실기기 플레이는 이 검사 범위에 포함되지 않는다.
