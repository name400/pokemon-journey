# 구역 16 파란 광장

별도 조사에서 전달받은 [원작 지도](https://images.nintendolife.com/038f6253c1473/wild-zone-16-pokemon-legends-z-a.large.jpg)와 [현장 화면](https://www.serebii.net/pokearth/maps/lumiosecity/17.jpg) 분석에 따르면 중앙 오벨리스크 주변의 파란 고리는 보행면이다. 이전의 물길 해석을 수정해 파란 타일 고리를 걸을 수 있도록 하고 북동쪽 분수는 수면으로 남겼다. 이 작업 환경에서는 두 원본 이미지를 직접 보지 못했다. [지역 설명](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_16)은 북서·동·남서 세 출입구와 중앙 오벨리스크·분수를 확인한다.

기존 북쪽 추가 출구는 구형 저장과 이동 호환을 위해 유지하며 원작 네 번째 출입구라고 주장하지 않는다. 정확한 충돌, 계단 단수, 고리·분수의 형태와 2D 타일 좌표는 추정이다. 기존 포켓몬·아이템·높은 정원·옥상과 세 출입 경로는 유지했다. 기존 물 칸을 보행면으로 열었으므로 그 칸의 옛 저장은 그대로 복원된다. 이전 물길 문서의 중앙 고리 물 해석은 이 기록으로 정정한다.

지도 단위 검사에서 중앙을 가로지르지 않는 고리 연결, 세 출입 및 저장 복원을 확인했다. 격리 SQLite API에서 구형 좌표·진행·재화 복원, 고리 이동, 개구마르 조우·도주와 높은 정원 연결을 확인했다. PC·모바일 Chromium 화면은 모의 API와 대체 스프라이트로 확인했다. 운영 D1·원작 기기는 검증하지 않았다. 충돌을 추가하지 않았으며 화면의 고리 판정은 미리 만든 집합을 사용한다.
