# 킬러스핀의 장해물 제거

고정 원본 `7c0881255af5cd51992e513ff93c2f71adbe40e0`의 [킬러스핀 기술 정의](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/data/moves/move.ts#L11799)와 [장해물 제거 속성](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/data/moves/move.ts#L6530)을 대조했다. 원본은 명중 대상에 피해를 주기 전에 사용자 진영의 네 설치 장해물을 제거한다.

기존 네이티브 처리에서는 우격다짐 사용자의 명중에도 설치 장해물이 남았다. 새 도전의 `mortalSpinHazardOrderRule: source-v1`은 유효한 명중 또는 대타 명중 시 사용자 진영의 압정뿌리기·독압정·스텔스록·끈적끈적네트를 피해 전에 제거한다. 모든 대상이 방어하거나 타입 면역인 경우 제거하지 않는다. 이전 저장에는 규칙을 소급 적용하지 않고, 전투 스냅샷에 적용 규칙을 기록한다.

격리 엔진에서 일반·우격다짐·패시브 우격다짐, 단일·더블·멀티렌즈, 대타·방어·타입 면역, 상대 진영 사용자, PP·저장 복원을 확인했다. 킬라플로르의 기술을 쓰는 실제 턴 경로와 우격다짐을 시험 설정한 사례는 별도다. 관련 전투 회귀를 합쳐 82건이 통과했다. 우격다짐과 결합된 씨뿌리기·부분 속박 해제, 모든 특성·도구 조합, 실기기·운영 저장은 이 수정으로 확인하지 않았고 Sites에는 배포하지 않았다.
