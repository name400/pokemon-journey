# 루주 스트리트와 센트리코 광장 연결

[루주 스트리트 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/rouge-street.html)는 남쪽 끝이 센트리코 광장이라고 설명하고, [광장 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/centrico-plaza.html)도 북쪽에 루주 스트리트를 기록한다. 기존 지상 화면 사이 왕복 접근을 추가했다. 출입 좌표와 길의 선형은 잠정 2D 배치다.

기존 야생 구역 20 출입과 해금 조건, 저장 형식을 유지하고 알 수 없는 거리 상태를 덮어쓰지 않는다. 원작 실기와 실제 Sites 병합본은 확인하지 않았다. 모바일 이동 오류 기록은 운영 재검증 전까지 유지한다.
