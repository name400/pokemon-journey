# 사이드 미션 87: 최고의 트리미앙 미용사

[의뢰 자료](https://www.serebii.net/legendsz-a/sidemissions/becomingapeerlessfurfroutrimmer.shtml)와 [보상 공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_81-100)에 따라 전문 미용 시연과 미션 30 시작 후 Mirte에게 후속 의뢰를 받고 선두 포켓몬의 사이코커터를 인형에 보여 준다. 퀸컷·가부키컷·킹덤컷을 기존 500원 미용에 추가하고 2,400원·기력의덩어리·경험사탕 L 2개를 한 번 받는다. 보상 대기 중에도 미용은 사용할 수 있고 가방 한도와 리비전으로 지급을 보호한다.

세 컷은 기존 검토된 로컬 일반·이로치 앞뒤 아틀라스를 사용한다. 기존 종·폼 식별자와 보유 개체 정보 및 이전 두 의뢰의 보상 대기는 변경하지 않는다. Mirte와 인형 좌표는 2D 초안이며 털이 자라는 시간과 필드 동행 외형은 미구현이다. 격리 API에서 해금·기술·재접속·가방 한도·중복과 이로치 개체 보존을 확인했다. 원작 실기·운영 D1·Sites 병합본은 확인하지 않았다.
