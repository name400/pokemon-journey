# 탐험·모험 메가파워의 턴제 환산

[원작 공략](https://www.powerpyx.com/pokemon-legends-z-a-how-to-unlock-mega-evolutions/)은 기술 적중으로 메가파워를 충전하고, 메가진화 중 서서히 소진하며, 교체 중 소진이 정지하고 소진 후 재충전·재진화할 수 있다고 설명한다. [기술플러스 자료](https://bulbapedia.bulbagarden.net/wiki/Plus_Move)는 메가진화 중 기술 자체가 플러스이며 기술마다 게이지를 따로 소모하지 않는다고 설명한다. 둘 다 2차 자료다.

원작은 실시간이므로 지속 시간을 턴으로 직접 변환할 수 없다. 이 구현의 지속 시간과 충전 단위는 플레이 가능한 턴제 근사이며 원작 턴 수나 원작 실측치가 아니다. 신규 탐험 전투에 버전 표식이 있을 때만 적용하고, 기존 진행 중 전투와 저장 개체·포켓로그는 기존 규칙을 보존한다. UI 테마와 이동은 변경하지 않는다.

- 변신한 포켓몬이 전장에 있는 턴을 3턴으로 제한한다. 변신한 턴도 포함하고, 교체로 벤치에 있는 동안은 남은 턴을 줄이지 않는다. 소진 또는 기절하면 원래 폼·특성과 현재 HP를 복원한다.
- 벤치의 메가 포켓몬 대신 기본 폼 포켓몬으로 행동해 모은 충전은 별도 다음 변신용 게이지로 남긴다. 원작의 시간 기반 게이지와 정확히 같지는 않으며, 이 충전으로 벤치의 남은 지속 턴을 늘리지는 않는다. 같은 소유자가 두 메가진화를 동시에 유지하지 못하게 한다. 동료·상대의 충전은 턴 단위 근사다.
- 새 버전 표식이 없는 기존 전투는 이전 규칙을 유지한다. 고정 폭주 메가 보스는 제한 대상이 아니다. 새 단일·동료·삼중 전투, 교체·기절·소유권·재접속·미션 26 마지막 일격 및 구형 전투를 대표 검사했다. 관련 개발본 단위 검사 34건과 격리 API 검사 3건이 통과했다.
- 최초 대표 검사에서 기절 시 교체 테스트가 실패했다. 같은 공격으로 상대까지 기절해 배틀이 끝나는 난수 경로가 존재했으며, 강제 교체를 검증하도록 상대 레벨을 높인 뒤 해당 검사군이 통과했다. 원래 실패 실행의 전투 로그는 수집하지 않아 동일 원인으로 확정하지 않는다. 운영 D1·실기기·Sites 병합본과 전체 테스트는 이번에 검증하지 않았다.
