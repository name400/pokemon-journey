# 구역 1 세 계열의 성장 기술

신규 일반 뿔충이·구구·메리프 조우에 Z-A 기술표 표식을 넣고 해당 개체가 포획·진화한 뒤에도 각 종의 레벨·진화·다시 배우기 기술을 사용한다. 새 야생 기술은 기존 방식대로 현재 레벨까지의 마지막 네 기술로 정한 근사다. [뿔충이](https://pokemondb.net/pokedex/weedle/moves/9), [딱충이](https://pokemondb.net/pokedex/kakuna/moves/9), [독침붕](https://pokemondb.net/pokedex/beedrill/moves/9), [구구](https://pokemondb.net/pokedex/pidgey/moves/9), [메리프](https://pokemondb.net/pokedex/mareep/moves/9), [전룡](https://pokemondb.net/pokedex/ampharos/moves/9)의 Z-A 목록을 대조했다.

기존 개체, 이미 생성된 전투·포획 기회의 개체, 표식이 미지의 형식인 개체는 소급 표기하지 않는다. 우두머리와 새로 조우한 진화형의 초기 기술은 이 변경 범위에 포함하지 않는다. 각 포획·진화 개체의 기술 목록, 기존 PP, 팀과 기타 데이터는 유지하며 새 기술은 빈 칸 또는 기존 기술 선택 대기 경로로 처리한다. 대표 단위·격리 API 검사는 실제 운영 데이터나 기기 검증이 아니다.

후속: 구역 1 옥상의 일반 구구 조우는 이미 검토한 종 기술표를 생성 경로에서 호출하지 않아 포획 후에도 공용 성장 기술로 돌아가는 누락이 있었다. 신규 일반 야생 조우만 기존 ZA 구구 기술표에 연결했다. 격리 API에서 실제 조우·마스터볼 포획·재조회와 기존 파티 개체 보존을 검사했으며, 우두머리와 기존 개체는 소급하지 않는다. 야생 초기 기술 네 칸 선택은 기존 근사 방식을 유지한다.
