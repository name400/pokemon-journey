# 베르날 대로 뚜뚜 카페와 뒤편 길

- [Bulbapedia](https://bulbapedia.bulbagarden.net/wiki/Caf%C3%A9_Woof)는 뚜뚜 카페가 블루 3번지의 베르날 대로에 있다고 설명한다. [GamesRadar](https://www.gamesradar.com/games/pokemon/full-pokemon-legends-z-a-map-and-all-locations/)는 카페 건물 뒤 길과 내려가는 계단에서 하수도와 구역 5로 갈라지는 경로를 설명한다.
- 기존 카페 서비스 위치와 옥상 사다리, 블루 3번지·뒤편 계단·하수도·구역 5 갈림길을 유지한다. 카페 앞 포장과 통행을 막는 건물 양쪽을 추가하고 사다리 뒤편 접근을 남겼다. 건물 모양·도로 너비·타일 좌표는 2D 초안이며 실제 원작 도면이나 모든 연결이 일치한다고 확인한 것은 아니다.
- 상층·물가 상태는 새 지상 건물 복원 대상에서 제외한다. 예전 지상 저장이 새 건물과 겹치면 같은 리비전에서 가까운 통행 가능 칸으로 복원하고 파티·재화·진행은 유지한다.
- 로컬 PC·모바일 브라우저 화면은 모의 API 데이터 및 외부 이미지 대체 화면이다. 운영 저장과 실제 Sites 배포는 검증하지 않았다.
