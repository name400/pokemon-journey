# 필드 장애물의 기술 이름 호환

탐험 필드의 가시덤불·거미줄·바위·얼음·메가결정·홀로베이터는 기존 저장에 기록된 기술의 한글 이름만 확인하고 있었다. 저장된 기술이 `flamethrower`, `Rock Smash`, `thunderbolt` 같은 영문 이름이나 기술 ID인 경우에도 기존 기술 데이터에서 같은 기술을 찾도록 수정했다. 조건에 맞는 속성·위력·물리 여부와 기절 여부, 각 장소의 진행 조건과 중복 방지 규칙은 유지한다. 알 수 없는 이름은 허용하지 않으며 포켓몬의 기술이나 저장 형식은 변경하지 않는다.

구역 19 가시덤불, 미션 22 얼음 다리, 미션 20 메가결정을 격리 API에서 영문 기술·잘못된 속성·변화 기술·기절·재접속으로 확인했다. 같은 판정을 사용하는 다른 필드 경로도 동일한 기술 데이터를 이용하며, 실제 운영 기기에서는 검증하지 않았다.
