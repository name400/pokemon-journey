# 구역 16 높은 정원의 분수

[Poképédia](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_16)는 블루 광장의 플라제스 분수 뒤와 우두머리 전룡 옆에 기술머신 076이 있다고 설명한다. [구역 안내](https://allthings.how/every-pokemon-in-wild-zone-16-in-pokemon-legends-z-a-and-how-to-catch-them/)는 전룡이 높은 정원에 있다고 설명한다. 기존 높은 정원 화면에 분수 수면과 조각상을 추가하고 주변 보도에서 기존 기술머신·전룡과 계단에 접근하도록 했다.

이 자료만으로 분수와 높은 정원의 정확한 높이 관계나 평면을 확정할 수 없다. 수면의 모양·크기·좌표와 조각상 표현은 2D 초안이며, 기존 지상 화면의 분수 표현도 구형 경로 보존을 위해 남긴다. 기존 수령 ID와 전룡 조우 상태를 변경하지 않는다. 새 수면·조각상에 있던 옛 저장 위치는 같은 리비전에서 가까운 통행 칸으로 복원한다.

격리 검사에서 계단·기술머신·전룡 접근, 기존 저장 복원, 중복 수령 방지와 재접속을 확인했다. PC·모바일 화면은 시험 데이터와 대체 외부 이미지를 사용했으며 원작 실기와 운영 환경은 검증하지 않았다.
