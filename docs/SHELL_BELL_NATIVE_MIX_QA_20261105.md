# native 껍질방울과 modifier 혼합

고정 원본 `7c0881255af5cd51992e513ff93c2f71adbe40e0`의 `HitHealModifier`는 총 피해에 중첩 수를 곱하고 8로 나눠 내린 후 최소 1로 계산한다. `PokemonHealPhase`는 그 회복량에 치유 부적 배율을 적용해 다시 내린다. 대타가 받은 피해도 총 피해에 포함된다.

새 도전의 `shellBellRule: source-v3`는 native 슬롯의 껍질방울을 modifier 중첩과 합쳐 최대 4개로 계산하고, 두 경로가 각각 회복하지 않도록 한 번만 발동한다. 대타와 실제 포켓몬에 준 피해를 함께 계산하며 치유 부적은 한 번 적용한다. 이전 v2 및 구형 진행은 기존 동작을 유지하고 전투 스냅샷에 규칙을 보존한다.

실제 턴에서 native 단독과 modifier 1·3개, 치유 부적 유무, 일반·대타·더블 혼합 피해, 상태 기술, 회복봉인, 최대 HP와 다음 턴, 저장 인코딩 및 독립 전투 복구를 검사했다. 도구 이전 중 특수 폼·다단 공격의 모든 조합이나 실계정 플레이는 별도 검증이 필요하다.

후속 경계 검사: 연속 5회 공격의 첫 타격에 집게손톱으로 상대의 native 껍질방울을 가져오는 실제 전투에서, 기존 modifier 0·2개와 치유 부적 2개 각각에 대해 전체 공격 피해로 한 번 회복하고 도구 소유권이 이전되는 것을 확인했다. 전투 스냅샷을 인코딩해 다시 연 뒤 다음 다단 공격의 회복도 확인했다. 이전 집게손톱 더블 복구 테스트에서 스냅샷을 전투 객체에 잘못 대입하던 테스트 자체를 바로잡고 실제로 전투를 재개했다. 이 범위에서는 추가 제품 수정이 필요하지 않았다.

위 후속 검사는 관련 회귀 일반·Worker 각각 140/140 통과했고, 마지막 재개 후 다음 턴을 추가한 집중 검사는 두 환경에서 통과했다. 다른 이전·특수 폼 조합과 실계정 플레이는 남아 있다.

관련 도구·전투·융합·챌린지 회귀는 일반 환경과 Worker 로더 각각 139/139 통과했다. 타입 검사와 프로덕션 빌드도 통과했다. 전체 테스트 스위트는 이번에 실행하지 않았다.
