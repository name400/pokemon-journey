# 진화 가능 안내와 실제 진화 재검사 — 2026-11-18

격리 SQLite API의 합성 유저 저장에서 윤겔라의 연결의끈 진화를 확인했다. 도구가 없을 때 파티 응답의 해당 진화는 `ready=false`이며 직접 진화를 요청해도 409로 거절되고 저장 행은 바뀌지 않았다. 시험용 보상 선택으로 연결의끈을 얻으면 `ready=true`, 진화 도구 확인 단계와 수량 1이 응답에 표시되고 저장 복원 뒤에도 유지됐다. 실제 진화 요청 뒤 후딘으로 변경되고 도구가 한 번 소모됐으며, 재조회·낡은 리비전 요청 거절 및 다른 슬롯·탐험 데이터 보존을 확인했다. 보상은 시험용으로 구성한 것이며 자연 획득 전 과정은 아니다.

별도 격리 엔진 검사 14건에서 날씨·바이옴·원래 성격 및 도구 조건 안내, 교환 파트너 기록과 보상, 수동·자동 진화와 별명·저장 복원을 확인했다. 위 API 경로 1건과 모두 통과했으며 확인한 범위에서 새 결함은 재현되지 않아 게임 코드는 변경하지 않았다. 모든 조건·종, 알림의 실제 브라우저 표현·실기기와 운영 저장은 이번에 검사하지 않았다. Sites에는 배포하지 않았다.
