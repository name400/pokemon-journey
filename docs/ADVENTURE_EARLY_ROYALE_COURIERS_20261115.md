# 초반 로열 배달원

랭크 Y의 Hanna, X의 Romain, W의 Ambre를 공용 경기장에 추가했다. [Y](https://www.serebii.net/legendsz-a/z-aroyale/ranky.shtml)·[X](https://www.serebii.net/legendsz-a/z-aroyale/rankx.shtml)·[W](https://www.serebii.net/legendsz-a/z-aroyale/rankw.shtml) 상대 목록에 기재된 포켓몬·레벨·기술을 사용한다. 승리 포인트는 기존 게임의 각 랭크 임시 규칙이며 배달원의 경기장 좌표도 초안이다.

승리 후 대화하면 랭크 V와 같은 [배달 보상](https://www.serebii.net/legendsz-a/z-aroyale.shtml)을 한 번 추첨하여 가방에서 수령한다. 자료의 확률 합계가 맞지 않아 균등 확률, 방문당 1회 제한은 잠정값이다. 보상이 남아 있으면 다음 방문에서도 먼저 받도록 유지한다. 알 수 없는 배틀 기록 형식은 덮어쓰지 않는다. 기존 저장과 진행 중인 배틀은 변경하지 않는다. 원작 실기·운영 환경은 미검증이다.
