# 존느 11·12번지와 플로랄 거리 이동 예측

`Lagsol.md`의 후속 예측 네 칸 제한을 현재 세 도시 거리의 긴 평지에 적용되는 것으로 확인했다. 존느 11·12번지와 플로랄 거리의 `.`·`,` 타일에만 기존 최대 12칸 버퍼를 허용한다. 출입구·상호작용 타일, 위험 상태, 실내 및 그룹은 기존 제한을 유지한다. 서버의 칸별 충돌·조우 판정과 요청 순서, 저장 방식은 변경하지 않는다.

존느 11번지에서 첫 응답 1,200ms 모의 지연과 약 800ms의 동일한 직진 입력을 사용한 Chromium Canvas 추적에서 기존은 다섯 칸을 416ms까지, 변경 후는 아홉 칸을 816ms까지 순서대로 그렸다. 각 실행에서 Canvas 목표, 전송 순서와 서버 최종 위치가 일치했고 동시 이동 요청은 하나였다. 모의 서버와 대체 이미지를 사용한 결과이며 실제 네트워크·운영 D1·실기기 프레임은 측정하지 않았다.

존느 12번지에서 응답 지연 중 예측과 확인, 플로랄 거리에서 요청 거절 시 원위치 복구를 브라우저로 검사했다. 격리 SQLite API에서 세 지역의 12칸 이동·128보 친밀도·재화 보존·오래된 리비전 거절과 구역 출입 또는 막힌 경계에서의 중단 및 복원을 확인했다. 단위 검사로 세 구역의 그룹·위험·출입 경계 제한을 검사했다. 실제 Sites 병합본, 운영 환경 및 두 탭 경합은 확인하지 않았으며 `testfailed.md`의 기존 복구 실패도 유지한다.
