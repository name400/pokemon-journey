# 야생 구역 6 남쪽의 북부 대로 연결

[구역 6 안내](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_6)는 북부 대로가 구역을 가로지르고 북쪽과 남쪽에 각각 대로 출입구가 있다고 설명한다. 기존 초안은 대로에서 구역 북쪽으로 가는 길만 직접 연결되어 있었다. 구역 6 지상 남쪽과 기존 북부 대로 화면 사이에 왕복 출입구를 추가하고 대로에 접근 포장을 표시했다. 두 대로 화면 출입구의 실제 거리·방향·타일 위치와 도로 너비는 자료에서 측정하지 못한 2D 추정이다.

기존 북쪽 대로 출입, 존느 12번지·운하·지붕 경로와 구역 11 해금 조건은 유지한다. 새 출입구는 기존 차단 경계만 바꾸며 지상의 이전 통행 칸과 저장 형식을 바꾸지 않는다. 구역을 나갈 때 일시적인 야생 출현 기록은 기존 규칙대로 초기화된다.

지도 단위 검사에서 신·구 출입구, 연결 경로, 저장 복원과 기존 존느 12번지 출입을 확인했다. 격리 SQLite API에서 왕복·재접속 및 파티·재화·나사 기록·메인 진행 보존을 확인했다. 원작 실기·운영 D1·실제 Sites 병합본은 검증하지 않았다.
