# 미션 28: 구역 7 서쪽 홀로베이터와 옥상 연결

[원작 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-28-a-rogue-mega-altaria)은 야생 구역 7의 북서쪽 홀로베이터에서 옥상을 돌아 비계를 지나 메가파비코리에게 가는 경로를 설명한다. 기존 구역 7 서쪽 홀로베이터의 옥상과 기존 로즈 4번지의 미션 28 옥상·비계 경로를 양방향으로 연결했다. 구역 7의 랭크 F 진입 제한은 역방향에서도 유지한다.

화면 간 접점과 옥상의 크기, 실제 연결 방향·고도는 추정한 2D 초안이다. 기존 옥상 내부의 이전 지름길과 지상 표식은 이전 저장과 진행을 위해 유지하므로, 이 경로가 원작의 유일한 경로라고 주장하지 않는다. 원작의 상세 건물 배치와 실시간 동료·보스 기믹은 미완성이다.
