# 미션 11 남쪽 물가

[미션 11 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-11-a-rogue-mega-slowbro)은 베르날 포켓몬센터 남쪽을 지나 물가에 동쪽 계단으로 내려가 동료와 메가야도란을 만나는 경로를 설명한다. 기존 베르날 거리에서 계단으로 내려가는 별도 물가 지도를 연결하고 기존 턴제 전투와 야도란나이트 보상을 사용할 수 있게 했다. 이전 저장을 위해 거리의 임시 전투 지점도 유지한다.

정확한 계단 좌표, 수변 윤곽과 높이는 2D 초안이다. 원작의 실시간 전투와 동료 동시 전투는 구현하지 않았다. 물가 패배 후 거리로 복귀해 재도전하며 다른 거리 저장과 옥상 경로는 유지한다.
