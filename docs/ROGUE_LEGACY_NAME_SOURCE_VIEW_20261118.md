# 종 ID가 확인되는 구형 별명 표시

기본 종명·별명 필드가 없는 구형 개체도 저장된 이름과 종 ID를 가질 수 있다. `고라파덕`의 종 ID와 실제 포켓몬 ID가 남은 개체의 저장 이름이 `별명 · Normal`인 경우, 파티·상점·보상에서 이전 표시 로직이 접미사를 폼으로 오인해 `별명`으로 표시하는 문제를 격리 재현했다.

명시적인 원본 종 ID와 실제 포켓몬 ID가 같은 원본 종을 가리키고, 존재하는 종별 ID도 모순되지 않는 비융합 개체에 한해 화면 DTO에 종명을 보완한다. 실제 저장 이름이나 원본 데이터는 바꾸지 않는다. 종 ID가 없거나 불일치하는 개체, 융합 개체와 명시적 별명·기본 종명이 있는 개체는 이 보완을 적용하지 않는다. 종명과 동일한 별명인지 판별할 수 없는 경우 등은 별도다.

파티·상점·보상 DTO, 실제 회복·보상 선택 및 저장 복원, 모순된 식별자와 다른 모드 보존을 포함한 대표 검사 14건이 통과했다. 소유권을 확인한 독립 fixture 서버의 Chromium 390×844·1280×800에서 파티·회복·보상에 전체 별명이 보이고 선택 대상과 재조회 후 저장 이름이 보존되는 것을 확인했다. 실제 모바일 기기·모든 구형 데이터와 융합 별명은 미검증이다. Sites에는 배포하지 않았다.
