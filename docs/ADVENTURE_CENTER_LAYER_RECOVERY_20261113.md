# 센터 간 빠른 이동의 도착 높이층

센터에서 센터로 이동하는 기존 `fastTravel-*` 경로는 목적지의 오래된 높이층 플래그를 그대로 뒀다. 합성한 구형 상태에서 블르 7 옥상, 아이믈리스 공원 아래층 또는 구역 3 옥상 플래그가 남아 있으면 센터 좌표가 벽이 되어 사방으로 이동할 수 없었다. 이 상태가 현재 일반 플레이에서 만들어지는지는 재현하지 못했다.

이동 전 지도 이동·택시와 같은 목적지 지상층 플래그를 적용한 상태로 실제 센터 타일을 확인한다. 검증이 성공하면 목적지의 높이층만 정리하고 도착한다. 도착 타일이 센터가 아니면 오류를 반환하며 기존 상태를 변경하지 않는다. 목적지 외의 높이층, 파티·보유 개체·재화·등록 지점은 이 변경으로 초기화하지 않는다.

격리된 실제 월드 API와 SQLite에서 세 플래그가 남은 저장을 각각 불러와 센터 간 이동, 저장 재접속과 한 칸 걷기를 확인했다. 파티·개체 데이터와 재화도 비교했다. 실제 운영 DB·기기는 검사하지 않았다. 원작의 지형 재현이나 이동 지연 성능 개선을 의미하지 않는다.
