# 2026-11-05 PP0 기술 카드가 사라지는 문제

사용자는 첫 라이벌 전투의 Lv9 염버니에서 신속이 사라지고 몸통박치기·전광석화·불꽃세례 세 개만 보인다고 보고했으며, 후속으로 **PP가0이 되면 보이지 않는다**고 확인했다. 운영 저장·Sites는 변경하지 않았다.

## 재현과 수정

실제 Lv9 염버니에 위 네 기술을 넣고 신속을5번 사용하면서 매번 저장 codec으로 복구했다. 파티의 `moves`에는 네 기술이 그대로 있고 `pp.extremespeed`만0인데, `classicCombatView`의 실행 가능한 `moves`에는 나머지 세 기술만 남았다. `actorRequest`가 PP0와 disabled 기술을 제거한 목록을 화면에도 사용한 것이 원인이다. 기술이 저장에서 삭제되거나 진화/성장으로 신속을 잃는 경로는 이번 재현에서 확인되지 않았다.

실행 가능한 `moves`는 유지하고 화면용 `displayMoves`를 추가했다. 화면용 기술에는 원래 slot·이름·PP·설명과 disabled/disabledReason을 포함한다. PP0은 `PP가 없습니다.`, 다른 사용 불가 상태는 `지금 사용할 수 없습니다.`로 구분한다. 새 배열은 서버 명령 허용 범위를 넓히지 않는다. 마자용 미니게임의 교체 기술 금지도 두 배열에 함께 반영한다.

native 요청이 모든 기술을 발버둥 하나로 대체하는 경우에는 기존 네 기술을 비활성 카드로 유지하고 발버둥을 추가한다. 기존 API의 발버둥 fallback 이름도 실제 한국어 이름과 맞췄다. PP를 임의 보충하거나 기존 기술을 추가하지 않는다.

BattlePanel 연결은 별도 UI 작업자가 담당한다. 기술 목록과1–4키가 `displayMoves ?? moves`를 사용하며 비활성 카드의 i 설명 버튼은 계속 사용할 수 있다. 다섯 번째 발버둥은 클릭/초점으로 선택하고 기존 네 단축키 자리를 옮기지 않는다. 실제 브라우저 검증은 통합 UI 기록을 따른다.

## 검사와 한계

`tests/rogue-unavailable-moves.test.mjs` 신규4개는 신속5회 소모와 codec/Lv9 표시, 성장 후 기술·PP 보존, 모든PP0의 발버둥 실제 사용, 실제 사슬묶기의 disabled 표시·명령 거부, PP회복 후 연속 야생 전투에서 같은4번 카드와 사용 가능 상태 복구를 검사한다. PP0의 서버 명령 거부는 파티와 저장 입력을 변경하지 않는다.

API9·테라8·PP표시4·기존다이맥스/Z기술2를 묶은 집중검사는 최종 표준/Worker 각각23개다. 결과는 `/tmp/astra-final-focused.log`, `/tmp/astra-final-worker-focused.log`, 변경 린트는 `/tmp/astra-final-lint.log`에 기록한다. 통합 전체 검사·타입·빌드와 UI 브라우저 결과는 부모 작업자의 최종 기록을 따른다.

이 수정은 사용자가 확인한 PP0 표시 결함을 해결한다. 임의의 기술 삭제 사건 전부나 실제 계정의 긴 진행 이력을 검증했다는 뜻은 아니다. 운영409·PC지속끊김의 원인 확정과도 별개다.
