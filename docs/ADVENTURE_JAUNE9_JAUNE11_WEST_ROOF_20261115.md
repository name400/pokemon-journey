# 존느 9번지와 11번지 서쪽 옥상

[존느 11번지 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-11.html)는 서쪽 작은 건물 옥상과 동쪽 난간에 각각 만병통치약과 큰진주가 있으며 존느 9번지의 큰 건물 쪽에서 접근한다고 설명한다. [9번지 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-9.html)는 두 번지의 인접 관계와 동쪽 건물 단지의 비계를 기재한다. 두 자료는 2차 자료이며 실제 기기에서 확인하지 않았다.

기존 9번지 비계 동쪽 플랫폼에서 별도의 11번지 작은 건물 옥상으로 왕복하는 길을 연결하고 동쪽 난간을 다른 바닥으로 구분했다. **기존 비계와 원작의 큰 건물이 정확히 어떻게 이어지는지는 확인되지 않았으므로 이 연결, 높이 차이, 통행로와 타일 좌표는 2D 추정이다.** 11번지 남쪽 나사 건물이나 실제 3D 구조와 동일하다고 주장하지 않는다. 기존 나사·활공·저장 좌표를 유지한다.

격리 API에서 실제 활공·왕복 이동과 재접속, 두 도구, 가방 한도·중복 요청, 구형 및 미확인 기록과 파티 보존을 검사했다. 기존 나사 지도 검사도 통과했다. 운영 D1·Sites 병합본·원작 실기는 확인하지 않았다.
