# 미션 35 연구소의 필드 포획

[공식 모험 안내](https://legends.pokemon.com/en-us/news/adventure)는 야생 포켓몬에게 볼을 조준해 던지고, 필요하면 배틀로 약화해 포획한다고 설명한다. 연구소에서도 현재 인접해 바라보는 야생 개체에 볼을 고르고 직접 던질 수 있도록 기존 필드 포획 처리에 연결했다. 실패하면 같은 개체와 배틀하며 기존 연구소 조우·우두머리 보정과 고유 기술을 사용한다.

포획 시 볼 차감과 연구소 개체 소진·도감·보유함 기록을 기존 저장 트랜잭션에서 처리한다. 도주 후에는 기존 개체의 우두머리·이로치가 유지된다. 존재하지 않는 개체, 다른 방향, 전투나 유니온 중 또는 알 수 없는 수령 기록은 거절한다. 조준 거리는 기존 게임의 인접 칸 규칙이며 원작의 실제 거리·투사체 동작은 아니다.

격리 API에서 이로치 우두머리의 포획 실패·배틀·도주·마스터볼 포획, 고정 아보크 포획, 색·기술·소진·중복 요청과 미확인 저장 및 기존 파티 보존을 확인했다. 실제 원작 기기·운영 D1·Sites 병합본과 브라우저 화면은 검사하지 않았다.
