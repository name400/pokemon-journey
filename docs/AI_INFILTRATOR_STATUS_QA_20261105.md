# AI의 틈새포착과 대타 상태 기술

고정 원본 `7c0881255af5cd51992e513ff93c2f71adbe40e0`의 `Move.hitsSubstitute`는 틈새포착 특성을 가진 사용자의 기술이 대타를 뚫도록 처리한다. 기존 AI의 혼란·씨뿌리기 등 휘발 상태 기술 점수는 이 경우에도 대타가 있으면 효과가 없는 것으로 취급했다.

새 도전의 `enemyAiStatusRule: source-v1`에서 틈새포착이 활성화된 적은 대타 뒤의 상대를 대상으로 해당 기술을 유효하게 평가한다. 특성이 억제됐거나 대상이 해당 효과에 면역이면 기존 면역 검사를 유지한다. 과거 도전은 이전 AI 규칙을 유지하고 전투 스냅샷에 규칙을 보존한다.

실제 전투에서 틈새포착의 혼란광선·씨뿌리기 선택 및 상태 적용, 마이페이스·풀 타입 면역, 화학변화가스에 의한 특성 억제, 패시브 틈새포착, 저장 복구를 검사했다. 프로젝트의 상태 기술 점수 자체는 여전히 휴리스틱이며 원본의 모든 기술 점수·대상 선택·교체·난수 동등성을 의미하지 않는다.

더블 전투에서 대타 뒤의 유효 대상과 마이페이스 면역 대상이 함께 있을 때 유효 대상을 선택하는 격리 사례도 검사했다. 이는 원본의 가중 대상 추첨 전체가 구현됐다는 뜻은 아니다.

더블 사례 추가 전 관련 트레이너·AI·챌린지·융합 회귀는 일반 환경과 Worker 각각 245/245 통과했다. 추가 후 집중 검사는 양 환경에서 각각 9/9, 타입 검사와 프로덕션 빌드도 통과했다. 전체 테스트 스위트와 실계정 플레이는 실행하지 않았다.
