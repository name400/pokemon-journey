# 도시 야생 개체의 직접 포획

[공식 안내](https://legends.pokemon.com/en-us/news/adventure)는 야생 구역 밖 미르시티에서도 야생 포켓몬을 향해 볼을 던져 잡을 수 있다고 설명한다. 기존 도시·하수도 야생 개체 여덟 종류는 필드에 표시되어도 대화 후 배틀만 가능했다. 인접해 마주 보는 개체의 상호작용에 기본 볼 투척을 추가했다. 원작의 자유 조준·투척 궤도·은신·개체별 도주는 아직 구현하지 않았으며 이 경로에는 확인되지 않은 뒤쪽·미발견 보너스를 주지 않는다.

서버는 실제 위치·방향·층·날씨·시간과 전투 상태를 확인한다. 기존 필드 이로치 기록을 사용하며 성공 시 도감·포획 연구와 볼 소비를 같은 리비전 저장으로 반영한다. 볼에서 나오면 같은 색의 상대와 기존 턴제 전투가 시작되며 도주 후에도 색을 유지한다. 볼이 없거나 오래된 요청은 기존 저장을 바꾸지 않는다. 구형 클라이언트의 배틀 선택과 보유 포켓몬은 그대로 유지한다.

격리 SQLite API에서 인접 조건·볼 부족·중복 요청, 이로치 직접 포획, 실패 후 전투·재접속·도주를 검사했다. PC·모바일 Chromium에서는 모의 API와 대체 이미지로 상호작용·새로고침을 확인했다. 이동 처리나 지도 충돌을 수정하지 않았으며 원작 기기·운영 D1은 검증하지 않았다.

## 희귀 볼 자동 선택 방지

필드에서 선택한 볼이 없으면 기존에는 보유 목록의 첫 볼로 자동 전환해, 일반 볼을 다 쓴 뒤 마스터볼이나 희귀 볼이 의도치 않게 선택될 수 있었다. 이제 자동 전환은 일반 판매 볼로 제한한다. 희귀 볼만 남았다면 투척 버튼은 비활성이며, 플레이어가 해당 볼을 직접 선택하면 기존 포획을 사용할 수 있다. 서버의 재고·포획 확률이나 전투 중 볼 선택은 바꾸지 않는다.

선택 규칙 단위 검사와 PC·모바일 Chromium의 모의 API 검사에서 마스터볼 직접 선택 전 투척 차단, 직접 선택 후 사용, 일반 볼 자동 전환 및 새로고침을 확인했다. 원작 기기와 운영 환경은 확인하지 않았다.
