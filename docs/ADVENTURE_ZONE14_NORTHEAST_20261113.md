# 구역 14 북동쪽 바위 구역

[Poképédia의 구역 14 설명](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_14)은 변전소의 바위로 막힌 길과 북동쪽 바위 뒤의 리보플라빈·금구슬을 설명한다. 기존 건물 북쪽과 동쪽의 접근을 바위로 둘러싸고 기존 격투·땅·바위 공격 기술의 바위 제거를 연결했다. 바위는 기존 남쪽 구역과 같은 개별 제거 목록을 사용하고 두 도구는 독립적으로 한 번씩 수령한다.

바위 개수·좌표, 건물과 설비의 정확한 크기 및 2D 접근 방향은 원작 자료에서 측정하지 못한 초안이다. 원작 설명의 주 출입은 북쪽 하나이지만, 기존 저장과 이동을 위해 게임에 있던 나머지 출입도 유지한다. 기존 일괄 바위 제거 저장은 계속 열린 상태이고, 새 바위에 겹친 이전 위치는 같은 리비전에서 인접 통행 칸으로 복원한다.

격리 검사에서 북동쪽 접근 차단·개별 바위 제거·구형 위치 복원, 도구 한도와 중복 수령 방지·재접속을 확인했다. PC·모바일 화면에는 시험 데이터와 대체 외부 이미지를 사용했으며 원작 실기와 운영 환경은 검증하지 않았다.
