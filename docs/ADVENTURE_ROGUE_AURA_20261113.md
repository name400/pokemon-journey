# 폭주 메가 상대의 일반 기술 피해

[Bulbapedia](https://bulbapedia.bulbagarden.net/wiki/Plus_Move)는 폭주 메가포켓몬에게 일반 기술 피해가 70% 감소한다고 설명하고, [Smogon의 계산 연구](https://www.smogon.com/forums/threads/legends-z-a-mechanics-research.3772579/page-4)도 일반 기술에 30% 배율을 보고한다. 본 구현은 기존 턴제 피해 계산에 약 0.3배를 적용한다. 플러스 기술과 메가진화 공격은 감소시키지 않는다. 계산 순서와 반올림은 기존 시뮬레이터를 따른다.

메가링을 가진 플레이어가 새로 시작한 미션 11~13·16~18·21~23·27~29·32~34 폭주 사건, 미션 36·37 방어전, 미션 41 및 폭주 재대결 시뮬레이터의 적을 전투별 식별자로 지정한다. 일반 메가진화와 지정되지 않은 적, 메가링이 없는 이전 저장, 이미 진행 중인 전투에는 적용하지 않는다. 본래 공격 피해 계산의 ModifyDamage 경로를 사용하므로 고정 피해·잔여 피해와 4배 이상 상성의 별도 원작 보정은 구현하지 않았다.

대표 격리 검사에서 레벨 45 치코리타와 실제 미션 11 동료가 숙달된 잎날가르기로 승리했다. 동일 난수·같은 단순 전략으로 레벨 30과 40은 적용 전후 모두 패배했으며, 전체 레벨·파티·아이템의 난이도는 검증하지 않았다. 실제 API의 새 미션 11 진입·재접속·승리·보상 중복 거절은 격리 데이터로 검사했다. 세부 원작 AI·실시간 회피 및 실제 운영 D1은 검증하지 않았다.
