# 존느 7번지 대로 연결

[존느 7번지 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-7.html)는 서쪽 이베르날 애비뉴와 북쪽·동쪽 큰길 접근을 설명하며 [이베르날 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/hibernal-avenue.html)도 7번지 접점을 명시한다. 기존 막힌 화면 경계에 두 대로로 통하는 왕복 출구를 추가했다. 정확한 출구 좌표와 거리 형태는 기존 2D 맵에 맞춘 추정이다.

기존 출입과 저장 형식, 야생 구역 15의 별도 랭크 제한을 유지한다. 두 대로 왕복, 기존 8번지 출구, 구역 15 잠금 및 저장 복원과 모의 API PC·모바일 화면을 검사했다. 실제 운영이나 Sites 병합본은 확인하지 않았다. 모바일 D1 이동 오류 기록은 운영 재검증 전까지 유지한다.
