# 후파 항아리와 이차원러시

고정 원본의 항아리로 후파의 굴레를 벗어난 폼을 얻고 해제하는 기존 도구 상태를 융합에 연결했다. 원본과 native의 능력치 6항목이 일치할 때만 허용한다. 기존 저장 수동 활성화와 새 저장 독립 활성 상태, 다른 슬롯 및 파티의 도구를 보존한다.

원본은 이차원러시의 사용자 종을 제한하지 않는다. native가 후파 언바운드만 허용하던 제한을 source-subset-v2 전투의 로컬 기술 객체에서만 해제한다. 공유 Dex 및 기존 규칙은 그대로다. 기술의 기존 방어 무시·자신 방어 하락 효과는 유지한다.

실제 보상, 활성/해제, 융합 두 역할, 전투 턴·codec·분리, 도구와 기존 저장을 검사했다. 후파가 아닌 뮤의 실제 기술 사용과 기존 규칙의 제한 유지, 공유 native 기술 불변도 검사했다. 관련 일반/Worker 각 38/38, 타입·production 빌드 통과. 실제 기기·운영과 원본 모든 기술 효과의 동등성은 검증하지 않았다. 로그 `/tmp/hoopa-final.log`, `/tmp/hoopa-worker.log`, `/tmp/hoopa-type.log`, `/tmp/hoopa-build.log`.
