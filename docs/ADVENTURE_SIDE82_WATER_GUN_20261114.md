# 사이드 미션 82: 완철포의 물대포

미션 26의 폭주 사건이 나타난 뒤 존느 8번지 옥상에서 Nett에게 의뢰를 받아 선두 포켓몬의 물대포로 옆 오염물을 씻을 수 있다. 물대포를 아는 살아 있는 포켓몬을 요구하며 다른 물 기술은 허용하지 않는다. 오염물을 치우면 1,500원·진주 3개·큰진주를 한 번 받는다. 가방 한도와 리비전으로 보상 중복을 막고 기술·포켓몬을 소모하지 않는다. 구형 저장의 보상과 진행은 추정하지 않는다.

[원작 의뢰](https://www.serebii.net/legendsz-a/sidemissions/clauncherlaunchingwatergun.shtml)와 [위치·보상 공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-082-clauncher-launching-water-gun)은 Nett의 완철포에게 시범을 보이도록 플레이어의 포켓몬이 물대포를 쓰는 흐름을 설명한다. 다른 자료는 완철포 보유를 요구한다고 기재하므로 실기 확인은 남았다. NPC와 오염물은 기존 옥상의 막힌 타일에 놓은 2D 초안이며 발사 거리·실시간 조준은 인접 상호작용으로 근사했다. 기존 진입·복귀와 나사 배치는 유지한다.

격리 API에서 해금, 기존 입구를 통한 실제 이동·복귀, 다른 물 기술 거절·물대포 사용·제거, 재접속·중복 요청, 가방 한도와 파티·기술·이로치 보존을 확인했다. 원작 실기·운영 D1·Sites 병합본은 확인하지 않았다.
