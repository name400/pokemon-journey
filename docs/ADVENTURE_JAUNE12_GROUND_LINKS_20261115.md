# 존느 12번지 지상 접근

[존느 12번지 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-12.html)는 서쪽 존느 9번지와 남쪽 세존 운하변의 연결을 설명한다. 기존 막힌 화면 경계에 9↔12↔운하변 왕복 출구를 추가했다. 정확한 접점과 타일 좌표는 기존 2D 맵에 맞춘 추정이다.

기존 10번지·야생 구역 6 출입, 구역 11의 해금 조건과 저장 형식을 유지한다. 새 경로와 기존 출입·잠금·저장 복원, 모의 API PC·모바일 화면을 검사했다. 이는 운영이나 Sites 병합본 검증이 아니다. `testfailed.md`의 모바일 D1 오류와 `ac57e03f` 배포 검사 실패 16건은 실제 재검증 전이므로 유지한다.
