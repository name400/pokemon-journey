# 5번 구역 남동쪽 옥상 사다리

[구역 안내](https://www.nintendolife.com/guides/pokemon-legends-z-a-wild-zone-5-guide-all-pokemon-and-alphas)는 지하 수로와 휠구 근처 사다리에서 동남쪽 옥상으로 갈 수 있다고 설명한다. [사다리 안내](https://game8.co/games/Pokemon-Legends-Z-A/archives/557826)의 검색 결과에는 첫 사다리 위에서 두 번째 사다리를 타고 옥상에 간다고 나온다. 해당 페이지 본문은 이 환경에서 열리지 않아 정밀 배치는 직접 확인하지 못했다.

기존 지하 휠구 구역의 사다리와 옥상 사이에 별도 중간 발판을 두고 두 사다리와 왕복 이동을 연결했다. 오염물 해금과 기존 지상·지하·옥상 좌표, 야생 개체 및 수집 이력은 유지한다. 기존 옥상 저장은 전에 이용하던 직접 지하 복귀를 그대로 허용한다. 새 경로에서 옥상에 도착한 경우 같은 발판을 거쳐 내려간다. 빠른 이동으로 이탈하면 임시 층 표시가 남지 않는다.

발판의 타일 크기와 좌표, 사다리의 화면상 방향은 2D 초안이며 원작의 정확한 형태나 축척이 아니다. 실제 Sites 및 운영 기기에서 검증하지 않았다.
