# 사이드 미션 13: 분수의 가시덤불

[Serebii](https://www.serebii.net/legendsz-a/sidemissions/stumpedatthefountain.shtml)와 [Bulbapedia 공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_1-20)을 대조해 미션 7 이후 존느 7번지 Croquis의 의뢰를 받고 가시덤불을 한 번, 세 번, 다섯 번 제거한 뒤 나목령의 이야기를 확인한다. 선두 포켓몬이 적합한 불꽃·베기 기술을 알아야 한다. 나목령은 선물이나 포획 대상으로 만들지 않았다.

분수·의뢰인·덤불 좌표와 그림은 간략한 2D 초안이다. 덤불은 원래 통행할 수 없던 칸에만 표시하고 제거 후에도 원래 충돌을 유지하므로 저장 위치나 기존 도로를 막지 않는다. 원작의 정확한 분수 및 덤불 배치는 검증하지 못했다.

완료 보상은 1,000원과 네스트볼 3개이며 가방이 가득 차면 남은 볼을 맡겨 둘 수 있다. 상태와 보상은 리비전으로 중복 수령을 막고 알 수 없는 미래 형식은 그대로 보존한다. 격리 SQLite API에서 세 단계 제거, 부적합한 기술 거절, 중복 요청·재접속, 가방 한도와 기존 선두 보존을 확인했다. 실제 기기·운영 D1·Sites 병합본은 확인하지 않았다.
