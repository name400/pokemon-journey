# 대기 파티원의 상태이상 표시

가방의 만병통치약·미르갈레트는 살아 있는 상태이상 파티원을 선택한다. 그러나 일반 조회와 이동 응답의 대기 파티원 요약에는 상태가 없어 선두 외 포켓몬을 대상으로 선택할 수 없었다. [원작 도구 목록](https://www.serebii.net/legendsz-a/items.shtml)은 두 도구의 상태이상 치료 효과를 설명한다.

기존 저장을 변경하지 않고 현재 파티에 속한 요약 개체에만 상태 필드를 포함한다. 파티 밖 보관함은 기존 요약을 유지하고 이동 계산·요청 순서는 변경하지 않는다. 이동 응답에는 대기 파티원 최대 다섯 개의 짧은 상태 값이 추가된다.

격리 SQLite API에서 일반 조회·이동 후 상태 표시, 두 도구의 사용 및 재접속, 보관함 개체와 중복 요청 거부, 단일·다수 전투 회귀를 확인했다. 실제 브라우저, 운영 D1과 Sites 병합본은 검증하지 않았다.
