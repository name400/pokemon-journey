# Ice Spinner terrain and Substitute — 2026-11-18

The pinned source gives Ice Spinner a target `ClearTerrainAttr`, and target effects are skipped while the move hits a Substitute: [move](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/data/moves/move.ts#L11785), [attribute](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/data/moves/move.ts#L3370), [target-effect check](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/phases/move-effect-phase.ts#L535). A pre-fix isolated battle reproduced Electric Terrain being removed by a hit absorbed by a Substitute.

New games carry `iceSpinnerSubTerrainRule: source-v1` into combat. The native substitute-damage terrain callback is suppressed only during each ordinary Ice Spinner hit and restored afterward. Direct hits still clear terrain, including when direct or passive Infiltrator bypasses a Substitute. If Multi Lens breaks a Substitute, a later direct hit clears terrain. Battles from older runs without the rule retain prior behavior.

Isolated engine tests cover single and double battles, both sides, four terrains, a broken and surviving Substitute, ordinary and passive Infiltrator, suppressed ability, Multi Lens, Protect, Wonder Guard, no terrain, actual command and PP, encoded save/restore and legacy saves. Two explicitly injected Substitute HP values were used to exercise break/survival paths. The eleven-file related suite passed 115 tests. Browser, real devices, source runtime comparison and every ability or item combination were not checked. No live server or user data was used.
