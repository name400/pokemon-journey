## 필수: 진행과 데이터

1. 운영 409·PC 끊김의 실제 원인은 미확정. 새 오류의 번호·시각·행동과 안전한 로그/해당 구간 성능 기록으로 재현하고 수정 후 배포 버전을 사용자가 검증한다. 이미 사라진 오류의 원인을 추정해 완료 처리하지 않는다.
2. 중복 기술 복구의 불일치·출처 불명 기록은 자동 삭제하지 않는다. 새로 안전하게 판별 가능한 실제 사례가 확인되면 원본 백업·명시적 선택·revision 충돌 검사를 유지해 공통 복구 경로를 확장한다. 자료가 없어 판별 불가능한 저장은 안전상 보류이며 지워야 할 작업이 아니다.
3. 융합·폼·도구·이벤트는 실제 획득 가능한 조합에서 파티·소지품·기술 보존, 전투, 저장 복구, 분리/종료의 누락부터 처리한다. 사용 가능성과 미연결 폼을 먼저 판별하고 원본의 보스 전용·비활성 조건은 유지한다. 불명확한 도구 기록을 추측해 이전하지 않는다.

## 필수: 여러 기술에 영향을 주는 전투 공통 경로

1. 일격기 네 종류는 원본의 레벨별 명중률과 보스 상대 위력 250 일반 피해를 신규 도전에 공통 적용했다. 대표 보스 분할 HP·옹골참·얼음 면역·저장 복원과 기존 저장 보존을 확인했다. 보스를 일반 피해로 쓰러뜨릴 때 잘못 표시되던 일격사 로그를 제거했고, 대표 멀티렌즈 연타·다이맥스 기술과 저장 복원을 확인했다. 다른 특수 판정 조합의 원본 동등성은 별도다.
2. 전체 공격은 신규 도전의 멀티렌즈 없는 일반 더블 전투에서도 부가 효과가 없는 15개 기술의 대상별 피해를 순차 처리한다. 앞 대상의 실제 기절을 다음 대상의 분산 피해 판정에 반영하며, 방어·기합의머리띠 생존·면역·아군이 남은 경우 및 저장 복원을 대표 검사했다. 별도로 멀티렌즈 첫 피해 연결이 있다. 후속 신규 규칙은 상태 이상·능력치 하락이 붙은 검토된 16개 기술의 대상별 부가 효과를 다음 대상 피해 전에 처리한다. 멀티렌즈의 후속 타격도 같은 순서로 처리하고 이미 기절한 대상을 건너뛰며, 남은 대상의 연타는 유지한다. 일반/멀티렌즈와 방어·클리어바디·대타·저장 복원을 대표 검사했다. 후속 흡수 공통 규칙은 확인된 피해 흡수 13종의 실제 피해별 회복량을 원본처럼 내림하며 생생버블은 실제 피해의 전부를 회복한다. 초과 피해·대타·멀티렌즈·전체 공격·해감액·치유 부적·상대·저장 복원을 대표 검사했다. **남음:** 흡수·사용자 효과·다른 복합 효과의 대상별 적용 시점, 검토 범위 밖 후속 타격과 원본 난수 흐름은 미완료이며 검토된 기술만으로 전체 공격이 완성된 것은 아니다.
3. AI는 기본 행동을 제공하지만 원본과 점수·대상 후보·교체·난수 흐름이 부분적으로 다르다. 특정 기술의 희귀 조합보다 여러 기술에 공통인 효과 점수와 실제 진행에 영향을 주는 선택 오류를 우선한다. PRNG·시드 완전 동등성은 별도 범위다.
