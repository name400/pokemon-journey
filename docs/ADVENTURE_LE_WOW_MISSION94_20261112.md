# Restaurant Le Wow: Side Mission 94

[Original mission](https://www.serebii.net/legendsz-a/sidemissions/fullcourseofbattles:threestars.shtml) starts with main mission 31 and uses ten trainer battles without healing between them. The first course is free; the ten teams, levels and listed moves use that source. The first clear awards 2,000 coins, TM045 Knock Off, five HP Up and five Carbos; [mission listing](https://pokemondb.net/pokebase/435127/what-are-all-the-side-missions-in-legends-z-a). TM compatibility is restricted to verified base forms from [Knock Off TM045](https://www.serebii.net/attackdex-sv/knockoff.shtml).

After the first clear a retry costs 100,000 coins. A successful retry pays 4,000 per course, and its reward claim gives ten Pearl Strings and ten Exp. Candy L, as described by [restaurant rewards](https://game8.co/games/Pokemon-Legends-Z-A/archives/559507) and [rematch guide](https://game8.co/games/Pokemon-Legends-Z-A/archives/560911). The 4,000 per-course split is an implementation assumption for the reported 40,000 total. An abandoned or lost run does not refund its fee; the player may start again. Rewards remain pending until claimed.

The existing single-active turn-based engine substitutes sequential fights for Z-A's real-time encounters. Plus moves are not represented. Trainer prize money on the first free course is not modeled beyond the mission reward. Exact restaurant interior and entrance coordinates remain provisional. Pearl Strings can be sold at the field shop; see [treasure sales](ADVENTURE_TREASURE_SALES_20261112.md). Tests use an in-memory database and do not cover production devices.

The representative automated ten-course test resets its strong test party between battles to avoid stochastic battle losses; the server separately rejects the player's between-course healing and party changes. It also checks a paid retry's first and final course using a seeded saved course state, rather than replaying all ten paid battles in the test.

The ten trainers now hold the items listed in the [original course data](https://www.serebii.net/legendsz-a/sidemissions/fullcourseofbattles:threestars.shtml). In the tenth course Tyranitar holds Tyranitarite and the existing opponent AI can Mega Evolve it on a legal turn. These items use the existing turn-based simulator rules, which may differ from Z-A’s real-time effects; Plus moves and simultaneous combat remain unimplemented. Already-started battle snapshots retain their old teams and items; subsequent new courses use the new teams. Representative isolated tests cover item effects, Mega Evolution, saved course restoration, rewards and legacy snapshots, not production or original hardware.
