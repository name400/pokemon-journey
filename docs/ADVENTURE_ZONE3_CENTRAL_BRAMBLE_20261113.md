# 구역 3 중앙 정원 가시덤불

[구역 3 안내](https://www.pokemon-france.com/en/guides/pokemon-legends-z-a/wild-zones/)는 루주 광장 중앙의 가시덤불에 맥스업이 있다고 설명한다. 기존 네 정원, 탑과 조각상 사이에 이를 추가했다. 불꽃·비행 공격 기술로 치우는 조작은 기존 탐험 모험의 가시덤불 규칙을 사용한다. [원작 장애물 안내](https://www.thegamer.com/pokemon-legends-z-a-obstacles-city-break-cut-thorns-rocks-how-to/)에서 불꽃 기술을 확인할 수 있으나, 모든 기술별 파괴 조건을 이 변경으로 재현하지는 않았다.

덤불의 정확한 좌표와 2D 크기는 초안이다. 중앙 플라베베 서식 타일과 기존 네 방향 통로를 유지하며, 새 덤불 칸에 저장된 이전 플레이어는 인접 통행 칸으로 복원한다. 진화, 조우, 기존 아이템과 미션 진행은 이 변경의 대상이 아니다.
