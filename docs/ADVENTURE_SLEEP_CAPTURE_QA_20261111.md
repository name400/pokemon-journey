# 탐험·모험 턴제 잠듦과 포획

공통 턴제 엔진은 잠든 포켓몬을 `잠듦` 또는 `slp`로 저장한다. 기존 Z-A 포획식은 `졸음`/`drowsy`와 얼음만 1.5배로 처리해 전투 중 잠재운 포켓몬의 포획률이 정상 상태와 같았다. 이제 잠듦 두 표기에도 1.5배를 적용한다. Z-A 원작은 졸음·얼음에 1.5배를 적용한다([포획식 자료](https://bulbapedia.bulbagarden.net/wiki/Capture_rate)); 이 앱은 사용자의 턴제 배틀 지시에 따라 잠듦을 졸음의 대응 상태로 취급한 구현이다. 포획 기회(catch window)의 별도 보정이 상태 보정보다 우선하는 규칙은 유지한다.

고정 난수로 정상·잠듦·졸음·얼음의 포획 차이, 포획 기회 우선, 실제 턴제 전투 생성과 JSON 저장 복원 뒤 잠듦을 검사한다. 기존 데이터 구조와 볼 소비·다른 상태 보정은 변경하지 않았다. 실제 운영 계정·모바일 기기 검증은 하지 않았다.
