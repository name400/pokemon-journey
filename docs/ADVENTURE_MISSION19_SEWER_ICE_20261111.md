# 미션 19 하수도 얼음 방

[원작 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-19-reaching-rank-d)은 잠긴 문 이후 서쪽·북쪽 분기의 얼음을 공격해 다리를 만들고 기술머신을 얻는 동선을 설명한다. [기술머신 목록](https://www.serebii.net/legendsz-a/tm.shtml)은 해당 기술이 025 깨물어부수기라고 밝힌다. 클레피를 포획한 뒤 기존 하수도 서쪽에서 얼음 방으로 출입하고, 공격 기술로 다리를 만든 뒤 기술머신을 얻을 수 있다. 기존 기술머신 학습 경로와 재사용 규칙을 사용하며 [Z-A 학습 가능 종 자료](https://www.serebii.net/attackdex-sv/crunch.shtml)를 대조했다. 구분이 불확실한 지역 폼 등은 보수적으로 제외한다.

새 방의 윤곽·방향·좌표와 기존 화면과의 접점은 2D 초안이다. 기존 하수도 스토리 좌표는 변경하지 않았고, 현재 얼음과 도구는 기존 지도 표식으로 나타난다. 원작의 주변 추가 구역과 실시간 공격 연출은 아직 구현하지 않았다. 기존 저장은 유지하고 일치하지 않는 구형 저장 리비전에서는 분기 내부 위치만 해제하며 만든 다리와 획득 기록은 보존한다.

격리 테스트에서 이전 하수도·샹델라·환상 벽 흐름, 분기 입출구 및 저장 복원, 공격 기술 요구, 일회성 수령, 호환 포켓몬 학습과 비호환 거부를 확인했다. 실제 운영 계정·기기는 검증하지 않았다.

## 갈림길과 현장 표시

[원작 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-19-reaching-rank-d)에 나온 금구슬과 얼음의돌이 있는 갈림길, 얼음 방의 두 번째 얼음의돌과 맥스업 방을 기존 분기 화면에 연결했다. 각 방과 물건의 2D 좌표는 추정이다. 기존에 막힌 칸을 통로로 열어 기존 저장 위치를 보존하며, 각 물건은 한 번만 받고 가방이 가득 차면 획득 기록을 남기지 않는다.

얼음 분기에 있는 동안 본래 하수도의 샹델라가 잘못 표시되지 않도록 서버 응답에서 해당 현장 표시만 숨긴다. 실제 샹델라 추적 단계는 저장해 두었다가 본래 하수도에 돌아오면 복원한다. 기존 지도 표식과 정밀하지 않은 실시간 연출은 그대로다. 대표 검사에서 네 물건의 수령·중복 방지, 가방 한도, 재접속, 추적 상태 보존 및 미션 19 회귀가 통과했다.


## 하수도 남쪽의 도구

[미션 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-19-reaching-rank-d)은 하수도 남서쪽 고급상처약, 남쪽 중앙 사포닌, 남동쪽 슈퍼볼을 안내한다. 세 도구를 기존 하수도에 한 번씩 획득할 수 있게 추가했다. 기존 2D 하수도에 맞춘 정확한 좌표는 추정이다. 포획 볼은 기존 종류별 99개, 사포닌은 가방 999개, 고급상처약은 기존 지갑 99개 한도와 원자적 저장을 따른다. 한도를 초과하면 획득 기록을 남기지 않는다. 기존 저장에 수령 기록을 추정해 넣지 않으며, 새 표식은 통행 가능한 타일이라 구형 저장 위치와 미션 19의 문·얼음 분기 경로를 보존한다. 사전 미션 57 NPC 표식은 도구가 아닌 사람으로 표시한다. 운영 기기 검증은 하지 않았다.
