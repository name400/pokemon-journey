# 아라모드 카페

[카페 자료](https://bulbapedia.bulbagarden.net/wiki/Caf%C3%A9_Classe)와 [메뉴·가격 목록](https://www.serebii.net/legendsz-a/cafes.shtml)에 맞춰 베르 4번지의 기존 카페 건물에서 여덟 음료를 주문하고 파티를 회복할 수 있다. 기존 카페처럼 선두 친밀도와 연구 활동도 기록한다. 친밀도 증가량은 이 게임의 공통 잠정값이며 정확한 원작 수치는 미확인이다.

[택시 목적지 목록](https://bulbapedia.bulbagarden.net/wiki/Lumi_Cab)에 따라 택시 및 방문 후 지도 이동 지점으로 연결한다. 건물 앞 주문·도착 좌표는 2D 초안이며, 옥상·안뜰에서 별도로 방문 등록되지 않는다. 카페 내부, 사진 촬영과 원작 실기는 재현·검증하지 않았다. 기존 의뢰와 저장된 방문 기록은 유지한다.
