# 포켓로그 전투 파티 키보드 — 2026-11-18

세로 파티 목록의 방향키 처리에 2열 명령창과 같은 위/아래 두 칸 이동이 적용돼 있었다. 격리 Chromium의 싱글·더블 전투에서 첫 행에 초점을 두고 아래 키를 한 번 누르면 둘째 행을 건너뛰어 셋째 행으로 이동하는 것을 재현했다.

파티 목록의 위/아래 키만 인접한 한 행으로 이동하도록 바꾸고, 명령창과 기술창의 기존 격자 이동은 유지한다. 방향키 이동만으로 포켓몬을 선택하거나 전투 명령을 보내지 않는다.

전용 포트와 소유 확인 토큰을 사용하는 격리 fixture 및 Chromium에서 280×568, 390×844, 1280×800의 싱글·더블: 인접 이동·역방향·끝에서 순환·기절 개체·확인 취소·실제 교체 명령·새로고침 저장 유지와 다른 저장/탐험 보존을 검사했다. 명령창의 좌우 방향키도 검사했다. 390×844 강제 교체의 키보드 조작·새로고침을 별도 확인했다. 실제 모바일·스크린리더 및 모든 전투 조합은 미검증이다.

변경 파일 ESLint는 512MiB에서 메모리 부족으로 중단됐다. 1024MiB 재실행 결과 103개 오류·20개 경고였고 동일 파일의 HEAD 원본도 103개 오류·20개 경고다. 린트 통과는 아니다. 포자 일반 판정과 재접속 연출 반복은 미해결로 유지한다. 사용자 데이터와 Sites는 건드리지 않았다.
