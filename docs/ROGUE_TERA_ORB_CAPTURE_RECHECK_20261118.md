# 테라 오브 없는 포획 후 발동 재검사 — 2026-11-18

과거 신고는 오브 없이 고라파덕을 포획한 뒤 다음 야생 전투에서 테라스탈할 수 있었던 실제 결함이다. 당시 원인과 수정 범위는 `TERA_ORB_CAPTURE_ACCESS_QA_20261105.md`에 남아 있다. 현재 개발본의 격리 엔진 검사에서 포획·저장 복원·다음 야생 전투, 파티 교체와 더블 포획, 충전 소모 및 보유 시 정상 발동, 구형 스냅샷과 특수 폼을 재검사했다. 기존 구형 저장 검사와 함께 12건이 통과했고 해당 경로에서 결함은 재현되지 않았다.

추가한 격리 SQLite API 검사에서는 오브가 없지만 충전 표식이 남은 시험 저장으로 더블 야생 전투 중 마스터볼을 사용해 포켓몬을 합류시키고, 재조회 뒤 교체했다. 해당 개체에 테라 명령이 표시되지 않고 직접 발동 요청은 409로 거절됐으며, 요청 전후 저장 행과 다른 슬롯·탐험 데이터가 유지됐다. 이는 오브 없는 포획·합류의 다른 대표 경계이며 기존 엔진의 고라파덕·다음 야생 전투 사례와 구분한다. 보상 오브 획득, 오브 또는 충전 부족 거절, 정상 발동·소모·재조회 API 검사를 포함해 4건이 통과했다.

시험 데이터로 실제 API 핸들러와 격리 SQLite를 사용했으며 운영 데이터나 실제 브라우저·기기, 모든 포켓몬·폼 및 과거 배포본을 확인하지 않았다. 이 표본에 새 결함이 재현되지 않아 게임 코드는 변경하지 않았다. Sites에는 배포하지 않았다.
