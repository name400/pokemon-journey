# 필드에서 파티 회복

[회복 안내](https://www.sportskeeda.com/pokemon/how-heal-pokemon-legends-z-a)는 가방의 회복 도구를 선택한 포켓몬에게 사용할 수 있다고 설명한다. 기존 필드 가방은 선두만 선택할 수 있었으므로 상처약·상태 치료 등 기존 회복 도구의 파티 대상 선택을 추가했다. 서버는 지정된 ID가 현재 파티에 속하는지 확인한다. 예전 요청이 ID를 생략하면 기존 선두를 사용하고, 가방 재고·회복량·기절·상태 제한 및 리비전 조건은 유지한다. 파티 순서와 기존 저장 개체는 변환하지 않는다.

격리 SQLite API에서 대기 파티원의 상처약·해독제 사용과 재접속, 보유함 개체·잘못된 ID·기절·중복 요청 거절과 기존 선두 사용을 검사했다. PC·모바일 Chromium에서는 모의 API로 대상 선택과 재접속을 확인했다. 실제 운영 D1·기기 및 원작의 실시간 전투 화면은 검증하지 않았다. 이동 경로는 수정하지 않았다.
