# 사이드 미션 11: 딱충이 마스터

[상대 자료](https://www.serebii.net/legendsz-a/sidemissions/thekakunamaster.shtml)와 [의뢰 공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-011-the-kakuna-master)을 따라 미션 7 시작 후 루주 1번지에서 Montée에게 의뢰를 받고 Lv.8·8·9 딱충이와 Lv.11 독침붕에 도전한다. 전투 상금 440과 별도 의뢰 보상 700·은빛가루·네트볼 5개를 지급한다. 가방·볼 한도로 받지 못한 도구는 보관하며 중복 수령을 막는다.

대상과 기술은 자료를 따르지만 2D 인물 좌표와 턴제 순차 전투는 초안이다. 원작의 실제 전투 배치와 진화 연출은 확인·재현하지 않았다. 격리 API에서 해금·상대·패배 후 재도전·재접속·승리·상금·한도·부분 수령·중복 요청·기존 파티 및 알 수 없는 보상 기록 보존을 확인했다. 운영 D1·실기·Sites 병합본은 확인하지 않았다.
