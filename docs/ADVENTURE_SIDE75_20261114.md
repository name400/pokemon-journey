# 사이드 미션 75: 특별한 포켓몬

[Serebii](https://www.serebii.net/legendsz-a/sidemissions/someunusualpokemon.shtml)의 미션 26 시작 후 베르 9번지 배틀코트, Touri의 레벨 50 가라르 야도란·야도킹과 기술 및 두 가라두구 도구를 참고했다. [Thonky](https://www.thonky.com/pokemon-legends-z-a/side-mission-075-some-unusual-pokemon)의 전투 상금 3,000원과 미션 보상 3,200원을 각각 지급한다. 원작의 실시간 전투는 이 게임의 단일 턴제 전투로 근사하고, 2D 인물 좌표는 추정이다.

승리 플래그와 보상 대기를 분리해 가방·지갑이 가득 차면 보상을 보관한다. 재도전과 오래된 요청을 검증하고, 승리 플래그만으로 보상 대기를 추정해 생성하지 않는다. 기존 벽만 상호작용 지점으로 쓰므로 통행 가능 칸을 막지 않는다. 현재 자연 플레이의 가라르 야돈 교환 의뢰(39)는 별도 미구현이다. 이미 보유한 가라르 야돈에는 기존 진화 경로와 이번 보상 도구가 작동한다.

격리 SQLite API에서 선행 조건, 실제 양쪽 폼과 레벨, 기권·재도전, 보상 한도·중복 및 재접속, 두 도구의 진화 소비를 검사했다. 구형 저장의 명시적 보상 대기 및 구역 충돌을 단위 검사했다. 원작 실기, 실제 운영 데이터, Sites 병합본과 브라우저 화면은 확인하지 않았다.
