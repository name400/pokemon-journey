# 미션 19 클레피 추적

[StrategyWiki](https://strategywiki.org/wiki/Pok%C3%A9mon_Legends%3A_Z-A/Reaching_Rank_D)와 [Pokémon Wiki 공략](https://pokemon.fandom.com/wiki/Pok%C3%A9mon_Legends%3A_Z-A/Walkthrough/Main_Mission_19_%E2%80%94_23)은 잠긴 문 조사 뒤 달아나는 클레피를 다음 방에서 쫓아가 포획하는 흐름을 설명한다. 기존 구현은 잠긴 문을 확인한 직후 바로 포획 전투만 제공했다.

이제 새로 문을 조사한 진행에서는 통로에서 클레피를 확인하면 클레피가 동쪽 방 쪽으로 이동하고, 이를 다시 찾아 기존 포획·전투를 진행한다. 단계는 저장되며, 이미 포획 단계에 있는 구형 저장과 알 수 없는 추적 표식은 소급 변경하지 않는다. 기존 하이퍼볼 지급·보류와 포획 처리는 유지한다.

추적의 두 타일과 2D 통로는 현재 압축 맵에 맞춘 근사이고 실제 이동 경로·속도는 미확인이다. 원작 공략은 클레피를 쫓아간 뒤 Emma에게 볼을 받는다고 설명하나, 기존 저장 및 볼 보류 호환을 위해 현재 지급 시점은 문 조사 때로 유지한다. 실기와 Sites 병합본은 검사하지 않았다.
