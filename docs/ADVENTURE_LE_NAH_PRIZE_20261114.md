# 르 나 전투 상금

[Thonky 공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-029-full-course-of-battles-one-star)과 [르 나 상대 편성](https://bulbapedia.bulbagarden.net/wiki/Restaurant_Le_Nah)은 Audrey·Thomas·Thierry에게 각각 승리하면 1,440원을 얻으며 별도의 최초 의뢰 보상은 300원이라고 설명한다. 새로 시작한 각 코스의 승리 상금을 지급하며 금색 인형은 이 전투 상금에만 적용한다. 최초 의뢰 보상·반복 보상·참가비는 기존 처리를 유지한다. 전투 당시의 금액과 2차 출처는 실기에서 확인하지 않았다.

이미 진행 중인 저장 스냅샷에는 새 지급 표시가 없으므로 기존 규칙대로 처리하고, 다음에 시작하는 코스부터 새 규칙을 적용한다. 패배·포기·오래된 요청은 상금을 지급하지 않는다. 지갑의 안전한 정수 한도를 넘으면 배틀 결과 저장을 거부하므로 포기 후 잔액을 줄여야 한다. 금색 인형·구형 전투·지갑 한도·재접속과 중복 요청은 격리 API에서 적 HP와 상태를 조정해 검사했으며 일반 난이도, 운영 데이터와 실제 기기는 확인하지 않았다.
