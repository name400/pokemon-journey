# 사이드 미션 70: 누가 제일 강해?

미션 20 완료 이후 Rust Syndicate 사무소 앞의 두 단원에게 의뢰를 받고 파티에 포켓몬을 한 마리만 둔 상태로 아보크 Lv.45와 얼음귀신 Lv.45를 각각 상대한다. 두 전투는 어느 순서로든 진행할 수 있으며 승리한 단원은 다시 도전하지 않는다. 각 전투 상금 2,160원과 최종 보상 2,000원·검은안경·기합의머리띠는 별개다. 보상 한도와 월드 리비전으로 중복 지급을 막고, 알 수 없는 승리 기록은 덮어쓰지 않는다. 구형 저장은 완료나 보상을 추정하지 않는다.

[단원 위치와 해금](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/estival-avenue.html), [상대 기술과 상금](https://bulbapedia.bulbagarden.net/wiki/Mission_(Legends:_Z-A)/Trainers) 및 [진행과 보상](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_61-80)을 참고했다. NPC 타일은 기존 사무소 외부 지도에 맞춘 2D 초안이다. 각 전투 시작 시 한 마리 조건을 적용하며 전투 사이 교체까지 제한하는지는 원작 실기를 확인하지 못해 제한하지 않는다. 실시간 전투와 특성 없는 원작은 기존 시뮬레이터의 턴제와 다르다.

격리 API에서 해금·파티 제한·기권·역순 승리·재접속·각 상금·가방 한도·중복 보상 및 기존 파티·보유함·진행 보존을 확인했다. 운영 D1, 원작 실기 및 Sites 병합본은 확인하지 않았다.
