# 하수도 재진입 의뢰의 진행 조건

[사이드 미션 57 공략](https://www.serebii.net/legendsz-a/sidemissions/thecameruptentrepreneur.shtml)과 [하수도 접근 안내](https://altema.jp/legendsza/tikasuidou)는 본편 미션 20 시작 이후 Hérup의 의뢰로 별도 하수도 입구를 연다고 설명한다. 두 자료는 2차 공략이다. 현재 2D 지도의 블루 3번지 지하 통로와 의뢰인 위치는 기존 근사이며 이 자료로 정확한 좌표나 지형을 확인한 것은 아니다.

새로운 ZA 모험에는 재진입 조건의 버전 표식을 기록한다. 미션 19를 마치고 호텔에서 미션 20을 시작해야 기존 의뢰인에게 문을 여는 선택지가 나오며 서버 요청도 같은 조건을 검사한다. 입구를 열면 종전의 하수도 이동·의뢰 전투·보상 및 빠른 이동 등록을 그대로 사용한다. 이미 열려 있는 문을 닫지 않는다. 표식이 없는 기존 저장은 이전 해금 규칙을 유지하고, 알 수 없는 미래 표식은 덮어쓰지 않는다. 구형 저장에 보상이나 진행을 소급하지 않는다.

격리 API에서 새 진행의 해금 전 거절·미션 20 시작 뒤 개방·하수도 진입·재접속·중복 거절, 이전 저장의 출입, 알 수 없는 표식과 파티·소지품 보존을 확인했다. 원작 실기, 실제 운영 데이터 및 Sites 병합본은 검사하지 않았다. 화면의 걷기와 카운트는 기존 동작이며 같은 포켓몬의 걸음 수가 실제 이동에 따라 증가한다.
