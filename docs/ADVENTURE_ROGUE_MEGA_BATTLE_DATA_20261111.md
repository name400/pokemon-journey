# 폭주 메가진화 사건 전투 데이터

원작 현장 자료에 따라 미션 12의 폭타는 Lv.34·대지의힘·박치기를 사용한다. 미션 21~23의 입치트·거북손데스·전룡은 Lv.48, 미션 27~29의 눈여아·파비코리·이상해꽃은 Lv.53, 미션 32~34의 망나뇽·마기라스·아쿠스타는 Lv.59로 새 전투를 생성한다. 각 포켓몬의 확인된 기술을 사건 데이터에 기록했다.

근거: [존느 3번지](https://bulbapedia.bulbagarden.net/wiki/Jaune_Sector_3), [로즈 6번지](https://bulbapedia.bulbagarden.net/wiki/Magenta_Sector_6), [블르 5번지](https://bulbapedia.bulbagarden.net/wiki/Bleu_Sector_5), [루주 6번지](https://bulbapedia.bulbagarden.net/wiki/Rouge_Sector_6), [몽테리공원](https://bulbapedia.bulbagarden.net/wiki/Aymlis_Park), [로즈 4번지](https://bulbapedia.bulbagarden.net/wiki/Magenta_Sector_4), [존느 8번지](https://bulbapedia.bulbagarden.net/wiki/Jaune_Sector_8), [베르 3번지](https://bulbapedia.bulbagarden.net/wiki/Vert_Sector_3), [존느 4번지](https://bulbapedia.bulbagarden.net/wiki/Jaune_Sector_4), [블르 9번지](https://bulbapedia.bulbagarden.net/wiki/Bleu_Sector_9).

변경은 새로 시작하는 전투에만 적용한다. 저장된 진행 중 전투, 사건 완료·보상·위치는 변경하지 않는다. 원작 자료가 불확실하다고 표시한 HP 단계별 기술 제한과 턴제에서 구현되지 않은 실시간 특수 공격·동료 동시 참전은 재현하지 않았다. 기존 턴제 전투 규칙과 특성 처리는 유지한다.
