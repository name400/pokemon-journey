# 루주 6번지 민트 판매와 사용

[판매 안내](https://allthings.how/modest-mint-locations-in-pokemon-legends-z-a/)와 [원작 도구 목록](https://www.serebii.net/legendsz-a/items.shtml)에 따라 루주 6번지의 공격 및 특수공격 민트 두 판매대를 개당 20,000원으로 연결했다. 정확한 노점 좌표는 2D 초안이다. 기존에 막힌 건물 칸을 재사용해 이동 경로·저장 위치를 바꾸지 않는다. 두 노점의 9종만 제공하며 다른 능력치 민트 및 다른 판매점은 아직 구현하지 않았다.

가방에서 선두 포켓몬에게 사용한다. 원래 `nature`는 보존하고 기존 포켓로그 민트와 전투·능력치 계산이 이미 사용하는 `rogueNatureOverride`에 보정만 기록한다. 다른 민트는 이전 보정을 대체하며 HP와 보유 개체 이력은 유지한다. 이 필드는 공유 포켓몬 데이터의 기존 보정이므로 같은 개체를 다른 게임에서 사용하면 기존 엔진의 처리에 따라 해당 보정도 적용된다. 구형 저장에 필드가 없으면 기존 성격이 그대로 적용된다.

격리 API에서 구매·잔액 부족·가방 한도·중복 요청, 원래 성격과 HP·능력치·민트 교체·재접속, 파티 외 대상 및 잘못된 장소 거절을 확인했다. 실제 전투 스냅샷의 성격 및 공격 능력치도 대조했다. 판매대와 가방은 PC·모바일 Chromium에서 모의 API로 확인했다. 실제 운영 D1·기기와 전체 원작 노점은 검증하지 않았다.

## 후속: 방어·특수방어·스피드 민트

[판매점 목록](https://allthings.how/modest-mint-in-pokemon-legends-z-a-locations-and-every-mint-stall/)을 기준으로 루주 1번지의 방어·특수방어 판매대와 베르 6번지의 스피드 판매대를 추가했다. 이로써 기존 두 판매대와 합쳐 능력치 보정 21종을 살 수 있다. 판매대의 정확한 2D 좌표는 초안이며 기존에 막힌 건물 칸을 사용한다. 위의 9종만 제공한다는 문장은 이 후속 내용으로 갱신한다. 다른 원작 판매대의 전수 구현은 아니다.

대표 세 종류의 구매·재접속·사용·능력치·기존 성격 및 중복 요청을 격리 API로 확인했다. 판매대별 출입 경로·기존 저장과 PC·모바일 시험 화면도 확인했다. 이 기능의 누락이 메인 스토리 자체를 막았다고 확인된 것은 아니다.

## 루주 시장의 나머지 두 판매대

[판매점 안내](https://allthings.how/modest-mint-locations-in-pokemon-legends-z-a/)는 야생 구역 3 서쪽의 같은 시장에 방어·특수방어뿐 아니라 공격·특수공격 민트 판매대도 있다고 설명한다. 이 안내는 해당 시장을 루주 3번지 또는 1번지로 부르는 자료가 있다고 밝혀, 기존 게임에서 두 판매대가 이미 자리한 루주 1번지 시장에 나머지 두 곳을 연결했다. 같은 자료와 [민트 위치 안내](https://www.dexerto.com/wikis/pokemon-legends-z-a/mints-pokemon-legends-z-a/)를 참고했으며 가격은 기존과 같은 개당 20,000코인이다. 건물과 판매대의 구체적인 2D 칸은 추정이다.

새 판매대는 이전부터 막힌 건물 칸을 사용한다. 따라서 기존 통행 경로·저장 좌표와 다른 판매대는 그대로이며, 이미 보유한 민트나 포켓몬은 수정하지 않는다. 네 판매대의 접근과 상품 분리·저장 복원, 두 신규 판매대의 실제 구매·재접속·잘못된 상품과 중복 요청 거절·파티와 기존 진행 보존을 격리 검사했다. 실제 원작 기기·운영 D1·Sites 병합본은 확인하지 않았다. 존느 광장의 야생 구역 개방 전 시장과 민트 판매는 별도 구현이 필요하다.
