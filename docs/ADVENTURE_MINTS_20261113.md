# 루주 6번지 민트 판매와 사용

[판매 안내](https://allthings.how/modest-mint-locations-in-pokemon-legends-z-a/)와 [원작 도구 목록](https://www.serebii.net/legendsz-a/items.shtml)에 따라 루주 6번지의 공격 및 특수공격 민트 두 판매대를 개당 20,000원으로 연결했다. 정확한 노점 좌표는 2D 초안이다. 기존에 막힌 건물 칸을 재사용해 이동 경로·저장 위치를 바꾸지 않는다. 두 노점의 9종만 제공하며 다른 능력치 민트 및 다른 판매점은 아직 구현하지 않았다.

가방에서 선두 포켓몬에게 사용한다. 원래 `nature`는 보존하고 기존 포켓로그 민트와 전투·능력치 계산이 이미 사용하는 `rogueNatureOverride`에 보정만 기록한다. 다른 민트는 이전 보정을 대체하며 HP와 보유 개체 이력은 유지한다. 이 필드는 공유 포켓몬 데이터의 기존 보정이므로 같은 개체를 다른 게임에서 사용하면 기존 엔진의 처리에 따라 해당 보정도 적용된다. 구형 저장에 필드가 없으면 기존 성격이 그대로 적용된다.

격리 API에서 구매·잔액 부족·가방 한도·중복 요청, 원래 성격과 HP·능력치·민트 교체·재접속, 파티 외 대상 및 잘못된 장소 거절을 확인했다. 실제 전투 스냅샷의 성격 및 공격 능력치도 대조했다. 판매대와 가방은 PC·모바일 Chromium에서 모의 API로 확인했다. 실제 운영 D1·기기와 전체 원작 노점은 검증하지 않았다.
