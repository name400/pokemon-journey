# 파티 포켓몬에게 사탕 사용

[Z-A 육성 안내](https://game8.co/games/Pokemon-Legends-Z-A/archives/557844)는 이상한사탕의 레벨 1 상승과 경험사탕의 경험치 지급을 설명한다. 기존 구현은 선두만 대상으로 해 다른 파티원을 육성할 때마다 선두를 바꿔야 했다. 가방에서 사용 대상을 파티원 중 선택해 이상한사탕과 경험사탕 XS·S·M·L·XL을 쓸 수 있도록 했다. 사탕 양과 기존 레벨·기술 습득 및 수동 진화 흐름은 유지한다.

서버는 선택한 ID가 현재 파티에 속하는지와 소지 수량·레벨 상한을 확인하고 기존 리비전 조건과 함께 저장한다. 보유함만의 개체는 거부하고 선두와 파티 순서를 바꾸지 않는다. 과거 클라이언트처럼 ID 없이 요청하면 기존대로 선두에 사용한다. 구형 저장과 기존 보유 개체는 일괄 변환하지 않는다.

격리 SQLite API에서 대기 파티원의 이상한사탕·경험사탕 사용, 기술 선택 대기, 재접속, 보유함·레벨 100 거부, 이전 리비전 재요청과 기존 선두 요청을 확인했다. PC·모바일 Chromium은 모의 API로 대상 선택과 재접속을 검사했다. 운영 D1·실기기는 확인하지 않았다. 이동 경로는 수정하지 않았다.
