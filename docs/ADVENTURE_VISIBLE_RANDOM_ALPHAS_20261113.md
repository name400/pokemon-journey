# 야생 구역의 보이는 무작위 우두머리 확장

[Serebii 구역별 출현표](https://www.serebii.net/pokearth/lumiosecity/wildzone5.shtml)의 5% 변종과 종별 레벨을 근거로 구역 14에 도입한 표시 개체 판정을 5·6·8~13·15~20에도 연결했다. 각 구역의 기존 조사 종 등록 및 미션 5 완료(또는 미션 6 시작 구형 저장)를 요구한다. 고정 우두머리·미션 개체·구역 8의 땅속 개체에는 새 판정을 적용하지 않는다. 구역 7에는 현재 고정 우두머리 외의 표시 개체가 없다.

새로 표시되는 개체에만 판정하며 색상과 레벨을 기존 개체 기록의 수명에 묶는다. 이미 색이 정해진 구형 개체와 진행 중 배틀을 재추첨하지 않는다. 일반 개체 갱신, 시간대 전용 이로치 보존과 10개 이로치 보관·포획·처치는 기존 수명 규칙을 재사용한다. 구역 20은 기존과 같이 별도 자동 시간 갱신이 없다. 구역 2·3의 이동 개체와 땅속 출현은 이동·접촉·갱신 규칙이 달라 이번 확장에 포함하지 않았다. 정확한 원작의 스폰 위치와 실시간 동작은 구현 범위가 아니다. 새로 추가한 종의 우두머리 고유 기술은 [고유 기술 목록](https://bulbapedia.bulbagarden.net/wiki/List_of_alpha_Pok%C3%A9mon_in_Legends:_Z-A_by_exclusive_move)을 대조해 적용했다.

격리 API에서 구역 5·6(지상과 물가)·12·15·18·19·20의 출현·배틀·도주·재접속·직접 포획·중복 요청을 검사했다. 구역 19 시간대 전용 이로치의 반대 시간대 및 복귀를 단위 검사하고 기존 고정 우두머리·미션 40을 회귀 검사했다. PC·모바일 Chromium의 구역 5·12·20 화면과 상호작용은 모의 API·대체 이미지로 확인했다. 새 개체의 최초 준비 시에만 우두머리 난수와 조사 판정이 추가되고 기존 개체를 반복 조회할 때 추가 DB 조회는 없다. 같은 로컬 Node 조건에서 구역 6 상호작용 15,000회 중앙값은 변경 전 43.82ms, 변경 후 50.37ms였다. 전체 이동 요청·운영 D1·실제 기기 성능은 측정하지 않았다.
