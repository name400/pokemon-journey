# 탐험 기술 이름 호환

기존 저장이나 교환 개체에는 같은 기술이 한국어 이름, 영문 이름 또는 시뮬레이터 ID로 남을 수 있다. 예를 들어 `Flamethrower`를 가진 포켓몬에게 기술머신으로 `화염방사`를 다시 가르치면 두 슬롯에 같은 기술이 들어가고 PP도 초기화되는 문제를 재현했다. 같은 기준의 연구 기술머신과 수동 학습에도 중복 가능성이 있었다.

기존 필드 기술 데이터의 실제 기술 ID를 사용해 스토리·연구 기술머신, 수동 학습과 대기 중인 기술 선택, 레벨업·진화 기술을 비교한다. 정상적인 기술 교체에서는 잊은 기술의 PP만 제거하고 나머지는 보존한다. 이미 중복된 구형 저장에서 한 슬롯만 교체하면 남은 동일 기술의 PP를 유지한다. 알 수 없는 이름은 원문이 같을 때만 같다고 판단하며 저장을 일괄 변환하지 않는다.

동일한 ID 확인을 기술 관리 화면, 숙달의씨 대화와 서버, 구역 2·과거 현장의 바위깨기 및 우두머리 고유 기술 교체 경고에도 적용했다. 영문 `Rock Smash`로 길을 열 수 있고, 영문으로 저장된 고유 기술도 실제로 잊을 때 경고한다. 이미 다른 슬롯에 같은 기술이 남아 있으면 잊는다는 경고를 하지 않는다. 기존 기술 데이터나 포켓몬을 소급 수정하지 않는다.

격리 API에서 중복 기술머신·수동 학습·대기 선택 거절, 일반 학습과 PP 보존, 숙달의씨·오래된 요청, 실제 바위깨기와 파티·지갑·구형 필드를 확인했다. 단위 검사에서 레벨업 중복, 영문 기술 교체와 기존 중복의 PP 보존, 우두머리 경고 및 기존 기술플러스 경로를 확인했다. 타입 검사도 통과했다. 원작 기기·운영 D1·Sites 병합본과 실제 PC·모바일 브라우저는 확인하지 않았다.
