# 존느 3번지 지상·비계·옥상 표현

[위치 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-3.html)는 북쪽 건물 옥상의 폭주 메가폭타와 그 남쪽 비계를 설명한다. 기존 미션 12의 지상 건물, 비계 발판과 옥상 가장자리를 서로 구분되게 표현했다.

건물과 비계의 정확한 윤곽, 층 높이, 사다리 위치는 기존 2D 초안이며 원작과 동일하다고 확인하지 못했다. 기존 타일·충돌·사다리 동작·미션·저장 형식을 변경하지 않았다. 주변 통로 및 실제 높이 관계는 추가 자료 대조가 남는다.

지상 사다리 접근과 지상·비계·옥상 저장 복원, 모의 API를 이용한 PC·모바일 사다리 대화 화면을 검사했다. 실제 운영이나 Sites 병합본 검증은 아니다. 모바일 D1 이동 오류의 운영 재검증 전 기록은 유지한다.
