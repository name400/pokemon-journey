# 마젠타 하수도 지도 비교 (2026-11-16)

- 참고 이미지: [Shiny Stash Live Map의 SewersB.png](https://github.com/Insektaure/Shiny-Stash-Live-Map/blob/main/romfs/SewersB.png). 이미지에는 남쪽의 긴 진입로, 중앙의 사각 수조를 둘러싼 순환 통로, 동쪽 통로로 연결되는 서쪽 방 둘이 보인다. 이 저장소는 게임 데이터를 이용하는 비공식 도구다.
- [Bulbapedia 하수도 설명](https://bulbapedia.bulbagarden.net/wiki/The_Sewers)은 마젠타 쪽이 블루 쪽보다 훨씬 작고 별개라고 설명한다. 두 이미지의 크기와 비교하면 SewersB가 마젠타 쪽일 가능성이 높지만, 파일명과 구역의 대응을 독립적으로 확정하지는 못했다.
- 기존 맵은 거의 열린 직사각형이다. 신규 모험용 23×17 격자에서는 남쪽 접근로, 수조 주변을 도는 길과 동쪽으로 열리는 두 서쪽 방을 표현했다. 격자의 정확한 좌표·비율, 방의 상세 기물, 야생 개체와 기존 결정 27개의 좌표는 원작과 대조되지 않은 근사다. 원본 이미지 자체를 제품에 포함하지 않는다.
- 기존 저장이 하수도 안에 있으면 구 지형을 그대로 유지한다. 밖으로 나온 뒤 정상적인 입구 행동으로 다시 입장할 때 전투·조우·포획 및 야생 개체 위치 기록이 없고 알 수 없는 버전이나 결정 기록이 없는 경우에만 `zaMagentaSewerLayout: 2`로 전환한다. 입장 좌표는 기존과 같은 안전한 `[11,14]`다. 알 수 없는 기록은 수정하지 않고 전환도 보류한다. 새 도입 또는 미르시티 직접 시작에도 같은 버전을 설정한다. 기존 결정 키·미션 진행·출구를 유지한다. 하수도 밖으로 나갈 때 기존 코드가 일시적인 야생 조우 상태를 정리하는 동작은 바꾸지 않았다. 27개 결정의 도달 가능성과 저장 복원을 대표 검사한다.
- [GamesRadar 하수도 안내](https://www.gamesradar.com/games/pokemon/full-pokemon-legends-z-a-map-and-all-locations/)는 세종 운하 옆의 별도로 떨어진 작은 하수도와 그 지도를 명시하고, [Thonky 미션 20 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-20-a-request-from-the-rust-syndicate)은 마젠타 센터 인근 운하에서 진입해 결정 27개를 정리한다고 설명한다. 다만 GamesRadar의 이미지 CDN은 이 환경에서 차단돼 이미지를 직접 대조하지 못했으므로 SewersB의 구역 대응 자체는 여전히 추정이다.
- 남은 일: 원작 플레이 영상이나 게임 내 지도에서 해당 이미지와 마젠타 입구의 대응, 두 방의 연결 및 수조의 실제 통행 가능 범위를 확인하고 세부 좌표를 대조한다. Sites 병합본과 운영 기기는 이번에 검증하지 않았다.
