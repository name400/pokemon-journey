# 마젠타 8번지 비계와 옥상 초안

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/magenta-sector-8.html)는 남서쪽 건물 북쪽 비계의 좋은상처약·진주·컬러풀한나사와 인근 건물 옥상들을 기록한다. 2차 자료이며 원작 실기는 확인하지 않았다.

기존 나사 수집 화면에서 비계와 인접 옥상을 다른 바닥으로 표시하고 비계의 두 도구를 연결했다. 기존 나사 위치, 사이드 미션 69 표식, 출입과 저장 좌표는 유지한다. 하나의 압축된 2D 화면에서 비계와 옥상을 같은 높이로 표현하며 실제 높낮이, 계단·비계·건물의 연결과 도구 좌표는 확인되지 않은 근사다. 정확한 입체 동선과 다른 옥상 도구는 미완성이다.

지상·비계 수집 기록의 보존, 가방 한도, 중복 요청, 위치 복원과 기존 구역 출입을 대표 검사했다. 실제 Sites 병합본과 모바일 이동 오류는 운영 재검증 전이며 실패 기록을 유지한다.

후속으로 같은 압축된 옥상 화면에 지역 자료의 남서쪽 네스트볼, 센터 옥상의 경험사탕 M, 남쪽 옥상의 기력의조각을 추가했다. 기존 지상·비계 도구와 같은 수집 기록을 사용하고 알 수 없는 기록은 덮어쓰지 않는다. 인접한 마젠타 7번지 남쪽 옥상으로 로토글라이드로 왕복하는 임시 출발점도 연결했다. 두 지역이 인접하고 남쪽 옥상에 로토글라이드가 필요하다는 자료를 바탕으로 한 경로이며 원작의 실제 출발 옥상·연결·높이는 확인하지 못했다. 출발점과 세 도구 좌표도 추정이다. 지도·격리 API에서 출입, 활공 해금 전 거절, 도구 한도·중복 방지, 기존 기록과 파티 보존을 대표 검사했다. 실제 기기·운영 Sites는 확인하지 않았다.
