# 미션 26 Asami의 의상

[미션 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-26-an-invitation-from-the-sbc)은 Asami의 배틀을 마친 뒤 의상을 받으며 바로 착용하지 않아도 된다고 설명한다. 기존 구현은 미션 진행만 처리하고 의상을 지급하지 않았다. 이제 미션 26의 Asami 승리 이후 옷 갈아입기 화면에 정장 한 벌을 제공한다. 자동 착용하거나 기존 의상·머리 설정을 바꾸지 않는다.

현재 플레이어 외형은 상의 중심의 작은 픽셀 표현이므로 정장 형태와 색상은 자체 2D 초안이다. 원작의 의상 전체 구성·색상·신발과 정확히 일치하는 것은 아니며 Boutique Couture의 전체 상품 판매도 구현하지 않았다. 저장된 미션 26 단계 1 이상 또는 완료 기록을 소유 근거로 읽어 이미 진행한 저장도 사용할 수 있다. 과거 저장을 일괄 수정하거나 보상을 중복 지급하지 않는다.

격리 API에서 메가진화 조건 실패·승리·착용·재접속·기본 옷 복귀와 SBC 연전을 검사했고, 구형 저장의 의상·머리 보존과 네 방향의 픽셀 마스크를 단위 검사했다. 검증 중 예전 미션 26 테스트가 첫 턴부터 메가진화를 기대했지만 현재 구현은 게이지 3칸이 필요해 실패했다. 기술 두 번으로 게이지를 채우는 실제 흐름으로 검사를 갱신하고 통과했다. 원작 기기·운영 D1·Sites 병합본 및 실제 브라우저 화면은 이번에 검사하지 않았다.
