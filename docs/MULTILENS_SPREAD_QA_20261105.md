# 전체 공격과 멀티렌즈

원본 `PokemonMultiHitModifier`와 원본 멀티렌즈 테스트의 전체 공격 사례를 대조했다. 신규 도전의 `multiLensSpreadRule: source-v1`은 여러 대상을 맞히는 적격 공격에도 멀티렌즈의 추가 타격과 기존 피해 분할을 적용한다. 이전 도전은 기존 단일 타격 동작을 유지한다. 이미 연속 타격인 기술, 변화 기술, Z·다이맥스 등 기존 제외 조건은 그대로 유지한다.

격리 전투와 실제 Classic 턴·저장 복원에서 스피드스타의 렌즈 1·2개와 두 상대별 타격, 면역·방어, 한쪽 또는 양쪽 기절, 파도타기의 아군 대상, 얼어붙은바람의 타격별 속도 하락, 부자유친 및 PP를 검사했다. 다른 저장 데이터도 보존했다.

남은 범위: 한 대상의 중간 기절 이후 원본의 전체 공격 피해 보정·후속 효과 순서, 사용자 기절, 추가 특성·도구·호출·고정 피해·이벤트와 모든 다중 대상 조합은 원본과 전수 대조하지 않았다. 실제 브라우저·모바일 플레이는 미검증이다. 운영 데이터와 Sites는 변경하지 않았다.
