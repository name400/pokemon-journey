# 이베르날 애비뉴와 북쪽 큰길 연결

[이베르날 애비뉴 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/hibernal-avenue.html)는 북동쪽 끝이 북쪽 큰길이라고 설명한다. [북쪽 큰길 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/north-boulevard.html)는 교차로 동쪽이 야생 구역 15에 포함된다고 구분한다. 기존 화면에 교차로 외곽 지상의 왕복 접근을 추가했다. 출입 좌표와 길의 선형은 잠정 2D 배치다.

기존 센트리코 접근과 야생 구역 15의 해금 조건, 저장 형식을 유지한다. 원작 실기와 실제 Sites 병합본은 확인하지 않았다. 모바일 이동 오류 기록은 운영 재검증 전까지 유지한다.
