# 사이드 미션 114 — 무장조의 깃털

[원작 의뢰 자료](https://www.serebii.net/legendsz-a/sidemissions/afeatherfromskarmory.shtml)와 [공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-114-a-feather-from-skarmory)에 따라 메인 미션 37 이후 쿨랑 수로의 Couper에게 의뢰를 받고 구역 17 옥상에서 반짝이는 깃털을 조사한다. 무장조 Lv.67을 이긴 뒤 Couper에게 돌아가 3,500원·금속코트·바리비열매 3개를 받는다. 의뢰 개체는 자료에 따라 포획할 수 없으며 기권하거나 패배하면 깃털에서 다시 도전할 수 있다. 별도 트레이너 승리 점수나 전투 상금은 주지 않는다.

의뢰 수락·배틀 승리·보상을 별도 단계로 저장하며 가방이나 지갑에 공간이 없으면 보상을 보류한다. 저장 리비전으로 중복 지급을 막고 과거 의뢰 완료 여부는 추정하지 않는다. 기존 옥상 사다리·통행·입치트·아이템과 저장 위치는 유지한다. 옥상 깃털과 Couper의 정확한 좌표는 기존 2D 맵에 맞춘 초안이며 무장조의 세부 기술과 실제 원작 장면은 확인하지 못했다. 원작 실시간 전투는 기존 턴제에 맞춘 근사다.

격리 API에서 사다리·옥상 이동, 깃털 조사, 포획 거절, 기권·재도전·승리, 트레이너 연구 점수 비증가, 재접속·가방과 지갑 한도·중복 요청과 파티 속성 보존을 확인했다. 이동 검사는 시험 저장에서 주변 우두머리를 처리된 상태로 설정했고 배틀 승리는 상대 HP를 시험용으로 낮췄다. 구역 17 기존 접근·복원과 연구 점수 검사도 통과했다. 원작 기기·자연 난이도·운영 D1·Sites 병합본은 미검증이다.
