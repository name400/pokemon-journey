# 포켓로그 더블 상태창 랭크 표시

더블 상태창에 능력치 랭크가 있으면 배지와 창을 압축해 랭크가 많은 경우 화면 밖으로 밀리지 않게 했다. 격리 Chromium 280×568, 390×844, 844×390, 1280×800에서 네 마리 각 일곱 랭크 변화를 응답에 합성해 28개 표시, 스크롤·뒤로 버튼 겹침 없음 및 저장 불변을 확인했다. 별도로 기존 단일·더블 상태, 볼 선택·소모 및 새로고침 회귀가 통과했다. 합성 랭크는 실제 전투에서 생긴 조합이 아니다.

작은 화면의 글씨는 축소되므로 실기기 가독성은 미검증이다. 탐험의 이전 격리 브라우저 검증 실패도 미해결이며, 원본의 더블 상태창과 픽셀 일치는 확인하지 않았다. 운영 데이터 및 Sites는 변경하지 않았다.
