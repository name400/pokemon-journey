# 전투 중 먹다남은음식 합산 한도

앞선 DNA/보상/수동 이전의 native+modifier 합계4개 한도를 전투 획득에도
연결했다. `lib/rogue-held-item-cap.mjs`의 공통 검증을 사용한다.

완료:
- 집게손톱과 미니블랙홀: native/중첩 어느 쪽을 선택해도 살아 있는
  전투 소유 기록을 합산한다. 초과하면 상대 도구를 제거하지 않는다.
- 네이티브 도둑질/탐내기/매지션/나쁜손버릇의 takeItem 경계에 획득 전
  검증을 연결했다. 트릭/바꿔치기는 양쪽을 미리 검사하며 같은 도구
  교환은 소지 수량이 늘지 않는 것으로 처리한다.
- 픽업: native/중첩 획득 모두 합산한다. 한도에 막힌 선택은 예외나
  무료 재추첨 없이 실패하며 원본 도구가 남는다. 이전의 중첩 추가
  검증에서 예외가 발생할 수 있던 경로를 사전 판정으로 바꿨다.
- 기존5개 이상 저장은 삭제하지 않는다. 부식가스 같은 파괴 동작은
  공격자의 보유 한도와 무관하게 작동한다.

최초5개 및 추가4개 검사에서 두 표현×합계3/4/5, 실제 codec/전투 복구와 소유 합계를
검사했다. 실제 도둑질·부식가스·트릭 턴과 집게손톱 이벤트, 미니블랙홀
잔여 턴, 픽업 단일 추첨·중복 정산 거부를 포함한다. 매지션/나쁜손버릇/탐내기의 실제 턴 검증도 이어서 통과했다. 바꿔치기는
트릭과 동일 훅에 연결했지만 개별 턴 검증은 아직 남아 있다.
선물은 실제 턴, 공생은 저장복구한 더블 전투의 열매 소비 뒤 전달을
검사해 받는 쪽 한도 초과 시 주는 쪽 도구 제거 전에 막도록 연결했다.

최종 회복 도구 통합 집중35/35(전투 획득9+DNA 새 조합3+기존 관련 회귀),
Worker 신규12/12. `/tmp/astra-healing-items-final.log`,
`/tmp/astra-healing-items-worker-final.log`. 최초 먹다남은음식 검사 결과는
`/tmp/astra-leftovers-acquisition-focused.log` 및 후속
`/tmp/astra-leftovers-transfer-complete.log`에 남긴다.

공통 cap 모델은 이어서 조개껍질방울까지 확장했다. 자세한 범위는
`DNA_HEALING_NATIVE_PAIRS_QA_20261105.md` 참고.
실제 미구현 잔량은 다른 native 충돌 도구와 독립 active 폼 도구 상태 및
자동 재활성 순서다. 검증 잔량은 바꿔치기 개별 턴, 모든 다중 대상/연타/
특성 억제 조합과 실제 운영 경로다. 원본 도구 전체 동등성 완료를 주장하지
않는다. 운영/Sites/원격/커밋 쓰기는 수행하지 않았다.
