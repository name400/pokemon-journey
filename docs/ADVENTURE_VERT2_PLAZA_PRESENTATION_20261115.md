# 베르 2번지 잔디 광장과 접근로 표현

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-2.html)는 베르 2번지의 잔디 광장, 동쪽 계단과 주변 건물 옥상을 설명한다. 기존 화면의 잔디와 횡단 보행면을 구분하고 기존 사다리를 알아보기 쉽게 표시했다.

광장 경계·사다리·계단의 격자 좌표와 원작 높이는 기존 2D 추정이다. 원작의 건물 외형 및 계단·옥상 경로의 정밀 관계는 이 작업에서 추가하지 않았다. 타일·충돌·기존 구역 연결·옥상·저장은 변경하지 않았다.

베르 2·4·5번지와 광장 연결, 옥상 이동과 저장 검사 4건 및 타입 검사가 통과했다. 모의 API를 사용한 PC·모바일 Chromium 화면을 확인했다. 원작 기기와 실제 Sites 병합본은 확인하지 않았다.
