# 구역 17 남쪽 공원과 북쪽 산책로의 연결

별도로 전달받은 원작 지도·3D 화면 분석은 작은 남서쪽 정원과 넓은 북쪽 산책로가 좁고 비스듬한 계단으로 연결되며, 산책로의 세 접근과 Y자 길이 있음을 설명한다. [원작 구역 설명](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_17)도 남쪽 정원·계단·북쪽 산책로와 출입 관계를 확인한다. 지도 원본은 이번 환경에서 직접 보지 못했다.

기존의 별도 공원·산책로 높이층을 유지하며 공원 계단의 산책로 도착점을 서쪽으로 옮기고, 북쪽 Y자 길로 비스듬히 이어지는 보행 칸을 열었다. 북쪽 넓은 산책로 동쪽도 기존 차단 칸 일부를 열어 확장했다. 세 북쪽 진입·사다리·옥상과 우두머리·도구 상태는 그대로다. 예전 산책로 계단은 구형 저장과 경로 복귀를 위해 남기며, 새 계단과 둘 다 같은 공원으로 내려간다. 기존 통행 칸을 새로 막거나 기존 저장 좌표를 옮기지 않는다.

각 계단의 위치·경사, 넓어진 부분의 좌표와 높이 차이는 2D 추정이며, 정확한 단수·고도와 원작의 두 옥상 연결 여부는 확인하지 않았다. 기존 호환 계단과 입구가 원작에 있다고 주장하지 않는다. 남쪽 정원의 전체 실루엣과 북쪽 본체의 정확한 외곽도 아직 정밀 재현하지 못했다.

구역 단위 검사 및 격리 SQLite API에서 새 계단 양방향, 이전 계단 탈출, 세 북쪽 출입, 옥상 사다리·조우, 재접속과 파티·재화 및 수령 상태를 확인했다. PC·모바일 화면은 모의 API와 대체 이미지를 사용했고 운영 환경과 원작 실기는 확인하지 않았다.
