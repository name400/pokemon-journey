# 루주 1번지 인접 지상 접근

[루주 1번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/rouge-sector-1.html)는 루주 3·4·5번지로의 접근을 설명한다. [3번지](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/rouge-sector-3.html), [4번지](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/rouge-sector-4.html), [5번지](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/rouge-sector-5.html) 안내도 1번지 접근을 각각 명시한다. 이전 지도에서는 직접 왕복할 수 없었다.

기존 지상 화면에 세 왕복 접근을 추가했다. 출입 좌표와 길의 폭·선형은 원작에서 측정하지 않은 2D 추정이다. 기존 상가·광장·구역 3 및 미션과 옥상 경로를 보존하고 이전 통행 칸을 막지 않는다. 저장 형식과 미션 진행 상태는 변경하지 않는다.

대표 단위 검사에서 세 경로 양방향·저장 복원과 기존 상점·전투·옥상 접근을 확인했다. 원작 실기·운영 D1·실제 Sites 병합본은 확인하지 않아 모바일 이동 오류 및 배포 검사 실패 기록을 유지한다.
