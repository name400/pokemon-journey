# 골동품 차데스·융합·소지 도구 격리 검사

기존 [융합 보상 경로 검사](../tests/rogue-dna-reward-flow.test.mjs)와 [검토된 폼 기증자 검사](../tests/rogue-dna-reviewed-donor-flow.test.mjs)를 근거로 골동품 모습 차데스를 융합 기증자로, 먹다남은음식을 소지 도구로 선택했다. 차데스와 DNA 보상은 시험용으로 구성했으며 자연 획득을 재현한 것은 아니다. 실제 보상 선택으로 융합하고 저장을 복원했을 때 기증자의 골동품 폼과 융합체에 이전된 도구가 유지됐다.

별도로 구성한 야생 전투에서 융합체의 실제 기술 명령 후 먹다남은음식의 턴 종료 회복을 확인했다. 저장 복원 뒤 융합 해제 확인 액션을 실행하고 다시 복원했을 때 주체에게 도구가 남고 기증자는 별도로 되살아나지 않았으며, 다른 슬롯·탐험 데이터·계정 코인이 유지됐다. 짧은 시험을 위해 전투와 해제 가능한 보상 화면은 직접 구성했으므로 자연 승리에서 보상 화면까지의 흐름을 검증한 것은 아니다.

신규 사례와 기존 융합 보상·융합 해제 관련 경량 엔진 검사 총 17건이 통과했다. 이 표본에서 결함은 재현되지 않아 게임 로직은 바꾸지 않았다. 다른 폼·도구 조합, API 동시성·브라우저·실기기·운영 저장은 이번에 검사하지 않았고 Sites에는 배포하지 않았다.
