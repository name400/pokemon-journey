# 미션 20 상가 건물 고스트

[상가 건물 자료](https://bulbapedia.bulbagarden.net/wiki/Old_Building)와 [이벤트 포켓몬 자료](https://bulbapedia.bulbagarden.net/wiki/List_of_in-game_event_Pok%C3%A9mon_in_Pok%C3%A9mon_Legends%3A_Z-A)는 고오스 Lv.40과 팬텀 둘 Lv.42를 포획하거나 쓰러뜨려 해결하는 흐름을 기술한다. 해당 종·레벨과 확인된 기술을 새 조우에 적용하고, 쓰러뜨린 뒤 포획 기회를 건너뛰어도 해당 개체를 해결한 것으로 기록한다. 도망·패배는 기록하지 않는다.

이전 저장의 세 슬롯 식별자 92·93·94는 유지한다. 과거 93 슬롯에서 이미 포획했거나 기존 고우스트 배틀을 진행 중이었다면 이를 그대로 보존하고 정상 완료한다. 일부 공략은 고우스트를 언급하므로 자료 간 차이가 있다. 실시간 동시 출현·이동과 건물의 정확한 내부 지형은 여전히 초안이다.

빈집의 각 미해결 슬롯에서 보유한 볼을 선택해 필드에서 던질 수 있다. 포획 실패는 기존 턴제 배틀로 이어지고, 성공은 기존 슬롯 완료 기록과 포켓몬 보유함에 원자적으로 반영된다. 필드 포획 확률과 실패 후 전투 전환은 현재 턴제 구현의 근사이며 실시간 원작과 동일하다고 확정하지 않는다. 이미 진행 중인 구형 배틀과 기존 보유 개체는 바꾸지 않는다.

해결한 슬롯은 그 자리의 필드 표식과 상호작용을 없애 남은 대상을 구분한다. 이전 저장에 플레이어가 그 칸에 있어도 통행 가능한 바닥으로 복원하며, 진행 중인 구형 배틀의 상대와 이미 보유한 포켓몬은 수정하지 않는다. 표식과 건물 배치는 2D 초안이다.

새 의뢰부터 미해결 고스트 세 마리가 각자의 네 칸 범위에서 플레이어 세 걸음마다 한 칸씩 이동한다. 가까이 접근하면 이동을 멈춰 기존 전투·볼 상호작용을 사용할 수 있으며, 이동과 위치는 서버 저장으로 재접속 시 유지된다. 여러 걸음 요청은 고스트가 움직이는 순간 멈추어 클라이언트가 위치를 다시 확인한다. 기존 미션 진행 중 저장은 별도 이동 표시가 없어 고정 배치를 유지한다. 원작에서 확인한 것은 세 개체의 조우이며, 이동 경로·속도·접근 시 정지는 실시간 원작을 정확히 재현한 것이 아닌 2D 턴 기반 초안이다.
