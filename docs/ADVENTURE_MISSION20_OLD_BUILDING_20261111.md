# 미션 20 상가 건물 고스트

[상가 건물 자료](https://bulbapedia.bulbagarden.net/wiki/Old_Building)와 [이벤트 포켓몬 자료](https://bulbapedia.bulbagarden.net/wiki/List_of_in-game_event_Pok%C3%A9mon_in_Pok%C3%A9mon_Legends%3A_Z-A)는 고오스 Lv.40과 팬텀 둘 Lv.42를 포획하거나 쓰러뜨려 해결하는 흐름을 기술한다. 해당 종·레벨과 확인된 기술을 새 조우에 적용하고, 쓰러뜨린 뒤 포획 기회를 건너뛰어도 해당 개체를 해결한 것으로 기록한다. 도망·패배는 기록하지 않는다.

이전 저장의 세 슬롯 식별자 92·93·94는 유지한다. 과거 93 슬롯에서 이미 포획했거나 기존 고우스트 배틀을 진행 중이었다면 이를 그대로 보존하고 정상 완료한다. 일부 공략은 고우스트를 언급하므로 자료 간 차이가 있다. 실시간 동시 출현·이동과 건물의 정확한 내부 지형은 여전히 초안이다.
