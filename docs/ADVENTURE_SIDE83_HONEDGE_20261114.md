# 사이드 미션 83: 단칼빙의 검

루주 북쪽 거리에서 Acier의 의뢰를 받고, 데기라스 한 마리만 파티에 편성해 단칼빙과 싸운다. 승리 후 전투 상금 2,120원과 별도 의뢰 보상 1,000원·어둠의돌·고급상처약 2개를 받는다. 진행 단계가 없는 구형 저장도 미션 26의 해당 단계부터 시작할 수 있다. 패배하면 재도전 가능하다.

[Thonky](https://www.thonky.com/pokemon-legends-z-a/side-mission-083-honedges-cutting-edge)와 [Dexerto](https://www.dexerto.com/wikis/pokemon-legends-z-a/honedges-cutting-edge-pokemon-legends-z-a/)는 단칼빙을 53레벨로 제시하지만 [Bulbapedia](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends%3A_Z-A/Side_Missions_81-100)는 52레벨로 기재한다. 게임에서는 우선 53레벨을 사용하며 실기 대조가 남았다. Acier의 2D 좌표와 기술 구성은 초안이고 실시간 전투를 기존 턴제로 옮겼다.

가방이나 고급상처약 보유 한도가 부족하면 전체 의뢰 보상을 받지 않고 다시 받을 수 있다. 상태와 재화의 변경은 기존 리비전 조건과 함께 저장한다. 실제 Sites 병합본과 원작 기기는 검증하지 않았다.
