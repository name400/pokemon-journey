# AI 스텔라 테라스탈 자속 점수

고정 원본 `Pokemon.getMatchupScore`의 자속 확인은 기본 `isOfType`을 사용한다. 원본의 스텔라 테라스탈 기본 타입 확인은 스텔라 타입을 반환하므로 신규 도전 AI가 원래 타입 또는 환영 타입의 자속 보너스를 잘못 적용하지 않도록 수정했다. 실제 데미지의 테라스탈 자속 계산은 이 점수와 별개다. 기존 저장은 이전 판단을 유지한다.

스텔라·원래 타입의 점수 경계와 환영 중 스텔라 전투의 직렬화·복구, 행동 실행 및 다른 슬롯 보존을 격리 검사했다. 다른 테라스탈 복합 상성 및 운영·실기기 플레이는 별도 검증이 필요하다.

추가 검증: 저장 복구 후 환영 상태인 스텔라 적이 자발적으로 교체하는 실제 선택을 이전 규칙과 비교했다. 다른 슬롯은 보존됐다.
