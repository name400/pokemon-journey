# 야생 구역 12 눈 공원

- 자료: [Nintendo Life 구역 12 안내](https://www.nintendolife.com/guides/pokemon-legends-z-a-wild-zone-12-guide-all-pokemon-and-alphas), [Poképédia 구역 12](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_12).
- 확인된 특징: 눈 덮인 구역, 북서쪽 배틀코트, 중앙 풀숲, 남서쪽 연못과 얼음, 연못에 내려가는 계단과 나무가 있는 열린 지형.
- 구현: 기존 코트·풀숲·연못·계단·입구를 유지하면서 이동 방향을 보여 주는 눈길과 충돌하는 나무를 추가했다. 나무 개수와 위치, 눈길과 지형의 정확한 타일은 원작을 재현한 확정 정보가 아닌 2D 초안이다. 기존 구역 외부 연결을 원작과 동일하게 수정한 것은 아니다.
- 저장 호환: 옛 상층 저장 위치가 새 나무와 겹치면 같은 리비전에서 인접 통행 가능 지점으로 복원한다. 하층·물길·아이템·야생 개체 상태와 다른 저장 데이터는 유지한다.
- 화면 검사는 로컬 브라우저와 모의 게임 데이터로 수행했다. 외부 포켓몬 이미지는 차단한 대체 화면이며 실제 운영 저장소는 사용하지 않았다.
