# 기합의머리띠와 간접 피해

고정 원본 `7c0881255af5cd51992e513ff93c2f71adbe40e0`의 `src/field/pokemon.ts`는 간접 피해에 생존 도구 판정을 막는다. `src/phases/post-turn-status-effect-phase.ts`도 독·맹독·화상에 이를 명시한다. 혼란 자해는 원본에서 별도 피해 분류다. 기존 구현은 피해 종류에 관계없이 머리띠가 발동할 수 있었다.

새 도전의 `focusBandRule: source-v2`에서 일반 기술 피해와 혼란 자해는 기존 생존 판정을 유지하고 상태 이상·날씨 등 간접 피해에는 발동하지 않는다. 진행 중인 `source-v1` 및 구형 저장은 종전 규칙을 유지한다. 보상 추첨과 광대 도구 교환은 두 버전을 모두 지원하며 전투 스냅샷에도 규칙을 보존한다. 기존 저장을 수정하거나 이전 전투 결과를 소급 변경하지 않는다.

독·맹독·화상, 실제 모래바람·혼란 턴, 기술 피해, 반동, 부활 씨앗 보존, 저장 인코딩 및 다른 슬롯, 보상 추첨과 광대 교환을 자동 검사한다. 시뮬레이터의 피해 효과 종류를 기준으로 한 구현으로, 모든 기술·도구의 간접 피해 조합이나 실계정 플레이의 완전한 원본 동등성을 뜻하지 않는다.

관련 전투·도구·이벤트·챌린지 회귀는 일반 런타임과 Worker 로더 각각 191/191 통과했고 타입 검사와 프로덕션 빌드가 통과했다. 전체 테스트 스위트와 실기기 플레이는 이번에 실행하지 않았다.
