# 베르 8번지와 베르 거리 연결

[베르 8번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-8.html)는 동쪽 베르 거리 접근을, [베르 거리 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-street.html)는 서쪽 베르 8번지 접근을 설명한다. 모두 2차 자료다.

기존 지상 화면에 왕복 접근을 추가했다. 정확한 접점과 방향은 압축된 2D 지도의 잠정 배치다. 미션 3의 바위 우회가 활성화된 동안 새 연결을 양방향으로 막아 기존 우회 진행을 보호하며, 이전 구형 저장과 기존 경로는 유지한다. 이 임시 차단은 현재 게임 구조를 위한 처리로, 원작의 정확한 도로 차단 위치를 확인한 것은 아니다.

모바일 이동 오류와 Sites 병합본 실패 기록은 운영 재검증 전이므로 유지한다.
