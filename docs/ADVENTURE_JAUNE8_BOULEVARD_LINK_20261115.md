# 존느 8번지와 북쪽 큰길

[존느 8번지 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-8.html)는 동쪽의 북쪽 큰길과의 연결을, [큰길 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/north-boulevard.html)는 존느 8번지 및 카페 접점을 설명한다. 기존에 막힌 경계에 왕복 출구를 추가했다. 정확한 접점과 타일 좌표는 기존 2D 화면에 맞춘 추정이다.

기존 카페·의뢰·출입·저장 형식과 야생 구역 15·19 해금 조건은 유지했다. 왕복·기존 출구·잠금·저장 복원 및 모의 API PC·모바일 화면을 검사했다. 실제 운영이나 Sites 병합본은 확인하지 않았다. 모바일 D1 이동 오류 기록은 운영 재검증 전까지 유지한다.
