# 베르 5번지 안뜰과 거리 표현

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-5.html)는 큰 건물의 안뜰과 리다 전투, 광장·주변 구역과의 연결을 설명한다. 기존 지도의 건물 외곽과 안뜰 바닥을 인접 보행면과 구분했다.

건물의 형태·크기, 출입구와 격자 좌표는 기존 2D 추정이다. 원작의 비계·옥상 간 정확한 높이와 접근 관계는 이 작업으로 확인하거나 추가하지 않았다. 기존 타일·충돌·미션 위치·출입·저장은 변경하지 않았다.

베르 4·5번지 및 주변 광장의 연결과 안뜰·저장 복원 검사 5건, 타입 검사가 통과했다. 모의 API를 사용한 PC·모바일 Chromium 화면을 확인했다. 원작 기기와 실제 Sites 병합본은 확인하지 않았다.
