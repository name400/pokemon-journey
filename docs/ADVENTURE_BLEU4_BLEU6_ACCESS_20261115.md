# 블루 4번지와 6번지 지상 접근

[블루 6번지 지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-6.html)는 북쪽의 블루 4번지와 북서쪽의 에스파스 비드를 각각 인접 접근으로 설명한다. 기존에는 두 거리 사이를 에스파스 비드를 통해 이동해야 했다.

두 지상 지도에 왕복 출입과 보행 접근을 추가했다. 정확한 접점·도로의 폭과 선형은 압축된 2D 추정이며, 자료가 원작의 모든 세부 동선을 확인해 주는 것은 아니다. 에스파스 비드의 지상·지하 연결과 블루 거리·야생 구역 5 접근은 유지한다. 기존 통행 칸을 막거나 저장 형식과 도구·미션 상태를 바꾸지 않았다.

대표 단위 검사에서 새 경로의 양방향 이동·저장 복원, 기존 에스파스 비드 지상·지하와 블루 거리 연결을 확인했다. 실제 원작 기기·운영 D1 및 Sites 병합본은 확인하지 않았다. 모바일 이동 오류와 배포 검사 기록은 운영 재검증 전이므로 유지한다.
