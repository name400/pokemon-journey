# 개별 상태이상 치료제

[상점 목록](https://www.serebii.net/pokearth/lumiosecity/magentadistrict.shtml)에 맞춰 마비치료제·화상치료제·얼음상태치료제·잠깨는약을 기존 프렌들리숍에 각 100원으로 추가했다. 각 도구는 해당하는 상태만 치료하고, 다른 상태·기절한 포켓몬·파티 밖 포켓몬에는 사용할 수 없다. 가방과 단일 전투, 동료·다수 상대 및 세 아군 전투에서 재고와 대상을 서버가 확인한다. 강제 교체와 기존 대여 전투의 도구 제한은 유지한다. 판매는 기존 상태 치료제와 같은 25원이며 [마비치료제 가격 자료](https://bulbapedia.bulbagarden.net/wiki/Paralyze_Heal)로 대표 대조했다.

기존 개체·가방 데이터를 이전하거나 새 아이템을 자동 지급하지 않는다. 구매·판매·사용은 기존 지갑/가방과 리비전 조건을 따르며 중복 요청과 잔고·수량 부족을 거절한다. 구형 상태이상 저장의 한국어 명칭과 전투 시뮬레이터 코드를 함께 판별한다. 현재 전투 엔진의 잠듦·얼음 상태를 사용하며 원작 실시간 졸음이나 상태 지속 시간의 재현을 추가하는 것은 아니다.

격리 API에서 네 도구 각각의 가방·단일·1대2·동료 및 세 아군 전투, 잘못된 상태·비소유 개체·재접속·중복 요청을 검사했다. 상점 구매와 판매, 기존 치료제 회귀와 PC·모바일 모의 상점 화면도 확인했다. 원작 실기·운영 D1·Sites 병합본은 확인하지 않았다.
