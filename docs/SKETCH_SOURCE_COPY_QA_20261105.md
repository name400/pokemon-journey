# 스케치 복사 조건

원본의 스케치 금지 목록은 NONE·발버둥·스케치다. 기존 엔진은 자체 `nosketch` 목록이 더 넓어 원본이 허용하는 다크홀도 거부했다. 최신 신규 도전에서는 원본 기술 ID로 확인 가능한 일반 기술의 추가 `nosketch` 금지를 적용하지 않는다. 이전 도전은 기존 복사 규칙을 유지한다.

현재 구현은 게임에 등록되지 않은 기술과 네이티브 Z·맥스 기술은 계속 거부하므로 원본의 전체 복사 동등성은 확인되지 않았다. 이미 아는 기술·스케치 자체·변신 상태의 복사 금지, 직접 사용한 잠꼬대와 간접 호출 기술 구분, 같은 출전에서 잊은 기술을 다시 복사할 때 뒀다쓰기 이력, PP·저장 복구·다른 슬롯 보존을 격리 검사했다. 실계정·실기기 검증은 하지 않았다.

남은 범위는 특수 기술 전체의 복사·학습과 스케치·변신·호출의 다른 복합 조합, 첫 턴 미행동 경계 및 AI·도구·이벤트·폼의 미완성 항목이다.

관련 변신·호출·AI·날씨·지형·트레이너·상태·챌린지·융합·학습·스케치 회귀는 일반 실행과 Worker 로더에서 각각 314건 통과했다. 이후 추가한 트레이너 스케치를 포함한 집중 검사 8건도 양쪽에서 통과했다. 타입 검사와 빌드도 통과했으며 전체 프로젝트 검사는 아니다.
