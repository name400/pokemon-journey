# 미션 20 결정 하수도의 기술머신 095

[하수도 공략](https://www.neoseeker.com/pokemon-legends-z-a/Main_Mission_20-23)과 [기술머신 위치 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Legends-Z-A/moves.html)는 마젠타 거리 입구에서 가는 하수도 북서쪽에 TM095 도발이 있다고 설명한다. 기존 결정 하수도 북서쪽에 일회성 수집 지점을 연결했다. 방의 크기와 정확한 도구 좌표는 2D 초안이다. 의뢰를 수락한 뒤 입장할 수 있으며 의뢰를 이미 완료한 저장도 기존 입구에서 다시 방문할 수 있다. 결정 제거·의뢰 진행 기록은 건드리지 않는다.

[Z-A 기술머신 학습 목록](https://www.serebii.net/attackdex-sv/taunt.shtml)을 기준으로 확인한 기본 종과 나옹·페르시온·마임맨·침바루의 명시된 지역 폼 및 로토무 폼에 기존 반복 학습 경로를 연결한다. 기타 폼은 확인 전까지 허용하지 않는다. 학습 시 기술머신은 소모되지 않고 다른 기술과 PP를 보존한다. 도발의 턴 수는 기존 턴제 시뮬레이터의 근사이며 원작의 실시간 지속 시간을 재현한 것은 아니다. 구형 저장의 도구 보유 여부를 추정하지 않고 가방이 가득 차거나 미확인 수집 형식이면 기록을 바꾸지 않는다.

격리 API에서 완료 후 재입장, 가방 한도·일회성 수집, 학습·비호환·기존 개체 및 진행 기록 보존을 확인했다. 단위 검사에서 의뢰 전·도중·완료 후, 미래 저장 형식과 기본·지역 폼을 대표 확인했다. 원작 실기·운영 D1·Sites 병합본은 검증하지 않았다.
