# 포켓로그 전투 기술 선택 키보드 — 2026-11-18

단일 배틀의 네 기술은 세로 한 열이지만 방향키는 2열 격자 기준으로 움직였다. 격리 Chromium의 280·390·1280px 화면에서 첫 기술에서 아래를 누르면 둘째를 건너뛰어 셋째로 초점이 이동하는 것을 재현했다. 더블은 실제 2열이므로 아래로 둘째 행에 이동한다.

포켓로그의 승인된 단일 전투 기술 목록만 세로 목록으로 처리한다. 더블 기술 격자, 명령 격자, 파티 방향키 및 실제 전투 명령은 유지한다.

전용 포트·소유 토큰이 있는 격리 fixture와 Chromium의 싱글·더블, 280×568·390×844·1280×800에서 실제 표시 행과 방향키 초점, 선택 전 저장 불변, 둘째 기술 명령과 PP 차감, 저장 재조회 및 다른 슬롯·탐험 보존을 확인했다. 기존 파티 키보드의 같은 세 크기 싱글·더블 및 강제 교체 경로도 재검사했다. 실제 기기·스크린리더, 모든 비활성 기술과 탐험 화면은 미검증이다.

이번 변경 후 전체 타입 검사·린트는 실행하지 않았다. 바로 전 변경 파일의 린트는 오류 103개·경고 20개로 미통과였고 당시 원본도 같은 개수였다. 포자 일반 규칙과 재접속 연출 반복은 미해결로 유지한다. 운영 데이터와 Sites는 변경하지 않았다.
