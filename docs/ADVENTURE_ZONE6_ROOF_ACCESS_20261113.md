# 6번 구역의 두 옥상 접근

[구역 안내](https://www.gamersheroes.com/game-guides/pokemon-legends-z-a-wild-zone-guide/)는 홀로베이터로 보송송·파비코가 있는 옥상에 가고 별도 사다리로 우두머리 피카츄 옥상에 오를 수 있다고 설명한다. 기존 구현은 홀로베이터가 피카츄 층으로 연결되고 다른 옥상은 별도 임시 연결을 사용했다. 각각 자료와 같은 목적지의 홀로베이터와 사다리를 추가하고 기존 임시 연결도 그대로 둔다.

새 연결은 지상과 각 옥상 사이를 왕복하며, 기존 건물 및 운하, 해당 층 포켓몬과 아이템 기록을 유지한다. 이전 저장에 사용되던 칸도 막지 않는다. 홀로베이터·사다리의 정확한 위치, 옥상 모양과 새 2D 좌표는 미확인 초안이며 기존 임시 경로가 원작에 있다는 뜻은 아니다. 원작 정밀 지도 및 운영 기기는 검증하지 않았다.
