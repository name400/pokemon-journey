# 이동 보간 실험 — 2026-11-12

로컬 Chromium에서 390×844, 모의 이동 요청 지연 150ms로 평지 직진 중 캐릭터의 보간 좌표를 프레임별로 기록했다. 시작·종료 경계를 제외한 구간에서 기준 보간 시간(이동 주기의 0.85배)은 동일 좌표 프레임 시간이 900~917ms 중 150ms로 세 번 관찰됐다. 보간 시간만 1배로 바꾸자 세 번의 같은 좌표 시간은 각각 200/800ms, 300/900ms, 334/883ms로 늘었다. 0.9배 역시 결과가 들쭉날쭉했다.

실험은 클라이언트 프레임의 제한된 표본이며 실제 기기, 운영 D1, 구역 전환과 방향 전환의 지연은 측정하지 않았다. 이전 목표와의 거리를 기준으로 큰 위치 보정을 판단하는 추가 실험도 일관된 개선을 보여주지 못해 어떤 보간 변경도 적용하지 않았다. 네트워크 지터에 독립적인 칸별 경로 애니메이션은 별도 설계·검증이 필요하다.
