# 루주 4번지와 7번지 지상 접근

[루주 4번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/rouge-sector-4.html)는 북동쪽의 루주 7번지 접근을, [루주 7번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/rouge-sector-7.html)는 서쪽의 루주 4번지 접근을 설명한다. 기존 지도에는 두 번지 사이의 직접 지상 경로가 없었다.

기존 지상 화면에 왕복 접근을 추가했다. 출입 좌표와 길의 폭·선형은 원작에서 측정되지 않은 2D 추정이다. 상가 입구와 전투장·사다리, 루주 거리와 5번지, 야생 구역 13의 기존 출입·랭크 제한은 유지한다. 이전 통행 칸을 막지 않으며 저장 형식과 미션 상태도 변경하지 않는다.

대표 단위 검사에서 양방향 이동·구형 위치 복원, 기존 상가 상호작용·전투장 접근, 구역 13 제한과 옥상 연결을 확인했다. 원작 실기·운영 D1·실제 Sites 병합본은 확인하지 않아 모바일 이동 오류 및 배포 검사 실패 기록을 유지한다.
