# 10번 구역 운하 옥상 연결

[원작 공략](https://gamerant.com/wild-zone-10-pokemon-legends-za-100-tynamo/)은 운하 별가사리 부근의 사다리로 옥상에 오르며 아보크 우두머리가 중앙 옥상에 있다고 설명한다. [동쪽 옥상 안내](https://game8.co/games/Pokemon-Legends-Z-A/archives/559761)는 보르그 우두머리와 남동쪽 사다리를 설명한다. 기존 지상 사다리, 옥상 포켓몬과 도구를 유지하고 기존 두 옥상 면 사이에 운하 위 보행 연결을 추가했다.

두 옥상의 존재와 사다리 접근은 확인됐지만 이 연결로의 존재·형태·위치는 원작 자료에서 확인하지 못한 2D 초안이다. 지상은 그대로 운하로 남고 옥상에만 보행 가능한 연결을 추가해 기존 좌표를 막지 않는다. 진입 조건과 도구·오염물 진행은 그대로 둔다. 대표 경로와 저장 복원, 격리 API 왕복, 시험 데이터 PC·모바일 렌더링을 확인했다. 실제 원작 구조와 운영 기기는 추가 확인이 필요하다.
