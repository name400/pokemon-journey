# 구역 3 남쪽 옥상 접근

[원작 미션 5 공략](https://www.neoseeker.com/pokemon-legends-z-a/Main_Mission_05)은 야생 구역 3 남쪽의 홀로베이터로 올라간 옥상에서 냐스퍼를 찾을 수 있다고 설명한다. 기존 구역 3의 남쪽 지상과 별도의 옥상을 홀로베이터로 왕복 연결하고 옥상 풀밭의 냐스퍼를 기존 야생 조우·전투·포획 흐름에 연결했다. 기존 중앙 탑, 서쪽 Sommi 옥상과 지상 냐스퍼는 유지한다.

홀로베이터의 정확한 위치, 옥상 평면·높이·두 지붕을 잇는 발판은 확인하지 못한 2D 초안이다. 원작의 정확한 레벨·출현률도 확인하지 못해 레벨 9와 기존 풀밭 조우 확률을 임시 사용한다. 원작 실시간 필드 개체의 행동과 필드 선표시는 구현하지 않았다.

새 지상 홀로베이터 칸은 종전처럼 통행 가능하며, 그 칸의 구형 저장도 이동할 수 있다. 옥상과 지상 저장 복원, 왕복, 파티·재화·의뢰 진행 유지와 냐스퍼 야생 조우를 격리 API에서 확인했다. 구역 3 필드·지도·이동 예측 대표 검사와 PC·모바일 모의 브라우저 화면을 확인했다. 화면은 시험 데이터와 대체 이미지를 사용했으며, 원작 기기나 운영 데이터는 검증하지 않았다.
