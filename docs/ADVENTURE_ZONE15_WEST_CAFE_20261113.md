# 구역 15 서쪽 카페 접근

별도로 전달받은 원작 지도 분석은 카페를 구역 서쪽에 놓고, 북서에서 남동으로 굽는 길과 중앙 식생을 보여 준다. 원본 이미지는 이 작업 환경에서 직접 확인하지 못했다. [구역 설명](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_15)과 [옥상 접근 안내](https://www.videogameschronicle.com/guide/pokemon-legends-z-a-wild-zone-15/)는 공원과 카페, 외부 옥상을 통한 접근을 설명한다.

서쪽 기존 벽에 카페 주문 지점을 만들고 빠른 이동·택시를 그 앞으로 옮겼다. 기존 동쪽 주문 지점과 등록 판정은 구형 저장과 기존 경로 호환을 위해 남는다. 포장길은 기존 일반 바닥만 변경하고 풀밭·출입구·포켓몬·도구·기존 저장 좌표는 바꾸지 않는다. 새 서쪽 외관과 곡선 길의 정확한 타일, 높이와 충돌 및 기존 동쪽 건물은 2D 초안이며 원작 지도의 정밀 재현이 아니다. 외부 홀로베이터와 옥상 거미줄 및 지상에서 돌아가는 구형 경로는 유지한다.

구역·빠른 이동 단위 검사와 격리 API에서 서쪽 입구·결제·재접속·중복 요청, 옛 주문 지점, 등록 지점과 택시 및 파티·재화를 확인했다. PC·모바일 Chromium은 시험 상태와 외부 이미지 대체물로 확인했다. 실제 Sites 병합본과 원작 기기는 검사하지 않았다.
