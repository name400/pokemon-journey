# 조사 완료 후 우두머리의 고유 기술

[우두머리 고유 기술 목록](https://bulbapedia.bulbagarden.net/wiki/List_of_alpha_Pok%C3%A9mon_in_Legends:_Z-A_by_exclusive_move)과 구역 1~20의 기존 무작위 우두머리 후보를 대조해, 기존에 빠진 종의 고유 기술을 공통 생성 경로에 추가했다. 새로 생성되는 고정 우두머리도 같은 공통 생성 경로를 이용하면 기술이 적용된다. 새 개체에만 기술과 초기 숙달 기록을 넣으며 이미 보유한 포켓몬이나 진행 중인 전투를 변환하지 않는다.

호바귀는 원작에서 크기별 고유 기술이 달라 현재 개체 폼의 정확한 크기 판정 없이 임의 지급하지 않았다. 표에 없는 폼이나 미확인 종도 제외한다. 원작의 실시간 AI 및 모든 고유 기술의 전투 효과를 이번에 검증한 것은 아니다. 포획 후 기술 교체 경고는 기존 공통 경로를 사용한다.

후속: 프로젝트의 호바귀 폼 ID `710`(보통), `10027`(작은), `10028`(큰), `10029`(특대)는 서로 구분된다는 점을 생성 데이터에서 확인했다. 각 폼에 원작 목록의 화염방사·사이코키네시스·악의파동·스톤샤워를 각각 적용했다. 우두머리의 XL 표시만으로 크기 폼을 추정하지 않으며 이미 보유한 개체와 전투는 바꾸지 않는다. 기존 미확인 보류 문장은 이 확인된 네 폼에 한해 갱신한다.
