# 우유마시기의 흉내내기와 지시

원본 `CopyMoveAttr`는 흉내내기에서 복사 대상의 지정 대상을 보존한다. 사용자가 선택할 수 있는 대상이 자신 한 명인 싱글에서는 자신을, 자신과 아군이 있는 더블에서는 흉내낸 대상을 지정한다. 신규 도전의 `milkDrinkMirrorTargetRule: source-v1`은 이 차이를 우유마시기에 적용한다. 이전 도전은 기존의 사용자 회복을 유지한다.

격리 전투에서 양측 더블 흉내내기, 싱글 및 이전 도전, 저장 복원과 다른 데이터 보존을 확인했다. 지시로 아군을 회복했던 우유마시기를 반복할 때 기존 대상을 다시 회복하고 우유마시기 PP가 두 번 소비되는 경계도 검사했다. 해당 검사는 상대 기절·교체, 다른 호출 및 특수 기술의 모든 조합이나 원본 난수열, 실제 브라우저·모바일 조작의 동등성을 보장하지 않는다. 운영 데이터와 Sites는 변경하지 않았다.
