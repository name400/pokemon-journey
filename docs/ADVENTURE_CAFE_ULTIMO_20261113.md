# 카페 울티모 주문

[원작 카페 메뉴](https://bulbapedia.bulbagarden.net/wiki/Caf%C3%A9_Ultimo)와 [Serebii 메뉴](https://www.serebii.net/legendsz-a/cafes.shtml)는 일반 Ultimo Coffee 한 잔의 가격이 100,000원이며 파티 회복과 선두 친밀도 증가가 있다고 명시한다. 구역 15 기존 카페 주문대에 해당 메뉴를 추가했다. 이 게임에서는 기존 카페와 같이 HP·상태·PP를 회복하고 선두 친밀도를 1 올린다. 정확한 원작 친밀도 증가량과 PP의 원작 처리 범위는 확인하지 못했으며, 1 및 PP 회복은 기존 게임 규칙이다.

가격이 높아 브라우저에서 별도 확인을 요청하며 서버도 확인 여부, 지상 주문대 위치, 전투·포획 상태와 잔액을 검증한다. 기존 리비전과 원자적 지갑·포켓몬 갱신을 사용해 실패 및 오래된 중복 요청은 결제하지 않는다. 저장 형식은 변경하지 않는다.

격리 API에서 확인 생략, 99,999원 잔액, 정상 결제, 파티 회복, 친밀도와 연구 활동, 재접속, 오래된 중복 요청, 다른 위치·옥상과 진행 보존을 검사했다. 23개 구역·빠른 이동 단위 검사, 카페 관련 API 3개와 타입 검사가 통과했다. PC·모바일 Chromium의 모의 API 및 대체 이미지로 가격 표시, 확인 취소 시 요청 없음, 승인 시 확인된 요청을 검사했다. 운영 D1과 원작 기기는 확인하지 않았다. 카페 내부 및 사진 촬영, DLC 사이드 미션 176과 100만 원 메뉴는 미구현이다.
