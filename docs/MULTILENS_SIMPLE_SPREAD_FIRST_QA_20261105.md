# 멀티렌즈 매지컬샤인·하이퍼보이스 첫 타격

신규 도전의 멀티렌즈 첫 타격 순차 처리를 스피드스타 외 매지컬샤인과 하이퍼보이스로 확장했다. 두 기술은 고정 원본의 인접한 모든 상대 공격이며 대상별 추가 효과가 없다. 앞 대상의 실제 기절·생존을 확인한 뒤 다음 대상의 피해를 계산한다. 기존 `swift-source-v1` 저장의 범위는 스피드스타로 그대로 유지한다.

각 기술의 앞 대상 기절·생존·방어·기합의머리띠, 하이퍼보이스의 방음, 적 측 멀티렌즈와 codec 복원을 격리 검사했다. 파도타기는 여전히 새 순서 범위에 포함하지 않는다. 다른 전체 공격의 대상·부가 효과·도구·특성, 원본 난수열, 실제 사용자 플레이와 실기기는 별도다.
