# 하수도 지도 대조와 저장 이전 계획

## 확인한 범위

- [하수도 평면 이미지](https://github.com/Insektaure/Shiny-Stash-Live-Map/blob/main/romfs/Sewers.png)는 방과 연결 통로의 전체 윤곽을 보여 주지만, 출입구와 미션 지점의 이름은 표시하지 않는다.
- [미션 19 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-19-reaching-rank-d)은 분수 입구에서 잠긴 문과 클레피를 지나 얼음다리 분기, 조사실, 환상의 벽, Gwynn으로 이어지는 순서를 설명한다. [다른 공략](https://www.neoseeker.com/pokemon-legends-z-a/Main_Mission_19)은 조사실의 전기 패널·기계·파이프·상자가 각각 북서·남서·남동·북동에 있다고 설명한다.
- 현재 압축 맵의 조사실 타일은 위 방향을 반영한다. 방의 타일 크기와 전체 지도상 위치는 근사다. 블루 3 재진입은 본 하수도와 연결되지만, 분수 입구와 재진입 문의 이미지상 정확한 좌표는 아직 확인하지 못했다. 세종 운하 쪽은 별도의 하수도다. [출처](https://www.gamesradar.com/games/pokemon/full-pokemon-legends-z-a-map-and-all-locations/)
- 2026-11-15 독립 확인자가 전달한 시각 관찰: 분수 입구는 블루 포켓몬센터 부근, 재진입 지상 위치는 야생 구역 5 남동쪽 골목이다. 서쪽 방은 동쪽 출구에서 북쪽으로 꺾여 중앙 분기에 연결된다. 서쪽 지도에 표시된 빨간 표시는 입구가 아니라 폭포오르기 아이템이다. 이 관찰만으로 지하 출입구나 각 미션 지점의 정확한 좌표를 확정하지 않는다.
- 위 관찰에 해당하는 여섯 이미지가 Library에 확보되었지만 이 작업 환경에서는 파일 전달이 실패해 직접 대조하지 못했다. 텍스트 설명만으로 지형을 교체하지 않았으며, 이미지의 실제 판독과 기존 지도 좌표 대응이 필요하다. Library 전달이 가능한 환경에서 자료를 확인한 뒤 아래 이전 계획을 진행한다.
- 2026-11-15 재확인: `sewer-map.jpg`는 Library 준비 단계에서 JPEG 23,256바이트라는 메타데이터가 확인되었으나 직접 작업 공간 경로 대신 다운로드 전송이 발급되었다. 공식 전송 도우미는 새로 준비한 전송에 대해 `download failed`를 반환했다. 하위 HTTP 오류는 제공되지 않아 원인을 단정할 수 없으며, 파일 바이트를 받지 못해 형식과 SHA를 독립 검증하지 못했다.
- [하수도 설명](https://bulbapedia.bulbagarden.net/wiki/The_Sewers)은 분수 입구가 Ivor 승급전 승리 후 닫힌다고 설명한다. Gwynn 승리 후 승급전 전인 기존 미션 19의 단계 14에서도 분수로 돌아갈 수 있게 했고, 단계 15부터는 기존처럼 닫힌다. 지도 좌표는 변경하지 않았다. [별도 재진입 안내](https://www.powerpyx.com/pokemon-legends-z-a-how-to-return-to-lumiose-sewers/)의 블루 3과 위 자료의 블루 1 표기는 서로 달라 추가 확인이 필요하다.

## 전체 지형 교체 전 저장 이전 계획

1. 원작 지도에 입구, 잠긴 문, 얼음다리 분기, 조사실, 환상의 벽과 복귀 입구를 식별할 수 있는 영상 또는 위치 표기 자료를 확보한다. 평면 이미지만으로 이 대응을 추정하지 않는다.
2. 구형 저장은 기존 맵과 좌표를 그대로 사용하고, 신규 맵은 별도의 명시적 버전으로 구분한다. 미션 단계, 수집 기록, 공유 보유함을 재설정하지 않는다.
3. 이전이 필요하다면 각 구역의 확인된 연결 지점에서만 버전을 전환하고, 진행 단계별로 유효한 안전 지점을 지정한다. 알 수 없는 미래 버전은 자동으로 덮어쓰지 않는다.
4. 각 출입구 왕복, 잠긴 문·얼음다리·조사실·벽의 진행 경로, 구형 진행 중 저장과 이미 수집한 아이템, 저장 후 복귀를 대표 검사한다. 실제 병합본과 운영 검증은 별도로 기록한다.

## 2026-11-17 문 확인 전 서쪽 분기

[미션 19 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-19-reaching-rank-d)은 클레피를 잡고 잠긴 문을 연 뒤 갈림길과 얼음 다리 방으로 간다고 설명한다. 현재 압축 맵에서는 클레피 포획 직후의 `zaMission19GateScene: 0` 상태에서도 서쪽 분기 입구에 도달해 진입할 수 있었다. 해당 단계에서는 화면이 잠긴 문을 먼저 확인하도록 안내하고 서버도 분기 진입을 거절한다. 문을 확인하면 분기를 이용할 수 있으며, 문 확인 표식이 없는 이전 저장의 기존 동작은 유지한다. 이미 분기에 저장되어 있던 진행은 출구로 돌아갈 수 있고 얼음 다리·아이템 기록을 지우지 않는다. 지도 타일·기존 좌표 및 보상은 변경하지 않았다.

격리 API에서 문 확인 전 거절과 저장 불변, 확인 후 분기 진입·다리·아이템·재접속 및 클레피 포획 경로를 확인했다. 분기 내부에 저장된 상태의 출구는 지도 단위로 확인했다. 테스트 작성 중 구형 위치 저장을 재설정할 때 압축 전 좌표를 다시 지정하지 않아 검사 실패가 있었으며 올바른 좌표로 보정한 뒤 통과했다. 분기 출입 순서만 제한한 것이므로 현재 압축 지도에서 잠긴 문 주변의 다른 바닥이 물리적으로 모두 차단된 것은 아니다.

[지도 안내](https://www.gamesradar.com/games/pokemon/full-pokemon-legends-z-a-map-and-all-locations/)와 [연구소 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-35-reaching-rank-a)은 블루 본 하수도와 세종 운하의 분리, 연구소의 세 지하층과 승강기·귀환 경로를 설명한다. 현재 분리·경로의 대표 격리 검사도 통과했다. 구역별 타일 대응, 문 주변 충돌, 원작 맵 이미지상의 입구·미션 지점과 구형 저장의 정밀 대응은 여전히 미확인이며 추가 지형 교체를 하지 않았다. 원작 실기·운영 데이터·Sites는 검사하거나 변경하지 않았다.
