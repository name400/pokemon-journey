# 하수도 지도 대조와 저장 이전 계획

## 확인한 범위

- [하수도 평면 이미지](https://github.com/Insektaure/Shiny-Stash-Live-Map/blob/main/romfs/Sewers.png)는 방과 연결 통로의 전체 윤곽을 보여 주지만, 출입구와 미션 지점의 이름은 표시하지 않는다.
- [미션 19 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-19-reaching-rank-d)은 분수 입구에서 잠긴 문과 클레피를 지나 얼음다리 분기, 조사실, 환상의 벽, Gwynn으로 이어지는 순서를 설명한다. [다른 공략](https://www.neoseeker.com/pokemon-legends-z-a/Main_Mission_19)은 조사실의 전기 패널·기계·파이프·상자가 각각 북서·남서·남동·북동에 있다고 설명한다.
- 현재 압축 맵의 조사실 타일은 위 방향을 반영한다. 방의 타일 크기와 전체 지도상 위치는 근사다. 블루 3 재진입은 본 하수도와 연결되지만, 분수 입구와 재진입 문의 이미지상 정확한 좌표는 아직 확인하지 못했다. 세종 운하 쪽은 별도의 하수도다. [출처](https://www.gamesradar.com/games/pokemon/full-pokemon-legends-z-a-map-and-all-locations/)

## 전체 지형 교체 전 저장 이전 계획

1. 원작 지도에 입구, 잠긴 문, 얼음다리 분기, 조사실, 환상의 벽과 복귀 입구를 식별할 수 있는 영상 또는 위치 표기 자료를 확보한다. 평면 이미지만으로 이 대응을 추정하지 않는다.
2. 구형 저장은 기존 맵과 좌표를 그대로 사용하고, 신규 맵은 별도의 명시적 버전으로 구분한다. 미션 단계, 수집 기록, 공유 보유함을 재설정하지 않는다.
3. 이전이 필요하다면 각 구역의 확인된 연결 지점에서만 버전을 전환하고, 진행 단계별로 유효한 안전 지점을 지정한다. 알 수 없는 미래 버전은 자동으로 덮어쓰지 않는다.
4. 각 출입구 왕복, 잠긴 문·얼음다리·조사실·벽의 진행 경로, 구형 진행 중 저장과 이미 수집한 아이템, 저장 후 복귀를 대표 검사한다. 실제 병합본과 운영 검증은 별도로 기록한다.
