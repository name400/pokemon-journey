# 하수도 사건 위치 확인

하수도 남동쪽 슈퍼볼과 Hérup·메가거북손데스 사건이 모두 `o` 타일을 사용했다. 격리 API에서 슈퍼볼 앞에 있을 때 직접 `mission57Battle`을 요청하자 Hérup 전투가 시작되는 결함을 재현했다. 해당 의뢰 전투·대기 보상과 미션 22 사건·메가스톤은 이제 일반 하수도의 기존 사건 좌표에서만 처리한다. 얼음 갈림길과 안쪽 통로의 같은 타일도 사건으로 취급하지 않는다. 미션 22의 별도 수변 터널과 이전 저장의 진행·수령 대기는 유지한다.

격리 API에서 잘못된 위치의 전투·보상 요청 거절, 해당 슈퍼볼 수령, 기존 사건 위치에서 Hérup 보상·메가스톤 수령, 가방 한도·구형 보상 대기 및 미션 22 수변 출입을 검사했다. 최초에 실제 재현한 항목은 Hérup 전투이며 나머지는 같은 타일 검사에서 식별한 위험을 수정 후 검증한 것이다. 실제 Sites 병합본과 운영 D1은 확인하지 않았다.
