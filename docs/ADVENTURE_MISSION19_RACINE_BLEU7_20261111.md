# 미션 19의 Canari와 블로스터 분수

[미션 19 공략](https://strategywiki.org/wiki/Pok%C3%A9mon_Legends%3A_Z-A/Reaching_Rank_D)은 누보 카페의 단서 이후 라시느건설에서 Canari와 재대결하고 블로스터 분수에서 하수도로 향하는 순서를 설명한다. [세부 공략](https://pokemon.fandom.com/wiki/Pok%C3%A9mon_Legends%3A_Z-A/Walkthrough/Main_Mission_19_%E2%80%94_23)은 분수가 블루 구역 7의 포켓몬센터 옆이라고 설명한다.

기존 라시느건설 차고의 Canari와 재대결하고, 블루 구역 7 포켓몬센터 옆의 분수에서 냉동빔을 사용한 뒤 하수도로 출입할 수 있다. 하수도를 나올 때 들어온 분수로 되돌아간다. 이전 저장 및 진행을 위해 기존 공사 현장 재대결과 베르날 분수 출입구도 유지한다. 차고와 분수의 정확한 2D 좌표·분수 형상·하수도 입구의 고저차는 초안이며 원작의 자동 장면과 실제 동작을 재현하지 않는다.
