# 묘지 서쪽 입구의 Moire

[원작 사이드 미션 3 안내](https://www.thonky.com/pokemon-legends-z-a/side-mission-003-sableye-in-the-cemetery)는 의뢰인 Moire가 야생 구역 4의 서쪽 출입구 바깥에 있고 반지를 찾은 뒤 같은 출입구로 돌아와 보고한다고 설명한다. 기존 서쪽 입구에 인접한 막힌 화면 가장자리에 의뢰인을 추가하고 수첩의 안내도 맞췄다. 정확한 2D 타일과 도로의 크기는 원작에서 측정하지 않은 초안이다.

기존 루주 거리의 의뢰인도 유지해 이전 저장과 미수령 기력의조각을 보호한다. 두 위치는 동일한 의뢰 단계·보상·리비전을 사용하므로 별도 보상을 만들지 않는다. 기존 묘지 출입구와 저장 가능한 바닥 좌표는 바꾸지 않았다.

격리 SQLite API에서 서문 의뢰 수락, 묘지 진입, 깜까미 포획, 출구 왕복, 보고·보상·재접속·중복 요청, 기존 위치의 미수령 보상을 확인했다. 묘지와 주변 길의 대표 검사를 실행했고 PC·모바일 Chromium에서는 모의 API로 의뢰 대화와 새로고침을 확인했다. 실제 원작 기기, 운영 D1과 Sites 병합본은 검증하지 않았다.
