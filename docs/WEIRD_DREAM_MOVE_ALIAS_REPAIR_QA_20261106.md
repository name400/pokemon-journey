# 이상한 꿈의 기존 중복 기술 교정

과거 이상한 꿈 변환 직후 보상 화면에 머물러 있는 저장만 대상으로 한다. 같은 기술 ID이면서 영문·한국어 등 서로 다른 이름이 동일한 네이티브 기술 이름으로 확인되는 경우, 첫 슬롯을 유지하고 중복 슬롯을 제거한다. 기술 PP·PP업은 변경하지 않고 교정 전 기술 목록과 PP 정보를 같은 도전의 `dreamMoveAliasBackups`에 보관한다.

전투·다른 구간으로 진행된 저장, 진행 중인 선택, 융합, 스케치·슬롯별 PP, 기술 랜덤화, 미확인 기술·폼별 이름·비정상 백업 등은 자동 교정하지 않는다. 다른 저장 슬롯은 조회하거나 수정하지 않는다. 백업은 게임 화면 응답에 포함하지 않는다.

격리된 실제 이벤트·저장 코덱·다음 전투와 SQLite API를 검사했다. GET은 교정된 화면을 만들지만 DB에 쓰지 않는다. 이후 유효한 POST에서 교정과 백업이 해당 도전의 수정과 함께 저장되며, 실패한 요청이나 동시 수정 충돌은 기존 저장을 덮어쓰지 않는다. 운영 데이터는 직접 변경하지 않았다. 이미 다음 구간으로 진행한 저장과 근거가 불충분한 사례의 복구 방식은 남아 있으며, 운영·실기기 검증도 별도다.

## 진행된 저장의 사용자 확인 정리

변환 이후 출처를 확정할 수 없는 저장은 자동 변경하지 않는다. 파티 화면에서 서로 다른 표시가 동일한 원본 기술 ID와 이름으로 확인되는 경우에만 후보와 양쪽 이름을 보여준다. 사용자가 명시적으로 확인하면 뒤쪽 중복 칸만 지우고 기존 기술 목록, 원본 ID, PP와 PP업을 해당 도전의 복구 기록에 남긴다. 다른 파티원과 슬롯은 변경하지 않는다. 기존 복구 기록이 있거나 전투 스냅샷, 대화·선택 대기, 검증되지 않은 융합, 확인할 수 없는 스케치 슬롯, 기술 무작위화, 불명확한 이름 등이 있으면 후보 자체를 표시하지 않는다. 전투 스냅샷이 남아 있는 진행 저장의 복구는 여전히 미지원이다.

API 검사에서 읽기 전용 조회, 확인 누락, 성공 저장, 동시 수정 충돌을 검증했다. 브라우저 및 실제 사용자 저장에서의 검증은 하지 않았다.

## 검증된 융합체

명시적으로 확인된 DNA 융합체는 사용자 확인 정리를 지원한다. 융합 데이터가 손상되었거나 지원하지 않는 표현은 제외한다. 격리 검사에서 기증자 데이터, 기술 목록 백업과 PP를 보존하고 저장 복구 후 다음 전투 및 분리를 확인했다. 전투 스냅샷이 존재하는 저장은 여전히 제외한다. 검증된 융합·스케치 결합은 아래와 같이 지원한다. 브라우저 및 운영 저장 실사용은 미검증이다.

## 스케치 슬롯별 PP

스케치가 허용하는 동일 기술의 중복은 정상일 수 있으므로 자동 삭제하지 않는다. 슬롯별 PP가 온전하고 서로 다른 두 표시가 같은 기술 이름과 ID를 가리키는 한 쌍에 한하여 사용자가 PP를 확인하고 지울 슬롯을 직접 선택할 수 있다. 나머지 슬롯과 순서를 유지하며 원본 슬롯별 PP와 삭제된 위치를 복구 기록에 남긴다. 스케치 자체의 중복, 정확히 동일한 표시, 여러 중복 쌍, 손상·미지원 메타데이터와 미검증 융합 스케치는 제외한다. API에서 PP 비교 실패 시 저장 불변, 성공 시 선택 슬롯 및 복구 기록, 다음 전투 PP를 검사했다. 브라우저·운영 저장은 미검증이다.

## 융합과 스케치의 결합

기존의 검증된 DNA 융합과 슬롯별 PP가 확인된 스케치 조건을 함께 만족하면 사용자 선택 정리를 지원한다. 기증자 정보, 삭제 전 슬롯과 PP를 보존한다. 양쪽 슬롯 선택, 저장 복구, 다음 전투의 PP, 융합 분리 및 손상된 기증자와 전투 스냅샷 제외를 격리 검사했다. 운영 저장과 브라우저는 미검증이다.
