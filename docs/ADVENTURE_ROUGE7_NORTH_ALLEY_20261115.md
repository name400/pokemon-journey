# 루주 7번지 건물 사이 골목

[루주 7번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/rouge-sector-7.html)는 배틀 코트 북쪽의 건물 단지 두 부분 사이에 긴 골목이 있다고 설명한다. 2차 자료이며 정확한 너비와 좌표는 확인되지 않았다.

기존 북쪽 건물 블록에 보행 가능한 골목을 추가했다. 건물과 골목의 크기·접점은 압축된 2D 지도의 잠정 배치다. 기존 코트, 옥상 사다리, 의뢰 위치, 출입 조건과 저장 필드를 유지한다. 원작의 골목 아이템과 인물은 이번에 추가하지 않았다.

모바일 이동 오류와 Sites 병합본 실패 기록은 운영 재검증 전이므로 유지한다.
