# 블르·마젠타 포켓몬센터 상점

원작의 [블르 포켓몬센터 판매 목록](https://www.serebii.net/pokearth/lumiosecity/southboulevard.shtml)과 [센터 안내](https://sportsrant.indiatimes.com/gaming/pokemon-legends-za-every-pokemon-center-location-in-lumiose-city/articleshow/126645919.html)에 따라 기존 블르·마젠타 센터 옆에 공통 프렌들리숍을 연결했다. 기존 게임의 구매·판매·하이퍼볼 조건과 재고·지갑 처리를 사용한다. 몬스터볼 가격은 출처가 엇갈려 변경하지 않았다.

상점 칸은 각 지도에서 기존에 막혀 있던 건물 타일을 사용한다. 원작의 정확한 점원 위치가 아닌 2D 초안이며 기존 센터·입구·저장 좌표는 옮기지 않았다. 블르 옥상 지도는 바꾸지 않았다. 격리 SQLite API에서 두 센터의 상점 접근·구매·재접속·중복 요청·기존 회복 및 도보 접근을 확인했고, 두 지역과 빠른 이동의 대표 지도 검사를 실행했다. 원작 기기·운영 D1·실제 Sites 병합본은 검증하지 않았다.
