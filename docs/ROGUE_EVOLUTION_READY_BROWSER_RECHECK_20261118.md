# 진화 가능 안내 브라우저 재검사 — 2026-11-18

소유권을 확인한 전용 격리 Vite 서버와 Chromium에서 불꽃의돌 보상 시험 상태를 사용했다. 390×844 모바일 세로와 1280×800 PC 크기에서 이브이는 도구 획득 전 진화 가능 배지·알림이 없고 부스터 진화 버튼은 비활성이며 필요한 도구 안내가 보였다. 새로고침 후에도 같은 화면 상태와 시험 저장이 유지됐다.

실제 화면의 보상 선택을 실행하면 진화 가능 알림이 표시되고 새로고침 후에도 유지됐다. 알림을 통해 파티에 들어가면 진화 가능 배지와 활성 부스터 버튼이 표시되며, 버튼으로 진화한 뒤 저장의 종과 도구 소모를 확인했다. 다시 새로고침한 파티에서도 부스터가 표시되고 저장·다른 슬롯·탐험 데이터가 보존됐다. 두 화면 크기 모두 통과했고 이 표본에서 추가 결함은 재현되지 않아 게임 코드는 수정하지 않았다.

이 검사는 실제 UI와 컨트롤러·저장 codec을 쓰는 합성 시험 데이터이며 보상 생성부터의 자연 진행은 아니다. 외부 포켓몬 이미지는 대역이다. 실제 기기·다른 진화 조건과 모든 화면 크기·운영 저장은 확인하지 않았고 Sites에 배포하지 않았다.
