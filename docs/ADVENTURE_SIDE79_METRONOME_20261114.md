# 사이드 미션 79: 운명의 손가락흔들기

[의뢰 자료](https://www.serebii.net/legendsz-a/sidemissions/afatefulswingofametronome.shtml)와 [공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_61-80#Side_Mission_079:_A_Fateful_Swing_of_a_Metronome)에 따라 미션 26의 의상 획득 후 Furiko에게 의뢰를 받고 손가락흔들기만 가진 삐삐 둘(Lv.51)과 픽시(Lv.52)를 상대한다. 승리 후 1,400원과 기술머신 099를 별도로 받는다. 기권·패배 후 다시 도전할 수 있고 보상 공간이 부족하면 수령을 보류한다. 확인하지 못한 별도 배틀 상금은 지급하지 않는다.

기술머신은 [Z-A 학습 자료](https://www.serebii.net/attackdex-sv/metronome.shtml)에서 확인한 일부 기본 종에 연결했다. 기술머신은 재사용 가능하며 미보유·중복 학습과 확인되지 않은 폼을 기존 서버 규칙으로 거절한다. 다른 학습 종과 폼은 추가 대조가 필요하다. 기존 저장·포켓몬은 이주하지 않는다.

Furiko의 위치는 이베르날 대로 2D 지도의 임시 좌표다. 원작의 실시간 전투 대신 기존 턴제 엔진의 손가락흔들기를 사용하며 호출 가능한 기술 목록과 상대 교체 방식은 원작과 다를 수 있다. 두 출처는 각각 의상 획득과 Lebanne 대결 후 해금을 설명하므로 이 게임에서는 의상 획득 직후를 적용했다.

격리 SQLite API에서 해금·편성·실제 손가락흔들기 사용·기권·재도전·재접속·승리·가방 한도·중복 수령과 기술머신 학습·이로치·지닌 도구 보존을 확인했다. 승리 검사는 상대의 HP와 상태를 조정했으므로 자연 난이도 검사는 아니다. 기술머신의 대표 호환·비호환과 수첩 단계별 표식도 검사했다. 실제 원작 기기·운영 D1·Sites 병합본과 PC·모바일 화면은 미검증이다.
