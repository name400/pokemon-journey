# 베르날 애비뉴와 남쪽 큰길 연결

[베르날 애비뉴 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vernal-avenue.html)는 남쪽 끝이 남쪽 큰길이라고 설명하고, [남쪽 큰길 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/south-boulevard.html)도 베르날 애비뉴를 인접 구역으로 기록한다. 지상 화면 사이 양방향 경로를 추가했다. 출입 좌표와 길의 선형은 2D 초안이다.

기존 출입과 저장 형식을 유지하고, 옥상·물가 및 알 수 없는 층 상태는 이 경로로 덮어쓰지 않는다. 원작 실기와 실제 Sites 병합본은 확인하지 않았다. 모바일 이동 오류 기록은 운영 재검증 전까지 유지한다.
