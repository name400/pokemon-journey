# 팔레 통로의 피카츄 교환

[팔레 통로 자료](https://bulbapedia.bulbagarden.net/wiki/Passage_du_Palais)와 [사이드 미션 2 안내](https://www.thonky.com/pokemon-legends-z-a/side-mission-002-a-use-for-an-evolution-stone)는 Tracie가 해당 쇼핑 통로에서 피카츄와 헤라크로스를 교환한다고 설명한다. 기존 통로의 막힌 상점 건물 칸에 의뢰인을 두고 의뢰 수락·선택 교환·기존 보상 수령과 수첩을 연결했다. 화면의 타일 좌표는 원작에서 측정하지 않은 2D 추정이다.

이전 버전의 야생 구역 3 의뢰인도 그대로 사용하므로 이미 시작한 저장과 미수령 볼·상처약은 어느 지점에서도 이어진다. 두 위치는 같은 저장 플래그와 리비전으로 처리하며 별개의 교환이나 보상을 만들지 않는다. 기존 여행 수첩이 응답에 없는 타일 속성에 의존해 실제 교환 선택기가 나타나지 않던 문제도, 서버가 확인한 의뢰인 표식을 사용하도록 수정했다. 기존 통행 가능한 칸과 구역 출입 경로는 바꾸지 않았다.

격리 SQLite API에서 통로 입구부터 도보 접근, 의뢰 수락·교환·상처약 및 보관 볼 지급·재접속·중복 요청과 기존 위치에서의 보상 수령을 확인했다. 통로의 양쪽 길과 옛 저장 좌표 및 목적지 검사가 통과했다. PC·모바일 Chromium에서 모의 API로 수첩 선택·교환 요청·새로고침을 확인했다. 실제 원작 기기, 운영 D1과 Sites 병합본은 검증하지 않았다.
