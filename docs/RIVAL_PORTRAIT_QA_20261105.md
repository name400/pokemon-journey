# 라이벌 기본 아이콘 교체

기준 `1dcfdce`. 라이벌 생성 함수가 1~6차전 모두 `fallback.svg`를 저장했고 대사만 `rival-local.svg` 임시 그림을 사용했다. 원본 코드 `7c0881255af5cd51992e513ff93c2f71adbe40e0`의 trainer-config는 Finn/Ivy의 `rival_m`/`rival_f` 자산을 사용한다.

원본 assets 서브모듈 `fb8ccb6d0703ffe48cdf80a8102d5ed943c82dba`의 두 PNG를 수정 없이 로컬에 포함했다. Git blob SHA와 크기 검증, 직접 이미지 확인을 수행했다. 출처와 각 SHA는 `data/rogue-rival-asset-provenance.json`에 기록했다. 남자 이미지는 69×69, 여자 이미지는 70×70이다. 해당 원본 images/REUSE.toml에는 이 PNG들의 개별 제작자/라이선스 항목이 없으므로 이웃 JSON의 라이선스를 PNG에 추정 적용하지 않았다.

새 라이벌은 현재 남성 대사 기본값과 일치하는 남성 이미지를 쓴다. 기존 저장의 기본/임시 아이콘은 읽기용 화면에서 저장된 `gender:F`, `variant:1/female`을 존중하여 여자 이미지로 표시한다. 표시 때문에 난수를 소비하거나 파티·라이벌 선택·저장을 재작성하지 않는다. 이미 지정된 다른 초상과 일반 트레이너는 보존한다. 성별 선택 UI나 임의 성별 추첨을 새로 추가한 것은 아니다.

`tests/rogue-rival-portrait.test.mjs` 3/3 통과: 자산 해시/크기, 기존 저장 불변·남녀/일반/지정 초상 경계, 실제 6회 라이벌 생성과 legacy view/대사 복구. 실제 브라우저 헤더·대사와 실패 처리는 이번 통합 화면 검사 기록을 따른다. Sites 저장·배포 및 운영 저장 수정은 하지 않았다.

브라우저 시각 검토에서 기존 대사 초상의 확대/상향 이동이 작은 원본 라이벌 얼굴을 잘라내는 것도 확인했다. 두 라이벌 PNG에만 변형을 해제해 얼굴과 전신을 유지하며 다른 트레이너의 기존 초상 표현은 보존한다.
