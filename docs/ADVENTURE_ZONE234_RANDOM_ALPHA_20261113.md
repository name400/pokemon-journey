# 야생 구역 2–4의 무작위 우두머리

[Serebii 구역 2](https://www.serebii.net/pokearth/lumiosecity/wildzone2.shtml), [구역 3](https://www.serebii.net/pokearth/lumiosecity/wildzone3.shtml), [구역 4](https://www.serebii.net/pokearth/lumiosecity/wildzone4.shtml)의 일반 개체별 우두머리 확률 5%와 레벨 범위를 기존 풀밭 조우에 적용했다. [우두머리 설명](https://www.serebii.net/legendsz-a/alphapokemon.shtml)에 따른 구역 조사 완료와 미션 5 완료를 요구한다. 이전 저장의 미션 6 시작도 미션 5 완료의 증거로 인정한다. 구역 조사는 현재 게임의 해당 종 도감 기록을 사용한다.

이 게임에서는 풀밭에서 새 전투가 생성될 때 판정한다. 이미 생성된 필드 개체·고정 우두머리·미션 조우는 바꾸거나 재추첨하지 않는다. 원작의 화면상 실시간 개체 생성과 정확히 같은 방식은 아니며, 개별 우두머리 전용 기술도 기존 구현 범위를 따른다. 구역 2 거북손손은 원작 표에 위치별 17–19와 18–20 범위가 있으나 이 게임은 해당 출현 지점들을 구분하지 않아 17–19로 임시 처리했다.
