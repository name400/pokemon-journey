# 신규 탐험 전투의 메가링 조건

[공식 메가진화 안내](https://legends.pokemon.com/en-gb/mega-pokemon)에 따르면 트레이너의 키스톤과 포켓몬의 메가스톤이 함께 필요하다. 기존 신규 탐험 전투는 메가스톤만 있으면 링이 없는 플레이어도 메가진화 명령을 사용할 수 있었다.

새 ZA 일반·동료·삼중 전투가 시작될 때 메가링을 갖고 있지 않으면 플레이어의 메가진화 선택과 명령을 막는다. 이 제한은 전투 스냅샷에 기록해 재접속에도 유지한다. 스토리 대여 전투, 다른 트레이너의 변신, 연합·원정, 포켓로그 및 이미 진행 중인 전투는 기존 규칙을 유지한다. 포켓몬이 지닌 메가스톤과 기존 저장은 변경하지 않는다. 룰 표식이 없는 알 수 없는 기존 전투를 추정하여 소급 수정하지 않는다.

격리 API에서 링 미보유 초반 전투의 선택 표시·명령 거절·재접속·포켓몬 도구 보존, 메가링을 보유한 미션 26, 미션 37 동료 메가진화를 확인했다. 단일·동료·삼중 전투의 링 미보유 명령 및 동료 변신을 단위 검사했다. 전체 검사·실제 기기·운영 D1·Sites 병합본은 이번에 확인하지 않았다.
