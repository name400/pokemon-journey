# 탐정사무소 지도 이동

- [미션 19 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-19-reaching-rank-d)은 탐정사무소로 지도 이동하는 경로를 설명한다. 원작의 최초 등록 시점은 이 자료만으로 확인하지 못했다.
- 이 구현은 기존 사무소 방문 플래그를 잠정 등록 기준으로 사용한다. 구형 저장은 기존 의상점 해금과 같은 Emma 만남·후속 미션·랭크 증거로 방문을 추론한다. Emma를 만나기 전 사무소만 방문한 구형 저장에 증거가 없으면 재방문이 필요하다.
- 도착점은 기존 루주 5번지 초안의 사무소 출입구 앞이며 원작의 정확한 좌표가 아니다. 택시 경로는 확인되지 않아 추가하지 않았다. 저장된 랜드마크 목록은 수정하지 않는다.
- 기존 Sites 병합본과 실제 모바일 환경은 이 변경으로 검증하지 않았다. `testfailed.md`의 미검증 기록을 유지한다.
