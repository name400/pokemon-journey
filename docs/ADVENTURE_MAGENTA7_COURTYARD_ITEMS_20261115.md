# 마젠타 7번지 남쪽 안뜰 도구

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/magenta-sector-7.html)는 남쪽 건물 안뜰의 잠깨는약과 고급상처약을 기록한다. 기존 안뜰에 각각 하나씩 배치하고 수집·재고를 연결했다. 2차 자료이며 정확한 좌표와 지형은 2D 초안이다.

구형 저장의 위치를 유지하고 수집 기록이 없는 저장은 두 도구를 받을 수 있다. 가방 제한으로 잠깨는약을 받지 못한 경우 기록하지 않으며 이미 받은 도구의 중복 획득을 막는다. 실제 라우터의 재고 한도·중복 요청·저장 검사와 지도·기존 저장 검사를 통과했다. 원작 기기와 운영 Sites는 검사하지 않았다. 모바일 D1 이동 오류 기록은 운영 재검증 전 유지한다.

북쪽 안뜰의 불꽃 장애물·옥상, 남쪽 건물 옥상과 나머지 지상 도구는 미완성이다.
