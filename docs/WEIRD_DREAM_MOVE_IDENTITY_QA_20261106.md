# 이상한 꿈의 기술 중복 판정

고정 원본은 알기술과 새 종의 기술을 기술 ID로 비교한다. 기존 구현은 문자열을 비교해 같은 기술이 영문과 한국어로 저장됐을 때 중복 추가할 수 있었다. 신규 도전은 확인 가능한 기술 ID로 중복을 판정하고 알기술을 재추첨하거나 다른 생성 기술을 선택한다. 이전 도전은 기존 규칙을 유지한다.

실제 이벤트 후보 준비에서 `Supercell Slam`과 `썬더다이브`가 중복되는 사례를 재현하고, 수정 후 다른 알기술을 고르는 것을 확인했다. 일반·융합 파티의 변환, 기존 PP와 PP업의 준비 단계 보존, 실제 이벤트의 원본 전체 회복, 저장 복구와 다음 전투, 다른 슬롯·탐험 데이터 보존을 격리 검사했다. 기존에 이미 중복된 저장 기술은 임의로 삭제하지 않는다. 이름을 해석할 수 없는 기술은 기존 문자열 비교를 유지한다.

코드 변경과 별개로 융합 파티의 이상한 꿈 전투 승리 후 도전 전용 패시브 지급·복구를 [WEIRD_DREAM_FUSION_PASSIVE_QA_20261106.md](WEIRD_DREAM_FUSION_PASSIVE_QA_20261106.md)에서 검사했다. 기존 중복 저장의 안전한 교정, 다른 폼·패시브 복합 조합, 원본 RNG 스트림 전체 및 운영·실기기 플레이는 별도 작업이다.
