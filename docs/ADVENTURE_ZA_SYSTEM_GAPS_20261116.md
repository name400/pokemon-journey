# 탐험·모험의 원작 시스템 차이 (2026-11-16)

사용자 정정에 따라 전투는 기존 턴제를 유지한다. 포켓로그와 공통 대전은 별도 범위다. 이 목록은 확인한 차이와 작업 순서이며 완성도 전수 조사 결과가 아니다.

1. **전투 특성**: [ZA 공략의 전투 시스템](https://www.pokemon-france.com/en/guides/pokemon-legends-z-a/battle-system/)은 일반 특성이 없고 일부 포켓몬의 고유 동작은 남는다고 설명한다(2차 자료). 현재 `lib/party-battle.mjs`의 `teamSet`은 저장된 특성을 시뮬레이터에 전달한다. 격리 전투에서 특성 부유를 가진 저리더프가 지진에 피해를 받지 않는 것을 확인했다. 기존 저장이나 진행 중 전투를 바꾸지 않으면서 신규 탐험 전투에서 일반 특성을 억제하려면 폼·고유 효과와 메가진화 예외 및 일반·동료·삼중 전투를 함께 조사해야 한다. 후속으로 신규 ZA 일반·동료·삼중 전투에서 부유·정전기·위협·프레셔·심록·맹화·급류·피뢰침·축전·저수·타오르는불꽃 11종을 시뮬레이터 입력에서만 억제한다. 저장된 특성과 기존 전투는 보존하고 확인된 킬가르도·따라큐·모르페코 고유 효과와 미검토 특성은 유지한다. 이 범위는 전체 특성 억제가 아니다. 메가진화가 시뮬레이터 특성을 새로 부여하는 경우, 별도 단일 전투 생성 경로 및 구형 로컬 탐험 경로는 미적용이다.
2. **메가파워**: 같은 자료는 메가파워가 충전되고 메가진화 중 감소해 소진 시 원래 모습으로 돌아간다고 설명한다. 현재 `adventurePlusGaugeV1`은 세 칸 충전과 기술플러스·메가진화에 쓰이지만 기존 턴제 시뮬레이터의 메가진화는 해당 실시간 소진 규칙과 같지 않다. 턴제에 맞는 소진 단위는 원작에서 직접 정해지지 않으므로 근사 규칙의 설계와 검증이 필요하다. 기존 전투의 변신을 임의 종료하지 않는다.
3. **지형**: 구역 10은 수로·서쪽 출입·동쪽 출입·옥상을 압축해 구현했다. [구역 공략](https://www.nintendolife.com/guides/pokemon-legends-z-a-wild-zone-10-guide-all-pokemon-and-alphas)은 서쪽 높은 옥상과 동쪽 옥상을 설명하지만, 현재 동서 연결과 층 높이·좌표는 원작에서 직접 확인되지 않은 근사다. 구형 저장 복원을 포함한 기존 지형을 유지하고 원작 화면과 출입 대응을 확보한 후 수정한다. 하수도 전체 좌표도 미확인이다.
4. **시간**: 실내·야생 전투의 정지 범위는 별도 구현됐지만 메뉴·지도와 다중 탭·연결 상실의 안전한 시간 정지는 보류 중이다. 동일 계정의 충돌·복구와 원작 동작을 함께 확인해야 한다.
5. **검증**: 본 문서 작성 시 전체 게임을 한 저장으로 처음부터 후일담까지 완료하거나 운영 Sites 병합본을 검증하지 않았다. 기존 `testfailed.md` 배포 실패 기록을 유지한다.

우선순위는 1의 원작 특성 예외 조사와 저장·전투 경계 설계, 2의 턴제 근사 설계, 충분한 자료가 확보된 구역의 3 순서다. 이 기록만으로 원작 시스템을 구현했다고 간주하지 않는다.
