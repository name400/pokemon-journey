# 팔레 통로 미용실

[미용실 위치와 서비스 안내](https://www.pokepedia.fr/Salon_de_coiffure)는 팔레 통로에 미용실이 있으며 각 매장의 서비스와 3,000원 요금이 같다고 설명한다. 기존 통로 지도에 미용실을 추가하고 다른 미용실과 같은 머리 모양·색상 선택 및 저장·결제에 연결했다. 미션 12·51의 기존 색상 해금도 공유한다.

통로의 점포 표식과 미용실 위치는 현재 2D 지도에 맞춘 추정이며 원작의 정확한 좌표나 실내를 재현하지 않는다. 헤어 옵션과 픽셀 표현은 기존에 구현된 일부에 한정한다. 원작 자료는 2차 출처이며 원작 실기는 확인하지 않았다.

격리 검사에서 기존 출입구·상점·교환 의뢰, 미용실 접근·결제·색상 해금 제한·중복 요청과 다른 미용실에서의 외형 복원, 파티 보존을 확인했다. 실제 운영 D1·기기·Sites 병합본은 확인하지 않았다.
