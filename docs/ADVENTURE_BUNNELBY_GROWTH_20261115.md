# 미션 3 파르빗 계열 성장 기술

[파르빗](https://pokemondb.net/pokedex/bunnelby/moves/9)과 [파르토](https://pokemondb.net/pokedex/diggersby/moves/9)의 Z-A 기술표에 따라, 미션 3을 포함해 새로 포획한 기본 폼의 성장·다시 배우기와 파르토의 진화 기술 땅고르기를 연결했다. 레벨 상승 시 기존 네 기술과 PP를 보존하며 자리가 없으면 기존 기술 선택 대기열을 사용한다. 기존 개체, 알 수 없는 버전 표식과 미확인 폼은 이전 처리대로 둔다. 새로 만나는 야생 개체가 처음 가진 기술은 이번에 변경하지 않았다.

두 자료는 2차 자료이며 원작 기기에서 독립 대조하지 않았다. 격리 API에서 미션 3 포획·재접속·사탕 성장·기술 선택 대기·진화와 개체 정보 보존을 확인했고, 레벨 경계와 이전 저장을 단위 검사했다. 운영 D1과 Sites 병합본은 검증하지 않았다.

후속으로 구역 1과 5에서 새로 발생하는 일반 파르빗 조우에도 위 표를 연결했다. 해당 레벨 이하의 마지막 네 기술을 고르는 방식은 이 프로젝트의 잠정 규칙이며 원작 개체별 초기 기술은 실기에서 확인하지 않았다. 이미 저장된 개체·진행 중인 조우, 우두머리 및 별도 이벤트 전투는 변경하지 않는다.
