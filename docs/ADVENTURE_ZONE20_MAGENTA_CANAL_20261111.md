# 구역 20 서쪽 운하 연결

[원작 구역 자료](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_20)는 구역 20의 서쪽 입구가 마젠타 측 세존 운하에 이어진다고 설명한다. 기존 구역 20 서쪽에 별도 출구를 열고 마젠타 운하 지도와 실제 왕복 이동으로 연결했다. 본편 종료 및 미션 42 단계의 입장 조건은 기존 방향별 출입구와 같다. 걸어서 처음 진입할 때도 기존 방식대로 중앙 우두머리 두 개체를 선정한다.

접점·통로 폭과 정확한 좌표는 2D 초안이다. 이전 저장과 이동을 위해 기존 센트리코 서쪽 출구와 출입구는 유지한다. 새 접점은 경계와 기존 통행 바닥을 사용해 기존 저장 좌표를 막지 않는다. 구역 20과 마젠타 운하의 왕복, 입장 제한, 우두머리 선택, 기존 출구, 저장 복원과 파티·도구 보존을 격리 검사했다. 동쪽 베르 측 운하와 실제 거리의 세부 접점, 정밀한 원작 지형 및 운영 기기 검증은 남아 있다.
