# 베르 9번지 북쪽 지상 접근

[베르 9번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-9.html)는 북쪽의 베르 4번지와 북동쪽의 베르 5번지 접근을 설명한다. [베르 4번지](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-4.html)와 [베르 5번지](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-5.html) 안내도 각각 9번지로의 접근을 명시한다.

기존 세 지상 화면 사이에 두 왕복 경로를 추가했다. 출입 좌표와 길의 폭·선형은 원작에서 측정하지 않은 2D 추정이다. 4번지로 들어갈 때 지상층을 명시하며 기존 옥상·안뜰은 그대로 둔다. 9번지 수로와 다리, 8번지·야생 구역 1 및 이전 통행 위치와 저장 형식도 유지한다.

대표 지도 검사에서 두 경로의 왕복·저장 복원과 진행값, 수로·다리, 옥상 경계와 기존 연결을 확인했다. 원작 실기·운영 D1·실제 Sites 병합본은 확인하지 않았으며 모바일 이동 오류와 배포 검사 실패 기록을 유지한다.
