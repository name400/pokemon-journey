# 세 자리 배틀의 노력치

세 자리 전투는 기존 단일·다수 상대 전투와 달리 상대 기절 이벤트를 노력치 처리에 넘기지 않아, 새 르 예 코스와 미션 35·36·37 등의 전투에서 쓰러뜨린 상대의 노력치가 지급되지 않았다. 새 세 자리 전투에 기존 노력치 기록을 연결해 상대별 기절 시점에 살아 있는 플레이어 소유 포켓몬에만 지급한다. 파워 도구와 총량 제한, 중복 지급 방지, 기술·HP 복원은 기존 규칙을 사용한다. 동료와 내부 빈 슬롯은 지급하거나 보유함에 저장하지 않는다.

버전 표식이 없는 진행 중 구형 전투는 기존 규칙을 유지한다. 과거 전투의 기절 이력은 추정해 지급하지 않는다. 원작의 실시간 동시 전투에서의 세부 노력치 규칙을 새로 확정한 것은 아니며, 현재 게임의 다른 턴제 전투와 일관되도록 처리한다.

격리 SQLite API에서 르 예의 개별 기절·파워 도구·재접속·이전 리비전 거절·기권과 구형 전투를 확인했다. 세 동료 엔진에서 동료가 쓰러뜨린 상대, 소유권과 빈 슬롯을 별도로 검사했으며 기존 단일·다수 배틀 및 세 자리 전투 회귀를 대표 확인했다. 운영 D1·Sites 병합본과 원작 기기는 검사하지 않았다.
