# 블루 6번지 두 안뜰

[블루 6번지 지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-6.html)는 서쪽과 동쪽 건물 단지에 각각 안뜰이 있다고 설명한다. 이는 2차 자료이며 각 안뜰의 정확한 윤곽과 출입구는 확인되지 않았다.

기존 두 건물 블록에 지상 안뜰과 접근로를 추가했다. 크기와 입구는 압축된 2D 지도의 잠정 배치다. 기존 비계, 주변 구역 출입, 의뢰 좌표와 저장 필드를 유지하며 다른 에스티발 지도에는 적용하지 않는다. 안뜰 아이템과 옥상은 이번에 추가하지 않았다.

모바일 이동 오류와 Sites 병합본 실패 기록은 운영 재검증 전이므로 유지한다.
