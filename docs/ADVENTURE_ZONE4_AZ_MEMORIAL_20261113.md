# 구역 4 공동묘지의 본편 이후 묘

[원작 지역 설명](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_4)은 묘비와 작은 묘실 사이의 길, 남쪽 건물과 벽의 페이검, 본편 사건 뒤 공동묘지 안쪽에 세워진 A.Z.의 원형 묘비와 꽃을 설명한다. 기존 세 출입구·묘비 길·묘실 및 가시덤불 경로는 이미 구현돼 있었으나 본편 이후 묘를 확인할 수 없었다.

미션 38 완료 상태에서 공동묘지 안쪽의 기존 묘비 하나를 원형 기념비와 꽃으로 표시하고 가까이에서 기록을 읽을 수 있게 했다. 다른 묘비에는 볼·꽃 무늬를 구분하고 남쪽 묘실의 벽도 표시했다. 새 충돌 타일이나 보상·저장 플래그를 만들지 않아 이전 저장 위치, 이동, 출입구, 야생 조우와 미수령 도구를 유지한다.

묘비의 위치·비율, 묘비 문양과 묘실 벽 표현은 2D 초안이다. 자료에 높이와 정밀 평면이 없어 새 높이층을 만들지 않았으며, 원작의 전체 장례 장면이나 정확한 묘비 문구를 재현한 것은 아니다. 이전 미션 완료 저장도 별도 이행 없이 표시한다.

구역 단위 검사와 격리 SQLite API에서 완료 전후 표시·상호작용, 재접속, 세 출입구, 구형 저장, 덤불 보상과 풀숲 조우를 확인했다. PC·모바일 Chromium은 모의 API 및 대체 이미지로 확인했으며 원작 실기기와 운영 환경은 확인하지 않았다.
