# 블루 8번지 안뜰 도구와 바닥

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-8.html)는 안뜰의 슈퍼볼·고급상처약·좋은상처약·하이퍼볼을 기록한다. 2차 자료이며 원작 기기에서 대조하지 않았다. 기존 안뜰 바닥을 도로와 구분해 표시하고 네 도구를 연결했다. 안뜰 윤곽과 입구 및 도구의 격자 좌표는 압축된 2D 초안이다.

기존 통행 가능 칸과 쇼 접수·미용실 표식, 출입 및 이전 저장 위치를 보존한다. 네 도구 수집, 볼 보관 한도, 중복 요청, 이전 저장 복원과 쇼 진행 보존을 대표 검사했다. 옥상과 나머지 지상 도구는 미완성이다. 모바일 D1 이동 오류와 Sites 병합본은 운영 재검증 전이므로 실패 기록을 유지한다.
