# 사탕 사용 시 공유 성장 정보 보호

이상한사탕과 경험사탕을 사용하기 전 공유 보유함의 원본 및 정규화된 개체에서 레벨·경험치·노력치·친밀도 형식을 확인한다. 유효하지 않은 레벨 또는 음수·문자열 경험치 등을 임의로 변환하지 않고 요청 전체를 거절해 사탕과 개체를 보존한다. 경험치가 없는 구형 저장은 기존처럼 0부터 시작한다. 기존 포켓몬·저장을 일괄 변경하지 않으며 포획·전투·이동의 처리나 다른 게임의 경험치 엔진은 바꾸지 않는다.

수정 전 격리 API에서 레벨이 문자열인 개체에 이상한사탕이 소모되면서 레벨이 오르지 않는 상황을 재현했다. 수정 후 두 사탕에 대해 비정상 성장·노력치 형식의 거절과 개체·재고·리비전 보존, 정상 사용·재접속·오래된 요청과 구형 저장을 대표 검사했다. 이는 운영 D1이나 실제 Sites 병합본 검증이 아니다. 다른 성장 경로의 모든 비정상 저장을 보호한다는 뜻도 아니다.

## 알 수 없는 기술 선택 대기 기록

사탕·포획 경험치·전투 승리 등으로 새 기술 선택을 추가할 때, 기존 대기 기록이 배열이 아닌 알 수 없는 형식이면 빈 배열로 덮어쓰지 않고 해당 요청을 거절한다. 저장이 없거나 null인 구형 상태와 기존 배열은 이전처럼 처리한다. 알 수 없는 형식이 실제로 존재하는 저장에서는 새 기술 선택이 필요한 행동이 제한되며, 이전 버전이 그 기록을 추측해 복구하지 않는다. 일반 이동이나 기술 선택이 필요 없는 성장의 계산은 바꾸지 않는다.

수정 전 격리 API에서 이상한사탕을 사용할 때 미래 형식 기록이 사라지는 것을 재현했다. 수정 후 사탕과 포획 요청의 대기 기록·포켓몬·재고·리비전 보존, 승리 직전 전투의 스냅샷 보존, 구형 null 기록의 정상 성장·재접속·중복 요청을 확인했다. 운영 D1·실제 Sites 병합본은 검증하지 않았다.
