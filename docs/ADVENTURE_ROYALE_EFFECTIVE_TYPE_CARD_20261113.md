# 타입별 효과가 굉장한 공격 보너스 카드

[원작 카드 목록](https://bulbapedia.bulbagarden.net/wiki/Bonus_card)에 있는 타입별 효과가 굉장한 공격 1회 목표와 티켓포인트 500점·메달 50개 보상을 추가했다. 노말 타입은 상성상 효과가 굉장한 공격이 불가능하므로 제외하고 17개 타입을 밤마다 순환시키며 기존 세 장 제한, 교체, 밤 종료, 승급과 보상 중복 방지를 재사용한다. 카드 위치·타입 순환과 랭크별 제공 시점은 현재 2D 배틀존의 초안이다. 원작은 실시간 배틀이므로 이 게임에서는 아군이 직접 사용한 기술이 상대에게 효과가 굉장한 피해를 한 번 주면 달성한다.

기존 카드 저장·점수·메달과 다른 포켓몬 데이터는 변경하지 않는다. 활성 카드는 기존 추가 카드 저장 필드에 식별자별로 기록하며, 이전 카드의 진행은 유지한다. 격리 검사에서 17개 타입과 무효·일반 피해·다른 타입을 검사했고, SQLite API에서는 실제 전투, 보상, 재접속, 낡은 요청과 새 카드 교체를 확인했다. 원작 기기, 운영 D1과 Sites 병합본은 검증하지 않았다.
