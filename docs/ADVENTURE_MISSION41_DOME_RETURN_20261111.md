# 미션 41 돔 재접근

[원작 미션 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-41-the-one-that-takes)은 돔의 목적지를 조사한 뒤 다시 로토글라이드로 돔에 접근해 이벨타르와 대결하는 흐름을 설명한다. 기존 구현의 조사 후 즉시 조우를 바꾸어, 플레이어가 직접 돔에서 발판으로 돌아가고 다시 돔으로 활공한 뒤 조우하도록 연결했다. 조사 직후 대기 상태와 복귀 여부는 저장되며, 기존에 조사한 저장이나 조사 플래그가 없는 구버전 저장은 새 절차로 되돌리지 않는다. 루주 거리의 기존 임시 조우 경로는 호환을 위해 유지한다.

돔·발판의 정확한 좌표와 원작 장면의 물리·연출은 초안이다. 자동 이동을 추가하지 않았고 로토글라이드의 일반 이동 규칙은 유지한다. 이 항목이 이전 돔 조사 문서의 '두 번째 활공은 강제하지 않음'을 갱신한다.
