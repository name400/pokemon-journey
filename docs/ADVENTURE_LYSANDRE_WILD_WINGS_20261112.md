# 미션 35 연구소의 구역별 야생 포켓몬

[원작 연구소 출현 목록](https://www.serebii.net/pokearth/lumiosecity/lysandrelabs.shtml)에 있는 델빌·헬가·썬더라이, 라이볼트·음뱃·음번, 아보·단칼빙·쌍검킬을 기존 지하 1층 세 구역에서 만날 수 있게 했다. 원래 보라색 구역의 메탕·메탕구·우두머리 아보크도 유지한다. 해당 자료의 층별 종과 레벨 범위는 확인했지만 각 개체를 어느 색 구역과 좌표에 둘지는 기존 2D 경로에 맞춘 추정이다. 각 슬롯은 고정 개체이므로 원작의 돌아다니는 행동, 출현 확률과 재생성 시점의 재현은 아니다.

구역을 조회할 때 해당 개체의 색을 서버 저장에 먼저 확정하고 화면·배틀·재조우·포획에서 같은 값을 사용한다. 기존 메탕 등 세 개체도 이전에는 필드에서 일반 색으로만 보여 실제 배틀 결과와 다를 수 있었으므로 함께 고쳤다. 슬롯 포획 후 기록은 지워지고 재입장 시 기존 재출현 처리에 따른다. 최초 조회 시 누락된 색을 저장하는 추가 쓰기가 생길 수 있으며 운영 지연은 측정하지 않았다.

구형 자유 배치 저장은 기존 세 개체만 보여 주며 지하 2층에서는 출현하지 않는다. 새 2D 구역의 맵 좌표·이동 타일·키카드·전송기 흐름은 유지한다. 격리 API에서 새 구역 세 곳의 이로치 조우·도주·재접속·포획과 기존 연구소 경로를 검사했다. 모바일 브라우저에서는 시험 데이터와 단색 대체 스프라이트를 사용해 세 구역 렌더링 및 일반·이로치 이미지 요청을 확인했다. 원작 실기 및 운영 서버는 검증하지 않았다.
