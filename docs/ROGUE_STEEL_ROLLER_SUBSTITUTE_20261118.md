# Steel Roller terrain and Substitute — 2026-11-18

The pinned source implements Steel Roller's terrain removal as `ClearTerrainAttr`, a target effect, and skips target effects while the hit is absorbed by a Substitute: [move](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/data/moves/move.ts#L11453), [attribute](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/data/moves/move.ts#L3370), [target-effect check](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/phases/move-effect-phase.ts#L535). An isolated before-fix native battle reproduced Electric Terrain being removed by a Steel Roller hit absorbed by a Substitute.

New runs carry `steelRollerSubTerrainRule: source-v1` into combat. During each ordinary Steel Roller hit, the native substitute-damage terrain callback is temporarily suppressed and then restored; direct hits still use the native terrain removal. Infiltrator therefore continues to bypass Substitute. Multi Lens can clear terrain on a later direct hit once a Substitute has broken. Old runs without the flag keep their former behavior.

Isolated engine tests cover singles, doubles, broken and surviving Substitutes, ordinary and passive Infiltrator, Multi Lens, Protect, Wonder Guard, missing terrain, actual move command, PP, encoding/restore, other stored values and legacy rules. Two Substitute HP values were explicitly injected to exercise break/survival paths rather than obtained naturally. The nine-file related suite passed 88 tests. Browser, real device, source MP4, all ability and terrain combinations and a source runtime side-by-side were not tested. No existing server or user save was used.
