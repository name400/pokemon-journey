# 미션 20 결정 정리 기록 보존

결정 파괴 시 기존 코드는 알려진 좌표만 추린 목록으로 저장을 덮어써 알 수 없는 항목을 잃을 수 있었다. 의뢰 시작 시에도 기존 목록을 초기화했다. 이제 누락·null 저장만 빈 목록으로 시작하고, 기존 배열은 알 수 없는 항목과 중복을 포함해 그대로 보존하면서 새 좌표를 추가한다. 배열이 아닌 미확인 형식은 덮어쓰지 않고 정리 요청을 거절한다.

[원작 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-20-a-request-from-the-rust-syndicate)의 결정 27개 목표는 유지한다. 진행 수는 알려진 고유 좌표만 세므로 미래 항목이나 중복으로 조기 완료되지 않는다. 이미 27개 좌표가 있는 기존 기록으로 의뢰를 시작하면 파괴 보상을 다시 주지 않고 보고 단계로 이어진다. 결정 배치와 조각 양은 기존 2D 게임 규칙이며 원작 실기의 정확한 위치와 동일하다고 확인한 것은 아니다.

격리 API에서 혼합·중복·알 수 없는 형식, 27번째 결정, 재시도와 이미 완료된 기록에서 보고, 조각 상한·경험치 및 기존 보유 개체 보존을 확인했다. 운영 D1과 Sites 병합본은 검증하지 않았다.
