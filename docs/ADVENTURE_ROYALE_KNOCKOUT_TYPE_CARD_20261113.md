# 타입별 기절 보너스 카드

[원작 보너스 카드 목록](https://bulbapedia.bulbagarden.net/wiki/Bonus_card)의 타입별 기절 1회, 티켓포인트 150점·메달 15개 목표를 추가했다. 18개 타입이 밤마다 순환하며 기존 세 장 제한·교체·밤 종료 및 저장을 재사용한다. 카드 위치와 순환·랭크별 제공 시점은 현재 2D 배틀존의 초안이다.

원작의 실시간 전투를 턴제로 옮겨, 플레이어가 사용한 해당 타입의 직접 공격으로 상대의 HP가 0이 된 경우에만 인정한다. 연속 공격의 마지막 타격도 확인하며 독·날씨 등 간접 피해와 상대의 행동은 제외한다. 다른 진행 중 카드와 세이브를 변환하지 않고 기존 리비전 저장으로 중복 지급을 막는다.

18개 타입의 판정과 다중 타격·간접 피해·교체를 단위 검사하고, 격리 SQLite API에서 실제 전투·보상·재접속·이전 요청 거절과 카드 교체를 확인했다. 원작 실기기·운영 D1·Sites 병합본은 검증하지 않았다.
