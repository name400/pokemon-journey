# 파워 도구 교환과 전투 노력치

메인 스토리 완료와 기존 교환소 해금 후 파워웨이트·리스트·벨트·렌즈·밴드·앵클을 각각 메가조각 180개로 교환할 수 있다. 기존 가방과 리비전 트랜잭션을 사용하며 교환소 위치는 기존 초안이다. 기존 저장과 진행 중인 구형 전투 스냅샷은 변경하지 않는다.

각 도구의 HP·공격·방어·특수공격·특수방어·스피드 노력치 추가 8과 전투 중 스피드 절반은 [Serebii의 도구별 효과](https://www.serebii.net/games/evs.shtml)를 따른다. [Z-A 육성 자료](https://rotomlabs.net/guide/stat-training-legends-z-a)도 비용·스토리 조건과 추가량을 설명하지만 도구 일부의 영문 이름과 능력치 대응은 Serebii 및 게임 내 설명과 달라 교차 확인이 필요하다. 이 구현은 Serebii와 기존 게임 내 도구 설명의 대응을 사용한다.

기존 노력치 처리와 같이 쓰러뜨린 적의 기본 지급분에 추가하고 252/510 한도를 적용한다. 턴 전후 지닌 도구가 바뀌었으면 그 턴의 보너스는 보수적으로 지급하지 않는다. 이미 진행 중인 구형 전투는 소급 적용하지 않는다. 포획만 했을 때의 지급, 원작 실시간 전투 차이와 실제 운영 검증은 남아 있다.
