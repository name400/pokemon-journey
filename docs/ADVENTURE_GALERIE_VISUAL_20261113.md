# 갈르리 드 라 륀 시각 개선

[Poképédia](https://www.pokepedia.fr/Galerie_Clair_de_Lune)는 중앙 광장의 유리 돔, 상점과 세 개의 연결 통로를 설명한다. [Bulbapedia](https://bulbapedia.bulbagarden.net/wiki/Galerie_de_la_Lune)는 부티크와 미용실이 있는 쇼핑 아케이드로 설명한다. 이를 참고해 기존 2D 중앙 홀에 돔 유리의 반사와 프레임을, 상점 타일에 진열창과 차양을 그렸다. 위치를 표현하기 위해 캐릭터가 통행할 바닥에 반사를 얹은 것이며 실제 지붕을 통과하거나 볼 수 있다는 원작 주장은 아니다.

상점별 색상과 외형·돔의 비율·건물 벽·타일 크기는 정밀 실측이 아닌 2D 초안이다. 기존 지도에 있는 추가 북쪽 출구도 저장 및 이동 호환을 위해 유지하므로 이 화면을 원작 전체 평면과 일치한다고 주장하지 않는다. 지도 셀, 충돌·상호작용·출입구·저장 좌표는 변경하지 않았다.

Chromium에서 390×844 모바일 및 1280×850 PC 크기의 격리 게임 화면을 확인했다. 더미 계정·게임 상태와 외부 포켓몬 이미지 대체 응답을 사용했으며 실제 운영 환경은 확인하지 않았다. 기존 홀·옥상·루주 구역의 출입과 저장 복원 검사를 실행했다.
