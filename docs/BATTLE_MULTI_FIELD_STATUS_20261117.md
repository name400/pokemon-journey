# Multi-battle field and status verification — 2026-11-17

Rogue's responsive double-battle CSS changes the displayed positions of combatants independently of the logical slot coordinates. At 390×844 the status burst for the second opposing slot was above its sprite. For Rogue multi-battles, status playback now measures the actual target combatant's displayed bounding box and centers the effect there; resize updates the measurement. No damage, status, weather, terrain, PP, reward or saved-state logic is changed.

At 390×844 in Chromium, isolated double battles exercised Will-O-Wisp, Toxic, Spore, Electric Terrain and Rain Dance. For each, the move preceded the correct status or field event, and the second opposing target was used for status effects. The target burst center was checked against that sprite's layout box. External artwork was stubbed; no conclusion is drawn about visible sprite alpha or physical devices.

## Real static sprite follow-up

The double-battle checks were repeated at 390×844 and 1280×800 using the actual 96×96 PokeAPI static front/back PNGs for Mew (151), Cyndaquil (155), Squirtle (7), and Eevee (133). The fixture deliberately returns 404 for animated GIFs so the real PNG fallback is used; it is not a test of animated frames. PNG alpha over 24 was sampled against each HP panel using the rendered image rectangle. Representative playback frames were checked for the status center against Eevee's alpha bounds, status/message and field/message overlap, field/HP overlap, and HP parent stacking above a status burst that overlaps it. These are geometric/alpha checks at sampled frames, not a pixel-perfect comparison with an approved animation or physical-device verification.

Two adventure mobile issues were reproduced at 390×844: Mew's opaque pixels extended about 1–2px into the ally HP panel, and the Electric Terrain label overlapped the opposing HP panel. A 4px upward shift in the 381.01–430px container range clears the first case and reuses the existing responsive effect offset; the field label now occupies the top-left area of the adventure multi-battle scene. Rogue's overlapping status effect box was already below the HP panel in stacking order (FX 7, vitals 8), so its HP was not covered by that burst. Actual attacks and the status cue were separately checked for correct responsive target alignment after the shift.

Both modes' five scenarios (burn, poison, sleep, Rain Dance, Electric Terrain) passed at both sizes with real PNGs; the Rogue visible-log geometry was rechecked for burn and terrain at both sizes. Adventure uses engine-generated JSON snapshots via a local intercepted route, with legacy weather-unlocked Rain Dance; Rogue uses its isolated fixture API and verifies saved-state reload. Concurrent weather and terrain labels, all other species, other slots, intermediate animation frames, real devices, production networking, and video identity remain unverified. Existing gameplay rules and saved data were not changed.
