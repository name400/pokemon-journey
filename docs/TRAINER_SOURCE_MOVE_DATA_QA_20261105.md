# 트레이너 기술 구성의 원본 수치

트레이너 기술 구성기는 전투에서 이미 보정한 기술 위력·명중률을 읽지 않고 simulator 기본값으로 공격 기술 점수와 필수 기술 대체 조건을 계산했다. 예를 들어 고정 원본의 `Slash` 위력은 80이지만 기존 구성 점수에는 70이 쓰였다.

새 도전의 `trainerMoveDataRule: source-v1`은 해당 도전에 활성화된 기존 원본 기술 보정, 찌릿찌릿액셀 위력 및 다크홀 명중률을 비전투 기술 조회에 반영한다. 공격 기술 점수와 필수 기술의 위력 조건은 이를 사용한다. 상태 기술 점수는 현재 별도 휴리스틱이라 명중률을 점수에 반영하지 않는다. 이전 도전과 공유 Dex는 유지한다.

실제 나옹마 기술 구성에서 수정된 베어가르기 선택, 상대 전투의 위력 80과 저장 복구를 확인하고 다크홀·기어그라인드 등의 조회값 및 위력 조건을 검사했다. 전체 트레이너의 기술 구성이 원본과 같거나 상태 기술 점수·AI 대상·난수·교체가 완성됐다는 의미는 아니다.

관련 트레이너·라이벌·AI·챌린지·융합 회귀는 일반 환경과 Worker 각각 251/251 통과했다. 타입 검사와 프로덕션 빌드도 통과했다. 전체 테스트 스위트와 실계정 플레이는 이번에 실행하지 않았다.
