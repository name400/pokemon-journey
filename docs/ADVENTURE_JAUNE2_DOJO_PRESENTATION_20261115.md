# 존느 2번지 안뜰과 정의단 도장 표시

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-2.html)는 존느 2번지 서쪽 건물 안뜰과 세존 운하변 등 주변 접근을 기록한다. [도장 자료](https://bulbapedia.bulbagarden.net/wiki/Justice_Dojo)는 정의단 도장이 존느 2번지에 있다고 설명한다. 기존 지도에서 건물·안뜰·도로를 구분하고 기존 도장 입구 상호작용에 표식을 표시했다.

안뜰·건물·도장 입구의 정확한 형상과 격자 좌표는 기존 2D 추정이다. 원작의 옥상 접근과 실제 높이는 이번 작업에서 추가하지 않았다. 타일·충돌·도장 상호작용·진행·출입·저장은 바꾸지 않았다.

존느 2번지와 세존 운하변·존느 거리 연결 및 저장 복원 검사 2건과 타입 검사가 통과했다. 모의 API를 사용한 PC·모바일 Chromium 화면과 도장 대화를 확인했다. 원작 기기와 실제 Sites 병합본은 확인하지 않았다.
