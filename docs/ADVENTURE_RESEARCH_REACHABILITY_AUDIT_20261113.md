# 연구 레벨 50 획득 경로 후보 대조

기준: `b6334636`, 사용자 요청에 따라 `testfailed.md`를 먼저 확인했다. 기존 Sites 병합본의 실패 기록은 실제 병합본을 재검증하지 못해 유지한다. 이 문서는 데이터 대조이며 정상 플레이 완주 증명이 아니다. 재실행: `node scripts/audit-adventure-research-coverage.mjs`.

## 확인된 누락 목록

현재 대조에서 **추가로 확정된 획득 누락은 없다.** 목록이 비었다는 것은 전체 경로가 완성됐다는 뜻이 아니다. 최근 추가한 미뇽·리오르·데덴네·곤율랭은 이 기준 코드에 포함된다. 명확한 근거가 없는 포켓몬·아이템을 임의 지급하거나 조우 테이블에 추가하지 않았다.

## 데이터 대조 범위와 결과

- 구역 5~19: 각 구역의 일반 조사 종을 해당 구역 `VISIBLE` 목록 및 낮·밤, 대표 좌표·층, RNG 표본으로 호출한 일반 조우 함수에 비교했다. 구역 20은 일반·고정·우두머리 후보와 비교했다. 목록상 후보가 없는 조사 종은 0개였다. 개별 고정 개체의 맵 배치, 접근·포획 성공이나 샘플 밖 좌표는 이 도구만으로 증명되지 않는다.
- 도감 230종: 위 출현 후보, 도시 조우, 나무·시장, 화석 복원, 연구소, 구역 20과 별도 열거한 하수도·전설·스타터 경로에 직접 포함된 종은 193종이다. 모든 버전의 진화 데이터 간선을 조건 없이 따라가면 230종 전부에 후보 연결이 나온다. 193종에는 우두머리와 진행 의존 경로가 포함되며, 진화 그래프는 세대·폼·성별·아이템·시간·날씨·교환 등의 조건과 실제 획득 가능성을 **검증하지 않는다**. 전설·하수도·스타터 일부는 코드 위치를 사람이 지정한 목록이라 새로운 경로의 자동 탐지도 보장하지 않는다.
- 메가스톤: 치코리타 스타터의 조각 교환소·후반 돌 가게·스토리 후보 합집합은 47종이다. 모든 다른 연구를 완료한 상태를 인위적으로 구성하면 45종과 47종은 91,300점(레벨 50), 44종은 90,800점(레벨 49)이다. 기준은 90,900점이다. 다른 항목을 전부 충족한다는 가정이므로 정상 플레이의 여유 점수나 스톤 확보를 보장하지 않는다.
- 상점에는 진화석 10종의 단계별 판매가 있으며, 향기주머니와 휘핑팝은 의뢰 경로가 있고 금속코트·왕의징표석 등의 반복 후보는 무한 로열 보상 표에 있다. 실제 후반 해금부터 필요한 금액·조각의 축적, 모든 구매·교환의 연속 정상 진행은 별도 확인이 필요하다.

## 남은 검증과 제한

1. 230종의 모든 실제 출현 위치와 37종의 진화 후보를 조건별로 전수 확인하지 않았다. 특히 별도 폼·성별·친밀도·야간·날씨·화석·전설의 정상 접근과 소모품 수급은 대표 사례 외 미검증이다.
2. 실제 친구와의 교환 진화 5회, 트레이너 승리 1,000회, 타입별 포획 및 결정 파괴의 정상 누적과 45종 이상의 메가스톤 확보를 한 저장에서 끝까지 이어서 검사하지 않았다. 후보 점수는 이 모든 조건을 완료한 시험 데이터다.
3. 49·50 보상 및 중복 방지는 시험 상태를 직접 구성한 격리 API에서 통과했다. 기존 보상 이력·저장 데이터를 변경하지 않았고 실제 운영 DB·원작 기기·Sites 병합본은 검사하지 않았다.
