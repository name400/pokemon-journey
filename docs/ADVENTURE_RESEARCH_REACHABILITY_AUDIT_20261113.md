기준: `b6334636`, 사용자 요청에 따라 `testfailed.md`를 먼저 확인했다. 기존 Sites 병합본의 실패 기록은 실제 병합본을 재검증하지 못해 유지한다. 이 문서는 데이터 대조이며 정상 플레이 완주 증명이 아니다. 재실행: `node scripts/audit-adventure-research-coverage.mjs`.

## 확인된 누락 목록

현재 대조에서 **추가로 확정된 획득 누락은 없다.** 목록이 비었다는 것은 전체 경로가 완성됐다는 뜻이 아니다. 최근 추가한 미뇽·리오르·데덴네·곤율랭은 이 기준 코드에 포함된다. 명확한 근거가 없는 포켓몬·아이템을 임의 지급하거나 조우 테이블에 추가하지 않았다.

## 데이터 대조 범위와 결과

- 도감 230종: 위 출현 후보, 도시 조우, 나무·시장, 화석 복원, 연구소, 구역 20과 별도 열거한 하수도·전설·스타터 경로에 직접 포함된 종은 193종이다. 모든 버전의 진화 데이터 간선을 조건 없이 따라가면 230종 전부에 후보 연결이 나온다. 193종에는 우두머리와 진행 의존 경로가 포함되며, 진화 그래프는 세대·폼·성별·아이템·시간·날씨·교환 등의 조건과 실제 획득 가능성을 **검증하지 않는다**. 전설·하수도·스타터 일부는 코드 위치를 사람이 지정한 목록이라 새로운 경로의 자동 탐지도 보장하지 않는다.
- 메가스톤: 치코리타 스타터의 조각 교환소·후반 돌 가게·스토리 후보 합집합은 47종이다. 모든 다른 연구를 완료한 상태를 인위적으로 구성하면 45종과 47종은 91,300점(레벨 50), 44종은 90,800점(레벨 49)이다. 기준은 90,900점이다. 다른 항목을 전부 충족한다는 가정이므로 정상 플레이의 여유 점수나 스톤 확보를 보장하지 않는다.
- 상점에는 진화석 10종의 단계별 판매가 있으며, 향기주머니와 휘핑팝은 의뢰 경로가 있고 금속코트·왕의징표석 등의 반복 후보는 무한 로열 보상 표에 있다. 실제 후반 해금부터 필요한 금액·조각의 축적, 모든 구매·교환의 연속 정상 진행은 별도 확인이 필요하다.

1. 230종의 모든 실제 출현 위치와 37종의 진화 후보를 조건별로 전수 확인하지 않았다. 특히 별도 폼·성별·친밀도·야간·날씨·화석·전설의 정상 접근과 소모품 수급은 대표 사례 외 미검증이다.
2. 실제 친구와의 교환 진화 5회, 트레이너 승리 1,000회, 타입별 포획 및 결정 파괴의 정상 누적과 45종 이상의 메가스톤 확보를 한 저장에서 끝까지 이어서 검사하지 않았다. 후보 점수는 이 모든 조건을 완료한 시험 데이터다.
3. 49·50 보상 및 중복 방지는 시험 상태를 직접 구성한 격리 API에서 통과했다. 기존 보상 이력·저장 데이터를 변경하지 않았고 실제 운영 DB·원작 기기·Sites 병합본은 검사하지 않았다.

## 2026-11-13 후속: 주요 스톤·교환 경로 대표 검증

후반 해금과 재화만 시험 데이터로 준비한 격리 API에서, 실제 메가조각 교환 요청으로 31종(7,860조각), 돌 가게 구매 요청으로 12종(910,000원), 미션 11·13의 수령 대기 상태에서 실제 요청으로 2종을 얻었다. 중복 없는 연구 기록이 45종·4,500점에 도달했고 재접속·오래된 리비전 재요청·일회성 수령·기존 파트너 보존을 확인했다. 조각과 돈의 자연 축적, 스토리 선행 전투 및 전체 플레이는 시드 처리했으므로 이 검사는 정상 완주가 아니다.

데이터 검사에서는 스타터가 각각 치코리타·리아코·뚜꾸리인 경우와 스타터 기록이 없는 구형 저장을 확인했다. 전자는 교환 31종·상점 12종·스토리 4종의 합집합이 47종, 후자는 상점의 스타터 스톤을 보수적으로 숨겨 45종이다. 모든 후보가 아이템 등록과 메가 연구 목록에 존재한다. 구형 저장의 45종 전체를 실제로 획득한 API 검사는 아니며 과거에 소유하고 없어진 돌의 이력은 추측해 복구하지 않는다.

격리 교환 API에서 친구 관계를 설정한 두 사용자로 윤겔라 일반 교환 진화, 구형 폼 ID 기록, 금속코트를 지닌 롱스톤 교환 진화를 각각 확인했다. 받기 전부터 도구를 지닌 교환이어야 하며, 진화 후 수령자의 연구 횟수만 한 번 오른다. 별도 API에서 결정 획득·재생 대기, 상점 중복 구매와 잔액 경합, 연구 레벨 50 시험 상태에서 빛나는부적 중복 수령을 대표 확인했다. 이 범위에서 새 진행 차단은 재현되지 않았다. 실제 두 사람의 연결, 재화의 자연 축적, 교환 진화 5회, 다른 모든 과제의 단일 저장 완주는 미검증이다.

원작에서 콰자르티코 접수원이 조각을 교환하는 점은 [건물 안내](https://bulbapedia.bulbagarden.net/wiki/Quasartico_Inc._%28building%29)로 대조했다. 정확한 각 품목 해금 경계와 전체 원작 규칙이 검증됐다는 뜻은 아니다.

## 2026-11-13 후속: 교환으로 받은 종의 도감 이력

[Serebii의 연구 설명](https://www.serebii.net/legendsz-a/mablesresearch.shtml)은 도감에 등록한 종을 획득 방식과 관계없이 과제에 포함하며, 야생 포획 횟수는 별도 과제로 구분한다. 기존 친구 교환은 받은 종을 자동 등록하지 않아 보유함 동기화 전에 다시 교환하면 도감과 구역 연구에 반영되지 않았다. 두 수령자의 월드 저장에 받은 종을 교환과 같은 원자적 배치로 등록한다. 교환 진화 횟수는 실제 진화한 수령자에게만 기록하는 기존 규칙을 유지하며, 야생 포획 횟수는 증가시키지 않는다. 구형 폼 ID만 있는 개체는 기존 교환 종 판별을 사용한다. 과거 교환 이력을 추측해 소급하지 않는다.

격리 SQLite에서 양방향 수령, 구형 개체, 중복 수락 거절, 재접속 및 재교환 후 이력 보존을 확인했다. 특히 구역 14의 마지막 미등록 종을 교환받아 1,000점을 얻고 다시 보내도 유지되는 대표 사례를 검사했다. 실제 두 사용자·운영 D1과 자연 플레이로 전체 연구 50 달성은 미검증이다. 기존 연구 보상·점수 이력은 삭제하지 않았다.

메가결정 8단계는 [Serebii](https://www.serebii.net/legendsz-a/mablesresearch.shtml)가 350회, [Bulbapedia](https://bulbapedia.bulbagarden.net/wiki/Mable%27s_research)가 400회로 기재해 근거가 상충한다. 원작 기록을 확인하지 못했으므로 현재 400회 판정은 유지한다. 정상 달성에는 반복 트레이너·포획·진화·교환과 스톤 확보가 여전히 필요하며, 위 수정은 완주를 증명하지 않는다.

## 2026-11-13 후속: 조건별 점수와 대표 반복 경로

`node scripts/audit-adventure-research-coverage.mjs`의 `scenarios`는 동일한 시험 저장에서 한 조건씩만 바꾼 계산이다. 모든 다른 과제 최대·후보 스톤 47종이면 91,300점, 스톤 44종이면 90,800점, 트레이너 승리 100회면 88,800점, 교환 진화 3회면 89,300점, 교환 진화 0회면 85,300점이다. 다른 조건을 모두 최대로 가정할 때 결정 총 250회는 90,900점, 249회는 90,800점이다. 이는 해당 조건의 실제 접근성을 증명하지 않으며 후보 외 스톤을 얻을 가능성을 배제하지 않는다. 기준 점수는 90,900점이다.

대표 경로로 격리 API에서 두 가상 사용자의 실제 교환·수동 진화 5회를 수행하여 수령자에게 6,000점이 누적되고 재접속·중복 요청에 중복되지 않음을 확인했다. 사용한 5마리는 시험 데이터로 넣었고 실제 사용자·포획·육성·친구 연결은 검사하지 않았다. 기존 식당 첫 도전과 재도전의 10개 코스가 트레이너 승리에 각각 기록되는 검사, 빛나는부적의 시험 점수 상태 수령·중복 검사도 통과했다. 식당 검사는 전투 상대 HP를 시험용으로 조정한다. 따라서 실제 1,000승, 전체 포획·육성 및 단일 자연 저장의 레벨 50 완주는 아직 미검증이다. 이번 확인에서 달성을 수학적으로 불가능하게 하는 확정 결함은 발견하지 못했다.

반복 자금의 대표 검사도 확장했다. 시험용 강한 파티와 HP를 낮춘 상대로 식당 재도전 5승 후 큰금구슬 2개를 받았고, 위치를 시험 데이터로 옮겨 실제 상점 판매 요청으로 40,000원을 받았다. 현재 게임의 재도전 비용은 30,000원이다. 실제 이동·정상 난이도·200회 반복은 검사하지 않았고, 이 경로의 원작 수익성을 확정하지 않는다. 결정은 실제 파괴·재생·중복 거절을 대표 검사했다.

도감 직접 후보 193종의 종별 타입 집합에는 18개 타입이 모두 나타난다. 이 목록은 선물·화석 등 야생 포획으로 세지 않는 후보도 포함하고 서식지 재출현과 각 50회 실제 포획을 검증하지 않으므로 타입 과제의 실현 가능성 증명은 아니다.
