# 구역 9~20 조사 이후의 풀밭 우두머리

[Serebii의 구역 9](https://www.serebii.net/pokearth/lumiosecity/wildzone9.shtml)부터 [구역 20](https://www.serebii.net/pokearth/lumiosecity/wildzone20.shtml)까지 각 구역의 출현표에서 5% 우두머리 변종과 레벨을 확인하고, 현재 각 구역의 풀밭 전투에서 생성하는 종에 연결했다. 구역별 조사 종의 등록과 미션 5 완료 또는 구형 저장의 미션 6 시작을 요구한다. 원작에서 고정 우두머리로 표시된 개체와 미션 개체는 새 후보에 넣지 않았다.

기존과 같이 새 풀밭 전투를 만들 때만 판정하므로 이미 저장된 전투, 필드에 표시된 개체, 고정 개체와 포획 상태를 변경하지 않는다. 원작의 필드 실시간 생성 전체를 구현한 것은 아니다. 원작에 존재해도 현재 풀밭 전투에서 생성되지 않는 종은 이 경로로 출현하지 않는다. 구역 14의 가보리·두더류는 원작에 저레벨과 고레벨 출현의 다른 변종 레벨이 있으나 현재 풀밭 조우는 저레벨 출현만 구현하므로 해당 범위를 사용한다. 우두머리 고유 기술은 기존 지원 범위를 따른다.
