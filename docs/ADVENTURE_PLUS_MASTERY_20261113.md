# 탐험 기술플러스: 숙달과 단일 배틀

- [Bulbapedia](https://bulbapedia.bulbagarden.net/wiki/Plus_Move)에 따르면 미션 9의 메가링 이후 숙달 기술은 메가파워 한 칸을 소모하며, 메가진화 중에는 기술이 자동으로 플러스가 된다. Josée의 숙달의씨 경로는 미션 19 배틀 후 열린다.
- 새 탐험 단일 배틀에서 기술별 숙달, 숙달의씨 소모, 공격 기술 플러스 선택 및 서버 검증을 지원한다. 기존 진행 중인 배틀과 탐험 외 전투에는 새 게이지를 추가하지 않는다. 여러 상대·동료 배틀에는 일반 포켓몬의 플러스 선택이 아직 없다.
- 실시간 축적을 턴제로 옮기는 임시 규칙: 시작 1/3칸, 통상 기술 실행마다 1칸 충전, 플러스는 실행 시 1칸 소모, 메가진화는 3칸을 소모한다. 실제 원작의 충전 속도·변신 지속 시간과는 다르다. 이미 메가진화한 포켓몬의 공격은 자동 플러스 피해 보정만 적용된다.
- 공격 피해는 이전 구현과 같이 보통 20%, 약점 30% 상승으로 잠정 처리했다. [Serebii](https://www.serebii.net/legendsz-a/plusmoves.shtml)는 25%를 기재하므로 원작 정확 수치는 미확정이다. 방어 관통, 변화 기술의 개별 효과, 범위 및 사용 간격은 미구현이다.
- 원작 레벨별 자동 숙달, 우두머리의 선행 숙달과 변화 기술 숙달은 확인 가능한 기술별 데이터와 효과가 없어 적용하지 않았다. 기존 보유 개체와 숙달 이력은 보존한다.
