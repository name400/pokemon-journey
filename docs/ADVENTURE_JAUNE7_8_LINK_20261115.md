# 존느 7·8번지 지상 연결

[존느 7번지 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-7.html)와 [존느 8번지 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-8.html)는 두 번지가 남북으로 인접한다고 설명한다. 기존 막힌 경계에 왕복 출구를 추가해 5번지 우회 없이 이동할 수 있다. 정확한 출구 좌표와 거리 형상은 기존 2D 화면에 맞춘 추정이다.

기존 출입·저장 형식과 야생 구역 15·19 해금 조건을 유지했다. 두 번지 왕복·기존 5번지 출구·잠금 조건과 저장 복원, 모의 API PC·모바일 화면을 대표 검사했다. 실제 운영이나 Sites 병합본은 확인하지 않았다. 모바일 D1 이동 오류의 운영 재검증 전 기록은 유지한다.
