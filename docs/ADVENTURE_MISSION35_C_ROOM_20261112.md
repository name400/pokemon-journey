# 미션 35 연구소 C 키카드와 킬가르도 방

- [원작 공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Part_24)에 따르면 보라색 구역의 C 키카드를 얻고 문을 열면 우두머리 킬가르도와 단칼빙 두 마리가 있는 방이 나오며, 그 뒤에 승강기 열쇠 방이 있다.
- 새 연구소 진입에서는 C 키카드 문, 전투실, 열쇠 방을 순서대로 이동한다. 포켓몬과 전투는 기존 순차 턴제다. 전투실의 바닥·크기, 문과 포켓몬의 좌표는 2D 재구성을 위한 추정이다.
- 이미 연구소를 시작한 저장은 기존 경로를 그대로 유지한다. 새 경로 여부는 처음 연구소에 입장할 때만 기록한다.
