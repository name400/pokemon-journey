# 미션 35 연구소 C 키카드와 킬가르도 방

- [원작 공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Part_24)에 따르면 보라색 구역의 C 키카드를 얻고 문을 열면 우두머리 킬가르도와 단칼빙 두 마리가 있는 방이 나오며, 그 뒤에 승강기 열쇠 방이 있다.
- 새 연구소 진입에서는 C 키카드 문, 전투실, 열쇠 방을 순서대로 이동한다. 포켓몬과 전투는 기존 순차 턴제다. 전투실의 바닥·크기, 문과 포켓몬의 좌표는 2D 재구성을 위한 추정이다.
- 이미 연구소를 시작한 저장은 기존 경로를 그대로 유지한다. 새 경로 여부는 처음 연구소에 입장할 때만 기록한다.

후속: 새로 시작하는 배틀은 플레이어 한 마리와 킬가르도·단칼빙 둘이 함께 싸우는 턴제로 진행한다. 상대 셋을 각각 선택할 수 있고 플레이어 자신의 파티만 교체·저장한다. 시뮬레이터의 빈 활성 슬롯 오류를 피하기 위해 내부에 기절한 자리표시자를 두며, 이들은 행동하지 않고 화면이나 보유함에 나타나지 않는다. 기존에 시작된 순차·1대2 스냅샷은 기존 엔진으로 마친다.

우두머리 보정과 포획 불가, 승리 후 열쇠 방 접근 및 경험치를 유지한다. 패배 또는 기권 시 파티를 회복해 다시 도전할 수 있다. 범위 기술은 현재 3대3 시뮬레이터의 인접 규칙을 사용하므로 원작 실시간 전투의 범위를 그대로 재현하지 않는다. 검사는 격리 API와 모의 브라우저에서 이루어졌으며, 운영 환경과 원작 기기는 확인하지 않았다.
