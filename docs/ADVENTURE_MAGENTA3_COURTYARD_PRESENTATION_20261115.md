# 마젠타 3번지 북쪽 안뜰과 접근로

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/magenta-sector-3.html)는 북쪽 건물 단지의 안뜰과 옥상 사건, 마젠타 광장·세존 운하와의 관계를 설명한다. 기존 2D 화면의 북쪽 건물 외곽·안뜰과 거리 포장을 구분하고 기존 홀로베이터 표식을 유지했다. 원작의 누보 카페 3호는 정확한 현재 2D 대응 위치를 확인하지 못해 이 작업에서 새 위치를 만들지 않았다.

건물 형태·높이, 안뜰 크기와 격자 좌표는 원작에서 추출한 것이 아닌 초안이다. 지도 타일·충돌·이동·의뢰 및 저장 위치는 바꾸지 않았다.

마젠타 3·4번지 옥상, 비계, 홀로베이터 및 구형 저장 복원 관련 검사 8건과 타입 검사를 통과했다. 모의 API를 사용한 PC·모바일 Chromium에서 화면과 홀로베이터 대화를 확인했다. 원작 기기, 운영 D1 및 실제 Sites 병합본은 확인하지 않았다.
