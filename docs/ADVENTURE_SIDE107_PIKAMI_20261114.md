# 사이드 미션 107 — 최강의 피카츄

[Serebii](https://www.serebii.net/legendsz-a/sidemissions/theworld%27sgreatestpikachu.shtml)와 [공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-107-the-worlds-greatest-pikachu)에 따라 메인 미션 37 이후 루주 1번지 코트의 Pikami에게 의뢰를 받고, 한 마리만 편성한 피카츄로 전기구슬을 지닌 Lv.66 피카츄와 싸운다. 상대의 방어·전광석화·아이언테일·구멍파기를 사용한다. 승리 상금 5,940원과 의뢰 보상 700원·전기구슬·경험사탕 L 3개는 별도이며 전기구슬은 기존 지닌 물건 처리로 장착할 수 있다. 원작 실시간 배틀은 기존 턴제 배틀의 근사이고, 코트 내 인물의 정확한 위치는 2D 초안이다.

구형 저장의 의뢰 완료·보상을 추정하지 않는다. 파티 수와 실제 소유 중인 피카츄를 확인하고 배틀 생성 시 공유 개체를 원자적으로 검사한다. 기권 시 재도전할 수 있고, 가방 또는 지갑 한도로 보상을 받을 수 없으면 진행을 보류한다. 같은 리비전의 중복 요청은 거부한다. 격리 API에서 해금, 잘못된 종과 둘 이상의 파티원 거절, 상대 편성, 기권·재도전, 승리, 수령 한도·중복 거절, 재접속과 전기구슬 장착을 확인했다. 승리 검사는 상대 HP를 시험용으로 낮췄다. 자연 난이도·원작 기기·운영 D1·Sites 병합본은 미검증이다.

직전 사이드 106과 감독 촬영 105·115의 보상에도 기존 원자적 지갑 상한 조건을 연결했다. 미션 106은 보상 직전 지갑 한도 초과에서 단계와 보상이 유지되는 것을 격리 검사했다. 기존 저장에 이미 기록된 보상은 소급 변경하지 않는다.
