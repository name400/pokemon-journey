# 단일 원시회귀·합체 선택 메뉴

승인 v52 기술창에서 원시회귀 또는 네크로즈마 합체가 유일한 특수 선택지이면 아이콘으로 예약·해제하므로 중복 메뉴를 숨긴다. 다이맥스 등 다른 선택지가 함께 있거나 같은 아이콘의 선택지가 여러 개면 메뉴를 유지한다.

포켓로그 격리 Chromium 390×844에서 실제 서버 명령과 폼 저장·새로고침을 원시회귀와 합체 각각 확인했다. 단일 선택지 검사는 서버 응답에서 다른 선택지를 제외해 수행했고, 실제 기본 응답의 다이맥스 동시 선택지는 별도 회귀 검사했다. 타입 검사도 통과했다. 실기기·승인 원본과 픽셀 일치는 미검증이며 사용자 데이터와 Sites는 변경하지 않았다.
