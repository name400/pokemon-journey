# 탐험모험 Z-A 스타터

[미션 1 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-01-get-your-travel-bag-back)에 따르면 판짱을 쫓은 뒤 치코리타·뚜꾸리·리아코 중 하나와 대화하고 선택을 확인한다. 미르시티 신규 도입도 이 세 종 가운데 선택한다. 기존 10지역 시작 API는 구형 클라이언트를 위해 관동 스타터도 계속 허용하며 새 화면에서는 Z-A 세 마리를 제시한다.

이미 시작한 모험·포켓몬은 변경하지 않고 포켓로그 스타터 규칙도 바꾸지 않았다. 격리 API 검사에서 세 종의 레벨 5 지급·재접속, 중복 시작 거부, 미르시티의 다른 종 거부, 구형 시작 호환 및 게임 내 별도 관동 스타터 보상을 확인했다. 실제 운영 기기는 미검증이다.

## 도입 추격과 현장 선택

신규 미르시티 시작은 포켓몬 없이 판짱을 따라 골목을 이동하고, 골목 끝에서 세 포켓몬에 각각 접근해 살펴본 뒤 선택을 취소하거나 확정한다. 진행·선택 상태는 서버에 저장하며 확정한 경우에만 파트너 한 마리를 지급한다. 재접속과 중복 확정을 검사했다. 구형 클라이언트의 직접 시작 API와 기존 저장은 호환을 위해 유지한다.

골목은 이동 가능한 간단한 격자 초안이고 판짱의 원작 경로·애니메이션과 실제 거리 배치는 재현하지 않았다. 실제 기기 조작은 확인하지 못했다.

## 첫 배틀과 배틀 존 탈출

[Andi 자료](https://bulbapedia.bulbagarden.net/wiki/Andi)는 첫 배틀 상대가 레벨 4 암컷 판짱이며 승리 보상이 192원이라고 설명한다. 스타터 선택 후 기존 턴제 배틀에서 상대하고 승리하면 가방을 되찾는다. [미션 2 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-02-escape-from-the-battle-zone)에 따라 Brigitte의 레벨 4 삐·파르빗과 배틀한 뒤 붉은 장벽과 터널을 지나 호텔 Z 로비에 도착한다. 두 배틀은 승리 시 각각 192원을 주고, 패배·포기 시 파트너를 회복하고 같은 단계에서 재도전할 수 있다. 진행 상태와 전투를 재접속해 복원한다.

탈출 화면의 격자와 이동 경로는 초안이고 원작의 실시간 공격·추격, 컷신과 정확한 지형은 재현하지 않는다. 이전에 도입을 완료한 저장은 새 배틀을 강제로 다시 진행하지 않는다.

## 호텔과 미션 3 시작

두 배틀에서 승리하면 기존 탐험 전투의 경험치 계산·레벨업·기술 학습을 적용한다. 원작 Z-A의 정확한 경험치 수치와는 대조하지 못했다. 패배·포기에는 지급하지 않고 이미 완료한 배틀에 소급 지급하지 않는다.

[미션 2](https://www.thonky.com/pokemon-legends-z-a/main-mission-02-escape-from-the-battle-zone)의 순서대로 호텔 접수처에서 202호 열쇠를 받고 2층 침대에서 쉰 다음 문을 나가 미션 3을 시작한다. [미션 3](https://www.thonky.com/pokemon-legends-z-a/main-mission-03-a-new-life-in-lumiose-city)의 동료가 호텔 밖에서 선택하지 않은 두 스타터를 약점 순서로 내며, 승리하면 280원을 받는다. 기존 턴제와 재도전 처리를 사용한다. 실제 호텔 도면과 배치 역시 초안이다.

## 미션 3 포획과 연구소

동료 배틀 후 센터를 방문하고 구역 1의 동료에게 볼 10개를 받는다. 화살꼬빈은 원작 안내처럼 첫 투척이 실패하고 다음 투척에 포획된다. 파르빗은 기존 턴제 야생 배틀과 포획 기능을 이용한다. 포획 뒤 동료에게 볼 10개를 더 받고, 미르시티 도감 다섯 종을 등록한 뒤 연구소 3층 Mable에게 보고한다. 기존 연구 보상 목록의 바위깨기를 등록하고 호텔 로비에서 미션 3을 마치면 기존 Z랭크 로열 흐름으로 이어진다. 볼 소지 한도 때문에 10개를 받을 자리가 부족하면 빈 공간을 만들어야 하며, 튜토리얼 중 볼이 0개면 동료에게 1개를 다시 받을 수 있다.

구역 1의 동료와 두 포켓몬 좌표는 초안이며 원작의 조준·웅크리기·실시간 포획 동작은 그대로 재현하지 않는다. 도감 앱 설치와 Mable의 설명은 대화로 축약했고 연구소 이후의 미션 4는 기존 로열 구현을 사용한다. 기존 저장에는 단계를 강제로 추가하지 않는다. 격리 API에서 포획 성공·실패, 재접속, 볼 지급 한도·중복 방지, 도감 조건, 연구소 보고와 호텔 복귀를 검증했다. 실제 기기 조작은 미검증이다.
