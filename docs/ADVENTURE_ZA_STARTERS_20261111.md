# 탐험모험 Z-A 스타터

[미션 1 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-01-get-your-travel-bag-back)에 따르면 판짱을 쫓은 뒤 치코리타·뚜꾸리·리아코 중 하나와 대화하고 선택을 확인한다. 신규 탐험 선택 화면은 이 세 마리를 보여 주고, 선택 후 시작 버튼을 눌러 확정한다. 미르시티 신규 시작 API도 세 종만 허용한다. 기존 10지역 시작 API는 구형 클라이언트를 위해 관동 스타터도 계속 허용하며 새 화면에서는 Z-A 세 마리를 제시한다.

이미 시작한 모험·포켓몬은 변경하지 않고 포켓로그 스타터 규칙도 바꾸지 않았다. 원작의 판짱 추격과 현장 대화 선택 장면은 구현하지 않았으며 현재는 게임 시작 전 선택한다. 격리 API 검사에서 세 종의 레벨 5 지급·재접속, 중복 시작 거부, 미르시티의 다른 종 거부, 구형 시작 호환 및 게임 내 별도 관동 스타터 보상을 확인했다. 실제 운영 기기는 미검증이다.
