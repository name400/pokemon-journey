# 사이드 미션 25: 깨봉이 손님

[미션 목록](https://bulbapedia.bulbagarden.net/wiki/Task_%28Legends%3A_Z-A%29)과 [공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_21-40)에 따라 미션 10의 동료 전투 후 마젠타 4번지 카페 포켓몬아미의 Fumi에게 의뢰를 받고 깨봉이 세 마리를 쓰레기 수거 장소로 안내한다. 맛있는 쓰레기는 별도 인벤토리 소모품이 아닌 의뢰 상태로 다룬다. 이동 뒤 세 마리는 서버가 확정한 이전 위치를 비차단 시각 경로로 따라오며 구르기는 제한된다. 수거 장소에서 1,200코인, 이상한사탕 2개와 다크볼 5개를 한 번 받는다. 가방이 가득 차면 공간에 들어가는 것만 지급하고 잔여분은 같은 장소에서 수령한다.

카페의 기존 상호작용과 막힌 건물 벽에 수거 장소를 배치해 통행 및 이전 위치를 유지했다. 카페와 수거 위치, 2D 추종 경로는 원작의 정밀 좌표·실시간 행동이 아닌 초안이다. 이 구현은 걷는 속도 전체를 원작처럼 제한하지 않으며, 구역 밖에서는 동행 표시가 숨겨지고 다시 돌아와 진행할 수 있다. 기존 완료 기록이 없는 구형 저장에 보상을 추정하지 않고, 알 수 없는 추종·보상 데이터를 덮어쓰지 않는다. 필드 상태 리비전으로 중복 수락·완료·수령을 거절한다.

격리 API에서 해금 후 수락·실제 경로 이동·재접속·구르기 거절·보상 보관과 부분 수령·오래된 요청·기존 파티 및 알 수 없는 추종 데이터 보존을 검증했다. 원작 실기·운영 D1·Sites 병합본은 확인하지 않았다.
