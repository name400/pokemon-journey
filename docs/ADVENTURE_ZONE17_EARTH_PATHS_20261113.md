# 구역 17 북쪽 산책로의 흙길

[구역 설명](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_17)은 남쪽 정원과 계단으로 이어지는 북쪽 Y자 산책로, 세 북쪽 접근, 두 화염레오 조각상과 광고기둥을 설명한다. 별도로 전달된 원작 지도·3D 화면 분석은 북쪽 길이 흙길이며 북쪽 돌출 입구에 짧은 접근로가 있다고 설명한다. 원본 이미지는 이번 환경에서 직접 보지 못했다.

기존 북쪽 산책로 층의 평탄한 바닥 표현을 Y자 흙길과 중간 입구의 접근로로 바꾸어 세 북쪽 출입구와 남서쪽 계단이 시각적으로 이어지게 했다. 나머지 북쪽 바닥은 잔디로 표시하며, 충돌·야생 개체·도구·건물·사다리·출입구와 기존 호환 계단은 변경하지 않는다. 각 타일의 좌표와 폭, 계단의 단수와 정확한 높이, 기존 호환 경로의 원작 대응은 추정이며 전체 외곽을 정확히 재현한 것은 아니다.

구역 단위 검사에서 흙길의 네 방향 연결과 기존 출입·사다리·저장 복원을 검사했다. 이전 맵과 비교해 바뀐 31칸이 모두 통행 가능한 일반 바닥과 포장 사이의 변경임을 확인했고, 격리 SQLite API에서 계단·북쪽 출입·옥상과 구형 저장을 대표 검사했다. PC·모바일 Chromium 화면은 모의 API와 대체 이미지를 사용했다. 원작 실기와 운영 환경은 검사하지 않았다.
