# 야생 구역 8의 대각선 출입과 모래 광장

별도로 전달받은 원작 지도·3D 화면 분석에는 대체로 평탄한 원형 광장과 중앙 모래 원, 그 둘레의 곡선 경계석 및 서남서·동북동의 존느 거리 출입구가 보인다. [구역 안내](https://www.nintendolife.com/guides/pokemon-legends-z-a-wild-zone-8-guide-all-pokemon-and-alphas)는 중앙 흙더미와 바깥 모래 지대의 조우를 설명한다. 원본 이미지는 이번 작업 환경에서 직접 보지 못했다.

기존 맵의 남서·북동 가장자리에 존느 거리의 두 부분과 연결되는 출입구를 추가했다. 두 방향 모두 기존 해금 조건을 적용하며 출구는 구형 저장에서도 이용할 수 있다. 중앙 모래 원과 둥근 경계석을 강조하고, 중앙의 기존 포장 타일은 충돌·조우 판정을 유지하면서 포장도로로 그리지 않는다. 기존 노점, 출현·소진 이력, 아이템과 통행 타일을 유지한다.

추가 입구의 정확한 2D 좌표, 광장의 타원 비율, 경계석·노점·흙더미의 세부 위치와 주변 거리 구조는 추정이다. 기존 북·남·다른 출입구 및 중복 노점은 저장과 이동 호환을 위해 남겼으며 원작에서 확인된 시설로 간주하지 않는다. 입구를 새로 추가한 2D 연결 역시 원작과 정밀하게 일치한다는 뜻이 아니다.

구역·격리 SQLite API 검사에서 잠긴 진입, 양쪽 왕복과 재접속, 종전 입구 탈출, 보유 포켓몬·재화·도구 및 흙더미 상태를 확인했다. 흙더미 조우와 상점 기존 검사도 실행했다. PC·모바일 Chromium 화면은 모의 API·대체 이미지이며 운영 기기와 원작 실기는 검사하지 않았다.
