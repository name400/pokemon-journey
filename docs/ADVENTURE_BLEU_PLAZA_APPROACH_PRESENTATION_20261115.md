# 블루 광장 접근로의 경찰서와 거리

[구역 16 안내](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_16)는 동쪽 출입구가 경찰서와 마주하고 북서 출입구가 Rust 사무소 쪽임을 설명한다. [광장 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-plaza.html)는 광장과 블루 거리·주변 구역의 연결을 설명한다. 기존 2D 접근로의 경찰서와 다른 건물, 포장 경계를 구분하고 기존 출입구를 표시했다. 경찰서 표식은 기존 건물 타일 위에 있으며 새 기능이나 출입구는 추가하지 않았다.

현재 접근 화면은 광장 전체가 아니라 압축된 바깥 경로이며, 중앙 오벨리스크·정원과 세 계단은 기존 구역 16 지도에 있다. 건물 외곽·높이, 거리 폭과 격자 좌표는 원작에서 추출한 것이 아닌 초안이다. 지도 타일·충돌·구역 해금·진행·저장 위치는 바꾸지 않았다.

블루 1번지·블루 거리와 구역 16의 출입·해금·저장 복원 단위 검사 15건 및 타입 검사가 통과했다. PC·모바일 Chromium에서는 모의 API로 화면과 기존 Yvon 대화를 확인했다. 원작 기기·운영 D1·Sites 병합본은 확인하지 않았다.
