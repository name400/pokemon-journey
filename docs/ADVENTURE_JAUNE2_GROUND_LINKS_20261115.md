# 존느 2번지 지상 연결

[존느 2번지 위치 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-2.html)는 서쪽 중앙 광장과 동쪽 존느 6번지 접근을 설명하며 [6번지 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-6.html)도 서쪽 2번지를 명시한다. 기존 막힌 화면 경계에 두 왕복 출구를 추가했다. 정확한 접점·좌표는 기존 2D 화면에 맞춘 추정이다.

기존 안뜰·정의단 도장·운하 출입, 통행 칸과 저장 형식을 유지한다. 양방향 이동·도장·운하·기존 10번지 경로·저장 복원 및 모의 API PC·모바일 화면을 검사했다. 실제 운영이나 Sites 병합본은 확인하지 않았다. `testfailed.md`의 16건 및 모바일 D1 이동 오류 기록은 운영 재검증 전까지 유지한다.
