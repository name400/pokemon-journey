# 플라드리 연구소의 무작위 우두머리

- [Serebii 연구소 조우표](https://www.serebii.net/pokearth/lumiosecity/lysandrelabs.shtml)는 연구소의 종별 무작위 우두머리와 레벨을 제시한다. [Bulbapedia 미션 35 공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Part_24)은 미션 5 이후 일반 출현이 우두머리로 나올 수 있다고 설명한다. 둘 다 2차 자료이며 실기 검증은 하지 않았다.
- 현재 연구소의 각 종 위치는 근사치다. 원작의 일부 개별 출현점에는 10% 또는 20%가 표시되지만 현재 슬롯과 대응을 확정할 수 없어 공통 5%를 잠정 적용한다. 델빌·썬더라이·음뱃·아보·단칼빙은 57–58레벨, 나머지 해당 종은 59–60레벨이다. 기존 고정 아보크는 그대로다.
- 새 개체의 우두머리 여부와 이로치를 기존 출현 기록에 저장한다. 이미 이로치 판정이 저장된 개체는 우두머리 여부를 소급 추첨하지 않는다. 도주와 재접속에서 같은 개체가 유지되고 포획 또는 승리 시 기존 소모 규칙을 따른다. 기존 진행 중 전투는 변경하지 않는다.
- 정확한 출현 좌표·개체별 확률, 일부 종의 우두머리 고유 기술 및 연구소에서의 실시간 추격 행동은 추가 확인이 필요하다. 새 폴링은 도입하지 않았으며 실제 기기 이동 성능은 측정하지 않았다. 운영 환경 이동 오류는 별도로 재검증해야 한다.
