# 사이드 미션 35: 요가 선생님의 가르침

[원작 의뢰 설명](https://www.serebii.net/legendsz-a/sidemissions/guidancefromayogamaster.shtml)과 [공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-035-guidance-from-a-yoga-master)에 따라 미션 14의 Naveen 배틀 이후 존느 거리의 Paix에게 의뢰를 받고, 야생 구역 3의 돌 건물 계단으로 올라가 옥상의 요가 선생님을 만난다. 요가랑을 충분히 먹여야 한다는 대화와 2,000원·휘어진스푼·경험사탕 S 5개 보상을 연결했다. 기존 건물 출입과 옥상 지형을 사용하며 두 인물의 정확한 2D 좌표와 외형은 초안이다.

도구별 가방 공간만큼 지급하고 잔여 도구는 선생님에게 보관한다. 재화는 한 번만 지급하며 지갑 수치가 안전한 정수 범위를 넘을 경우 전체 요청을 거절한다. 알 수 없거나 잘못된 보상 저장은 고치거나 덮어쓰지 않는다. 기존 저장에서 완료·보상을 추정하지 않는다.

격리 API에서 해금 전 거절, 의뢰 수락, 돌 건물로 내려간 뒤 계단으로 옥상 재입장·도보 접근, 부분 지급·보관·재접속·중복 요청과 지갑 상한, 파티의 이동에 따른 걸음 수 외 데이터 보존을 확인했다. 타입 검사를 통과했다. 원작 기기·PC/모바일 화면·운영 D1·Sites 병합본은 확인하지 않았다.
