# 미션 41 폭주 메가진화 시뮬레이터

[원작 진행 공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough%3APok%C3%A9mon_Legends%3A_Z-A/Part_28)은 레벨 70의 우츠보트·루차불·마기라스가 이전 폭주 전투의 기술을 다시 사용한다고 설명한다. 새로 시작하는 세 시뮬레이터 전투에 확인된 대표 기술을 각각 세 개씩 적용했다. 우츠보트와 마기라스는 [재대결 설명](https://www.serebii.net/legendsz-a/roguerematch.shtml), 루차불은 [원래 사건 설명](https://www.serebii.net/legendsz-a/mainmissions/aroguemegahawlucha.shtml)을 참고했다.

실시간 돌진·광역 충전 공격은 일반 턴제 기술로 각색하며 세 기술이 원작의 완전한 기술 목록이라는 뜻은 아니다. 변경은 새 배틀 생성 시에만 적용해 이미 저장된 전투 스냅샷을 교체하지 않는다. 기존 승패·재도전·진행과 파티·보상을 유지한다.
