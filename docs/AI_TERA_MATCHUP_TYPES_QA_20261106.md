# AI 테라스탈 상대 타입 점수

고정 원본의 교체 점수는 상대의 공격 타입을 `getTypes`로 가져오고 방어 상성은 스텔라일 때 원래 타입을 사용한다. 신규 도전에서 일반 테라스탈은 환영보다 테라 타입을 우선하고, 스텔라는 공격 타입으로 스텔라를 쓰면서 방어 상성에는 원래 또는 환영 타입을 유지하도록 구분했다. 기존 저장은 이전 규칙을 유지한다.

일반·스텔라 테라스탈과 환영 타입 어댑터, 스텔라 공격 상성 점수, 스텔라 전투 저장 복구와 다른 슬롯 보존을 격리 검사했다. 실제 교체 결과, 특성·변신·날씨의 전체 조합과 운영·실기기 플레이는 별도 검증이 필요하다.
