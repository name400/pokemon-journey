# 미션 12: Jaune Sector 3 비계

공개 공략 [Thonky](https://www.thonky.com/pokemon-legends-z-a/main-mission-12-a-rogue-mega-camerupt)와 [PokeQuery](https://pokequery.com/games/legends-za/walkthrough)를 참고했다. 프리즘타워 북동쪽 공사 현장에서 Tony와 배틀하고 동료가 회복시킨 후 사다리와 비계를 올라 메가폭타와 싸우며 폭타나이트를 받는 순서를 반영했다.

기존 공사 현장 경로와 저장은 유지한다. 새 거리 출입구와 두 사다리의 좌표, 비계 형태와 층별 세부 배치는 원작 좌표를 검증하지 못한 2D 초안이다. 동료의 실시간 지원, 비계의 정확한 구조와 현장 도구 배치는 구현되지 않았다.
