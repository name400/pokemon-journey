# 사이드 미션 47: 트리미앙 미용사

[의뢰 자료](https://www.serebii.net/legendsz-a/sidemissions/becomingafurfroutrimmer.shtml)와 [미용 안내](https://www.siliconera.com/how-to-unlock-the-furfrou-salon-in-pokemon-legends-z-a/)에 따라 존느 6번지 Mirte의 의뢰를 받고 대타 인형에 선두 포켓몬의 베어가르기를 보여 주면 미용 서비스가 열린다. 서비스는 선두의 일반 트리미앙을 대상으로 하트·스타·다이아컷과 야생의 모습 사이를 500원에 바꾸며, 의뢰 보상 800원·기력의조각·경험사탕S 3개는 가방 공간이 생길 때까지 보류할 수 있다.

트리밍은 탐험 전용 외형 필드에 기록하고 포켓몬의 종·폼 식별자, 기술, 능력치, 도구와 다른 게임용 필드는 바꾸지 않는다. 공유 데이터 보호를 위해 융합·다른 게임 전용 개체나 출처 이미지가 지정된 개체는 제외한다. 파티 선두로 선택한 개체만 다듬을 수 있다. 이미 포함된 검토된 로컬 이미지 자산으로 미용·이로치의 앞뒤 모습을 표시하며, 필드의 작은 동행 포켓몬 표현과 원작의 털이 자라는 시간은 아직 반영하지 않았다.

베어가르기 일반 사용을 명시한 자료와 플러스 숙달을 요구하는 공략이 상충해 현재 일반 기술 시연을 허용한다. 의뢰자·인형의 정확한 2D 좌표도 초안이다. 대표 격리 API에서 해금·기술 조건·가방 한도·보상 및 결제 중복·잔액 부족·재접속과 개체 식별정보 보존을 확인했다. 실제 원작 기기·PC/모바일 브라우저·운영 D1·Sites 병합본은 확인하지 않았다.
