# 블루 5번지 수변 표시

[블루 5번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-5.html)는 에이믈리스 파크 수로를 내려다보는 울타리와 물가 계단을 언급한다. 이는 2차 자료이며 정확한 난간 형태와 격자 좌표는 확인되지 않았다.

기존 지도 동쪽의 막힌 경계에 수로와 난간을 그려 공원 수변을 구분하고, 기존 하층 출입구에 계단 모양을 표시했다. 수로·난간·계단의 정확한 배치는 압축된 2D 지도에 맞춘 추정이다. 지도 타일, 충돌, 출입 조건, 저장 형식과 진행 상태는 변경하지 않았다.

모바일 이동 오류와 Sites 병합본의 실패 기록은 운영 재검증 전이므로 유지한다.
