# 구역 19 경사와 높이 검토

- [Poképédia](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_19)는 구역이 경사진 포도밭 공원이며 정자가 있고 서쪽 존느대로와 동쪽 존느 8번지에서 들어간다고 설명한다. [Game8](https://game8.jp/pokemon-legends-z-a/729772)은 중앙 정자·대좌 주변의 고정 우두머리를 설명한다.
- 위 자료에서는 경사의 방향·기울기, 계단의 존재와 위치, 정자와 출입구 사이의 정확한 높이 차이를 확인하지 못했다. 경사라는 사실만으로 계단이나 이동이 제한되는 단차가 존재한다고 단정할 수 없다.
- 현재 구역 19는 하나의 2D 타일맵이다. 위치 저장은 구역과 x/y를 사용하고 포도나무 충돌에 대한 구형 저장 복원을 지원한다. 정자의 우두머리·기존 조우와 아이템, 출입구는 이 맵의 좌표에 묶여 있다. 다른 높이층으로 옮기면 이들 접근, 구형 저장, 예측 이동 및 재접속을 함께 이행해야 한다.
- 실제 높이층과 계단은 이번에 추가하지 않았다. 정밀한 원작 영상이나 지형 자료로 경사 방향과 이동 가능 경계를 확인한 뒤, 구형 저장을 안전하게 연결하는 방식부터 검증해야 한다. 현재 색상 차이는 경사 표현이며 실제 높이 판정이 아니다.
- `32c4ef25`에서 구역 19 단위 검사 8개와 격리 API의 조우·저장·재접속 검사 3개를 다시 통과했다. PC·모바일 브라우저는 시험 상태와 외부 이미지 대체물을 사용했다. 실제 운영 저장이나 원작 실기는 검증하지 않았다.
