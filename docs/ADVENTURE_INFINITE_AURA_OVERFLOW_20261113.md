# 무한 로열 플라엣테 전투 스택 오류

격리 API에서 무한 로열 15번째 상대 팀을 반복해 `Maximum call stack size exceeded`를 재현했다. 재현된 전투를 추적한 결과 페어리오라가 AI 피해량 추정 중 공유 기술 객체의 `auraBooster`에 시뮬레이터 포켓몬을 남겼다. 이후 플라엣테의 파멸의빛을 사용하려는 순간 공유 객체를 복사하면서 포켓몬과 전투 사이의 순환 참조를 무한 복사했다. 기록된 최초 실패는 내부 스택을 수집하지 못했으므로 두 실행이 완전히 동일한 내부 상태였다고 단정하지는 않는다.

탐험과 포켓로그 AI의 피해량 추정에 각각 전투 전용 기술 복사본을 사용한다. 능력·기술 자체나 저장된 포켓몬과 배틀 스냅샷은 변경하지 않는다. 수정 전에는 단일 턴 페어리오라·다크오라 재현이 각각 실패하고 수정 후 통과했다. 격리해 둔 실패 직전 전투 스냅샷도 수정 후 이어졌으며, 15번째 상대 구성 120회 반복과 포켓로그 단일 턴을 검사했다. 최초 실패 당시의 스냅샷과 실제 Sites 병합본·운영 환경은 확보하지 못했다.
