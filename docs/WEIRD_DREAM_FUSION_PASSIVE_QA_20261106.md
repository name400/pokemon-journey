# 이상한 꿈 융합 파티 패시브 검증

고정 원본은 현재 도전에서 패시브가 꺼진 파티원 중 하나를 선택하며, 융합체의 패시브는 주체 종·폼을 따른다. 원본 `randSeedInt`는 후보가 하나 이하면 난수를 소비하지 않는다. 현재 구현의 후보 0·1·2개 선택과 소비 횟수를 확인했다.

격리 게임 경로에서 융합 파티로 이상한 꿈 대체 전투를 승리하고, 주체 패시브 지급·영구 패시브 해금 불변·다른 슬롯 보존·저장 복구·다음 전투 적용을 확인했다. 전투는 친밀도 등 정상 계정 진행을 변경할 수 있으므로 계정 전체가 불변이라고 단정하지 않았다. 이번 변경은 구현 변경이 아닌 검증 추가다. 다른 폼·패시브 복합 조합과 원본 RNG 스트림 전체, 운영·실기기 플레이는 별도 검증이 필요하다.
