# 르 예 2성 식당 배틀

[원작 의뢰 자료](https://www.serebii.net/legendsz-a/sidemissions/fullcourseofbattles:twostars.shtml)와 [보상 안내](https://www.thonky.com/pokemon-legends-z-a/side-mission-060-full-course-of-battles-two-stars)를 바탕으로 미션 20 이후 5코스에 처음 무료로 도전할 수 있다. 코스의 포켓몬·레벨·기술·소지 도구와 코스별 2,160코인 상금, 첫 완료 보상 1,000코인·기술머신 094·리보플라빈 3개·키토산 3개를 연결했다. [재도전 자료](https://bulbapedia.bulbagarden.net/wiki/Restaurant_Le_Yeah)에 따라 15,000코인 참가비, 작은버섯 30개와 경험사탕 M 4개를 지급한다. 금색 인형은 전투 상금에만 적용하며 코스 중 회복은 제한한다.

루주 3번지 건물 벽에 출입구를 추가했다. 건물의 구역은 자료에 근거하지만 문과 실내의 정확한 타일은 2D 초안이다. 기존 통행 가능한 저장 칸과 구역 연결을 보존한다. 원작의 실시간 3대1은 기존 턴제 다수 상대 배틀로 근사하며 적은 최대 두 마리가 동시에 행동하고 나머지 한 마리는 교체로 등장한다. 기술머신 094는 [학습 자료](https://www.serebii.net/attackdex-sv/whirlwind.shtml)에서 확인한 일부 기본 종만 지원하며 나머지 종·폼과 원작 실시간 효과는 미완성이다. 저장된 개체와 미수령 보상은 임의로 수정하지 않는다.

격리 API에서 출입·재접속, 해금, 최초 5코스, 상금·가방 한도, 보상 중복 거절, TM 사용, 참가비 부족·기권 및 재도전 5코스 보상을 검사했다. 승리 검사는 상대의 HP·상태를 조정했다. 구역 접근·구형 저장과 수첩 목표 단위 검사, 르 나·르 와우 API 회귀와 타입 검사도 통과했다. 기존 Sites 병합본, 운영 D1, 실기와 실제 브라우저 화면은 검사하지 않았다. 지갑이 안전한 정수 한도에 도달하면 승리 결과 저장이 거절되는 기존 제한은 남아 있다.
