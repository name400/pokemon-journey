# 존느 9·6번지 지상 연결

[존느 9번지 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-9.html)는 남서쪽 6번지와의 연결, 존느 스트리트 쪽 건물 사이 미션 18 안뜰 및 남쪽의 낮은 풀 지형을 설명한다. 두 기존 지상 화면의 막힌 경계에 9↔6 왕복 출구를 추가했다. 정확한 접점과 출구 좌표는 2D 추정이며, 미션 안뜰의 실제 건물과 남쪽 단차는 추가 대조가 필요하다.

기존 10번지·광장 출구, 구역 8의 해금 조건, 미션 18 상태와 저장 형식을 유지했다. 새 연결·기존 출구·해금 전 제한·미션 표식·저장 복원과 모의 API PC·모바일 화면을 검사했다. 처음 잠금 검사에 이미 해금된 미션 상태를 사용해 기대가 실패했으며 해금 전 상태로 바로잡아 통과했다. 실제 운영이나 Sites 병합본은 확인하지 않았다. 모바일 D1 이동 오류 기록은 운영 재검증 전까지 유지한다.
