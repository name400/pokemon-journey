# TM101 일렉트릭네트 호환 보완

기존 블루 7번지 주민의 TM101은 기본 종 16종과 6개 폼만 지원했다. [Serebii의 Z-A 기술머신 목록](https://www.serebii.net/attackdex-sv/electroweb.shtml)과 [폼별 기술 정보](https://www.dittobase.com/legends-za/moves/electroweb)를 대조해 에몽가·저리더프·메더·게노세크트·목도리키텔·일레도리자드·마기아나·제라오라·스트린더·모르페코 기본 폼을 추가했다. 기본 종은 총 26종이다. 두 자료는 2차 자료이며 실제 기기에서 독립 검증하지 않았다.

기존 알로라 라이츄와 로토무 5개 폼에 더해 마기아나 500년 전의 색, 스트린더 로우한 모습, 모르페코 배고픈 모습, 게노세크트 카세트 4종을 프로젝트의 폼 ID와 종 ID로 명시했다. 메더 기본 폼이 가능해도 가라르 폼을 자동 허용하지 않는다. 기존 포켓몬·저장 데이터를 수정하지 않고 기술 학습 시 호환 여부만 바뀐다. 메가 등 다른 폼은 이번에 확정하지 않았다.
