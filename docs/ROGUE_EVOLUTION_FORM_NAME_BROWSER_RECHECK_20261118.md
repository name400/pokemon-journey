# 진화 폼 이름 표시 재검사 — 2026-11-18

격리 UI 시험 상태의 마빌크에 루비크림 진화 조건과 도구를 설정했다. Chromium의 모바일 세로 390×844와 PC 1280×800에서 실제 파티 화면 버튼이 `마휘핑 · 루비크림`으로 표시되고 실제 진화 명령을 실행한 뒤 결과 화면과 새로고침한 파티에 `Ruby Cream`이 나타나지 않는 것을 확인했다. 저장된 종·폼 인덱스와 도구 소모, 다른 슬롯·탐험 데이터도 확인했다. 시험용 상태에서의 직접 진화이며 자연 획득과 진행 전체는 아니다.

별도의 고라파덕 진화 시험에서는 사용자가 지정한 것으로 식별되는 `별명 · Normal`이 진화 결과와 저장 복원 후에도 보존됐다. 두 화면 크기 모두 통과했다. 표시 대상 폼명과 사용자 별명은 구분하며 저장 이름을 일괄 변경하지 않는다. 기존 진화·융합·표시 관련 엔진 검사 30건도 통과했다.

확인한 두 대표 사례에서 추가 결함은 재현되지 않아 게임 코드를 변경하지 않았다. 다른 폼·별명 조합, 실제 기기와 운영 저장은 이번에 검사하지 않았다. 외부 포켓몬 이미지는 대역이며 Sites에는 배포하지 않았다.
