# 미션 3 화살꼬빈 계열 성장 기술

[화살꼬빈](https://pokemondb.net/pokedex/fletchling/moves/9), [불화살빈](https://pokemondb.net/pokedex/fletchinder/moves/9), [파이어로](https://pokemondb.net/pokedex/talonflame/moves/9)의 Z-A 기술표를 기준으로 새로 포획하는 기본 폼의 레벨업·기술 다시 배우기와 진화 기술을 연결했다. 불화살빈 진화에는 날개치기, 파이어로 진화에는 브레이브버드를 제안한다. 기술 네 칸이 차면 기존 선택 대기열과 PP 보존 규칙을 쓴다.

새 미션 3 화살꼬빈의 최초 기술도 확인된 5레벨 기술로 만든다. 일반 야생 조우의 최초 기술은 기존 시스템처럼 해당 레벨 이하 마지막 네 가지로 고르는 잠정 규칙이다. 이미 시작한 전투와 이전에 포획한 개체, 미확인 폼·미래 버전 표식은 변경하지 않는다. 우두머리의 최초 기술도 바꾸지 않는다.

격리 단위 검사에서 레벨 경계·두 진화 기술·과거 및 미래 형식과 PP 보존을 확인했다. 격리 SQLite API에서 미션 3 포획·재접속·성장·기술 선택 및 두 차례 진화를 확인했다. 자료는 2차 출처이며 원작 실기·운영 D1·Sites 병합본은 확인하지 않았다. 운영 재검증 전 실패 기록은 유지한다.
