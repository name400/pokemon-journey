# 집게손톱과 같은 편의 점착

고정 원본 `7c0881255af5cd51992e513ff93c2f71adbe40e0`의 `MoveEffectPhase.applyOnTargetEffects`는 공격 기술의 대상에 집게손톱을 적용한다. `BattleScene.tryTransferHeldItemModifier`는 서로 다른 진영 사이의 이전에만 대상의 도구 도난 방지 특성을 확인한다. 기존 구현은 같은 편 대상의 점착도 차단했다.

새 도전의 `gripClawRule: source-v2`는 같은 편 대상의 점착으로 집게손톱을 막지 않는다. 적의 점착과 다른 이전 제한은 기존 검사를 유지하며, 이전 도전은 기존 규칙을 보존한다. 전투 스냅샷에도 규칙을 저장한다.

실제 더블 지진으로 같은 편의 도구 1개를 이전하면서 적의 도구는 점착으로 보존되는 경우, 기존 규칙, 저장 복구, 독립 전투 스냅샷 및 다른 슬롯을 자동 검사했다. 모든 기술·능력 무효화·융합 조합과 실계정 플레이의 원본 동등성은 별도 검증이 필요하다.

관련 도구·전투·융합·이벤트·챌린지 회귀는 일반 환경과 Worker 로더에서 각각 160/160 통과했다. 타입 검사와 프로덕션 빌드도 통과했다. 전체 테스트 스위트는 이번에 실행하지 않았다.
