# 추적 의뢰의 포켓몬 표시

사이드 미션 85의 불켜미와 사이드 미션 65의 데덴네가 기존 `cloudNpcTile`의 사람 스프라이트로 잘못 표시되던 문제를 고쳤다. 단계별 상호작용 좌표를 표시에도 재사용하고, 기존 필드 포켓몬 이미지 로딩과 대체 표시를 적용한다. Consei·여동생·Ante는 기존 사람 표시를 유지한다. 경로, 충돌, 의뢰 진행, 포획 및 저장 형식은 바꾸지 않는다.

단계별 포켓몬 종류·위치와 상호작용, 의뢰 종료·다른 구역·실내에서 숨김을 단위 검사했고 기존 두 의뢰 API 경로를 대표 검사했다. PC·모바일 Chromium에서 모의 이미지와 API로 캔버스, 종별 이미지 요청 및 대화를 확인했다. 이는 원작 실시간 추격이나 실제 원작 좌표를 구현한 것이 아니며, 실제 기기와 Sites 병합본은 미검증이다.
