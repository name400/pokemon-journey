# 모바일 스타터 선택 개선

520px 이하에서 전체 선택 화면을 문서 스크롤로 바꾸고 내부 목록의 고정 높이와 중첩 스크롤을 제거했다. 파티 빈 칸은 숨기고 상단 인원 수를 유지하며, 선택된 카드는 가로 스크롤·줄바꿈과 44px 제거 버튼을 사용한다. 세대 필터도 44px 버튼의 가로 스크롤로 만들고, 화면 하단 고정 메뉴에 가려지지 않도록 입력/버튼 스크롤 여백을 둔다. 데스크톱 CSS는 변경하지 않았다. 상세 패널은 기존 전체 화면 스크롤과 닫기 동작을 유지한다.

실제 페이지·격리 API Chromium 터치 에뮬레이션 320×568, 375×667, 390×844, 430×932에서 목록 최초 가시 높이는 각각 120/232/409/497px이며, 가로 페이지 넘침·페이지 오류 없이 페이지 이동과 파티 추가·출발 버튼 활성화를 검사했다. 14글자 한글 이름이 파티 카드 경계에 들어오는지도 검사했다. 챌린지 9종의 터치·키보드 조작, 실제 도전 시작/재접속은 375×667, 390×844, 844×390, 1280×850에서 통과했다. fixture는 실제 API의 선택 중 스타터 포함 조건을 반영하도록 고쳤다. 운영 계정이나 물리 기기는 사용하지 않았다.

테스트: `tests/browser/challenge-start/mobile-layout.mjs`, 기존 `check.mjs`; 로그 `/tmp/starter-clean-mobile-final.log`, `/tmp/starter-clean-check-final.log`. 별도 독립 체크아웃에서 테스트했다. 맨 작은 화면은 처음에 목록 한 행 이상이 보이고, 나머지는 페이지 스크롤로 확인한다.
