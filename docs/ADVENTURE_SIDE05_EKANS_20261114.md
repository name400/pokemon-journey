# 사이드 미션 5: 아보를 보여 줘

[Serebii](https://www.serebii.net/legendsz-a/sidemissions/i%27dliketoseeanekans.shtml)와 [보상 공략](https://trainerlab.top/lza/guides/missions/side-005/)에 따라 미션 6부터 마젠타 1번지 Ismene에게 의뢰를 받고 파티의 아보를 보여 주면 500원·복슝열매 3개·버치열매 3개·미네랄사이다 1개를 받는다. 아보는 소비하지 않는다. 인물의 정확한 2D 좌표와 대사는 초안이다.

보상은 빈 공간만큼 지급하고 나머지를 보관하며, 리비전으로 중복 수령을 막는다. 보상 열매는 기존 지닌 도구 경로를 이용한다. 미네랄사이다는 필드 또는 지원하는 전투에서 자기 파티 한 마리의 HP를 최대 50 회복한다. 전투 사용은 한 턴을 소비하며 재고를 한 번 차감한다. 강제 교체·대여 전투·식당 연속전과 연합 제한은 기존 도구 정책을 유지한다. 기존 포켓몬과 보상 형식이 불명확한 미래 저장을 임의 수정하지 않는다.

격리 SQLite API에서 해금, 파티 외 아보 거절, 보유 아보·색·지닌 도구 보존, 보상 한도·재접속·중복 방지, 열매 장착·해제와 사이다 필드 사용을 검사했다. 실제 기기·운영 D1·Sites 병합본과 PC·모바일 화면은 확인하지 않았다.

후속: 단일·1대2·동료·세 자리 전투의 자기 파티 회복, 타인의 포켓몬·기절·만전·대여·강제 교체·식당 사용 거절, 재접속·재고 중복 차감을 격리 API에서 검사했다. 모의 브라우저에서 PC·모바일의 대기 포켓몬 선택과 새로고침도 확인했다. 실기·운영 D1·실제 Sites 병합본은 확인하지 않았다.
