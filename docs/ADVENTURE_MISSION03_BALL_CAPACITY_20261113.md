# 미션 3 포획 연습 볼과 보유 한도

[원작 공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough%3APok%C3%A9mon_Legends%3A_Z-A/Part_3)은 화살꼬빈 연습 전에 몬스터볼 10개, 파르빗 포획 후 10개를 더 받는다고 설명한다. 기존 구현에서는 지갑에 볼이 90개 이상이면 지급 트랜잭션이 99개 한도를 넘겨 초기 포획 연습을 시작할 수 없었다.

두 지급 단계에서 현재 공간에 들어가는 몬스터볼만 받고, 나머지를 저장해 동료에게서 나누어 받을 수 있도록 했다. 미수령 수량이 있으면 연구소 방문 이후에도 같은 구역의 동료가 남는다. 0개일 때의 기존 1개 보충과 도감 확인은 별도 선택지로 보존하며, 기존 저장의 미수령 수량을 임의 생성하지 않는다. 분할 지급은 게임 내 보관 한도를 위한 처리이며 원작의 정확한 보관 규칙은 아니다.
