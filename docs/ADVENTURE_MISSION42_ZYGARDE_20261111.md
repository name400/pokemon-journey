# 미션 42 지가르데 전투와 포획

[원작의 지가르데 기록](https://bulbapedia.bulbagarden.net/wiki/Zygarde_(game))은 미션 42의 세 전투 폼과 포획 개체를 레벨 84로 기록한다. 신규 3연전의 각 폼에 확인된 기술을 적용하고, 새로 생성하는 포획 개체는 레벨 84·조용한 성격·고정 개체값 31/31/15/31/28/19·스웜체인지와 확인된 기술 네 개를 갖도록 했다. 포획 볼은 플레이어가 선택한다. 전투는 기존 턴제이며 원작의 무특성·실시간 기술 연출은 재현하지 않는다.

변경 전에 이미 진행 중인 배틀 스냅샷과 포획 창, 포획된 기존 개체는 덮어쓰지 않는다. 구역 20의 정확한 대결 지형은 여전히 초안이다.
