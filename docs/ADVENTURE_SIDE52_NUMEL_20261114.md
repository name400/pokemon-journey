# 사이드 미션 52: 얼어붙은 둔타

[Serebii](https://www.serebii.net/legendsz-a/sidemissions/numelfrozensolid.shtml)와 [공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_41-60)을 참고해 미션 19의 Canari 승리 후 구역 12에서 의뢰를 받고 선두 포켓몬의 기본 위력 95 이상 불꽃 기술로 둔타를 구조한다. 보상은 900원, 얼음상태치료제 3개와 경험사탕 M 2개다. 가방에 공간이 없으면 보상을 보류하며 중복 요청은 기존 리비전으로 거절한다.

기존에 막힌 나무 칸을 이용한 NPC·얼음 표시는 정확한 원작 좌표가 아닌 2D 초안이며 실제 얼음 물체와 실시간 기술 연출은 근사다. 기존 이동 경로, 연못 하층과 저장은 변경하지 않는다. 격리 API에서 기술 조건·저장 복원·보상 한도·중복 요청과 파티 보존을 대표 검사했다. 실제 기기·운영 D1·Sites 병합본은 확인하지 않았다.
