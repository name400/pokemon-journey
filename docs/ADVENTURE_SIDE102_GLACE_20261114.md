# 사이드 미션 102: 차가운 도전

[Serebii](https://www.serebii.net/legendsz-a/sidemissions/achillingchallenge.shtml)와 [Thonky](https://www.thonky.com/pokemon-legends-z-a/side-mission-102-a-chilling-challenge)에 따라 미션 35에서 연구소 방문 후 AZ를 만난 뒤 구역 12 코트 뒤의 Glace에게 의뢰를 받는다. 얼음귀신·눈설왕·눈여아의 레벨과 기술을 해당 자료에 맞춰 적용한다. 기존 턴제 엔진의 얼음 상태와 야외 날씨를 사용한다.

승리 상금 4,956원과 별도의 의뢰 보상 4,200원·녹지않는얼음·얼음의돌은 저장 리비전으로 중복을 방지한다. 가방이 가득 차면 보상 전체를 대기시키고 나중에 받을 수 있다. 구형 저장에 미수령 보상을 추정해 만들지 않는다. 의뢰 단계는 여행 수첩에서 추적할 수 있다.

[Bulbapedia의 공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_101-119)은 플레이어 파티를 얼음 타입으로 제한한다고 적지만, Serebii와 Thonky에는 명시되지 않는다. 실기에서 확인되지 않아 현재 게임은 이 제한을 적용하지 않는다. NPC 정확한 칸과 외형, 실시간 전투는 2D·턴제 근사다.

격리 API에서 해금 경계·수락·수첩 추적·상대 편성·기권 후 재도전·승리·가방 한도·재접속·중복 요청을 검사했다. 상대 HP는 시험용으로 조정했으며 자연 난이도·원작 기기·운영 D1·Sites 병합본은 확인하지 않았다.
