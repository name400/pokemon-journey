# 딜리버드 교환 보상 한도 처리

기존 교환은 확정 보상이 한도에 도달했을 때 선두 포켓몬에게 조개껍질방울을 대체 지급했다. 선두의 한도도 찬 경우에는 실제 지급 없이 보상 이름만 반환하고 돈이나 교환 도구를 소비했다.

교환 전에 보상과 대체 지급 가능 슬롯을 검증한다. 선두가 가득 차면 다른 파티원을 검사하고, 모두 가득 차면 거래를 거부해 자금·도구를 보존하며 선택 취소를 허용한다. 조개껍질방울 자체를 교환하는 경우에는 교환으로 비워지는 자리를 고려한다. 기존 저장 포맷은 바꾸지 않는다. 다른 파티원에게 대체 지급하는 처리와 거래 거부는 데이터 손실을 막기 위한 이 프로젝트의 정책으로, 원본 포켓로그와 완전히 같다고 주장하지 않는다.

검증: 딜리버드 이벤트 선택·저장 복원·확정, 금전/도구 각각의 전원 한도 거부와 취소, 다른 파티원 대체 지급, native와 modifier 조개껍질방울 교환을 일반 및 Worker 로더에서 검사했다. 운영 계정 및 기기에서 검증하지 않았다.
