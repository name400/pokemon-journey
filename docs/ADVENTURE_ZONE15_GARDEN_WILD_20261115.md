# 구역 15 서쪽 정원 필드 조우

[구역 공략](https://allthings.how/pokemon-legends-z-a-wild-zone-15-spawns-alphas-and-rooftop-larvitar/)은 서쪽 정원에서 낮에 휠구·독침붕, 밤에 고우스트를 볼 수 있다고 설명한다. [출현 자료](https://www.serebii.net/pokearth/lumiosecity/wildzone15.shtml)는 각 종과 레벨 범위를 기재한다. 기존 풀숲 무작위 조우 외에 세 종의 보이는 필드 개체를 추가했다. 각 종의 단일 개체, 고정 레벨과 정확한 2D 좌표는 임시 각색이며 원작에서의 개체 수·실시간 움직임을 검증한 것은 아니다.

기존 공통 조우의 시간대·이로치·무작위 우두머리·소진과 재출현 규칙을 사용하고 각 개체 기록을 독립적으로 저장한다. 플레이어가 같은 칸에 있으면 출현 표식을 숨겨 기존 저장과 발밑 출현을 보호한다. 옥상층·기존 고정 우두머리와 도구 및 진입 조건은 바꾸지 않는다. 운영 D1과 모바일 이동 문제는 검증하지 않았으며 실패 기록을 유지한다.
