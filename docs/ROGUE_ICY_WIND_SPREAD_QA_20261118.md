# 얼다바람 전체 공격과 저장 복원

고정 원본 대조 기록 [멀티렌즈 속도 감소 전체 공격](MULTILENS_SPEED_SPREAD_FIRST_QA_20261105.md)은 얼다바람이 두 상대에게 피해와 속도 감소를 적용하고 신규 규칙에서 앞 대상의 처리를 반영하도록 명시한다. 기존 `spreadSecondaryOrderRule: source-v3`도 각 대상의 속도 감소를 다음 대상 피해 전에 처리한다. 이번 검사는 해당 범위의 실행과 복원을 추가 확인한 것이며, 원본을 이번에 다시 다운로드하거나 전체 기술을 대조한 것은 아니다.

시험용 더블 전투에서 멀티렌즈 1개를 가진 사용자의 실제 명령을 두 대상에게 실행했다. 두 타격 각각 첫 대상 피해→첫 대상 속도 감소→둘째 대상 피해→둘째 대상 속도 감소 순서였고, 두 대상의 최종 속도 단계는 -2였다. 저장 인코딩·복원 후에도 양쪽 HP와 속도 단계, 기술 PP와 별도 데이터가 유지됐다. 양 상대의 프레셔 때문에 기술 PP는 사용 1과 추가 2를 합쳐 3 감소했다. 기존 방어·클리어바디·대타·기절·구형 규칙 등의 같은 파일 검사까지 총 21건이 통과했다.

처음 작성한 검사는 양쪽 관점의 연속 로그 행을 별도 피해로 세고 프레셔의 추가 PP 소모도 빠뜨려 실패했다. 기존 로그 방식 및 전투의 실제 특성을 대조해 시험 단언을 수정했으며 재실행에서 통과했다. 이 표본에서 게임 결함은 재현되지 않아 게임 로직은 변경하지 않았다. 모든 특성·도구·대상 조합, 원본 난수 흐름, API·브라우저·실기기 및 운영 저장은 이번에 검사하지 않았다. Sites에는 배포하지 않았다.
