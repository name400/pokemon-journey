# 베르 5번지와 8번지 지상 접근

[베르 5번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-5.html)는 남쪽의 베르 8번지 접근을, [베르 8번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-8.html)는 북쪽의 베르 5번지 접근을 설명한다. 이전 지도에서는 두 번지를 직접 왕복할 수 없었다.

두 지상 화면에 왕복 접근을 추가했다. 출입 위치와 길의 폭·선형은 2D 추정이다. 기존 호텔 화면과 야생 구역 1의 출입구, 베르 광장과 4번지 연결을 보존하며 기존 통행 칸을 막지 않는다. 저장 형식과 미션 상태를 바꾸지 않았다.

대표 단위 검사에서 새 출입 양방향·저장 복원, 기존 호텔·야생 구역 접근과 옥상 관련 경로를 확인했다. 원작 실기·운영 D1·실제 Sites 병합본은 확인하지 않았고 모바일 이동 오류와 배포 검사 실패 기록을 유지한다.
