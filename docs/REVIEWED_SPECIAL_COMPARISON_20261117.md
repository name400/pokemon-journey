# 승인 특수 연출 대조 (2026-11-17)

검증된 원본 영상 4개와 격리 Chromium 960×540 실제 클래식 명령 재생을 정지 화면으로 각각 대조했다. 영상 프레임은 메가 4.5초, 다이맥스 3.5초, 테라스탈 6.4초, Z기술 5.6초를 사용했다. 게임은 서로 다른 상태에서 일시 캡처했으므로 시간 동기화나 픽셀 동일성 검사는 아니다. 최신 v52 메뉴·HUD 위치가 영상 속 이전 UI보다 우선한다.

* 메가: 원본은 암전된 전장 중앙에 큰 정면 헤라크로스를 보여주고 무지개 선·백색 실루엣·메가형을 차례로 보여준다. 게임은 기존 배틀 위치에서 색상 효과와 폼을 교체한다. 중앙 정면 전환·리본·타이밍은 여전히 다르며 이번 캡처의 메가형 그림은 테스트 대체 이미지여서 실제 이미지 일치 판단이 불가능하다.
* 다이맥스: 원본의 서로 떨어진 세 자홍색 구름과 바닥 고리를 반영했다. 게임은 현재 더 짧은 시간의 광선·조각 효과를 쓰고, 확대 크기와 정착 속도·움직이는 입자는 영상과 다르다. 거다이맥스도 이 구름 효과를 공유한다.
* 테라스탈: 원본의 투명 결정 껍질을 근사하는 선형 다면체를 서버의 테라 발동 이벤트 동안 추가했다. 왕관 종류는 실제 테라 타입을 따른다. 원본의 면 굴절, 별빛, 등장·소멸 시간과는 다르다.
* Z기술: 실제 Z파워 이벤트에 금색 고리 효과가 나오는 것을 확인했다. 원본은 이후 배우가 돌진하여 별 모양으로 부딪히지만 현재 게임은 해당 돌진·충돌을 재현하지 않는다. 피해·명중·PP는 엔진 결과를 사용한다.

실제 포켓로그 특수 연출 재생에서 큰 크림색 전투 기록이 배우를 가리던 것을 확인해, 단일 v52 재생 중 기록을 아래 메시지 위치로 옮기고 중복 폼 문구 및 잠긴 명령의 시각 표시를 숨겼다. 기록 데이터는 유지한다. 영상의 원본은 3D 스타일 배우·숲 배경이고 게임은 기존 2D 스프라이트·배경이다. 960×540 격리 화면의 왼쪽은 앱 사이드바에 일부 가려져 화면 전체 비교가 불완전하다. 실제 모바일 기기, 오디오 청취 및 전체 프레임 비교는 하지 않았다.

격리 브라우저에서 메가·다이맥스·테라·Z 각각 실제 명령과 서버 연출 이벤트, 기술 PP 1회 감소, HP 유지 또는 다이맥스 HP 비율, 저장된 결과와 새로고침을 검사했다. 테라스탈은 오브 소비도 확인했다. 메가 장면은 리자몽, 다른 세 장면은 이브이를 사용하며 상대는 잠만보다. 거다이맥스 등장과 테라 특수 폼은 별도 PC·모바일 크기 검사에서 확인했다. 탐험의 신형·구형 저장에서 메가 외 신규 변신 차단, 진행 중 구형 변신 복구, 포켓로그의 다이맥스·테라·Z 조건과 저장 회복은 별도 엔진 회귀로 검사했다. 운영 데이터와 배포는 사용하지 않았다.

## 중앙 메가와 Z 돌진 추가

실제 단일 배틀에서 새 메가 폼이 확정된 이벤트에만 기존 2D 포켓몬의 정면 이미지로 중앙 확대, 배경 암전, 색 선과 국소 섬광, 원래 폼에서 메가 폼으로의 전환을 표시한다. 화면 상태 변경은 기존 서버 이벤트와 중단 처리를 따르며, 다중 배틀이나 이미 메가인 기존 상태에 임의로 재생하지 않는다. 게임의 메가 발동 이벤트는 기본 2.2초로, 원본의 약 10초와 다르고 선·결정 효과 및 2D 픽셀 이미지는 원본 3D 스타일 영상과 다르다. 원본 영상의 헤라크로스와 달리 격리 검사는 리자몽을 사용했다.

승인된 울트라대시어택 예시에 한해, 서버 이벤트에서 해당 사용자의 해당 상대에 대한 실제 적중 피해가 확인되면 배우가 대상 방향으로 이동했다가 돌아가고 금빛 속도선을 표시한다. 명중 효과는 별도의 실제 피해 이벤트에서 표시한다. 빗나감·면역·대상 불명이나 다른 기술에 피해를 추정해 적용하지 않는다. 기본 기술 연출은 1.4초로 영상과 타이밍이 다르며 다른 Z기술의 고유 돌진은 미구현이다.

960×540과 390×844 격리 Chromium에서 배틀 동안 사이드바가 장면을 가리지 않게 처리하고 화면 가장자리의 실제 클릭 대상을 확인했다. 960×540에서는 실제 정면 일반 리자몽과 메가리자몽 Y 스프라이트를 각각 표시해 확인했다. 별도 격리 실제 명령에서 Z 돌진 중 위치 이동과 크기 유지, 이어지는 상대 피해 충돌, PP 감소와 새로고침 보존을 확인했다. 메가 연출 중 움직임 줄이기를 켜 중단한 뒤에도 저장 결과가 유지됐다. 별도 수동 건너뛰기 버튼은 이 배틀에 없으며 그 경로는 검사하지 않았다. 빗나감·면역의 돌진 제외는 순수 이벤트 검사이고 해당 엔진·브라우저 조합은 미검증이다. 포켓로그 더블, 탐험 메가의 중앙 연출, 실제 모바일 기기와 원본 프레임별 일치는 추가 검증이 필요하다.

## 탐험·더블 재생 및 시간 조정

위의 2.2초 단일 메가 수치는 이전 구현이다. 원본에서 정면 장면이 대략 0.65~7.7초에 걸리는 점을 참고해, 신형 단일 배틀의 메가 폼 이벤트를 기본 속도 7초로 조정했다. 격리 탐험 실제 엔진 테스트에서 중앙 장면 유지 시간이 약 6,945ms였고 종료 후 메가 폼이 보였다. 포켓로그 더블은 중앙 단일 장면을 강제로 적용하지 않으며 기존 2.2초 폼 이벤트와 슬롯 배치를 유지한다. 여러 사건이 재생 한도에 걸리거나 2배속·움직임 줄이기를 사용할 때 시간은 달라진다. 원본 영상 전체가 10초인 것과 동일하다는 뜻은 아니다.

원본 Z파워 준비와 기술 선언 구간의 약 1.8초를 참고해 실제 `zpower` 폼 이벤트를 기본 속도 1.8초로 조정했다. 울트라대시어택 돌진과 실제 피해 충돌은 기존처럼 확정된 결과로만 표시한다. 원본과 정확한 프레임·속도 곡선, 다른 Z기술의 고유 장면은 여전히 미검증·미구현이다.

390×844 격리 Chromium의 탐험 단일에서 실제 엔진 메가 명령, 전체 장면 완료와 중간 새로고침 각각을 확인했다. 메가파워 남은 턴과 현재 HP가 보존됐다. 이 검사는 격리 API 응답을 가로채 실제 엔진을 호출하고 JSON 복사본을 유지하며, 운영 D1이나 실제 사용자 저장 검사는 아니다. 포켓로그 더블은 격리 API와 실제 클래식 저장 직렬화를 사용해 두 마리의 명령, 선택된 한 마리의 변신 효과, 양쪽 HP와 연출 중 새로고침을 검사했다. 두 검사 모두 테스트 대체 이미지를 사용하므로 원본과 시각 일치 여부는 입증하지 않는다. 메가 중 움직임 줄이기와 Z파워 실제 명령·PP·돌진·피해 순서도 다시 검사했다. 첫 진입 등장 연출은 더블 검사에서 움직임 줄이기로 생략했다. 실제 기기, 운영 환경, 다중 기술·교체·기절의 모든 조합은 미검증이다.

## 다이맥스 유지 중 빛줄기와 입자

승인 다이맥스 영상의 0.6초와 4.5초를 확인하면 거대화한 이브이 주변에 가는 분홍 선 세 개와 작은 떠오르는 점이 유지된다. 기존 화면에는 구름·바닥 고리·일시적 변신 효과가 있었으나 이 유지 효과는 없었다. 엔진의 다이맥스 또는 거다이맥스 상태를 표시하는 포켓몬에 선과 입자를 추가했다. 해당 상태가 해제되면 함께 제거되며 움직임 줄이기와 게임의 애니메이션 끄기에서는 반복 움직임을 멈춘다. 판정·HP·PP·저장과 아군/상대 선택은 변경하지 않는다.

격리 Chromium에서 포켓로그 단일의 실제 다이맥스 명령·효과·PP·HP 비율과 재접속을 960×540과 390×844에서 검사했다. 모바일 검사에서 움직임 줄이기를 전환해 반복 움직임이 중지됨도 확인했다. 실제 더블 명령에서 선택한 한 포켓몬에만 표시되는지와 2배속·PP·재접속을 확인했고, 거다이맥스 등장 재사용은 1280×800·390×844에서, 3턴 종료·HP 비율·PP·재접속은 별도 실제 명령으로 검사했다. 화면의 이브이는 기존 2D 픽셀 자산이고 다른 포켓몬 중 일부는 대체 이미지다. 영상과 선·입자 운동의 정확한 프레임, 원본의 1.6배 확대 대비 현재 크기 차이, 모든 종의 가림 및 실제 기기는 미검증이다. 재생 취소 단위 검사와 타입 검사는 통과했으며 Sites에는 배포하지 않았다.
