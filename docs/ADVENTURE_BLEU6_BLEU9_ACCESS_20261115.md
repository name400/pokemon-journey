# 블루 6번지와 9번지 지상 접근

[블루 6번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-6.html)는 서쪽 블루 9번지 접근을, [블루 9번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-9.html)는 북동쪽 블루 6번지 접근을 설명한다. 이전 지도는 두 구역을 오갈 때 블루 8번지를 경유해야 했다.

두 지상 지도에 왕복 접근을 추가했다. 출입 타일과 길의 폭·선형은 원작에서 측정되지 않은 2D 추정이다. 기존 블루 8번지·4번지, 상가 통로와 에스파스 비드 연결을 유지하며, 상가 건물 입구와 기존 통행·저장 위치를 바꾸지 않았다. 미션·보유함 데이터도 변경하지 않는다.

대표 지도 검사에서 양방향 이동, 기존 저장 복원과 미션 진행값, 상가 건물 접근 및 블루 8번지 연결을 확인했다. 원작 실기, 운영 D1 및 Sites 병합본은 확인하지 않았으므로 모바일 이동 오류와 배포 검사 실패 기록을 유지한다.
