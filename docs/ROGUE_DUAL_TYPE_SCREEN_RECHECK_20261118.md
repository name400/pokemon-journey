# 전투 복수 타입 표시 재검사 — 2026-11-18

사용자가 지적한 전투 HUD의 복수 타입 표시를 전용 포트의 격리 Vite 서버와 Chromium에서 확인했다. 실전 컨트롤러와 저장 codec을 사용한 시험 상태이며 운영 서버와 사용자 저장은 사용하지 않았다. 화면 크기는 PC 1280×800 및 모바일 세로 390×844, 움직임 줄이기 설정이다.

두 크기에서 리자몽의 불꽃·비행 두 배지를 확인하고 실제 메가 X 명령 뒤 불꽃·드래곤 두 배지, 고스트 테라 명령 뒤 고스트 한 배지, 메타몽의 실제 변신 뒤 불꽃·비행 두 배지와 각각 새로고침 후 표시 및 저장 불변을 확인했다. 검사에는 배지의 표시 상태·양수 크기·화면 안 위치와 서로 겹치지 않는 사각형 확인을 추가했다. 여섯 화면 경로가 통과했으며 이 표본에서 신고된 타입 누락은 재현되지 않아 게임 코드는 변경하지 않았다.

첫 실행은 Playwright 패키지 경로를 지정하지 않아 모듈 로딩에 실패했고, CommonJS 경로도 이름 지정 export를 제공하지 않아 실패했다. 설치된 공식 `index.mjs` 경로를 지정한 재실행은 통과했다. 외부 포켓몬 이미지는 대역이며 실기기·다른 크기·종과 더블 화면, 원본 이미지와의 픽셀 일치 및 운영 저장은 이번 검사에서 확인하지 않았다. 기존 데이터와 다른 미추적 파일을 보존하고 Sites에 배포하지 않았다.

후속 재실행에서 변신 전 배지의 첫 측정이 크기 0으로 한 번 실패했다. 배지가 보일 때까지 기다린 뒤 측정하도록 검사를 보완하자 여섯 경로가 통과했다. 해당 실패가 실제로 사용자에게 지속적으로 보이는 UI 결함이라는 증거는 확인하지 못했으며 게임 화면 코드는 변경하지 않았다.
