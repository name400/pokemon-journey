# 사이드 미션 98: 특대 폼 호바귀

[원작 의뢰 안내](https://www.serebii.net/legendsz-a/sidemissions/jumbovarietypumpkaboo.shtml)와 [포획 공략](https://www.nintendolife.com/guides/pokemon-legends-z-a-how-to-find-a-jumbo-pumpkaboo)을 참고해 북쪽 대로의 Taille에게 의뢰를 받고, 우두머리가 아닌 특대 폼 호바귀를 확인 후 건네면 6,000원·숙달의씨 5개·이상한사탕 2개를 받는다. 특대 폼 ID와 우두머리 표기를 별도로 확인하며, XL 크기 또는 우두머리 표시만으로 폼을 추정하지 않는다.

인도는 탐험 보유함과 파티에서 선택한 포켓몬을 제외한다. 다른 게임과 공유하는 보유함 원본은 기존 교환과 같이 삭제·수정하지 않는다. 아이템을 지녔거나 유효하지 않은 개체, 교환 대기 중인 개체와 마지막으로 싸울 수 있는 파티원은 건넬 수 없다. 원본 데이터·소유권·다른 파티원의 상태와 저장 리비전을 커밋 시 확인하고, 가방 공간이나 재화 한도가 부족하면 인도와 보상을 함께 보류한다. 기존 저장과 알 수 없는 미래 단계는 완료로 추정하지 않는다.

해금은 미션 35 시작 이후로 적용했다. 자료에 따라 미션 31 완료·35 시작·랭크 A 등 설명이 달라 실기 확인 전 잠정 조건이다. Taille의 정확한 좌표는 기존 2D 북쪽 대로의 초안이다. 격리 SQLite API에서 잘못된 폼·우두머리·확인 누락·마지막 파티원·가방 한도·교환 대기·중복 요청과 재접속, 공유 원본 보존을 확인했다. 별도 검사에서 의뢰 표시와 구형·미지의 저장을 확인했다. PC·모바일 실제 화면, 운영 D1, 원작 기기와 Sites 병합본은 확인하지 않았다.
