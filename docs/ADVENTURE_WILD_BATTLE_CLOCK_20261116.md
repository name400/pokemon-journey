# 일반 야생 배틀의 시계

[원작 시간 자료](https://bulbapedia.bulbagarden.net/wiki/Time#Pok%C3%A9mon_Legends:_Z-A)는 일반 야생 배틀 동안 시간이 흐르고 미션 중 정해진 배틀은 정지한다고 설명한다. 2차 자료이며 원작 실기 검증은 하지 않았다. 기존 구현은 모든 전투 중 시계를 멈췄다.

미르시티에서 새로 시작한 일반 풀숲 조우에만 전투 스냅샷 표식을 부여해 야외에서 시간이 흐르게 한다. 실내·하수도는 정지 우선이며, 이전에 시작된 전투와 미션·트레이너 전투는 기존 동작을 유지한다. 고정 표시 개체 등 다른 조우 경로는 아직 이 변경의 대상이 아니다. 전투는 기존 포켓몬식 턴제 그대로다. 시계가 흐르는 야생 배틀은 연결이 끊겨도 기존 야외 시계처럼 시간이 흐르며, 이는 원작 종료 동작을 검증한 결과가 아니다.

격리 API에서 구역 1 야생 조우·재접속·19시에서 20시 경계·도주 동안 같은 조우와 파티·재화를 확인했고 기존 로열 전투·호텔·하수도 정지도 대표 검사했다. 단위 검사는 신규·구형·실내 전투를 비교했다. 실제 운영 D1·기기·Sites 병합본과 모든 야생 조우 경로는 미검증이다.

메뉴·지도는 브라우저의 `screen` 상태로만 열리고 서버와 공유되지 않는다. 단순 저장 플래그는 탭을 닫거나 연결이 끊기면 정지가 고착될 수 있고, 여러 탭의 오래된 종료 요청이 다른 탭의 정지를 해제할 수 있다. 만료·소유권·동시 요청 처리와 사용자 행동의 관계를 별도로 검증하기 전까지 적용하지 않는다.
