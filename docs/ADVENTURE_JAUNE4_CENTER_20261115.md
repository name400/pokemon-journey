# 존느 4번지의 이베르날 포켓몬센터

[존느 4번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-4.html)는 이베르날 포켓몬센터를 기록한다. 기존 건물의 막힌 타일에 센터 표식과 회복을 연결했다. 외형과 좌표는 잠정 2D 배치다.

기존 이베르날 센터와 등록 ID·빠른 이동 및 복귀 지점을 공유하므로 중복 등록되지 않는다. 기존 출입과 저장 형식을 유지한다. 원작 실기와 실제 Sites 병합본은 확인하지 않았다. 모바일 이동 오류 기록은 운영 재검증 전까지 유지한다.
