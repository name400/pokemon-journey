# 루주 2번지의 센트리코 포켓몬센터

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/rouge-sector-2.html)는 루주 2번지에 센트리코 포켓몬센터가 있다고 기록한다. 기존 건물의 막힌 타일에 센터 표식과 회복을 연결했다. 외형과 좌표는 2D 초안이다.

인접 거리의 기존 센트리코 센터와 등록 ID·빠른 이동 및 복귀 지점을 공유하므로 센터가 중복 등록되지 않는다. 기존 출입과 저장 형식은 유지한다. 원작 실기와 실제 Sites 병합본은 확인하지 않았으며, 모바일 이동 오류 기록은 운영 재검증 전까지 유지한다.
