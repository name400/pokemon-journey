# 벤치에서 파티와 쉬기

[친밀도 자료](https://bulbapedia.bulbagarden.net/wiki/Friendship#Pok%C3%A9mon_Legends:_Z-A)는 벤치에서 최소 10초 함께 있으면 파티 전체의 친밀도가 10 오른다고 설명한다. 기존에 시간 변경을 제공하던 벤치에서 파티와 함께 앉고, 서버 시간으로 10초 이상 지난 뒤 다시 벤치를 선택해 일어날 수 있다. 각 파티원에게 기존 평온의방울·럭셔리볼 보정을 적용한다. 포켓몬이 기절했어도 파티에 있으면 포함하며 보유함은 건드리지 않는다.

휴식 기록은 시작 위치·방향·대상 벤치·파티를 저장한다. 다른 행동에 성공하면 휴식이 취소되고, 만료 전이나 파티·위치가 다른 상태의 완료 요청은 거절한다. 리비전 조건으로 중복 지급을 막고 알 수 없는 미래 형식의 기록은 덮어쓰지 않는다. 기존 아침·밤까지 쉬기 기능은 그대로다. 화면의 낮은 자세는 2D 근사이며 실제 시간과 모션 재현은 아니다. 접속이 끊겨도 같은 위치와 파티의 저장 상태로 남은 시간은 서버 시간에 포함된다. 10초가 지나도 자동 지급하지 않고 사용자가 일어나기를 선택해야 한다.

격리 API에서 9,999ms 거절·10초 수령, 파티·기절·보유함·평온의방울, 재접속, 방향 전환 취소, 구형·미래 기록·오래된 요청, 기존 벤치 시간 변경과 연구 활동을 대표 검사했다. 단위 검사에서 위치·파티 검증을 확인했고 타입 검사도 통과했다. 실제 PC·모바일 화면, 원작 기기, 운영 D1 및 Sites 병합본은 확인하지 않았다. 정확한 원작 보정 반올림과 휴식 중 실시간 연출은 미확인이다.
