# 사이드 미션 27: 화석에서 되살아난 포켓몬

[의뢰 자료](https://www.serebii.net/legendsz-a/sidemissions/restoredfromafossil.shtml)와 [연구소 안내](https://bulbapedia.bulbagarden.net/wiki/Sycamore_Pok%C3%A9mon_Lab)에 따라 메인 미션 10의 폭주 사건 공개 이후 2층 Reg에게 구입비 20,000원을 받고, 베르날 애비뉴의 돌 가게에서 턱화석·지느러미화석을 각각 20,000원, 비밀의호박을 30,000원에 구입한다. 가게 위치와 연구실의 정확한 타일은 초안이다.

첫 턱·지느러미화석 복원은 레벨 20 티고라스·아마루스와 2,500원·딱딱한돌·시마열매 10개를 한 번 지급한다. 의뢰 후 비밀의호박을 포함한 화석을 계속 소모해 프테라 등을 복원할 수 있다. 저장된 화석도 사용할 수 있으며 파티가 가득 차면 보유함으로 보낸다. 보상 가방 공간이 부족하면 화석 소비나 포켓몬 지급 없이 다시 시도할 수 있다. 구버전의 후반 랭크 저장도 의뢰를 시작할 수 있도록 한다.

현재 돌 가게는 거리 상호작용 초안이며 원작의 실내는 미구현이다. 진화석 판매는 [구현 기록](ADVENTURE_STONE_EMPORIUM_20261112.md)을 참고한다. 신규 복원은 25가지 성격과 각 개체값 0~31을 독립적으로 추첨하고, 이로치는 원작의 기본 확률 1/4096으로 단 한 번 판정한다. [확률 자료](https://rotomlabs.net/legends-z-a/shiny-rates)에 따라 빛나는부적의 보정은 적용하지 않는다. 각 값은 복원 시 개체에 저장되며 기존에 받은 개체는 변환하지 않는다. 복원 우두머리 여부와 원작의 정밀 난수 생성 과정은 구현하지 않았다. 실제 운영 기기에서는 검증하지 않았다.
