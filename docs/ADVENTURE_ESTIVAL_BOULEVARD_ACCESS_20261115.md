# 에스티발 애비뉴와 남쪽 큰길 연결

[에스티발 애비뉴 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/estival-avenue.html)는 남서쪽 끝이 남쪽 큰길이라고 설명한다. 기존 지상 화면에 왕복 연결을 추가했다. 출입 좌표와 길의 선형은 잠정 2D 배치다.

기존 에스파스 비드 출입과 야생 구역 9·10의 해금 조건, 저장 형식을 유지하며 남쪽 큰길의 옥상 및 알 수 없는 층 상태를 덮어쓰지 않는다. 원작 실기와 실제 Sites 병합본은 확인하지 않았다. 모바일 이동 오류 기록은 운영 재검증 전까지 유지한다.
