# 미션 26 Asami의 메가진화 조건

[원작 진행 안내](https://www.thonky.com/pokemon-legends-z-a/main-mission-26-an-invitation-from-the-sbc)는 Asami와의 배틀에서 메가진화를 보여주고 승리해야 한다고 설명한다. 새 배틀에서는 플레이어 포켓몬의 실제 메가진화가 일어난 뒤 승리한 경우에만 SBC 초대 단계로 진행한다. 메가진화 없이 승리하면 대전금 200원과 경험치를 받고 재도전한다. 배틀 중 저장·재접속 시 조건을 유지한다.

이미 진행 중이던 이전 배틀 저장에는 새 조건 플래그가 없으므로 기존 승리 처리로 완료할 수 있다. 이전에 완료한 스토리는 되돌리지 않는다. 원작 의상 지급과 장면은 아직 구현되지 않았다. 실제 전투는 기존 턴제이며, 포켓몬이 이미 메가 모습인 상태만으로 새 메가진화로 기록하지 않는다.
