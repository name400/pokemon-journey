# 구역 12 배틀코트와 접근

별도 조사에서 원작 지도·3D 화면을 분석해 북서 배틀코트의 철망, 남서쪽의 낮은 연못과 동쪽 보행로를 확인했다. [구역 자료](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_12)는 공원과 여섯 출입구, 코트의 기술머신·도구를 설명한다. 이번 환경에서는 원본 지도 이미지를 직접 보지 못했다.

기존 북서 코트 외곽에 통과할 수 없는 철망과 남쪽 개구부를 만들고 눈 공원과 구분되도록 표현했다. 입구로 들어가 코트의 바위와 기술머신에 접근하며, 기존 연못 하층·얼음 다리·여섯 주요 출입과 호환용 옛 출입구, 야생 개체·도구 상태를 유지한다. 울타리의 정확한 타일과 문 위치는 원작에서 확인하지 못했으며 남쪽 개구부는 2D 초안이다. 높이 수치와 다른 구역 경계의 정밀 형상도 미확인이다.

새 울타리 칸에 저장된 기존 지상 위치는 저장 리비전이 일치할 때만 같은 구역의 가까운 보행 칸으로 복원한다. 새 저장에는 레이아웃 표식을 기록하며 연못 하층에는 이 복원을 적용하지 않는다. 기존 보유 포켓몬·재화·아이템·바위·조우 기록은 바꾸지 않는다.

구역 단위 검사에서 모든 새 울타리 칸의 구형 저장 복구와 출구 접근, 코트 출입 및 연못층을 확인했다. 격리 SQLite API에서 구형 저장·재접속, 코트 진입과 기술머신 중복 방지, 출입구·계단·얼음 다리 회귀를 검사했다. PC·모바일 Chromium은 모의 API와 대체 이미지를 사용했다. 원작 실기·운영 환경은 검사하지 않았다.
