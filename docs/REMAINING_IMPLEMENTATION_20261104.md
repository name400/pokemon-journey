# 남은 구현과 검증 — 2026-11-04

## 현재 운영 및 구현된 범위
- 운영은 Sites v34, 소스 a893da7904d5309d25997bc3d3c04b51a9a601da. 306개 자동 검사, 타입 검사, 빌드 통과. 배포 후 로그인 상태와 기존 저장 슬롯 목록이 실제 운영에서 열림을 확인했다. 이 확인에서 전투나 뽑기를 실행하지 않았다.
- 기본 전투·교체·포획·성장·수동 진화, 200웨이브 일정, 저장 슬롯, 스타터 등록, 관리자 스타터/바우처 지급, 알 뽑기 및 랭킹에는 구현 코드와 부분 검증이 있다. 전체 자연 진행 및 원작 모든 상호작용이 검증됐다는 뜻은 아니다.

## 구현이 더 필요한 것으로 확인된 항목
1. 챌린지 사용자 흐름: lib/rogue-challenge-eligibility.mjs는 세대/타입 내부 부분집합이며 일반 시작 API/화면에서 노출하지 않는다. 원본 챌린지 선택·조건·배틀·보상 흐름을 연결하고, 융합·특수 폼의 불확실 판정(null)을 실제 원본 규칙으로 확장해야 한다.
2. 미스터리 이벤트: lib/rogue-mystery.mjs의 weird-dream, expert-breeder, clowning-around는 후보 이름이 존재하지만 선택 후 실제 이벤트로 연결되지 않고 일반 조우로 돌아가는 경로가 있다. 원본 이벤트별 조건·선택·효과·보상·재접속 및 대사를 연결해야 한다. 다른 원본 이벤트 누락도 전체 목록 대조가 더 필요하며 이 세 가지가 전체 잔량이라는 뜻은 아니다.
3. 풍·란 파트너 더블의 종 풀·전용 선두·소유자별 일반/강제 교체와 예비가 없는 기절 슬롯 처리는 v36 저장본에 연결했다. 이후 원본 더블 전용 대사와 자연 관장 조우의 대화 큐도 연결했다. 현재 운영에는 이 변경이 아직 반영되지 않았으며, 두 트레이너 초상 연출과 자연 관장 조우의 실화면 검증은 남아 있다. 현재 수정 상태를 전체 파트너 연출까지 완성된 것으로 표시하지 않는다.
4. 기술·특성·도구 전체 효과: 네이티브 시뮬레이터가 원본의 고유 효과와 항상 같지는 않다. 필드·승리 후·등장/퇴장·패시브 중복·억제·융합·폼 변화 상호작용의 원본 차이 표를 계속 채우고 실제 누락을 구현해야 한다.
5. 이미지: 원본 벌레 마니아의 개별 라이선스와 출처를 보존해 연결했다. 라이벌은 아직 프로젝트 임시 그림이다. 미확인 원본 이미지·모든 폼·변형별 자산의 출처/이용 조건과 실제 표시를 점검해야 한다.
6. 탐험: 포켓로그와 별도 데이터의 지도·스토리·상점 통합에는 부분 구현과 검증이 있다. NEXT_STEPS.md 앞부분의 탐험 진행 분기/구저장 마이그레이션/잔여 클라우드 콘텐츠 항목을 별도 완성해야 한다.

## 코드 구현과 구분해야 하는 검증 잔량
- 자연 진행 1~200웨이브, 최종 보스의 단계 전환, 어려운 더블 교체/포획/기절 및 패배 종료 전 과정을 실제 플레이로 확인.
- 대량 뽑기·다중 부화, 교환권 보장/천장과 관리자 지정·중복 지급·재접속의 운영 회귀. 이미 확인한 단일 뽑기와 스타터 지급을 전체 경우 검증으로 확대 해석하지 않음.
- 개인 기록과 글로벌 랭킹의 실제 완료 기록/동점/재접속, 저장 충돌과 오류 복구 경로.
