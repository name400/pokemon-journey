# 존느 6번지 동쪽 골목

[존느 6번지 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-6.html)는 동쪽 두 건물 단지 사이의 골목과 남동쪽 미용실을 설명한다. 기존에 막힌 네 칸을 열어 양끝에서 걸을 수 있는 골목을 만들었다. 기존 통행 칸과 미용실·홀로베이터 타일 및 주변 출입은 유지한다.

골목 폭과 건물의 정확한 크기·좌표는 기존 2D 화면에 맞춘 추정이다. 자료의 골목 아이템과 원작 옥상·비계의 정확한 형태는 이번에 추가하지 않았다. 골목 횡단·기존 거리 접근·미용실과 홀로베이터 조건·저장 복원, 모의 API PC·모바일 화면을 검사했다. 실제 운영과 Sites 병합본은 확인하지 않았다. `testfailed.md`의 배포 검사 16건과 모바일 D1 이동 오류는 운영 재검증 전까지 유지한다.
