# 블루 4번지 지상과 지하 통로

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-4.html)는 서쪽 에스파스 비드, Rust 사무소, 서쪽 건물의 안뜰을 설명한다. [에스파스 비드 자료](https://www.pokepedia.fr/All%C3%A9e_Ranavoir)는 블루 4번지와 지상·지하 연결이 각각 있음을 설명한다. 기존 2D 지상 화면에서 건물 외곽·안뜰·도로를 구분하고 지하 통로에는 다른 석재 보행면을 그렸다. 기존 계단과 각 층의 출입 연결 및 전투 의뢰인 표시는 유지한다.

건물 형태와 높이, 안뜰·계단·출입구의 정확한 위치는 원작에서 추출한 값이 아닌 초안이다. 지도 타일·충돌·층 연결·의뢰·저장 위치는 바꾸지 않았다.

에스파스 비드와 블루 4번지의 지상·지하 왕복, 구역 10 연결 및 저장 복원 단위 검사 3건과 타입 검사가 통과했다. PC·모바일 Chromium에서 모의 API로 양 층의 화면과 계단 대화를 확인했다. 원작 기기·운영 D1·Sites 병합본은 확인하지 않았다.
