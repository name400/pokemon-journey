# Tracie 교환 의뢰 보상

피카츄 교환 뒤 대기 중이던 상처약을 Tracie에게 받을 수 있다. [Serebii](https://www.serebii.net/legendsz-a/sidemissions/auseforanevolutionstone.shtml)와 [Game8](https://game8.co/games/Pokemon-Legends-Z-A/archives/557721)은 3개를 기재하므로 3개를 지급한다. 다만 [Bulbapedia 의뢰 목록](https://bulbapedia.bulbagarden.net/wiki/Mission_%28Legends%3A_Z-A%29)은 1개로 표기해 자료가 불일치하며 실기 확인이 남아 있다.

기존 보상 대기 저장도 수령할 수 있으며 기존 교환 기록과 포켓몬은 변경하지 않는다. 상처약이 97개 이상이면 99개 한도 때문에 지급을 거절하고 대기 플래그를 보존한다. 96개 이하에서 지급과 대기 해제를 한 트랜잭션으로 처리하여 중복 수령을 막는다. 의뢰인의 현재 맵 위치는 원작과 정확히 대조되지 않은 초안이다.
