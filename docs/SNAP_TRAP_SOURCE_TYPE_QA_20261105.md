# 집게덫 원본 타입

고정 원본 `7c0881255af5cd51992e513ff93c2f71adbe40e0`의 `SNAP_TRAP`은 강철 타입이다. 기존 simulator 데이터는 풀 타입이라 실제 피해 상성과 타입 강화 도구가 원본과 달랐다.

새 도전의 `snapTrapRule: source-v1`은 전투별 Dex에서 기술을 강철 타입으로 처리하고 학습 화면에도 강철로 표시한다. 기존 도전과 공유 Dex는 바꾸지 않는다. 물 타입 상대에 대한 실제 반감, 타입 강화 도구, 노말스킨, 손가락흔들기 호출과 조이기 상태 저장 복구를 검사했다.

전투 화면과 학습 화면을 검사했으며, 전역 기술 백과 등 다른 화면의 전수 표시 및 모든 특수 폼·호출 조합, 실계정 플레이는 별도 확인이 필요하다.

후속: 같은 규칙을 타입 강화 도구 추첨과 광대 이벤트의 기술 타입 선택, Z크리스탈 후보 및 기술머신 보상 표시에도 연결했다. simulator의 Z기술 가능 여부 조회가 별도 Dex를 사용해 강철 크리스탈을 거부하던 경로도 해당 기술 보유자에 한해 전투별 Dex를 조회하도록 보완했다. 강철 Z크리스탈 지급·실제 사용·복구, 잘못된 크리스탈의 무손실 거부, 노말스킨과 기존 규칙을 확인했다. 기술머신 생성의 해당 기술 개별 실플레이, 트레이너 기술 구성·전체 AI 및 다른 화면의 전수 확인은 남는다.

후속 관련 일반 환경과 Worker 회귀는 각각 223/223, 마지막 노말스킨 경계를 추가한 집중 검사는 양쪽 4/4 통과했다. 타입 검사와 프로덕션 빌드도 통과했으며 전체 테스트 스위트는 실행하지 않았다.

트레이너 후속: 신규 규칙에서 트레이너 기술 구성의 타입 다양성·같은 타입 보너스와 원본 트레이너의 필수 기술 대체 조건도 집게덫을 강철로 본다. 고정 원본 WIKSTROM의 강철 물리기 조건과 가라르 메더의 결정적 기술 구성, 실제 상대 전투·저장 복구를 검사했다. 기존 규칙의 구성은 유지한다. 이 구성기는 여전히 프로젝트 고유 점수 휴리스틱이므로 전체 원본 기술 구성·AI 동등성은 아니다.

트레이너 후속 관련 일반 환경과 Worker 회귀 각각 233/233, 타입 검사와 프로덕션 빌드가 통과했다. 전체 테스트 스위트와 실계정 플레이는 실행하지 않았다.

학습 화면 추가 전 관련 회귀는 일반 환경과 Worker에서 각각 213/213, 추가 후 집게덫 집중 검사는 일반 환경 6/6과 Worker 관련 검사 11/11 통과했다. 타입 검사는 추가 전, 프로덕션 빌드는 추가 후 통과했다. 전체 테스트 스위트는 실행하지 않았다.
