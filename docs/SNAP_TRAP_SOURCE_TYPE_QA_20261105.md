# 집게덫 원본 타입

고정 원본 `7c0881255af5cd51992e513ff93c2f71adbe40e0`의 `SNAP_TRAP`은 강철 타입이다. 기존 simulator 데이터는 풀 타입이라 실제 피해 상성과 타입 강화 도구가 원본과 달랐다.

새 도전의 `snapTrapRule: source-v1`은 전투별 Dex에서 기술을 강철 타입으로 처리하고 학습 화면에도 강철로 표시한다. 기존 도전과 공유 Dex는 바꾸지 않는다. 물 타입 상대에 대한 실제 반감, 타입 강화 도구, 노말스킨, 손가락흔들기 호출과 조이기 상태 저장 복구를 검사했다.

전투 화면과 학습 화면을 검사했으며, 전역 기술 백과 등 다른 화면의 전수 표시 및 모든 특수 폼·호출 조합, 실계정 플레이는 별도 확인이 필요하다.

학습 화면 추가 전 관련 회귀는 일반 환경과 Worker에서 각각 213/213, 추가 후 집게덫 집중 검사는 일반 환경 6/6과 Worker 관련 검사 11/11 통과했다. 타입 검사는 추가 전, 프로덕션 빌드는 추가 후 통과했다. 전체 테스트 스위트는 실행하지 않았다.
