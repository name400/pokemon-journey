# 이동 예측 재시작 후 취소 보정

같은 칸을 이동하다 서버 거절로 되돌아오는 중에 다시 움직인 뒤 재차 거절되면, 두 번째 애니메이션의 시작점은 소수 좌표다. 종전 보정은 시작점과 목표가 정확히 한 칸 떨어진 경우만 허용하므로 이 상황에서 서버 좌표로 즉시 보정했다. 캔버스에 이미 표시한 정수 좌표의 한 칸 구간을 별도로 기억하고, 그 양 끝으로의 보정과 같은 구간의 재시작만 거리 비례 시간으로 표시한다. 다른 구간·대각선·구역 또는 층 변경은 기존처럼 즉시 처리한다. 이동 가능 여부, 충돌·조우와 최종 좌표는 기존 서버 판정 그대로다.

방향 전환·반복 재시작·같은 칸 양 끝 보정·구간 외 좌표의 단위 검사, 충돌과 구역 이동의 기존 검사, 모의 API를 사용하는 모바일 폭 Chromium의 연속 거절·방향 전환 및 충돌 보정을 검사했다. 실제 운영 기기, D1 및 Sites 병합본은 검사하지 않았다. 기존 `testfailed.md` 기록은 유지한다.

융합 도구 충돌의 두 번째 네이티브 슬롯도 조사했다. 한 슬롯을 전제로 한 엔진의 `takeItem`, Trick/Knock Off, Fling과 modifier 이전·전투 복원·분리 처리를 함께 확장하지 않으면 효과 또는 도구 소유권이 어긋날 수 있다. 동일 광각렌즈나 광각렌즈·손톱 두 네이티브 조합은 추측 변환하지 않고 계속 거절한다.
