# 존느 3번지와 존느 거리 지상 연결

[존느 3번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-3.html)는 남쪽의 존느 거리 접근을, [존느 거리 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-street.html)는 북쪽의 존느 3번지 접근을 설명한다. 모두 2차 자료다.

두 화면에 지상 왕복 출구를 추가했다. 출구 좌표와 도로 폭은 압축된 2D 지도의 잠정 배치다. 기존 센트리코·인접 구역 출입, 야생 구역 8 해금 조건 및 미션 12의 비계·옥상 층과 저장 형식을 유지한다. 새 연결은 지상에서만 사용한다.

모바일 이동 오류와 Sites 병합본 실패 기록은 운영 재검증 전이므로 유지한다.
