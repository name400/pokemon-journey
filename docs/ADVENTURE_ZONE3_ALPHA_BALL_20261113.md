# 야생 구역 3 돌 건물 우두머리 필드 포획

[구역별 목록](https://www.pokemon-france.com/en/guides/pokemon-legends-z-a/wild-zones/)은 구역 3의 고정 우두머리 레오꼬와 화살꼬빈을 기재한다. 게임의 기존 돌 건물 내부와 옥상에 표시된 두 개체도 다른 우두머리처럼 인접 상호작용에서 보유한 볼을 골라 직접 던질 수 있다. 좌표와 건물·높이층은 기존 2D 초안이며 원작의 정확한 위치를 확인한 것은 아니다. 자유 조준·투척 궤적과 개별 감지 역시 기존 근사를 유지한다.

서버는 현재 층·정확한 개체·해금 상태·볼 재고와 리비전을 확인한다. 실패하면 같은 이로치 개체와 전투가 시작되고, 도주 후 색이 유지된다. 성공하면 기존 개별 소진 플래그와 도감·연구·볼 소비를 함께 저장한다. 기존 구형 저장과 이전 소진·층 이동 규칙을 변환하지 않는다.

격리 SQLite API에서 두 층의 해금 전 거절, 볼 부족, 실패·재접속·도주, 이로치 마스터볼 포획, 소진 및 오래된 요청을 검사했다. 랭크 F의 화살꼬빈은 시험한 일반 볼 조건에서 확정 포획되어 실패 경계는 랭크 Z에서 검사했다. 기존 우두머리 전투와 76개 지도·이동 예측 검사가 통과했다. PC·모바일 볼 선택은 모의 API이며 원작 실기·운영 D1 및 Sites 병합본은 검증하지 않았다.
