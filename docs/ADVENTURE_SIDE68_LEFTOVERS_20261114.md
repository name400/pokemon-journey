# 사이드 미션 68: 먹다남은음식 활용

미션 20의 세 사건을 해결하고 호텔에 보고하면 베르 6번지 르 나 앞의 Seizi에게 의뢰를 받아 파르토 Lv.48, 롱스톤 Lv.48, 하마돈 Lv.49와 싸운다. 각 상대는 먹다남은음식을 지니며 기존 턴제 엔진의 회복 효과를 받는다. 승리 상금 2,352원과 의뢰 보상 1,500원·먹다남은음식은 별도다. 가방 공간이 없으면 의뢰 보상을 보류하며 재접속과 중복 요청으로 다시 지급하지 않는다. 구형 저장은 진행이나 보상을 추정해 만들지 않는다.

[상대 기술·소지품 자료](https://www.serebii.net/legendsz-a/sidemissions/thebestuseforleftovers.shtml)와 [해금·상금·보상 공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-068-the-best-use-for-leftovers)을 참고했다. NPC 좌표는 기존 2D 맵의 초안이고, 원작 실시간 회복 시점은 기존 턴제로 근사했다. 원작 실기에서 직접 확인하지 않았다.

격리 API에서 해금·재도전·상대 도구의 실제 회복·승리·재접속·가방 한도·중복 보상과 기존 파티·진행 보존을 확인했다. 운영 D1과 실제 Sites 병합본은 검사하지 않았다.
