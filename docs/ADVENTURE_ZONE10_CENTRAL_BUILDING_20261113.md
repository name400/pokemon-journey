# 구역 10 중앙 건물과 강변 계단

별도 조사에서 전달받은 지도·3D 화면 분석은 서쪽 잔디와 낮은 수로, 넓은 강변 계단, 수로 위의 남북 방향 중앙 건물과 높이가 다른 동서 옥상을 설명한다. 이 작업 환경에서는 원본 이미지를 직접 열어 보지 못했다. [원작 공략](https://www.videogameschronicle.com/guide/pokemon-legends-z-a-wild-zone-10/)도 건물 아래 수로와 옥상을 구분한다.

지상에 중앙 건물의 추정 윤곽과 잔디에서 수변 보행로로 내려가는 넓은 계단을 추가했고 수로에 건물 아래의 그늘을 표현했다. 옥상은 서쪽과 동쪽 표면을 다른 색으로 표현한다. 좌표·건물 면적·계단 폭은 2D 초안이며 옥상 높이 차이는 실제 높이층이 아닌 시각 표현이다. 기존 옥상 연결은 유지하지만 원작에 같은 연결이 있다고 확인된 것은 아니다. 지상의 기존 북쪽 출입구도 이전 경로 호환을 위해 유지하므로 원작의 두 출입구와 개수는 다르다.

새 건물 칸의 구형 지상 저장은 같은 리비전일 때 가까운 통행 칸으로 복원하고 다른 층·야생 개체·수령 기록과 출입 경로를 보존한다. 단위 검사와 격리 API에서 이전 저장 복원, 양쪽 입구와 사다리 접근, 옥상 전환·수로 차단 및 파티·재화를 확인했다. PC·모바일 Chromium의 지상과 옥상은 모의 API·대체 이미지로 확인했다. 원작 기기와 운영 데이터는 검사하지 않았다.
