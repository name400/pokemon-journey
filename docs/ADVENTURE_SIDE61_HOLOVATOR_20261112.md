# 사이드 미션 61: 블루 구역 홀로베이터

[원작 공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-061-my-favorite-holovator)에 따르면 단원의 포켓몬은 깨봉이·로젤리아가 45레벨, 입치트가 46레벨이며 배틀 상금 2,208원과 별도의 의뢰 보상 2,000원·독바늘·메가조각 20개를 받는다. 기존 2D 블루 구역 3 홀로베이터 접근과 옥상 연결을 유지하면서 새 배틀의 팀과 보상을 바로잡았다. 기존 메인 미션 20의 회의 이후 해금 조건을 유지한다.

기존에 완료한 저장을 변경하거나 보상을 다시 주지 않는다. 업데이트 이전에 이미 시작한 배틀은 이전 보상(2,000원·독바늘·리조치움 3개)으로 끝나도록 구분한다. 전투 중 재접속·패배·재도전 및 승강기 왕복을 대표 검사했다. 정확한 지형과 원작 실시간 전투는 여전히 초안이며 실제 운영 기기에서는 확인하지 않았다.
