# 구역 10 강변 벤치와 별가사리

[원작 안내](https://www.videogameschronicle.com/guide/pokemon-legends-z-a-wild-zone-10/)는 건물 아래 수로와 옥상, 물가 벤치 근처 육지의 별가사리, 동쪽 얕은 물의 저리어를 설명한다. 강변에 벤치와 기존 운하 보행로·사다리 사이의 포장을 추가하고 별가사리를 수중에서 벤치 근처 육지로 옮겼다. 개별 좌표와 벤치 수·길 폭은 확인되지 않은 2D 초안이다. 실제 원작 지도 이미지와 3D 지형을 이 작업에서 직접 대조하지 않았다.

기존 별가사리 ID·소진 상태·이로치 기록을 재사용하며 수로, 동쪽 얕은 물, 옥상과 출입 경로는 유지한다. 새 벤치 두 칸의 구형 지상 저장은 같은 리비전일 때만 가까운 통행 가능 칸으로 복원한다. 이미 진행 중인 전투나 보유 개체는 변경하지 않는다.

구역 단위 검사에서 옛 저장 복원, 강변과 양쪽 출입구·사다리 경로, 수중 차단 및 옥상 분리를 확인했다. 격리 API에서 저장 복원, 기존 이로치 개체의 조우·도망·소진 기록과 파티·재화를 확인했고 옥상·저리어 회귀도 확인했다. PC·모바일 Chromium 화면은 모의 API와 대체 외부 이미지를 사용했다. 실제 운영 환경과 원작 기기는 검사하지 않았다.
