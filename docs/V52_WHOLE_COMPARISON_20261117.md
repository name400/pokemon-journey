# v52 전체 화면 비교 및 잔여 차이

승인 v52 HTML과 포켓로그 단일 전투를 960×540 및 390×844 격리 Chromium에서 주명령·기술 화면으로 캡처했다. 원본의 512×512 포켓몬 PNG가 없어 양쪽 모두 동일한 리자몽 후면·이상해꽃 정면 2D 파일을 대체해 사용했으며, 원본의 이름·HP는 샘플에 맞췄다. 기술 목록과 일부 아이콘·실제 볼 보유 상태는 같지 않다. 게임 장면은 PC에서 약 946×532이고 원본은 960×540이므로 동일 논리 비율 비교이지 정확한 픽셀 비교가 아니다. 출력은 `/workspace/scratch/v52-whole-comparison/`에 있다.

가장 큰 배경 차이는 초원 단일에 대한 승인 배경 CSS가 포켓로그 전용 CSS에 덮이는 결함이었다. 해당 경우에만 원본 배경을 적용했다. 원본과 게임의 배경 파일 SHA-256은 `a7d7a7f05689c396f795b8be08c33e8ab1a55fc780915848f590d992da10ca56`으로 일치한다. 포켓로그 초원·숲 각각 390×844, 960×540에서 배경 선택과 기술 네 개·저장 복원을 확인했다.

게임 기술창이 열릴 때 마우스 아래 기술의 설명이 자동으로 열려 배우를 가리던 차이도 있었다. 승인 단일에서는 설명 버튼으로만 열도록 조정했다. 390×844, 960×540에서 설명 열기·닫기와 저장 불변, 포켓로그 단일·더블 4개 크기의 실제 기술·PP·상성 회귀를 확인했다.

원본 포켓몬 이미지가 없어 실제 원본 실루엣의 크기·위치 일치는 판단할 수 없다. 게임에는 원본에 없는 설정·기록·특수 선택 조작과 경험치 등이 남고, 기술 목록 데이터도 달라 화면 전체 일치를 주장할 수 없다. 실기기 터치·가독성, 운영 서버 및 탐험의 이전 브라우저 실패는 미검증이다. 사용자 저장과 Sites는 변경하지 않았다.

승인 Z기술 영상 5.6초의 국소 별 모양 충돌을 확인하고, 같은 울트라대시어택의 확정된 적중 피해에만 표시했다. 격리 포켓로그 단일·더블의 실제 명령·대상·메시지 순서·PP·새로고침을 검사하고 무효·다른 대상·중간 행동이 끼는 경우는 단위 검사했다. 원본과 프레임별 일치와 실제 기기는 미검증이다.
