게임 기술창이 열릴 때 마우스 아래 기술의 설명이 자동으로 열려 배우를 가리던 차이도 있었다. 승인 단일에서는 설명 버튼으로만 열도록 조정했다. 390×844, 960×540에서 설명 열기·닫기와 저장 불변, 포켓로그 단일·더블 4개 크기의 실제 기술·PP·상성 회귀를 확인했다.

## 포켓로그 단일 전장 크기 (2026-11-18)
