# 사이드 미션 76: 메가진화 수업

[원작 공략](https://gmtreks.com/pokemon-z-a/side-missions/76)과 [보상·오답 설명](https://game8.jp/pokemon-legends-z-a/731341)을 대조해 미션 26 무렵 에투알 학교 안뜰에서 다섯 질문에 답하는 수업을 연결했다. 오답을 골라도 다음 질문으로 넘어가며 마지막 질문은 어느 선택지도 허용한다. 보상은 메가조각 100개와 500원이다. 기존 2D 안뜰의 인물 좌표와 대화 문장은 근사이며 원작의 동행 장면은 구현하지 않았다.

안뜰의 기존 통행 불가 벽을 상호작용에 재사용해 기존 이동 및 저장 좌표를 유지한다. 각 답변과 보상 대기 단계는 저장하며 낡은 리비전과 중복 지급을 거절한다. 조각·지갑 한도에 걸리면 보상 대기는 유지한다. 대화 및 보상은 파트너 개체를 갱신하지 않아 정규화가 필요한 공유 보유함의 구형 기록도 그대로 둔다.

단위 검사에서 구형 안뜰 지도·접근·좌표 복원과 다섯 질문·목표 표시를, 격리 SQLite API에서 선행 조건, 오답·재접속, 다섯 단계, 조각·지갑 한도, 중복 보상과 구형 파트너 보존을 확인했다. 원작 기기, 실제 사용자 데이터, Sites 병합본과 PC·모바일 화면은 확인하지 않았다.
