# 존느 10번지 구역 11 접근로 표현

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-10.html)는 존느 10번지 남쪽이 야생 구역 11에 포함되며 주변 번지·세존 운하와 접한다고 설명한다. 기존 화면에서 건물 외곽과 보행면을 구분했다.

현재 수로와 구역 11은 별도 화면으로 압축되어 있다. 건물 형태·출입 좌표·도로 선형은 측량하지 않은 2D 추정이며 원작의 정확한 옥상·수변 높이는 이 작업에서 추가하지 않았다. 기존 타일·충돌·랭크 제한·출입·저장은 바꾸지 않았다.

구역 11 북안과 존느 6·10·12번지 연결, 랭크 제한 및 저장 복원 검사 2건과 타입 검사가 통과했다. 모의 API를 사용한 PC·모바일 Chromium 화면을 확인했다. 원작 기기와 실제 Sites 병합본은 확인하지 않았다.
