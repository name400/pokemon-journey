# 포켓몬 연구소 주변 거리

- [Nintendo Life](https://www.nintendolife.com/guides/pokemon-legends-z-a-wild-zone-1-guide-all-pokemon-and-alphas)는 베르날 대로 남쪽의 연구소에서 동쪽으로 가면 야생 구역 1에 도달한다고 설명한다. [Bulbapedia](https://bulbapedia.bulbagarden.net/wiki/Lumiose_City)는 연구소가 남쪽 큰길에 있다고 설명한다.
- 기존 연구소 문, 세 지역 출구와 빠른 이동 도착점을 유지하며 동서 큰길·북쪽 통로, 연구소 전면 그림과 주변 건물 두 블록을 추가했다. 도로 너비와 정확한 타일, 연구소 외형과 주변 건물은 출처에서 도면을 확인하지 못한 2D 초안이다. 추가 건물은 특정 원작 상점으로 주장하지 않는다.
- 구형 지상 저장이 새 건물에 겹치면 같은 리비전에서 인접 통행 가능 칸으로 복원하며 실내 저장은 건드리지 않는다. 연구소 출입·구역 1 왕복·진행 상태와 파티를 로컬 API에서 검증했다.
- PC·모바일 브라우저 화면은 모의 API와 외부 이미지 대체 표시를 사용했다. 운영 환경 및 실제 Sites 병합본을 검증한 것은 아니다.
