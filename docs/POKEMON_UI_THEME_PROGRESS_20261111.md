# 포켓몬 테마 UI 작업 — 공통 진입 화면

포켓로그 진행 기록의 최신 필수 목록을 확인했다. 일반 시작·전투·보상·저장 및 주요 챌린지 경로는 기존 대표 검사 기록이 있으나, 도구·융합의 미검증 조합과 운영 409/끊김의 미확정 원인은 남아 있다. 이 기록은 전체 원본 동등성 또는 운영 완성을 의미하지 않는다. 별도 재현 가능한 일반 진행 차단을 현재 확인하지 못해 요청한 다음 단계인 UI 작업을 시작한다.

공통 셸 브랜드를 몬스터볼 형태로 정리하고, 게임 선택 화면·로그인 안내·사이드 메뉴를 두 게임과 어울리는 남색/크림색 기반으로 수정했다. 탐험 카드와 로그라이크 카드의 색상과 이동 버튼을 구분했다. 320px 상단에서 장식용 계정 아이콘이 가로 폭을 넘던 문제도 줄였다. 기능과 저장·기존 게임 패널은 변경하지 않았다.

320·390·1280px 격리 Chromium에서 게임 선택, 안내, 두 모드 셸, 카드 이미지와 제목 겹침, 가로 스크롤 및 메뉴 이동을 검사했다. 기존 전투 오류 복구 화면 4개와 타입 검사가 통과했다. 외부 포켓몬 이미지는 테스트에서 대체했으며 실제 이미지의 저작권이나 운영 기기 렌더링을 확인한 것은 아니다.

남은 UI: 포켓로그 내부 스타터·상점·보상·전투, 탐험의 필드·파티·가방, 공통 도감·친구·관리 화면을 사용자 흐름별로 시각 대조하고 일관성·모바일 가독성을 개선해야 한다. 전체 UI 개선 완료가 아니다. 포켓로그의 미확인 특수 조합·운영 검증도 별도다. Sites 배포는 하지 않는다.

## 포켓로그 전투·보상·정비 화면

전투 화면의 단일 HP 창, 명령·대화 창과 더블 명령 안내의 색을 공통 남색·청록·금색으로 정리했다. 무료 보상과 유료 파티 정비 카드에도 크림·청록 계열을 적용했다. 기존 화면의 크기·배치·터치 영역·전투 및 보상 처리에는 손대지 않았다. 잠금·선택 상태와 타입별 표시는 기존 규칙을 유지한다.

격리 Chromium의 390·1280px 전투 및 보상 화면을 변경 전후 대조했다. 기존 보상·정비 구매·포획·재접속 검사는 320·360·390·430·640×390·1280px 6개 크기에서 통과했다. 외부 포켓몬 그림은 테스트 대체물이어서 실기기나 실제 이미지 표시 검증은 아니다. 나머지 포켓로그 스타터·알 상점·파티·랭킹, 공통 도감·친구·관리 화면과 탐험 화면 검토가 남는다.

전투 타입·단일/더블 HUD와 진화·동작 줄이기 관련 기존 브라우저 검사 30개 및 타입 검사도 통과했다.

## 포켓로그 스타터·알 상점·파티·랭킹

스타터 선택과 파티 카드, 알 기계 및 보관함, 랭킹의 배경과 선택 강조를 기존 남색·크림색·청록색 계열에 맞췄다. 랭킹 새로고침 버튼의 글자가 좁은 화면에서 줄바꿈되지 않도록 조정했다. 게임 규칙과 저장 형식은 변경하지 않았다.

격리 Chromium의 320·390·1280px에서 스타터 선택, 파티, 알 기계 선택 및 랭킹 새로고침과 가로 넘침을 검사했다. 랭킹은 시험 데이터, 외부 이미지는 대체 이미지를 사용했으므로 실제 계정과 운영 기기 검증은 남아 있다. 공통 도감·친구·관리 화면과 탐험 화면의 테마 및 모바일 검토가 남는다.

## 공통 보유함·친구·관리 화면

현재 공통 메뉴의 포켓몬 보유함 카드와 친구·프로필, 관리자 선택 영역에 같은 크림·청록 계열을 적용했다. 탐험 모드의 좁은 상단에서 계정 영역이 화면을 넘지 않게 조정했다. 별도의 전체 도감 화면은 현재 공통 메뉴에 없으므로 보유함을 전체 도감 완성으로 간주하지 않는다.

격리 Chromium 320·390·1280px에서 보유함 표시, 탐험·포켓로그의 친구 화면과 새로고침, 관리자 게임 선택 및 가로 넘침을 확인했다. 계정·친구·관리 데이터는 시험 응답이고 이미지는 대체물이므로 실제 운영 계정 및 기기 검증은 남아 있다. 탐험의 필드·파티·가방과 다른 공통 화면의 시각 검토가 남는다.
