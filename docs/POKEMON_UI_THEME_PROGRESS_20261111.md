# 포켓몬 테마 UI 작업 — 공통 진입 화면

포켓로그 진행 기록의 최신 필수 목록을 확인했다. 일반 시작·전투·보상·저장 및 주요 챌린지 경로는 기존 대표 검사 기록이 있으나, 도구·융합의 미검증 조합과 운영 409/끊김의 미확정 원인은 남아 있다. 이 기록은 전체 원본 동등성 또는 운영 완성을 의미하지 않는다. 별도 재현 가능한 일반 진행 차단을 현재 확인하지 못해 요청한 다음 단계인 UI 작업을 시작한다.

공통 셸 브랜드를 몬스터볼 형태로 정리하고, 게임 선택 화면·로그인 안내·사이드 메뉴를 두 게임과 어울리는 남색/크림색 기반으로 수정했다. 탐험 카드와 로그라이크 카드의 색상과 이동 버튼을 구분했다. 320px 상단에서 장식용 계정 아이콘이 가로 폭을 넘던 문제도 줄였다. 기능과 저장·기존 게임 패널은 변경하지 않았다.

320·390·1280px 격리 Chromium에서 게임 선택, 안내, 두 모드 셸, 카드 이미지와 제목 겹침, 가로 스크롤 및 메뉴 이동을 검사했다. 기존 전투 오류 복구 화면 4개와 타입 검사가 통과했다. 외부 포켓몬 이미지는 테스트에서 대체했으며 실제 이미지의 저작권이나 운영 기기 렌더링을 확인한 것은 아니다.

남은 UI: 포켓로그 내부 스타터·상점·보상·전투, 탐험의 필드·파티·가방, 공통 도감·친구·관리 화면을 사용자 흐름별로 시각 대조하고 일관성·모바일 가독성을 개선해야 한다. 전체 UI 개선 완료가 아니다. 포켓로그의 미확인 특수 조합·운영 검증도 별도다. Sites 배포는 하지 않는다.
