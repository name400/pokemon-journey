# 사이드 미션 100 — 밤하늘의 아쿠스타

[원작 공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-100-starmie-on-high)에 따라 미션 35의 Mable 대화 이후 마젠타 포켓몬센터 근처 운하변의 Cate에게 의뢰를 받고, 밤에 파티에 아쿠스타를 넣고 모이면 2,800원·진화의휘석·큰진주를 받을 수 있다. 현재 2D 맵에서 NPC 좌표는 추정이다. 별하늘과 원작 모임의 별도 영상·실시간 연출은 구현하지 않았다.

서버 시계와 실제 보유 파티를 확인하고, 선택된 아쿠스타의 소유자와 데이터가 저장 시점까지 유지되는지 확인한다. 포켓몬을 소모하거나 수정하지 않는다. 기존 저장에 단계가 없다면 미수락 상태로 두고, 진행 중인 저장과 알 수 없는 미래 단계는 소급 변경하지 않는다. 보상 가방에 공간이 없으면 지급을 보류하며 오래된 리비전과 중복 수령을 거절한다. 수락한 의뢰는 여행 수첩에서 추적할 수 있다.

격리 API에서 해금 전·낮·보관함에만 아쿠스타가 있는 경우 거절, 밤의 파티 조건, 재접속·구형 저장·가방 한도·중복 요청과 저장 직전의 공유 개체 소유권 변경, 포켓몬·재화 보존을 확인했다. 실제 원작 기기·운영 D1·Sites 병합본은 확인하지 않았다.
