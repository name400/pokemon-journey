# 블루 5번지와 블루 광장 바깥 접근

[블루 5번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-5.html)는 북쪽 블루 광장 접근을, [블루 광장 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-plaza.html)는 남쪽 블루 5번지 접근을 설명한다. 기존 지도에는 두 화면 사이의 직접 지상 경로가 없었다.

광장 바깥 화면과 5번지 사이에 왕복 접근을 추가했다. 출입 좌표와 길의 선형·폭은 원작에서 측정되지 않은 2D 추정이다. 이 접근은 야생 구역 16의 새 출입구가 아니며 기존 세 출입구와 랭크 제한을 유지한다. 구역 12 제한과 기존 도로, 저장·진행 상태도 유지한다.

대표 단위 검사에서 양방향 이동·구형 저장 복원, 야생 구역 16 세 입구의 제한과 구역 12 입장 제한을 확인했다. 원작 실기·운영 D1·실제 Sites 병합본은 확인하지 않아 모바일 이동 오류와 배포 검사 실패 기록을 유지한다.
