# 검토된 융합 폼 회귀 검사 복구

기존 회귀 검사 2건의 기준을 원본 폼 규칙과 현재 검토 범위에 맞췄다. 실제 게임 코드나 기존 저장은 변경하지 않았다.

- 검토된 기증자 폼은 테라파고스 등 추가 후 237개인데 테스트의 고정 기대치는 234였다. 237개를 모두 검증하도록 갱신했다.
- 각오의모습 케르디오는 신비의칼이 필요하다. 주체 테스트에 해당 기술을 넣어 유효한 각오 폼을 생성한다. 기술을 잊으면 통상 폼이 되는 별도 검사도 유지한다.
- 스텔라 테라파고스는 테라 상태가 없는 새 전투에서 테라스탈 폼으로 돌아간다. 주체 테스트는 새 전투 후 정상 폼을 기대한다. 스텔라 폼의 융합·분리 자체와 실제 테라스탈 중 복구는 별도 검사로 유지한다.

고정 원본의 케르디오 `SpeciesFormChangeMoveLearnedTrigger`와 테라파고스 `SpeciesFormChangeLapseTeraTrigger`를 대조했다. 검토된 237개 기증자·주체의 보상, 실제 전투, codec, 분리와 다른 저장 데이터 보존은 격리 테스트 범위다. 실사용·실기기 또는 임의의 다른 변형 전체 검증은 아니다.
