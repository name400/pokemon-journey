# 셰이미 스카이폼과 얼음 상태

고정 원본의 그라시데아꽃으로 스카이폼을 획득·해제하는 도구 상태 및 융합 양쪽 역할을 연결했다. 원본과 native 능력치 6항목을 확인하고 폼별 주특성·패시브 변경과 복귀를 유지한다.

격리 전투에서 기존 native 엔진은 얼음 상태가 되면 스카이폼을 랜드폼으로 즉시 바꾸지만, 고정 원본의 폼 목록은 도구 전환만 정의한다. 원본 규칙 전투에서 검증된 주체 셰이미의 이 전환만 막고 얼음 상태 자체와 상태 메시지는 유지한다. 공유 native 조건과 구형 전투 규칙은 바꾸지 않는다. 변신한 포켓몬 및 확인할 수 없는 융합은 자동 변경하지 않으며 추가 검증 범위로 둔다.

도구 보상·활성/해제·융합 양쪽·실제 전투 턴·codec·분리, 패시브, 기존 저장과 다른 슬롯을 검사했다. 얼음 발생 후 폼/상태·codec을 단독/융합, 호출 기술 정책 유무에서 검사하고 구형 규칙의 기존 동작을 확인했다. 관련 일반·Worker 각 45/45, 타입·production 빌드 통과. 실기기·운영과 모든 상태/특성 조합은 미검증이다. 로그 `/tmp/shaymin-final.log`, `/tmp/shaymin-worker.log`, `/tmp/shaymin-type.log`, `/tmp/shaymin-build.log`.
