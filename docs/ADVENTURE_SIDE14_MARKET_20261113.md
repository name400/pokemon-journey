# 블루 시장 조우와 사이드 미션 14

[슈쁘 출현 안내](https://www.powerpyx.com/pokemon-legends-z-a-spritzee-location/)와 [나룸퍼프 출현 안내](https://www.powerpyx.com/pokemon-legends-z-a-swirlix-location/)는 블루 5번지 시장의 노점 높은 곳에 두 종이 출현한다고 설명한다. 기존에 통행이 막혀 있던 건물 두 칸에 조우를 연결했다. 각 종은 기존 단일 턴제 배틀·포획·도감·연구 기록을 사용하며, 전투 중 재접속은 기존 전투 저장을 사용한다. 정확한 위치·높이·레벨과 원작의 변동 출현 대신 종별 고정 표식을 사용하는 점은 2D 초안이다.

[사이드 미션 14 공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-014-slurpuffs-cafe-visit)에 따라 미션 7 시작 후 Shutterbug Café의 Meuse에게 의뢰를 받고 Café Soleil에서 나루림을 만나면 휘핑팝 2개와 3,000코인을 한 번 받는다. 두 카페는 남쪽 거리의 기존 막힌 건물 칸으로 표현하며 정확한 위치는 초안이다. 원작의 나루림 독립 동행·간식 연출은 현재 미구현이며, 시작한 뒤 목적지와 상호작용하는 단계식 근사다. 가방 공간이 부족하면 완료·재화·물품은 변하지 않고 리비전 조건으로 중복 요청을 방지한다.

슈쁘와 나룸퍼프를 각각 향기주머니·휘핑팝을 지닌 상태에서 교환하면 기존 진화 로직을 이용할 수 있다. 기존 저장 좌표·파티와 소유 개체는 바꾸지 않는다. 격리 API에서 두 포획, 의뢰 해금·순서·재접속·가방 한도·중복 요청을, 단위 검사에서 경로·구형 저장·교환 진화 조건을 확인했다. 실제 교환 상대 기기·원작 실기·운영 환경, 연구 레벨 50의 전체 정상 달성은 검사하지 않았다.

후속: 가방의 휘핑팝이 가득 차도 의뢰를 완료하고 코인을 한 번 받을 수 있다. 공간이 있는 수량을 먼저 지급하고 남은 수량은 Café Soleil에서 공간을 확보한 만큼 받는다. 보상 대기는 명시적으로 새로 저장한 수량만 표시하므로 기존 완료 저장에 보상을 추정해 만들지 않는다. 각 요청의 리비전 검사와 기존 지갑 한도는 유지하고, 의뢰 상호작용은 공유 보유함 개체를 갱신하지 않는다. 분할 수령은 이 게임의 가방 한도를 위한 처리다. 격리 API에서 가방 998·999개, 지갑 한도, 재접속·분할 수령·중복 요청과 파티 개체 보존을 검사했다. 실제 원작 기기와 운영 데이터는 확인하지 않았다.
