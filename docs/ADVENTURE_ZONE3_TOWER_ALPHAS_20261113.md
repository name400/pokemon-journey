# 구역 3 돌 건물 우두머리

[구역 안내](https://thephrasemaker.com/2025/10/17/pokemon-legends-z-a-wild-zone-3-guide/)에 따라 돌 건물 안에 우두머리 레오꼬, 그 위 옥상에 우두머리 화살꼬빈을 추가했다. [레오꼬 안내](https://www.nintendolife.com/guides/pokemon-legends-z-a-wild-zone-3-guide-all-pokemon-and-alphas)의 레벨 24와 [출현 목록](https://www.pokemon-france.com/en/guides/pokemon-legends-z-a/wild-zones/)의 화살꼬빈 레벨 30~31을 참고했다. 파르빗 우두머리 의뢰 완료 후 나타나며, 기존 턴제 전투와 이로치 저장·포획 경로를 사용한다.

정확한 좌표와 건물 규모는 기존 2D 맵에 맞춘 초안이며 잠든 상태, 실시간 추격 및 우두머리 고유 기술은 재현하지 않았다. 포획 또는 승리 후 해당 층을 나가면 다시 등장할 수 있고, 아직 남은 이로치 개체는 저장된 색을 유지한다. 새 출현 칸은 기존 통행 가능한 바닥에 놓았고 계단·기술머신 위치와 기존 저장은 유지한다. 격리 API 및 모의 브라우저 시험이며 원작 실기와 운영 환경은 검증하지 않았다.

후속으로 실내 레오꼬는 [구역 안내](https://www.nintendolife.com/guides/pokemon-legends-z-a-wild-zone-3-guide-all-pokemon-and-alphas)에 나온 잠든 상태로 표시한다. 잠들었을 때 인접 볼 던지기는 기존 미발견 포획 보정 1.5배를 사용한다. 그 칸에 직접 들어가거나 전투를 시작하거나 볼 포획에 실패하면 깨어나며, 이후 재접속·도망 후에도 깨어 있는 상태가 남는다. 건물 밖으로 나갈 때 기존 출현 초기화에 맞춰 다시 잠든 상태로 돌아간다. 깨는 거리와 재수면 시점, 기존 1.5배는 이 게임의 잠정 근사이며 원작의 정확한 잠금·소음·포획 배율을 확인한 것은 아니다. 옥상 화살꼬빈에는 잠든 상태를 임의로 적용하지 않는다.

이미 진행 중인 배틀 스냅샷은 바꾸지 않고 구형 미수집 저장은 최초 조우에서 잠든 것으로 처리한다. 이로치 상태와 이미 보유한 포켓몬·기존 수집 플래그를 유지한다. 격리 API에서 잠든/깬 포획 결과, 접촉·실패 후 재접속과 이탈, 이로치·중복 요청을 검사하고, PC·모바일 모의 브라우저에서 잠든 표시와 기존 볼 선택을 확인했다. 스크린샷은 대체 이미지를 사용했으며 원작 기기·운영 D1·Sites 병합본은 미검증이다.
