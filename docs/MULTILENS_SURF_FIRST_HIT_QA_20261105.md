# 멀티렌즈 파도타기 첫 타격

고정 원본의 `getMoveTargets`는 전체 인접 대상 공격에서 상대를 나열한 뒤 아군을 나열한다. 기존 엔진은 파도타기의 아군을 먼저 처리했다. 신규 도전의 멀티렌즈 파도타기 첫 타격은 상대 두 슬롯을 먼저 처리한 뒤 아군을 처리하고, 대상별 실제 피해를 적용한 후 다음 대상의 살아 있는 대상 수를 계산한다. 이전 `swift-source-v1`·`simple-spread-v1` 저장은 기존 처리를 유지한다.

격리 검사에서 상대 둘의 기절 뒤 아군 피해, 방어·저수·기합의머리띠로 상대가 생존하는 경계, 적 측 사용, 실제 턴, codec 복원과 다른 데이터를 확인했다. 이는 첫 타격 피해 적용의 순서이며, 모든 개별 부가 효과·특성·도구의 실행 순서와 원본 난수열까지 일치한다는 의미는 아니다. 지진·방전 등 다른 전체 공격, 실사용 및 실기기는 별도다.
