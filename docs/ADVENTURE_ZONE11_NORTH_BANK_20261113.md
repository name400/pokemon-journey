# 구역 11 북쪽 높은 강변

[구역 11 안내](https://pokequery.com/games/legends-za/wild-zones/11)는 야돈이 북동쪽 출입구 부근의 높은 북쪽 구역에 있다고 설명한다. [Nintendo Life](https://www.nintendolife.com/guides/pokemon-legends-z-a-wild-zone-11-guide-all-pokemon-and-alphas)는 세존 운하가 구역을 가로지르고 야돈이 북동쪽 풀숲에 있다고 설명한다. 이를 반영해 북쪽 강변에서 오가는 별도 상층과 야돈 서식지를 추가했다.

상층의 범위, 계단의 존재와 정확한 위치, 두 화면의 좌표 대응은 확인되지 않은 2D 초안이다. 중앙 운하, 기존 남서쪽 두 계단과 제르네아스·다른 야생 개체는 기존 층에 둔다. 야돈의 기존 개체 ID·수령 상태와 이로치 기록은 공유하며, 이전에 야돈 위치에 저장된 플레이어를 다른 위치로 옮기지 않는다. 상층의 도착점과 기존 아래층의 도착점을 각각 확인한 후 이동하고 재접속 시 높이층을 복원한다.

PC·모바일 확인은 시험 상태와 외부 이미지 대체물을 사용했다. 실제 원작 기기의 상층 평면과 운영 저장소는 검증하지 않았다.
