# 센터 간 빠른 이동

[닌텐도 공식 안내](https://www.nintendo.com/us/whatsnew/12-tips-and-tricks-for-pokemon-legends-z-a/)에 따르면 탐험 중 방문한 포켓몬센터 등의 장소가 지도에 등록되고 지도에서 빠르게 이동할 수 있다. 현재 맵의 포켓몬센터 9곳을 서버에서 식별하고, 각 센터에서 회복하면 해당 지점을 저장한다. 미션 5의 메가진화 이후 또는 기존 진행상 미션 6이 열린 모험에서는 센터 안내 대화에 등록한 다른 센터로 이동하는 선택지가 나타난다. 서버도 실제 센터 위치, 등록 여부, 진행 조건, 전투·그룹·포획과 연속 배틀 상태를 확인한다. 등록 데이터가 없는 기존 저장은 기존 좌표와 파티를 보존하고, 센터를 다시 이용하면서 등록한다.

이는 원작의 전체 지도 빠른 이동이 아니라 센터 간 이동으로 제한한 1차 구현이다. 원작은 장소를 탐험해 지도에 등록하고 지도에서 선택하지만, 여기서는 기존 조작을 활용해 센터에서 회복할 때 등록하고 센터에서 출발한다. 택시·야생 구역·배틀존 등 다른 목적지는 미구현이다. 기존 맵의 센터 좌표는 2D 초안이며 정확한 원작 좌표로 주장하지 않는다. 실제 기기·운영 환경에서는 검증하지 않았다.

## 지도와 택시 확장

[공식 안내](https://www.nintendo.com/us/whatsnew/12-tips-and-tricks-for-pokemon-legends-z-a/)와 [지도 안내](https://game8.jp/pokemon-legends-z-a/729675)는 미션 4 이후 등록한 곳을 지도에서 무료로 선택하고, 야생 구역에 한 번 들어가면 그곳을 등록한다고 설명한다. 게임에 이동 지점 목록을 포함한 지도 메뉴를 추가했다. 외부 지상 화면에서 선택하며, 기존 저장에는 방문 기록을 추측해 넣지 않는다. 구역 1~19는 기존 출입 성공 시 지상 진입 좌표를 저장하고, 이동할 때 기존 해금 조건과 현재 타일을 다시 검증한다. 구역 20은 지가르데 스토리를 건너뛰지 않도록 미션 42 완료 후 다시 들어간 경우에만 등록한다. 각 구역에서 처음 등록된 출입 좌표는 2D 임시값이다. 센터에 직접 들어서거나 기존처럼 회복할 때도 해당 센터가 등록된다.

[Lumi Cab 자료](https://bulbapedia.bulbagarden.net/wiki/Lumi_Cab)는 Z-A에서 미방문 목적지도 710원에 이용할 수 있고 요금 부족 시 기사 배틀이 없다고 명시한다. 사우스 대로의 기존 택시 승강장에 기사를 두어 주요 센터 7곳으로 이동하며, 도착한 센터를 등록한다. 잔액이 부족하면 결제·이동·등록이 모두 일어나지 않는다. 다른 승강장과 광장·카페 등 전체 목적지는 아직 미구현이고 기사와 좌표는 초안이다.

구역 18·19는 [구역 18 공략](https://www.nintendolife.com/guides/pokemon-legends-z-a-wild-zone-18-guide-all-pokemon-and-alphas)과 [구역 19 공략](https://game8.jp/pokemon-legends-z-a/730120)이 미션 30 완료를 제시하지만 출처 간 경계에 차이가 있으므로 이번에 해금 정책을 바꾸지 않았다. 기존 랭크 B 또는 미션 완료 조건을 이동 시에도 재검증한다. 실내·배틀존·옥상과 야생 구역의 별도 높이층·일부 스토리 전용 구역, 동료 추격 및 연전 중 이동은 안전을 위해 제한되며 원작의 세밀한 감지 제한과 완전히 같지는 않다. 새로운 지도는 지리적 배치도가 아니라 등록 지점 목록이며 실제 기기와 운영은 미검증이다. 이 절이 위의 센터 간 이동만 가능하다는 설명을 갱신한다.

## 센트리코 승강장과 주요 목적지

[센트리코 광장 자료](https://bulbapedia.bulbagarden.net/wiki/Centrico_Plaza)는 광장 곳곳의 기사 네 명을, [Lumi Cab 목적지 목록](https://bulbapedia.bulbagarden.net/wiki/Lumi_Cab)은 호텔 Z·연구소·리시심·콰자르티코와 식당들을 명시한다. 기존 광장 화면에 기사 네 명을 추가하고 구현된 호텔 Z, 연구소, 호텔 리시심, 르 와우, 르 나, 스시 하이 롤러와 콰자르티코를 710코인 목적지로 연결했다. 기사 좌표와 도착 좌표는 2D 초안이다. 콰자르티코는 기존 사무실 입장 단계 이후에만 제공한다.

각 시설 근처를 직접 걷거나 택시로 도착하면 지도 목록에 등록되고, 등록 후에는 무료로 이동할 수 있다. 기존 센터와 야생 구역 기록은 유지한다. 원작의 모든 카페·광장·건물과 나머지 승강장은 아직 연결되지 않았으며, 주요 시설을 스쳐 지나갈 때 등록되는 이 게임의 거리 판정도 원작의 정확한 판정과는 다를 수 있다. 실제 기기·운영 검증은 하지 않았다.

센터와 주요 시설로 이동할 때 해당 목적지의 이전 옥상·수로 층 플래그가 남아 있으면 지상 도착으로 정리한다. 다른 구역의 진행 플래그는 유지하며, 현재 별도 높이층에서 이동하는 것은 제한한다.

## 광장·카페와 루주 승강장

[Lumi Cab 목적지 목록](https://bulbapedia.bulbagarden.net/wiki/Lumi_Cab)에 있는 여섯 광장과 Café Woof, Café Gallant, Nouveau Café 2호를 연결했다. 존느·마젠타 광장은 기존 게임에서 야생 구역과 겹치므로 잠긴 구역 안이 아니라 기존 도로 쪽에 도착한다. 루주 광장은 기존 미션 5 완료 이후 제공한다. 카페의 위치·광장 도착 좌표는 2D 초안이며 방문·택시 도착 시 지도 목록에 등록한다.

[의뢰 안내](https://www.thonky.com/pokemon-legends-z-a/side-mission-088-the-nervous-novice-cabbie)는 루주 광장 북서쪽에 택시 기사가 있다고 설명한다. 다른 [의뢰 목록](https://bulbapedia.bulbagarden.net/wiki/Side_Mission)은 해당 의뢰의 선행 시점을 다르게 기재하므로, 기존 경계를 건드리지 않고 승강장은 미션 30 시작 이후 또는 랭크 B 이후에 보수적으로 제공한다. 정확한 화면 좌표는 미확인이며 기사 Tesse의 무료 첫 승차·사이드 미션 88과 보상은 구현하지 않았다. 구역을 택시로 떠날 때 기존 이동과 같은 일시 조우 상태 정리를 수행한다. 실제 기기·운영 환경은 미검증이다.

갱신: 루주 승강장의 Tesse 무료 첫 승차와 사이드 미션 88이 구현되었다. 상세 조건과 원작 대비 차이는 [의뢰 기록](ADVENTURE_SIDE88_TESSE_20261112.md)을 참고한다.
