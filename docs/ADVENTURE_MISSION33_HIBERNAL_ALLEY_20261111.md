# 미션 33: 히베르날 골목 접근

[원작 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-33-a-rogue-mega-tyranitar)은 히베르날 포켓몬센터에서 남동쪽으로 이동한 뒤 남서쪽의 좁은 골목으로 들어가 메가마기라스에 도달하는 길을 설명한다. 기존 히베르날 접근로에서 이어지는 별도 지도에 센터 외관, 좁은 골목과 전투 장소를 연결하고 기존 턴제 전투와 보상 처리를 사용한다.

지도 크기, 건물 외관·센터 기능·진입점·세부 좌표는 확인되지 않은 2D 초안이다. 센터는 현재 랜드마크만 표시하며 내부나 회복 기능은 없다. 기존 북쪽 큰길의 사건 표식은 이전 저장과 미수령 보상을 위해 유지한다. 원작의 실시간 지형 공격과 동료 동시 전투는 구현하지 않았다.

[센터 위치 자료](https://thegamehaus.com/pokemon-legends-z-a/all-pokemon-center-names-and-locations-in-pokemon-legends-z-a/2025/10/15/)는 히베르날 포켓몬센터를 안내하며, [센터 이용 안내](https://howtovideogame.com/pokemon-legends-za-how-to-heal/)는 파티 회복을 설명한다. 기존 센터 외관 앞에 회복과 기존 상점 서비스를 연결했다. 건물 내부와 정확한 창구 위치는 확인되지 않았으므로 외부 상호작용 초안이며, 상품과 가격은 게임의 기존 상점 규칙을 사용한다. 이 문단이 위의 센터 기능 미구현 서술을 갱신한다.
