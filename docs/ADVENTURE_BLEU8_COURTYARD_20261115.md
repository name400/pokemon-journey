# 블루 8번지 안뜰

[블루 8번지 지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-8.html)는 안뜰과 그 주변의 아이템을 언급한다. 이는 2차 자료이며 안뜰의 정확한 윤곽과 입구는 확인되지 않았다.

기존 건물 블록 안에 안뜰과 접근로를 추가했다. 지도 위 위치·크기·입구는 압축된 2D 지도에 맞춘 추정이다. 기존 의뢰 16 표식, 미용실, 주변 출입구와 저장 필드는 유지한다. 원작 안뜰 아이템과 건물 옥상은 이번에 추가하지 않았다.

모바일 이동 오류와 Sites 병합본 실패 기록은 운영 재검증 전이므로 유지한다.
