# 마젠타 4번지의 거리와 작은 광장

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/magenta-sector-4.html)는 콰자르티코·마젠타 광장과의 연결, 작은 광장과 카페 포켓몬아미를 설명한다. 기존 2D 지도의 건물 외곽·포장길·녹지 경계를 구분해 카페와 홀로베이터에 이르는 경로를 읽기 쉽게 했다. 카페·깨봉이 의뢰, 옥상 접근과 구역 연결은 기존 기능을 사용한다.

건물 윤곽·높이, 녹지의 형태와 카페·시설의 격자 좌표는 원작에서 추출한 것이 아닌 2D 초안이다. 타일·충돌·풀숲 조우·의뢰·저장 위치는 바꾸지 않았다.

콰자르티코·인접 구역 연결, 홀로베이터·옥상 왕복과 저장 복원 단위 검사 5건 및 타입 검사가 통과했다. PC·모바일 Chromium에서는 모의 API로 거리 화면과 Fumi의 기존 의뢰 대화를 확인했다. 원작 기기·운영 D1·Sites 병합본은 확인하지 않았다.
