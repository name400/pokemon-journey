# 알기술 신고 조사

무장조의 거수참은 원본 포켓로그 `7c0881255af5cd51992e513ff93c2f71adbe40e0`의 `src/data/balance/moves/egg-moves.ts`에 두 번째 알기술로 명시돼 있다. 원본의 해당 네 기술은 날개쉬기·거수참·비검천중파·부리캐논이다. 본 프로젝트의 종 227 데이터와 기술 번호·표시도 동일하다. 원본 포켓로그의 알기술은 본가의 종별 학습 가능 기술 목록과 다를 수 있다.

`scripts/audit-source-egg-moves.mjs`는 고정된 원본 체크아웃을 입력으로 받아 종 이름·슬롯별 기술 이름을 로컬 전체 데이터와 대조하고, 각 기술의 원본 enum 번호와 실제 전투 엔진의 번호가 같은 기술인지 확인한다. 원본 571종, 고유 기술 398개에서 목록·번호 불일치 0건. `tests/rogue-egg-move-mapping.test.mjs`는 각 스타터의 각 비트 해금이 해당 종 슬롯의 기술을 허용하는지, 무장조 부화의 두 번째 슬롯 및 codec과 다른 저장 슬롯·탐험 데이터 보존을 검사한다. 기존 부화 검사와 함께 격리된 27baf46 트리에서 3/3 통과했다. 생성 UI 전체·모든 과거 저장의 지급 이력은 검사하지 않았다.

이 데이터는 이미 해금된 마스크와 현재 기술만 남기며 해당 기술이 어떤 경로로 지급됐는지 보편적으로 기록하지 않는다. 무장조 거수참은 원본상 정상이고, 임의의 종·기술 이상 여부만으로 잘못 지급됐다고 확정할 수 없다. 따라서 사용자 저장의 기술·PP·해금 비트를 일괄 삭제하거나 대체하지 않았다. 실제 원본 불일치 또는 잘못 지급된 사례의 기록과 재현이 확보되면 복사본/백업에서 해당 근거에 한정해 교정하고, 판별할 수 없는 사례는 보존한다. 운영 저장에는 접근하거나 변경하지 않았다.
