# 사이드 미션 62: 전문 트리미앙 미용사

[의뢰 자료](https://www.serebii.net/legendsz-a/sidemissions/becomingaprofurfroutrimmer.shtml)와 [미용 가격](https://bulbapedia.bulbagarden.net/wiki/Furfrou_%28Pok%C3%A9mon%29)을 참고해 첫 트리미앙 미용 의뢰와 미션 20 시작 이후 Mirte에게 후속 의뢰를 받고, 선두 포켓몬의 잎날가르기를 인형에 보여 주면 레이디컷·마담컷·젠틀컷을 해금한다. 각 미용은 기존 서비스와 같은 500원이며 포켓몬의 공유 종·폼 ID, 이로치·능력치·기술과 도구는 유지한다. 1,600원·기력의조각 3개·경험사탕 M 3개 보상은 가방에 공간이 생기면 받을 수 있고 리비전으로 중복을 막는다. 첫 의뢰 보상과 후속 의뢰는 서로 독립적이다.

기존에 검토된 로컬 이미지의 일반·이로치 앞뒤 아틀라스를 사용한다. 기존 의뢰와 같은 인형 및 Mirte 위치는 정확한 원작 좌표가 아닌 2D 초안이다. 털이 자라는 시간이나 필드 동행 외형은 아직 구현하지 않았다. 격리 API에서 해금·기술·보상 한도·중복·이로치와 공유 개체 정보 보존을 확인했다. 원작 실기·운영 D1·Sites 병합본은 확인하지 않았다.
