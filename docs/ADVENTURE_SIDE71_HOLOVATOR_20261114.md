# 사이드 미션 71: 우두머리 보르그와 승강기

미션 20 완료 후 마젠타 2번지 Chuckie에게 의뢰를 받아 홀로베이터의 우두머리 보르그 Lv.50을 포획하거나 쓰러뜨리면 승강기가 열린다. 승강기는 기존 마젠타 2번지 옥상으로 이어지고 그곳의 기존 복귀 경로를 사용한다. 1,200원·돌격조끼·만병통치약 3개는 따로 수령하며 가방 한도와 리비전으로 중복 지급을 막는다. 기권 후 재도전은 기존 이로치 상태를 유지한다.

[위치·해금과 보상](https://bulbapedia.bulbagarden.net/wiki/Mission_(Legends:_Z-A)), [포획·퇴치와 승강기](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_61-80)를 참고했다. 새 승강기와 의뢰인 좌표, 옥상 배치는 2D 초안이다. 구형 저장의 기존 옥상 진입과 탈출을 막지 않기 위해 이전 옥상 접근로도 그대로 유지한다. 보르그의 실제 기술·실시간 탐지와 원작의 정확한 승강기 연결은 미확인이다.

격리 API에서 해금 전 제한, 기권·이로치 보존·재도전, 포획 및 별도 퇴치, 승강기·기존 옥상 복귀, 가방 한도·중복 보상과 파티·기존 진행 보존을 확인했다. 실제 기기·운영 D1·Sites 병합본은 미검증이다.
