# 구역 8 정원 출입 조건

[구역 안내](https://www.nintendolife.com/guides/pokemon-legends-z-a-wild-zone-8-guide-all-pokemon-and-alphas)는 야생 구역 8이 랭크 F에서 열린다고 설명한다. 게임의 기존 구역 8 입구 대부분은 공통 해금 조건을 검사하지만 존느 정원 쪽 출입구는 빠져 있어 진행 전 진입이 가능했다. 해당 입구에도 기존 `zone7Unlocked` 조건을 적용했다. 이 조건은 이전 저장 호환을 위해 기존 미션 완료와 구형 진행 플래그도 허용하며, 원작 조건의 완전한 재현이라는 뜻은 아니다.

구역 8에서 정원으로 나가는 경로와 구형 저장은 제한하지 않는다. 정원과 구역 8의 화면 접점 및 좌표는 기존 2D 초안이며 원작의 정확한 접점은 확인하지 않았다. 격리 이동 및 SQLite API 검사에서 잠긴 진입, 해금 후 진입, 저장 복원과 이전 저장의 탈출 및 파티·재화 보존을 확인했다. 실제 운영 환경은 검사하지 않았다.
