# 먹다남은음식 중첩 회복량

고정 원본 `7c0881255af5cd51992e513ff93c2f71adbe40e0`의 `TurnHealModifier`는 최대 HP의 1/16을 정수로 내리고 최소 1로 만든 뒤 도구 개수를 곱한다. 기존 구현은 곱한 뒤 정수화해, 예를 들어 최대 HP 175에서 4개일 때 40 대신 43을 회복했다.

새 도전의 `leftoversRule: source-v2`에 원본 순서를 적용하고 전투 스냅샷에 보존했다. 기존 도전에는 기존 규칙을 유지한다. native 도구 1개와 modifier 3개의 혼합도 검사했다. 실제 턴의 1~4개 회복량, 저장 인코딩 복구, 독립 전투 스냅샷과 다른 저장 슬롯을 검증했다. 다이맥스 등 모든 특수 폼의 최대 HP 차이와 실계정 플레이는 별도 확인이 필요하다.

관련 도구·융합·챌린지 회귀는 일반 환경과 Worker에서 각각 142/142 통과했다. 이후 추가한 최대 HP 초과 방지 검사는 두 환경에서 각각 별도로 통과했으며, 타입 검사와 프로덕션 빌드도 통과했다. 전체 테스트 스위트는 이번에 실행하지 않았다.
