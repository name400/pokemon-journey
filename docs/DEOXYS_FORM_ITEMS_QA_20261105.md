# 데오키시스 운석 폼

원본 운석 3종은 노멀에서 공격·방어·스피드 폼을 각각 선택한다. 폼별 native 종과 능력치 6항목이 원본과 일치하는 경우에만 기존 폼 도구 상태·보상·전환 경로에 포함한다. 부정확한 폼·도구는 일반화하지 않는다. 획득 시 활성화하고 비활성화하면 노멀로 되돌리며 기존 운석 활성 상태·보유자를 보존한다. 융합 주체/기증자 양쪽과 포켓몬 분리도 지원한다.

3종별 실제 보상 선택·활성/해제·주체 및 기증자 융합·전투·codec·분리/도구 보존 테스트와 기존 활성 도구·팔레트·이미지 생성 회귀 일반 28/28, Worker 28/28 통과. 타입·production 빌드 통과. 실기기/운영 저장은 검증하지 않았다. `/tmp/deoxys-final.log`, `/tmp/deoxys-worker.log`, `/tmp/deoxys-type.log`, `/tmp/deoxys-build.log`.
