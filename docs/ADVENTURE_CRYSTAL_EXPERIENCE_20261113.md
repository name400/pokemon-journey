# 메가결정 경험치

[미션 5 공략](https://strategywiki.org/wiki/Pok%C3%A9mon_Legends%3A_Z-A/The_City_in_the_Shadow_of_Prism_Tower)과 [미션 20 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-20-a-request-from-the-rust-syndicate)은 결정 파괴로 경험치를 얻는다고 설명한다. 기존에는 옥상 튜토리얼·구역 9 옥상·미션 20 하수도에서 결정만 처리하고 경험치를 주지 않았다. 세 경로에서 파괴에 성공하면 선두 포켓몬에게 경험치를 주고, 레벨 상승과 기술 습득은 기존 육성 규칙을 따른다. 기술 선택이 필요한 경우 기존 선택 대기 절차를 사용한다.

자료에서 정확한 경험치와 분배 규칙을 확인하지 못해 현재는 선두에게 결정 하나당 50점을 주는 임시 규칙이다. 크기별 차이와 빨간 카나리 인형 보정은 확인되지 않아 적용하지 않았다. 과거에 부순 결정에 경험치를 소급하지 않으며, 최대 레벨에서는 경험치를 지급하지 않는다. 결정 상태·조각·경험치를 같은 저장에서 반영해 이미 부순 결정이나 이전 리비전 요청으로 중복 지급하지 않는다. 격리 API에서 세 경로와 재접속·중복·레벨 상승·기술 선택·최대 레벨을 확인했다. 원작 실기와 운영 환경은 미검증이다.
