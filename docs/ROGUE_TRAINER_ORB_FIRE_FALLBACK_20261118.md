# 트레이너 도구 재검사와 화산 진정 우선순위

`testfailed.md`의 밀로틱 독구슬 실패를 현재 개발 코드에서 격리 재검사했다. `tests/rogue-trainer-items.test.mjs`는 물 테라스탈 시 맹독, 독·강철 테라스탈 시 면역, 소지 도구와 시뮬레이터 복원을 확인했고 통과했다. 격리 SQLite API의 실제 턴·재조회·저장 보존 검사도 통과했다. 당시 실패한 저장과 실행 환경은 없으므로 당시 원인을 단정하지 않는다. 시험용 상태이며 운영 저장과 배포본은 확인하지 않았다.

별도로 이전 화산 이벤트 조사에서 남겨 둔 폴백의 대상 우선순위를 재현했다. 살아 있는 내열 특성 잠만보 뒤에 불꽃 타입 가디와 검증된 융합 포켓몬이 있으면, 저장된 대상이 없는 신형 경로가 잠만보를 선택했다. [고정 원본의 조건 순서](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/data/mystery-encounters/encounters/fiery-fallout-encounter.ts#L259)와 [조건 질의 순서](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/data/mystery-encounters/mystery-encounter-requirements.ts#L178)는 불꽃 타입을 특성보다 먼저 찾는다. 수정 전 신규 격리 검사는 `snorlax !== fire`로 실패했다.

수정은 저장된 대상이 없는 신형 규칙에서, 전원이 살아 있고 기본 폼·타입 또는 융합의 타입이 검증되는 경우로 제한한다. 이 경우 불꽃 타입을 우선 선택한다. 구형 규칙, 기절자나 미검증 폼 및 이미 저장된 대상은 기존 경로를 유지한다. 새 엔진 검사에서는 확정·저장 복원·경험치와 다른 슬롯 보존, 미검증·구형 경계를 확인했다. 격리 SQLite API에서는 잘못된 대상 거절 시 저장 불변, 올바른 선택·확정과 경험치 및 다른 슬롯 보존을 확인했다. 초기 시험의 파이리는 경험치로 진화 화면이 나타나 예상 보상 화면 단언이 실패했으므로 돌 진화 가디를 사용해 검사했다.

실제 자연 조우·모든 폼과 기절 조합, 브라우저·실기기와 전체 테스트는 이번에 검증하지 않았다. 기존 미추적 파일과 사용자 저장을 보존하고 Sites에 배포하지 않았다.
