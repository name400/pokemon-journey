# 루주 5번지 탐정사무소 거리

- [구역 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/rouge-sector-5.html)는 미션 5의 Emma가 탐정사무소 바깥 잔디 공간에 있다고 설명한다. [옷가게 안내](https://esports.gg/guides/pokemon/change-clothes-pokemon-legends-z-a/)는 파사주 옹브라제가 탐정사무소 서쪽에 있음을 설명한다. [옥상 안내](https://raiderking.com/pokemon-legends-z-a-pansage-pansear-and-panpour-locations-a-pan-tastic-pot-of-tea-guide/)는 사무소 오른쪽 홀로베이터를 언급한다.
- 기존 2D 맵의 사무소 건물·입구와 잔디 앞마당, 거리와 옥상 접근 장치, 동쪽 건물을 서로 구별되게 그렸다. 앞마당의 풀은 보행 가능한 시각 표현이며 야생 조우를 발생시키지 않는다. 기존 타일·충돌·사무소 및 이웃 구역 연결은 변경하지 않았다.
- 건물의 외관·크기, 앞마당과 도로 폭, 홀로베이터의 정확한 좌표는 이 게임의 추정이다. 원작 도시를 정밀 측량하거나 전체 동선을 재현한 것은 아니다.
- 구형 사무소 앞 저장 복원, 사무소 진입·복귀와 서쪽·북쪽 연결, 파티·재화·진행을 격리 API에서 확인했다. PC·모바일 Chromium 화면은 시험 데이터와 외부 이미지 대체물을 사용했으며 실제 운영 기기는 확인하지 않았다.
