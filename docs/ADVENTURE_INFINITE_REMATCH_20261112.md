# 무한 로열 20승 이후 보상 배틀

[Serebii의 무한 로열 보상 상대 목록](https://www.serebii.net/legendsz-a/z-aroyale/rankinfinity.shtml)은 20번째 배틀과 Jacinthe의 미션 이후 무작위 재대전을 설명한다. 새 미션 38 진행에는 이 해금 조건을 적용하고, 이미 진행 중인 구형 저장은 이전 접근을 유지한다. 티켓과 진행 중인 전투는 변환하지 않는다.

원작 기본 목록의 Josée·Asami를 재대전 후보에 추가했다. 지가르데 미션 완료 후에는 Andi와 동료 재대전도 후보에 포함하고 자료의 강화 레벨을 적용한다. 이미 진행 중인 전투 팀은 바꾸지 않는다. 지가르데 완료 시점은 큐브를 받는 미션 완료 상태로 판단한다.

상대 기술·메가진화, Asami의 플라제스 꽃색과 Andi의 지닌 도구는 원작 재현이 완료되지 않았다. 난수 추첨과 재대전 난이도는 격리 테스트로 확인했으며 실제 기기·운영 서버는 검증하지 않았다.
