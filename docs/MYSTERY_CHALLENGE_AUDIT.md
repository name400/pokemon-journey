# 미스터리 이벤트 챌린지 대조 메모

고정 원본의 `src/data/mystery-encounters/encounters`와 `mystery-encounter-requirements.ts`, 이 프로젝트의 `lib/rogue-mystery.mjs`를 비교한 작업 메모다. 아래는 확인한 범위이며 전체 이벤트·폼·난수 동등성 표가 아니다. `source-subset-v1` 챌린지에 한해 판정이 불명확한 저장은 임의 허용하지 않는다.

| 이벤트·경로 | 원본에서 확인한 조건 | 현재 상태·다음 검증 |
| --- | --- | --- |
| Mysterious Chest | 출전 가능 생존자 2명 이상 출현; 함정은 그중 최고 레벨; 남은 출전 가능 개체가 없으면 패배 | 자연 출현, 함정·패배·전투·저장 복구를 구현·검사했다. |
| Berries Abound 경주 | 출전 가능 생존자 중 가장 빠른 개체가 경주 | 경주 승패·보상·전투 복구를 구현·검사했다. |
| The Strong Stuff | 출전 가능 생존자 3명 이상 출현; 주스는 파티 전체에 적용 | 출현과 주스 대상 구분, 챌린지 자연 출현 후 전투 복구를 검사했다. |
| Part Timer·Shady Vitamin Dealer | 수동 선택은 출전 가능 개체를 요구 | 화면 후보·서버 선택·저장 복구를 검사했다. 원본의 자동 후보 추첨과 RNG는 전체 동등성이 아니다. |
| Uncommon Breed 매료 | 출전 가능하고 지정 기술을 가진 후보 중 난수로 참가자 선택 | 새 도전은 추첨을 한 번 저장한다. 기존 도전은 이전 방식이며 원본 Phaser 시드·재평가 순서와 다르다. |
| Fight or Flight·Slumbering Snorlax 훔치기 | 출전 가능하고 훔치기 기술을 가진 후보 중 난수 선택 | 새 도전은 추첨을 한 번 저장한다. 기존 도전과 원본 RNG 차이는 위와 같다. |
| Lost at Sea 방황 | 출전 가능한 생존자에게만 최대 HP의 25% 피해, 기절 방지 | 자연 출현·저장 복구 후 피해와 다른 슬롯 보존을 검사했다. |
| Lost at Sea 길 안내 | `CanLearnMoveRequirement.meetsRequirement`는 출전 가능자를 검사하지만 `queryParty`는 전달받은 파티를 기술 호환성으로만 거른다. 원본 옵션 처리에서 요구 조건 재평가·후보 추첨도 수행한다. | 현재 게임은 사용자가 안내자를 직접 선택한다. 원본의 실제 후보 범위·재추첨·난수 상태와 저장 복구 차이를 추가 검증해야 한다. |
| Fiery Fallout 진정 | 원본은 기절 제외 타입 조건과 출전 가능 능력 조건을 조합한다. | 조합 요구 조건의 후보 평가와 능력 억제·패시브·폼 처리를 대조해야 한다. 임의로 두 조건에 동일 필터를 적용하지 않았다. |

검사에서 실제 계정의 전체 플레이나 원본 RNG 상태를 전수 재현한 것은 아니다. 원본에서 비활성인 이벤트는 활성화하지 않고, 추가 운영 배포는 하지 않는다.
