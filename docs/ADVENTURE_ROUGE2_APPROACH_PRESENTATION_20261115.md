# 루주 2번지 식당과 거리 표현

[루주 2번지 위치 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/rouge-sector-2.html)는 학원·루주 광장·루주 스트리트·중앙 광장·이베르날 애비뉴와의 관계, 중앙 포켓몬센터와 갤러리, 레스토랑 르 와우의 옥상 아이템을 설명한다.

기존 초안 타일의 르 와우 입구와 건물 윤곽, 교차 보행로를 시각적으로 구분한다. 정확한 원작 건물 외형·좌표와 도로 폭은 확인하지 못해 기존 2D 추정으로 유지한다. 센터 및 옥상의 정확한 배치와 통행 관계는 추가 자료가 필요하다. 타일·충돌·출입과 저장 형식은 바꾸지 않았다.

기존 루주 2번지의 접근·식당 복원 테스트 및 모의 API를 이용한 PC·모바일 입구 대화 화면을 검사했다. 실제 운영이나 Sites 병합본 검증은 아니다. 모바일 D1 이동 오류의 운영 재검증 전 기록은 유지한다.
