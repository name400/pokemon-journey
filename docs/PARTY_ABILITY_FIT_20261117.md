# 파티 특성명 표시 검증

승인 v52 파티 상세의 특성 행 위치를 유지하면서 긴 특성명만 행 안에 맞추도록 했다. 격리 포켓로그 Chromium 280×568, 960×540에서 긴 이름, 현재 특성 우선, 알 수 없는 특성과 저장 보존을 확인했다. 타입 검사는 통과했다.

탐험은 추적 파일만 별도 복사한 서버에서 시험했다. 계정 API 503 후 계정 응답을 격리한 재시도에서도 전투 장면 대기 15초가 초과되어 탐험 브라우저 검증은 미완료다. 실제 기기와 승인 원본의 전체 픽셀 일치도 미검증이다. 운영 데이터 및 Sites는 변경하지 않았다.
