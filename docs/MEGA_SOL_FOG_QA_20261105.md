# 메가솔과 안개 기술 효과

원본의 `getEffectiveWeatherForMove`는 메가솔 보유자의 기술에 햇살을 우선 적용한다. 신규 도전의 `megaSolFogRule: source-v1`은 해당 사용자의 기술에 안개 명중률·회복량·위력 보정을 중복 적용하지 않는다. AI의 날씨 회복량 추정도 메가솔의 햇살을 사용한다. 기존 도전의 처리는 유지한다.

저장 복원 전투에서 광합성, 솔라빔과 날씨볼의 안개·맑음 결과를 비교했다. 일반 기술·일격기 명중률 이벤트, 패시브 메가솔, 특성 억제와 다른 저장 데이터 보존도 검사했다. 날씨 기반 다른 모든 기술과 특성·도구 조합, AI의 실제 대안 선택 경계 및 브라우저 플레이는 아직 검증하지 않았다. 운영 데이터와 Sites는 변경하지 않았다.
