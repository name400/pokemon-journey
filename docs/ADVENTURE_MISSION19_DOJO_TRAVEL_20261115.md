# 미션 19 정의단 도장 빠른 이동

[미션 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-19-reaching-rank-d)은 Josée에게 승리한 후 정의단 도장이 지도 이동 지점으로 추가된다고 설명한다. 승리 직후 도장 바깥으로 나가면 지도에서 도장 입구 앞으로 이동할 수 있도록 연결했다. 도장 앞 좌표는 기존 2D 지도에 맞춘 초안이며 원작의 정확한 착지 위치는 확인하지 않았다. 택시 목적지는 별도 근거가 없어 추가하지 않았다.

신규 승리 기록과 이전 저장의 미션 19 후속 단계·완료·랭크 D 이상의 명시적 진행을 이용해 해금 여부를 계산한다. 별도의 기록을 저장하거나 기존 이동 지점 목록을 덮어쓰지 않으므로 알 수 없는 목록 형식도 그대로 보존한다. 격리 API에서 실제 승리 전후 표시, 실내에서 도장 밖으로 나온 뒤 이동·재접속, 오래된 요청 거절 및 파티·기존 지점 보존을 확인했다. 구형 진행의 해금 판정도 단위 검사했다. 자료는 2차 출처이며 원작 실기·운영 D1·Sites 병합본은 검증하지 않았다.
