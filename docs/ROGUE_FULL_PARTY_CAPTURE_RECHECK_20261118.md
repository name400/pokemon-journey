# 파티 6마리 포획 검증 (2026-11-18)

- 독립 메모리 fixture의 6마리 파티와 마스터볼을 사용했다. Chromium 390×844 및 1280×800에서 각각 볼 선택 취소 시 미소모, 실제 포획 후 새로고침, 기존 멤버 교체와 도감 등록 후 놓아주기를 검사했다. 네 경로 모두 볼 1개 소모, 파티 6마리 유지, 다른 슬롯과 탐험 데이터 보존을 확인했다. 종·레벨·볼은 테스트용으로 구성한 값이다.
- 격리 SQLite API에서 포획 후 복원, 잘못된 교체 대상 거절, 같은 확인 요청 두 번 중 한 번만 반영, 교체와 놓아주기 후 저장 복원을 확인했다. 도감의 포획 횟수도 한 번만 증가했다. 별도의 엔진 회귀 6건은 울트라볼 성공·실패·볼줍기·6마리 교체/놓아주기를 검사했다.
- 볼 던지기 전의 취소와 포획 성공 후의 놓아주기는 서로 다른 동작이다. 현재 성공 후 선택 화면의 놓아주기는 도감 등록을 유지한다. 실제 기기, 운영 계정, 모든 챌린지·더블 전투 조합은 확인하지 않았다. 운영 데이터와 Sites는 변경하지 않았다.
