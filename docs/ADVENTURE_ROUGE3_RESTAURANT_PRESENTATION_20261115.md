# 루주 3번지 식당과 거리 표현

[르 예 자료](https://bulbapedia.bulbagarden.net/wiki/Restaurant_Le_Yeah)는 오토널 애비뉴의 레스토랑 건물이 루주 3번지에 있다고 설명한다. [지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/rouge-sector-3.html)는 이 지역의 건물과 볼 부티크를 기록한다. 기존 건물·도로를 구분하고 실제 식당 입구 상호작용을 표시했다. 별도의 기존 식당 안내 표식은 입구와 구분해 표시한다.

식당·부티크의 격자 위치, 건물의 외형·높이 및 거리 선형은 기존 2D 추정이다. 원작의 정확한 옥상·비계 경로는 이 작업에서 추가하지 않았다. 타일·충돌·식당과 상점 상호작용·저장은 변경하지 않았다.

식당 접근·출입·기존 위치 복원 검사 2건과 타입 검사가 통과했다. 모의 API를 사용한 PC·모바일 Chromium 화면과 식당 입구 대화를 확인했다. 원작 기기와 실제 Sites 병합본은 확인하지 않았다.
