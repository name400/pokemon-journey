# 미션 34: Philippe 재대결과 Lida의 회복

[원작 미션 자료](https://www.serebii.net/legendsz-a/mainmissions/aroguemegastarmie.shtml)는 Philippe의 강철톤·핫삼·보스로라 Lv.56, 무장조 Lv.57과 각 기술, 무장조나이트 및 승리 보상 3,648원을 기록한다. 새 재대결에 확인된 기술과 무장조나이트를 적용했다. CPU는 기존 포켓몬식 턴제 엔진의 메가진화 규칙을 사용한다.

[사건 공략](https://strategywiki.org/wiki/Pok%C3%A9mon_Legends%3A_Z-A/A_Rogue_Mega_Starmie)은 아쿠스타를 진정시킨 뒤 Lida가 파티를 회복한다고 설명한다. 승리 시 파티의 HP·상태·PP를 회복하고, 메가스톤은 기존과 같이 별도 수령한다. 이미 진행 중인 전투 스냅샷과 과거 보상 상태는 바꾸지 않는다.

옥상과 접근 좌표는 초안이며 원작 실시간 공격, 동료 동시 전투와 세부 대사는 재현하지 않았다. 운영 기기에서는 검증하지 않았다.
