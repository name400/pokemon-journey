# 베르 1번지 건물 안뜰과 거리 표현

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-1.html)는 베르 1번지의 건물 사이 골목과 북쪽 건물 내부의 안뜰, 주변 거리 연결을 설명한다. 기존 두 건물의 외곽과 안뜰 바닥을 거리와 구분해 표시했다. 별도의 세존 운하변 층에는 이 표현을 적용하지 않았다.

건물의 형태·크기, 안뜰 입구와 도로의 격자 좌표는 기존 2D 초안이며 원작에서 측량한 값이 아니다. 자료에 나오는 바위 장애물, 안뜰 사다리와 실제 옥상 접근 관계는 이번에 추가하지 않았다. 기존 타일·충돌·동선·저장은 변경하지 않았다.

기존 안뜰과 출입·저장 복원 검사 2건 및 타입 검사가 통과했다. 모의 API를 사용한 PC·모바일 Chromium 화면을 확인했다. 원작 기기와 실제 Sites 병합본은 확인하지 않았다.
