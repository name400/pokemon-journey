# 타입 기술 위력 강화 특성 대조

이번 표는 확인한 특성만 다루며 전체 전투 동등성 표가 아니다. 기준은 제공 ZIP에 대응하는 고정 원본 `7c0881255af5cd51992e513ff93c2f71adbe40e0`의 `src/data/abilities/init-abilities.ts`, `ab-attrs.ts`, `src/field/pokemon.ts`, `src/data/moves/move.ts`다. 원본 저작권·AGPL 고지는 유지한다.

| 특성 | 원본 규칙 | 네이티브 기본과 차이 | 적용 범위 |
| --- | --- | --- | --- |
| 트랜지스터 | 전기 기술 위력 ×1.3 | 공격·특수공격 보정 대신 위력 보정 | 기존 `typedPowerRule: source-subset-v1` 및 v2 |
| 용의턱 | 드래곤 기술 위력 ×1.5 | 위와 같음 | v1 및 v2 |
| 강철술사 | 강철 기술 위력 ×1.5 | 위와 같음 | 새 `source-subset-v2` |
| 바위나르기 | 바위 기술 위력 ×1.5 | 위와 같음 | 새 v2 |
| 심록 | 낮은 HP에서 풀 기술 위력 ×1.5 | 위력 단계 및 HP 경계 | 새 v2 |
| 맹화 | 낮은 HP에서 불꽃 기술 위력 ×1.5 | 위와 같음 | 새 v2 |
| 급류 | 낮은 HP에서 물 기술 위력 ×1.5 | 위와 같음 | 새 v2 |
| 벌레의알림 | 낮은 HP에서 벌레 기술 위력 ×1.5 | 위와 같음 | 새 v2 |

`MoveTypePowerBoostAbAttr`와 `LowHpMoveTypePowerBoostAbAttr`는 기술의 위력을 강화하고, `calculateBattlePower`는 그 뒤에 동일 테라 타입의 비선제·단발 기술 최소 위력 60 조건을 검사한다. 예를 들어 위력 40인 물 기술은 급류로 위력 60이 된 뒤 최소 위력 조건을 통과한다. 공격 능력치를 강화하는 기존 방식은 최소 위력 60을 먼저 적용한 뒤 공격을 강화하므로 피해가 달라질 수 있다.

낮은 HP 조건은 정확한 `hp/maxhp <= 1/3`이 아니다. 원본의 `getHpRatio()` 기본값은 정수 퍼센트로 반올림하며 해당 특성 조건은 이 비율이 0.33 이하인지 검사한다. 최대 HP 341에서 HP 114(약 33.43%)는 원본에서 발동하고 네이티브 기본에서는 발동하지 않는다. HP 115(약 33.72%)에서는 발동하지 않는다. v2는 이 경계와 공격할 때의 현재 HP를 사용한다.

새 도전의 규칙 표지만 v2로 생성한다. 기존 v1은 트랜지스터·용의턱의 앞선 수정만 유지하고 추가 여섯 특성에는 이전 네이티브 동작을 유지한다. 규칙이 없는 도전도 변경하지 않는다. 전투별 Dex에서만 콜백을 바꾸며 일반·패시브에 공통 적용하고 같은 특성의 중복 가산을 방지하는 기존 어댑터를 사용한다. 전투 스냅샷의 기존 `typedPowerRule` 저장 경로를 그대로 사용한다.

## 검사와 남은 범위

`tests/rogue-typed-power-v2.test.mjs`는 다음을 실제 네이티브 전투로 검사한다.

- 추가 여섯 특성 각각의 물리·특수 공격과 일반·패시브, 상대 트레이너의 일반·패시브 공격.
- 저위력 테라스탈 및 선제 기술, 기존 v1과의 실제 피해 차이.
- 네 스타터 특성의 낮은 HP·정수 퍼센트 경계·경계 직후·최대 HP.
- 다른 타입 보존, 위액·화학변화가스 억제, 동일 일반·패시브 중복 방지.
- 실제 encode/decode 저장 후 낮은 HP·규칙·패시브·테라스탈 공격과 다른 슬롯·재화 보존.
- 새 도전의 v2 선택, 기존 v1 유지 및 공유 Dex 미변경.

피해 비교 검사는 명중·급소·피해 난수 일부를 고정했다. 모든 분수 위력·반올림·날씨·필드·도구·특성 교환·변신·융합·다중 배율 조합과 자연 진행 실계정·모바일 플레이는 미검증이다. 다른 기술·특성·도구와 이벤트의 미완성 대조는 계속해야 한다. 이번 변경은 UI나 Sites를 수정하지 않는다.

최종 검사: 전체 회귀 634개 통과(실패·취소·건너뜀 0), 타입 검사·빌드·변경 파일 ESLint·diff 공백 검사 통과. 기존 v1 타입 위력 회귀도 유지된다.
