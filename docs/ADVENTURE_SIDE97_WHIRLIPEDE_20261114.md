# 사이드 미션 97: 달아난 휠구

[원작 공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-097-stop-the-runaway-whirlipede)과 [의뢰 자료](https://www.serebii.net/legendsz-a/sidemissions/stoptherunawaywhirlipede.shtml)를 참고해 미션 35 시작 후 Rouland에게 의뢰를 받고 휠구를 따라잡아 레벨 59 휠구와 배틀한다. 의뢰 개체는 포획할 수 없으며, 승리 후 3,900원과 퀵볼·리피트볼 각 3개를 받는다. 볼 한도 또는 재화 한도에 걸리면 보상을 보류하고 저장 리비전으로 중복 수령을 막는다. 진행 중 위치는 저장되며, 기권이나 패배 후 재도전할 수 있다. 기존 파티·보유함과 구형 저장을 변경하지 않는다.

휠구는 남쪽 대로에서 플레이어가 이동할 때마다 기존 서버 요청 안에서 일정 간격으로 한 칸씩 움직이고, 플레이어가 가까이 오면 멈춘다. 접근·배틀은 상호작용으로 처리한다. 별도 폴링은 없고 위치·간격·경로와 턴제 추적은 실시간 원작의 정확한 물리가 아닌 2D 초안이다. 자료에는 의뢰 위치가 남쪽 대로와 북쪽 대로로 엇갈려 남쪽 대로의 임시 위치를 사용했다. 원작 기기에서의 정확한 이동 동작과 해금 시점, 휠구의 세부 기술은 확인하지 못했다.

격리 SQLite API에서 이동 중 추적·비포획·기권·재도전·승리·재접속·볼 한도·중복 요청과 기존 파티를 확인했다. 단위 검사에서 가까울 때 정지, 별도 층과 알 수 없는 미래 저장 보존을 확인했다. PC·모바일 Chromium에서는 모의 API와 대체 이미지로 필드와 배틀 안내를 확인했다. 실제 이동 지연·원작 기기·운영 D1·Sites 병합본은 확인하지 않았다.
