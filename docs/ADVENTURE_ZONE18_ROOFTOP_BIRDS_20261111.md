# 구역 18 옥상 조우

[원작 현장 안내](https://www.videogameschronicle.com/guide/pokemon-legends-z-a-wild-zone-18/)는 옥상에서 낮에 파비코와 파비코리, 밤에 음뱃과 음번을 만날 수 있다고 설명한다. [구역 자료](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_18)는 각 종의 레벨 범위를 제시한다. 기존 옥상층의 두 통행 칸에 낮·밤에 따른 개체를 추가하고, 기존 게임 시간과 조우·포획 기록을 재사용했다. 정확한 2D 좌표와 개체별 레벨은 해당 범위 안의 초안이다.

낮·밤 전환은 기존 서버 시간 확인 방식에 따른다. 도망치면 다시 만나고, 처치·포획하면 기존 구역 18 방식대로 구역을 벗어날 때까지 해당 개체가 사라진다. 원작의 개체 이동과 부활 시간, 푸호꼬의 하루 한 번 출현·도주 행동, 일반 우두머리 확률은 이번에 구현하지 않았다. 기존 옥상 바닥과 저장 좌표는 유지한다.
