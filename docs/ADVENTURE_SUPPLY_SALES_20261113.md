# 프렌들리숍 회복 도구·볼 판매

회복 도구와 판매 가능한 일반·특수 볼을 기존 프렌들리숍 판매 목록에서 판매한다. 가격은 Z-A 기준으로 [상처약 37원](https://bulbapedia.bulbagarden.net/wiki/Potion), [슈퍼볼 75원](https://bulbapedia.bulbagarden.net/wiki/Great_Ball), [기력의덩어리 500원](https://bulbapedia.bulbagarden.net/wiki/Max_Revive) 등 각 품목 자료와 대조했다. 현재 게임에 구현된 여덟 종류의 일반 특수 볼과 기본 몬스터볼을 지원한다. 마스터볼과 Z-A에서 판매 불가로 기재된 희귀 볼은 목록과 서버 허용 목록에서 제외한다. 기존 구매 가격은 이번에 변경하지 않았다.

기본 볼·일부 회복 도구는 지갑 열, 일반 특수 볼과 구형 맛있는물은 탐험 상태, 나머지 회복 도구는 가방에 저장된다. 지갑 열의 차감은 리비전·보유량·잔고 상한을 같은 D1 배치의 선행 UPDATE에서 확인하고, 상태와 가방도 기존 리비전 및 재고 조건으로 보호한다. 판매 보상과 재고 변경은 같은 배치에 있다. 기존 저장 형식은 변경하지 않으며 없는 볼 기록은 0개로 취급한다.

격리 API에서 전 품목 가격과 세 저장 방식, 구형 맛있는물, 기존 구매, 재고 부족, 상점 밖, 금지 품목, 오래된 revision, 잔고 상한 및 옛 저장 복원을 확인했다. 귀중품·진화석 판매 회귀와 타입 검사도 통과했다. PC·모바일 Chromium 화면은 모의 API·시험 데이터와 대체 이미지를 사용했다. 실제 운영 D1과 물리 기기는 검사하지 않았다. 다른 가방 도구의 판매는 별도 작업이다.
