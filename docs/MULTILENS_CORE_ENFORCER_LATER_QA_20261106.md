# 멀티렌즈 코어퍼니셔 후속 타격의 특성 억제

신규 도전에서 코어퍼니셔의 후속 타격도 적중한 첫 대상의 특성 억제를 다음 대상의 피해 계산 전에 적용한다. 이전 `source-v1` 저장은 첫 타격만 순차 처리하던 규칙을 유지한다.

첫 타격에 대타출동이 깨지고 두 번째 타격에서 날씨 억제 특성이 해제되는 경우, 햇살과 선파워가 두 번째 대상 피해에 반영되는 것을 아군·상대 전투에서 확인했다. 방어, 대타출동 유지, 특성가드, 미행동, 억제 불가 특성, 저장 복구 및 다른 슬롯 보존을 격리 검사했다. 다른 패시브 특성·폼·원본 난수 전체 조합과 운영·실기기 플레이는 별도 검증이 필요하다.
