# Z-A 도입 스타터 기술

[원작 공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Part_1)은 세 스타터의 첫 기술과 첫 승리 후 레벨 6 기술을 설명한다. 새 도입 선택에서 몸통박치기와 꼬리흔들기(리아코는 째려보기)를 지급하고, Andi에게 승리하면 레벨 6에 필요한 최소 경험치와 나뭇잎·물대포·불꽃세례를 지급한다. 경험치 수치 자체는 기존 턴제 환산이다.

새 도입 저장의 버전 표식에 한해 적용하며 이미 선택한 스타터와 진행 중인 전투를 수정하지 않는다. 이후 레벨의 기술 목록은 기존 공유 데이터를 따르므로 원작 Z-A의 전체 기술 습득표와 일치한다고 보장하지 않는다. 원작 실기 직접 검증은 하지 않았다. Sites 병합본의 기존 실패 기록은 별도 검증 전 유지한다.

## 도입 기술 다시 배우기

[기술 변경 안내](https://www.dexerto.com/wikis/pokemon-legends-z-a/how-to-teach-pokemon-new-moves/)는 레벨로 배운 기술을 다시 선택할 수 있다고 설명한다. 새 도입의 스타터는 원작에서 확인한 첫 두 기술과 레벨 6 기술을 기존 기술 관리에서 다시 선택할 수 있다. 레벨 6 기술은 레벨이 부족하면 추가하지 않고, 칸이 가득 찬 상태에서 습득 대기에 올라온 기술도 동일한 조건으로 선택한다. 새 저장에는 스타터 개체 ID를 기록한다. 직전 버전의 ID 없는 저장은 기존 스타터 출처와 종 또는 도입 중 활성 개체를 기준으로 처리하며 포켓몬이나 저장을 이주시키지 않는다. 진화 후 기술 목록과 다른 종·다른 레벨의 Z-A 기술표는 후속 확인이 필요하다.

격리 SQLite API에서 세 스타터의 다시 배우기·재접속·중복 요청과 치코리타의 기술 대기를 확인하고, 단위 검사에서 다른 개체·구형 저장·레벨 제한을 확인했다. 원작 실기·운영 D1·Sites 병합본은 검증하지 않았다.

## 초기 레벨 기술 보완

도입에서 선택한 미진화 스타터에 한해 치코리타의 9·12·14레벨, 리아코의 10·15레벨, 뚜꾸리의 10·13·15레벨 기술을 원작 학습 정보에 맞춰 추가했다. [치코리타](https://pokemondb.net/pokedex/chikorita/moves/9), [리아코](https://pokemondb.net/pokedex/totodile/moves/9), [뚜꾸리](https://pokemondb.net/pokedex/tepig/moves/9)의 Z-A 구간과 대조했다. 전투 경험치와 사탕으로 해당 레벨을 지날 때 기존 기술 칸·대기열을 사용하고, 삭제한 기술은 같은 스타터의 기술 관리에서 다시 선택할 수 있다. 이미 선택한 기술과 이전 저장에 허용된 기술은 삭제하지 않는다. 기존 기술표에 따른 추가 기술이 여전히 나올 수 있으며 진화형과 나머지 레벨의 원작 학습표는 미완성이다.

스타터 식별 표식이 없는 구형 저장·다른 개체는 기존 규칙을 유지한다. 단위 검사와 격리 API에서 레벨 경계, 기술 칸 한도, 기존 PP, 사탕 소모, 재접속과 오래된 요청 거부를 확인했다. 원작 실기·운영 D1·Sites 병합본은 검증하지 않았다.

## 스타터 진화 기술과 다시 배우기

도입 스타터가 진화할 때 원작에서 확인된 기술을 제안한다. 베이리프·메가니움은 기가드레인·리프블레이드, 엘리게이·장크로다일은 베어가르기·깨물어부수기, 차오꿀·염무왕은 그로우펀치·히트스탬프다. 각각 [베이리프](https://pokemondb.net/pokedex/bayleef/moves/9), [메가니움](https://pokemondb.net/pokedex/meganium/moves/9), [엘리게이](https://pokemondb.net/pokedex/croconaw/moves/9), [장크로다일](https://pokemondb.net/pokedex/feraligatr/moves/9), [차오꿀](https://pokemondb.net/pokedex/pignite/moves/9), [염무왕](https://pokemondb.net/pokedex/emboar/moves/9)의 Z-A 진화 기술 자료를 참고했다. 기존 기술이 네 개면 대기열을 사용하며 진화 후에도 초기 확인 기술과 해당 진화 기술을 다시 선택할 수 있다. 두 번째 진화형은 첫 진화 기술도 다시 선택할 수 있다.

선택한 스타터의 저장 ID 또는 이전 저장의 스타터 종과 버전 표식을 확인하며, 식별할 수 없는 저장과 다른 개체는 이전 진화 기술 처리를 유지한다. 이미 익힌 기술이나 PP는 삭제하지 않는다. 이전에 적용한 확인된 초기 레벨 기술도 진화한 스타터가 아직 해당 레벨을 지나지 않았다면 받을 수 있다. 높은 레벨의 나머지 원작 학습표와 원작 실기·운영·Sites 병합본은 확인하지 않았다. 여섯 기술의 빈칸·가득 찬 칸·다시 배우기와 구형 분기를 단위 검사했고, 격리 API에서 진화·재접속·대기열·중복 요청과 도구·이로치·PP 보존을 확인했다.

## 스타터 계열의 이후 레벨 기술

도입 스타터 세 계열의 나머지 레벨 기술을 [치코리타](https://pokemondb.net/pokedex/chikorita/moves/9), [리아코](https://pokemondb.net/pokedex/totodile/moves/9), [뚜꾸리](https://pokemondb.net/pokedex/tepig/moves/9)의 Z-A 기술표에 맞춰 기존 학습 흐름에 추가했다. 차오꿀·염무왕의 벌크업과 염무왕의 인파이트는 해당 진화 단계에만 적용한다. 전투·사탕 레벨 상승과 기술 관리에서 같은 조건을 쓰며 기존 스타터 식별·기술·PP·구형 저장을 보존한다. 기존 다른 작품의 학습표도 호환을 위해 유지하므로 원작에 없는 추가 선택지가 나올 수 있고, 다른 포켓몬과 스타터가 아닌 동종 개체의 원작 기술표는 이번 범위가 아니다.

세 계열의 대표 레벨 경계·진화 단계·가득 찬 기술 칸과 다른 개체 보존을 단위 검사했다. 격리 API에서 염무왕의 레벨 45 사탕·선택 대기·재접속·중복 요청과 도구·이로치·PP를 확인했다. 원작 실기·운영 D1·Sites 병합본은 확인하지 않았다.

## 새 도입 스타터의 Z-A 레벨 기술표

새로 도입에서 선택한 스타터에는 별도 V2 표식을 부여한다. 이 개체의 레벨업과 기술 관리는 확인한 Z-A 레벨·진화 기술을 사용하여 다른 작품의 기술이 자동으로 추가되지 않는다. 예를 들어 치코리타는 레벨 9에 독가루 대신 차밍보이스를 제안한다. 앞의 기술표 혼합 설명은 기존 V1 저장에 대해서는 유지된다. 이미 선택한 기술과 PP는 지우지 않으며, 이전 저장·표식이 없는 저장·다른 개체의 학습 및 다시 배우기 선택지도 바꾸지 않는다. 새 스타터가 아닌 일반 개체의 Z-A 기술표는 여전히 미완성이다.

세 스타터의 도입·레벨 6, 새 기술표와 기존 저장 분기, 진화 후 다시 배우기를 단위 검사했다. 격리 API에서 실제 도입 선택·레벨업·사탕 소모·대기열·재접속·낡은 요청과 이전 저장 선택지 보존을 확인했다. 원작 실기·운영 D1·Sites 병합본은 확인하지 않았다.
