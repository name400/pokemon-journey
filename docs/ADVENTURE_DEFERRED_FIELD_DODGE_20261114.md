# 이동 중 구르기 입력

[원작 조작 설명](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_battle_%28Legends%3A_Z-A%29)은 이동과 구르기를 지원한다. 이 프로젝트에서는 구르기를 기존 서버의 최대 두 칸 이동으로 구현하며, 원작의 실시간 전투나 회피 무적을 재현하지 않는다.

이동 요청이 진행되는 동안 구르기를 누르면 이미 화면에 예측된 경로의 정상 확정을 기다린 뒤 한 번 실행한다. 대기 중 추가 경로를 예측하지 않으며, 다른 이동 입력·메뉴 열기·포커스 이탈은 예약을 취소한다. 충돌이나 불일치, 구역 전환, 조우·기술 선택, 통신 오류·복구에서도 실행하지 않는다. 요청하지 않은 예측 경로가 남은 경우에는 예약하지 않고 다시 누르도록 안내한다. 서버 리비전·충돌·저장 규칙은 바꾸지 않았다.

PC·모바일 Chromium과 모의 API에서 일반 확인, 연속 예측 경로, 충돌 보정, 조우, 응답 실패, 메뉴 취소와 새 이동 입력을 검사했다. 원작 기기, 실제 브라우저와 D1 간 네트워크 지연, 두 탭 경합은 이번 검사의 범위가 아니다.
