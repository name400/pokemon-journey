# 야생 구역 14의 보이는 무작위 우두머리

[구역 14 출현 자료](https://pente.koro-pokemon.com/legendsz-a/map-wild-zone-14.shtml)는 조사 완료 후 일반 필드 출현이 약 5% 확률로 우두머리가 될 수 있다고 설명한다. 기존에는 풀밭 전투에서만 이 판정이 있었고 지도에 표시되는 일반 개체에는 없었다. 구역 14에서 새로 생성된 표시 개체에 기존 구역 조사·미션 해금 조건과 [종별 레벨 범위](https://www.serebii.net/pokearth/lumiosecity/wildzone14.shtml)를 적용하고, 지도에도 우두머리 표시를 연결했다. 고정 우두머리는 별도로 유지한다.

개체의 색과 우두머리 레벨을 함께 저장해 재접속·도주 후에도 같은 개체가 보인다. 시간대 전환 때는 기존 출현 갱신과 같은 기준으로 일반 개체를 바꾸며, 남아 있는 이로치의 우두머리 여부는 보존한다. 포획·처치하거나 이로치 보관에서 제거되는 경우 관련 기록을 정리한다. 구형 저장에서 이미 색이 결정된 개체와 진행 중인 배틀은 새로 추첨하지 않는다. 원작의 정밀한 필드 배치·실시간 이동·출현 시점은 기존 2D 근사이며, 이 기능은 우선 구역 14의 표시 개체에만 적용된다.

격리 API에서 새 이로치 우두머리의 필드 표시·배틀·도주·재접속·직접 포획·중복 요청과 구형 일반 개체 보존을 확인했다. 출현 주기 전환, 이로치 보존 및 10개 제한 정리도 단위 검사했다. PC·모바일 Chromium에서는 모의 API와 대체 스프라이트로 필드 표시·상호작용·새로고침을 확인했다. 실제 기기·운영 D1·Sites 병합본은 확인하지 않았다.

후속: 이 기능은 [다른 구역의 고정 위치 표시 개체](ADVENTURE_VISIBLE_RANDOM_ALPHAS_20261113.md)로 확장되었다. 이동 개체와 땅속 출현 등은 해당 문서의 제한을 따른다.
