# 포획 경험치

[원작 야생 포획 안내](https://strategywiki.org/wiki/Pok%C3%A9mon_Legends%3A_Z-A/Gameplay)는 포획 뒤 경험치를 얻는다고 설명하며, [육성 안내](https://www.dexerto.com/wikis/pokemon-legends-z-a/how-to-gain-xp-fast/)는 야생 포켓몬을 쓰러뜨린 뒤 포획하면 추가 경험치를 받는다고 설명한다. 기존 탐험 모험은 쓰러뜨린 경우에만 경험치를 줬으므로, 미르시티에서 실제 포획에 성공하면 필드 직접 투척·전투 중 볼·쓰러진 뒤 포획 기회 모두 기존 파티 성장 흐름에 포획 경험치를 지급한다. 이미 쓰러뜨려 승리 경험치를 받았다면 성공한 포획에서 별도 경험치를 받는다.

정확한 원작 포획 경험치 수식과 파티 분배율은 확인하지 못했다. 당분간 기존 야생 승리 경험치 계산과 선두·대기 분배, 빨간 인형 보정을 재사용하는 임시 규칙이다. 살아 있는 기존 파티원만 받으며, 기절한 파티원과 방금 잡은 개체에는 지급하지 않는다. 포획에 실패하거나 기회를 넘기면 포획 경험치를 주지 않고, 이미 완료한 과거 포획은 소급하지 않는다. 경험치·배울 기술 대기·볼 소모·포획 개체는 기존 리비전 조건을 가진 같은 저장 작업에서 처리한다. 포획 자체로 노력치를 추가하지 않는다.

격리 SQLite API에서 세 포획 경로, 선두·대기·기절 개체, 실패 후 성공, 기술 학습 대기, 재접속 및 오래된 요청의 중복 거부를 대표 검증했다. 실제 원작 기기, 정확한 수식, 전체 스토리 난이도와 운영 데이터는 검증하지 않았다.
