# 날씨볼의 적 AI 평가

신규 도전의 `enemyAiWeatherBallRule: source-v1`은 격리된 전투 복제본에서 날씨볼의 타입·위력 변경을 계산하고, 메가솔 사용자의 실제 날씨 우선순위를 적용해 기절 후보와 원시 날씨 취소 여부를 판단한다. 기존 도전의 선택은 유지한다. 공유 기술 데이터와 다른 저장 슬롯을 변경하지 않는다.

원본의 날씨볼 타입·위력과 원시 날씨 취소 조건을 대조했다. 햇살에서의 기절 선택과 메가솔·시작의바다에 의한 공격 취소를 이전 동작과 비교했고, 날씨부정·노말스킨·패시브 메가솔 및 저장 복원을 검사했다. 여러 날씨의 평가가 공유 기술 데이터를 변경하지 않는 것도 확인했다.

남은 범위: 원본의 강풍 등 모든 날씨에서 날씨볼의 실제 실행과 평가 동등성, 다이맥스·다른 타입 변경 특성·타입 효과의 모든 조합, AI 대상·교체·난수와 실제 브라우저 플레이는 별도 구현 또는 검증이 필요하다. 운영 데이터와 Sites는 변경하지 않았다.
