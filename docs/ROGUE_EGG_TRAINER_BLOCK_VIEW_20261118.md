# 트레이너의 시험 중 알 뽑기 안내

기존 동작은 트레이너의 시험이 종료되기 전 알 뽑기 요청을 거절하지만 알 상점에는 차단 사유가 없어 교환권이 있으면 뽑기 버튼이 활성화됐다. 화면과 요청이 같은 차단 사유 판정을 사용하게 하여 실제 제한과 안내를 일치시켰다. 시험 종료 전 제한과 웨이브 보상 선택 중 제한의 우선순위·기존 처리 조건은 유지한다.

격리 저장 직렬화·복원, 다른 슬롯 선택, 시험 종료 및 웨이브 보상 상태에서 안내와 명령 제한을 검증했다. 소유권을 확인한 독립 fixture 서버와 Chromium 390×844·1280×800에서 사유 표시, 뽑기 버튼 비활성화, 새로고침 후 표시와 시험 저장 불변을 확인했다. 첫 브라우저 스크립트는 새로고침 후 슬롯 선택 화면을 잘못 가정해 대기 시간이 초과됐고, 실제 복원되는 상점 화면을 확인하도록 고친 후 두 크기에서 통과했다. 실제 기기·운영 저장은 검증하지 않았다.
