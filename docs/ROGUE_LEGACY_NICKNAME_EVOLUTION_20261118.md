# 종 ID로 확인되는 구형 별명의 진화 보존

기본 종명 필드가 없는 구형 개체도 원본 종 ID와 실제 포켓몬 ID가 일치하고 저장 이름의 앞부분이 종명과 다르면 `별명 · Normal` 같은 이름이 별명임을 구분할 수 있다. 종명 필드가 없다는 이유로 수동 또는 자동 진화 시 이 이름을 새 종명으로 덮는 결함을 격리 재현했다.

기존 화면용 검증을 재사용해 명확히 식별되는 비융합 개체의 별명만 진화 후 보존한다. 종명으로 시작하는 알 수 없는 폼 이름, ID 누락·불일치, 융합 개체는 새로 추측하지 않고 이전 동작을 유지한다. 저장을 일괄 변경하지 않는다.

수동·자동 진화 실제 명령, 저장 직렬화·복원, 다른 슬롯·탐험 데이터, 기존 별명·융합·자동 진화 관련 39건이 통과했다. 공유 메모리 여유가 작아 다른 작업을 방해할 수 있는 별도 브라우저 서버는 실행하지 않았다. 브라우저·실기기 및 모든 구형 저장은 미검증이다. Sites에는 배포하지 않았다.
