# 카페·경험사탕의 친밀도

[원작 친밀도 자료](https://bulbapedia.bulbagarden.net/wiki/Friendship#Pok%C3%A9mon_Legends:_Z-A)에 따라 탐험에서 구현된 카페 음료의 선두 포켓몬 친밀도 기본 증가량을 30으로 통일했다. 파티 회복·가격·연구 기록은 그대로이며, 성공한 주문에만 적용한다. 평온의방울·럭셔리볼에는 기존 탐험 보정 함수를 사용한다. 두 보정의 원작 내 정확한 적용 순서와 반올림은 실기 미확인이다.

경험사탕 XS·S·M·L·XL에는 레벨업과 별개의 친밀도 증가를 적용한다. 사용 전 친밀도 0~99는 각각 1·1·2·3·4, 100~159는 1·1·1·2·2이며 이 사탕 보너스는 160에서 멈춘다. 기존 레벨업 보너스와 기술 선택은 유지한다. 이 게임은 사탕 보너스를 레벨업 보너스보다 먼저 적용하며 원작의 정확한 처리 순서는 확인하지 못했다. 경험사탕과 무관한 기존 레벨업의 160 상한, 걷기·다른 방법의 원작 친밀도 규칙은 아직 전체적으로 구현하지 않았다. 기존 저장은 소급 변경하지 않는다.

격리 API에서 여러 카페의 결제·파티 회복·중복 거절, 평온의방울 보정, 사탕 재고·보유자·중복 처리와 카페를 통한 리오르 진화를 확인했다. 사탕 종류별 친밀도 구간·상한·잘못된 저장은 단위 검사했다. 타입 검사도 통과했다. 실제 원작 기기·PC/모바일 화면·운영 D1·Sites 병합본은 확인하지 않았다.
