# 베르 4번지와 베르 광장 지상길

[베르 4번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-4.html)는 베르날 애비뉴에서 베르 광장으로 이어지는 길을, [베르 광장 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-plaza.html)는 남서쪽 베르 4번지 접근을 설명한다. 기존 화면에 양방향 지상 출입을 추가했다. 출입 타일의 좌표와 길의 모양은 측량되지 않은 2D 초안이다.

기존 옥상·안뜰 층과 출입구, 저장 형식을 유지하며 알 수 없는 층 기록을 덮어쓰지 않는다. 원작 실기 및 실제 Sites 병합본은 확인하지 않았다. 모바일 이동 오류 기록은 운영 재검증 전까지 유지한다.
