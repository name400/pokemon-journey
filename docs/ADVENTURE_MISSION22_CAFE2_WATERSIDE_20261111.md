# 미션 22: 누보 카페 2호와 물가 접근

[원작 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-22-a-rogue-mega-barbaracle)은 누보 카페 2호 북동쪽의 물가를 돌아 계단을 내려가 북서쪽 터널과 얼음 다리를 지나 거북손데스에게 가는 경로를 설명한다. 블르 5번지 서쪽에 카페와 물가 화면을 추가하고 북동쪽 계단에서 기존 터널로 연결했다. 새로운 진입은 터널을 나올 때 해당 계단으로 복귀하며, 이전 진입 및 반환 정보가 없는 옛 저장은 기존 블르 5번지로 돌아간다.

카페·물가·계단의 상세 좌표와 수역 윤곽은 2D 초안이다. 카페는 현재 경로를 설명하는 표식이며 상점 기능은 없다. 원작의 실시간 동료·소환 포켓몬·공격 연출은 재현하지 않았다. 기존 얼음 다리·턴제 전투·보상과 저장을 보존한다.

[카페 자료](https://bulbapedia.bulbagarden.net/wiki/Nouveau_Caf%C3%A9_%28Truck_No._2%29)는 카페 2호점의 음료가 파티를 회복하고 선두 포켓몬의 친밀도를 올린다고 설명한다. [가격 목록](https://www.serebii.net/legendsz-a/cafes.shtml)에 따라 맛있는물 100원, 튼튼밀크 200원, Ember Roast 250원을 주문할 수 있다. 친밀도 증가량은 이 게임의 임시값 1이며 정확한 원작 수치는 확인하지 못했다. 전체 음료 메뉴, 잔액이 없는 손님에 관한 원작 대사·정책과 배틀존 중 영업 조건, 빠른 이동은 미구현이다. 이 항목이 위의 카페 기능 없음 설명을 갱신한다.
