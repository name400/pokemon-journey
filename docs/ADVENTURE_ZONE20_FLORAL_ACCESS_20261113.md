# 야생 구역 20 남쪽 플로랄 대로 접근

[원작 구역 설명](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_20)은 중앙의 무너진 프리즘타워와 네 주변 지형, 남쪽의 플로랄 대로 출입을 설명한다. 기존 맵은 지형 구분과 타워 유적을 가지고 있었지만 남쪽 출구가 임시 센트리코 경로로만 이어졌다.

기존 출구를 유지하고 구역 20 남쪽 경계와 플로랄 대로 북쪽 사이의 왕복 경로를 추가했다. 다른 구역 20 입구와 같은 본편·미션 42 진행 조건을 적용하며, 첫 진입에서 기존 우두머리 생성 경로를 사용한다. 구역과 플로랄 대로의 기존 통행 타일, 저장 위치, 중앙 유적, 서쪽 건조 지대와 도시 지대, 동쪽 물길 및 연못 통로는 유지한다.

새 출입구의 타일 좌표와 화면 간 거리, 지형 경계와 유적 높이는 2D 초안이다. 자료에서 확인한 남쪽 대로와의 연결을 반영한 것이며 원작 지도·높낮이를 정밀하게 재현했다는 뜻은 아니다. 남쪽의 기존 센트리코 출구도 구형 경로 호환을 위해 남아 있다.

구역 단위 검사와 격리 SQLite API에서 잠긴 진입·미션 42 단계별 제한, 신규 왕복·재접속, 우두머리 생성, 기존 동서 출구·조우 및 저장·파티·재화·아이템 보존을 대표 확인했다. PC·모바일 Chromium 화면은 모의 상태와 대체 이미지를 사용했으며 원작 실기기·실제 운영 환경은 확인하지 않았다.
