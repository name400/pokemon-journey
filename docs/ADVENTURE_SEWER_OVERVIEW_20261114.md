# 하수도 현재 구역 지도

[미션 19 공략](https://www.thonky.com/pokemon-legends-z-a/main-mission-19-reaching-rank-d)은 하수도에서 도시 지도 대신 하수도 지도를 볼 수 있다고 설명한다. 지도 메뉴에 현재 서버가 보내는 하수도 본 통로·서쪽 얼음 분기·문 안쪽 통로의 타일과 플레이어 위치를 표시한다. 열린 얼음다리는 실제 맵 상태를 따르며 다른 층은 미리 표시하지 않는다. 기존 2D 맵을 축소한 안내이므로 원작 하수도의 정확한 평면도가 아니다. 지도 열기는 이동·저장·보유함 쓰기나 추가 서버 조회를 하지 않는다.

지도 데이터와 재접속 좌표·얼음다리, 기존 이동 예측 및 불켜미 포획·재진입을 대표 검사했다. React 컴포넌트의 서버 렌더링을 확인했으나 Chromium은 격리 환경에서 화면 출력이 완료되지 않아 PC·모바일 실제 화면을 확인하지 못했다. 원작 기기와 운영 데이터도 검증하지 않았다.

후속 진단: 기본 Chromium 실행은 headless 사용자 디렉터리 생성에 실패했다. 쓰기 가능한 별도 사용자·설정·캐시 디렉터리를 지정하면 프로세스는 시작하지만 18초 제한 안에 정적 컴포넌트 출력도 끝나지 않았다. 로그에는 D-Bus 연결 및 읽기 전용 OOM 조정 오류가 있었으나 화면 대기의 직접 원인은 확인하지 못했다. 제한을 우회하지 않았고 PC·모바일 화면은 여전히 미검증이다. 이는 `testfailed.md`의 별도 모의 브라우저 초기 화면 실패가 해결되었다는 의미가 아니다.
