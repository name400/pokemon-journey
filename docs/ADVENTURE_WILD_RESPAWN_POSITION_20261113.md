# 고정 야생 개체 재출현과 저장 위치

시간 구간이 바뀔 때 고정 야생 개체를 재출현시키는 기존 처리에서, 플레이어가 포획 후 비어 있는 출현 칸에 서 있으면 개체가 같은 칸에 생길 수 있었다. 구역 8의 딥상어동 칸에서는 출현 타일이 통행 불가여서 이후 저장 복원 시 도시 위치가 해제되는 문제가 격리 API에서 재현됐다.

구역 5·6·8~19의 고정 출현은 현재 플레이어 칸에 소진된 개체가 다시 나타나야 하는 경우 시간대 갱신을 미룬다. 플레이어가 이동한 뒤에는 다음 안전한 조회 또는 행동에서 갱신한다. 대기 중 구형 저장, 포획 상태, 파티, 재화와 이로치 기록은 변경하지 않는다. 구역 2·3의 이동 개체는 별도의 위치 겹침 방지 처리를 사용한다.

구역 8의 통행 불가 칸과 구역 19의 일반 칸에서 시간 경과·재조회·이동 후 재출현을 격리 API로 검사했다. 실제 운영 D1·다른 탭과 원작 기기는 검사하지 않았다.
