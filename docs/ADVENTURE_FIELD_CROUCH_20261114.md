# 필드 웅크리기

[원작 조작 안내](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_battle_%28Legends%3A_Z-A%29)는 웅크리면 야생 포켓몬과 트레이너가 플레이어를 발견하기 어려워진다고 설명한다. 필드에서 C 또는 버튼으로 자세를 바꾸며, 기존 저장은 기본적으로 서 있는 상태다. 이 게임의 2D 근사에서는 기존에 반응이 구현된 구역 2 꼬몽울, 구역 3 냐스퍼와 야생 우두머리 구구에만 적용한다. 웅크린 플레이어가 한 칸 옆에 있을 때 새 경계·도주를 막지만, 같은 칸에 닿거나 이미 경계 중인 경우는 기존 반응을 유지한다. 한 칸 범위와 웅크린 이동 간격 150ms는 게임의 임시값이며 원작 수치가 아니다.

상태는 월드의 리비전 조건으로 저장하며 파티·야생 개체·이로치·가방을 직접 변환하지 않는다. 필드 외 행동과 전투·포획·기술 선택 중에는 자세를 변경할 수 없다. 다른 야생 개체·트레이너의 실제 시야, 엄폐물과 뒤쪽 판정, 원작 실시간 전투는 구현 범위 밖이다. 격리 SQLite API 및 단위 검사에서 자세·기존 저장·이로치·위치·중복 요청과 반응 범위를, PC·모바일 Chromium에서는 모의 API로 조작과 재접속을 확인했다. 운영 D1과 원작 기기는 확인하지 않았다.
