# 프렌들리숍의 필수 회복 도구

기존 상점의 지갑형 상품 목록에서 빠져 살 수 없던 기력의조각과 만병통치약을 가방형 상품으로 추가했다. [원작 초반 포켓몬센터 판매표](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Part_3)는 기력의조각 800원을, [만병통치약 가격표](https://bulbapedia.bulbagarden.net/wiki/Full_Heal)는 200원을 명시한다. 기존 프렌들리숍 접근 조건을 이용한다. 만병통치약의 원작 세부 판매 해금 시점은 확인하지 못했으므로 동일하다고 주장하지 않는다.

구매는 서버 가격과 수량·가방 상한·잔액·리비전을 확인하고 대금과 수량을 함께 저장한다. 이미 있던 가방 수량과 구형 `zaRevives`는 별도로 유지한다. 격리 SQLite API에서 구매·재접속, 기존 보유 수량, 허용되지 않은 상품, 공간·잔액 부족과 이전 리비전 요청을 확인했다. 모의 API와 대체 이미지를 사용한 PC·모바일 Chromium에서 기력의조각 구매 화면을 확인했다. 실제 운영 D1과 물리 기기는 검사하지 않았다.
