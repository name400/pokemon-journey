# v52 기술 설명 버튼 및 상성 배율 정렬

사용자 요청에 따라 단일 v52 기술 설명 i의 보이는 지름을 최대 12px에서 최대 16px로 늘리고 포켓로그 입력 영역의 폭을 44px에서 56px로 확장했다. 탐험 단일에도 같은 폭 증가와 아이콘 변경을 적용했다. 네 기술을 같은 화면에 유지하기 위해 세로 입력 영역은 행 간격 내로 제한하며, 280px에서는 약 19px로 44px보다 작다.

격리 포켓로그 Chromium 280×568, 320×568, 390×844, 844×390, 1280×800에서 네 설명 영역의 사각형 및 모서리 안쪽 적중점이 서로, 기술 및 메가 버튼과 충돌하지 않는지 확인했다. 각 설명 열기·닫기, 데스크톱 키보드, 저장 불변과 실제 기술 선택도 통과했다. 280·320px 특수 선택 메뉴 및 메가 X/Y, 원시회귀·합체 단일·더블 버튼의 대표 회귀도 통과했다. 기존 반복 설명 검사는 장시간 실행 후 중단하여 전체 통과로 취급하지 않는다. 점 입력 검사는 실기기 손가락 오터치율을 증명하지 않고, 탐험 브라우저 검증도 미완료다.

추가로 포켓로그 단일 기술창의 상성 문구와 실제 배율이 붙어 표시되던 것을 원본처럼 좌우로 정렬했다. 280×568, 390×844, 844×390, 960×540에서 동일 기술·상성의 원본 HTML과 세 행의 좌표를 비교하고 실제 화염방사 요청 및 저장 불변을 확인했다. 원본 포켓몬·타입 이미지 부재로 전체 화면 픽셀 일치와 실기기 사용성은 미검증이다. 사용자 데이터와 Sites는 변경하지 않았다.

## 탐험 단일 기술창 상성 정렬 추가 비교 (2026-11-18)

승인 v52 원본과 같은 데이터의 390×844 화면에서 탐험 기술창 상성 문구의 왼쪽 시작점이 원본의 논리 좌표 255px보다 약 1.02px 왼쪽인 것을 확인했다. 원본의 1px 안쪽 여백을 장면 비율에 맞춰 적용하고 문구와 실제 배율의 양끝 정렬을 유지했다. 기존 정보 버튼, 기술 입력 영역과 서버 판정은 바꾸지 않았다.

격리 Chromium에서 280×568, 320×568, 390×844, 844×390, 1280×800의 원본 HTML과 각 상성 문구·배율의 좌우·상단 좌표를 비교했고, PP 및 기술명, 입력 영역 비중첩과 실제 기술 요청을 확인했다. 격리 포켓로그 단일의 네 화면 크기 원본 상성 좌표와 기술 요청도 회귀 통과했다. 최초 전체 검사 중 격리 서버가 메모리 부족으로 종료돼 독립 서버를 제한된 힙으로 다시 실행한 결과다. 실제 모바일 기기와 전투 화면 전체의 픽셀 일치는 미검증이다.

추가 자산 확인: v52 매니페스트의 타입 아이콘 13개는 현재 `public/game/type-icons`의 같은 번호 파일과 SHA-256이 각각 일치하고 해당 타입 이미지 경로에 사용된다. 나머지 타입의 승인 원본 일치 여부나 5개 포켓몬 원본 PNG 수신 여부까지 확인한 것은 아니다.

## 기술 설명과 특수 변화 메뉴 겹침 (2026-11-18)

격리 포켓로그 단일 배틀의 390×844 화면에서 기술 설명을 열면 설명창과 특수 변화 메뉴가 약 23.5px 높이로 겹치는 것을 재현했다. 승인 v52 원본에는 설명 버튼이 없지만 사용자가 별도로 요청한 정보 버튼과 포켓로그의 특수 변화를 함께 보존해야 한다. 승인 단일 화면에서 설명이 열려 있는 동안 메뉴를 숨기고, 설명을 닫으면 같은 메뉴와 선택 상태를 복원한다. 다중 배틀의 메뉴 동작은 변경하지 않는다.

280×568, 320×568, 390×844, 844×390, 1280×800의 격리 Chromium에서 네 설명 버튼의 열기·닫기, 메뉴 숨김·복원, 선택 영역 비중첩과 메가 Y 예약 후 실제 기술 명령을 검사했다. 1280×800에서는 키보드 Enter도 확인했다. 390×844에서 수정 전 메뉴와 설명의 화면 사각형이 겹치고 수정 후 메뉴가 숨겨져 겹치지 않는 것을 별도로 측정했다. 실제 기기와 전체 화면의 승인 원본 픽셀 일치는 미검증이다.
