# 존느 8번지 거리와 리테이크 카페 외관

- [원작 시설 설명](https://bulbapedia.bulbagarden.net/wiki/Caf%C3%A9_Action%21)은 리테이크 카페가 존느 8번지의 북쪽 큰길 부근에 있다고 설명한다. [야생 구역 19 안내](https://bulbapedia.bulbagarden.net/wiki/Wild_Zone_19)는 구역 19가 존느 8번지에 있음을 확인한다. 구역 입구의 초록색 홀로그램과 기둥은 [입구 화면](https://www.gamerguides.com/pokemon-legends-z-a/guide/wild-zones/jaune-sector-8/all-wild-zone-19-pokemon-locations)에서 참고했다.
- 기존 화면의 도로·포켓몬센터·가게·야생 구역 출입 경로를 유지하면서 카페 외관과 입구, 포장된 교차로 및 구역 입구를 구분해 그린다. 카페 안내는 외관만 제공하고 내부·메뉴·빠른 이동은 구현하지 않는다.
- 압축된 도시 맵에서 카페의 정확한 좌표, 건물 외관·폭, 도로와 포켓몬센터의 배치 및 출입구 정렬은 추정이다. 원작 전체 지형을 실측한 결과가 아니다. 기존 벽과 이동 판정은 바꾸지 않고 카페 입구만 기존 보행 칸에 추가하므로 그 칸의 구형 저장도 보존한다.
- 격리 API에서 카페 칸 저장·재접속, 포켓몬센터 접근, 구역 19 출입 및 기존 진행·지갑·파티 보존을 확인했다. PC·모바일 Chromium 화면은 시험 API 상태와 외부 이미지 대체물을 사용했으며 실제 운영 기기는 확인하지 않았다.
