# 마젠타 3번지와 에스티발 대로 지상 접근

[마젠타 3번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/magenta-sector-3.html)는 남쪽 에스티발 대로 접근을, [대로 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/estival-avenue.html)는 북쪽 마젠타 3번지 접근을 설명한다. 기존 지도에는 두 곳의 직접 지상 경로가 없었다.

기존 지상 화면에 왕복 접근을 추가했다. 출입 좌표와 길의 폭·선형은 원작에서 측정되지 않은 2D 추정이다. 기존 마젠타 1·6번지, 에스파스 비드, 야생 구역 접근·랭크 제한 및 홀로베이터·옥상 경로는 유지한다. 이전 통행 칸을 막지 않으며 저장 형식과 미션 진행 상태를 바꾸지 않는다.

대표 단위 검사에서 양방향 이동·저장 복원, 기존 출입·랭크 제한과 홀로베이터·옥상을 확인했다. 최초 검사에서는 해금 진행값이 든 시험 상태를 잠긴 상태로 잘못 가정해 실패했고, 잠긴 상태를 명시한 뒤 같은 검사가 통과했다. 원작 실기·운영 D1·실제 Sites 병합본은 확인하지 않아 모바일 이동 오류와 배포 검사 실패 기록을 유지한다.
