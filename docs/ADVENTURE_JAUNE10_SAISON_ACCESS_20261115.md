# 존느 10번지와 세존 운하 산책로 연결

[존느 10번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-10.html)는 서쪽·남쪽의 세존 운하 산책로를, [운하 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/saison-canalside.html)는 북쪽의 존느 10번지 접근을 설명한다. 모두 2차 자료다.

기존 지상 화면 사이에 왕복 출구를 추가했다. 접점과 도로 방향은 압축된 2D 지도의 잠정 배치이며, 구역 11 내부 진입이 아니다. 기존 구역 11 랭크 제한과 출입구, 물길·인접 지역, 저장 형식을 유지한다.

모바일 이동 오류와 Sites 병합본 실패 기록은 운영 재검증 전이므로 유지한다.
