# 사이드 미션 33: 더 큰 잉어킹

[Serebii](https://www.serebii.net/legendsz-a/sidemissions/whohasthebiggermagikarp.shtml)와 [현장 공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-033-who-has-the-bigger-magikarp)에 따라 미션 14 시작 뒤 베르 4번지에서 Kingsley의 의뢰를 받고, 구역 2의 우두머리 잉어킹을 포획해 파티에서 보여 줄 수 있다. 기존 우두머리·이로치·포획 처리와 보유 개체는 수정하지 않는다. NPC의 정확한 좌표는 기존 2D 지도의 추정 배치다.

확인된 보상은 1,500원·진주 1개·경험사탕 S 10개다. 가방에 남은 공간만큼 수령하고 나머지는 맡길 수 있으며, 저장 리비전과 남은 수량으로 재접속·중복 요청 시 재지급을 막는다. 알 수 없는 미래 보상 형식은 건드리지 않는다. 아직 일반 개체의 상세 크기 체계가 없으므로 원작의 정확한 크기 비교 대신 실제 우두머리 잉어킹 여부를 확인한다. 다른 크기의 잉어킹 인정 여부는 실기 미확인이다.

격리 SQLite API에서 의뢰 해금, 일반 잉어킹 거절, 구역 2 우두머리 포획·제시·재접속, 부분 수령과 중복 요청, 기존 파티와 포획 개체 데이터 보존을 확인했다. 이로치 경로는 기존 포획 처리를 재사용하며 이번에 별도 검사하지 않았다. 포획 경험치에 따른 정상 성장은 허용한다. 원작 실기·운영 D1·Sites 병합본은 검증하지 않았다.
