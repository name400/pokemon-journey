# 단일 메가 선택의 중복 메뉴

승인 v52 기술창에서 사용 가능한 특수 선택지가 메가 하나뿐이면 별도의 특수 변화 메뉴를 숨긴다. 메가 아이콘으로 예약·해제하며, 기술 확정 때 기존 명령에 예약값을 전달한다. X/Y 등 선택지가 둘 이상이거나 다른 특수 선택지가 함께 있으면 메뉴를 유지한다.

격리 포켓로그 Chromium의 280×568, 390×844, 1280×800에서 응답의 메가 선택지를 하나로 제한하여 토글·변신 전 저장 불변·실제 명령 전달을 확인했다. 선택지 둘의 기존 X/Y 메뉴·명령과 타입 검사도 통과했다. 단일 선택지는 시험 응답 조정이고 실제 기기 및 탐험 브라우저는 검증하지 않았다. 운영 데이터와 Sites는 변경하지 않았다.
