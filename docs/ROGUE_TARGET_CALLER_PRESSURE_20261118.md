# 상대 대상 호출 기술과 프레셔 PP

고정 원본 `7c0881255af5cd51992e513ff93c2f71adbe40e0`에서 흉내내기와 자연의힘은 상대를 대상으로 사용한다. 원래 기술의 프레셔 비용은 해당 대상 기준으로 차감하고, `CallMoveAttr`가 생성한 `FOLLOW_UP`은 추가 PP를 소모하지 않는다. 기존 엔진은 호출된 공격에서도 원래 기술의 PP를 추가로 차감했다.

신규 도전 `calledTargetPressureRule: source-v1`에서 흉내내기·자연의힘 후속 기술의 추가 차감만 생략한다. 원래 기술의 대상과 프레셔 비용은 유지하고 구형 저장은 기존 동작을 보존한다. 잠꼬대와 자기 대상 호출 기술은 별도 규칙을 유지하며 지시하기는 변경하지 않는다.

각 기술의 실제 격리 단일 전투와 저장 복원, 더블 전투에서 자연의힘의 전체 공격 및 서로 다른 프레셔 대상의 PP를 확인했다. 흉내내기·자연의힘·다른 호출 기술·잠꼬대 관련 검사 76건이 통과했다. 원본은 코드 대조이며 원본 게임 런타임, 실기기·브라우저, 흉내내기의 모든 더블 대상과 특수 변화 조합은 미검증이다. 운영 데이터와 Sites 배포는 사용하지 않았다.
