# 사이드 미션 91: 드래곤 타입 배틀

[의뢰 공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-091-dragon-you-into-battle)과 [트레이너 편성](https://bulbapedia.bulbagarden.net/wiki/Mission_(Legends:_Z-A)/Trainers)을 참고해 미션 31 시작 후 베르 3번지의 Guivre에게 의뢰를 받아 Lv.47 한바이트·Lv.48 쉘곤·Lv.49 신뇽과 싸운다. 세 포켓몬은 용의이빨과 자료에 기재된 기술을 지닌다. 2D NPC 좌표는 초안이며 실시간 대전은 기존 턴제로 근사한다.

승리 상금은 트레이너 편성 자료의 3,332원이다. 의뢰 공략은 4,998원으로 달리 기재하므로 실제 기기 대조 전 잠정값이다. 의뢰 보상 5,000원·용의이빨·하반열매 5개는 별도 수령하며, 가방이 가득 차면 수령을 보류한다. 패배·기권 후 재도전, 재접속 및 리비전 중복 거절을 기존 흐름으로 처리한다. 구형 저장에 완료나 보상을 임의 생성하지 않는다.

격리 API에서 해금 전 거절·의뢰·편성·지닌 도구·기권 후 재도전·승리·가방 한도·중복 수령·파티 보존을 검사했다. 실제 원작 기기·운영 D1·Sites 병합본은 확인하지 않았다.
