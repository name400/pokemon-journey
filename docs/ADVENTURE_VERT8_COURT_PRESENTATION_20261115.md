# 베르 8번지 전투장과 보행면 표현

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-8.html)는 호텔 Z, 포켓몬센터, 전투장 인근 건물과 주변 접근을 기록한다. [야생 구역 1 안내](https://www.nintendolife.com/guides/pokemon-legends-z-a-wild-zone-1-guide-all-pokemon-and-alphas)는 호텔 남쪽과 베르 8번지 인근의 관계를 설명한다. 기존 화면의 건물 윤곽·전투장 바닥과 호텔 방향 보행면을 구분했다.

건물 모양과 전투장·길의 정확한 좌표는 기존 2D 초안이다. 호텔과 구역 1은 별도 화면으로 압축되어 있으며 원작의 옥상·안뜰과 세부 높이 관계는 이 작업에서 추가하지 않았다. 기존 타일·충돌·진행·출입·저장은 변경하지 않았다.

베르 8번지와 호텔·구역 1의 왕복 및 저장 복원 검사와 타입 검사가 통과했다. 모의 API를 사용한 PC·모바일 Chromium 화면을 확인했다. 원작 기기와 실제 Sites 병합본은 확인하지 않았다.
