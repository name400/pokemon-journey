# 야생 구역 13 북쪽 대로 숲

- 자료: [Bulbapedia 구역 13](https://bulbapedia.bulbagarden.net/wiki/Wild_Zone_13), [Pokémon GO Hub 야생 구역 안내](https://pokemongohub.net/post/guide/all-wild-zones-pokemon-legends-z-a/), [Gamer Guides 구역 13](https://www.gamerguides.com/pokemon-legends-z-a/guide/wild-zones/north-boulevard-2/).
- 확인된 관계: 루주 구역 7 북쪽의 북쪽 대로에 위치하며 도로 양쪽 숲에 야생 포켓몬이 산다. 북쪽에는 대로트, 남쪽에는 우츠동이 나타난다.
- 기존 동서 도로 및 남쪽 출입과 야생 개체·아이템 좌표를 보존하고 양쪽 숲 안에 통행이 막히는 나무와 풀숲 외형을 추가했다. 여덟 나무의 좌표 및 숲의 구체적인 형태는 압축된 2D 초안이다. 이번 변경은 원작 가시덤불 제거, 도로 지형이나 시가지 연결 전체의 재현을 의미하지 않는다. 새 나무가 차지한 여덟 칸은 더 이상 랜덤 조우 풀숲이 아니다.
- 구형 저장 위치가 새 나무와 겹칠 경우 같은 리비전에서 인접한 통행 가능 칸으로 복원한다. 이전 소지품·진행과 조우 상태를 유지한다.
- PC·모바일 화면은 모의 API 데이터로 로컬 브라우저에서 확인했고, 외부 이미지 로딩을 차단해 포켓몬 이미지는 대체 표시다. 운영 환경을 검증한 것은 아니다.
