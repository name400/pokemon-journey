# 블루 9번지 안뜰

[블루 9번지 지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-9.html)는 건물 단지의 안뜰과 별도로 미션 20의 오래된 건물을 언급한다. 이는 2차 자료이며 두 시설의 정확한 관계, 안뜰의 윤곽과 입구는 확인되지 않았다.

기존 건물 블록에 지상 안뜰을 추가했다. 위치·크기·입구는 압축된 2D 지도에 맞춘 추정이며 오래된 건물과 동일한 건물이라는 뜻은 아니다. 기존 미션 20 입구, 주변 출입구와 저장 필드는 유지한다. 원작 안뜰 아이템과 옥상은 이번에 추가하지 않았다.

모바일 이동 오류와 Sites 병합본 실패 기록은 운영 재검증 전이므로 유지한다.
