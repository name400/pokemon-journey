# 베르 3번지 안뜰 표현

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-3.html)는 북동쪽 안뜰의 생울타리와 분수, 주변 광장·수로 접근을 설명한다. [Nintendo Life](https://www.nintendolife.com/guides/pokemon-legends-z-a-the-many-flowers-of-flabebe-side-mission-where-to-find-all-five-colours)는 베르 3번지 안뜰의 플라제스 분수를 기록한다. 기존 북동쪽 건물과 안뜰의 바닥을 시각적으로 구분했다.

건물 크기·외형, 출입구와 분수의 격자 좌표, 생울타리 모양은 정확한 원작 측량이 아닌 2D 초안이다. 자료의 남쪽 건물 안뜰·옥상과 실제 높이 관계는 이번 작업에서 새로 구현하지 않았다. 타일, 충돌, 출입, 의뢰와 저장은 변경하지 않았다.

직전 베르 광장 작업에서 종료됐던 타입 검사는 개발 서버 정리 후 통과했고 이번 변경 후에도 통과했다. 베르 3번지 안뜰 및 주변 안뜰 연결 검사 3건과 모의 API를 사용한 PC·모바일 Chromium 화면 검사가 통과했다. 원작 기기와 실제 Sites 병합본은 확인하지 않았다.
