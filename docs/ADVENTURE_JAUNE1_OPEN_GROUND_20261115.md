# 존느 1번지 지상 구역

[위치 자료](https://bulbapedia.bulbagarden.net/wiki/Jaune_Sector_1)는 존느 1번지가 건물이 없는 구역이며 프리즘타워 동쪽·존느 3번지 서쪽에 있고 이베르날 애비뉴와 존느 스트리트에 접한다고 설명한다. 건물이 없는 지상 화면을 추가하고 기존 중앙 광장 접근, 존느 3번지, 이베르날, 존느 스트리트와 왕복 연결했다.

도로 선형·출입구 좌표·화면 축척과 바닥 무늬는 원작 화면에서 검증되지 않은 2D 추정이다. 원작과 동일한 정확한 경계나 높이라고 확정하지 않는다. 주변의 기존 출입·미션 12 옥상·구역 8의 해금 조건과 저장 형식을 유지한다.

네 방향 왕복, 기존 잠금·옥상 분리와 저장 복원, 모의 API PC·모바일 화면을 검사했다. 실제 운영이나 Sites 병합본은 확인하지 않았다. 모바일 D1 이동 오류 기록은 운영 재검증 전까지 유지한다.
