# 야생 구역 14 변전소

- 자료: [Nintendo Life 구역 14 안내](https://www.nintendolife.com/guides/pokemon-legends-z-a-wild-zone-14-guide-all-pokemon-and-alphas), [Poképédia 구역 14](https://www.pokepedia.fr/Zone_sauvage_n%C2%B0_14).
- 확인된 특징: 변전소 내 북서쪽 건물, 중앙 전력 설비와 가장자리 흙 지형. 우두머리 몰드류는 중앙 설비 근처에 출현한다.
- 기존 건물과 출입구·흙 지형·야생 개체·아이템을 유지하며 중앙 변전 설비 네 칸과 출입구 및 건물로 이어지는 작업 통로를 추가했다. 기기 형태, 개수·정확한 좌표와 통로 배치는 압축된 2D 맵의 초안이며 원작과 동일한 배치로 확인된 것은 아니다. 기존 시가지 연결도 원작과 일치한다고 검증된 것은 아니다.
- 이전 저장이 새 설비와 겹치는 경우 같은 리비전의 위치만 인접 통행 가능 칸으로 이동한다. 기존 소지품·진행 및 바위 상태는 유지한다.
- PC·모바일 화면은 모의 API 데이터와 외부 이미지 대체 화면을 사용해 로컬 브라우저에서 확인했다. 실제 운영 환경 검사는 아니다.
