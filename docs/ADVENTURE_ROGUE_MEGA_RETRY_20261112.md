# 미션 11~13 폭주 메가 재도전

[원작 공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Part_11)은 폭주 전투에서 패배하면 상대의 남은 HP에 따라 75%, 50%, 25%부터 이어가거나 처음부터 다시 할 수 있다고 설명한다. 메가야도란·메가폭타·메가우츠보트의 새 턴제 전투에 세 구간을 적용했다. 파티가 쓰러지면 파티를 회복하고 현장에서 재도전하거나 처음부터 시작할 수 있다. 기권은 이전처럼 처리하고 새 구간 기록을 만들지 않는다.

기록은 사건별로 분리하고 저장·재접속 후 유지한다. 이미 진행 중인 구형 전투 스냅샷은 기존 패배 처리로 끝나며, 새로 시작한 전투에서만 새 규칙을 적용한다. 승리하거나 처음부터 다시 시작하면 해당 사건의 기록을 지운다. 보상·기존 진행·다른 사건 기록은 보존한다.

이는 원작 실시간 전투를 기존 싱글 턴제로 근사한 것이다. 원작의 동료 동시 참전, 공격 회피·실시간 HP 유지와 25% 구간의 세부 전투 양상은 재현하지 않는다. 운영 환경과 실제 기기는 검증하지 않았다.

같은 구간 재도전 규칙을 미션 27~29와 32~34의 여섯 폭주 메가 사건에도 적용했다. 사건별 현장·출입구와 완료·보상 플래그는 그대로 사용하고, 기록은 사건별로 별개다. 해당 사건의 구형 배틀 스냅샷은 변경하지 않는다. 실시간 동료·지형 공격은 여전히 미구현이다.
