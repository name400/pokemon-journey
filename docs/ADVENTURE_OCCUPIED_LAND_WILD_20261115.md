# 야생 구역의 발밑 출현 보호

구역 5·7·9·10·11·12·16의 보이는 지상 개체는 이전 저장이나 재출현 시 플레이어가 같은 칸을 점유해도 표식이 표시될 수 있었다. 일곱 구역에 공통 판정을 연결해 점유 중에는 해당 개체를 숨기고, 플레이어가 벗어나면 같은 출현 기록으로 다시 표시한다. 점유한 소진 개체의 주기 갱신은 이동할 때까지 미룬다. 저장된 이로치·우두머리·소진 기록을 별도로 지우거나 재추첨하지 않는다.

맵 생성에서는 각 개체의 좌표를 한 번씩 비교하며 이동마다 추가 DB 조회나 넓은 탐색을 하지 않는다. 수중 개체는 수면 충돌과 구형 저장을 보호하기 위해 기존 동작을 유지한다. 구역 8 땅속 개체와 다른 특수 출현은 별도 검토가 필요하다. 이는 원작의 정확한 실시간 등장 애니메이션에 대한 주장이 아닌 이 게임의 저장·이동 안전 처리다.

일곱 구역의 저장 좌표와 지상 표시, 대표 수중 조우, 구역 10의 이로치 보존과 점유 중 주기 갱신 연기, 기존 구역 지도를 검사했다. 실제 운영 기기와 Sites 병합본은 검증하지 않았으며 모바일 이동 오류 기록을 유지한다.
