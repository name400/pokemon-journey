# 루주 4번지 파사주 옹브라제 외관

[원작 상점가 자료](https://www.pokepedia.fr/Passage_de_l%27Ombre)는 루주 4번지의 파사주 옹브라제가 유리 천장 복도이며 북쪽 루주 3번지와 남쪽 루주 1번지에 출입구가 있다고 설명한다. 기존 화면의 상점가 외곽과 유리 지붕, 앞 도로를 구분했다.

현재 화면의 지붕·건물 치수와 도로 좌표는 기존 2D 추정이다. 외관의 상점가 표식은 안내이며 실내 출입은 기존 북쪽·남쪽 경로를 사용한다. 원작의 정확한 외관과 높이는 확인하지 못했다. 타일·충돌·상호작용·실내 및 저장은 변경하지 않았다.

루주 3·4·5번지 왕복과 기존 저장 복원 검사 및 타입 검사가 통과했다. 모의 API를 사용한 PC·모바일 Chromium 화면과 외관 안내 대화를 확인했다. 원작 기기와 실제 Sites 병합본은 확인하지 않았다. 모바일 이동 오류의 운영 재검증 기록은 testfailed.md에 유지한다.
