# 블루 6번지와 8번지 지상 접근

[블루 6번지](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-6.html)와 [블루 8번지](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-8.html)의 지역 안내는 두 번지가 남북으로 인접한다고 각각 설명한다. 기존 지도에서는 직접 이동하지 못하고 상가 통로를 돌아야 했다.

두 지도에 지상 왕복 접근을 추가했다. 정확한 출입점과 길의 선형·폭은 2D 추정이다. 기존 상가, 남쪽 대로, 광장, 에스파스 비드 및 블루 4번지 연결을 유지하고 기존 통행 칸을 막지 않았다. 저장 형식과 진행 상태는 변경하지 않았다.

대표 단위 검사에서 새 출입 양방향·저장 복원과 기존 연결을 확인했다. 원작 실기, 운영 D1과 실제 Sites 병합본은 확인하지 않았으며 모바일 이동 오류와 배포 검사 실패 기록은 유지한다.
