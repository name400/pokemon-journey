# 전투 중 대기 파티 회복

[회복 안내](https://www.sportskeeda.com/pokemon/how-heal-pokemon-legends-z-a)는 가방의 회복 도구를 선택한 포켓몬에게 사용할 수 있다고 설명한다. 이 게임의 턴제 전투에서는 가방의 대기 포켓몬 항목에서 상처약·상태 회복 도구를 선택하면 플레이어의 한 턴을 소비한다. 원작의 실시간 메뉴와 대기시간을 재현한 것은 아니다.

단일 전투, 동료 및 1대2 전투, 세 아군 전투에 자신의 살아 있는 대기 파티원 대상 처리를 연결했다. 동료나 보관함 개체는 서버에서 거절하며, 기절 대상은 기존 부활 도구만 쓴다. 기존 출전 포켓몬 회복 호출과 저장 형식은 유지한다. 대여·식당·통신 전투의 기존 제한을 넘는 대기 대상 사용은 허용하지 않는다.

격리 SQLite API에서 세 전투 형태의 회복, 해독, 재접속, 교체, 소유권·재고 보존 및 오래된 요청을 확인했고 세 아군 엔진의 소유권과 복원도 검사했다. 모의 API·대체 이미지를 사용한 Chromium 390×844 및 1280×850에서 회복 대상 선택과 재접속을 확인했다. 실제 운영 D1·기기와 세 아군 전체 API 흐름의 대기 회복은 확인하지 않았다.
