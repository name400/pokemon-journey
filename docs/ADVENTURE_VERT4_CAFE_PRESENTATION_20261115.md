# 베르 4번지 카페와 홀로베이터 표현

[원작 지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-4.html)는 베르 4번지와 베르날 애비뉴·주변 번지의 연결, 홀로베이터와 건물 옥상·안뜰을 설명한다. [카페 자료](https://bulbapedia.bulbagarden.net/wiki/Caf%C3%A9_Classe)는 아라모드 카페가 베르 4번지 건물의 베르날 애비뉴 쪽에 있음을 설명한다. 기존 초안의 카페 건물과 도로를 구분하고 기존 홀로베이터 타일에 표식을 표시했다.

카페·건물의 모양과 출입·홀로베이터의 격자 좌표는 측량하지 않은 2D 추정이다. 원작의 정확한 옥상·안뜰 높이와 동선은 추가 대조가 필요하다. 타일·충돌·상호작용·기존 층·저장은 변경하지 않았다.

베르 4번지와 주변 구역 연결 및 지상·옥상·안뜰 저장 검사 3건과 타입 검사가 통과했다. 모의 API를 사용한 PC·모바일 Chromium 화면과 홀로베이터 대화를 확인했다. 원작 기기 및 실제 Sites 병합본은 확인하지 않았다.
