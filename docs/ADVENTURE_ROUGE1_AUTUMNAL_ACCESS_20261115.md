# 루주 1번지와 오토널 대로 지상 접근

[루주 1번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/rouge-sector-1.html)는 남서쪽 오토널 대로 접근을, [오토널 대로 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/autumnal-avenue.html)는 남쪽 루주 1번지 접근을 설명한다. 기존 지도에는 두 화면 사이의 직접 지상 경로가 없었다.

기존 지상 화면에 왕복 접근을 추가했다. 출입 좌표와 길의 선형·폭은 원작에서 측정되지 않은 2D 추정이다. 루주 3번지·광장 접근, 상가와 전투장·미션, 야생 구역 18의 랭크 제한을 유지한다. 이전 통행 칸을 막거나 저장 형식·진행 상태를 바꾸지 않는다.

대표 단위 검사에서 양방향 이동·저장 복원, 기존 출입·미션 상호작용과 구역 18 제한을 확인했다. 원작 실기·운영 D1·실제 Sites 병합본은 확인하지 않아 모바일 이동 오류와 배포 검사 실패 기록을 유지한다.
