# 리오르와 데덴네 옥상 획득

도감에 필요한 리오르는 기존 트레이너 배틀에 등장하고 루카리오 선물도 있지만, 조사한 클라우드 탐험 야생 포획 경로에서는 확인되지 않았다. [리오르 위치 안내](https://www.siliconera.com/where-to-find-riolu-in-pokemon-legends-z-a/)의 파사주 옹브라제 옥상 낮 출현과 [날씨 안내](https://allthings.how/riolu-in-pokemon-legends-z-a-early-locations-spawn-rules-and-evolution/)의 맑은 날 조건을 기준으로 기존 옥상에 레벨 18 개체를 배치했다. 이 게임은 흐림과 쾌청을 구분하지 않아 비가 아닌 날을 맑음의 근사치로 취급한다.

데덴네는 기존 구역 20 우두머리 후보에 있으나 원작처럼 일찍 접근할 수 있는 일반 옥상 개체는 없었다. [데덴네 위치 안내](https://www.powerpyx.com/pokemon-legends-z-a-dedenne-location/)의 마젠타 6번지 옥상에 기존 사다리로 접근하는 레벨 20 개체를 추가했다. 정확한 2D 좌표·데덴네 레벨·출현 확률은 초안이며 두 종의 희귀 출현과 행동은 재현하지 않는다.

두 위치는 기존 통행 불가 타일이어서 보유 개체와 저장 위치를 바꾸지 않는다. 격리 API에서 두 옥상의 접근·포획·재접속·중복 요청, 리오르의 날씨·시간 제한과 진화를 확인했다. 진화 검사는 포획 개체의 친밀도를 시험 데이터로 설정했으며 정상 육성 전체를 검증한 것은 아니다. 이 변경만으로 미르 도감이나 연구 레벨 50을 정상 완주할 수 있다고 보장하지 않는다.
