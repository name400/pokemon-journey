# 존느 스트리트 음료 가판대

- 존느 지구 가판대에서 맛있는물(200), 미네랄사이다(300), 후르츠밀크(400), 튼튼밀크(600)를 판매한다. 원작 가격 참고: https://www.serebii.net/pokearth/lumiosecity/jaunedistrict.shtml .
- 후르츠밀크와 튼튼밀크는 각각 HP 70, 100을 회복한다. 원작 도구 효과 참고: https://www.serebii.net/legendsz-a/items.shtml . 기존 맛있는물과 미네랄사이다 사용 경로는 유지한다.
- 현재 2D 맵의 가판대 좌표와 인물 외형은 원작의 정확한 위치나 외형을 확인한 결과가 아니라 접근 가능한 임시 배치다. 전투 중 사용은 기존 턴제 전투에 맞춘 구현이다.
- 맛있는물의 기존 월드 저장과 다른 음료의 기존 인벤토리 저장을 유지하며, 구매는 서버에서 재고 상한과 재화를 검사한다. 기존 저장 마이그레이션은 없다.
- 로컬 API 대표 검사에서 네 음료 구매, 중복 요청과 상한, 파티 소유권, 필드 사용 및 단일·1대2·동료·3자리 전투 사용을 확인했다. 실기와 실제 Sites 병합본, PC·모바일 브라우저 화면은 확인하지 않았다.
