# Defog field cleanup through Substitute — 2026-11-18

The pinned source's Defog removes side hazards/screens as self-targeted attributes but declares `ClearTerrainAttr` and `ClearWeatherAttr` as target effects. Target effects are skipped when the move is absorbed by Substitute unless Infiltrator bypasses it: [Defog](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/data/moves/move.ts#L10167), [target effects](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/phases/move-effect-phase.ts#L535), [Substitute check](https://github.com/pagefaultgames/pokerogue/blob/7c0881255af5cd51992e513ff93c2f71adbe40e0/src/data/moves/move.ts#L465). An isolated pre-fix native battle showed Defog incorrectly clearing Electric Terrain through the target's Substitute.

New runs carry `defogSubFieldRule: source-v1` into combat. On an ordinary Defog against an unbypassed Substitute, the native terrain-clear call and local fog-clear action are skipped while target-side screen cleanup still runs, and a successful hit is not reported as a failure merely because the target effects were blocked. The terrain callback is restored after the move callback even on exception. Active or passive Infiltrator permits field clearing; blocked moves and existing battles without the flag retain their prior behavior.

Isolated tests cover singles, doubles, terrain plus fog, screens, Protect, direct and passive Infiltrator, suppressed Infiltrator, Magic Bounce, actual command, PP, serialized restore, another value and legacy saves. The ten-file related suite passed 99 tests. This is engine-level validation; browser, actual devices, all terrain types, all ability interactions and source-runtime side-by-side remain unverified. No running server or user save was used.
