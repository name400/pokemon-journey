# 메가결정의 재생 안내

호텔 옥상과 구역 9 옥상의 반복 결정은 부순 직후 상호작용에 남은 재생 시간을 표시하고 부수기 버튼을 숨긴다. 다시 조회할 때 서버 시각으로 판정하므로 별도 주기 요청이나 기기 시계가 필요하지 않다. [조각 자료](https://www.serebii.net/itemdex/megashard.shtml)는 작은 결정과 큰 결정 모두 600초를 제시하지만, 다른 공략은 다른 시간을 적어 실제 기기에서의 재생 조건은 확인되지 않았다. 기존 10분 규칙을 유지한다.

구역 9에서도 인식하지 못하는 결정 기록 형식은 덮어쓰지 않는다. 저장 리비전과 조각·경험치 지급 규칙은 그대로다. 대기 표시는 마지막 서버 응답 시점을 기준으로 하며 실시간으로 줄어드는 타이머는 아니다. 운영 D1·Sites 병합본은 검증하지 않았다.
