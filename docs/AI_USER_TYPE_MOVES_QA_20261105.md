# 사용자의 타입이 필요한 기술의 적 AI

신규 도전의 `enemyAiUserTypeRule: source-v1`에서 적 AI는 현재 불꽃 타입이 아닌 사용자의 불사르기와 현재 전기 타입이 아닌 사용자의 더블쇼크를 기절 후보에서 제외하고 점수를 낮춘다. 다이맥스 기술은 원래 기술의 실패 조건을 적용하지 않는다. 기존 도전의 판단은 유지한다.

원본 `RequireTypeCondition`과 양쪽 기술 정의, 전투 엔진의 `onTryMove`를 대조했다. 조건의 충족·불충족, 타입 변경 후 저장·복원, 다이맥스 예외, 이전 도전과 다른 슬롯 보존을 격리 전투에서 검사했다.

남은 범위: 테라스탈·변신 및 특성으로 인한 타입 변경의 모든 조합, 전체 조건부 기술, AI 대상·교체·난수 동등성과 실제 브라우저 플레이는 별도 검증이 필요하다. 운영 데이터와 Sites는 변경하지 않았다.
