# 베르 9번지 건물 사이 골목

[베르 9번지 지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-9.html)는 두 건물 단지 사이 골목을 언급한다. 이는 2차 자료이며 골목의 정확한 길이·폭·방향은 확인되지 않았다.

기존 두 건물 블록 사이의 통행 가능한 일반 바닥을 보행면으로 구분했다. 좌표와 크기는 압축된 2D 지도의 추정이다. 새 충돌이나 아이템은 추가하지 않았으며 기존 운하·다리·야생 구역 출입·의뢰 및 저장 형식을 유지한다. 골목의 원작 도구는 아직 추가하지 않았다.

모바일 이동 오류와 Sites 병합본 실패 기록은 운영 재검증 전이므로 유지한다.

후속으로 같은 [지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/vert-sector-9.html)에 기록된 리피트볼과 좋은상처약을 골목에 추가했다. 자료는 두 건물 단지 사이 골목이라는 상대 위치만 제시하므로 각 물품의 타일과 골목 폭은 기존 2D 맵에 맞춘 추정이다. 두 물품은 통행 가능한 칸으로 표시하고, 기존 저장에 있던 좌표도 이동시키지 않는다.

수집은 기존 볼·회복약 보유 한도와 저장 리비전을 따르며, 한도가 찼거나 알 수 없는 수집·볼 보관 형식이면 기록을 덮어쓰지 않는다. 격리 지도·API 검사에서 경로와 구형 위치, 수집·재접속·한도·중복 요청 및 파티 보존을 확인했다. 원작 기기, 운영 D1과 Sites 병합본은 확인하지 않았다. 위의 도구 미구현 문장은 이 내용으로 갱신한다.
