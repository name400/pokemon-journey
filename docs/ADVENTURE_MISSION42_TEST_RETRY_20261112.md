# 미션 42 연속 전투 검사

지하 대결 경로를 확인하던 기존 테스트가 두 번째 전투 이후 진행 단계 2 대신 0을 반환한 적이 있었다. 최초 실패에는 상세 전투 로그가 남지 않았다. 같은 검사를 턴별로 계측한 별도 재현에서 일곱 번째 실행에 동일한 단계 불일치가 나타났다. 지가르데 50%폼이 악 타입으로 테라스탈하자 뮤츠의 사이코브레이크가 무효가 되었고, 파동탄 이후 깨물어부수기에 쓰러졌다. 실제 승자는 지가르데였고 패배 뒤 단계 0으로 돌아간 것은 연속 전투의 기존 규칙에 부합한다. 최초 실패와 완전히 같은 난수 경로였는지는 확인할 수 없다.

검사의 목적은 세 단계 승리 후 포획과 재방문 경로 확인이므로 각 승리 전투의 상대를 1 HP·잠듦으로 설정해 전투 밸런스의 우연한 패배에 좌우되지 않게 했다. 별도로 두 번째 단계에서 실제 공격으로 플레이어가 쓰러지는 경우를 구성해 패배자·단계 초기화·파티 회복·지하 퇴장을 확인한다. 최초 수동 기권 검사는 유지한다. 이는 진행 처리 검사이며 정상 난이도의 승률을 검증한 것은 아니다. 실제 원작 기기와 운영 서버는 확인하지 않았다.
