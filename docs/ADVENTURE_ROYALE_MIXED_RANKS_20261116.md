# 로열 인접 랭크 상대: 확인 범위와 구현

- [Serebii 로열 안내](https://www.serebii.net/legendsz-a/z-aroyale.shtml)는 스토리 중 배틀존에서 자신의 랭크와 한 단계 위·아래 랭크의 상대가 등장한다고 설명한다. [초반 공략](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Part_6)도 상대 랭크에 따라 획득 포인트가 달라지는 흐름을 설명한다.
- 이번 구현은 X 구역의 Y·W, W 구역의 X·V 상대를 추가한다. 상대 팀은 프로젝트에 이미 기록된 해당 랭크 트레이너 데이터를 재사용하며 Y 400, X 450, W 500, V 550점을 상대 랭크 기준으로 지급한다. X·W 승급에 쓰이는 기존 점수 필드와 상한을 유지한다.
- **근사:** 새 상대의 두 타일 위치와 항상 등장하는 방식은 기존 2D 맵에 맞춘 배치다. 원작의 위치·출현 확률·개별 직업 보상은 확인하지 못했다. 나머지 랭크의 인접 상대는 이번 범위 밖이며 원작 전체 재현으로 보지 않는다. 턴제 전투는 기존 방식을 유지한다.
- 기존 저장의 위치가 새 상대 타일과 겹치면 플레이어가 떠날 때까지 해당 상대를 표시하지 않는다. 방문별 승리 기록은 별도 필드에 보존하고, 인식할 수 없는 기존 필드는 덮어쓰지 않는다. 이전 전투와 포켓몬·기존 보상 데이터는 소급 변경하지 않는다.
- 검증 범위: 지도 경로 및 저장 좌표 겹침, 격리 SQLite의 실제 API를 통한 X/W 각각 두 상대의 승리·점수·중복 방지·재접속·알 수 없는 저장값 보존. 실제 운영 배포와 모바일 기기 검증은 포함하지 않는다.

후속 수정: 배틀존 재입장 시 승리 배열 전체를 초기화하던 경로는 알 수 없는 배열 항목도 지울 수 있었다. 현재 구현에서 아는 네 상대 ID만 제거하고 나머지 항목은 원래 순서와 값으로 보존한다. 격리 API에서 재입장·재접속 후 점수와 기존 포켓몬을 유지하면서 같은 상대에게 다시 도전할 수 있음을 확인했다. 운영 저장에 해당 미확인 항목이 실제 존재했는지는 확인하지 못했다.
