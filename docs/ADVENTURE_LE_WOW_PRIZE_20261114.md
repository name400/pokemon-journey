# 르 와우 연속 배틀 상금

[원작 공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-094-full-course-of-battles-three-stars)은 열 명의 트레이너가 각각 승리 시 3,960원을 지급하고 최초 의뢰 보상은 별도 2,000원이라고 설명한다. 이전 구현은 첫 도전에서 전투 상금을 지급하지 않았고, 재도전에서는 코스마다 4,000원을 지급했다. 이제 새로 시작하는 코스의 전투에 3,960원과 금색 인형 보정을 적용한다. 최초 및 반복 완료 보상, 재도전 비용은 유지한다. 원작 실기에서 금액을 직접 확인하지는 않았다.

이미 진행 중인 구형 전투는 시작 당시 규칙을 보존한다. 구형 최초 도전은 전투 상금이 없고 구형 재도전은 4,000원을 지급한다. 다음 새 코스부터는 새 상금을 적용하며 기존 저장의 완료 보상은 소급하지 않는다. 지갑이 안전한 정수 한도를 넘는 승리의 결과는 저장하지 않아 상금이 유실되거나 잔액이 손상되지 않는다. 이 극단적 상황에서는 포기하고 지갑 잔액을 낮춰야 하는 제한이 남아 있다.

격리 SQLite API에서 최초 10코스 상금, 재도전, 금색 인형, 구형 전투, 포기, 중복 요청과 기존 완료 보상을 검사했다. 금색 인형과 구형 저장의 승리 사례는 적 HP·상태를 조정했으므로 일반 난이도 검증이 아니다. 운영 D1, Sites 병합본과 실제 기기는 확인하지 않았다.
