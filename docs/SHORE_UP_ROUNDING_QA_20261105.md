# 모래모으기의 날씨와 반올림

원본의 `shoreUpHealRatioFunc`와 `HealAttr.addHealPhase`에 맞춰 신규 도전의 `shoreUpSourceRule: source-v1`에서 모래모으기는 유효한 모래바람일 때 최대 HP의 2/3, 그 외에는 1/2을 반올림해 회복한다. 메가솔은 사용자 관점의 날씨를 햇살로 취급한다. 이전 도전은 해당 도전의 기존 규칙과 기존 메가솔 수정을 유지한다.

격리 전투와 저장 복원에서 홀수 HP의 반 회복, 높은 HP의 모래바람 회복, 메가솔·날씨부정, 안개·비, 치유 부적, 상대 사용 및 다른 저장 데이터 보존을 검사했다. 다른 특성·도구의 모든 조합과 실제 브라우저 플레이는 별도 검증이 필요하다. 운영 데이터와 Sites는 변경하지 않았다.
