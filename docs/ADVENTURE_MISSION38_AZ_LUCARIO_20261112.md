# 미션 38의 AZ가 남긴 루카리오

[원작 이벤트 자료](https://bulbapedia.bulbagarden.net/wiki/List_of_in-game_event_Pok%C3%A9mon_in_Pok%C3%A9mon_Legends%3A_Z-A#Lucario)는 미션 37 이후 호텔 202호에서 AZ가 남긴 루카리오를 선택적으로 받는다고 설명한다. 레벨 50, 수컷, 무보정 성격, 불굴의마음, 색이 다른 모습 없음, 개체값 31/20/31/20/31/20과 대여 당시의 파동탄·불릿펀치·바위깨기·방어를 적용했다. 트레이너 Korrina와 ID 912562는 개체 메타데이터로 보존한다. [다른 선물 목록](https://www.serebii.net/legendsz-a/giftpokemon.shtml)은 기술 네 개를 다르게 기재하므로 해당 기술 구성은 실기 대조가 필요하다. 테라스탈 타입은 기존 탐험 개체 규칙에 따라 생성 시 결정한다.

202호 탁자에 몬스터볼을 표시하며, 자리의 정확한 좌표와 실내 외형은 2D 초안이다. 수령은 선택 사항이고 파티가 가득 차면 보관함으로 보내며 한 번만 받을 수 있다. 미션 37 이전에는 나타나지 않고, 이미 미션 38을 끝낸 기존 저장에서도 받을 수 있다. 기록·개체 생성과 도감 등록은 같은 저장 처리에서 이뤄지며 파티의 기존 포켓몬, 재화와 스토리 진행을 변경하지 않는다. 원작 실기와 운영 환경은 검증하지 않았다.
