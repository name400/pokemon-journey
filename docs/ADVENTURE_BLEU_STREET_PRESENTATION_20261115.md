# 블루 거리의 건물과 도로

[지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-street.html)와 [도로 설명](https://bulbapedia.bulbagarden.net/wiki/Bleu_Street)은 블루 거리가 광장을 지나 여러 블루 구역과 연결되고 북쪽 일부는 야생 구역 5에 포함된다고 설명한다. 기존 2D 화면의 두 건물에 지붕·입면을 그려 보행면과 구분하고, 포장 경계와 기존 카페 표식을 강조했다. 화면의 카페 갈랑은 기존 임시 위치이며 새 시설이나 기능을 추가하지 않았다.

건물 모양·높이, 도로 폭과 카페 좌표는 원작에서 추출한 것이 아닌 추정이다. 기존 타일과 충돌, 출입 동선, 조우 및 저장 위치는 바꾸지 않았다.

기존 블루 광장·남쪽 대로·인접 구역 왕복과 저장 복원 단위 검사 2건 및 타입 검사가 통과했다. PC·모바일 Chromium에서 모의 API로 화면과 기존 카페 안내를 확인했다. 원작 기기·운영 D1·Sites 병합본은 확인하지 않았다.
