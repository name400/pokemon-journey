# 탐험모험 미용실

파사주 옹브라제, 달의 갤러리, 블루 구역 8의 기존 미용실에서 머리 모양과 색상을 선택하고 미리 본 뒤 3,000코인으로 변경한다. 세 곳은 같은 외형을 공유한다. 기존 모자 모습과 세 가지 머리 모양, 네 가지 색상은 이 게임을 위한 제한적인 픽셀 표현이며 원작의 전체 외형 목록이나 정확한 외형 재현이 아니다. 눈썹 등 다른 미용 옵션과 추가 해금은 아직 없다. 기존 모자 모습으로 되돌리는 선택에도 같은 비용을 적용한다.

원작의 미용실에서 머리 모양과 색을 고르고 3,000원을 지불하는 흐름은 [Game8 공략](https://game8.jp/pokemon-legends-z-a/730162)을 참고했다. 각 타일의 정확한 원작 위치를 이 변경에서 새로 검증하지 않았으며 게임에 이미 있던 입구를 사용한다.

외형이 없는 기존 저장은 기존 모자로 표시한다. 변경 요청은 서버에서 위치, 전투 상태, 외형 및 잔액을 확인하고 저장 리비전과 잔액 조건으로 결제와 외형을 함께 반영한다. 같은 외형 재요청은 결제하지 않는다. 외형 변경은 기존 포켓몬이나 진행 기록을 변환하지 않는다.

검증은 격리 API 테스트와 모의 API를 사용하는 PC·모바일 Chromium 화면 테스트를 사용한다. 실제 운영 환경과 물리 기기에서는 검증하지 않았다.
