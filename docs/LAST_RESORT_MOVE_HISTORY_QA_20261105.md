# 기술 변경 시 뒀다쓰기 이력

신규 도전에서 전투 진행 중 기술 구성을 동기화할 때, 기존에 그대로 남은 기술의 사용 여부를 기술 ID로 유지한다. 새로 추가된 기술은 미사용으로 시작하며, 이미 삭제한 기술을 후에 다시 배우더라도 사용 기록을 물려주지 않는다. 변경 전 구현은 기술 한 개가 바뀌어도 모든 사용 이력을 초기화했다. 기존 도전은 이전 동작을 보존한다.

원본의 조건은 교체 전에 사용한 이력을 기술 ID로 확인한다. 원본 코드에는 기술을 지운 뒤 다시 배우면 해당 이력을 초기화해야 한다는 미해결 주석이 있으므로, 이번 재학습 처리는 그 의도에 맞춘 동작이며 현재 원본의 모든 경계와 동일하다고 주장하지 않는다. 변신·호출 기술·스케치와 복합 기술 교체의 전수 검증은 남아 있다.

후속으로 변신 직전 기술에 남아 있는 직접 사용 이력의 일부를 복사 기술에 이어 주고, 잠꼬대·따라하기 사례를 확인했다. 상세 범위와 남은 차이는 [LAST_RESORT_TRANSFORM_QA_20261105.md](LAST_RESORT_TRANSFORM_QA_20261105.md)를 참조한다.

격리 야생 전투에서 기술 사용 후 다음 웨이브 전 기술 변경, 저장 복구, 바뀌지 않은 이력 보존, 새 기술 사용 뒤 뒀다쓰기 성공, 삭제 후 재학습 초기화 및 기존 규칙·다른 슬롯 보존을 확인했다. 실계정·실기기 검증은 하지 않았다.
