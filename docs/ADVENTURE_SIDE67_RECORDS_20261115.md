# 님피아 수로 의뢰 기록 보존

[의뢰 공략](https://www.thonky.com/pokemon-legends-z-a/side-mission-067-sylveon-the-soother)은 쿨랑 수로와 다리의 다섯 대화를 확인하고 Calma에게 돌아가는 흐름을 설명한다. 기존 2D 위치·의뢰·보상은 유지한다.

기존 코드는 새로운 대화를 기록할 때 알려진 ID만으로 배열을 다시 만들어 알 수 없는 항목이나 중복 기록을 지웠다. 이제 원본 배열에 확인한 ID만 더하고, 진행 개수와 완료 여부는 알려진 다섯 ID의 중복 없는 수로 계산한다. 의뢰 시작 전 이미 비어 있지 않은 기록과 배열이 아닌 형식은 덮어쓰지 않고 요청을 거절한다. 확인할 수 없는 형식은 거짓 진행 표식이나 수첩 진행도를 만들지 않는다. 기존 보유 개체·보상 및 정상 기록은 바꾸지 않는다.

격리 SQLite API에서 혼합·중복·미래 형식과 정상 다섯 대화, 재접속·중복 요청·보상을 확인했다. 원작 기기·운영 D1·Sites 병합본은 미검증이며 이전 실패 기록은 유지한다.
