# 기술머신 085 학습 호환

르 나 1성 보상인 대타출동의 학습 대상을 기존 스타터 일부와 피카츄에서 칼로스 스타터 세 계열, 이브이·랄토스·리오르 계열과 라이츄로 확장했다. 알로라 라이츄는 폼 ID와 종 ID가 모두 맞는 경우에만 허용한다. [학습 자료](https://www.dittobase.com/legends-za/moves/substitute)에서 해당 개체들을 확인했고, 원작 Z-A 목록으로 이전에 확인된 [별도 자료](https://www.serebii.net/attackdex-sv/substitute.shtml)와 대조했다. 원작 실기 대조는 하지 않았다.

Dittobase의 [이용 조건](https://www.dittobase.com/terms)은 허가 없는 대규모 수집·복제·재배포를 금지한다. 목록 전체를 일괄 수집하지 않았고 플레이에 중요한 일부 계열만 확인했다. 이번에 전달된 ns5 주소는 502, advent 주소는 404를 반환했다. 접근 제한을 우회하지 않았다. 나머지 종과 폼은 여전히 미지원이며 화면에서 확인 중이라고 안내한다. 포켓몬 데이터나 기존 기술은 소급 수정하지 않는다.

격리 API에서 구형 저장의 이브이·알로라 라이츄 학습, 기존 기술·PP, 기술머신 재사용, 미보유·중복·구형 리비전·잉어킹 거절과 재접속을 확인했다. 순수 함수에서는 대표 계열, 폼/종 ID 불일치와 미확인 폼을 검사했다. 운영 D1, Sites 병합본과 실기는 확인하지 않았다.

## 추가 확인

기존에 확인된 입문 포켓몬 등의 목록에 더해, 공개된 Legends: Z-A 기술머신 목록에서 확인한 일반 종 54종과 지역 폼 7종을 추가했다. 지역 폼은 알로라 나옹·페르시온·텅구리, 가라르 나옹·야돈·야도란·야도킹이다. 폼별 ID와 종 ID가 모두 일치해야 하며, 기존 기술머신 소유·중복 학습 조건은 그대로 적용된다.

- 종 대조: [Serebii 대타출동의 Legends: Z-A TM085 목록](https://www.serebii.net/attackdex-sv/substitute.shtml)
- 지역 폼 대조: [DittoBase 대타출동](https://www.dittobase.com/legends-za/moves/substitute)

위 자료는 2차 자료로, 해당 종과 기술머신의 관계만 개별 대조했다. 외부 데이터 파일을 복사하거나 접근 제한을 우회하지 않았다. 목록은 전체 호환 종을 망라하지 않으며 원작 실기 대조도 하지 않았다. 미확인 종과 폼을 일괄 허용하지 않는다.

대표 API 검사에서 일반 종과 지역 폼 학습, 기존 기술·PP·이로치 및 기술머신 보존, 재접속, 오래된 요청의 거절과 잉어킹의 비호환을 확인했다. 실제 Sites 병합본은 검사하지 않았다.
