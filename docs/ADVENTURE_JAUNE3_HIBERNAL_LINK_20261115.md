# 존느 3번지와 이베르날 지상 연결

[이베르날 애비뉴 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/hibernal-avenue.html)는 동쪽에 존느 3번지가 접한다고 설명한다. 기존에 막힌 화면 경계에 지상 왕복 출구를 추가했다. 출구 타일과 길의 정확한 형태는 기존 2D 화면에 맞춘 추정이다.

기존 4·5번지 및 남쪽 출입과 미션 12의 비계·옥상 사다리 조건, 저장 형식을 유지한다. 양방향 이동, 미션 사다리 제한·옥상 분리·기존 출입·저장 복원 및 모의 API PC·모바일 화면을 검사했다. 실제 운영이나 Sites 병합본은 확인하지 않았다. 모바일 D1 이동 오류 기록은 운영 재검증 전까지 유지한다.
