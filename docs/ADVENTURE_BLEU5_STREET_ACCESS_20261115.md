# 블루 5번지와 블루 거리 지상 접근

[블루 5번지 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-sector-5.html)는 서쪽 블루 거리 접근을, [블루 거리 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/bleu-street.html)는 동쪽 블루 5번지 접근을 설명한다. 기존 지도에서는 누보 카페나 블루 7번지 등을 경유해야 했다.

기존 지상 화면에 왕복 접근을 추가했다. 출입 좌표와 길의 선형·폭은 원작에서 측정되지 않은 2D 추정이다. 기존 카페·블루 7번지와 에이믈리스 공원 접근, 구역 12 입장 제한과 저층 수로를 유지한다. 이전 통행 칸을 막거나 저장 형식·진행 상태를 바꾸지 않는다.

대표 단위 검사에서 양방향 이동·저장 복원, 기존 출입·구역 12 제한과 연못 층을 확인했다. 원작 실기·운영 D1·실제 Sites 병합본은 확인하지 않아 모바일 이동 오류와 배포 검사 실패 기록을 유지한다.
