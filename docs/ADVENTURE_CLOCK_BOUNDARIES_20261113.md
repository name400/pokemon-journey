# 탐험모험 낮밤 경계

[Z-A 낮밤 자료](https://www.serebii.net/legendsz-a/daynightcycle.shtml)에 따라 클라우드 탐험모험의 낮을 게임 시각 04:00~19:59, 밤을 20:00~03:59로 구분한다. [시간 설명](https://bulbapedia.bulbagarden.net/wiki/Time)은 밤 직전의 해질녘에 낮·밤 전용 진화를 모두 할 수 없다고 설명한다. 이 구현은 기존 게임 시각으로 16:00~19:59를 해질녘으로 보고, 출현·로열 구역은 낮으로 취급하되 낮·밤 전용 진화는 막는다.

필드·로열·이로치 출현 갱신·진화가 같은 클라우드 시각을 사용한다. 기존 개인 오프셋의 단위를 바꾸지 않고, 구형 저장의 이전 출현 주기는 첫 조회에서 새 기준으로 다시 기록하되 이미 잡은 개체나 이로치를 초기화하지 않는다. 진행 중 전투는 보존하며, 구형 클라우드 저장에 엔진 태그가 없더라도 해당 API의 진화 판정은 클라우드 시계를 쓴다. 로컬 탐험 및 포켓로그의 기존 시계는 바꾸지 않는다.

호환성을 위해 실제 시간으로 한 시간당 50초와 휴식 시 08:00·20:00으로 이동하는 기존 규칙을 유지한다. 따라서 원작의 실제 주기 길이, 실내·메뉴·트레이너 배틀 중 시간 정지는 여전히 구현되지 않았다. 구역 갱신·진화·야간 구역·옛 저장·휴식은 격리 테스트로 확인한다. 실제 원작 기기 및 운영 환경은 검증하지 않았다.

추가 확인: [이로치 안내](https://www.pockettactics.com/pokemon-legends-z-a/shiny)는 시간대 전용 이로치가 반대 시간에 보이지 않다가 해당 시간대에 다시 나타난다고 설명한다. 구역 6의 낮 전용 이로치 요가랑으로 낮 → 밤 → 재접속 → 다음 날 낮을 격리 API에서 확인했으며, 다시 등장한 개체와 이어진 전투에서 이로치가 유지됐다. 기존 보유 개체는 변경하지 않았다. 이 검사는 다른 모든 시간대 전용 개체나 원작 기기의 동작을 전수 검증한 것은 아니다.
