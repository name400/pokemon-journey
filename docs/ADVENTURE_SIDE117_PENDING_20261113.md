# 사이드 미션 117 보상 보관

[Josée의 수련 자료](https://www.serebii.net/legendsz-a/sidemissions/josee%27straining.shtml)와 기존 구현의 전투·보상을 유지한다. 기존에는 달인의띠나 숙달의씨의 가방 수량이 가득 차면 보상 처리가 409로 막혀 후속 의뢰 118도 시작할 수 없었다.

도장의 보상을 확인하면 의뢰를 완료하고 기존 코인 보상은 한 번 지급한다. 도구는 가방에 들어가는 만큼 지급하고 나머지는 저장해 가방 화면에서 나누어 받을 수 있다. 리비전 조건과 재고 제한을 기존 원자적 저장에서 함께 검사한다. 이미 완료한 구형 저장에는 보관 보상을 생성하지 않는다. 보관·분할 지급은 이 게임의 가방 한도에 맞춘 처리이며 원작 동작으로 확인된 것은 아니다.

격리 SQLite API에서 기존 대련·동료 전투, 가방 한도, 후속 의뢰 시작, 분할 수령·재접속·오래된 요청 및 기존 완료 저장을 확인했다. PC·모바일 Chromium 화면은 모의 응답을 사용했다. 원작 실기기·운영 D1과 실제 Sites 병합본은 검증하지 않았다.
