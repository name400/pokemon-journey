# 야생 구역 18 공사 골목과 옥상

[원작 경로 안내](https://www.videogameschronicle.com/guide/pokemon-legends-z-a-wild-zone-18/)는 보만다 왼쪽 골목의 이어롭 근처 비계 사다리를 올라 옥상 입구에 접근하며, 푸호꼬 부근 굴뚝을 이용할 수 있다고 설명한다. 기존 공사 골목의 사다리 위에 별도 비계 발판과 야생 구역 옥상 입구를 연결하고 푸호꼬 부근 굴뚝을 장애물로 표시했다. 기존 거리·외부 사다리와 두 옥상 출입구는 유지한다. 옥상에서 다시 내려올 때 올라온 골목을 복구하며 저장·재접속 후에도 유지한다.

비계 발판의 모양과 정확한 사다리·입구·굴뚝 좌표는 확인하지 못했으므로 2D 초안이다. 구형 저장에서 옥상 사다리의 복귀 목적지가 공사 골목으로 기록돼 있으면 이전 목적지를 유지한다. 옛 옥상 저장이 새 굴뚝과 겹치면 같은 리비전의 구형 저장만 인접 통행 칸으로 복구한다. 기존 외부 비계의 지상 도착 칸은 포장도로일 수 있으므로 포장된 통행 칸도 허용한다.
