# 메가솔과 모래모으기

원본의 `getEffectiveWeatherForMove`, 모래모으기 회복 비율과 회복 반올림을 대조했다. 신규 도전의 `megaSolShoreUpRule: source-v1`은 메가솔 보유자의 모래모으기를 햇살 기준으로 최대 HP의 절반만큼 반올림해 회복시키고, 적 AI의 회복량 추정에도 같은 비율을 사용한다. 기존 도전은 기존 판정을 유지한다.

격리 전투에서 모래바람·비·맑은 날씨, 양측 사용, 패시브 메가솔, 위액에 의한 억제, 치유 부적, 저장·복원 및 다른 데이터 보존을 확인했다. AI가 특정 대안 기술 사이에서 선택을 바꾸는 경계 사례와 실제 브라우저 플레이는 검증하지 않았다. 다른 기술의 메가솔·날씨 조합, AI 대상·교체·난수와 도구·이벤트·폼 원본 동등성이 남는다. 운영 데이터와 Sites는 변경하지 않았다.
