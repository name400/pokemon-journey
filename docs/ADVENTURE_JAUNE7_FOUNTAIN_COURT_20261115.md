# 존느 7번지 분수 안뜰

[위치 자료](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/jaune-sector-7.html)는 존느 7번지 안뜰에 Croquis가 있다고 설명하고, [의뢰 자료](https://www.serebii.net/legendsz-a/sidemissions/stumpedatthefountain.shtml)는 분수의 가시덤불 제거를 설명한다. 기존 의뢰 위치 주변의 막힌 다섯 칸을 안뜰 바닥으로 열고 분수를 의뢰 해금 전에도 볼 수 있게 했다. 기존 분수·Croquis·가시덤불 좌표와 기존 통행 칸을 유지했다.

안뜰의 윤곽, 포장과 입구 타일은 기존 맵에 맞춘 2D 추정이며 정확한 원작 배치나 높이는 확인하지 못했다. 모든 의뢰 단계에서 안뜰 접근·가시덤불·대화를 확인하고 중간 저장을 복원했다. 첫 단위 검사에서 단계별 대화 제목을 동일하다고 잘못 예상했으며 실제 단계별 제목을 확인하도록 고친 뒤 통과했다. 기존 대로 출입과 모의 API PC·모바일 화면도 확인했다. 실제 운영이나 Sites 병합본 검증은 아니다. 모바일 D1 이동 오류 기록은 운영 재검증 전까지 유지한다.
