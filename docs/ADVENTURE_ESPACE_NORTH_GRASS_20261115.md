# 리앙 에스파스 북동쪽 잔디

[리앙 에스파스 지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/espace-vide.html)는 북동쪽 잔디 띠를, [Poképédia 안내](https://www.pokepedia.fr/All%C3%A9e_Ranavoir)는 북쪽 계단과 별도의 지하 수로를 설명한다. 모두 2차 자료다.

기존 지상 북쪽 계단 옆에 걸을 수 있는 잔디 띠를 추가했다. 폭과 좌표는 압축된 2D 지도의 추정이며 새 야생 조우는 추가하지 않는다. 기존 북쪽·남쪽 계단, 지하 수로와 저장 필드는 유지한다. 안내에 나온 슈퍼볼은 아직 추가하지 않았다.

모바일 이동 오류와 Sites 병합본 실패 기록은 운영 재검증 전이므로 유지한다.
