# 리앙 에스파스 북동쪽 잔디

[리앙 에스파스 지역 안내](https://altissimo1.github.io/Supplementary-Series/Legends/Lumiose-Locations/espace-vide.html)는 북동쪽 잔디 띠를, [Poképédia 안내](https://www.pokepedia.fr/All%C3%A9e_Ranavoir)는 북쪽 계단과 별도의 지하 수로를 설명한다. 모두 2차 자료다.

기존 지상 북쪽 계단 옆에 걸을 수 있는 잔디 띠를 추가했다. 폭과 좌표는 압축된 2D 지도의 추정이며 새 야생 조우는 추가하지 않는다. 기존 북쪽·남쪽 계단, 지하 수로와 저장 필드는 유지한다.

두 안내가 기술하는 북쪽 계단 옆 슈퍼볼을 잔디에 배치했다. 위치는 추정이다. 기존 볼 재고와 별도 수령 상태를 사용하며, 꽉 찬 재고와 중복 요청은 지급하지 않는다. 알 수 없는 수령 상태나 층 값은 보존한다. 격리 SQLite API에서 재고 한도, 지급, 재접속, 중복 요청, 알 수 없는 수령 상태 및 파티·진행 보존을 확인했다.

모바일 이동 오류와 Sites 병합본 실패 기록은 운영 재검증 전이므로 유지한다.
